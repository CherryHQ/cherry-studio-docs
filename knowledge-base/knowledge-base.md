# 知识库入门

知识库把文件、笔记、目录或网页整理成可检索的资料集合。你可以先检查系统能否找回正确片段，再把这些片段交给对话或 Agent 使用。

> 本章的目标：用最短路径完成一次“创建 → 导入 → 召回测试 → 使用”，并知道后续应该到哪一章继续。

### 什么时候适合使用知识库

适合放入知识库的内容通常有两个特点：以后还会反复查询，并且答案应该以你自己的资料为准。例如员工制度、产品手册、项目文档、研究资料和常见问题。

下面几种情况不必先建知识库：

* 只需要处理一次的短文本，直接粘贴到对话更快。
* 需要模型读取一个临时附件，直接在对话中上传即可。
* 资料还没有整理到可判断真伪的程度，先在笔记中梳理更合适。

### 先认识 6 个词

| 名称    | 含义                        |
| ----- | ------------------------- |
| 知识库   | 一组围绕同一主题组织的资料和检索设置        |
| 资料条目  | 导入的一个文件、笔记、目录中的文件或网页快照    |
| Chunk | 资料被切分后用于检索的小片段            |
| 召回    | 根据问题找出最相关片段的过程            |
| 嵌入模型  | 把文字转换为向量，用于按语义找相近内容；不是必选项 |
| 重排序模型 | 对候选片段重新排序；也是可选项           |

### 一次回答经历什么

BM25 关键词检索可以单独工作。配置嵌入模型后，系统会同时利用语义相似度；配置重排序模型后，还可以对候选结果再次排序。

### 5 分钟快速开始

1. 打开顶部的【知识库】，点击新建按钮。
2. 输入名称。第一次体验时可以把嵌入模型设为【不使用】，先用关键词检索跑通流程。
3. 打开知识库，点击添加资料按钮，选择【文件】、【笔记】、【目录】或【链接】。
4. 等待资料状态变为【就绪】，再打开资料预览或 Chunks 检查内容。
5. 进入【召回测试】，输入一个你已经知道答案的真实问题。
6. 召回正确后，在对话中选择知识库，或把知识库绑定到 Agent。

### 怎样判断已经可以使用

满足下面三个条件后，再进入对话或 Agent：

* 需要的资料都显示【就绪】，没有长期停在处理中或错误状态。
* 随机打开一两条资料，正文和 Chunks 没有乱码、缺页或明显错序。
* 用 3～5 个真实问题做召回测试，正确来源能够稳定出现在前几条结果中。

### 推荐阅读顺序

第一次使用时，按下面顺序学习即可：

1. 创建知识库
2. 添加与整理资料
3. 检查资料与召回
4. 在对话中使用 或 与 Agent 一起使用

需要进一步调优时，再阅读模型与检索设置和文档解析与 OCR。涉及备份和隐私时，请看数据、隐私与维护。

### 常见误区

* 知识库不等于聊天模型。它负责找资料，聊天模型负责根据资料组织回答。
* 没有嵌入模型也能使用知识库，此时主要依赖 BM25 关键词检索。
* 导入成功不等于质量合格，召回测试才是进入正式使用前的验收步骤。
* 修改切分设置不会自动改变旧条目；旧资料需要重新索引。
