# 知识库教程

知识库可以把本地文档和网页整理成可检索的资料库。聊天时，Cherry Studio 会先找出与问题相关的片段，再把这些片段交给当前模型生成回答。

知识库不会训练或修改模型。它适合需要反复查询、跨对话复用，或资料量较大、不方便每次作为附件发送的场景。

本页带你完成一次完整流程：**准备嵌入模型 → 创建知识库 → 添加资料 → 测试召回 → 在对话中使用**。

{% hint style="info" %}
如果只想快速了解用途，可以先看[知识库功能介绍](../cherrystudio/preview/knowledge-base.md)。模型选择、数据存储和文档解析分别参见[嵌入模型](emb-models-info.md)、[知识库数据](data.md)和[文档预处理](document-preprocessing.md)。
{% endhint %}

## 使用前准备

创建知识库前，至少需要配置一个可用的**嵌入（Embedding）模型**。嵌入模型负责把资料和问题转换成可检索的数据，普通聊天模型不会出现在知识库的嵌入模型列表中。

在 **设置 → 模型服务** 中完成服务商配置，并确认目标模型：

* 已添加到模型列表并处于启用状态
* 能力类型包含嵌入
* API 地址、密钥和网络连接可正常使用

模型列表可能随服务商变化，文档不固定推荐某个在线模型。选择方法和常见模型请查看[嵌入模型](emb-models-info.md)。

## 创建知识库

1. 打开顶部启动台，在应用列表中选择**知识库**。
2. 点击左侧导航区域的添加按钮，选择**创建知识库**。
3. 输入一个便于识别的名称。
4. 如已创建分组，可选择知识库所属的分组。
5. 选择已启用的嵌入模型，完成创建。

创建窗口只显示带有嵌入能力标记的已启用模型。如果列表为空，请先返回模型服务设置检查配置。

{% hint style="warning" %}
嵌入模型和向量维度决定索引格式。批量导入资料前，建议先用少量内容完成一次召回测试。后续更换嵌入模型或维度时，需要通过重建流程重新生成索引。
{% endhint %}

## 添加资料

进入知识库后，点击数据源区域的添加按钮，选择资料来源。

| 来源 | 适合内容 | 当前说明 |
| --- | --- | --- |
| 文件 | 一个或多个本地文件 | 支持 PDF、DOCX、MD、XLSX、TXT、CSV、EPUB |
| 文件夹 | 同一目录中的一组资料 | 选择本地目录后批量导入 |
| 网址 | 单个公开网页 | 输入完整的 `http://` 或 `https://` 地址 |
| Sitemap | 网站中的多篇页面 | 输入可直接访问的 Sitemap 地址 |
| 笔记 | 手动输入文本 | 当前 V2 添加界面中尚未开放提交 |

### 导入文件

1. 选择**文件**。
2. 拖入文件，或点击选择本地文件。
3. 确认文件列表后提交。
4. 返回数据源列表，等待处理完成。

一次可以选择多个文件。若文件格式不受支持，应先转换为上表中的格式。

### 导入文件夹

1. 选择**文件夹**。
2. 点击选择目录，并确认系统文件访问权限。
3. 确认目录后提交。

文件夹适合集中导入一组资料。导入后仍应检查数据源列表，确认需要的文件都已成功处理。

### 导入网页或 Sitemap

1. 选择**网址**或 **Sitemap**。
2. 输入可公开访问的完整地址。
3. 提交后等待页面抓取和索引完成。

网页需要登录、动态脚本才能显示，或启用了访问限制时，Cherry Studio 可能无法提取有效内容。Sitemap 也必须是应用能够直接访问的地址。导入完成后，建议先预览提取结果并进行召回测试。

{% hint style="info" %}
添加任务提交后，资料会在后台继续读取、分块和嵌入。不要在处理过程中退出应用或断开模型服务。
{% endhint %}

## 检查处理状态

资料建立索引时会依次经历准备、读取、处理、分块和嵌入等阶段。不同来源显示的中间状态可能不同，最终以**已完成**为准。

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 准备中 / 读取中 / 处理中 / 分块中 / 嵌入中 | 正在建立索引 | 保持应用运行并等待 |
| 已完成 | 可以被检索并用于聊天 | 先进行召回测试 |
| 失败 | 当前资料没有完成索引 | 查看错误原因，修复后重新索引 |

数据源列表还可以：

* 按文件、文件夹、网址和 Sitemap 筛选
* 搜索资料名称并查看就绪数量
* 预览提取后的原始内容
* 查看已完成资料的分块结果
* 对已完成或失败的资料重新索引
* 多选资料后批量重新索引或删除

如果原文件或网页内容发生变化，执行**重新索引**以更新检索内容。处理中的资料不能重新索引，需要先等待当前任务结束。

## 先做召回测试

知识库顶部提供**召回测试**。它直接测试检索结果，适合在开始聊天前排查资料、分块和检索配置。

1. 点击顶部的召回测试按钮。
2. 输入用户实际可能提出的问题。
3. 查看返回的片段、结果数量、耗时和相关度或排序信息。
4. 展开结果，确认片段包含回答问题所需的原文。
5. 换几种问法重复测试。

测试时重点检查：

* 正确资料是否排在前几条
* 片段是否包含完整的关键信息
* 片段是否过长、过短或在关键句中间被切断
* 无关结果是否过多

召回测试会为每个知识库保留查询历史，可以复用同一组问题比较不同配置。若召回结果本身不准确，聊天模型通常也无法给出可靠答案。

## 在对话中使用知识库

1. 打开**对话**并进入一个聊天。
2. 在输入框工具区域点击知识库按钮。
3. 选择一个或多个知识库。
4. 输入与资料相关的问题并发送。
5. 阅读回答时，同时核对检索到的知识库引用和原始资料。

知识库选择器支持多选，也可以一键清空。所选知识库会关联到当前助手，之后继续使用该助手时仍可复用。

{% hint style="warning" %}
以下情况可能看不到或无法使用知识库按钮：

* 当前助手或工具模式不支持知识库
* 输入框已经添加文件附件

如已添加附件，请先移除附件，再选择知识库。
{% endhint %}

知识库只负责提供相关片段，最终回答仍由聊天模型生成。重要结论应结合引用内容和原始资料复核。

## 调整 RAG 设置

点击知识库顶部的设置按钮，可以调整文档处理与检索流程。

| 设置 | 作用 | 调整建议 |
| --- | --- | --- |
| 文件处理器 | 将文档转换为可分块的文本 | 扫描件、图片或复杂版式优先检查此项 |
| 分块大小与重叠 | 决定每个检索片段的范围 | 改动后需要重新索引已有资料 |
| 嵌入模型与维度 | 生成并存储向量索引 | 改动会进入重建流程 |
| 搜索模式 | 选择不同的检索方式 | 先保留默认值，再根据召回测试调整 |
| 结果数量 | 控制每次返回的片段数 | 过少可能漏信息，过多可能引入噪声 |
| 相似度阈值 | 过滤相关性不足的结果 | 只在相应搜索模式下生效 |
| 混合权重 | 平衡语义与关键词检索 | 专有名词较多时可重点测试 |
| 重排序模型 | 对初次召回结果再次排序 | 会增加一次模型调用和等待时间 |

建议一次只修改一类参数，并使用相同问题重复召回测试。这样更容易判断效果来自哪项改动。

## 常见问题

### 创建时没有可选的嵌入模型

检查模型服务是否已启用、模型能力是否标记为嵌入，以及 API 配置是否可用。普通聊天模型不能代替嵌入模型。

### 资料一直处理中

先保持应用运行并等待。若长时间没有进展，检查模型服务、网络、文件访问权限和文档处理器，再重新索引失败的资料。

### 文件显示失败

将鼠标移到失败状态查看错误原因。常见原因包括格式不受支持、文件无法读取、网页无法访问，以及嵌入服务调用失败。

### 扫描版 PDF 没有有效文字

扫描版 PDF 通常只有图片，需要使用支持 OCR 或图片解析的文档处理方式。请参考[文档预处理](document-preprocessing.md)。

### 召回不到正确内容

确认资料已经完成索引，再依次检查原文质量、分块大小、搜索模式、结果数量、阈值和重排序配置。不要只通过更换聊天模型掩盖召回问题。

### 聊天没有使用知识库

确认当前助手已选中知识库、目标资料状态为已完成，并且输入框没有文件附件。也可以先在召回测试中用同一问题确认检索是否正常。

## 数据、隐私和费用

知识库元数据和索引由 Cherry Studio 管理。根据所选的文档处理、嵌入、重排序和聊天服务，原文或提取后的内容可能会发送给相应服务商；回答时，召回片段也会发送给当前聊天模型。

导入敏感资料前，请确认服务商的数据政策和部署方式。建立索引、重新索引、重排序和聊天回答也可能产生模型调用费用。

本地存储、备份和清理方式请查看[知识库数据](data.md)。
