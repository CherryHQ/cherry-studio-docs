# 商务合作

Cherry Studio 商务邮箱：

**[bd@cherry-ai.com](mailto:bd@cherry-ai.com)**

该邮箱用于企业版咨询、采购、商业许可及合作洽谈，不是社区版日常使用问题的优先支持渠道。

## 适合联系商务团队的事项

### Cherry Studio 企业版

企业版面向需要统一管理 AI 资源、组织成员和知识资产的团队。官方当前公布的方向包括：

* 云端模型与本地私有模型的统一接入。
* 团队共享知识库。
* 员工与权限管理。
* 私有化部署。
* 企业级数据备份与恢复。

可先访问 [Cherry Studio 企业版](https://enterprise.cherry-ai.com)了解公开信息，再通过商务邮箱咨询演示、报价和适配范围。

{% hint style="info" %}
具体功能、部署方式、服务范围、价格和交付时间，以商务团队针对实际需求给出的方案与合同为准。
{% endhint %}

### 商业许可

Cherry Studio 社区版采用 **GNU Affero General Public License v3.0（AGPL-3.0）**。商业使用并非一律禁止，但需要遵守许可证条款。

如果组织希望获得不受 AGPL-3.0 部分要求约束的商业许可，请联系商务团队。许可证的基础说明见[Cherry Studio 开源许可协议](questions/license.md)。

### 生态与联合合作

以下合作可以发送简要方案：

* 模型服务与 API 接入。
* 企业解决方案与私有化交付。
* 硬件、操作系统或渠道合作。
* 教育、研究及社区联合活动。
* 经授权的品牌、媒体或市场合作。

发送邮件不代表合作已经成立。涉及产品名称、Logo、宣传口径或客户案例时，应先取得书面确认。

## 邮件中建议包含什么

为了减少来回确认，请在首封邮件中说明：

1. **组织信息**：公司或机构名称、官网、所在地区和联系人。
2. **合作类型**：企业版、商业许可、模型接入、渠道或其他合作。
3. **使用规模**：预计用户数、设备数或部署范围。
4. **部署环境**：公有云、私有云、局域网或完全离线。
5. **核心需求**：必须解决的业务问题和关键功能。
6. **安全要求**：数据驻留、身份认证、权限、审计和合规要求。
7. **计划时间**：希望评估、测试或上线的时间范围。
8. **联系方式**：可用于后续沟通的工作邮箱和时区。

### 邮件标题示例

```text
[企业版咨询] 某公司 / 200 人 / 私有化部署
[商业许可] 某产品集成 Cherry Studio 社区版
[生态合作] 某模型服务商 API 接入
```
