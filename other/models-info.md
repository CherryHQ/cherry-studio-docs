# 模型数据与选择方法

模型名称、价格、上下文长度和可用状态变化很快。Cherry Studio V2 不维护一张静态的“全部模型表”，而是从你配置的 Provider 获取当前模型列表。

{% hint style="warning" %}
本页不提供实时价格或完整模型清单。请以 Provider 控制台和官方模型文档为准；第三方网关返回的同名模型，能力和限制也可能不同。
{% endhint %}

## 查看当前可用模型

1. 打开 **设置 → 模型服务**。
2. 进入目标 Provider。
3. 填写 API Key，并保留或核对 API 地址。
4. 点击 **获取模型列表**。
5. 添加需要的模型，并使用 **检测** 验证连接。

如果服务商不支持获取模型列表，可以按其官方文档手动添加模型 ID。模型 ID 必须完全一致，包含大小写、日期后缀和命名空间。

## 常见能力

| 能力 | 适合做什么 | 选择时注意 |
| --- | --- | --- |
| 对话 | 问答、写作、总结、代码解释 | 关注质量、速度、价格和上下文 |
| 视觉 | 识别图片、截图、图表 | 确认模型支持图片输入 |
| 工具调用 | 联网搜索、MCP、工作流 | 不是所有兼容 API 都完整支持 |
| 推理 | 数学、规划、复杂分析 | 通常响应更慢、Token 消耗更高 |
| 嵌入 | 为知识库建立向量索引 | 关注语言、维度和最大输入 |
| 图像生成 | 根据提示词生成或编辑图片 | 需要使用对应的图像接口 |

## 上下文和输出长度

* **最大输入**：模型一次能接收的提示词、历史消息和附件总量。
* **最大输出**：模型单次最多能生成的 Token 数。
* **上下文窗口**：通常包含输入和输出，具体计算方式由服务商决定。

不要把近似标注 `8K` 机械地当作永远可用的 `8192`。服务商、网关和请求参数都可能预留系统空间；出现长度错误时，应减少历史消息、附件或最大输出设置。

## 如何选第一个模型

第一次配置时，不需要同时添加很多模型：

1. 先选一个稳定的通用对话模型。
2. 用同一组 3～5 个真实任务测试回答质量和速度。
3. 再根据需要补充视觉、推理、嵌入或图像模型。
4. 对重要工作保留一个备用 Provider，避免单一服务临时不可用。

{% hint style="info" %}
排行榜只能反映特定测试或用户偏好，不能替代你的实际任务测试。涉及隐私、合规、成本或地区可用性时，还要查看服务商条款。
{% endhint %}

## 模型突然不可用怎么办

* 重新获取模型列表，确认模型是否更名或下线；
* 检查 API Key、余额、限额和地区权限；
* 查看 Provider 官方状态页或公告；
* 使用同一 Provider 的稳定模型，或切换到备用 Provider；
* 不要仅通过修改高级参数来绕过服务端不支持的问题。
