# 安装教程

Cherry Studio 提供 Windows、macOS 和 Linux 安装包。请优先从[官方下载页](https://cherryai.com.cn/download)或 [GitHub Releases](https://github.com/CherryHQ/cherry-studio/releases) 获取，避免使用来源不明的安装包。

## 选择平台

* [Windows 安装教程](windows.md)
* [macOS 安装教程](macos.md)
* [Linux 安装教程](linux.md)

{% hint style="warning" %}
Cherry Studio V2 目前属于测试版本，可能存在兼容性问题或数据结构调整。日常使用建议保留稳定版，并在升级前通过 **设置 → 数据** 完成备份。
{% endhint %}

## 安装成功的标志

能够正常打开 Cherry Studio 主界面，即表示客户端安装完成。安装成功不等于模型已经可用，还需要添加一个模型服务。

如果程序无法启动，请先确认操作系统与芯片架构匹配，再参考对应平台教程中的运行库或安全设置说明。

## 下一步

继续完成[5 分钟快速开始](../../getting-started/quick-start.md)：添加模型服务、启用一个对话模型并发送第一条测试消息。第一次使用不需要配置绘画模型、嵌入模型、API 网关或 Agent。
