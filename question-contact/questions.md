# 常见问题

## 常见错误代码

* **4xx（客户端错误状态码）**：服务器因当前请求存在问题而无法完成处理，常见原因包括参数或格式不符合要求、认证失败、权限不足以及请求的资源不存在。
* **5xx（服务器错误状态码）**：服务商或上游网关处理请求时发生异常。不同状态码分别表示内部错误、功能未实现、网关响应异常、服务暂不可用或网关超时。

| 错误码 | 含义 | 先检查什么 |
| --- | --- | --- |
| **400** | 请求内容不符合服务商要求 | 参数、上下文长度、附件大小和错误响应正文 |
| **401** | 认证失败 | API Key 是否正确或已失效 |
| **403** | 服务器理解请求，但拒绝执行 | 账户、组织、地区和模型访问权限 |
| **404** | 请求的接口、模型、部署或其他资源不存在 | API 地址、API 版本、模型 ID 和部署名称 |
| **422** | 请求格式可解析，但内容不合法 | 空值、字段类型和高级参数 |
| **429** | 请求过多，触发速率限制；部分服务商也用它表示配额受限 | TPM、RPM、并发、服务商配额和 `Retry-After` |
| **500** | 服务商内部错误 | 服务状态、错误正文，并在稍后重试 |
| **501** | 当前接口或功能未实现 | API 兼容性，以及接口、模型是否支持该功能 |
| **502** | 网关从上游服务收到无效响应 | 服务商或网关状态、网络，并在稍后重试 |
| **503** | 服务暂时不可用 | 服务商维护或负载状态、`Retry-After`，等待后重试 |
| **504** | 网关等待上游响应超时 | 网络、服务商状态和请求耗时；缩短请求后重试 |

不同服务商对余额不足、账户配额和内容限制的状态码映射可能不同。排查时应同时查看**状态码、错误响应正文和服务商文档**，不要只根据状态码判断原因。

### 400 错误的常见原因

1. **参数不受支持**：新建一个不带自定义参数的助手测试。
2. **上下文超过限制**：新建话题，减少历史消息、附件或最大输出。
3. **图片或附件过大**：压缩文件，或减少单次上传数量。
4. **账户前置条件未完成**：部分服务商可能会在尚未绑卡、实名或开通模型时返回 400，具体以错误响应正文为准。

请先查看对话中的原始错误；信息不完整时，再按下方方法查看调用链。

## 通过调用链查看请求与错误详情

Cherry Studio V2 的模型请求主要由客户端主进程执行，渲染进程开发者工具的 **Network** 面板可能无法显示完整的服务商请求。内置的**调用链**能提供更完整的排查信息，推荐优先使用：

1. 打开 **设置 → 系统**，启用**开发者模式**。
2. **完全退出并重新启动 Cherry Studio**，让开发者模式生效。

<figure><img src="../.gitbook/assets/cherry-developer-mode-v2.png" alt="Cherry Studio V2 系统设置中的启用开发者模式开关"><figcaption><p>在设置 → 系统中启用开发者模式，然后完全退出并重新启动应用</p></figcaption></figure>

3. 回到发生问题的对话或工作任务，重新执行刚才失败的操作。
4. 点击对话顶部右侧的**调用链**入口，展开请求节点。模型请求通常包含一个 `http.request` 子节点；请求失败时，对应节点会标红。

<figure><img src="../.gitbook/assets/cherry-call-chain-list-v2.png" alt="Cherry Studio V2 对话页面中的调用链节点列表"><figcaption><p>调用链会按层级显示 ai.turn、ai.streamText 和 http.request 等节点</p></figcaption></figure>

5. 在节点详情中查看**响应状态、输入、输出、请求头、响应头**或**原始数据**。服务商返回的错误正文通常位于**输出**中。

<figure><img src="../.gitbook/assets/cherry-call-chain-request-details-v2.png" alt="Cherry Studio V2 调用链 http.request 节点的输出详情"><figcaption><p>选择 http.request 后，可查看请求方法、URL、响应状态及输入、输出、请求头、响应头和原始数据</p></figcaption></figure>

{% hint style="info" %}
调用链只记录启用开发者模式并重启后产生的请求。旧消息不会补录调用链；发送请求后如果面板仍显示没有 Trace 信息，可以关闭调用链面板后重新打开。不同服务商能够提供的字段可能不同；请求和响应正文过长时会被截断，因此这里展示的是可用于排查的请求详情，不保证等同于完整的原始 HTTP 抓包。
{% endhint %}

{% hint style="warning" %}
Cherry Studio 会自动遮盖常见鉴权请求头，但输入、输出、文件路径或服务商返回内容仍可能包含敏感信息。提交反馈前请再次检查并遮盖 API Key、账号、私人对话和本地路径。
{% endhint %}

## 公式没被渲染/公式渲染错误

* 如果公式代码直接显示而未被渲染，请先检查公式是否使用了正确的定界符。

> **定界符用法**
>
> _行内公式_
>
> * 使用单个美元符号：`$formula$`
> * 或使用`\(` 和 `\)`，如：`\(formula\)`
>
> _独立公式块_
>
> * 使用双美元符号：`$$formula$$`
> * 或使用 `\[formula\]`
> * 示例：`$$\sum_{i=1}^n x_i$$`\
>   $$\sum_{i=1}^n x_i$$

* 公式中包含中文时，可能出现渲染错误或乱码。可以尝试将公式引擎切换为 KaTeX。

## 无法创建知识库/提示获取嵌入维度失败

1. **嵌入模型不可用**

> 确认当前服务商是否提供该嵌入模型，并检查服务商侧的模型状态是否正常。

2. **选择了非嵌入模型**

> 创建知识库必须使用嵌入模型。请在服务商的模型列表中确认模型类型，不要仅根据模型名称判断。

***

## 模型不能识图/无法上传或选择图片

首先确认模型是否支持图像输入。模型名称后的眼睛图标通常表示 Cherry Studio 当前将其标记为支持视觉；该标记仅供辅助判断，准确能力应以模型所属服务商的官方说明为准。

支持视觉的模型可以接收图像文件。如果模型本身支持视觉，但功能未被正确匹配，可以在对应服务商的模型列表中找到该模型，点击模型名称后的设置按钮，并勾选**图像**能力。

模型的具体能力请查阅对应服务商的官方说明。不支持视觉的模型即使手动勾选**图像**能力，也不会因此获得图像理解能力。
