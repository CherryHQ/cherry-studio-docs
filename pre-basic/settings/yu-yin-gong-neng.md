# 语音功能

{% hint style="warning" %}
Cherry Studio V2 社区版当前没有内置的语音输入、文本转语音或实时语音通话功能。旧版文档中出现过的 TTS、ASR 和语音通话设置并未进入当前 `main` 版本，请勿按照旧教程配置。
{% endhint %}

## 当前状态

当前设置页面中没有 **语音功能** 入口，聊天输入区也没有内置的录音或语音通话按钮。

以下能力目前不属于 Cherry Studio V2 社区版的可用功能：

- 将 AI 回复自动朗读为语音（TTS）
- 使用麦克风将说话内容转成输入文字（ASR / STT）
- 在悬浮窗口中进行实时语音对话
- 配置语音服务商、音色、语速或语音识别模型
- 为按住说话设置专用快捷键

因此，你不需要为这些功能填写 OpenAI、SiliconFlow 或其他语音服务的 API 密钥，也不会在 **设置** 中找到对应选项。

## 音频附件不等于语音输入

Cherry Studio 可以识别常见音频文件类型，并允许在支持的场景中将文件作为附件处理。但能否理解音频内容取决于所选模型、服务商协议和模型能力。

上传音频文件与应用内语音功能有本质区别：

| 场景 | 当前状态 |
| --- | --- |
| 上传已有音频文件交给支持音频输入的模型处理 | 取决于模型与服务商 |
| 直接使用麦克风录音并转写到输入框 | 暂不支持 |
| 自动朗读模型回复 | 暂不支持 |
| 与模型进行连续语音通话 | 暂不支持 |

如果模型选择器或服务商没有明确标注音频输入能力，不要假定它可以处理音频附件。

## 可用替代方式

需要语音输入时，可以先使用操作系统自带的听写功能或其他转写工具，将语音转换为文字后粘贴到 Cherry Studio。具体可用性、快捷键和隐私策略由操作系统或所用工具决定。

需要朗读回复时，可以使用操作系统的辅助功能或外部文本朗读工具。Cherry Studio 不会管理这些工具的音色、语速、音频存储或网络请求。

{% hint style="info" %}
使用第三方听写、转写或朗读服务前，请先确认其数据处理与隐私政策。不要将敏感对话发送给未经信任的服务。
{% endhint %}

## 如何确认未来版本是否支持

语音相关功能若重新进入社区版，应同时出现可访问的界面入口和正式发布说明。请以当前版本的 **设置** 页面和 [GitHub Releases](https://github.com/CherryHQ/cherry-studio/releases) 为准，不要仅依据旧截图或历史 PR 判断。

如果当前安装版本出现了本文未提及的语音入口，请先确认版本号和安装来源，再通过[反馈与建议](../../question-contact/suggestions.md)提交界面截图与复现信息。
