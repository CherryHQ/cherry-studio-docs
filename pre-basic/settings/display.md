# 外观设置

打开 `设置 → 外观` 可以统一调整语言、主题、颜色、字体、消息布局、Markdown、代码块和自定义 CSS。

<figure><img src="../../.gitbook/assets/cherry-appearance-v2.png" alt="Cherry Studio V2 外观设置"><figcaption><p>V2 外观设置集中管理界面与消息渲染。</p></figcaption></figure>

## 基础外观

* **语言**：切换应用界面语言。
* **主题**：跟随系统、浅色或深色。
* **主题色**：选择预设颜色或输入自定义颜色值。
* **界面风格**：可在 Cherry 与原生风格之间切换。
* **字体**：分别设置界面字体和代码字体。

## 输入与消息

* 发送快捷键；
* 显示预估 Token 数；
* Markdown 渲染输入消息；
* 删除消息前确认；
* 宽布局模式；
* 衬线字体、消息大纲和思考内容折叠；
* 消息样式、工具栏排列和头像显示方式；
* 字号。

## Markdown 与代码块

可配置公式语法、花式代码块、代码编辑器、行号、折叠和自动换行。某些选项只影响新渲染的消息，切换后可重新打开话题检查效果。

## 自定义 CSS

页面底部可以启用并填写自定义 CSS，也可从 `cherrycss.com` 获取示例。修改前建议先保存原内容；如果样式导致页面不可用，请参考 [清除 CSS 设置](../personalization-settings/clear-css.md)。

{% hint style="warning" %}
自定义 CSS 可以隐藏按钮或改变布局，但不会增加产品能力。升级后选择器可能变化，出现显示异常时先停用 CSS 排查。
{% endhint %}
