# 软件设置

Cherry Studio V2 把模型接入、工具服务、应用偏好、数据管理和效率功能集中在设置中心。本页是设置导航，不重复每个开关的细节；按目标找到对应分区后，再进入相关专题文档。

## 打开设置

点击主窗口左下角的**设置**图标。

设置中心默认打开**模型服务**，左侧按功能分为：

1. 模型接入；
2. 工具服务；
3. 应用设置；
4. 效率工具；
5. 系统信息。

{% hint style="info" %}
不同操作系统、窗口尺寸或版本中的文字和位置可能略有差异。若某项功能没有出现，请先在**关于**中确认版本，并检查它是否仅在特定平台可用。
{% endhint %}

## 模型接入

| 设置项 | 用途 | 相关文档 |
| --- | --- | --- |
| 模型服务 | 添加或管理模型服务商、API Key、API 地址、连接方式和模型列表 | [模型服务设置](providers.md) |
| 模型 | 设置默认对话、视觉、嵌入、重排序、翻译等模型 | [默认模型设置](default-models.md) |
| API 服务器 | 把 Cherry Studio 的模型能力通过本地 OpenAI 兼容接口提供给其他应用 | [API 服务器](../../advanced-basic/api-server.md) |

首次使用时，建议按以下顺序配置：

1. 在**模型服务**中启用服务商并完成连接检测；
2. 确认需要的模型已经出现在模型列表中；
3. 在**模型**中设置各类默认模型；
4. 返回对话页发送一条测试消息。

模型服务商的 API Key 属于敏感凭证。不要把真实 Key 放进截图、公开文档或问题反馈。

## 工具服务

| 设置项 | 用途 | 相关文档 |
| --- | --- | --- |
| MCP 服务器 | 安装和管理 MCP 工具，为助手或智能体连接外部能力 | [MCP 使用教程](../../advanced-basic/mcp/) |
| 网络搜索 | 选择关键词搜索和 URL 读取服务商，设置结果数量、压缩和黑名单 | [网络搜索](../websearch/) |
| 文档处理 | 配置 PDF、Office 文档、图片 OCR 等文件解析服务 | [文档处理](doc-process.md) |
| 集成 | 连接 Obsidian、Notion、思源、语雀、Joplin 等外部知识工具 | [数据设置](../data-settings/) |
| 插件 | 查看和管理当前版本支持的应用插件 | 暂无独立专题页 |

工具服务是否可用，通常同时取决于：

- 功能本身是否配置完成；
- 当前模型是否支持工具调用或相应输入类型；
- 助手或智能体是否获得了该工具权限；
- 本机网络和第三方服务是否可访问。

不要只根据界面中出现一个开关判断功能已经可用。完成配置后，应在实际对话中做一次最小测试。

## 应用设置

| 设置项 | 用途 | 相关文档 |
| --- | --- | --- |
| 常规设置 | 语言、主题、字体、消息显示、启动行为、代理、语音等应用偏好 | [常规设置](general.md) |
| 数据设置 | 本地数据目录、导入导出、备份、WebDAV、S3 和笔记服务 | [数据设置](../data-settings/) |

常规设置中的内容较多，以下专题会进一步说明：

- [显示设置](display.md)：主题、字体、布局和消息显示；
- [语音功能](yu-yin-gong-neng.md)：语音输入与语音朗读；
- [个性化设置](../personalization-settings/)：自定义字体、CSS 和存储位置。

{% hint style="warning" %}
大多数外观选项会立即生效，但语言、代理、存储位置以及部分系统集成可能需要重新打开窗口或重启应用。是否需要重启，以设置项旁的提示和实际界面为准。
{% endhint %}

## 系统信息

**关于**页面用于查看：

- Cherry Studio 版本；
- 更新状态和更新渠道；
- 官方网站、开源仓库等链接；
- 许可证及相关系统信息。

开发版本中还可能出现**组件实验室**。它用于开发和测试界面组件，不属于社区版日常使用流程，也不应作为正式功能入口写入自动化步骤。

## 推荐的首次设置顺序

如果刚安装 Cherry Studio，可以按下面的顺序完成最小配置：

1. **模型服务**：启用一个服务商，填写凭证并检测连接；
2. **模型**：选择默认对话模型；
3. **常规设置**：选择语言、主题和启动行为；
4. **数据设置**：确认数据位置并创建首次备份；
5. **网络搜索或文档处理**：只配置当前确实需要的工具；
6. **快捷键**：避免全局组合键与其他应用冲突；
7. **关于**：确认已使用预期版本。

不必一次开启所有服务。先让基本对话稳定工作，再逐项增加联网、MCP、频道和自动任务，更容易定位配置问题。

## 设置后的检查

修改设置后，可用以下方式快速确认：

| 改动 | 建议检查 |
| --- | --- |
| 模型服务或 API Key | 运行连接检测，再发送一条简短消息 |
| 默认模型 | 新建对话，确认顶部显示的模型 |
| 网络搜索 | 开启地球图标，询问一条需要最新资料的问题 |
| 文档处理 | 上传一个小型测试文件并检查解析结果 |
| 代理 | 重新访问需要代理的服务，必要时重启应用 |
| 快捷键 | 在目标窗口中实际按一次组合键 |
| 数据或备份 | 创建备份并确认文件或远端记录确实生成 |

## 常见问题

### 设置改完没有生效

先确认输入框已经失焦或点击了保存/检查按钮。然后重新打开对应页面；涉及语言、网络、系统权限或存储路径时，再重启 Cherry Studio。

### 找不到文档里提到的设置项

检查：

1. 当前 Cherry Studio 是否为 V2 社区版的近期版本；
2. 该功能是否只支持特定操作系统；
3. 是否需要先启用某个服务商、模型或实验功能；
4. 设置窗口左侧是否可以继续滚动；
5. 文档所述功能是否已迁移到助手、智能体或应用页面。

### 能否把所有设置同步到另一台设备

不同备份方式覆盖的数据范围不同。不要只凭“备份成功”判断所有凭证和本机路径均会同步；迁移前请阅读[数据设置](../data-settings/)并在目标设备上核对模型服务、路径和系统权限。
