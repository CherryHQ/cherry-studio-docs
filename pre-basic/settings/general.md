# 常规设置

Cherry Studio V2 的常规设置分为四个页面：

1. **显示与语言**
2. **系统与启动**
3. **隐私与高级**
4. **自定义 CSS**

进入：

> **设置 → 常规设置**

本页说明各项设置的作用、依赖关系和需要重启的场景。

## 显示与语言

### 界面语言

当前应用可选择：

- 简体中文
- 繁體中文
- English
- Deutsch
- 日本語
- Русский
- Ελληνικά
- Español
- Français
- Português
- Română
- Tiếng Việt

切换后界面会立即更新。第三方模型名称、服务商返回的错误、助手内容和用户自定义文本不会被自动翻译。

{% hint style="info" %}
应用界面支持的语言数量与社区文档发布语言不是同一个概念。当前社区文档按简体中文、繁體中文、English、日本語、Русский维护。
{% endhint %}

### 主题与主色

主题可以选择：

- 浅色
- 深色
- 跟随系统

主色用于按钮、选中状态和部分强调元素。若自定义 CSS 同时修改主题变量，最终效果可能覆盖主色设置。

### 透明窗口

macOS 会显示透明窗口开关。它控制系统材质与窗口背景效果；其他平台不会显示此项。

如果透明效果导致文字对比度低、窗口闪烁或截图不清晰，可切回不透明窗口。

### 使用系统标题栏

Linux 会显示系统标题栏开关。更改后应用会确认并重新启动。

系统标题栏有助于兼容部分桌面环境和窗口管理器，但外观会与 Cherry Studio 自带标题栏不同。

### 界面缩放

可按 `10%` 步进放大或缩小，也可以恢复默认缩放。

缩放影响整个设置窗口和主界面的视觉尺寸。截图或排查布局问题时，应记录缩放比例；非 `100%` 缩放可能让同一窗口尺寸呈现不同内容。

### 全局字体与代码字体

可以从系统字体中分别选择：

- 全局界面字体；
- 代码块和编辑器字体。

选择列表来自当前操作系统。另一台设备没有相同字体时，界面会回退到默认字体。

更完整的外观说明见[显示设置](display.md)和[字体设置](../personalization-settings/font.md)。

### 话题列表

话题列表支持：

- 显示在左侧或右侧；
- 显示话题时间；
- 把固定话题置顶。

当话题列表位于左侧时，还可以开启**点击助手后自动切换到话题列表**。列表位于右侧时，这个开关不会显示。

## 系统与启动

### 开机自动启动

开启后，Cherry Studio 会尝试在系统登录时启动。

如果没有生效，检查：

- 系统是否允许登录项或自启动应用；
- 安全软件是否拦截；
- 应用是否已移动或重新安装；
- 当前用户是否有权限修改登录项。

### 启动时最小化到托盘

开启后，应用启动时不直接显示主窗口。

该设置依赖托盘功能：开启它时，Cherry Studio 会自动开启**显示托盘图标**。

### 显示托盘图标

托盘菜单可用于显示主窗口、打开快捷助手或退出应用。关闭托盘图标时：

- **启动时最小化到托盘**会同时关闭；
- **关闭窗口时最小化到托盘**会同时关闭。

这样可以避免窗口被隐藏后没有入口重新打开。

### 关闭窗口时最小化到托盘

开启后，点击窗口关闭按钮只隐藏主窗口，Cherry Studio 进程仍在后台运行。

若要完全退出，应使用托盘菜单中的退出命令。关闭该开关后，窗口关闭行为会按系统和应用退出逻辑执行。

{% hint style="warning" %}
后台运行可能继续保留正在执行的任务、频道或定时任务。需要停止所有运行时，不要只关闭窗口，应确认应用已经退出。
{% endhint %}

## 代理设置

代理模式包括：

| 模式 | 行为 |
| --- | --- |
| 系统代理 | 使用操作系统当前代理配置 |
| 自定义代理 | 使用 Cherry Studio 中填写的代理地址与绕过规则 |
| 不使用代理 | 不主动使用代理 |

### 自定义代理地址

可填写有效的 HTTP、HTTPS 或 SOCKS 代理 URL，例如：

```text
socks5://127.0.0.1:6153
```

实际协议和端口必须与本机代理程序一致。若代理需要身份验证，按代理程序支持的 URL 形式配置，并避免在截图或反馈中暴露用户名和密码。

输入无效地址时，Cherry Studio 会拒绝保存。

### 代理绕过规则

绕过规则让特定地址直接连接，不经过自定义代理。适合：

- `localhost` 和 `127.0.0.1`；
- 局域网模型服务；
- 本机 SearXNG、Ollama 或 LM Studio；
- 不应经过代理的企业内网域名。

规则格式应参考设置项提示。错误的绕过规则可能导致本地服务走代理，或让外部服务绕过代理后连接失败。

### 代理排错

模型服务超时时，不要只反复切换代理模式。依次检查：

1. 浏览器或终端能否访问服务商；
2. 代理程序是否正在监听设置的端口；
3. Cherry Studio 的代理模式和地址是否正确；
4. 目标域名是否被绕过规则误匹配；
5. 本地服务是否应该使用直连；
6. 修改代理后是否需要重新打开窗口或重启应用。

## 禁用硬件加速

默认情况下，Electron 会使用硬件加速渲染界面。只有出现以下问题时，才建议开启**禁用硬件加速**：

- 黑屏或白屏；
- 窗口闪烁；
- 字体或图像渲染异常；
- 特定显卡驱动导致崩溃。

更改后应用会确认并重新启动。

禁用硬件加速可能降低滚动、动画和复杂界面的流畅度。它不是所有性能问题的通用解决方案。

## 拼写检查

启用后，输入框会使用 Electron 的拼写检查能力标记可能拼错的单词。

在 Windows 和 Linux 上，还可以选择检查语言，包括英语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、荷兰语、波兰语、斯洛伐克语和希腊语。

macOS 使用系统提供的拼写检查行为，因此界面不显示同样的多语言选择器。

拼写检查只影响本地输入提示，不会调用模型纠正文案，也不会改变已经发送的消息。

## 通知

可分别控制：

| 通知 | 触发场景 |
| --- | --- |
| 助手消息 | 助手回答完成等消息事件 |
| 备份 | 备份流程完成或产生结果 |
| 知识库 | 知识库嵌入或索引任务完成 |

即使应用内开关已开启，操作系统仍可能阻止通知。请在系统通知设置中允许 Cherry Studio，并检查专注模式或勿扰模式。

通知只表示任务产生了结果，不等于结果一定成功。备份和知识库任务仍应查看最终状态与错误信息。

## 匿名错误报告和数据统计

**匿名发送错误报告和数据统计**用于控制应用的数据收集开关。

是否开启由用户自行决定。需要了解收集范围、保留方式和第三方处理规则时，应查看当前版本展示的隐私说明及项目正式隐私政策；不要仅依据开关名称推断所有数据类别。

关闭该开关不会阻止用户主动发送反馈，也不会阻止已配置的模型服务、网络搜索、MCP 或外部集成按功能要求传输数据。

## 开发者模式

开发者模式用于开启面向调试或开发的功能。

普通用户可保持关闭。需要排查问题时，可以按开发者或维护者指引临时开启；完成后再关闭。

开发者模式不会自动修复连接问题，也不会让模型获得额外能力。调试界面和日志可能包含对话、路径、请求参数或服务信息，分享前必须脱敏。

## 自定义 CSS

常规设置内置 CSS 编辑器，可以直接覆盖应用样式。

适合调整：

- 字号与间距；
- 颜色和圆角；
- 特定组件的显示方式；
- 社区主题。

有关编写、恢复和清除方法，见[自定义 CSS](../personalization-settings/custom-css.md)和[清除 CSS](../personalization-settings/clear-css.md)。

{% hint style="danger" %}
错误 CSS 可能隐藏按钮、使文字不可见或破坏布局。粘贴第三方主题前先阅读代码并备份现有 CSS；若设置入口无法操作，可按清除 CSS 文档恢复。
{% endhint %}

Cherry Studio 更新后，内部类名和结构可能变化，旧 CSS 不保证长期兼容。

## 推荐检查顺序

### 新用户

1. 选择界面语言；
2. 选择浅色、深色或跟随系统；
3. 保持 `100%` 缩放；
4. 按需要开启开机启动和托盘；
5. 先使用系统代理，只有明确需要时再改为自定义代理；
6. 保持硬件加速启用；
7. 按需要开启通知。

### 出现网络问题

1. 检查服务商 Key 和地址；
2. 检查系统或自定义代理；
3. 检查绕过规则；
4. 使用同一网络测试服务商官方地址；
5. 重启应用后复测。

### 出现显示问题

1. 恢复 `100%` 缩放；
2. 切换到默认主题与默认字体；
3. 暂时清空自定义 CSS；
4. 关闭透明窗口；
5. 最后再尝试禁用硬件加速并重启。

## 常见问题

### 文档只有五种语言，为什么应用里更多

应用本身和社区文档是两套语言覆盖范围。应用当前提供十二种界面语言；本社区文档当前维护五种语言。

### 自定义代理保存后仍无法连接

确认 URL 包含协议，例如 `http://` 或 `socks5://`，端口正确，代理程序正在运行，并检查目标域名是否被绕过。

### 关闭窗口后应用仍在运行

检查**关闭窗口时最小化到托盘**。开启时，关闭按钮不会退出应用；请从托盘菜单退出。

### 托盘相关开关自动变化

这是依赖关系：

- 开启“启动时最小化到托盘”或“关闭窗口时最小化到托盘”会自动开启托盘；
- 关闭托盘会同时关闭这两个依赖项。

### 修改系统标题栏或硬件加速后应用重启

这是正常行为。这两项需要在应用启动阶段生效，确认修改后 Cherry Studio 会重新启动。

### 字体列表中没有某个字体

列表来自当前系统已安装字体。先在操作系统中安装字体，再重新打开 Cherry Studio；从其他设备同步设置不会同步字体文件。

### 通知开关已开但没有通知

检查系统通知权限、勿扰模式，以及任务是否真的完成。Linux 桌面环境还可能需要可用的通知服务。
