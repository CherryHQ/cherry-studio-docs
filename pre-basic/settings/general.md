# 系统与通知

V2 已把旧版“常规设置”拆成 **外观、通知、数据和系统**。本页说明启动、代理和通知等常用项目；界面相关选项请看 [外观设置](display.md)。

## 系统设置

打开 `设置 → 系统`：

<figure><img src="../../.gitbook/assets/cherry-system-settings-v2.png" alt="Cherry Studio V2 系统设置"><figcaption><p>启动、托盘、代理、硬件加速和开发者模式。</p></figcaption></figure>

### 启动

* **开机自动启动**：登录系统后自动运行 Cherry Studio。
* **启动时最小化到托盘**：适合与开机自启一起使用。
* **显示托盘图标**：在系统托盘保留入口。
* **关闭时最小化到托盘**：点击窗口关闭按钮时继续后台运行。
* **运行任务时保持系统唤醒**：长时间生成、Agent 或定时任务执行时避免系统休眠。

### 代理模式

默认可选择 **系统代理**。如果使用代理客户端，请先确认代理节点已经连接，再让 Cherry Studio 跟随系统代理。

遇到连接超时或模型检测失败时：

1. 用浏览器确认目标服务可以访问；
2. 检查代理客户端是否启用系统代理或 TUN；
3. 确认 Cherry Studio 的代理模式与当前网络配置一致；
4. 回到模型服务页重新执行 **检测**。

### 硬件加速

**禁用硬件加速**只用于黑屏、闪烁、字体异常等渲染问题。正常情况下保持关闭；修改后建议重启应用。

### 开发者模式

开发者模式面向调试和开发。普通用户无需开启；反馈问题时仅在维护者明确要求下使用。

## 通知

打开 `设置 → 通知` 管理生成完成、备份、知识库索引等提醒。通知是否显示还取决于操作系统是否允许 Cherry Studio 发送通知。

如果应用内已经开启但没有系统通知，请到 Windows/macOS/Linux 的系统通知设置中检查权限和勿扰模式。
