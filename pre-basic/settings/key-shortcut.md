# 快捷键设置

快捷键设置集中管理 Cherry Studio 的键盘操作。你可以在这里查看当前绑定、修改可编辑的组合键、临时停用某项操作，或将配置恢复为默认值。

{% hint style="info" %}
本文中的 `Cmd/Ctrl` 表示 macOS 使用 `Command (⌘)`，Windows 和 Linux 使用 `Ctrl`。实际界面会按照当前操作系统显示对应按键。
{% endhint %}

## 打开快捷键设置

进入 **设置 > 快捷键**。

页面左侧按用途分为四组：

| 分组 | 包含的操作 |
| --- | --- |
| 全局与窗口 | 显示或隐藏应用、打开设置、切换侧边栏、界面缩放和全局搜索 |
| 消息交互 | 清空消息、清除上下文、搜索消息、复制或编辑消息、选择模型 |
| 会话与话题 | 新建话题、重命名话题、显示或隐藏话题列表 |
| AI 助手工具 | 快捷助手和划词助手的全局快捷键 |

功能没有启用时，对应快捷键不会显示。例如，只有启用快捷助手后，**AI 助手工具**中才会出现快捷助手；划词助手的两项快捷键还仅支持 macOS 和 Windows。

页面上方的搜索框只搜索当前分组，可按操作名称或当前显示的组合键筛选。

## 修改快捷键

### 设置或替换按键

1. 找到目标操作。
2. 点击右侧的按键区域；尚未绑定时，点击 **按下快捷键**。
3. 直接按下新的组合键。
4. 组合键通过校验后会立即保存并启用。

编辑过程中按 `Esc` 可以取消。有效组合键通常需要同时包含修饰键和普通按键，例如 `Cmd/Ctrl + Shift + M`；`Esc` 和 `F1` 至 `F12` 也可以单独使用。

部分系统级快捷键不可编辑，例如打开设置、退出全屏和界面缩放。它们仍会显示在列表中，但按键区域不可点击。

### 启用或停用

每项快捷键右侧都有独立开关：

- 关闭开关会保留按键绑定，但不再响应操作。
- 重新开启后继续使用原绑定。
- 没有绑定按键的项目不能直接开启，需要先设置组合键。

**全部启用**和**全部禁用**只影响当前分组中、当前筛选结果内且已经绑定按键的项目，不会修改未绑定的项目。

### 处理冲突

Cherry Studio 会检查两类冲突：

- **应用内重复：** 如果新组合键已被另一个已启用的 Cherry Studio 操作占用，界面会显示冲突操作名称，并拒绝保存。
- **系统或其他应用占用：** 如果操作系统无法注册该组合键，界面会以红色提示“该快捷键已被系统或其他应用占用”。

遇到冲突时，请为其中一个操作换用其他组合键。系统预留键、输入法快捷键、窗口管理器快捷键，以及其他常驻应用的全局快捷键，都可能造成注册失败。

## 当前默认快捷键

下表对应 Cherry Studio V2 当前默认配置。升级后的实际绑定可能保留你此前的自定义设置，请以应用内显示为准。

### 全局与窗口

| 操作 | 默认绑定 | 默认状态 | 说明 |
| --- | --- | --- | --- |
| 显示 / 隐藏应用 | 未绑定 | 停用 | 设置后可在其他应用前台时显示或隐藏 Cherry Studio |
| 打开设置 | `Cmd/Ctrl + ,` | 启用 | 打开设置窗口 |
| 切换侧边栏 | `Cmd/Ctrl + [` | 启用 | 切换或聚焦助手侧栏 |
| 退出全屏 | `Esc` | 启用 | 退出全屏模式 |
| 放大界面 | `Cmd/Ctrl + =` | 启用 | 增大界面缩放比例；数字键盘 `+` 也可使用 |
| 缩小界面 | `Cmd/Ctrl + -` | 启用 | 减小界面缩放比例；数字键盘 `-` 也可使用 |
| 重置缩放 | `Cmd/Ctrl + 0` | 启用 | 恢复默认缩放比例 |
| 搜索消息 | `Cmd/Ctrl + Shift + F` | 启用 | 打开全局消息搜索 |

### 消息交互

| 操作 | 默认绑定 | 默认状态 | 说明 |
| --- | --- | --- | --- |
| 清空消息 | `Cmd/Ctrl + L` | 启用 | 确认后删除当前话题中的全部消息 |
| 在当前对话中搜索消息 | `Cmd/Ctrl + F` | 启用 | 在当前话题内查找消息 |
| 清除上下文 | `Cmd/Ctrl + K` | 启用 | 在当前话题中切换上下文分隔点，不删除历史消息 |
| 复制上一条消息 | `Cmd/Ctrl + Shift + C` | 停用 | 复制当前话题的最后一条消息正文 |
| 编辑最后一条用户消息 | `Cmd/Ctrl + Shift + E` | 停用 | 打开最后一条用户消息的编辑状态 |
| 选择模型 | `Cmd/Ctrl + Shift + M` | 启用 | 打开当前助手的对话模型选择器 |

{% hint style="warning" %}
**清空消息**与**清除上下文**不是同一操作。清空消息会在确认后删除当前话题的全部消息；清除上下文只让后续对话从新的上下文段开始，原有消息仍保留在页面中。再次触发清除上下文可以移除末尾尚未使用的分隔点。
{% endhint %}

### 会话与话题

| 操作 | 默认绑定 | 默认状态 | 说明 |
| --- | --- | --- | --- |
| 新建话题 | `Cmd/Ctrl + N` | 启用 | 在当前助手下新建一个独立话题 |
| 重命名话题 | `Cmd/Ctrl + T` | 停用 | 修改当前话题名称 |
| 切换话题显示 | `Cmd/Ctrl + ]` | 启用 | 切换或聚焦话题列表 |

### AI 助手工具

| 操作 | 默认绑定 | 默认状态 | 使用条件 |
| --- | --- | --- | --- |
| 快捷助手 | `Cmd/Ctrl + E` | 停用 | 先在快捷助手设置中启用功能 |
| 开关划词助手 | 未绑定 | 停用 | 先启用划词助手；仅 macOS 和 Windows |
| 划词助手：取词 | 未绑定 | 停用 | 先启用划词助手；仅 macOS 和 Windows |

快捷助手、划词助手和“显示 / 隐藏应用”属于全局快捷键：完成绑定并启用后，即使 Cherry Studio 窗口没有焦点也能响应。其他大多数对话和窗口快捷键只在 Cherry Studio 窗口处于前台时生效。

有关功能本身的配置方法，请参阅[快捷助手](../../cherrystudio/preview/quick-assistant.md)和[划词助手](../../cherrystudio/preview/selection-assistant.md)。

## 恢复默认设置

修改过的可编辑快捷键旁会出现恢复图标，点击后只恢复这一项的默认绑定和默认启用状态。

点击页面顶部的 **重置**，确认后会恢复所有快捷键的默认配置。此操作会覆盖你为快捷键设置的自定义绑定。

## 常见问题

### 按下快捷键没有反应

依次检查：

1. 对应项目是否已经绑定按键并处于启用状态。
2. 当前功能是否已经启用，例如快捷助手或划词助手。
3. 对话类快捷键触发时，Cherry Studio 窗口是否处于前台。
4. 界面是否出现系统或其他应用占用的红色提示。
5. 操作系统、输入法或其他常驻应用是否使用了相同组合键。

修改后仍无效时，先换用一个不常见的组合键测试，再尝试重启 Cherry Studio。

### 为什么看不到划词助手快捷键？

划词助手快捷键只有在功能已经启用时才显示，并且目前仅支持 macOS 和 Windows。Linux 不会显示这两项。

### 为什么“全部启用”没有开启某些项目？

批量操作只处理当前分组和当前搜索结果中已经绑定按键的项目。对于显示“按下快捷键”的未绑定项目，需要先逐项设置组合键。

### 如何快速回到默认配置？

若只改错了一项，使用该项旁边的恢复图标；若多项配置已经混乱，使用页面顶部的 **重置**。

如仍无法解决，请通过[反馈与建议](../../question-contact/suggestions.md)提交系统版本、Cherry Studio 版本、冲突组合键和复现步骤。
