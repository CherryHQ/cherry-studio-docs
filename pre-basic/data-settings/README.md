# 数据设置

Cherry Studio V2 的数据设置位于 **设置 > 数据设置**。这里不仅可以手动备份和恢复，还可以配置本地或云端自动备份、把数据迁移到其他目录，以及管理导入和导出选项。

{% hint style="warning" %}
恢复备份、迁移数据目录和重置数据都可能覆盖现有内容。操作前先创建一份可用的备份，并确认备份文件保存在应用数据目录之外。
{% endhint %}

## 页面结构

数据设置左侧包含以下页面：

| 页面 | 用途 |
| --- | --- |
| 数据 | 手动备份与恢复、导出至手机、迁移应用数据、查看日志、清理缓存和重置数据 |
| 本地备份 | 把备份写入本机、外置硬盘或已挂载的网络目录，并设置自动备份 |
| WebDAV | 使用支持 WebDAV 的远程存储保存和恢复备份 |
| 坚果云 | 登录坚果云后选择远程目录并管理备份 |
| S3 | 使用 S3 或 S3 兼容对象存储保存备份 |
| 导入设置 | 导入受支持的外部应用数据 |
| 导出菜单 | 决定对话导出菜单中显示哪些格式和目标 |
| Markdown 导出 | 设置默认目录、公式、模型信息和引用格式 |

## 选择备份方式

| 使用场景 | 建议方式 |
| --- | --- |
| 立即保存一份可移动的备份 | 在 **数据** 页面点击 **备份** |
| 定期备份到本机、移动硬盘或已挂载的 NAS | 使用 **本地备份** |
| 已经有支持 WebDAV 的网盘或服务器 | 使用 [WebDAV 备份](webdav.md) |
| 使用坚果云并希望通过账户授权连接 | 使用 **坚果云** |
| 已有 AWS S3、Cloudflare R2、MinIO 等对象存储 | 使用 [S3 兼容存储备份](s3-compatible.md) |

云端和本地页面中的“自动备份”表示按周期创建新的备份文件，不是两台设备之间的实时双向同步。若在多台电脑上使用同一备份位置，应先在一台设备完成备份，再在另一台设备手动选择对应版本恢复；同时修改后互相恢复可能覆盖较新的数据。

## 备份包含什么

普通备份包含 Cherry Studio 的数据库、设置和应用管理的文件数据，例如聊天记录、助手配置、图片和知识库相关文件。

打开 **精简备份** 后，备份仍保留聊天记录和设置，但会跳过应用 `Data` 目录中的图片、知识库等文件数据。这样可以缩小文件并加快备份，但恢复后不能依靠该备份找回被跳过的文件。

{% hint style="info" %}
“精简备份”不是增量备份。每次仍会生成独立备份文件，只是排除了文件数据。
{% endhint %}

备份可能包含对话内容、服务商配置和其他敏感信息。不要把备份公开分享，也不要恢复来源不明的文件；远程存储应使用私有目录、强密码和最小权限凭据。

## 手动备份与恢复

进入 **设置 > 数据设置 > 数据**：

1. 若希望减小备份体积，先打开 **精简备份**；需要完整保留图片和知识库文件时保持关闭。
2. 点击 **备份**，选择应用数据目录之外的保存位置。
3. 等待备份完成，不要在写入过程中退出应用或移走磁盘。

恢复时点击 **恢复** 并选择 Cherry Studio 备份文件。恢复会用备份中的数据替换当前数据，完成后应用可能自动重新启动。

建议定期执行一次恢复验证：在确认当前数据另有备份后，检查备份文件能否被识别、版本和时间是否正确。不要等到原始数据已经丢失时才第一次验证。

## 自动备份与保留数量

本地、WebDAV、坚果云和 S3 页面分别保存自己的自动备份配置。当前可选周期为：

- 关闭；
- 1、5、15 或 30 分钟；
- 1、2、6、12 或 24 小时。

可保留的最大备份数为无限制、1、3、5、10、20 或 50。达到上限后，Cherry Studio 会清理较旧的自动备份；“无限制”不会主动控制存储占用。

每种备份方式也有独立的 **精简备份** 开关。修改 **数据** 页中的开关，不会自动替代本地、WebDAV、坚果云或 S3 页面中的设置。

### 配置本地自动备份

1. 打开 **本地备份**。
2. 选择一个可写目录。该目录不能位于 Cherry Studio 的应用数据目录或安装目录中。
3. 选择自动备份周期和最大备份数。
4. 根据恢复需求决定是否启用 **精简备份**。
5. 查看 **备份状态**，确认最近一次时间或错误信息。

选择有效目录后会启用本地自动备份。备份目录放在移动硬盘或网络挂载点时，要确保执行期间设备仍在线且有足够空间。

## 导出至手机

**数据 > 导出至手机**提供两种方式：

- **局域网传输：** 在同一局域网中扫描 Cherry Studio 移动端，建立连接后发送临时备份。
- **导出为文件：** 生成一个可由移动端通过文件方式导入的 ZIP 备份。

这两种方式用于传输聊天记录和设置等部分数据，并会跳过 `Data` 目录中的文件数据。它们不替代完整备份。

局域网找不到设备时，确认电脑和手机连接同一网络、移动端已打开局域网传输页面，并检查系统防火墙是否阻止设备发现或文件传输。

## 修改应用数据目录

**数据 > 应用数据**会显示当前目录。点击修改图标可把 Cherry Studio 的数据放到其他磁盘位置。

新目录必须满足以下条件：

- 不是磁盘根目录；
- 不在当前应用数据目录内部；
- 不在 Cherry Studio 安装目录内部；
- 当前用户拥有写入权限。

确认时可以选择复制原目录中的数据。若目标目录不为空，应用会再次警告，因为继续操作可能覆盖目标中的文件。迁移期间不要强制退出、断开磁盘或让设备休眠；完成后应用会重新启动，某些情况下可能重启多次。

只修改路径而不复制数据，会让新位置以其现有内容启动，不等同于迁移当前数据。需要完整搬迁时应保留 **复制数据**，并在开始前创建备份。

## 日志、缓存与重置

- **应用日志：** 打开日志所在目录，适合排查问题或按反馈要求提交日志。分享前检查并移除敏感信息。
- **清除缓存：** 删除应用缓存和小程序本地数据，不用于删除聊天历史。该操作不可撤销。
- **重置数据：** 清空 Cherry Studio 数据并重新启动。页面会进行两次确认；只有在已有可用备份且确实希望从头开始时使用。

{% hint style="danger" %}
不要把“清除缓存”和“重置数据”混为一谈。前者针对缓存；后者会清空本地数据库和应用管理的数据。
{% endhint %}

## 导入外部应用数据

当前 **导入设置**页面提供 **导入 ChatGPT 数据**。点击 **导入文件**后按弹窗选择导出的 ChatGPT 数据文件。

导入前保留 Cherry Studio 当前备份。若页面没有列出其他应用，就表示当前版本尚未在这里提供对应导入器，不要直接把其他软件的数据库或备份文件当作 Cherry Studio 备份恢复。

## 设置导出菜单

**导出菜单**控制对话页面中出现的导出选项，当前包括：

- 图片；
- Markdown；
- Markdown（包含思考）；
- Notion、语雀、Joplin、Obsidian 和思源笔记；
- Word（DOCX）；
- 复制为纯文本。

打开开关只会让该选项出现在导出菜单中，不会自动配置第三方服务。Notion、语雀等目标仍需在 **设置 > 集成**中完成对应连接。

## 设置 Markdown 导出

**Markdown 导出**可以配置：

- 默认导出路径；留空时每次弹出保存对话框；
- 强制使用 `$$` 标记 LaTeX 公式；
- 使用话题名称作为消息标题；
- 显示模型名称和模型供应商；
- 不导出引用内容；
- 把引用标记标准化为 Markdown 脚注格式。

部分选项也会影响基于 Markdown 的第三方导出，例如 Notion 和语雀。启用“不导出引用内容”与“标准化引用格式”前，应先用一段包含引用的对话验证结果是否符合预期。

## 常见问题

### 自动备份一直没有生成文件

确认备份周期不是“关闭”，目标目录或远程服务可访问，并查看页面底部的最近备份时间或错误提示。本地目录位于移动设备或网络挂载点时，还要确认它当前在线。

### 精简备份恢复后缺少图片或知识库文件

这是精简备份的预期行为。它只保留聊天记录和设置，不包含 `Data` 目录中的文件数据。请改用关闭“精简备份”后创建的完整备份。

### 更改数据目录后像是全新安装

可能是迁移时关闭了 **复制数据**，或应用启动到了空目录。先不要继续写入大量新数据，检查原目录是否仍在，再通过设置迁回或从备份恢复。

### 多台电脑恢复后数据没有自动合并

备份恢复是覆盖式流程，不会合并两边的新增内容。选择恢复前先比较备份时间，并为当前设备另存一份备份。

如仍无法解决，请通过[反馈与建议](../../question-contact/suggestions.md)提交操作系统、Cherry Studio 版本、使用的备份方式、错误提示和已脱敏的设置截图。
