# 数据设置

打开**设置 → 数据设置**，可以管理应用数据目录、导入与导出选项、缓存、日志和笔记服务连接。

{% hint style="warning" %}
当前 V2 的应用内备份与恢复尚未上线。数据、本地备份、WebDAV、坚果云和 S3 页面会显示“V2 备份恢复尚未上线”提示，相关控件均为禁用状态。不要依赖这些入口保存或恢复重要数据。
{% endhint %}

## 页面一览

| 分组 | 页面 | 当前用途 |
| --- | --- | --- |
| 数据 | 数据 | 查看或迁移应用数据目录、打开日志、清理缓存、重置数据和设置隐私选项 |
| 云备份 | 本地备份、WebDAV、坚果云、S3 | 页面可见，但备份、恢复、自动同步和凭据输入当前不可用 |
| 导入设置 | 导入应用数据 | 选择导入菜单中显示的来源 |
| 导出设置 | 导出菜单 | 选择对话导出菜单中显示的格式和目标 |
| 导出设置 | Markdown 导出 | 设置默认目录、文件名、公式、模型信息和引用格式 |
| 笔记导出 | Notion、语雀、Joplin、Obsidian、思源笔记 | 配置各笔记服务或本地笔记库的导出目标 |

## 数据页面

### 应用数据目录

**应用数据**一行显示当前实例实际使用的目录。点击路径或**打开目录**可以在系统文件管理器中查看；点击修改目录图标可以发起迁移。

迁移会重启应用，而且可能复制数据库、内部文件、知识库和笔记。请先阅读[修改存储位置](../personalization-settings/storage.md)，准备离线副本并使用空目录作为目标。

### 应用日志

点击**打开日志**可以进入日志目录。提交问题时，只提供与故障时间相符的必要日志，并先检查其中是否包含路径、提示词或其他敏感信息。

### 清理缓存

**清理缓存**会删除可重新生成的缓存和本地 Trace 数据，不等同于删除聊天记录或重置整个应用。若问题与登录状态、模型配置或知识库有关，不要把清理缓存当作通用修复。

### 数据重置

**数据重置**是破坏性操作，会清除当前实例的数据并返回初始状态。当前应用内备份不可用；没有独立副本时不要执行。

## 导入设置

**导入应用数据**用于控制导入菜单里显示哪些来源。它只改变菜单入口，不会在后台自动读取其他应用的数据。

导入前先确认文件来源可信，并保留原文件。导入结果取决于来源格式和当前版本支持范围。

## 导出设置

### 导出菜单

决定对话导出时显示哪些格式或第三方目标。关闭某项只会隐藏入口，不会删除已经导出的文件。

### Markdown 导出

可以设置默认保存目录、文件名规则，以及是否包含模型信息、引用和公式等内容。导出目录应位于应用数据目录之外，方便独立归档。

### 笔记导出

Notion、语雀、Joplin、Obsidian 和思源笔记各自使用独立设置。配置服务地址、令牌或本地目录后，先用一条非敏感测试内容验证目标位置和格式，再批量导出。

{% hint style="info" %}
导出是单向写出，不是双向同步，也不能替代完整备份。外部附件、知识库索引和应用内部状态不一定包含在导出结果中。
{% endhint %}

## 当前如何保护数据

在 Backup & Restore V2 上线前：

1. 记录**应用数据**页面显示的当前目录。
2. 完全退出 Cherry Studio。
3. 将整个目录复制到另一块磁盘，并确认副本可读取。
4. 保留重要资料的原始文件和必要的对话导出。

不要在应用运行时复制或合并数据库文件。后续备份功能启用后，请以应用内状态和本页最新说明为准。
