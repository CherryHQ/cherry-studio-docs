# WebDAV 备份

Cherry Studio V2 可以把备份文件保存到支持 WebDAV 的网盘、NAS 或自建服务器。你可以手动创建备份，也可以按固定周期自动备份并控制保留数量。

WebDAV 在这里是“创建备份文件并恢复”的存储通道，不是多台设备之间的实时双向同步。恢复会覆盖当前数据，不会合并两边各自新增的对话。

{% hint style="warning" %}
WebDAV 备份可能包含对话、服务商配置和其他敏感信息。使用私有目录和应用专用密码，不要把凭据或备份文件公开分享。
{% endhint %}

## 准备连接信息

在 WebDAV 服务商或服务器管理页面取得：

| 字段 | 填写内容 |
| --- | --- |
| WebDAV 地址 | WebDAV 服务入口，通常是包含 `https://` 的完整地址 |
| WebDAV 用户名 | 服务商分配的账户名、邮箱或 WebDAV 专用用户名 |
| WebDAV 密码 | 普通密码或服务商生成的应用专用密码 |
| WebDAV 路径 | Cherry Studio 保存备份的远程目录 |

不同服务对地址和认证方式的要求不同。普通网页登录地址不一定是 WebDAV 地址；启用双重验证后，通常需要应用专用密码而不是账户登录密码。

默认远程路径为 `/cherry-studio`。目标目录不存在时，Cherry Studio 会在第一次上传时尝试递归创建。建议为 Cherry Studio 使用独立目录，避免备份管理器与其他文件混在一起。

{% hint style="info" %}
Cherry Studio V2 还提供独立的 **坚果云**备份页面。希望通过坚果云账户授权连接时，可以直接使用该入口；只有需要手动填写通用 WebDAV 参数时才使用本页。
{% endhint %}

## 在 Cherry Studio 中配置

1. 打开 **设置 > 数据设置 > WebDAV**。
2. 填写 **WebDAV 地址**，保留地址中的 `http://` 或 `https://`。
3. 填写 **WebDAV 用户名**和 **WebDAV 密码**。
4. 填写远程路径，例如 `/cherry-studio`。
5. 暂时保持 **自动备份**为关闭。
6. 点击 **备份到 WebDAV**，使用默认文件名创建一份测试备份。
7. 上传完成后点击 **从 WebDAV 恢复**，确认备份管理器能列出刚创建的文件。

当前页面没有单独的“测试连接”按钮。能成功上传测试备份并在管理器中重新列出，才表示地址、认证、路径创建和写入权限均可用。

测试时使用不含敏感附件的小型数据更容易定位问题。连接确认后，再决定是否启用完整备份和自动备份。

## 手动创建备份

点击 **备份到 WebDAV**后会显示默认文件名，格式中包含时间、主机名和设备类型。可以修改名称；未以 `.zip` 结尾时，Cherry Studio 会自动补上扩展名。

打开 **精简备份**会跳过应用 `Data` 目录中的图片、知识库等文件数据，只保留聊天记录和设置等内容。它不是增量备份，也不能用于找回被跳过的文件。

手动备份完成后，远程目录中会保留一个独立 ZIP 文件。不要在上传过程中退出应用、切断网络或让系统休眠。

## 设置自动备份

**自动备份**支持：

- 关闭；
- 1、5、15 或 30 分钟；
- 1、2、6、12 或 24 小时。

先完成一次手动测试，再选择周期。频率越高，远程请求和存储写入越多；对大体积完整备份，通常不需要按分钟执行。

页面会显示上次备份时间或最近错误。看到“等待下次备份”时，表示当前还没有成功记录；不代表连接已经验证。

### 控制保留数量

**最大备份数**可设为无限制、1、3、5、10、20 或 50。

自动清理只针对当前设备按默认命名规则创建的备份。Cherry Studio 会根据文件名中的主机名和设备类型识别当前设备，并删除超出数量的较旧文件。

自定义文件名若不含当前设备标识，可能不会被自动清理；“无限制”也不会主动释放远程空间。应定期打开备份管理器检查容量。

## 管理和恢复备份

点击 **从 WebDAV 恢复**打开备份管理器。这里可以：

- 查看文件名、修改时间和大小；
- 刷新远程文件列表；
- 选择一个备份恢复；
- 删除单个或批量删除备份。

恢复前：

1. 先为当前设备创建一份新的备份。
2. 根据文件名、修改时间和大小确认目标版本。
3. 确认当前没有其他设备正在向同一目录写入。
4. 点击 **恢复**并确认覆盖当前数据。

恢复完成后应用可能自动重新启动。删除备份不可撤销，批量删除前应再次核对所选文件。

{% hint style="warning" %}
同一个远程目录可以被多台设备读取，但恢复不会合并数据。需要在 B 设备使用 A 设备的数据时，应先备份 B，再恢复 A 的目标版本。
{% endhint %}

## 何时启用“禁用流式上传”

默认情况下，Cherry Studio 以流式方式上传备份，适合大文件且内存占用较低。

部分 WebDAV 服务不兼容分块或流式上传，表现为小文件正常、大备份上传失败，或返回与请求长度、`chunked` 传输有关的错误。此时可以打开 **禁用流式上传**后重试。

启用后，Cherry Studio 会先把整个备份文件读取到内存再上传，因此：

- 内存占用会接近备份文件大小；
- 大型备份可能使应用明显变慢；
- 只应作为兼容性方案，不建议默认开启。

若开启后仍失败，应检查服务端的单文件大小、请求体和超时限制，而不是反复提高备份频率。

## 安全建议

- 在公网环境优先使用 `https://`，避免通过明文 HTTP 发送密码和备份。
- 为 Cherry Studio 创建独立账户或应用专用密码，只授予目标目录所需权限。
- 不在截图、反馈或共享配置中显示完整地址中的私有信息、用户名和密码。
- 不要恢复来源不明的 ZIP 文件。
- 定期验证至少一份完整备份可被列出和识别。

## 常见问题

### 点击备份后提示未授权、401 或 403

检查用户名和密码是否属于 WebDAV，而不是普通网页登录；服务启用双重验证时改用应用专用密码。还要确认账户对目标路径有创建目录和写文件权限。

### 返回 404 或找不到路径

先确认填写的是 WebDAV 服务入口，而不是网盘首页或文件分享链接。将路径改为以 `/` 开头的简单目录，例如 `/cherry-studio`，再用手动备份测试。

### 可以列出文件，但上传大备份失败

先检查服务端单文件大小、反向代理请求体和超时限制。若错误与分块上传有关，再打开 **禁用流式上传**；使用该选项时为完整备份预留足够内存。

### 自动备份没有执行

确认周期不是“关闭”、WebDAV 地址不为空，并检查页面底部的备份状态。电脑休眠、断网或服务不可用时，计划备份无法完成。

### 达到最大备份数后旧文件仍在

自动清理按当前设备标识筛选文件。手动改名、来自其他设备或不符合默认命名格式的文件可能保留，需要在备份管理器中手动删除。

### 从另一台电脑恢复后，本机新对话消失

恢复是覆盖式操作，不是数据合并。使用远程备份跨设备搬迁前，先分别备份两台设备，并只恢复已确认的目标版本。

如仍无法解决，请通过[反馈与建议](../../question-contact/suggestions.md)提交 Cherry Studio 版本、操作系统、已脱敏的地址与路径、HTTP 状态码和完整错误信息。
