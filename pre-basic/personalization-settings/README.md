# 个性化设置

让 Cherry Studio **长成你喜欢的样子**：换颜色、改字体、维护自定义 CSS，并管理数据位置。

<figure><img src="../../.gitbook/assets/cherry-appearance-v2.png" alt="浅色模式下的 Cherry Studio 外观设置，包含语言、主题、缩放和字体选项"><figcaption><p>设置 → 外观：常用个性化选项集中在同一页</p></figcaption></figure>

## 我可以改什么？

| 想做的事 | 看哪一篇 |
|---|---|
| 把界面颜色 / 布局深度自定义 | [自定义 CSS](custom-css.md) |
| 调整界面与代码字体 | [字体设置](font.md) |
| 查看或迁移应用数据目录 | [数据存储位置](storage.md) |
| CSS 改得太乱想还原 | [清除 CSS 设置](clear-css.md) |

## 分别在哪里设置

| | 外观设置 | 本节进阶文档 |
|---|---|---|
| 入口 | `设置 → 外观` | CSS 在 `设置 → 外观`；数据路径在 `设置 → 数据设置` |
| 控制 | 主题、颜色、字体、消息与代码块样式 | 自定义 CSS、字体建议、数据目录查看与迁移 |
| 风险 | 安全 | 改坏了可能影响界面（可清除还原）|
| 适合谁 | 所有人 | 想深度定制的进阶用户 |

如果只想简单调整界面，请看 [外观设置](../settings/display.md)；需要维护 CSS 或迁移数据目录时再阅读本节。
