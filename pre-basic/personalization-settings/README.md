# 个性化设置

Cherry Studio V2 已把常用的外观选项集中到**设置 > 通用设置 > 显示与语言**。无需编写代码，就能调整主题、颜色、缩放、字体和话题布局；只有内置选项无法满足需求时，才需要使用自定义 CSS。

{% hint style="info" %}
“个性化设置”是本文档中的专题名称，不是应用内的独立设置菜单。请从左下角的**设置**进入**通用设置**。
{% endhint %}

## 先选择合适的方式

| 想要完成的操作 | 推荐入口 | 风险 |
| --- | --- | --- |
| 切换浅色、深色或跟随系统 | 设置 > 通用设置 > 显示与语言 | 低 |
| 修改主题强调色 | 设置 > 通用设置 > 显示与语言 | 低 |
| 放大或缩小整个界面 | 设置 > 通用设置 > 显示与语言 | 低 |
| 修改全局字体或代码字体 | 设置 > 通用设置 > 显示与语言 | 低 |
| 调整话题位置、时间和置顶方式 | 设置 > 通用设置 > 显示与语言 | 低 |
| 深度修改组件样式 | 设置 > 通用设置 > 自定义 CSS | 中 |
| 把应用数据迁移到其他磁盘 | 设置 > 数据设置 > 数据目录 | 高，建议先备份 |

建议从内置选项开始。内置设置会随版本维护，通常比自定义 CSS 更稳定。

## 显示与语言

打开**设置 > 通用设置 > 显示与语言**后，可以调整以下内容。

### 语言与主题

- **语言**：切换 Cherry Studio 的界面语言；
- **主题**：选择浅色、深色或跟随系统；
- **主题色**：从预设颜色中选择，或输入自定义颜色；
- **窗口透明效果**：仅在 macOS 上显示；
- **使用系统标题栏**：仅在 Linux 上显示，修改后需要重启应用。

### 界面缩放

使用减号和加号逐级调整整个应用的缩放比例，点击重置按钮可恢复默认缩放。

如果只是觉得消息文字偏小，优先调整消息字体大小；如果按钮、侧栏和弹窗都偏小，再调整整个界面缩放。

### 字体

V2 会读取操作系统中已经安装的字体，并分别提供：

- **全局字体**：用于大部分界面和正文；
- **代码字体**：用于代码块、代码编辑器等等宽内容。

选择字体后立即生效；点击对应的重置按钮可恢复默认字体。需要安装新字体时，可参考[字体推荐](font.md)。

{% hint style="info" %}
字体列表来自当前操作系统。安装新字体后，如果列表没有更新，请完全退出并重新打开 Cherry Studio。
{% endhint %}

### 话题布局

可以把话题列表放在左侧或右侧，并控制：

- 点击助手时是否自动切换到话题；
- 是否显示话题时间；
- 是否将选中的话题固定到顶部。

“点击助手时自动切换到话题”只会在话题位于左侧时显示。

## 自定义 CSS

当内置主题和布局选项无法满足需求时，可以进入**设置 > 通用设置 > 自定义 CSS**，直接编辑样式。

自定义 CSS 适合修改间距、颜色、圆角和特定组件外观，但应用升级后组件结构可能变化，旧规则也可能失效。开始前请阅读[自定义 CSS](custom-css.md)，并保留一份可用样式的副本。

如果错误样式导致设置页无法操作，可参考[清除 CSS 设置](clear-css.md)恢复。

{% hint style="warning" %}
不要为了修改字体或主题色而优先使用 CSS。V2 已提供对应的内置选项，使用内置设置更容易恢复，也更不容易在升级后失效。
{% endhint %}

## 数据目录

修改存储位置不是外观设置，而是数据迁移操作。入口位于**设置 > 数据设置 > 数据目录**。

迁移可能涉及对话、助手、知识库和其他本地数据。操作前请先完成备份，并确认目标目录：

- 不是磁盘根目录；
- 不在当前数据目录内部；
- 不在应用安装目录内部；
- 具有写入权限；
- 有足够的可用空间。

详细步骤与注意事项请参阅[修改存储位置](storage.md)。

## 推荐顺序

如果想快速调整界面，可以按以下顺序进行：

1. 选择主题和主题色；
2. 调整界面缩放；
3. 选择全局字体和代码字体；
4. 调整话题布局；
5. 确认内置选项仍不能满足需求后，再添加自定义 CSS。

这样可以减少样式冲突，后续恢复默认外观也更简单。
