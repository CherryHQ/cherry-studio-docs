# 清除 CSS 设置

自定义 CSS 出现语法或选择器错误时，可能导致按钮被遮挡、文字不可见、页面无法滚动，甚至无法进入设置。请根据界面是否仍可操作，选择下面的恢复方式。

## 方法一：在设置中清空

如果仍能打开设置：

1. 进入**设置 > 通用设置 > 自定义 CSS**。
2. 先把需要排查的 CSS 复制到文本文件中。
3. 全选并删除编辑器中的全部内容。
4. 等待界面恢复。
5. 完全退出并重新打开 Cherry Studio，确认问题没有再次出现。

这是首选方法。清空编辑器会同时删除已保存的自定义 CSS 设置。

## 方法二：用开发者工具临时恢复

如果错误样式让设置页无法操作，可以先在当前窗口中移除已注入的样式节点。

{% hint style="warning" %}
下面的命令只会让当前窗口**临时恢复**。在重新加载或重启应用前，必须回到设置页清空 CSS，否则错误样式会再次出现。
{% endhint %}

### 1. 打开开发者工具

可使用任一方式：

- Windows / Linux：按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd>；
- macOS：按 <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>I</kbd>；
- 应用菜单：选择**视图 > 切换开发者工具**；
- 在页面空白处点击右键，选择**检查**。

### 2. 打开 Console

在开发者工具顶部选择 **Console**。如果开发者工具停靠后空间太小，可以把它切换到独立窗口。

### 3. 移除当前样式

在 Console 中手动输入下面一行，然后按回车：

```javascript
document.getElementById('user-defined-custom-css')?.remove()
```

命令执行后，自定义 CSS 应立即从当前主窗口移除。

某些 Chromium 版本会阻止直接粘贴到 Console。请按照开发者工具中的安全提示操作，或手动输入这条短命令；不要粘贴来源不明的其他脚本。

### 4. 删除已保存的 CSS

不要刷新或关闭当前窗口。立即：

1. 回到 Cherry Studio；
2. 打开**设置 > 通用设置 > 自定义 CSS**；
3. 清空编辑器；
4. 关闭开发者工具；
5. 完全退出并重新打开应用。

如果重启后界面正常，说明已保存的 CSS 已被清除。

## 只删除有问题的规则

如果希望保留主题中的其他部分：

1. 先按方法二临时恢复界面；
2. 把编辑器中的全部 CSS 复制到外部文本文件；
3. 清空编辑器并确认应用恢复；
4. 每次只放回一小段；
5. 在浅色、深色、聊天、设置和弹窗中分别检查。

当问题再次出现时，最后放回的规则通常就是排查重点。

常见原因包括：

- 缺少 `}`、`;` 或引号；
- 使用覆盖全局的 `display: none`、`position: fixed` 或极高 `z-index`；
- 把所有按钮、输入框或滚动容器隐藏；
- 使用旧版类名或 `body[theme-mode="dark"]` 等旧主题选择器；
- 大范围使用 `!important`；
- 第三方主题与当前版本的 DOM 结构不兼容。

## 常见问题

### 命令执行后没有变化

确认 Console 对应的是 Cherry Studio 主页面，而不是小程序网页或开发者工具自身。再次执行：

```javascript
document.getElementById('user-defined-custom-css')
```

如果返回 `null`，当前窗口没有这个样式节点；问题可能不是自定义 CSS，或命令执行在错误的页面上下文。

### 临时恢复后，重启又出现问题

这是因为只移除了当前页面中的样式节点，没有清空已保存设置。重新执行方法二，并在不刷新页面的情况下进入 CSS 编辑器清空内容。

### 快捷键无法打开开发者工具

尝试应用菜单中的**视图 > 切换开发者工具**，或右键选择**检查**。系统快捷键工具可能拦截默认组合键。

### 设置页仍然无法打开

不要删除整个应用数据目录，也不要直接修改数据库。请保留当前版本号、系统信息和日志目录，通过官方反馈渠道寻求帮助。

### 清空后仍有自定义外观

检查是否还启用了操作系统主题、Cherry Studio 内置主题色、字体设置或第三方窗口工具。它们不属于自定义 CSS，不会随本页操作一起重置。

## 避免再次发生

- 每次只添加一小段规则；
- 在修改前保存一份可用版本；
- 优先覆盖语义变量，少依赖内部类名和 DOM 层级；
- 升级 Cherry Studio 后先禁用复杂主题再逐段验证；
- 只使用能够阅读和理解的第三方 CSS。

更多编写建议请参阅[自定义 CSS](custom-css.md)。
