# 智谱 GLM-4.6V

Cherry Studio 能识别多家服务商提供的 GLM-4.6V 及其常见变体，并将标准版本识别为支持图片、文件、推理和工具调用的多模态模型。最终可用能力仍取决于服务商实际开放的接口。

{% hint style="warning" %}
本文不再承诺 GLM-4.6V 始终属于 CherryAI 或 CherryIN 免费试用模型。模型是否免费、是否仍可用，请以模型选择器、服务商控制台和实际请求结果为准。
{% endhint %}

## 先检查是否已经可用

1. 打开对话界面的模型选择器；
2. 搜索 `GLM-4.6V`；
3. 确认模型所属服务商，并查看视觉、文件、推理和工具调用标签；
4. 选择模型，上传一张不含敏感信息的图片进行测试。

同一模型可能由多个服务商提供，显示名称、模型 ID 和能力标签可能不同。

## 通过服务商接入

如果模型选择器中没有 GLM-4.6V：

1. 打开 `设置 → 模型服务`；
2. 选择 ZhiPu，或账户中提供该模型的聚合服务商；
3. 填写 API Key 并检查 Base URL；
4. 点击**添加**，应用同步预览中的模型变更；
5. 搜索并启用 GLM-4.6V；
6. 运行连接检查或模型健康检查。

Cherry Studio 的模型注册表能识别多家服务商使用的 GLM-4.6V 标识，但并不保证你的账户已经开通该模型。

## 选择正确的变体

服务商可能同时提供标准版、Flash、FP8 或带其他后缀的版本。它们是独立模型，不应只按名称相似就假设能力相同。

- 需要图片理解时，确认模型带有**视觉**或**图片识别**能力；
- 需要上传文档时，确认模型带有**文件输入**能力；
- 需要 MCP 或其他工具时，确认模型带有**工具调用**能力；
- 只做文本任务时，可以根据服务商的速度、额度和计费说明选择合适变体。

{% hint style="danger" %}
不要根据本文猜测模型 ID。请复制服务商控制台或 API 文档中的完整 ID；填错 ID 可能返回“模型不存在”，也可能路由到不同变体。
{% endhint %}

## 在对话中使用图片

1. 选择带视觉能力的 GLM-4.6V；
2. 将图片拖入输入区、粘贴图片，或点击附件按钮添加图片；
3. 在同一条消息中说明任务，例如提取表格、解释图表或分析界面；
4. 发送前检查图片中是否包含 API Key、个人信息或其他敏感内容。

如果输入区不允许添加图片，通常表示当前模型没有被识别为视觉模型。可以重新同步模型，或在模型编辑页核对能力设置。

## 常见问题

### 上传了图片，但模型无法识别

确认选择的是支持视觉的 GLM-4.6V 变体，并检查服务商端点是否支持图片输入。仅名称相同不足以证明接口能力一致。

### 模型能对话，但无法调用工具

先检查工具调用能力标签，再用一个简单工具测试。服务商可能没有为该变体开放工具调用，或使用了不兼容的接口。

### 同步列表中没有 GLM-4.6V

查看服务商控制台是否已向你的账户开放该模型。如果接口不返回模型列表，可以点击**自定义**并填写服务商给出的模型 ID。

### 返回文件或上下文过大

减少图片数量或分辨率，拆分长文档，并新建话题后重试。具体限制由服务商和模型变体决定。

免费试用的通用规则见 [CherryAI（免费试用）](README.md)，服务商配置流程见[模型服务](../README.md)。
