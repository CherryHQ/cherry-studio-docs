# Qwen3-8B

Cherry Studio 能识别多家服务商提供的 Qwen3-8B。部分版本会把 `Qwen/Qwen3-8B` 作为应用内试用模型，并将服务入口指向 CherryIN；其他服务商也可能使用相同或不同的模型 ID。

{% hint style="warning" %}
模型出现在试用列表中，不代表它会长期免费。请以模型选择器中的**免费**标记、服务商控制台和实际请求结果为准。
{% endhint %}

## 先检查是否已经可用

1. 打开对话界面的模型选择器；
2. 搜索 `Qwen3-8B`，或启用**免费**标签；
3. 确认模型所属服务商；
4. 选择模型并发送一条简单测试消息。

如果试用标签旁显示 CherryIN，点击该标签可以进入对应服务商配置。CherryAI 本身不会出现在常规模型服务列表中。

## 通过服务商接入

如果模型选择器中没有 Qwen3-8B：

1. 打开 `设置 → 模型服务`；
2. 选择 ModelScope、OpenRouter，或账户中提供该模型的其他服务商；
3. 填写 API Key 并检查 Base URL；
4. 点击**添加**并应用模型变更；
5. 搜索并启用 Qwen3-8B；
6. 运行连接检查或模型健康检查。

部分服务商使用 `Qwen/Qwen3-8B`，另一些使用 `qwen/qwen3-8b`。大小写、命名空间和后缀都可能影响路由。

## 无法同步时手动添加

如果服务商不提供模型列表接口，点击**自定义**，复制该服务商控制台或 API 文档中的完整模型 ID。

{% hint style="danger" %}
不要把其他平台的模型 ID 直接复制过来。即使名称相同，不同服务商也可能使用不同命名空间、能力配置或接口路径。
{% endhint %}

## 推理与工具调用

Qwen3 系列可能支持可控推理。Cherry Studio 会根据服务商能力使用 `enable_thinking` 参数，或在不支持该参数的接口上使用兼容方式控制思考模式。

使用时建议：

- 只有在模型选择器显示推理能力时才依赖思考设置；
- 需要 MCP 或其他工具时，先确认工具调用标签并完成一次简单测试；
- 不要手动把 `/think` 或 `/no_think` 固定写入所有提示词，优先使用 Cherry Studio 的思考设置；
- 同名模型由不同服务商提供时，分别验证推理和工具调用。

## 常见问题

### “免费”筛选中找不到 Qwen3-8B

当前版本或地区可能没有提供该试用模型。你仍可以配置支持它的服务商，并使用自己的 API Key。

### 点击试用标记后进入 CherryIN

这是预期行为。V2 会把特定 Qwen 试用模型的服务入口映射到 CherryIN，方便用户在试用额度结束后配置服务。

### 思考模式没有变化

检查服务商是否支持 `enable_thinking`，以及当前模型是否为可切换推理的变体。某些端点会忽略不支持的参数。

### 返回“模型不存在”

核对大小写和完整模型 ID，重新同步列表；如果是手动添加的条目，请使用当前服务商给出的 ID 替换。

免费试用的通用规则见 [CherryAI（免费试用）](README.md)，服务商配置流程见[模型服务](../README.md)。
