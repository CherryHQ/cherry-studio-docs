# 智谱 GLM-4.5-Air

Cherry Studio 能识别多家服务商提供的 GLM-4.5-Air 及其常见变体。标准模型会被识别为文本推理与工具调用模型；是否开放这些能力，仍以服务商接口和实际测试为准。

{% hint style="warning" %}
本文不再承诺 GLM-4.5-Air 始终属于 CherryAI 或 CherryIN 免费试用模型。模型是否免费、是否仍可用，请以模型选择器、服务商控制台和实际请求结果为准。
{% endhint %}

## 先检查是否已经可用

1. 打开对话界面的模型选择器；
2. 搜索 `GLM-4.5-Air`；
3. 确认模型所属服务商和能力标签；
4. 选择模型并发送一条简单测试消息。

如果出现多个同名条目，请根据服务商名称和完整模型 ID 区分。

## 通过服务商接入

如果模型选择器中没有 GLM-4.5-Air：

1. 打开 `设置 → 模型服务`；
2. 选择 ZhiPu，或账户中提供该模型的聚合服务商；
3. 填写 API Key 并检查 Base URL；
4. 点击**添加**并应用模型变更；
5. 搜索并启用 GLM-4.5-Air；
6. 运行连接检查或模型健康检查。

Cherry Studio 的模型注册表包含多个服务商使用的 GLM-4.5-Air 标识。这些映射用于识别模型，不表示你的账户一定有权限或免费额度。

## 选择正确的变体

服务商可能提供标准版、AirX、FP8 或带 `free` 后缀的条目。

- 标准版与 AirX、FP8 是不同的模型或部署；
- `free` 只表示该服务商给模型 ID 使用了免费标记，不代表永久免费；
- 同名模型的上下文、速度、工具调用和推理控制可能因端点而异；
- 不要把模型 ID 从一家服务商直接复制到另一家服务商。

{% hint style="danger" %}
请从当前服务商的控制台或 API 文档复制模型 ID。手动填写看似相同但实际不受支持的 ID，会导致 404 或“模型不存在”。
{% endhint %}

## 推理与工具调用

如果模型选择器显示推理能力，你可以在对话中使用 Cherry Studio 提供的思考设置。不同服务商可能通过参数、模型变体或提示词控制推理，Cherry Studio 会按服务商配置选择相应方式。

需要使用 MCP 或其他工具时：

1. 确认模型带有工具调用能力标签；
2. 先启用一个简单且可验证的工具；
3. 发送明确指令并观察模型是否真正发起调用；
4. 若只输出调用计划而没有执行，检查服务商端点和模型能力。

## 常见问题

### 找不到思考开关

当前服务商或模型变体可能不支持可控推理。重新同步模型并核对能力标签；不要仅凭模型名称判断。

### 工具调用格式错误

更换服务商端点或模型变体后重试。聚合网关对工具调用参数的兼容程度可能不同。

### 返回 401、403 或余额不足

检查 API Key、模型权限、账户余额和地区限制。试用额度用尽时，请配置自己的凭证或切换模型。

### 模型 ID 不存在

删除手动添加的错误条目，重新同步列表，或使用服务商文档中的完整模型 ID。

免费试用的通用规则见 [CherryAI（免费试用）](README.md)，服务商配置流程见[模型服务](../README.md)。
