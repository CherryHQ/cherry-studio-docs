# CherryIN 模型服务

Cherry Studio V2 把官方模型入口统一到 **CherryIN**。可用模型、免费额度、活动和授权方式会动态变化，请以 `设置 → 模型服务 → CherryIN` 中的实时界面为准。

## 适合谁？

* 第一次使用 Cherry Studio，希望尽快完成对话；
* 不想逐个研究第三方 Provider 的 API 地址；
* 希望直接查看 CherryIN 当前提供的模型列表。

CherryIN 是否免费、具体额度和模型可用状态可能随服务端调整。客户端开源不代表所有云端模型都永久免费。

## 配置步骤

1. 打开 `设置 → 模型服务 → CherryIN`；
2. 按当前页面提示完成登录、授权或密钥配置；
3. 点击 **获取模型列表**；
4. 添加并启用一个对话模型；
5. 点击 **检测** 验证连接。

**成功标志**：检测返回成功，并且该模型能在对话页的模型选择器中出现。

如果无法获取模型，检查授权信息、账户状态和网络；仍然失败时，请保留错误信息并查看[反馈与建议](../../../question-contact/suggestions.md)。

## 如何选择模型？

模型名称、能力、上下文和额度均可能变化。选择时以客户端实时说明为准：

* 日常问答和写作：选择通用对话模型；
* 图片理解：选择明确标注视觉能力的模型；
* Agent：选择支持工具调用且运行稳定的对话模型；
* 知识库：需要单独选择嵌入模型，不能用普通对话模型代替。

本节保留的模型介绍用于理解典型能力，不应作为当前价格、额度或上线状态的唯一依据。
