# CherryAI（免费试用）

CherryAI 是 Cherry Studio 内置的云端试用服务。它会随应用自动启用，不要求用户先填写 API Key，适合初次安装后快速体验对话和模型选择。

{% hint style="info" %}
CherryAI 是应用内试用服务；[CherryIN](../cherryin-1.md) 是可以配置 API Key 的模型服务商。两者名称相近，但入口、额度和配置方式不同。
{% endhint %}

## 直接开始使用

1. 打开[对话界面](../../../cherrystudio/preview/chat.md)；
2. 点击输入区或助手标题栏中的模型名称，打开模型选择器；
3. 搜索 `CherryAI`，或使用**免费**标签筛选可用试用模型；
4. 选择模型并发送消息。

CherryAI 模型会在模型选择器中显示试用服务标记。可用模型可能随应用版本和服务状态变化，因此请以应用内实际列表为准。

## 为什么“模型服务”中找不到 CherryAI

这是正常行为。V2 会把 CherryAI 加入可选模型来源，但刻意不在 `设置 → 模型服务` 的常规服务商列表中显示，也不允许用户修改它的 API Key 或 Base URL。

如果需要稳定使用自己的账户和额度，请按[模型服务](../README.md)中的步骤配置 CherryIN、模型厂商官方 API、本地模型或其他网关。

## 免费额度

CherryAI 请求使用试用额度。额度用尽时，应用会显示相应提示；你可以：

- 等待试用额度恢复后再使用；
- 切换到其他已配置且已启用的模型；
- 按提示前往对应服务商配置自己的 API Key。

{% hint style="warning" %}
免费额度、恢复时间和可用模型均可能调整。本文不提供固定额度承诺，也不建议把试用服务作为生产任务、长期自动化或唯一可用模型。
{% endhint %}

## 使用限制

- **无需配置不等于离线运行**：消息仍会发送到 CherryAI 的云端接口；
- **模型能力各不相同**：视觉、推理、联网和工具调用等能力以模型标签及实际响应为准；
- **服务商页面不可编辑**：在模型选择器中看到 CherryAI，但在模型服务设置中找不到，是预期设计；
- **试用模型可能变更**：已经保存到助手中的模型如果下线，请重新打开模型选择器并更换。

## 与自有模型一起使用

你可以先用 CherryAI 完成首次体验，再配置自己的服务商。完成配置后：

1. 在模型服务页面启用目标服务商和模型；
2. 回到模型选择器选择新模型；
3. 按需在[默认模型设置](../../settings/default-models.md)中指定默认、快速、翻译或主题命名模型。

这样即使试用额度暂时不可用，也能直接切换到自己的模型。

如果 CherryAI 没有出现在模型选择器中，或所有试用模型都无法请求，请先确认网络正常并重启应用。仍无法使用时，提交 Cherry Studio 版本、操作系统和脱敏后的错误信息，反馈渠道见[反馈与建议](../../../question-contact/suggestions.md)。
