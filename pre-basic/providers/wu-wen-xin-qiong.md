# 无问芯穹

无问芯穹（Infini-AI）是 Cherry Studio 内置的模型服务商之一。配置 API Key 后，可以在 Cherry Studio 中使用该平台当前提供的对话模型和嵌入模型；实际模型、价格与额度以服务商控制台为准。

## 使用前准备

1. 登录 [无问芯穹控制台](https://cloud.infini-ai.com/genstudio/model?cherrystudio)。
2. 在控制台创建 API Key。
3. 确认账户具备目标模型的调用权限和可用额度。

{% hint style="warning" %}
API Key 只会用于连接模型服务。不要把它放进截图、公开文档、群聊或 Git 仓库；怀疑泄露时请立即撤销并重新生成。
{% endhint %}

## 在 Cherry Studio 中配置

1. 打开 **设置 → 模型服务**。
2. 在内置 Provider 列表中选择 **无问芯穹**。
3. 粘贴 API Key；API 地址没有特殊需求时保留默认值。
4. 点击 **获取模型列表**，添加要使用的模型。
5. 选择一个对话模型并点击 **检测**。

## 开始对话

检测成功后回到对话页，从模型选择器中选择刚添加的模型，发送一条简短测试消息。

成功时应看到：

* 模型列表可以正常获取；
* 检测返回成功；
* 对话页能选中该模型并收到回复。

## 用于知识库

如果无问芯穹当前提供嵌入模型，也可以把它用于 Cherry Studio 知识库：

1. 先在 Provider 页面添加并启用目标嵌入模型。
2. 新建知识库时选择该嵌入模型。
3. 导入少量文档，等待索引完成。
4. 用文档中的明确问题测试检索结果。

{% hint style="info" %}
嵌入模型决定知识库如何建立索引。知识库创建后不要随意更换嵌入模型；确需更换时，建议新建知识库并重新索引。
{% endhint %}

## 常见问题

* **检测失败**：检查 API Key、账户余额、目标模型权限和当前网络。
* **获取不到模型**：稍后重试，并到服务商控制台确认模型仍可用。
* **知识库无法创建**：确认选择的是嵌入模型，而不是普通对话模型。
