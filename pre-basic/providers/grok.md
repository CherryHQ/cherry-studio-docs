# Grok

Cherry Studio V2 的 Grok 内置模板用于连接 xAI 官方 API。V2 会为该服务商使用 xAI Responses 适配，从而支持对话、推理、工具调用，以及 xAI 官方的 Web Search 和 X Search。

{% hint style="warning" %}
Grok 不会自动获得实时信息。只有在对话中启用联网后，Cherry Studio 才会向 xAI 请求 Web Search 和 X Search；服务器端搜索工具可能产生额外费用。
{% endhint %}

## 开始前准备

- 可登录 [xAI Console](https://console.x.ai/)的账户；
- 已在 xAI Console 创建 API Key；
- 团队或账户具有可用额度；
- 已确认当前可用模型和服务地区。

x.com 或 Grok 网页端的登录状态不会自动写入 Cherry Studio。使用 xAI API 需要单独创建 API Key。

## 配置 Grok

1. 打开 `设置 → 模型服务`；
2. 将左侧筛选切换为**全部**，选择 **Grok**；
3. 输入 xAI API Key；
4. 保留默认 Base URL `https://api.x.ai`；
5. 打开页面顶部的服务商开关；
6. 在模型列表点击**添加**，检查同步预览并应用变更；
7. 启用准备使用的模型。

{% hint style="danger" %}
不要把 API Key 写入聊天消息、文档、代码仓库或问题截图。泄露后应立即在 xAI Console 撤销并重新创建。
{% endhint %}

## 选择模型

xAI 会持续更新模型和别名。点击**添加**同步账户当前可见的列表，并以 [xAI 模型文档](https://docs.x.ai/developers/models)为准。

当前常见选择包括：

| 模型 ID | 适合场景 |
| --- | --- |
| `grok-4.5` | 复杂知识工作、代码和 Agent 任务 |
| `grok-4.3` | 通用对话、图像理解和可调推理 |
| `grok-build-0.1` | 面向 Agent 的代码任务 |

- 只启用实际需要的模型；
- 核对完整模型 ID，不要只看显示名称；
- `-latest` 别名可能自动迁移到新版本；
- 带日期的模型 ID 更适合需要固定行为的工作流；
- 模型出现在同步列表中，不代表账户具有无限额度。

## 使用联网搜索

在对话输入框打开**联网**后，Cherry Studio 会为 Grok 配置：

- xAI Web Search；
- xAI X Search；
- 搜索页面和 X 帖子中的图片理解；
- 搜索来源与引用返回。

如果在联网设置中配置排除域名，Grok 的官方搜索最多接收前 5 个有效域名规则。

使用方法：

1. 选择一个已启用的 Grok 文本模型；
2. 打开输入框中的**联网**；
3. 提出明确需要最新网页或 X 信息的问题；
4. 等待模型完成服务器端搜索；
5. 展开引用并核对来源。

{% hint style="info" %}
“模型知识较新”和“联网搜索”不是同一件事。未启用联网时，Grok 只基于模型已有知识回答；需要当前信息时，应明确打开联网并检查引用。
{% endhint %}

## 推理与工具调用

Cherry Studio 会根据模型 ID 显示相应的推理选项：

- `grok-4.3` 支持关闭、低、中、高等推理强度；
- Grok 4 Fast 的推理版和非推理版是不同模型，不能只靠开关互换；
- 其他新模型的选项取决于当前 Cherry Studio 版本和模型注册信息。

使用 MCP 或其他工具前：

1. 先完成普通对话健康检查；
2. 启用一个简单工具；
3. 使用明确需要工具的请求；
4. 确认模型实际调用工具；
5. 再增加联网或多个工具。

联网搜索是 xAI 服务器端工具，MCP 是 Cherry Studio 本地或远程工具。两者可以同时使用，但排查问题时应分别测试。

## 检查连接

1. 在 API Key 区域运行连接检查；
2. 选择一个已同步并启用的模型；
3. 确认检查成功；
4. 在模型列表运行健康检查；
5. 回到对话界面发送一条简单消息；
6. 再打开联网并测试一次带引用的查询。

连接检查成功不代表搜索工具一定可用。搜索还会受到模型能力、账户权限和工具计费状态影响。

## 连接 Grok 兼容网关

如果使用的不是 xAI 官方 API：

1. 新建[自定义服务商](zi-ding-yi-fu-wu-shang.md)；
2. 按网关文档选择 OpenAI Chat Completions 或 OpenAI Responses；
3. 填写网关提供的 Base URL 和 API Key；
4. 同步或手动添加网关实际提供的模型；
5. 分别验证推理、工具调用和联网能力。

第三方网关提供 Grok 模型，不代表它支持 xAI 官方 Web Search 或 X Search。不要直接覆盖官方 Grok 模板。

## 常见问题

### 返回 401

API Key 无效、已撤销或复制不完整。重新创建 Key，并确认没有多余空格。

### 返回 403

团队、地区、模型或工具权限不满足要求。到 xAI Console 检查账户和模型访问状态。

### 返回 404 或模型不存在

重新点击**添加**同步列表，核对完整模型 ID。旧模型可能已经迁移、重定向或停止提供。

### 返回 429

当前团队或模型达到速率限制。减少并发、稍后重试，并在 xAI Console 检查限制和用量。

### 联网后没有引用

确认输入框中的联网已打开，并提出明确需要最新信息的问题。若使用第三方网关，它可能不支持 xAI 服务器端搜索工具。

### 联网费用高于预期

xAI 可能同时计算模型 Token 和服务器端工具调用。减少不必要的联网请求，并到 xAI Console 核对实际用量。

### 推理选项与文档不一致

重新同步模型，并确认 Cherry Studio 已更新。xAI 的新模型可能早于应用内能力规则发布；此时以当前界面和实际健康检查为准。
