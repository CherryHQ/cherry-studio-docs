# 联网模式

联网模式让模型在回答前搜索网页或读取指定链接，适合查询新闻、版本更新、价格、政策等可能随时间变化的信息。

它不是“自动保证答案最新”的开关。Cherry Studio 会把搜索结果或网页正文交给模型，最终答案是否正确，仍取决于搜索来源、模型的工具调用能力和回答质量。

{% hint style="info" %}
使用联网模式后，仍应打开引用来源核对发布日期、原文上下文和关键数字。对于医疗、法律、金融等高风险信息，不要只依据模型摘要做决定。
{% endhint %}

## 两种联网方式

Cherry Studio 会根据当前模型自动选择联网方式。

| 联网方式 | 何时使用 | 搜索由谁执行 | 是否需要配置网络搜索服务商 |
| --- | --- | --- | --- |
| 模型原生联网 | 当前模型及服务商支持内置网络搜索 | 模型服务商 | 通常不需要 |
| Cherry Studio 外部联网 | 当前模型没有可用的原生联网能力 | Cherry Studio 调用已配置的搜索与网页读取服务 | 需要同时选择默认搜索服务商和默认 URL 获取服务商 |

两种方式共用聊天输入框中的联网开关，但计费、搜索覆盖范围、引用形式和可用参数可能不同。

### 模型原生联网

Cherry Studio 会把联网参数传给当前模型服务商，由服务商完成搜索和结果整理。是否可用取决于：

- 当前模型是否被识别为支持联网；
- 当前服务商是否实现了相应接口；
- 账号、地区与模型权限；
- 服务商当前的 API 规则。

部分模型会强制使用自身的联网能力。例如某些 Sonar 或 OpenRouter 联网模型，即使没有单独配置外部搜索服务商，也可能执行搜索。

### Cherry Studio 外部联网

当当前模型不使用原生联网时，Cherry Studio 会向模型提供两项工具：

- **搜索网页**：根据关键词获取候选网页；
- **读取 URL**：打开搜索结果或对话中给出的链接，提取正文。

模型自行判断何时调用工具、使用哪些关键词以及是否继续读取网页。搜索结果会整理为带编号的参考内容，供模型在回答中引用。

{% hint style="warning" %}
外部联网依赖模型的工具调用表现。即使开关已经启用，模型也可能不搜索、搜索不充分或没有正确引用来源。
{% endhint %}

## 使用前配置

如果只使用支持原生联网的模型，可以先跳到[在对话中启用联网](#在对话中启用联网)。

要让普通模型使用外部联网，请打开：

```text
设置 → 网络搜索
```

至少完成以下两项：

1. 选择**默认搜索服务商**；
2. 选择**默认 URL 获取服务商**。

这两个角色相互独立：

- 搜索服务商负责根据关键词发现网页；
- URL 获取服务商负责读取具体网页正文。

如果缺少任意一项，普通模型开启联网时会提示前往设置。

## 选择服务商

当前版本内置以下网络搜索服务商：

| 服务商 | 搜索关键词 | 读取 URL | 配置说明 |
| --- | :---: | :---: | --- |
| 智谱 | ✓ |  | 使用智谱模型服务商的 API Key |
| Tavily | ✓ |  | 需要 Tavily API Key |
| SearXNG | ✓ |  | 连接自托管或可访问的 SearXNG 实例 |
| Exa | ✓ |  | 需要 Exa API Key |
| ExaMCP | ✓ |  | 通过 Exa MCP 服务执行搜索 |
| 博查 | ✓ |  | 需要博查 API Key |
| Querit | ✓ |  | 需要 Querit API Key |
| Fetch |  | ✓ | Cherry Studio 内置的 URL 获取服务 |
| Jina | ✓ | ✓ | 可同时用于搜索和网页读取 |

服务商的套餐、额度和地区可用性可能变化，请以各服务商官网为准。需要快速开始时，可继续阅读[免费联网模式](free-search.md)。

### 配置 API 服务商

1. 在**设置 → 网络搜索**中打开目标服务商；
2. 填写 API Key；
3. 如使用代理、私有部署或兼容网关，按需修改 API 地址；
4. 点击**检测**；
5. 验证成功后，将其设为对应的默认服务商。

部分服务商支持填写多条 API Key。运行时可以轮换使用，但每条 Key 都应来自你有权使用的账号，不要把密钥写入提示词、截图或公开文档。

### 配置 SearXNG

SearXNG 需要一个 Cherry Studio 所在电脑能够访问的实例地址。默认地址是：

```text
http://localhost:8080
```

如果 SearXNG 运行在另一台电脑、NAS、Docker 容器或公网服务器上，应填写实际可访问的地址。实例启用 Basic Auth 时，还需要填写用户名和密码。

详细步骤参见 [SearXNG 配置](searxng.md)。

### 智谱 API Key

智谱网络搜索使用智谱模型服务商中保存的 API Key。先在**设置 → 模型服务**完成智谱配置，再回到**设置 → 网络搜索**选择智谱并检测。

## 设置搜索结果

### 搜索结果个数

**搜索结果个数**可设置为 `1–100`，默认值为 `5`。

结果越多，覆盖面通常越广，但也会：

- 增加响应时间；
- 占用更多上下文；
- 消耗更多 Token；
- 引入更多重复或低相关来源。

日常问答可从默认值开始。只有在需要比较多个来源时，再逐步增加。

### 搜索结果压缩

可选择：

| 压缩方法 | 行为 | 适用场景 |
| --- | --- | --- |
| 不压缩 | 保留服务商返回的正文 | 结果较少、需要更多原文上下文 |
| 截断 | 按设定上限缩短各条结果的正文 | 结果较多、希望控制上下文消耗 |

启用**截断**后，需要填写截断长度。长度过小可能丢失关键上下文；长度过大则无法有效控制 Token。建议先保留默认值，再根据回答是否遗漏信息调整。

### 黑名单

黑名单会在外部搜索结果进入模型前排除匹配的域名。适合屏蔽内容农场、镜像站或不希望使用的网站。

规则格式与订阅配置参见[网络搜索黑名单](blacklist.md)。

{% hint style="info" %}
模型原生联网由模型服务商执行，黑名单是否生效以及支持多少条排除规则，取决于对应服务商的实现，不能假定与外部联网完全一致。
{% endhint %}

## 在对话中启用联网

1. 打开一个对话；
2. 选择准备使用的模型；
3. 点击输入框下方的**地球**图标；
4. 图标高亮后发送问题。

联网状态保存在当前助手中。切换模型后，Cherry Studio 会根据新模型重新判断使用原生联网还是外部联网。

适合联网的问题示例：

```text
查找 Cherry Studio 最近一个正式版本的更新内容，并引用官方发布页。
```

```text
比较这三个产品当前的官方定价，只使用各自官网作为来源。
```

```text
阅读这个链接，总结主要结论，并指出文章的发布日期和作者。
```

为了得到更可靠的结果，建议在问题中说明：

- 时间范围；
- 希望优先使用的来源；
- 是否排除论坛或聚合站；
- 是否需要逐条引用；
- 需要核对的字段，例如版本号、价格或发布日期。

## 查看和核对引用

外部联网会把搜索结果整理为编号参考资料，并提示模型使用 `[1]`、`[2]` 等形式引用。模型原生联网的引用样式则由对应服务商决定。

得到回答后至少检查：

1. 引用能否打开；
2. 页面标题与回答主题是否一致；
3. 原文是否真的支持对应结论；
4. 发布日期是否满足问题的时间范围；
5. 不同来源之间是否存在冲突。

搜索结果为空不代表网上没有相关内容，也可能是关键词、服务额度、网络、黑名单或网页反爬策略导致。

## 已知兼容限制

### 较早的 Gemini 模型与 MCP

较早的 Gemini 模型在函数工具模式下，不能同时使用模型内置联网和启用中的 MCP。发生冲突时，Cherry Studio 会关闭联网并显示提示。

可以尝试：

- 暂时停用 MCP；
- 切换到支持该组合的新模型；
- 改用其他支持联网的模型。

### GPT-5 系列的 minimal 思考强度

GPT-5 系列推理模型使用 `minimal` 思考强度时，不能启用 OpenAI 网络搜索。Cherry Studio 会关闭联网并显示提示。

将思考强度调高后重试，或选择其他联网方式。

## 隐私与费用

启用联网后，搜索关键词、要读取的 URL 以及必要的对话上下文可能发送给模型服务商、搜索服务商或网页服务器。

使用前请确认：

- 不在搜索词中包含密码、API Key、个人身份信息或内部机密；
- 目标服务符合所在组织的数据合规要求；
- 搜索、模型调用和网络流量的费用规则；
- 网页内容可能包含错误信息或针对模型的恶意指令。

{% hint style="danger" %}
网页内容属于不可信输入。不要因为网页或模型回答要求，就粘贴密钥、运行未知命令、下载可疑文件或更改安全设置。
{% endhint %}

## 常见问题

### 点击联网图标后跳转到设置

当前模型没有使用原生联网，并且**默认搜索服务商**或**默认 URL 获取服务商**尚未选择。补齐两项后重试。

### 服务商检测失败

依次检查：

1. API Key 是否完整、有效且有可用额度；
2. API 地址是否为接口地址，而不是网页控制台；
3. 代理、防火墙和 DNS 是否允许访问；
4. 自托管服务是否已启动并监听正确地址；
5. 系统时间是否准确；
6. 服务商状态页是否报告故障。

### 已开启联网，但回答没有引用

可能原因包括：

- 模型没有调用搜索工具；
- 模型原生联网没有返回可展示的引用；
- 搜索结果为空或相关性不足；
- 模型没有遵循引用指令；
- 当前问题不需要联网，模型直接作答。

可以明确要求“必须搜索并逐条引用来源”，或更换工具调用能力更稳定的模型。

### 搜索结果太长或回答变慢

降低**搜索结果个数**，或启用**截断**并逐步减小截断长度。不要一次把结果数和截断长度都调到很高。
