# 免费联网模式

如果不想额外申请搜索服务的 API Key，可以在 Cherry Studio V2 中使用：

```text
默认搜索服务商：ExaMCP
默认 URL 获取服务商：Fetch
```

这套组合在当前版本中不要求填写额外的搜索 API Key：

- ExaMCP 负责根据关键词查找网页；
- Fetch 负责直接读取搜索结果或指定 URL 的正文；
- 普通模型通过工具调用使用这两项能力。

{% hint style="warning" %}
这里的“免费”是指 Cherry Studio 当前无需你额外配置搜索 API Key，不代表所有相关服务永久免费。模型调用仍可能计费，ExaMCP 的开放策略、额度和可用性也可能变化。
{% endhint %}

## 适用场景

适合：

- 初次体验联网模式；
- 偶尔查询最新资料；
- 不想注册多个搜索平台账号；
- 暂时没有 Tavily、Exa、博查等服务的 API Key；
- 希望先验证模型的工具调用效果。

如果需要稳定的大量调用、固定服务等级、企业合规或完全自主管理，建议改用有正式账号的搜索 API，或部署自己的 SearXNG。

## 工作方式

一次典型的外部联网过程如下：

1. 模型判断问题需要搜索；
2. 模型调用 ExaMCP，提交搜索关键词；
3. ExaMCP 返回候选网页；
4. 模型按需调用 Fetch 读取具体 URL；
5. Cherry Studio 提取网页主要正文；
6. 模型根据返回内容组织答案和引用。

ExaMCP 与 Fetch 分工不同，不能互相替代：

| 服务商 | 能力 | 能否单独完成普通模型的完整联网配置 |
| --- | --- | --- |
| ExaMCP | 搜索关键词 | 不能，还缺少默认 URL 获取服务商 |
| Fetch | 读取 URL | 不能，还缺少默认搜索服务商 |
| ExaMCP + Fetch | 搜索并读取网页 | 可以 |

{% hint style="info" %}
如果当前模型使用自身的原生联网能力，Cherry Studio 不会改用这套外部组合。原生联网由模型服务商执行，费用和引用形式以模型服务商为准。
{% endhint %}

## 配置 ExaMCP 与 Fetch

### 1. 打开网络搜索设置

进入：

```text
设置 → 网络搜索
```

页面顶部有两个独立选项：

- **默认搜索服务商**；
- **默认 URL 获取服务商**。

### 2. 选择 ExaMCP

在**默认搜索服务商**中选择：

```text
ExaMCP
```

也可以打开 ExaMCP 详情页，点击**设为默认**。

当前默认地址是：

```text
https://mcp.exa.ai/mcp
```

通常无需修改，也无需填写 API Key。点击**检测**，确认当前网络能够访问该服务。

{% hint style="warning" %}
不要随意把 API 地址替换为来源不明的 MCP 地址。搜索词会发送到该地址，恶意服务还可能返回误导性内容。
{% endhint %}

### 3. 选择 Fetch

在**默认 URL 获取服务商**中选择：

```text
Fetch
```

Fetch 是 Cherry Studio 内置的网页读取方式，不需要 API Key，也没有需要填写的远程提取服务地址。

### 4. 确认两个默认项

最终应同时显示：

| 设置项 | 选择 |
| --- | --- |
| 默认搜索服务商 | ExaMCP |
| 默认 URL 获取服务商 | Fetch |

如果只配置其中一项，普通模型点击联网图标时仍会提示前往设置。

## 在对话中使用

1. 返回对话页面；
2. 选择一个工具调用表现稳定的聊天模型；
3. 点击输入框下方的**地球**图标；
4. 发送一个需要实时信息的问题。

首次测试可使用：

```text
搜索 Cherry Studio 最近一个正式版本，只引用官方 GitHub Release，
列出版本号、发布日期和三个主要变化。
```

回答后检查：

- 是否真的执行了搜索；
- 是否出现可打开的引用；
- 引用是否来自要求的来源；
- 版本号和发布日期是否与原文一致。

## Fetch 能读取什么

Fetch 会从 Cherry Studio 所在电脑直接请求目标 URL，再从返回的 HTML 中提取主要正文并转换为适合模型读取的文本。

通常适合：

- 新闻与博客正文；
- 产品文档；
- 静态网页；
- 无需登录的公开页面；
- 搜索结果中的文章链接。

以下页面可能失败或内容不完整：

- 必须登录后才能查看的页面；
- 主要内容依赖浏览器脚本加载的页面；
- 带验证码或强反爬策略的网站；
- 仅允许特定地区或网络访问的页面；
- PDF、音视频或非 HTML 文件；
- 已失效、重定向异常或证书错误的链接。

Fetch 单次读取有超时限制。目标网站响应太慢时，模型可能拿不到正文。

## “无需额外 Key”不等于“没有成本”

仍可能产生：

- 模型输入与输出 Token 费用；
- 搜索结果占用的上下文；
- 本机或服务器网络流量；
- 自建 SearXNG 的设备、域名或运维费用；
- 第三方服务未来调整后的调用费用。

搜索结果越多、网页正文越长，模型上下文消耗通常越高。可以在**设置 → 网络搜索**中降低**搜索结果个数**，或启用**截断**。

## 隐私说明

使用 ExaMCP + Fetch 时：

- 搜索关键词会发送给 ExaMCP 服务；
- Fetch 会从本机直接访问目标网站；
- 目标网站通常能够看到请求来源的网络地址；
- 搜索结果和网页正文会作为上下文发送给当前模型服务商。

不要在搜索词或 URL 中包含：

- API Key、密码或验证码；
- 私有系统中带访问令牌的链接；
- 客户资料或个人身份信息；
- 公司内部机密。

{% hint style="danger" %}
网页内容是不可信输入。不要执行网页或模型回答中来源不明的命令，也不要按其要求关闭安全软件、上传密钥或下载可疑文件。
{% endhint %}

## 其他低成本方案

### 使用模型原生联网

如果已经在使用支持原生联网的模型，通常无需另外配置搜索 API Key。但模型联网可能包含在模型计费中，不能因此视为免费。

### 自建 SearXNG + Fetch

希望自行控制搜索入口时，可以使用：

```text
默认搜索服务商：SearXNG
默认 URL 获取服务商：Fetch
```

SearXNG 本身不要求 Cherry Studio 填写搜索 API Key，但你需要有一个可访问的实例。自建实例需要自行承担部署、更新、安全和上游搜索引擎限制。

详细配置参见 [SearXNG 配置](searxng.md)。

### 使用服务商赠送额度

部分搜索 API 可能为新账号提供试用或免费额度，但规则会变化。注册前应查看服务商当前的官方定价、地区限制和隐私政策，不要依据旧教程中的额度数字做长期规划。

## 常见问题

### ExaMCP 检测失败

依次检查：

1. 当前网络能否访问 `https://mcp.exa.ai/mcp`；
2. 代理是否已正确配置并允许 Cherry Studio 使用；
3. DNS、防火墙或安全软件是否拦截；
4. ExaMCP 服务是否暂时不可用；
5. API 地址是否被误改。

恢复默认地址后重新检测。仍然失败时，可换用其他搜索服务商或自建 SearXNG。

### Fetch 读取失败

先在普通浏览器中打开同一 URL。如果浏览器也无法访问，应先解决网络、登录、地区或证书问题。

浏览器能打开但 Fetch 失败，常见原因是：

- 页面依赖 JavaScript；
- 网站要求 Cookie、登录态或验证码；
- 网站阻止自动请求；
- 返回的不是可提取正文的 HTML；
- 响应时间超过限制。

可以换一个来源，或把网页中需要分析的正文手动复制到对话。

### 已配置两项，但模型没有搜索

联网开关只提供工具，模型仍需决定是否调用。可以：

- 确认地球图标已高亮；
- 明确要求“先联网搜索，再回答并引用来源”；
- 换用工具调用能力更稳定的模型；
- 将问题写得更具体，给出时间范围和优先来源；
- 新建对话后重试。

### 有搜索结果，但没有网页正文

ExaMCP 可能已经返回候选链接，但 Fetch 无法读取某些页面。尝试降低结果数量、换一个来源，或直接给模型一个可以公开访问的具体 URL。
