# 研究复盘工作流

目标：把内部资料、公开信息和分析过程整理成一份可以追溯的复盘报告，并保留关键产物。

## 需要的能力

* Agent：推进研究并汇总结论；
* 工作目录：保存原始材料和报告；
* 知识库：检索团队内部资料；
* 技能：固定研究框架与引用要求；
* 网页搜索或可信 MCP：取得外部信息；
* 子智能体：并行处理不同角度；
* 多窗口：同时查看任务状态和资料对话。

## 搭建步骤

{% stepper %}
{% step %}
### 1. 创建“研究复盘”Agent

主模型选择已经验证能使用工具的模型，权限保持【逐次确认】，绑定相关知识库和研究技能。
{% endstep %}

{% step %}
### 2. 准备工作目录

放入原始数据、背景说明和输出模板。明确要求保留原始文件，只在 `report/` 下创建产物。
{% endstep %}

{% step %}
### 3. 分配研究任务

让 Agent 用子智能体分别处理事实时间线、数据变化和外部观点，再由主 Agent 交叉检查冲突。
{% endstep %}

{% step %}
### 4. 生成报告与配图

要求报告包含结论、支持材料、不确定项和后续行动。需要封面图时，先配置绘画模型，再让 Agent 生成不含文字的配图。
{% endstep %}

{% step %}
### 5. 人工复核

在右侧【文件】检查引用、日期和数字，修改文字后再导出或分享。调用链只用于排查工具错误，不替代事实核验。
{% endstep %}
{% endstepper %}

## 示例任务

```
复盘本目录中的项目资料，并补充公开信息。把事实、判断和建议分开写；每项外部信息保留来源链接。使用子任务分别检查时间线、数据和风险，最后在 report/review.md 生成报告。不要修改 raw/ 中的文件。
```

## 完成标准

* 报告中的重要事实能回到原文件或来源链接；
* 事实与推测分开；
* 冲突信息没有被强行合并；
* 工作目录只新增约定产物；
* 失败的子任务和缺失信息明确列出。

{% hint style="danger" %}
金融、医疗、法律等高风险主题不能只依赖 Agent 结论。报告应保留来源，并由具备相应资质的人复核。
{% endhint %}
