# Agent 实战

下面的案例不绑定某个模型或服务商，重点是怎样把 Agent、技能、知识库、MCP、频道、定时任务和多窗口组合成稳定流程。

## 选择案例

<table data-view="cards"><thead><tr><th></th><th></th></tr></thead><tbody><tr><td>研究复盘工作流</td><td>内部资料、外部搜索、子智能体和报告产物</td></tr><tr><td>自动日报工作流</td><td>Agent、频道、定时任务和运行记录</td></tr></tbody></table>

## 通用搭建顺序

{% stepper %}
{% step %}
### 1. 先定义交付物

用文件、表格、消息或图片描述最终结果，不先从“要开哪些工具”出发。
{% endstep %}

{% step %}
### 2. 在【工作】中手动跑通

验证模型、提示词、工作目录和资料是否足够。需要批准的操作逐项检查。
{% endstep %}

{% step %}
### 3. 把稳定方法做成技能

只有重复出现的步骤、格式和检查项才进入技能；临时信息留在任务提示词。
{% endstep %}

{% step %}
### 4. 再增加外部能力

私有资料绑定知识库，外部工具连接 MCP，需要外部消息时配置频道。
{% endstep %}

{% step %}
### 5. 最后自动运行

完成一次人工验收后再建立定时任务。为失败准备运行记录、通知和人工处理入口。
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
案例中的配置是起点，不是通用最佳值。数据敏感度、服务商费用、权限要求和团队流程不同，自动化前应重新检查。
{% endhint %}
