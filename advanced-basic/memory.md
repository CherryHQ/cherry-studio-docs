# 记忆能力

Cherry Studio 的持久记忆主要分为两类：**工作中的 Agent 内置记忆**和 **MCP 记忆服务器**。

{% hint style="warning" %}
普通对话助手没有统一的“全局记忆”开关。需要跨任务保存信息时，请按场景选择 Agent 内置记忆或 MCP 记忆服务器。
{% endhint %}

## Agent 内置记忆

Agent 提供内置的 **记忆（AgentMemory）** 工具，用于跨会话存储和回忆与任务有关的信息。它面向 `工作` 中的 Agent，而不是普通对话助手的全局开关。

使用建议：

1. 打开顶部 `工作`，进入目标 Agent。
2. 在 Agent 的工具或权限配置中确认 **记忆** 可用。
3. 明确告诉 Agent 哪些内容需要长期记住。
4. 对敏感信息保持谨慎，不要让 Agent 保存密码、API Key 或一次性验证码。

Agent 信息面板可能显示 **记忆文件**，用于查看本次任务加载了哪些持久上下文。

## MCP 记忆服务器

如果希望普通助手或其他支持 MCP 的场景使用持久记忆，可以打开：

`设置 → MCP → 内置服务器 → memory`

内置的 `memory` 服务器使用本地知识图谱保存信息，需要配置 `MEMORY_FILE_PATH` 环境变量。建议把它指向一个明确、可备份且访问权限受控的文件路径。

也可以选择 `Nowledge Mem` 等第三方记忆 MCP，但需要按其说明安装本地应用或完成授权。

## 两种方式怎么选

| 需求 | 推荐方式 |
|---|---|
| 让 Agent 在多个任务间记住工作信息 | Agent 内置记忆 |
| 让普通助手通过工具读写持久记忆 | MCP `memory` |
| 使用第三方本地知识与记忆产品 | 对应的 MCP 服务器 |
| 仅希望保留当前对话上下文 | 继续使用同一话题，无需额外配置 |

## 隐私与维护

* 不要写入 API 密钥、密码、身份证号等高敏感信息；
* 定期检查记忆内容，删除过时或错误事实；
* 备份记忆文件前确认备份位置可信；
* 更换 `MEMORY_FILE_PATH` 后，旧文件不会自动迁移。
