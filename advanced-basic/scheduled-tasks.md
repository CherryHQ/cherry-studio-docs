# 定时任务

定时任务让 [智能体](agent.md) 在指定时间自动执行提示词，适合生成日报、周期检查、定时提醒或把结果发送到消息频道。每次运行都会形成会话和运行记录，方便查看结果与错误。

定时任务由 Cherry Studio 本机的调度器执行，不是操作系统级后台服务。到点运行时，Cherry Studio 必须处于运行状态；应用重新打开后，会恢复仍处于活跃状态的任务。

{% hint style="warning" %}
定时任务属于无人值守操作。运行它的智能体必须启用自主模式，或使用全自动权限模式；开启自主模式时，Cherry Studio 会自动切换为全自动权限。工具调用不会逐次等待确认，请限制智能体可访问的工作目录，并避免在提示词中保存密码、API Key 或其他敏感信息。
{% endhint %}

## 创建前准备

1. 创建或选择一个[智能体](agent.md)，配置可用模型。
2. 在智能体设置中开启**自主模式**。如果只准备在设置页面手动建任务，也可以使用全自动权限模式的智能体。
3. 先在普通会话中测试同一段提示词，确认模型、工具和工作目录权限符合预期。
4. 如果需要把结果发送到 IM，先配置并连接相应的[频道](agent-channels.md)。

设置页只会把开启自主模式或全自动权限模式的智能体列为可选对象。创建和运行定时任务不需要另行开启 API 服务器。

## 用对话创建

对于启用了自主模式的智能体，可以直接描述需求，例如：

> 每个工作日上午 9 点整理最近 24 小时的项目动态，输出 5 条要点。

智能体可以通过内置的定时任务工具创建、列出或删除任务。说明中最好包含：

* 任务名称和要完成的事情；
* 执行时间、重复间隔或一次性日期；
* 是否需要把结果发送到某个频道；
* 预计耗时较长时的超时时间。

创建完成后，前往 **设置 → 定时任务** 检查调度值、提示词、接收频道和下次运行时间。

## 在设置中创建

1. 打开 **设置 → 定时任务**。
2. 点击左侧的 **+ 添加**。
3. 选择智能体并填写表单。
4. 点击 **保存**。任务会以“活跃”状态开始等待调度。

| 字段 | 作用 |
| :--- | :--- |
| 名称 | 用于任务列表和会话名称，例如“每日代码审查” |
| 提示词 | 每次运行时作为用户消息发送给智能体的完整指令 |
| 调度类型 | `Cron`、`间隔` 或 `一次性` |
| 调度值 | Cron 表达式、间隔分钟数，或一次性日期和时间 |
| 超时时间 | 单次运行允许的最长时间，单位为分钟 |
| 发送到频道 | 可选；把生成过程与最终结果发送到选定频道 |

{% hint style="info" %}
当前版本的数据层默认超时时间为 2 分钟。界面中的空白占位虽然显示“无限制”，但新任务未填写时仍会保存为 2 分钟。长任务请显式填写更大的正整数。
{% endhint %}

### 选择调度类型

{% tabs %}
{% tab title="间隔" %}
填写正整数分钟数。`60` 表示每 60 分钟运行一次。间隔以计划时间为基准计算；如果应用暂时关闭，不会为了补齐所有错过的周期而连续运行多次。
{% endtab %}

{% tab title="Cron" %}
填写标准 5 字段 Cron 表达式：`分 时 日 月 星期`。

| 表达式 | 含义 |
| :--- | :--- |
| `0 9 * * *` | 每天 9:00 |
| `*/15 * * * *` | 每 15 分钟 |
| `0 9 * * 1-5` | 每个工作日 9:00 |

Cron 按设备当前时区计算。保存后，请核对页面显示的“下次运行”时间。
{% endtab %}

{% tab title="一次性" %}
在日期时间选择器中指定一次运行时间。任务执行后会标记为“已完成”，不能再编辑、运行或恢复；如需再次执行，请新建任务。
{% endtab %}
{% endtabs %}

## 发送到频道

创建或编辑任务时，可以选择一个或多个已配置频道。任务运行时，智能体的文本输出会发送到这些频道；失败时也会发送错误通知。

频道必须已经连接，并且记录了可接收通知的 Chat ID。如果页面提示“当前无可用的接收目标”，请先在对应平台向 Bot 发送一条消息，让 Cherry Studio 记录会话目标，再回来选择频道。

不选择频道时，任务仍会正常运行，结果保留在 Cherry Studio 的任务会话和运行历史中。

## 管理任务

在左侧选择任务后，可以在详情页：

* 修改名称、智能体、提示词、调度、超时时间和接收频道；
* 点击运行按钮立即触发一次，不改变后续计划；
* 暂停或恢复周期任务；
* 删除不再需要的任务。

修改调度或从暂停恢复时，Cherry Studio 会重新计算“下次运行”。同一任务已经在运行时，不会并发启动第二次。

周期任务会优先复用上一次成功运行的会话，让后续运行保留上下文；第一次运行或原会话不存在时，会创建以任务名称命名的新会话。

## 查看运行历史

详情页的**运行历史**会显示运行时间、耗时、状态以及结果或错误。可以搜索记录，也可以点击会话图标打开该次任务的完整对话。

单次任务达到超时时间会被中止并记录为错误。一个任务连续 3 次运行失败后，调度器会自动把它暂停；排除模型、网络、工具权限或提示词问题后，再手动恢复。

## 没有按时运行

依次检查：

1. Cherry Studio 在计划时间是否处于运行状态。
2. 任务状态是否为“活跃”，以及“下次运行”是否正确。
3. 智能体的模型是否可用，服务商余额和网络是否正常。
4. 智能体是否仍处于自主模式或全自动权限模式。
5. 运行历史是否出现超时、工具权限或频道投递错误。

调度器约每分钟检查一次到期任务，因此实际开始时间可能比计划时间稍晚。长期任务会持续消耗模型 Token；建议先手动运行验证输出，再启用高频调度。
