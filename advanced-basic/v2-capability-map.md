# V2 进阶能力地图

{% hint style="info" %}
这一部分不按设置菜单逐项罗列，而是从“想完成什么工作”出发。界面路径均使用简体中文名称。
{% endhint %}

Cherry Studio 的进阶能力围绕 Agent 展开。模型负责理解与推理，Agent 把模型、工作目录和工具组织成一个可以持续工作的角色；技能、MCP、知识库、频道和定时任务再分别补上方法、外部能力、资料、消息入口与运行时间。

## 先选工作方式

| 你的目标                      | 建议入口                       | 会用到的能力                       |
| ------------------------- | -------------------------- | ---------------------------- |
| 持续问答、翻译或润色                | 左侧导航【对话】                   | 助手、模型、知识库、联网搜索               |
| 处理文件或完成多步骤任务              | 左侧导航【工作】                   | Agent、工作目录、工具、技能、MCP         |
| 让 Agent 直接生成图片            | 【设置】→【默认模型】→【绘画模型】，再回到【工作】 | Agent 内置【生成图片】工具             |
| 从飞书、Telegram 等平台使用 Agent  | 先在【工作】中让 Agent 引导配置        | 频道、权限模式、通知                   |
| 自动执行日报、检查或提醒              | 先验证 Agent，再让 Agent 创建计划    | 定时任务、频道、运行记录                 |
| 同时盯住多个对话或任务               | 右键话题、任务或标签页→【从新窗口打开】       | 多窗口、标签页、窗口置顶                 |
| 管理本地编程 CLI                | 左侧导航【Code CLI】             | 工具安装、服务商配置、工作目录、终端           |
| 把 Cherry Studio 提供给其他程序调用 | 【设置】→【API 网关】              | OpenAI/Anthropic 兼容接口、API 密钥 |
| 排查模型、MCP 或 Agent 调用       | 【设置】→【系统】→【开发者模式】          | 调用链、输入输出、耗时和状态               |

图中：① 【工作】是 Agent 工作区；② 【设置】中的【MCP】负责外部工具；③ 【定时任务】负责按计划运行 Agent。

## V2 中最值得先掌握的变化

### Agent 不再只是另一种聊天窗口

一个 Agent 可以拥有主模型、Plan 模型和 Small 模型，绑定知识库、技能与 MCP，读取或编辑工作目录中的文件，并在右侧面板查看状态、文件、子任务、后台命令和消息流。配置改变后，已打开的任务会在后续消息中使用新配置。

### 图片生成已经进入 Agent 工作流

只要全局配置了绘画模型，并保持 Agent 的【生成图片】工具启用，就可以直接在 Agent 对话中描述画面。生成结果会作为图片出现在任务中，不必先跳到独立绘画页面。

### 自动化由 Agent、频道和定时任务共同完成

频道负责从外部平台收发消息，定时任务负责按计划启动 Agent。两者都绑定具体 Agent 和工作区，因此应先在【工作】中把任务跑通，再接入外部平台或定时运行。

### 同一工作可以拆到多个窗口

话题、Agent 任务和普通标签页都可以从右键菜单拆成独立窗口。独立窗口支持置顶，也能随时回到主窗口，适合一边保留资料，一边继续处理另一个任务。

## 推荐阅读顺序

{% stepper %}
{% step %}
### 1. 先完成 Agent 工作区

学会创建 Agent、选择工作目录、分配模型并理解权限。后面的绘画、自动化和外部工具都建立在这里。
{% endstep %}

{% step %}
### 2. 再增加能力

固定工作方法用技能，需要外部工具用 MCP，需要私有资料用知识库。不要一开始就把所有能力全部打开。
{% endstep %}

{% step %}
### 3. 最后接入自动化和外部系统

先手动验证结果，再配置频道、定时任务、API 网关或 Code CLI。这样出现问题时更容易定位原因。
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
工作目录、MCP、频道和完全访问权限都可能扩大 Agent 可接触的数据范围。只授予当前任务需要的目录、工具和账号，不要把 API Key 或机器人密钥贴进公开对话与截图。
{% endhint %}
