# 频道

频道可以把 Cherry Studio 中的 [Agent](agent.md) 接入即时通讯平台。成员在群聊或私聊中发送消息后，绑定的 Agent 会在 Cherry Studio 中处理请求，并把结果回复到原会话。

当前支持：

* 飞书 / Lark
* Telegram
* QQ
* 微信
* Discord
* Slack

例如，你可以让知识助手回答飞书群中的内部问题，让个人助理通过 Telegram 接收指令，或让 [定时任务](scheduled-tasks.md) 把日报主动发送到指定频道。

{% hint style="info" %}
频道由 Cherry Studio 本地运行。应用退出后，频道连接和消息处理也会停止；重新打开应用后，已启用且已绑定 Agent 的频道会自动重新连接。频道不依赖 API 服务器。
{% endhint %}

## 使用前准备

在添加频道前，请先：

1. 创建并配置一个可正常对话的 [Agent](agent.md)。
2. 为 Agent 选择可用模型，并确认服务商配置有效。
3. 准备目标平台要求的机器人凭据，或使用飞书、微信提供的扫码接入。

频道可以绑定普通 Agent，也可以绑定已开启自主模式的 Agent。手动创建频道不要求自主模式；如果希望 Agent 自行创建频道、排查连接或联动任务，建议使用已开启自主模式的 Agent，并谨慎检查它的工具权限。

## 添加频道

打开 `设置 → 频道`，选择目标平台，然后点击 **添加**。

需要配置的通用项目包括：

| 配置项 | 说明 |
|---|---|
| 名称 | 用于区分同一平台下的多个频道实例 |
| 绑定 Agent | 负责处理频道消息的 Agent；未绑定时，频道不会建立连接 |
| 平台凭据 | 不同平台需要的 App ID、Token 或 Secret |
| 允许的聊天 ID | 限制哪些会话可以使用机器人 |
| 频道权限模式 | 继承 Agent 设置，或仅为该频道指定权限模式 |
| 启用状态 | 启用后立即尝试连接；关闭后保留配置但断开连接 |

同一平台可以添加多个实例，一个 Agent 也可以绑定多个频道。例如，同一个 Agent 可以同时连接飞书群和 Telegram 私聊，但每个频道实例仍可使用不同的凭据、允许列表和权限模式。

保存后可在频道详情中查看连接状态。修改启用状态、凭据或绑定 Agent 时，Cherry Studio 会重新连接该实例。

## 按平台填写配置

{% tabs %}
{% tab title="飞书 / Lark" %}
飞书和 Lark 支持两种接入方式：

* **扫码接入**：不填写 App ID 和 App Secret，启用后扫描页面中的二维码。注册完成后，Cherry Studio 会保存获得的凭据并重新连接。
* **手动接入**：填写自建应用的 App ID 与 App Secret，并选择 `飞书` 或 `Lark` 域名。Encrypt Key 和 Verification Token 按应用配置选填。

手动创建应用时，需要在对应开放平台中启用机器人能力、消息权限和长连接事件订阅。飞书与 Lark 的应用和域名不能混用。
{% endtab %}

{% tab title="Telegram" %}
使用 Telegram 的 Bot Token。可通过 BotFather 创建机器人并取得 Token。

允许列表使用 Telegram Chat ID。机器人连接成功后，可在目标私聊或群聊中发送 `/whoami` 获取当前 Chat ID。
{% endtab %}

{% tab title="QQ" %}
填写 QQ 机器人应用的 App ID 和 Client Secret。

允许列表支持带类型的会话 ID，例如：

* `c2c:openid`：单聊
* `group:groupid`：群聊
* `channel:channelid`：频道
* `dm:guildid`：频道私信

发送 `/whoami` 可以查看当前会话的类型与 ID。
{% endtab %}

{% tab title="微信" %}
微信通过扫码登录，不需要手动填写 Token。添加实例并启用后，使用微信扫描二维码完成登录；登录凭据会保存在 Cherry Studio 的本地数据目录中。

允许列表填写微信用户 ID。可在会话中发送 `/whoami` 获取当前 ID。
{% endtab %}

{% tab title="Discord" %}
填写 Discord Bot Token，并将机器人邀请到目标服务器。

允许列表填写 Discord Channel ID；也可以在目标频道或私信中发送 `/whoami`，复制 Cherry Studio 返回的会话 ID。
{% endtab %}

{% tab title="Slack" %}
Slack 使用 Socket Mode，需要同时填写：

* Bot Token，通常以 `xoxb-` 开头
* App-Level Token，通常以 `xapp-` 开头

安装应用并授予消息权限后，将机器人加入目标频道。允许列表填写 Slack Channel ID，可发送 `/whoami` 获取。
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
机器人凭据等同于账号访问凭证。不要把 Token 或 Secret 发送到公开对话、截图或文档中；如怀疑泄露，请立即到对应平台撤销并重新生成。
{% endhint %}

## 限制可访问的会话

“允许的聊天 ID”是频道的访问控制：

* **留空**：任意能向机器人发送消息的会话都可以触发 Agent。
* **填写 ID**：只有列表中的会话可以触发 Agent，其他消息会被忽略。

允许列表留空时，Cherry Studio 会自动记录与机器人成功互动过的会话 ID。这些记录也可作为 [定时任务](scheduled-tasks.md) 的主动发送目标。

建议先在目标会话中发送 `/whoami`，复制返回的 ID，再把它加入允许列表。面向群聊或多人环境时，不建议长期留空。

## 设置频道权限

频道权限决定从该频道进入的请求可以怎样调用 Agent 工具。默认选择 **继承 Agent 设置**；也可以为当前频道覆盖为：

* **默认模式**：执行敏感操作前按默认规则确认。
* **接受编辑**：自动接受文件编辑，其他高风险操作仍受限制。
* **绕过权限**：不再请求确认，风险最高。
* **规划模式**：优先分析和制定方案，不直接执行修改。

频道权限会在每次收到消息时应用，因此修改后对已有会话也会生效。

{% hint style="danger" %}
即时通讯中的消息属于外部输入。只有在 Agent 的工作区、工具和允许列表都经过严格限制时，才考虑使用“绕过权限”。不要让公开群聊中的机器人访问敏感目录或凭据。
{% endhint %}

## 在频道中使用命令

连接成功后，可以向机器人发送：

| 命令 | 作用 |
|---|---|
| `/new` | 为当前频道切换到一个新会话 |
| `/compact` | 压缩当前会话上下文 |
| `/help` | 查看 Agent 信息和可用命令 |
| `/whoami` | 查看当前会话 ID，用于配置允许列表 |

如果同一频道需要服务不同团队或承担不同权限级别的工作，建议创建独立频道实例，分别设置 Agent、允许列表和权限，而不是共用一套高权限配置。

## 与定时任务配合

频道既可以接收消息，也可以作为 [定时任务](scheduled-tasks.md) 的发送目标：

1. 先创建并连接频道。
2. 至少在目标会话中与机器人互动一次，或直接填写允许的聊天 ID。
3. 创建定时任务并选择要推送的频道。

如果允许列表留空且目标会话从未与机器人互动，Cherry Studio 可能没有可用的主动发送目标。

## 排查连接问题

### 保存后仍显示未连接

依次检查：

1. 频道是否已启用并绑定 Agent。
2. Agent 的模型和服务商是否可正常使用。
3. Token、Secret、App ID 和平台域名是否匹配。
4. 机器人是否已安装到目标工作区、服务器或群聊，并获得消息权限。
5. 打开频道详情中的 **日志**，查看实时连接错误。

修改错误配置并保存后，Cherry Studio 会重新连接频道。也可以先关闭再重新启用该实例。

### 机器人在线但不回复

* 检查当前会话 ID 是否在允许列表中。
* 在群聊中确认机器人可读取消息；部分平台要求 @ 机器人或额外授予群消息权限。
* 确认 Cherry Studio 仍在运行。
* 检查 Agent 的模型是否可用，以及频道权限是否阻止了所需工具。

### 扫码后没有完成连接

* 确认二维码未过期；过期后重新发起扫码。
* 飞书 / Lark 要使用与所选域名一致的客户端账号。
* 微信登录失效时，重新扫码会更新本地登录凭据。

{% hint style="warning" %}
各平台对机器人、消息保存和自动化行为有不同的服务条款与组织管理要求。将机器人加入企业群或对外服务前，请确认已获得相应授权。
{% endhint %}
