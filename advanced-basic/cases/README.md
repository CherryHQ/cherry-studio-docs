## 通用搭建顺序

{% stepper %}
{% step %}
### 1. 先定义交付物

说明最后要得到哪个文件、表格、图片或消息，以及怎样算完成。
{% endstep %}

{% step %}
### 2. 在【工作】中手动跑通

验证模型、提示词、工作目录和资料是否足够。需要批准的操作逐项检查。
{% endstep %}

{% step %}
### 3. 只沉淀稳定部分

重复步骤做成技能，长期资料放知识库，临时要求留在任务提示词。
{% endstep %}

{% step %}
### 4. 最后增加外部连接和自动化

完成一次人工验收后，再接 MCP、频道或定时任务，并保留失败时的人工处理入口。
{% endstep %}
{% endstepper %}
