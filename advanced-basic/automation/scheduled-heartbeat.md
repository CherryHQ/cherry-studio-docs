# 定时任务、心跳与运行记录



<details>

<summary>任务运行了但频道没有收到消息怎么办？</summary>

先看【运行历史】确认 Agent 是否成功。如果任务成功，再检查频道接收目标；如果任务失败，点击【查看会话】检查模型、权限、工作区和工具错误。

</details>
