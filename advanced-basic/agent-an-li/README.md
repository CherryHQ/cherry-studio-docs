# Agent 案例

这里收录基于 Cherry Studio V2 **工作**模块制作的完整案例。案例重点展示任务拆解、工具选择、提示词设计和结果复核，不代表唯一实现方式。

## 开始之前

1. 在 **设置 → 模型服务** 中准备支持工具调用的模型。
2. 从顶部导航进入 **工作**。
3. 新建或导入 Agent，并只授予任务确实需要的工具。
4. 涉及联网、文件写入或外部服务时，先检查数据与权限边界。
