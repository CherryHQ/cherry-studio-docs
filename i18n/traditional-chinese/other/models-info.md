# 模型資料

Cherry Studio V2 不再依賴文件中的靜態大型模型表格。模型版本、上下文、價格與服務商能力變化很快，長期手動維護會讓過期資訊看起來像確定的事實。

本頁改為說明應用程式中的模型資料來源、各欄位的意義，以及如何判斷目前服務商上的模型是否確實可用。

{% hint style="info" %}
應用程式顯示的模型資訊用於設定與路由。模型服務商的官方文件、控制台權限與實際 API 回應，才是可用性、限制與計費的最終依據。
{% endhint %}

## 模型資料來自哪裡

V2 會合併多類資料，形成最終顯示的模型：

1. **模型目錄**：提供通用名稱、能力、輸入輸出類型、上下文、參數與價格等基礎資料。
2. **服務商覆寫資訊**：描述特定服務商上的端點、特殊限制、別名或替代模型。
3. **服務商模型清單**：部分服務商可透過 API 回傳目前帳戶可見的 Model ID。
4. **使用者設定**：手動新增的模型、名稱、能力標籤、端點與限制等自訂資訊。

合併優先順序以使用者設定最高，其次是服務商覆寫資訊，最後是通用模型目錄。

當服務商 API 只回傳 Model ID 時，Cherry Studio 會嘗試使用目錄補齊資料；目錄中找不到的 ID 仍可作為自訂模型加入，但欄位可能不完整。

## 在哪裡查看

開啟**設定 → 模型服務**並選擇一個服務商。模型清單可以：

* 搜尋模型名稱或 ID。
* 依能力篩選。
* 啟用或停用單一模型。
* 批次啟用目前篩選結果。
* 開啟模型編輯面板，查看或修改部分欄位。
* 手動新增服務商未自動列出的模型。

只有已啟用的模型會出現在大多數模型選擇器中。停用模型不會刪除其設定。

模型服務商的完整設定流程請參閱[模型服務](../pre-basic/providers/)。

## 常見欄位

### 顯示名稱與 Model ID

| 欄位 | 作用 |
| :--- | :--- |
| 顯示名稱 | Cherry Studio 介面中顯示的名稱，可以與 API ID 不同 |
| Model ID | 請求服務商 API 時使用的真實模型識別碼 |
| 服務商 | 負責驗證、端點與請求路由的設定 |
| 分組 | 只用於整理模型清單，不會改變 API 行為 |

同一個 Model ID 可以存在於多個服務商下。應用程式內部會將服務商與 Model ID 組合成唯一識別碼，但手動新增模型時通常應填寫服務商文件提供的 API Model ID，不要自行加入應用程式內部前綴。

### 端點類型

端點類型決定請求格式。V2 支援的模型端點包括：

* OpenAI Chat Completions
* OpenAI Responses
* Anthropic Messages
* Google Generate Content
* OpenAI Image Generation
* Jina Rerank

模型名稱相同，不代表每個服務商都支援相同端點。端點選擇錯誤時，常見表現為 `400`、`404`、工具參數無效或回傳結構無法解析。

### 上下文與輸出限制

| 欄位 | 意義 |
| :--- | :--- |
| 上下文視窗 | 單次請求可以處理的整體 Token 規模 |
| 最大輸入 | 服務商允許的輸入 Token 上限 |
| 最大輸出 | 單次產生允許的輸出 Token 上限 |

這些值不是簡單的相加規則。服務商還可能對圖片、工具定義、快取、推理 Token 或特定方案設定個別限制。

不要將文件中的 `k` 或 `M` 縮寫直接視為精確可用值。需要設定數值時，請使用服務商目前 API 文件提供的整數，並透過最小請求驗證。

### 輸入與輸出類型

模型可以分別聲明支援的輸入與輸出：

* 文字
* 圖片
* 音訊
* 影片

「可以理解圖片」與「可以產生圖片」是兩種能力；支援音訊輸入也不代表可以產生語音。

### 能力標籤

模型清單可能顯示下列能力：

| 能力 | 說明 |
| :--- | :--- |
| 視覺理解 | 接收圖片並產生文字結果 |
| 圖片產生 | 產生或編輯圖片 |
| 音訊理解 | 接收或辨識音訊 |
| 音訊產生 | 產生音訊或語音 |
| 影片理解 | 接收並理解影片 |
| 影片產生 | 產生影片 |
| 推理 | 支援推理強度或思考相關設定 |
| 工具呼叫 | 產生結構化函式或工具呼叫 |
| 原生連網 | 由模型或服務商端點提供搜尋能力 |
| Embedding | 產生向量，用於知識庫索引與檢索 |
| Rerank | 對候選文字重新排序 |

能力標籤會影響模型篩選、介面控制項與請求路由。手動勾選標籤只會告訴 Cherry Studio 如何使用模型，**不會為服務商模型增加實際能力**。

### 參數支援

不同模型可能支援不同參數，例如：

* Temperature
* Top P
* Top K
* Frequency Penalty
* Presence Penalty
* Max Tokens
* Stop Sequences
* System Message

推理模型可能忽略或拒絕部分傳統取樣參數。遇到 `unsupported parameter` 時，請先恢復預設設定，再依該模型目前的官方文件逐項啟用。

### 推理設定

推理模型還可能包含：

* 推理類型。
* 可用的推理強度。
* 思考 Token 最小值、最大值與預設值。
* 是否支援交錯思考。

實際可用值同時受到模型、端點與服務商實作影響。同一個模型透過 OpenAI 相容端點與 Anthropic Messages 端點呼叫時，參數格式可能不同。

### 價格

目錄可以儲存輸入、輸出、快取、圖片或音訊影片的價格，但這些資訊只適合估算：

* 服務商可能隨時調整價格。
* 不同地區、方案與管道可能不同。
* 推理、快取、批次處理與工具呼叫可能個別計費。
* 第三方中繼服務可能採用自己的計價方式。

付款與成本核對應以服務商帳單為準。

## 為何同名模型顯示不同資訊

常見原因包括：

* 服務商對應到不同快照或別名。
* 端點類型不同。
* 目前帳戶只開通部分能力。
* 服務商限制了上下文或輸出長度。
* 聚合服務使用自己的 Model ID 與價格。
* 本機模型的量化、範本或執行參數不同。
* 使用者曾手動修改能力或限制欄位。

比較模型時，應同時記錄**服務商、Model ID、端點與日期**，不能只比較顯示名稱。

## 自動取得模型清單的邊界

「成功取得模型清單」只代表服務商回傳了一組模型 ID，不代表：

* 目前 API Key 一定具有呼叫權限。
* 模型支援圖片、工具、推理或連網。
* 上下文與價格資訊完整。
* 該模型適用於所有端點。
* 服務商日後不會下架或重新命名。

取得清單後，應啟用需要的模型並執行一次實際請求。

## 如何驗證模型

### 1. 基礎連線

在服務商設定中檢查 API Host 與憑證，再執行連線檢查。連線檢查通過後，使用一則短文字完成實際對話。

### 2. 只測試需要的能力

| 目標能力 | 最小測試 |
| :--- | :--- |
| 視覺理解 | 上傳一張不含敏感資訊的圖片，要求描述一個明確元素 |
| 工具呼叫 | 繫結一個沒有副作用的工具，要求讀取固定資訊 |
| 推理 | 使用可人工核對的多步驟問題，並觀察參數是否被接受 |
| 原生連網 | 詢問一項剛更新且可查證的資訊，檢查實際搜尋記錄與引用 |
| Embedding | 取得維度，並以小型範例文件完成一次召回測試 |
| Rerank | 對一組固定候選文字排序，檢查結果是否符合問題 |
| 圖片產生 | 使用簡單提示產生測試圖片，檢查回傳格式與尺寸 |

### 3. 記錄測試環境

至少記錄：

* Cherry Studio 版本。
* 服務商。
* Model ID。
* 端點類型。
* 測試日期。
* 成功的能力與參數。

如此在服務商升級模型後，可以區分「模型行為變化」與「本機設定變化」。

## 手動修改模型資料

目錄資訊缺失或服務商使用自訂 ID 時，可以編輯模型。

修改前建議：

1. 先儲存目前 Model ID、端點與能力。
2. 每次只修改一個欄位。
3. 立即執行對應的最小測試。
4. 失敗時恢復原值。

{% hint style="warning" %}
不要為了讓模型出現在特定篩選器中而盲目勾選能力。錯誤的 Embedding、Rerank、圖片產生或工具呼叫標籤，可能將請求傳送到不相容的介面。
{% endhint %}

## 常見問題

### 服務商控制台有模型，但 Cherry Studio 未顯示

請先嘗試取得模型清單；如果仍未出現，請依服務商提供的準確 Model ID 手動新增。檢查該模型是否需要專用端點、區域或 API 版本。

### 清單中有模型，但請求回傳 404

常見原因是 API Host、Model ID、區域或端點不相符。不要只根據清單名稱修改大小寫或刪除版本後綴。

### 模型標籤與實際能力不符

請先以服務商官方文件與實際請求為準，再編輯能力標籤。如果是公共目錄錯誤，可以依[意見與建議](../question-contact/suggestions.md)提供服務商、Model ID、官方文件連結與測試結果。

### 上下文未達標示值

檢查最大輸出、圖片、檔案、工具定義與歷史訊息占用。聚合服務也可能採用低於模型廠商的上限。

### 價格與帳單不同

目錄價格可能已過期，或不適用於目前管道。請停止使用該值進行財務結算，並改查目前服務商的價格頁面與帳單明細。
