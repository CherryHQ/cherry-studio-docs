# 聯網模式

聯網模式讓模型在回答前搜尋網頁或讀取指定連結，適合查詢新聞、版本更新、價格、政策等可能隨時間變化的資訊。

它不是「自動保證答案最新」的開關。Cherry Studio 會將搜尋結果或網頁正文交給模型，最終答案是否正確，仍取決於搜尋來源、模型的工具呼叫能力和回答品質。

{% hint style="info" %}
使用聯網模式後，仍應開啟引用來源，核對發布日期、原文脈絡和關鍵數字。對於醫療、法律、金融等高風險資訊，不要只依據模型摘要做決定。
{% endhint %}

## 兩種聯網方式

Cherry Studio 會依目前模型自動選擇聯網方式。

| 聯網方式 | 使用時機 | 由誰執行搜尋 | 是否需要設定網路搜尋供應商 |
| --- | --- | --- | --- |
| 模型原生聯網 | 目前模型及供應商支援內建網路搜尋 | 模型供應商 | 通常不需要 |
| Cherry Studio 外部聯網 | 目前模型沒有可用的原生聯網能力 | Cherry Studio 呼叫已設定的搜尋與網頁讀取服務 | 需要同時選擇預設搜尋供應商和預設 URL 取得供應商 |

兩種方式共用聊天輸入框中的聯網開關，但計費、搜尋涵蓋範圍、引用形式和可用參數可能不同。

### 模型原生聯網

Cherry Studio 會將聯網參數傳給目前模型供應商，由供應商完成搜尋和結果整理。是否可用取決於：

- 目前模型是否被識別為支援聯網；
- 目前供應商是否實作了相應介面；
- 帳號、地區與模型權限；
- 供應商目前的 API 規則。

部分模型會強制使用自身的聯網能力。例如某些 Sonar 或 OpenRouter 聯網模型，即使沒有另外設定外部搜尋供應商，也可能執行搜尋。

### Cherry Studio 外部聯網

當目前模型不使用原生聯網時，Cherry Studio 會向模型提供兩項工具：

- **搜尋網頁**：依關鍵字取得候選網頁；
- **讀取 URL**：開啟搜尋結果或對話中提供的連結，擷取正文。

模型自行判斷何時呼叫工具、使用哪些關鍵字，以及是否繼續讀取網頁。搜尋結果會整理為帶編號的參考內容，供模型在回答中引用。

{% hint style="warning" %}
外部聯網依賴模型的工具呼叫表現。即使開關已啟用，模型也可能不搜尋、搜尋不充分，或未正確引用來源。
{% endhint %}

## 使用前設定

如果只使用支援原生聯網的模型，可以先跳到[在對話中啟用聯網](#在對話中啟用聯網)。

若要讓一般模型使用外部聯網，請開啟：

```text
設定 → 網路搜尋
```

至少完成以下兩項：

1. 選擇**預設搜尋供應商**；
2. 選擇**預設 URL 取得供應商**。

這兩個角色彼此獨立：

- 搜尋供應商負責依關鍵字尋找網頁；
- URL 取得供應商負責讀取特定網頁的正文。

如果缺少任一項，一般模型開啟聯網時會提示前往設定。

## 選擇供應商

目前版本內建以下網路搜尋供應商：

| 供應商 | 搜尋關鍵字 | 讀取 URL | 設定說明 |
| --- | :---: | :---: | --- |
| 智譜 | ✓ |  | 使用智譜模型供應商的 API Key |
| Tavily | ✓ |  | 需要 Tavily API Key |
| SearXNG | ✓ |  | 連線至自架或可存取的 SearXNG 執行個體 |
| Exa | ✓ |  | 需要 Exa API Key |
| ExaMCP | ✓ |  | 透過 Exa MCP 服務執行搜尋 |
| 博查 | ✓ |  | 需要博查 API Key |
| Querit | ✓ |  | 需要 Querit API Key |
| Fetch |  | ✓ | Cherry Studio 內建的 URL 取得服務 |
| Jina | ✓ | ✓ | 可同時用於搜尋和網頁讀取 |

供應商的方案、額度和地區可用性可能變更，請以各供應商官網為準。若要快速開始，可繼續閱讀[免費聯網模式](mian-fei-lian-wang-mo-shi.md)。

### 設定 API 供應商

1. 在**設定 → 網路搜尋**中開啟目標供應商；
2. 填寫 API Key；
3. 如使用代理、私人部署或相容閘道，依需要修改 API 位址；
4. 點選**檢查**；
5. 驗證成功後，將其設為對應的預設供應商。

部分供應商支援填寫多組 API Key。執行時可以輪替使用，但每組 Key 都應來自您有權使用的帳號；不要將密鑰寫入提示詞、螢幕截圖或公開文件。

### 設定 SearXNG

SearXNG 需要一個 Cherry Studio 所在電腦能夠存取的執行個體位址。預設位址是：

```text
http://localhost:8080
```

如果 SearXNG 執行於另一台電腦、NAS、Docker 容器或公網伺服器上，應填寫實際可存取的位址。執行個體啟用 Basic Auth 時，還需要填寫使用者名稱和密碼。

詳細步驟請參閱 [SearXNG 設定](searxng.md)。

### 智譜 API Key

智譜網路搜尋使用智譜模型供應商中儲存的 API Key。先在**設定 → 模型服務**完成智譜設定，再回到**設定 → 網路搜尋**選擇智譜並檢查。

## 設定搜尋結果

### 搜尋結果個數

**搜尋結果個數**可設定為 `1–100`，預設值為 `5`。

結果越多，涵蓋範圍通常越廣，但也會：

- 增加回應時間；
- 占用更多上下文；
- 消耗更多 Token；
- 引入更多重複或低相關性的來源。

日常問答可從預設值開始。只有在需要比較多個來源時，再逐步增加。

### 搜尋結果壓縮

可選擇：

| 壓縮方法 | 行為 | 適用情境 |
| --- | --- | --- |
| 不壓縮 | 保留供應商傳回的正文 | 結果較少、需要更多原文脈絡 |
| 截斷 | 依設定的上限縮短各項結果的正文 | 結果較多、希望控制上下文消耗 |

啟用**截斷**後，需要填寫截斷長度。長度過小可能遺失關鍵脈絡；長度過大則無法有效控制 Token。建議先保留預設值，再依回答是否遺漏資訊調整。

### 黑名單

黑名單會在外部搜尋結果進入模型前排除符合規則的網域。適合封鎖內容農場、鏡像站或不希望使用的網站。

規則格式與訂閱設定請參閱[網路搜尋黑名單](blacklist.md)。

{% hint style="info" %}
模型原生聯網由模型供應商執行，黑名單是否生效以及支援多少項排除規則，取決於對應供應商的實作，不能假定與外部聯網完全一致。
{% endhint %}

## 在對話中啟用聯網

1. 開啟一個對話；
2. 選擇準備使用的模型；
3. 點選輸入框下方的**地球**圖示；
4. 圖示反白後傳送問題。

聯網狀態儲存在目前助理中。切換模型後，Cherry Studio 會依新模型重新判斷使用原生聯網或外部聯網。

適合聯網的問題範例：

```text
尋找 Cherry Studio 最近一個正式版本的更新內容，並引用官方發布頁面。
```

```text
比較這三項產品目前的官方定價，只使用各自官網作為來源。
```

```text
閱讀這個連結，摘要主要結論，並指出文章的發布日期和作者。
```

為了得到更可靠的結果，建議在問題中說明：

- 時間範圍；
- 希望優先使用的來源；
- 是否排除論壇或彙整網站；
- 是否需要逐項引用；
- 需要核對的欄位，例如版本號、價格或發布日期。

## 檢視和核對引用

外部聯網會將搜尋結果整理為編號參考資料，並提示模型使用 `[1]`、`[2]` 等形式引用。模型原生聯網的引用樣式則由對應供應商決定。

取得回答後至少檢查：

1. 引用是否能開啟；
2. 頁面標題與回答主題是否一致；
3. 原文是否真的支援對應結論；
4. 發布日期是否符合問題的時間範圍；
5. 不同來源之間是否存在衝突。

搜尋結果為空不代表網路上沒有相關內容，也可能是關鍵字、服務額度、網路、黑名單或網頁反爬蟲策略所致。

## 已知相容限制

### 較早的 Gemini 模型與 MCP

較早的 Gemini 模型在函式工具模式下，無法同時使用模型內建聯網和已啟用的 MCP。發生衝突時，Cherry Studio 會關閉聯網並顯示提示。

可以嘗試：

- 暫時停用 MCP；
- 切換到支援此組合的新模型；
- 改用其他支援聯網的模型。

### GPT-5 系列的 minimal 思考強度

GPT-5 系列推理模型使用 `minimal` 思考強度時，無法啟用 OpenAI 網路搜尋。Cherry Studio 會關閉聯網並顯示提示。

調高思考強度後重試，或選擇其他聯網方式。

## 隱私與費用

啟用聯網後，搜尋關鍵字、要讀取的 URL，以及必要的對話上下文，可能傳送給模型供應商、搜尋供應商或網頁伺服器。

使用前請確認：

- 不在搜尋詞中包含密碼、API Key、個人身分資訊或內部機密；
- 目標服務符合所在組織的資料合規要求；
- 搜尋、模型呼叫和網路流量的費用規則；
- 網頁內容可能包含錯誤資訊或針對模型的惡意指令。

{% hint style="danger" %}
網頁內容屬於不可信輸入。不要因為網頁或模型回答要求，就貼上密鑰、執行未知命令、下載可疑檔案或變更安全設定。
{% endhint %}

## 常見問題

### 點選聯網圖示後跳轉到設定

目前模型未使用原生聯網，且**預設搜尋供應商**或**預設 URL 取得供應商**尚未選擇。完成兩項設定後重試。

### 供應商檢查失敗

依序檢查：

1. API Key 是否完整、有效且有可用額度；
2. API 位址是否為介面位址，而不是網頁控制台；
3. 代理、防火牆和 DNS 是否允許存取；
4. 自架服務是否已啟動並監聽正確位址；
5. 系統時間是否準確；
6. 供應商狀態頁是否回報故障。

### 已開啟聯網，但回答沒有引用

可能原因包括：

- 模型未呼叫搜尋工具；
- 模型原生聯網未傳回可顯示的引用；
- 搜尋結果為空或相關性不足；
- 模型未遵循引用指示；
- 目前問題不需要聯網，模型直接回答。

可以明確要求「必須搜尋並逐項引用來源」，或更換工具呼叫能力較穩定的模型。

### 搜尋結果太長或回答變慢

降低**搜尋結果個數**，或啟用**截斷**並逐步縮短截斷長度。不要一次將結果數和截斷長度都調得很高。
