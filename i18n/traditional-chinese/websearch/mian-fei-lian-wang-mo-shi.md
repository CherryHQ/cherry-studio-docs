# 免費聯網模式

如果不想另外申請搜尋服務的 API Key，可以在 Cherry Studio V2 中使用：

```text
預設搜尋供應商：ExaMCP
預設 URL 取得供應商：Fetch
```

這套組合在目前版本中不要求填寫額外的搜尋 API Key：

- ExaMCP 負責依關鍵字尋找網頁；
- Fetch 負責直接讀取搜尋結果或指定 URL 的正文；
- 一般模型透過工具呼叫使用這兩項能力。

{% hint style="warning" %}
這裡的「免費」是指 Cherry Studio 目前不需要您另外設定搜尋 API Key，不代表所有相關服務永遠免費。模型呼叫仍可能計費，ExaMCP 的開放政策、額度和可用性也可能變更。
{% endhint %}

## 適用情境

適合：

- 初次體驗聯網模式；
- 偶爾查詢最新資料；
- 不想註冊多個搜尋平台帳號；
- 暫時沒有 Tavily、Exa、博查等服務的 API Key；
- 希望先驗證模型的工具呼叫效果。

如果需要穩定的大量呼叫、固定服務等級、企業合規或完全自主管理，建議改用有正式帳號的搜尋 API，或部署自己的 SearXNG。

## 運作方式

一次典型的外部聯網過程如下：

1. 模型判斷問題需要搜尋；
2. 模型呼叫 ExaMCP，提交搜尋關鍵字；
3. ExaMCP 傳回候選網頁；
4. 模型依需要呼叫 Fetch 讀取特定 URL；
5. Cherry Studio 擷取網頁主要正文；
6. 模型依傳回內容組織答案和引用。

ExaMCP 與 Fetch 的分工不同，不能互相取代：

| 供應商 | 能力 | 能否單獨完成一般模型的完整聯網設定 |
| --- | --- | --- |
| ExaMCP | 搜尋關鍵字 | 不能，還缺少預設 URL 取得供應商 |
| Fetch | 讀取 URL | 不能，還缺少預設搜尋供應商 |
| ExaMCP + Fetch | 搜尋並讀取網頁 | 可以 |

{% hint style="info" %}
如果目前模型使用自身的原生聯網能力，Cherry Studio 不會改用這套外部組合。原生聯網由模型供應商執行，費用和引用形式以模型供應商為準。
{% endhint %}

## 設定 ExaMCP 與 Fetch

### 1. 開啟網路搜尋設定

進入：

```text
設定 → 網路搜尋
```

頁面頂端有兩個獨立選項：

- **預設搜尋供應商**；
- **預設 URL 取得供應商**。

### 2. 選擇 ExaMCP

在**預設搜尋供應商**中選擇：

```text
ExaMCP
```

也可以開啟 ExaMCP 詳細資料頁面，點選**設為預設**。

目前的預設位址是：

```text
https://mcp.exa.ai/mcp
```

通常不需要修改，也不需要填寫 API Key。點選**檢查**，確認目前網路能夠存取該服務。

{% hint style="warning" %}
不要任意將 API 位址替換成來源不明的 MCP 位址。搜尋詞會傳送到該位址，惡意服務還可能傳回誤導性內容。
{% endhint %}

### 3. 選擇 Fetch

在**預設 URL 取得供應商**中選擇：

```text
Fetch
```

Fetch 是 Cherry Studio 內建的網頁讀取方式，不需要 API Key，也沒有需要填寫的遠端擷取服務位址。

### 4. 確認兩個預設項目

最終應同時顯示：

| 設定項目 | 選擇 |
| --- | --- |
| 預設搜尋供應商 | ExaMCP |
| 預設 URL 取得供應商 | Fetch |

如果只設定其中一項，一般模型點選聯網圖示時仍會提示前往設定。

## 在對話中使用

1. 返回對話頁面；
2. 選擇一個工具呼叫表現穩定的聊天模型；
3. 點選輸入框下方的**地球**圖示；
4. 傳送一個需要即時資訊的問題。

首次測試可使用：

```text
搜尋 Cherry Studio 最近一個正式版本，只引用官方 GitHub Release，
列出版本號、發布日期和三項主要變更。
```

回答後檢查：

- 是否真的執行了搜尋；
- 是否出現可開啟的引用；
- 引用是否來自指定的來源；
- 版本號和發布日期是否與原文一致。

## Fetch 能讀取什麼

Fetch 會從 Cherry Studio 所在電腦直接請求目標 URL，再從傳回的 HTML 中擷取主要正文，並轉換為適合模型讀取的文字。

通常適合：

- 新聞與部落格正文；
- 產品文件；
- 靜態網頁；
- 不需登入的公開頁面；
- 搜尋結果中的文章連結。

以下頁面可能失敗或內容不完整：

- 必須登入後才能檢視的頁面；
- 主要內容依賴瀏覽器指令碼載入的頁面；
- 帶有驗證碼或強力反爬蟲策略的網站；
- 僅允許特定地區或網路存取的頁面；
- PDF、音訊、視訊或非 HTML 檔案；
- 已失效、重新導向異常或憑證錯誤的連結。

Fetch 單次讀取有逾時限制。目標網站回應太慢時，模型可能無法取得正文。

## 「不需額外 Key」不等於「沒有成本」

仍可能產生：

- 模型輸入與輸出 Token 費用；
- 搜尋結果占用的上下文；
- 本機或伺服器網路流量；
- 自架 SearXNG 的裝置、網域或維運費用；
- 第三方服務未來調整後的呼叫費用。

搜尋結果越多、網頁正文越長，模型上下文消耗通常越高。可以在**設定 → 網路搜尋**中降低**搜尋結果個數**，或啟用**截斷**。

## 隱私說明

使用 ExaMCP + Fetch 時：

- 搜尋關鍵字會傳送給 ExaMCP 服務；
- Fetch 會從本機直接存取目標網站；
- 目標網站通常能夠看到請求來源的網路位址；
- 搜尋結果和網頁正文會作為上下文傳送給目前模型供應商。

不要在搜尋詞或 URL 中包含：

- API Key、密碼或驗證碼；
- 私有系統中帶有存取權杖的連結；
- 客戶資料或個人身分資訊；
- 公司內部機密。

{% hint style="danger" %}
網頁內容是不可信輸入。不要執行網頁或模型回答中來源不明的命令，也不要依其要求關閉安全軟體、上傳密鑰或下載可疑檔案。
{% endhint %}

## 其他低成本方案

### 使用模型原生聯網

如果已經在使用支援原生聯網的模型，通常不需要另外設定搜尋 API Key。但模型聯網可能包含在模型計費中，不能因此視為免費。

### 自架 SearXNG + Fetch

希望自行控制搜尋入口時，可以使用：

```text
預設搜尋供應商：SearXNG
預設 URL 取得供應商：Fetch
```

SearXNG 本身不要求 Cherry Studio 填寫搜尋 API Key，但您需要有一個可存取的執行個體。自架執行個體需要自行承擔部署、更新、安全和上游搜尋引擎限制。

詳細設定請參閱 [SearXNG 設定](searxng.md)。

### 使用供應商贈送額度

部分搜尋 API 可能為新帳號提供試用或免費額度，但規則會變更。註冊前應查看供應商目前的官方定價、地區限制和隱私權政策，不要依據舊教學中的額度數字做長期規劃。

## 常見問題

### ExaMCP 檢查失敗

依序檢查：

1. 目前網路是否能存取 `https://mcp.exa.ai/mcp`；
2. 代理是否已正確設定並允許 Cherry Studio 使用；
3. DNS、防火牆或安全軟體是否攔截；
4. ExaMCP 服務是否暫時無法使用；
5. API 位址是否被誤改。

恢復預設位址後重新檢查。若仍失敗，可改用其他搜尋供應商或自架 SearXNG。

### Fetch 讀取失敗

先在一般瀏覽器中開啟相同 URL。如果瀏覽器也無法存取，應先解決網路、登入、地區或憑證問題。

瀏覽器能開啟但 Fetch 失敗，常見原因是：

- 頁面依賴 JavaScript；
- 網站要求 Cookie、登入狀態或驗證碼；
- 網站阻止自動請求；
- 傳回的不是可擷取正文的 HTML；
- 回應時間超過限制。

可以更換來源，或將網頁中需要分析的正文手動複製到對話。

### 已設定兩項，但模型沒有搜尋

聯網開關只會提供工具，模型仍需決定是否呼叫。可以：

- 確認地球圖示已反白；
- 明確要求「先聯網搜尋，再回答並引用來源」；
- 改用工具呼叫能力較穩定的模型；
- 將問題寫得更具體，提供時間範圍和優先來源；
- 建立新對話後重試。

### 有搜尋結果，但沒有網頁正文

ExaMCP 可能已傳回候選連結，但 Fetch 無法讀取某些頁面。嘗試減少結果數量、更換來源，或直接給模型一個可公開存取的特定 URL。
