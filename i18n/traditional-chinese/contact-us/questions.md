# 商務合作

Cherry Studio 商務電子郵件：

**[bd@cherry-ai.com](mailto:bd@cherry-ai.com)**

此信箱用於企業版諮詢、採購、商業授權與合作洽談，不是社群版日常使用問題的優先支援管道。

## 適合聯絡商務團隊的事項

### Cherry Studio 企業版

企業版面向需要統一管理 AI 資源、組織成員與知識資產的團隊。官方目前公布的方向包括：

* 統一接入雲端模型與本機私有模型。
* 團隊共用知識庫。
* 員工與權限管理。
* 私有化部署。
* 企業級資料備份與復原。

可先造訪 [Cherry Studio 企業版](https://enterprise.cherry-ai.com)了解公開資訊，再透過商務信箱諮詢展示、報價與適用範圍。

{% hint style="info" %}
具體功能、部署方式、服務範圍、價格與交付時間，應以商務團隊依實際需求提供的方案與合約為準。
{% endhint %}

### 商業授權

Cherry Studio 社群版採用 **GNU Affero General Public License v3.0（AGPL-3.0）**。商業使用並非一律禁止，但必須遵守授權條款。

如果組織希望取得不受 AGPL-3.0 部分要求約束的商業授權，請聯絡商務團隊。授權的基礎說明請參閱 [Cherry Studio 開放原始碼授權條款](questions/cherrystudio-xu-ke-xie-yi.md)。

### 生態與聯合合作

下列合作可以傳送簡要方案：

* 模型服務與 API 接入。
* 企業解決方案與私有化交付。
* 硬體、作業系統或通路合作。
* 教育、研究與社群聯合活動。
* 經授權的品牌、媒體或行銷合作。

傳送電子郵件不代表合作已經成立。涉及產品名稱、Logo、宣傳用語或客戶案例時，應先取得書面確認。

## 電子郵件中建議包含什麼

為減少來回確認，請在第一封郵件中說明：

1. **組織資訊**：公司或機構名稱、官網、所在地區與聯絡人。
2. **合作類型**：企業版、商業授權、模型接入、通路或其他合作。
3. **使用規模**：預計使用者數、裝置數或部署範圍。
4. **部署環境**：公有雲、私有雲、區域網路或完全離線。
5. **核心需求**：必須解決的業務問題與關鍵功能。
6. **安全要求**：資料駐留、身分驗證、權限、稽核與合規要求。
7. **計畫時間**：希望評估、測試或上線的時間範圍。
8. **聯絡方式**：可用於後續溝通的工作信箱與時區。

### 郵件標題範例

```text
[企業版諮詢] 某公司 / 200 人 / 私有化部署
[商業授權] 某產品整合 Cherry Studio 社群版
[生態合作] 某模型服務商 API 接入
```

### 郵件範本

```text
組織名稱：
官網：
聯絡人與職稱：
合作類型：

使用情境：
預計規模：
部署環境：
必須滿足的功能：
安全與合規要求：
計畫時間：

希望商務團隊提供：
```

不要在第一封郵件中傳送正式環境 API Key、密碼、私鑰、真實使用者資料或未去識別化的內部文件。
