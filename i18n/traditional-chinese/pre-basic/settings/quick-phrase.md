# 提示詞與快速插入

提示詞用於儲存經常重複輸入的內容，例如固定的寫作要求、分析架構或回覆格式。儲存後，可以從對話輸入框快速搜尋並插入，不必每次重新輸入。

Cherry Studio V2 使用「提示詞」統一管理這類內容，取代舊版本的「快捷短語」。

## 新增提示詞

### 從資源庫新增

1. 開啟[資源庫](../../cherrystudio/preview/library.md)。
2. 在左側選擇 **提示詞**。
3. 點選新增按鈕，填寫名稱和內容。
4. 點選儲存。

名稱用於搜尋和識別，內容則是插入輸入框的實際文字。儲存後，提示詞會顯示在資源庫和對話輸入框的提示詞清單中。

### 從輸入框新增

1. 點選對話輸入框下方的閃電圖示，開啟提示詞清單。
2. 選擇清單底部的「新增提示詞...」。
3. 填寫名稱和內容並儲存。

如需編輯或刪除現有提示詞，請前往資源庫。

## 從輸入框插入提示詞

可以使用下列任一方式開啟提示詞清單：

* 點選對話輸入框下方的閃電圖示。
* 在輸入框中輸入 `/`，開啟快捷選單，然後選擇「提示詞管理」。

在清單中搜尋並選擇提示詞後，Cherry Studio 會將提示詞內容插入目前的游標位置。如果已選取一段文字，使用閃電按鈕插入時會取代所選內容；透過 `/` 開啟快捷選單時，則會取代用於觸發和搜尋的文字。

插入後仍可繼續編輯，再傳送給模型。

## 關於變數

提示詞編輯器可以插入 `${variable}` 作為預留位置文字。目前版本會原樣儲存和插入提示詞，不會自動為預留位置填入內容。插入對話輸入框後，按下 Tab 可以選取下一個 `${...}` 預留位置；到達最後一個後，再按一次 Tab 會返回第一個。

{% hint style="warning" %}
傳送訊息前，請手動將 `${variable}` 替換為實際內容。請勿在提示詞中儲存密碼、API Key 或其他敏感資訊。
{% endhint %}

## 使用建議

* 名稱應盡量描述任務，例如「檢查產品文件」或「產生會議摘要」。
* 將穩定的要求寫入提示詞，每次會變動的資料則留到插入後再補充。
* 定期清理不再使用或內容重複的提示詞，讓搜尋結果保持簡潔。
