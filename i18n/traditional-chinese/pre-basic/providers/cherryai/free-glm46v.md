# 智譜 GLM-4.6V

Cherry Studio 可以識別多個服務商提供的 GLM-4.6V 及其常見變體，並將標準版本識別為支援圖片、檔案、推理和工具呼叫的多模態模型。最終可用能力仍取決於服務商實際開放的介面。

{% hint style="warning" %}
本文不再承諾 GLM-4.6V 一定是 CherryAI 或 CherryIN 的免費試用模型。模型是否免費、是否仍然可用，請以模型選擇器、服務商控制台和實際請求結果為準。
{% endhint %}

## 先檢查是否已經可用

1. 開啟對話介面的模型選擇器；
2. 搜尋 `GLM-4.6V`；
3. 確認模型所屬服務商，並查看視覺、檔案、推理和工具呼叫標籤；
4. 選擇模型，上傳一張不含敏感資訊的圖片進行測試。

同一個模型可能由多個服務商提供，顯示名稱、模型 ID 和能力標籤也可能不同。

## 透過服務商連線

如果模型選擇器中沒有 GLM-4.6V：

1. 開啟 `設定 → 模型服務`；
2. 選擇 ZhiPu，或帳戶中提供該模型的聚合服務商；
3. 填寫 API Key 並檢查 Base URL；
4. 點選**新增**，套用同步預覽中的模型變更；
5. 搜尋並啟用 GLM-4.6V；
6. 執行連線檢查或模型健康檢查。

Cherry Studio 的模型登錄資料可以識別多個服務商使用的 GLM-4.6V 識別碼，但不保證你的帳戶已經開通該模型。

## 選擇正確的變體

服務商可能同時提供標準版、Flash、FP8 或帶有其他後綴的版本。它們是獨立模型，不應只因名稱相似就假設能力相同。

- 需要理解圖片時，確認模型帶有**視覺**或**圖片識別**能力；
- 需要上傳文件時，確認模型帶有**檔案輸入**能力；
- 需要使用 MCP 或其他工具時，確認模型帶有**工具呼叫**能力；
- 只執行文字任務時，可以根據服務商的速度、額度和計費說明選擇合適的變體。

{% hint style="danger" %}
不要根據本文猜測模型 ID。請複製服務商控制台或 API 文件中的完整 ID；填寫錯誤的 ID 可能會傳回「模型不存在」，也可能路由到不同的變體。
{% endhint %}

## 在對話中使用圖片

1. 選擇具有視覺能力的 GLM-4.6V；
2. 將圖片拖曳至輸入區、貼上圖片，或點選附件按鈕新增圖片；
3. 在同一則訊息中說明任務，例如擷取表格、解釋圖表或分析介面；
4. 傳送前，檢查圖片中是否包含 API Key、個人資訊或其他敏感內容。

如果輸入區不允許新增圖片，通常表示目前模型未被識別為視覺模型。你可以重新同步模型，或在模型編輯頁面核對能力設定。

## 常見問題

### 已上傳圖片，但模型無法識別

確認選擇的是支援視覺的 GLM-4.6V 變體，並檢查服務商端點是否支援圖片輸入。只有名稱相同，並不足以證明介面能力一致。

### 模型可以對話，但無法呼叫工具

請先檢查工具呼叫能力標籤，再使用一個簡單工具進行測試。服務商可能未對該變體開放工具呼叫，或使用了不相容的介面。

### 同步清單中沒有 GLM-4.6V

查看服務商控制台是否已對你的帳戶開放該模型。如果介面不傳回模型清單，可以點選**自訂**並填寫服務商提供的模型 ID。

### 傳回檔案或上下文過大

減少圖片數量或解析度、拆分長文件，並建立新話題後重試。具體限制由服務商和模型變體決定。

免費試用的一般規則請參閱 [CherryAI（免費試用）](../cherryin/README.md)，服務商設定流程請參閱[模型服務](../README.md)。
