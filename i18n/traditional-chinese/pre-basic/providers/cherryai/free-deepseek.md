# DeepSeek V3.2

Cherry Studio 可以識別多個服務商提供的 DeepSeek V3.2 及其常見變體。模型是否免費、是否仍然可用，以及具體的模型 ID，均由你使用的服務商決定。

{% hint style="warning" %}
本文不再承諾 DeepSeek V3.2 一定是 CherryAI 或 CherryIN 的免費試用模型。請以模型選擇器中的**免費**標記、服務商控制台和實際請求結果為準。
{% endhint %}

## 先檢查是否已經可用

1. 開啟對話介面的模型選擇器；
2. 搜尋 `DeepSeek V3.2`；
3. 如果找到模型，確認其所屬服務商；
4. 選擇模型並傳送一則簡單的測試訊息。

同一個模型可能由多個服務商提供，顯示名稱和 API 模型 ID 也可能不同。選擇前，請確認帳戶額度、地區可用性和服務商計費規則。

## 透過服務商連線

如果模型選擇器中沒有 DeepSeek V3.2：

1. 開啟 `設定 → 模型服務`；
2. 選擇 [DeepSeek](../deepseek.md) 官方服務，或帳戶中提供該模型的聚合服務商；
3. 填寫 API Key 並檢查 Base URL；
4. 點選**新增**，在同步預覽中套用模型變更；
5. 搜尋 DeepSeek V3.2，並開啟目標模型的開關；
6. 執行連線檢查或模型健康檢查。

Cherry Studio 的模型登錄資料包含多個服務商使用的 DeepSeek V3.2 識別碼，但這只用於識別模型能力，並不表示所有服務商帳戶都能呼叫它。

## 無法同步時手動新增

部分閘道不提供模型清單介面。此時請點選**自訂**，將服務商控制台提供的模型 ID 原樣填入。

常見名稱可能包含：

- `deepseek-v3.2`
- `deepseek/deepseek-v3.2`
- 帶有日期、`thinking`、`exp` 或 `speciale` 後綴的變體

{% hint style="danger" %}
不要根據本文猜測模型 ID。不同服務商的 ID、能力和路由可能不同，必須複製該服務商控制台或 API 文件中的實際值。
{% endhint %}

## 在對話中使用

DeepSeek V3.2 系列適合程式碼、長文字分析和多步驟推理等任務。使用時建議：

- 只在複雜任務中啟用模型提供的推理能力，簡單問答不需要刻意增加推理成本；
- 需要呼叫 MCP 或其他工具時，先確認模型具有工具呼叫能力標籤，並完成一次測試；
- 長對話遇到上下文或輸出限制時，請建立新話題或減少附加檔案；
- 重要結果應自行複核，不要直接將模型輸出作為最終決策。

不同變體的能力不盡相同。例如，帶有特殊後綴的推理版本可能不支援工具呼叫；請以 Cherry Studio 中顯示的模型能力和實際測試為準。

## 常見問題

### 搜尋到模型，但無法選擇

確認所屬服務商和該模型的開關都已啟用。如果模型來自舊設定，可以重新取得清單後再檢查。

### 傳回 401、403 或餘額不足

檢查 API Key、帳戶權限、餘額和地區限制。試用額度用完後，可以切換服務商或設定自己的 API Key。

### 傳回「模型不存在」

這通常是模型 ID 與服務商不相符。刪除錯誤項目、重新取得清單，或複製服務商文件中的完整 ID 後手動新增。

### 無法使用工具

服務商提供同名模型，不代表該端點一定開放工具呼叫。請查看模型能力標籤；必要時，請更換支援工具呼叫的變體或服務商。

免費試用的一般規則請參閱 [CherryAI（免費試用）](../cherryin/README.md)，服務商設定流程請參閱[模型服務](../README.md)。
