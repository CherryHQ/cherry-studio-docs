# Grok

Cherry Studio V2 的 Grok 內建範本用於連線 xAI 官方 API。V2 會為該服務商使用 xAI Responses 轉接，從而支援對話、推理、工具呼叫，以及 xAI 官方的 Web Search 和 X Search。

{% hint style="warning" %}
Grok 不會自動取得即時資訊。只有在對話中啟用網路搜尋後，Cherry Studio 才會向 xAI 請求 Web Search 和 X Search；伺服器端搜尋工具可能會產生額外費用。
{% endhint %}

## 開始前的準備

- 可登入 [xAI Console](https://console.x.ai/)的帳戶；
- 已在 xAI Console 建立 API Key；
- 團隊或帳戶具有可用額度；
- 已確認目前可用的模型和服務地區。

x.com 或 Grok 網頁版的登入狀態不會自動寫入 Cherry Studio。使用 xAI API 需要另外建立 API Key。

## 設定 Grok

1. 開啟 `設定 → 模型服務`；
2. 將左側篩選切換為**全部服務商**，選擇 **Grok**；
3. 輸入 xAI API Key；
4. 保留預設 Base URL `https://api.x.ai`；
5. 開啟頁面頂端的服務商開關；
6. 在模型列表點選**新增**，檢查同步預覽並套用變更；
7. 啟用準備使用的模型。

{% hint style="danger" %}
不要把 API Key 寫入聊天訊息、文件、程式碼儲存庫或問題截圖。洩漏後應立即在 xAI Console 撤銷並重新建立。
{% endhint %}

## 選擇模型

xAI 會持續更新模型和別名。點選**新增**同步帳戶目前可見的列表，並以 [xAI 模型文件](https://docs.x.ai/developers/models)為準。

目前常見的選擇包括：

| 模型 ID | 適用情境 |
| --- | --- |
| `grok-4.5` | 複雜知識工作、程式碼和 Agent 任務 |
| `grok-4.3` | 一般對話、圖片理解和可調整推理 |
| `grok-build-0.1` | 面向 Agent 的程式碼任務 |

- 只啟用實際需要的模型；
- 核對完整模型 ID，不要只看顯示名稱；
- `-latest` 別名可能會自動遷移到新版本；
- 帶日期的模型 ID 更適合需要固定行為的工作流程；
- 模型出現在同步列表中，不代表帳戶具有無限額度。

## 使用網路搜尋

在對話輸入框開啟**網路搜尋**後，Cherry Studio 會為 Grok 設定：

- xAI Web Search；
- xAI X Search；
- 理解搜尋頁面和 X 貼文中的圖片；
- 傳回搜尋來源與引用。

如果在網路搜尋設定中設定排除網域，Grok 的官方搜尋最多接收前 5 個有效網域規則。

使用方法：

1. 選擇一個已啟用的 Grok 文字模型；
2. 開啟輸入框中的**網路搜尋**；
3. 提出明確需要最新網頁或 X 資訊的問題；
4. 等待模型完成伺服器端搜尋；
5. 展開引用並核對來源。

{% hint style="info" %}
「模型知識較新」和「網路搜尋」不是同一件事。未啟用網路搜尋時，Grok 只會根據模型已有知識回答；需要目前資訊時，應明確開啟網路搜尋並檢查引用。
{% endhint %}

## 推理與工具呼叫

Cherry Studio 會根據模型 ID 顯示相應的推理選項：

- `grok-4.3` 支援關閉、低、中、高等推理強度；
- Grok 4 Fast 的推理版和非推理版是不同模型，不能只靠開關互換；
- 其他新模型的選項取決於目前的 Cherry Studio 版本和模型登錄資訊。

使用 MCP 或其他工具前：

1. 先完成一般對話健康檢查；
2. 啟用一個簡單工具；
3. 使用明確需要工具的請求；
4. 確認模型實際呼叫工具；
5. 再增加網路搜尋或多個工具。

網路搜尋是 xAI 伺服器端工具，MCP 是 Cherry Studio 本機或遠端工具。兩者可以同時使用，但排查問題時應分別測試。

## 檢查連線

1. 在 API Key 區域執行連線檢查；
2. 選擇一個已同步並啟用的模型；
3. 確認檢查成功；
4. 在模型列表執行健康檢查；
5. 回到對話介面傳送一則簡單訊息；
6. 再開啟網路搜尋並測試一次帶有引用的查詢。

連線檢查成功不代表搜尋工具一定可用。搜尋還會受到模型能力、帳戶權限和工具計費狀態影響。

## 連線 Grok 相容閘道

如果使用的不是 xAI 官方 API：

1. 新增[自訂服務商](zi-ding-yi-fu-wu-shang.md)；
2. 依閘道文件選擇 OpenAI Chat Completions 或 OpenAI Responses；
3. 填寫閘道提供的 Base URL 和 API Key；
4. 同步或手動新增閘道實際提供的模型；
5. 分別驗證推理、工具呼叫和網路搜尋能力。

第三方閘道提供 Grok 模型，不代表它支援 xAI 官方 Web Search 或 X Search。不要直接覆蓋官方 Grok 範本。

## 常見問題

### 傳回 401

API Key 無效、已撤銷或複製不完整。請重新建立 Key，並確認沒有多餘空格。

### 傳回 403

團隊、地區、模型或工具權限不符合要求。請到 xAI Console 檢查帳戶和模型存取狀態。

### 傳回 404 或模型不存在

重新點選**新增**同步列表，核對完整模型 ID。舊模型可能已經遷移、重新導向或停止提供。

### 傳回 429

目前的團隊或模型已達速率限制。請減少並行請求、稍後重試，並在 xAI Console 檢查限制和用量。

### 啟用網路搜尋後沒有引用

確認輸入框中的網路搜尋已開啟，並提出明確需要最新資訊的問題。若使用第三方閘道，它可能不支援 xAI 伺服器端搜尋工具。

### 網路搜尋費用高於預期

xAI 可能同時計算模型 Token 和伺服器端工具呼叫。減少不必要的網路搜尋請求，並到 xAI Console 核對實際用量。

### 推理選項與文件不一致

重新同步模型，並確認 Cherry Studio 已更新。xAI 的新模型可能早於應用程式內能力規則發布；此時以目前介面和實際健康檢查為準。
