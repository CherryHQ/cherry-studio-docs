# 智譜 GLM-4.5-Air

Cherry Studio 可以識別多個服務商提供的 GLM-4.5-Air 及其常見變體。標準模型會被識別為文字推理與工具呼叫模型；這些能力是否開放，仍以服務商介面和實際測試為準。

{% hint style="warning" %}
本文不再承諾 GLM-4.5-Air 一定是 CherryAI 或 CherryIN 的免費試用模型。模型是否免費、是否仍然可用，請以模型選擇器、服務商控制台和實際請求結果為準。
{% endhint %}

## 先檢查是否已經可用

1. 開啟對話介面的模型選擇器；
2. 搜尋 `GLM-4.5-Air`；
3. 確認模型所屬服務商和能力標籤；
4. 選擇模型並傳送一則簡單的測試訊息。

如果出現多個同名項目，請根據服務商名稱和完整模型 ID 加以區分。

## 透過服務商連線

如果模型選擇器中沒有 GLM-4.5-Air：

1. 開啟 `設定 → 模型服務`；
2. 選擇 ZhiPu，或帳戶中提供該模型的聚合服務商；
3. 填寫 API Key 並檢查 Base URL；
4. 點選**新增**並套用模型變更；
5. 搜尋並啟用 GLM-4.5-Air；
6. 執行連線檢查或模型健康檢查。

Cherry Studio 的模型登錄資料包含多個服務商使用的 GLM-4.5-Air 識別碼。這些對應關係用於識別模型，不表示你的帳戶一定具有權限或免費額度。

## 選擇正確的變體

服務商可能提供標準版、AirX、FP8 或帶有 `free` 後綴的項目。

- 標準版與 AirX、FP8 是不同的模型或部署；
- `free` 只表示該服務商為模型 ID 使用了免費標記，不代表永久免費；
- 同名模型的上下文、速度、工具呼叫和推理控制可能因端點而異；
- 不要將一家服務商的模型 ID 直接複製到另一家服務商。

{% hint style="danger" %}
請從目前服務商的控制台或 API 文件複製模型 ID。手動填寫看似相同但實際不受支援的 ID，會導致 404 或「模型不存在」。
{% endhint %}

## 推理與工具呼叫

如果模型選擇器顯示推理能力，你可以在對話中使用 Cherry Studio 提供的思考設定。不同服務商可能透過參數、模型變體或提示詞控制推理，Cherry Studio 會依照服務商設定選擇相應方式。

需要使用 MCP 或其他工具時：

1. 確認模型帶有工具呼叫能力標籤；
2. 先啟用一個簡單且可以驗證的工具；
3. 傳送明確指令，並觀察模型是否實際發起呼叫；
4. 如果只輸出呼叫計畫但沒有執行，請檢查服務商端點和模型能力。

## 常見問題

### 找不到思考開關

目前的服務商或模型變體可能不支援可控推理。重新同步模型並核對能力標籤；不要只根據模型名稱判斷。

### 工具呼叫格式錯誤

更換服務商端點或模型變體後重試。聚合閘道對工具呼叫參數的相容程度可能不同。

### 傳回 401、403 或餘額不足

檢查 API Key、模型權限、帳戶餘額和地區限制。試用額度用完時，請設定自己的憑證或切換模型。

### 模型 ID 不存在

刪除手動新增的錯誤項目、重新同步清單，或使用服務商文件中的完整模型 ID。

免費試用的一般規則請參閱 [CherryAI（免費試用）](README.md)，服務商設定流程請參閱[模型服務](../README.md)。
