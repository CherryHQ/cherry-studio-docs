# CherryAI（免費試用）

CherryAI 是 Cherry Studio 內建的雲端試用服務。它會隨應用程式自動啟用，不要求使用者先填寫 API Key，適合在首次安裝後快速體驗對話和模型選擇。

{% hint style="info" %}
CherryAI 是應用程式內的試用服務；[CherryIN](../cherryin-1.md)則是可以設定 API Key 的模型服務商。兩者名稱相近，但入口、額度和設定方式不同。
{% endhint %}

## 直接開始使用

1. 開啟[對話介面](../../../cherrystudio/preview/chat.md)；
2. 點選輸入區或助手標題列中的模型名稱，開啟模型選擇器；
3. 搜尋 `CherryAI`，或使用**免費**標籤篩選可用的試用模型；
4. 選擇模型並傳送訊息。

CherryAI 模型會在模型選擇器中顯示試用服務標記。可用模型可能隨應用程式版本和服務狀態變更，因此請以應用程式內的實際清單為準。

## 為什麼在「模型服務」中找不到 CherryAI

這是正常行為。V2 會將 CherryAI 加入可選模型來源，但刻意不在 `設定 → 模型服務` 的一般服務商清單中顯示，也不允許使用者修改它的 API Key 或 Base URL。

如果需要穩定使用自己的帳戶和額度，請依照[模型服務](../README.md)中的步驟設定 CherryIN、模型廠商官方 API、本機模型或其他閘道。

## 免費額度

CherryAI 請求會使用試用額度。額度用完時，應用程式會顯示相應提示；你可以：

- 等待試用額度恢復後再使用；
- 切換到其他已設定且已啟用的模型；
- 依提示前往相應服務商設定自己的 API Key。

{% hint style="warning" %}
免費額度、恢復時間和可用模型均可能調整。本文不提供固定額度承諾，也不建議將試用服務用於生產任務、長期自動化或作為唯一可用模型。
{% endhint %}

## 使用限制

- **無需設定不等於離線執行**：訊息仍會傳送到 CherryAI 的雲端介面；
- **模型能力各不相同**：視覺、推理、網路連線和工具呼叫等能力，請以模型標籤及實際回應為準；
- **服務商頁面無法編輯**：在模型選擇器中看到 CherryAI，但在模型服務設定中找不到，是預期設計；
- **試用模型可能變更**：如果已儲存到助手中的模型下線，請重新開啟模型選擇器並更換。

## 與自有模型一起使用

你可以先使用 CherryAI 完成首次體驗，再設定自己的服務商。完成設定後：

1. 在模型服務頁面啟用目標服務商和模型；
2. 返回模型選擇器選擇新模型；
3. 視需要在[預設模型設定](../../../cherrystudio/preview/settings/default-models.md)中指定預設、快速、翻譯或話題命名模型。

這樣即使試用額度暫時無法使用，也能直接切換到自己的模型。

如果 CherryAI 沒有出現在模型選擇器中，或所有試用模型都無法傳送請求，請先確認網路正常並重新啟動應用程式。如果仍無法使用，請提交 Cherry Studio 版本、作業系統和去識別化後的錯誤資訊；意見回饋管道請參閱[意見回饋與建議](../../../question-contact/suggestions.md)。
