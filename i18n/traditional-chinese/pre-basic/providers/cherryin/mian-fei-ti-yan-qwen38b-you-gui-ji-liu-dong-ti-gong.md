# Qwen3-8B

Cherry Studio 可以識別多個服務商提供的 Qwen3-8B。部分版本會將 `Qwen/Qwen3-8B` 作為應用程式內的試用模型，並將服務入口指向 CherryIN；其他服務商也可能使用相同或不同的模型 ID。

{% hint style="warning" %}
模型出現在試用清單中，不代表它會長期免費。請以模型選擇器中的**免費**標記、服務商控制台和實際請求結果為準。
{% endhint %}

## 先檢查是否已經可用

1. 開啟對話介面的模型選擇器；
2. 搜尋 `Qwen3-8B`，或啟用**免費**標籤；
3. 確認模型所屬服務商；
4. 選擇模型並傳送一則簡單的測試訊息。

如果試用標籤旁顯示 CherryIN，點選該標籤即可前往相應的服務商設定。CherryAI 本身不會出現在一般的模型服務清單中。

## 透過服務商連線

如果模型選擇器中沒有 Qwen3-8B：

1. 開啟 `設定 → 模型服務`；
2. 選擇 ModelScope、OpenRouter，或帳戶中提供該模型的其他服務商；
3. 填寫 API Key 並檢查 Base URL；
4. 點選**新增**並套用模型變更；
5. 搜尋並啟用 Qwen3-8B；
6. 執行連線檢查或模型健康檢查。

部分服務商使用 `Qwen/Qwen3-8B`，其他服務商則使用 `qwen/qwen3-8b`。大小寫、命名空間和後綴都可能影響路由。

## 無法同步時手動新增

如果服務商不提供模型清單介面，請點選**自訂**，並複製該服務商控制台或 API 文件中的完整模型 ID。

{% hint style="danger" %}
不要直接複製其他平台的模型 ID。即使名稱相同，不同服務商也可能使用不同的命名空間、能力設定或介面路徑。
{% endhint %}

## 推理與工具呼叫

Qwen3 系列可能支援可控推理。Cherry Studio 會根據服務商能力使用 `enable_thinking` 參數，或在不支援該參數的介面上使用相容方式控制思考模式。

使用時建議：

- 只有在模型選擇器顯示推理能力時，才依賴思考設定；
- 需要使用 MCP 或其他工具時，先確認工具呼叫標籤並完成一次簡單測試；
- 不要手動將 `/think` 或 `/no_think` 固定寫入所有提示詞，請優先使用 Cherry Studio 的思考設定；
- 同名模型由不同服務商提供時，請分別驗證推理和工具呼叫。

## 常見問題

### 在「免費」篩選中找不到 Qwen3-8B

目前版本或地區可能沒有提供該試用模型。你仍可設定支援該模型的服務商，並使用自己的 API Key。

### 點選試用標記後前往 CherryIN

這是預期行為。V2 會將特定 Qwen 試用模型的服務入口對應至 CherryIN，方便使用者在試用額度用完後設定服務。

### 思考模式沒有變化

檢查服務商是否支援 `enable_thinking`，以及目前模型是否為可切換推理的變體。部分端點會忽略不支援的參數。

### 傳回「模型不存在」

核對大小寫和完整模型 ID，並重新同步清單；如果是手動新增的項目，請使用目前服務商提供的 ID 取代。

免費試用的一般規則請參閱 [CherryAI（免費試用）](README.md)，服務商設定流程請參閱[模型服務](../README.md)。
