# 模型服務

模型服務用於將 Cherry Studio 連接至雲端模型平台、本機推論服務或自建閘道。完成設定後，你還需要在該服務商的模型清單中啟用模型，才能在助手、翻譯、知識庫等功能中選擇它們。

{% hint style="info" %}
如果你已經知道要使用哪個服務商，可以直接前往相應的[服務商設定指南](#服務商設定指南)。如果只想快速比較支援情況，請查看[全部 Provider 快速參考](quick-reference.md)。
{% endhint %}

## 開始前準備

請根據服務商類型準備以下資訊：

- **雲端模型平台或聚合閘道**：API Key，以及帳戶中已開通的模型；
- **自建閘道**：API Key、Base URL 和閘道支援的介面協定；
- **本機推論服務**：已啟動的服務位址，以及已下載或載入的模型；
- **雲端平台專用連線**：可能還需要區域、專案、部署名稱或雲端帳戶憑證。

不同服務商的身分驗證和位址結構不完全相同。請優先使用 Cherry Studio 內建的服務商範本；只有清單中沒有目標服務商，或需要連接自建相容介面時，才建立自訂服務商。

## 設定一個服務商

### 1. 尋找或新增服務商

開啟 `設定 → 模型服務`。

左側清單預設顯示已啟用的服務商。你可以：

- 搜尋服務商名稱或模型名稱；
- 篩選**已啟用**、**已停用**、**全部服務商**或支援 Agent 介面的服務商；
- 拖曳服務商以調整順序；
- 點選搜尋框右側的 `+` 建立自訂服務商；
- 透過服務商的右鍵選單編輯、複製或刪除可管理的項目。

{% hint style="warning" %}
「支援 Agent」篩選只表示該服務商具有目前 Agent 功能所需的相容端點，不代表其中每個模型都支援工具呼叫。實際能力仍取決於所選模型和服務商。
{% endhint %}

### 2. 填寫身分驗證與介面位址

選擇服務商後，在右側完成身分驗證設定：

1. 輸入 API Key，或依頁面提示完成 OAuth、AWS、Azure、Google Cloud 等專用身分驗證；
2. 檢查 Base URL。使用內建範本時，通常保留預設位址即可；
3. 如果服務商同時提供多種協定，可以在介面設定中分別設定 OpenAI Chat Completions、Anthropic Messages、Google Generate Content 或 OpenAI Responses 端點；
4. 開啟頁面頂端的服務商開關。

自訂服務商預設以 **OpenAI Chat Completions** 作為主要介面，也可以展開「更多端點」補充其他相容介面。詳細規則請參閱[自訂服務商](zi-ding-yi-fu-wu-shang.md)。

{% hint style="danger" %}
API Key 是敏感憑證。不要將真實 Key 寫入文件、聊天內容或問題截圖；排查問題時，只保留經過遮蔽的前後少量字元。
{% endhint %}

### 3. 同步並啟用模型

在**模型清單**區域：

1. 點選**新增**，從服務商同步目前可用的模型；
2. 在同步預覽中確認新增、更新和移除項目，再套用變更；
3. 如果介面不支援傳回模型清單，點選**自訂**，手動填寫模型 ID；
4. 開啟準備使用的模型開關。

模型清單支援依名稱搜尋，也可以依視覺、推理、工具呼叫等能力篩選。能力標籤主要來自服務商資訊和 Cherry Studio 的模型規則；如果自動識別不準確，可以編輯模型並手動調整。

### 4. 檢查連線

完成設定後，建議執行兩類檢查：

- 在身分驗證區域發起連線檢查，選擇一個已設定的模型和 API Key 來驗證請求；
- 在模型清單中執行健康檢查，批次確認已啟用的模型是否可以存取。

檢查通過後，建立或開啟一個助手，在模型選擇器中選擇剛啟用的模型，並傳送一則測試訊息。

## 如何選擇連線方式

| 使用情境 | 建議方式 | 說明 |
|---|---|---|
| 使用 OpenAI、Anthropic、DeepSeek 等官方 API | 選擇相應的內建範本 | 預設位址和介面類型已預先設定 |
| 使用一個 Key 存取多家模型 | 選擇聚合服務商或閘道範本 | 模型、價格與可用地區由該平台決定 |
| 連接 NewAPI、OneAPI 等自建閘道 | 優先使用相應範本 | 如果部署路徑不同，再修改 Base URL |
| 使用 Ollama、LM Studio 等本機服務 | 選擇本機服務範本 | 先確認本機服務已啟動且連接埠可供存取 |
| 連接清單中沒有的相容介面 | 建立自訂服務商 | 需要確認協定、Base URL 和模型 ID |

{% hint style="info" %}
同一個服務商可以設定多個 API Key，也支援更精細的請求位址與參數設定。請參閱[模型服務設定](../../cherrystudio/preview/settings/providers.md)。
{% endhint %}

## 常見問題

### 無法同步模型

請先確認 API Key、Base URL 和介面協定是否相符。部分服務商不提供模型清單介面，此時可以根據服務商控制台中的模型 ID 手動新增。

### 模型沒有出現在模型選擇器中

確認頁面頂端的服務商開關和目標模型開關都已開啟。模型即使已同步，但處於停用狀態時，也不會顯示為可選模型。

### 傳回 401 或 403

這通常表示 API Key 無效、權限不足、帳戶尚未開通目標模型，或服務商限制了存取來源。請前往服務商控制台檢查憑證狀態和模型權限。

### 傳回 404 或協定錯誤

請重點檢查 Base URL 是否包含重複或缺少的路徑，以及服務商實際支援的介面協定。使用閘道時，還需要確認閘道是否相容於所選模型的端點。

### 本機模型連線逾時

確認本機推論服務正在執行，且監聽位址和連接埠與 Cherry Studio 中的設定一致。如果服務執行於容器、虛擬機器或其他裝置上，還需要確認網路和防火牆允許存取。
