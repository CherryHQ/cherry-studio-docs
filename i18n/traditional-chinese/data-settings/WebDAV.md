# WebDAV 備份

Cherry Studio V2 可以將備份檔案儲存到支援 WebDAV 的雲端硬碟、NAS 或自行架設的伺服器。你可以手動建立備份，也可以依固定週期自動備份並控制保留數量。

WebDAV 在此是「建立備份檔案並還原」的儲存管道，不是多部裝置之間的即時雙向同步。還原會覆寫目前資料，不會合併兩邊各自新增的對話。

{% hint style="warning" %}
WebDAV 備份可能包含對話、服務供應商設定和其他敏感資訊。請使用私人目錄和應用程式專用密碼，請勿公開分享憑證或備份檔案。
{% endhint %}

## 準備連線資訊

請在 WebDAV 服務供應商或伺服器管理頁面取得：

| 欄位 | 填寫內容 |
| --- | --- |
| WebDAV 位址 | WebDAV 服務入口，通常是包含 `https://` 的完整位址 |
| WebDAV 使用者名稱 | 服務供應商分配的帳號名稱、電子郵件或 WebDAV 專用使用者名稱 |
| WebDAV 密碼 | 一般密碼或服務供應商產生的應用程式專用密碼 |
| WebDAV 路徑 | Cherry Studio 儲存備份的遠端目錄 |

不同服務對位址和驗證方式的要求不同。一般的網頁登入位址不一定是 WebDAV 位址；啟用雙重驗證後，通常需要使用應用程式專用密碼，而不是帳號登入密碼。

預設遠端路徑為 `/cherry-studio`。目標目錄不存在時，Cherry Studio 會在第一次上傳時嘗試遞迴建立。建議為 Cherry Studio 使用獨立目錄，避免備份管理器與其他檔案混在一起。

{% hint style="info" %}
Cherry Studio V2 也提供獨立的 **堅果雲** 備份頁面。希望透過堅果雲帳號授權連線時，可以直接使用該入口；只有需要手動填寫通用 WebDAV 參數時，才使用本頁。
{% endhint %}

## 在 Cherry Studio 中設定

1. 開啟 **設定 > 資料設定 > WebDAV**。
2. 填寫 **WebDAV 位址**，保留位址中的 `http://` 或 `https://`。
3. 填寫 **WebDAV 使用者名稱**和 **WebDAV 密碼**。
4. 填寫遠端路徑，例如 `/cherry-studio`。
5. 暫時將 **自動備份** 保持為關閉。
6. 點擊 **備份到 WebDAV**，使用預設檔案名稱建立一份測試備份。
7. 上傳完成後，點擊 **從 WebDAV 還原**，確認備份管理器可以列出剛建立的檔案。

目前頁面沒有獨立的「測試連線」按鈕。能夠成功上傳測試備份，並在管理器中再次列出，才表示位址、驗證、路徑建立和寫入權限都可用。

測試時使用不含敏感附件的小型資料，更容易找出問題。確認連線後，再決定是否啟用完整備份和自動備份。

## 手動建立備份

點擊 **備份到 WebDAV** 後，會顯示預設檔案名稱，其格式包含時間、主機名稱和裝置類型。你可以修改名稱；未以 `.zip` 結尾時，Cherry Studio 會自動補上副檔名。

開啟 **精簡備份** 會略過應用程式 `Data` 目錄中的圖片、知識庫等檔案資料，只保留聊天記錄和設定等內容。這不是增量備份，也不能用來找回略過的檔案。

手動備份完成後，遠端目錄中會保留一個獨立的 ZIP 檔案。請勿在上傳過程中退出應用程式、切斷網路或讓系統休眠。

## 設定自動備份

**自動備份**支援：

- 關閉；
- 1、5、15 或 30 分鐘；
- 1、2、6、12 或 24 小時。

請先完成一次手動測試，再選擇週期。頻率越高，遠端請求和儲存寫入越多；對於大型完整備份，通常不需要每隔幾分鐘執行。

頁面會顯示上次備份時間或最近的錯誤。看到「等待下次備份」時，表示目前還沒有成功記錄；不代表連線已經驗證。

### 控制保留數量

**最大備份數**可以設為無限制、1、3、5、10、20 或 50。

自動清理只會處理目前裝置依預設命名規則建立的備份。Cherry Studio 會依檔案名稱中的主機名稱和裝置類型辨識目前裝置，並刪除超過數量的較舊檔案。

如果自訂的檔案名稱不包含目前裝置識別資訊，可能不會被自動清理；「無限制」也不會主動釋放遠端空間。請定期開啟備份管理器檢查容量。

## 管理和還原備份

點擊 **從 WebDAV 還原** 開啟備份管理器。你可以在這裡：

- 查看檔案名稱、修改時間和大小；
- 重新整理遠端檔案清單；
- 選擇一個備份進行還原；
- 刪除單一備份或批次刪除備份。

還原前：

1. 先為目前裝置建立一份新的備份。
2. 依檔案名稱、修改時間和大小確認目標版本。
3. 確認目前沒有其他裝置正在寫入同一個目錄。
4. 點擊 **還原**，並確認覆寫目前資料。

還原完成後，應用程式可能會自動重新啟動。刪除備份的操作無法復原，批次刪除前應再次核對所選檔案。

{% hint style="warning" %}
多部裝置可以讀取同一個遠端目錄，但還原不會合併資料。需要在 B 裝置使用 A 裝置的資料時，應先備份 B，再還原 A 的目標版本。
{% endhint %}

## 何時啟用「停用串流上傳」

在預設情況下，Cherry Studio 會以串流方式上傳備份，適合大型檔案，而且記憶體用量較低。

部分 WebDAV 服務不相容於分塊或串流上傳，可能出現小型檔案正常、大型備份上傳失敗，或傳回與請求長度、`chunked` 傳輸有關的錯誤。此時可以開啟 **停用串流上傳** 後重試。

啟用後，Cherry Studio 會先將整個備份檔案讀入記憶體，再進行上傳，因此：

- 記憶體用量會接近備份檔案大小；
- 大型備份可能會讓應用程式明顯變慢；
- 只應作為相容性方案，不建議預設開啟。

如果開啟後仍然失敗，應檢查伺服器端的單一檔案大小、請求主體和逾時限制，而不是反覆提高備份頻率。

## 安全建議

- 在公用網路環境中，優先使用 `https://`，避免透過明文 HTTP 傳送密碼和備份。
- 為 Cherry Studio 建立獨立帳號或應用程式專用密碼，只授予目標目錄所需的權限。
- 請勿在截圖、意見回饋或共用設定中顯示完整位址中的私人資訊、使用者名稱和密碼。
- 請勿還原來源不明的 ZIP 檔案。
- 定期驗證至少有一份完整備份可以被列出和辨識。

## 常見問題

### 點擊備份後提示未授權、401 或 403

請檢查使用者名稱和密碼是否屬於 WebDAV，而不是一般的網頁登入資訊；服務啟用雙重驗證時，請改用應用程式專用密碼。也要確認帳號對目標路徑具有建立目錄和寫入檔案的權限。

### 傳回 404 或找不到路徑

請先確認填寫的是 WebDAV 服務入口，而不是雲端硬碟首頁或檔案分享連結。將路徑改成以 `/` 開頭的簡單目錄，例如 `/cherry-studio`，再使用手動備份測試。

### 可以列出檔案，但無法上傳大型備份

請先檢查伺服器端的單一檔案大小、反向 Proxy 請求主體和逾時限制。如果錯誤與分塊上傳有關，再開啟 **停用串流上傳**；使用該選項時，請為完整備份預留足夠的記憶體。

### 自動備份沒有執行

請確認週期不是「關閉」、WebDAV 位址不為空，並檢查頁面底部的備份狀態。電腦休眠、網路中斷或服務無法使用時，排程備份無法完成。

### 達到最大備份數後，舊檔案仍然存在

自動清理會依目前裝置識別資訊篩選檔案。手動改名、來自其他裝置或不符合預設命名格式的檔案可能會保留，需要在備份管理器中手動刪除。

### 從另一部電腦還原後，本機的新對話消失

還原是覆寫操作，不是資料合併。使用遠端備份跨裝置搬遷前，請先分別備份兩部裝置，並且只還原已確認的目標版本。

如果仍無法解決，請透過[意見回饋與建議](../question-contact/suggestions.md)提交 Cherry Studio 版本、作業系統、已移除敏感資訊的位址與路徑、HTTP 狀態碼和完整的錯誤資訊。
