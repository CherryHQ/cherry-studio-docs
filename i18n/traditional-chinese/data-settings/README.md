# 資料設定

Cherry Studio V2 的資料設定位於 **設定 > 資料設定**。你不僅可以在此手動備份和還原，也可以設定本機或雲端自動備份、將資料移轉到其他目錄，以及管理匯入和匯出選項。

{% hint style="warning" %}
還原備份、移轉資料目錄和重設資料都可能覆寫現有內容。操作前請先建立一份可用的備份，並確認備份檔案儲存在應用程式資料目錄之外。
{% endhint %}

## 頁面結構

資料設定左側包含以下頁面：

| 頁面 | 用途 |
| --- | --- |
| 資料 | 手動備份與還原、匯出至手機、移轉應用程式資料、查看記錄、清理快取和重設資料 |
| 本機備份 | 將備份寫入本機、外接硬碟或已掛載的網路目錄，並設定自動備份 |
| WebDAV | 使用支援 WebDAV 的遠端儲存空間儲存和還原備份 |
| 堅果雲 | 登入堅果雲後選擇遠端目錄並管理備份 |
| S3 | 使用 S3 或 S3 相容物件儲存空間儲存備份 |
| 匯入設定 | 匯入受支援的外部應用程式資料 |
| 匯出選單 | 決定對話匯出選單中顯示哪些格式和目標 |
| Markdown 匯出 | 設定預設目錄、公式、模型資訊和引用格式 |

## 選擇備份方式

| 使用情境 | 建議方式 |
| --- | --- |
| 立即儲存一份可移動的備份 | 在 **資料** 頁面點擊 **備份** |
| 定期備份到本機、外接硬碟或已掛載的 NAS | 使用 **本機備份** |
| 已經有支援 WebDAV 的雲端硬碟或伺服器 | 使用 [WebDAV 備份](WebDAV.md) |
| 使用堅果雲，並希望透過帳號授權連線 | 使用 **堅果雲** |
| 已有 AWS S3、Cloudflare R2、MinIO 等物件儲存空間 | 使用 [S3 相容儲存空間備份](s3-compatible.md) |

雲端和本機頁面中的「自動備份」表示依週期建立新的備份檔案，不是兩部裝置之間的即時雙向同步。如果在多部電腦上使用同一個備份位置，請先在一部裝置上完成備份，再於另一部裝置手動選擇對應版本還原；同時修改後互相還原可能會覆寫較新的資料。

## 備份包含哪些內容

一般備份包含 Cherry Studio 的資料庫、設定和應用程式管理的檔案資料，例如聊天記錄、助理設定、圖片和知識庫相關檔案。

開啟 **精簡備份** 後，備份仍會保留聊天記錄和設定，但會略過應用程式 `Data` 目錄中的圖片、知識庫等檔案資料。如此可以縮小檔案並加快備份，但還原後無法依靠該備份找回略過的檔案。

{% hint style="info" %}
「精簡備份」不是增量備份。每次仍會產生獨立的備份檔案，只是排除了檔案資料。
{% endhint %}

備份可能包含對話內容、服務供應商設定和其他敏感資訊。請勿公開分享備份，也不要還原來源不明的檔案；遠端儲存空間應使用私人目錄、強密碼和最小權限憑證。

## 手動備份與還原

前往 **設定 > 資料設定 > 資料**：

1. 如果希望減少備份大小，請先開啟 **精簡備份**；需要完整保留圖片和知識庫檔案時，請保持關閉。
2. 點擊 **備份**，選擇應用程式資料目錄以外的儲存位置。
3. 等待備份完成，請勿在寫入過程中退出應用程式或移除磁碟。

還原時點擊 **還原**，並選擇 Cherry Studio 備份檔案。還原會以備份中的資料替換目前資料，完成後應用程式可能會自動重新啟動。

建議定期執行一次還原驗證：確認目前資料另有備份後，檢查備份檔案能否被辨識，以及版本和時間是否正確。請勿等到原始資料遺失後才進行第一次驗證。

## 自動備份與保留數量

本機、WebDAV、堅果雲和 S3 頁面會分別儲存自己的自動備份設定。目前可選週期為：

- 關閉；
- 1、5、15 或 30 分鐘；
- 1、2、6、12 或 24 小時。

可保留的最大備份數為無限制、1、3、5、10、20 或 50。達到上限後，Cherry Studio 會清理較舊的自動備份；「無限制」不會主動控制儲存空間用量。

每種備份方式也有獨立的 **精簡備份** 開關。修改 **資料** 頁面中的開關，不會自動取代本機、WebDAV、堅果雲或 S3 頁面中的設定。

### 設定本機自動備份

1. 開啟 **本機備份**。
2. 選擇一個可寫入的目錄。該目錄不能位於 Cherry Studio 的應用程式資料目錄或安裝目錄中。
3. 選擇自動備份週期和最大備份數。
4. 依照還原需求決定是否啟用 **精簡備份**。
5. 查看 **備份狀態**，確認最近一次的時間或錯誤資訊。

選擇有效目錄後，會啟用本機自動備份。備份目錄位於外接硬碟或網路掛載點時，請確保執行期間裝置仍在線上，且有足夠空間。

## 匯出至手機

**資料 > 匯出至手機**提供兩種方式：

- **區域網路傳輸：** 在同一個區域網路中掃描 Cherry Studio 行動版，建立連線後傳送暫時備份。
- **匯出為檔案：** 產生一個可由行動版透過檔案方式匯入的 ZIP 備份。

這兩種方式用於傳輸聊天記錄和設定等部分資料，並會略過 `Data` 目錄中的檔案資料。這些方式不能取代完整備份。

在區域網路中找不到裝置時，請確認電腦和手機連線到同一個網路、行動版已開啟區域網路傳輸頁面，並檢查系統防火牆是否阻止裝置探索或檔案傳輸。

## 修改應用程式資料目錄

**資料 > 應用程式資料**會顯示目前的目錄。點擊修改圖示，可以將 Cherry Studio 的資料放到其他磁碟位置。

新目錄必須符合以下條件：

- 不是磁碟根目錄；
- 不在目前的應用程式資料目錄內部；
- 不在 Cherry Studio 安裝目錄內部；
- 目前使用者擁有寫入權限。

確認時可以選擇複製原目錄中的資料。如果目標目錄不為空，應用程式會再次警告，因為繼續操作可能會覆寫目標中的檔案。移轉期間請勿強制退出、拔除磁碟或讓裝置休眠；完成後應用程式會重新啟動，在某些情況下可能會重新啟動多次。

只修改路徑而不複製資料，會讓新位置以其現有內容啟動，不等同於移轉目前資料。需要完整搬遷時，請保留 **複製資料**，並在開始前建立備份。

## 記錄、快取與重設

- **應用程式記錄：** 開啟記錄所在的目錄，適合用於排查問題，或依意見回饋要求提交記錄。分享前請檢查並移除敏感資訊。
- **清除快取：** 刪除應用程式快取和小程式本機資料，不會用於刪除聊天歷史記錄。此操作無法復原。
- **重設資料：** 清空 Cherry Studio 資料並重新啟動。頁面會進行兩次確認；只有在已有可用備份，且確實希望從頭開始時使用。

{% hint style="danger" %}
請勿混淆「清除快取」和「重設資料」。前者針對快取；後者會清空本機資料庫和應用程式管理的資料。
{% endhint %}

## 匯入外部應用程式資料

目前的 **匯入設定** 頁面提供 **匯入 ChatGPT 資料**。點擊 **匯入檔案** 後，依照彈出視窗選擇匯出的 ChatGPT 資料檔案。

匯入前請保留 Cherry Studio 目前的備份。如果頁面沒有列出其他應用程式，表示目前版本尚未在這裡提供對應的匯入器，請勿直接將其他軟體的資料庫或備份檔案當作 Cherry Studio 備份還原。

## 設定匯出選單

**匯出選單**控制對話頁面中出現的匯出選項，目前包括：

- 圖片；
- Markdown；
- Markdown（包含思考）；
- Notion、語雀、Joplin、Obsidian 和思源筆記；
- Word（DOCX）；
- 複製為純文字。

開啟開關只會讓該選項出現在匯出選單中，不會自動設定第三方服務。Notion、語雀等目標仍需要在 **設定 > 整合** 中完成對應連線。

## 設定 Markdown 匯出

**Markdown 匯出**可以設定：

- 預設匯出路徑；留空時每次都會彈出儲存對話框；
- 強制使用 `$$` 標示 LaTeX 公式；
- 使用話題名稱作為訊息標題；
- 顯示模型名稱和模型供應商；
- 不匯出引用內容；
- 將引用標記標準化為 Markdown 註腳格式。

部分選項也會影響以 Markdown 為基礎的第三方匯出，例如 Notion 和語雀。啟用「不匯出引用內容」與「標準化引用格式」前，請先使用一段包含引用的對話，驗證結果是否符合預期。

## 常見問題

### 自動備份一直沒有產生檔案

請確認備份週期不是「關閉」、目標目錄或遠端服務可以存取，並查看頁面底部最近的備份時間或錯誤提示。本機目錄位於行動裝置或網路掛載點時，也要確認它目前在線上。

### 還原精簡備份後缺少圖片或知識庫檔案

這是精簡備份的預期行為。它只會保留聊天記錄和設定，不包含 `Data` 目錄中的檔案資料。請改用關閉「精簡備份」後建立的完整備份。

### 變更資料目錄後看起來像全新安裝

可能是在移轉時關閉了 **複製資料**，或應用程式啟動到了空目錄。請先不要繼續寫入大量新資料，檢查原目錄是否仍然存在，再透過設定移回或從備份還原。

### 多部電腦還原後，資料沒有自動合併

備份還原是覆寫流程，不會合併兩邊新增的內容。選擇還原前，請先比較備份時間，並為目前裝置另存一份備份。

如果仍無法解決，請透過[意見回饋與建議](../question-contact/suggestions.md)提交作業系統、Cherry Studio 版本、使用的備份方式、錯誤提示和已移除敏感資訊的設定截圖。
