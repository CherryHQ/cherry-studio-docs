# 資料設定

開啟**設定 → 資料設定**，可以管理應用程式資料目錄、匯入與匯出選項、快取、日誌及筆記服務連線。

{% hint style="warning" %}
目前 V2 的應用程式內備份與還原尚未開放。資料、本機備份、WebDAV、堅果雲和 S3 頁面會顯示「V2 備份還原尚未上線」提示，相關控制項均為停用狀態。請勿依賴這些入口儲存或還原重要資料。
{% endhint %}

## 頁面一覽

| 分組 | 頁面 | 目前用途 |
| --- | --- | --- |
| 資料 | 資料 | 查看或移轉應用程式資料目錄、開啟日誌、清除快取、重設資料及設定隱私選項 |
| 雲端備份 | 本機備份、WebDAV、堅果雲、S3 | 頁面可見，但備份、還原、自動同步和憑證輸入目前不可用 |
| 匯入設定 | 匯入應用程式資料 | 選擇匯入選單中顯示的來源 |
| 匯出設定 | 匯出選單 | 選擇對話匯出選單中顯示的格式和目標 |
| 匯出設定 | Markdown 匯出 | 設定預設目錄、檔案名稱、公式、模型資訊和引用格式 |
| 筆記匯出 | Notion、語雀、Joplin、Obsidian、思源筆記 | 設定各筆記服務或本機筆記庫的匯出目標 |

## 資料頁面

### 應用程式資料目錄

**應用程式資料**列會顯示目前執行個體實際使用的目錄。按一下路徑或**開啟目錄**，可以在系統檔案管理器中查看；按一下變更目錄圖示可以開始移轉。

移轉會重新啟動應用程式，而且可能複製資料庫、內部檔案、知識庫和筆記。請先閱讀[修改儲存位置](../personalization-settings/storage.md)，準備離線副本，並使用空白目錄作為目標。

### 應用程式日誌

按一下**開啟日誌**可以進入日誌目錄。提交問題時，只提供與故障時間相符的必要日誌，並先檢查其中是否包含路徑、提示詞或其他敏感資訊。

### 清除快取

**清除快取**會移除可以重新產生的快取和本機 Trace 資料，不等同於刪除對話或重設整個應用程式。如果問題與登入狀態、模型設定或知識庫有關，請勿將清除快取當成通用修復方式。

### 資料重設

**資料重設**是破壞性操作，會清除目前執行個體的資料並回到初始狀態。目前應用程式內備份不可用；沒有獨立副本時請勿執行。

## 匯入設定

**匯入應用程式資料**用於控制匯入選單中顯示哪些來源。它只會變更選單入口，不會在背景自動讀取其他應用程式的資料。

匯入前請確認檔案來源可信，並保留原始檔案。匯入結果取決於來源格式和目前版本的支援範圍。

## 匯出設定

### 匯出選單

決定匯出對話時顯示哪些格式或第三方目標。關閉某個項目只會隱藏入口，不會刪除已經匯出的檔案。

### Markdown 匯出

可以設定預設儲存目錄、檔案名稱規則，以及是否包含模型資訊、引用、公式等內容。匯出目錄應位於應用程式資料目錄之外，以便獨立封存。

### 筆記匯出

Notion、語雀、Joplin、Obsidian 和思源筆記各自使用獨立設定。設定服務位址、權杖或本機目錄後，先匯出一筆非敏感測試內容，確認目標位置和格式，再批次匯出。

{% hint style="info" %}
匯出是單向寫出，不是雙向同步，也不能取代完整備份。外部附件、知識庫索引和應用程式內部狀態不一定包含在匯出結果中。
{% endhint %}

## 目前如何保護資料

在 Backup & Restore V2 上線前：

1. 記錄**應用程式資料**頁面顯示的目前目錄。
2. 完全退出 Cherry Studio。
3. 將整個目錄複製到另一個磁碟，並確認副本可以讀取。
4. 保留重要資料的原始檔案和必要的對話匯出。

請勿在應用程式執行期間複製或合併資料庫檔案。後續備份功能啟用後，請以應用程式內狀態和本頁最新說明為準。
