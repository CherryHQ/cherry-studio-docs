# 個人化設定

Cherry Studio V2 已經將常用的外觀選項集中到**設定 > 一般設定 > 顯示與語言**。不需要撰寫程式碼，就能調整主題、色彩、縮放、字型和話題配置；只有內建選項無法滿足需求時，才需要使用自訂 CSS。

{% hint style="info" %}
「個人化設定」是本文件中的專題名稱，不是應用程式內的獨立設定選單。請從左下角的**設定**進入**一般設定**。
{% endhint %}

## 先選擇合適的方式

| 想要完成的操作 | 建議入口 | 風險 |
| --- | --- | --- |
| 切換淺色、深色或跟隨系統 | 設定 > 一般設定 > 顯示與語言 | 低 |
| 修改主題強調色彩 | 設定 > 一般設定 > 顯示與語言 | 低 |
| 放大或縮小整個介面 | 設定 > 一般設定 > 顯示與語言 | 低 |
| 修改全域字型或程式碼字型 | 設定 > 一般設定 > 顯示與語言 | 低 |
| 調整話題位置、時間和置頂方式 | 設定 > 一般設定 > 顯示與語言 | 低 |
| 深度修改元件樣式 | 設定 > 一般設定 > 自訂 CSS | 中 |
| 將應用程式資料移轉到其他磁碟 | 設定 > 資料設定 > 資料目錄 | 高，建議先備份 |

建議從內建選項開始。內建設定會隨版本維護，通常比自訂 CSS 更穩定。

## 顯示與語言

開啟**設定 > 一般設定 > 顯示與語言**後，可以調整以下內容。

### 語言與主題

- **語言**：切換 Cherry Studio 的介面語言；
- **主題**：選擇淺色、深色或跟隨系統；
- **主題色彩**：從預設色彩中選擇，或輸入自訂色彩；
- **視窗透明效果**：只會在 macOS 上顯示；
- **使用系統標題列**：只會在 Linux 上顯示，修改後需要重新啟動應用程式。

### 介面縮放

使用減號和加號逐級調整整個應用程式的縮放比例，點擊重設按鈕可以恢復預設縮放比例。

如果只是覺得訊息文字偏小，請優先調整訊息字型大小；如果按鈕、側邊欄和彈出視窗都偏小，再調整整個介面的縮放比例。

### 字型

V2 會讀取作業系統中已經安裝的字型，並分別提供：

- **全域字型**：用於大部分介面和正文；
- **程式碼字型**：用於程式碼區塊、程式碼編輯器等需要等寬顯示的內容。

選擇字型後會立即生效；點擊對應的重設按鈕，可以恢復預設字型。需要安裝新字型時，可以參考[字型建議](font.md)。

{% hint style="info" %}
字型清單來自目前的作業系統。安裝新字型後，如果清單沒有更新，請完全退出並重新開啟 Cherry Studio。
{% endhint %}

### 話題配置

可以將話題清單放在左側或右側，並控制：

- 點擊助理時是否自動切換到話題；
- 是否顯示話題時間；
- 是否將選取的話題固定到頂部。

「點擊助理時自動切換到話題」只會在話題位於左側時顯示。

## 自訂 CSS

當內建主題和配置選項無法滿足需求時，可以前往**設定 > 一般設定 > 自訂 CSS**，直接編輯樣式。

自訂 CSS 適合修改間距、色彩、圓角和特定元件外觀，但應用程式升級後，元件結構可能會變更，舊規則也可能失效。開始前請閱讀[自訂 CSS](css.md)，並保留一份可用樣式的副本。

如果錯誤的樣式導致設定頁面無法操作，可以參考[清除 CSS 設定](clear-css.md)進行恢復。

{% hint style="warning" %}
請勿為了修改字型或主題色彩而優先使用 CSS。V2 已經提供對應的內建選項，使用內建設定更容易恢復，也比較不容易在升級後失效。
{% endhint %}

## 資料目錄

修改儲存位置不是外觀設定，而是資料移轉操作。入口位於**設定 > 資料設定 > 資料目錄**。

移轉可能涉及對話、助理、知識庫和其他本機資料。操作前請先完成備份，並確認目標目錄：

- 不是磁碟根目錄；
- 不在目前的資料目錄內部；
- 不在應用程式安裝目錄內部；
- 具有寫入權限；
- 有足夠的可用空間。

詳細步驟與注意事項請參閱[修改儲存位置](storage.md)。

## 建議順序

如果想快速調整介面，可以依照以下順序進行：

1. 選擇主題和主題色彩；
2. 調整介面縮放；
3. 選擇全域字型和程式碼字型；
4. 調整話題配置；
5. 確認內建選項仍然無法滿足需求後，再加入自訂 CSS。

如此可以減少樣式衝突，後續恢復預設外觀也更簡單。
