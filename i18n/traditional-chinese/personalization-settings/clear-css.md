# 清除 CSS 設定

自訂 CSS 發生語法或選擇器錯誤時，可能會導致按鈕被遮擋、文字不可見、頁面無法捲動，甚至無法進入設定。請根據介面是否仍可操作，選擇下列復原方式。

## 方法一：在設定中清空

如果仍能開啟設定：

1. 前往**設定 > 一般設定 > 自訂 CSS**。
2. 先將需要排查的 CSS 複製到文字檔中。
3. 全選並刪除編輯器中的所有內容。
4. 等待介面恢復。
5. 完全結束並重新開啟 Cherry Studio，確認問題沒有再次發生。

這是首選方法。清空編輯器會同時刪除已儲存的自訂 CSS 設定。

## 方法二：使用開發人員工具暫時復原

如果錯誤樣式導致設定頁面無法操作，可以先在目前視窗中移除已注入的樣式節點。

{% hint style="warning" %}
下列指令只會讓目前視窗**暫時復原**。重新載入或重新啟動應用程式之前，必須回到設定頁面清空 CSS，否則錯誤樣式會再次出現。
{% endhint %}

### 1. 開啟開發人員工具

可使用下列任一方式：

- Windows / Linux：按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd>；
- macOS：按 <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>I</kbd>；
- 應用程式選單：選擇**檢視 > 切換開發人員工具**；
- 在頁面空白處按一下滑鼠右鍵，選擇**檢查**。

### 2. 開啟 Console

在開發人員工具頂端選擇 **Console**。如果開發人員工具停駐後空間太小，可以將它切換為獨立視窗。

### 3. 移除目前樣式

在 Console 中手動輸入下列一行，然後按 Enter：

```javascript
document.getElementById('user-defined-custom-css')?.remove()
```

執行指令後，自訂 CSS 應該會立即從目前主視窗中移除。

某些 Chromium 版本會阻止直接貼到 Console。請依照開發人員工具中的安全提示操作，或手動輸入這個簡短指令；不要貼上來源不明的其他指令碼。

### 4. 刪除已儲存的 CSS

不要重新整理或關閉目前視窗。請立即：

1. 回到 Cherry Studio；
2. 開啟**設定 > 一般設定 > 自訂 CSS**；
3. 清空編輯器；
4. 關閉開發人員工具；
5. 完全結束並重新開啟應用程式。

如果重新啟動後介面正常，表示已儲存的 CSS 已清除。

## 只刪除有問題的規則

如果想保留主題中的其他部分：

1. 先依照方法二暫時復原介面；
2. 將編輯器中的所有 CSS 複製到外部文字檔；
3. 清空編輯器並確認應用程式恢復正常；
4. 每次只放回一小段；
5. 分別在淺色、深色、聊天、設定和彈出視窗中檢查。

問題再次出現時，最後放回的規則通常就是排查重點。

常見原因包括：

- 缺少 `}`、`;` 或引號；
- 使用會覆蓋全域的 `display: none`、`position: fixed` 或極高的 `z-index`；
- 隱藏所有按鈕、輸入框或捲動容器；
- 使用舊版類別名稱或 `body[theme-mode="dark"]` 等舊版主題選擇器；
- 大範圍使用 `!important`；
- 第三方主題與目前版本的 DOM 結構不相容。

## 常見問題

### 執行指令後沒有變化

確認 Console 對應的是 Cherry Studio 主頁面，而不是小程式網頁或開發人員工具本身。再次執行：

```javascript
document.getElementById('user-defined-custom-css')
```

如果回傳 `null`，表示目前視窗中沒有這個樣式節點；問題可能不是自訂 CSS，或指令是在錯誤的頁面內容中執行。

### 暫時復原後，重新啟動又出現問題

這是因為只移除了目前頁面中的樣式節點，沒有清空已儲存的設定。重新執行方法二，並在不重新整理頁面的情況下進入 CSS 編輯器清空內容。

### 快速鍵無法開啟開發人員工具

嘗試使用應用程式選單中的**檢視 > 切換開發人員工具**，或按一下滑鼠右鍵並選擇**檢查**。系統快速鍵工具可能會攔截預設按鍵組合。

### 設定頁面仍然無法開啟

不要刪除整個應用程式資料目錄，也不要直接修改資料庫。請保留目前版本號、系統資訊和日誌目錄，透過官方回饋管道尋求協助。

### 清空後仍有自訂外觀

請檢查是否仍啟用了作業系統主題、Cherry Studio 內建主題色、字型設定或第三方視窗工具。它們不屬於自訂 CSS，不會隨著本頁操作一併重設。

## 避免再次發生

- 每次只新增一小段規則；
- 修改前先儲存一份可用版本；
- 優先覆寫語意變數，減少依賴內部類別名稱與 DOM 層級；
- 升級 Cherry Studio 後，先停用複雜主題，再逐段驗證；
- 只使用自己能閱讀和理解的第三方 CSS。

更多撰寫建議請參閱[自訂 CSS](css.md)。
