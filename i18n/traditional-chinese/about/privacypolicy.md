# 隱私協議

**更新日期：2026 年 5 月 31 日**

**生效日期：2026 年 5 月 31 日**

歡迎使用 Cherry Studio（以下簡稱「本軟體」或「我們」）。我們高度重視您的隱私保護，本隱私協議將說明我們如何處理與保護您的個人資訊及資料。請在使用本軟體前仔細閱讀並理解本協議：

### 一、我們收集的資訊範圍

為確保軟體正常執行、最佳化使用者體驗並提升產品品質，我們將分級收集下列完全匿名的非個人化執行資訊（統稱「匿名基礎執行資訊」）。所有資訊均經匿名化處理，不包含任何可識別您個人身分的資料，也無法與您的個人資訊建立關聯。您始終保有對所有資訊收集行為的完整控制權，具體方式請參閱下文說明。

#### （一）基礎執行資訊

此類資訊用於確保軟體基礎功能正常執行、安全性與版本相容性，預設收集範圍如下：

1. 軟體版本資訊：用於判斷版本相容性、推送安全更新等；
2. 功能使用彙總資訊：各項功能整體使用情況的彙總（不涉及具體使用行為細節）；

#### （二）產品改善資訊

為持續改善產品體驗，我們預設會收集下列資訊：

1. 功能使用活躍度與頻率：各項功能的使用活躍程度、呼叫頻率等；
2. 錯誤日誌與當機資訊：軟體執行過程中發生的匿名錯誤日誌、當機堆疊資訊等，用於疑難排解與提升穩定性。

上述資訊均為高度彙總的匿名資料，不涉及您的對話內容、API Key 或任何個人身分資訊。

關閉方式：您可以隨時透過【設定】-【一般設定】-【隱私與進階】中的「匿名傳送錯誤報告與資料統計」開關，關閉上述兩類資訊的收集。關閉後不影響軟體核心功能的正常使用。

#### 特別說明（關於本次協議更新）：

由於本次協議更新涉及資料收集架構調整，新版本啟用後，上述【設定】-【一般設定】-【隱私與進階】中的相關開關將統一重設為預設開啟狀態。如果您希望維持先前的關閉設定，請在升級後再次前往該頁面調整。對此造成的不便，敬請見諒。

#### （三）我們的承諾

無論是基礎執行資訊或產品改善資訊，我們均承諾：

* 所有資料均經匿名化處理，無法關聯到您的個人身分；
* 不會用於使用者剖析、廣告推送或對外出售；
* 不會包含您的對話內容、API Key、知識庫內容等任何敏感資料（詳細說明請參閱第二條）。

### 二、我們不會收集的任何資訊

為最大程度保護您的隱私安全，我們明確承諾不會收集、儲存、傳輸或處理下列資料：

* 您的 API Key：您輸入本軟體的模型服務 API Key 資訊；

* 您的對話資料：您在使用本軟體過程中產生的任何對話資料，包括但不限於聊天內容、指令資訊、知識庫資訊、向量資料及其他自訂內容；

* 個人敏感身分資訊：任何可以直接識別您個人身分的敏感資訊。

### 三、本機儲存與資料互動說明

* 資料本機化：您的 API Key、歷史對話記錄及個人偏好設定等資料，均完整儲存在您的本機裝置中。Cherry Studio 不提供雲端同步服務，也不會將這些資料上傳到我們的伺服器。

* 直接呼叫：本軟體僅作為本機工具，提供呼叫第三方模型服務介面的功能。您的終端裝置會直接與您設定的第三方模型提供商（如 OpenAI、Anthropic 等）伺服器建立網路連線。但您不得利用本軟體製作、複製、發布或傳播任何違反中華人民共和國與您所在國家法律法規、危害國家安全、損害國家榮譽與利益、破壞民族團結、散布謠言、擾亂社會秩序、宣揚淫穢色情或暴力、侵害他人合法權益等違法或不良資訊。

### 四、第三方模型服務提供商隱私政策聲明

由於本軟體使用您自行申請並設定的第三方模型服務提供商 API Key，您在使用 AI 對話功能時，實際上是直接接受該第三方模型服務提供商的服務：

* 您需自行承擔使用第三方模型服務提供商所涉及的隱私與合規風險。

* 各模型提供商（如大型語言模型廠商）會依據自身的隱私政策、資料安全措施等，處理您主動輸入的資料（如對話內容），並可能在其服務範圍內獨立收集其他相關資料。上述處理與收集行為均不受本軟體控制，本軟體【設定】-【一般設定】-【隱私與進階】中的開關也無法關閉這類行為。

* 如果您希望了解或關閉相關資料處理與收集行為，請查閱所選模型服務提供商官方網站的隱私政策，並向其尋求關閉方式。我們對此不承擔任何責任。

### 五、關於第三方服務的特別說明

為方便您管理與處理資料，本軟體在【設定】-【資料設定】中支援部分第三方服務功能，由您透過輸入 API 位址、使用者名稱、密碼等方式，自行選擇設定並使用這些服務：

* 雲端備份設定：WebDAV、S3 相容儲存、堅果雲。

* 第三方連線：Notion、語雀、Joplin、Obsidian、思源筆記。

當您透過本軟體使用上述第三方服務時：

* 您輸入的 API 金鑰、密碼等憑證只在您的裝置本機使用，本軟體不會收集或儲存任何資訊或資料。請自行妥善保管您的憑證。

* 第三方服務由對應服務商獨立營運，其資料處理行為（包括收集、使用、儲存與分享）受該服務商自身的隱私政策與條款約束。我們建議您在連線前仔細閱讀並理解相關服務商的隱私政策與服務條款，合規使用該第三方服務，並自行承擔使用對應服務的一切風險與責任。對於因您使用第三方服務所造成的資料外洩、遺失或違規處理等情況，我們不承擔任何責任。

* 同時請您知悉，上述第三方服務商可能在其服務範圍內獨立收集您的資料，該收集行為不受本軟體控制，本軟體【設定】-【一般設定】-【隱私與進階】中的開關也無法關閉這類收集。如需關閉，請向對應的第三方服務商尋求關閉方式。
