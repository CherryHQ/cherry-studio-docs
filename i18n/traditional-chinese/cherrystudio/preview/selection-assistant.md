# 劃詞助手

劃詞助手會在其他應用程式中選取文字後顯示浮動工具列。你可以直接翻譯、解釋、總結、搜尋或複製所選內容，也可以新增自己的 AI 操作。

{% hint style="info" %}
劃詞助手和[快捷助手](kuai-jie-zhu-shou.md)是兩個獨立功能。劃詞助手處理剛剛選取的文字；快捷助手透過快捷鍵或系統匣開啟主動輸入視窗。
{% endhint %}

## 平台支援

| 平台 | 目前說明 |
| --- | --- |
| macOS | 支援；首次啟用需要授予輔助使用權限 |
| Windows | 支援直接劃詞、Ctrl 鍵觸發和快捷鍵觸發 |
| Linux X11 | 支援主要功能；按鍵監聽可能需要 `input` 群組權限 |
| Linux Wayland | 受桌面環境限制；工具列可能只能置中顯示，應用程式篩選可能不會生效 |

在 Wayland 環境下，設定頁面會檢查 XWayland、`input` 群組權限和桌面合成器相容性。目前環境不相容時，建議改用 X11。

## 啟用劃詞助手

1. 開啟**設定 → 劃詞助手**。
2. 開啟**啟用**。
3. 選擇取詞方式。

尚未啟用時，設定頁面會顯示示範工具列，你可以先確認緊湊模式和操作配置。

### macOS 輔助使用權限

在 macOS 首次啟用時：

1. 在權限提示中點選前往設定。
2. 開啟**隱私權與安全性 → 輔助使用**。
3. 為 Cherry Studio 開啟權限。
4. 返回 Cherry Studio，再次啟用劃詞助手。

如果權限遭到關閉，Cherry Studio 會自動關閉劃詞助手。

### Linux 權限提示

設定頁面顯示尚未取得 `input` 群組權限時，可以執行：

```bash
sudo usermod -aG input $USER
```

完成後需要登出目前的系統工作階段並重新登入。在 Wayland 下可能還需要以 XWayland 模式啟動；請以設定頁面的環境檢查結果為準。

## 選擇取詞方式

| 方式 | 平台 | 行為 |
| --- | --- | --- |
| 劃詞 | macOS、Windows、Linux | 選取文字後立即顯示工具列 |
| Ctrl 鍵 | Windows | 選取文字後按住 Ctrl 才顯示工具列 |
| 快捷鍵 | macOS、Windows | 選取文字後按下已設定的取詞快捷鍵 |

快捷鍵方式需要前往**設定 → 快捷鍵**，為「劃詞助手：取詞」設定並啟用組合鍵。目前沒有預設按鍵。

如果直接劃詞經常誤觸，可以改用 Ctrl 鍵或快捷鍵方式。

## 使用工具列

1. 在支援的應用程式中選取文字。
2. 等待工具列出現，或按下所選的觸發鍵。
3. 點選需要的操作。

工具列左側的 Cherry Studio 圖示是拖曳區域，可以移動整個工具列。開啟**緊湊模式**後，工具列只顯示圖示；將游標移到圖示上仍可查看名稱。

## 內建操作

劃詞助手包含七個內建操作。

| 操作 | 預設狀態 | 行為 |
| --- | --- | --- |
| 翻譯 | 已啟用 | 偵測原文語言，並在目標語言和備用語言之間選擇翻譯目標 |
| 解釋 | 已啟用 | 使用模型解釋所選內容 |
| 總結 | 已啟用 | 使用模型總結所選內容 |
| 搜尋 | 已啟用 | 使用設定的搜尋引擎開啟查詢 |
| 複製 | 已啟用 | 將所選內容寫入剪貼簿 |
| 潤飾 | 未啟用 | 使用模型優化或潤飾所選內容 |
| 引用 | 未啟用 | 將所選內容引用至 Cherry Studio 主視窗輸入框 |

翻譯使用已設定的翻譯模型。解釋、總結、潤飾，以及未指定助手的自訂 AI 操作，均使用預設模型。

{% hint style="warning" %}
劃詞助手的 AI 結果視窗會停用網頁搜尋、MCP 和知識庫。如需使用這些工具，請將內容引用至主視窗後再繼續處理。
{% endhint %}

## 調整操作和順序

在**設定 → 劃詞助手 → 功能**中，上方清單是已啟用操作，下方清單是未啟用操作。

你可以：

* 拖曳操作以調整工具列順序
* 將操作拖到上方以啟用
* 將操作拖到下方以停用
* 重設內建操作的預設順序和狀態

工具列最多可同時啟用 8 個操作，且至少要保留 1 個已啟用操作。重設不會刪除自訂操作，但會將自訂操作移到未啟用區域。

內建操作的提示詞無法在這裡修改；「搜尋」可以另外更換搜尋引擎。

## 新增自訂操作

最多可以建立 10 個自訂操作。

1. 在功能設定中點選新增自訂功能。
2. 輸入操作名稱。
3. 選擇或隨機產生一個 Lucide 圖示。
4. 選擇使用預設模型，或選擇一個助手。
5. 輸入提示詞。
6. 儲存後，將新操作拖到已啟用區域。

提示詞可以使用 `{{text}}` 代表選取的文字。如果沒有填寫佔位符，所選文字會自動附加到提示詞結尾。

選擇「使用助手」時，會同時使用該助手的系統提示詞、模型和模型參數。

## 設定搜尋引擎

1. 在功能清單中找到**搜尋**。
2. 點選右側的設定按鈕。
3. 選擇 Google、百度或 Bing，或者新增自訂搜尋引擎。

自訂 URL 必須：

* 以 `http://` 或 `https://` 開頭
* 包含 `{{queryString}}` 佔位符

執行搜尋時，Cherry Studio 會先對所選文字進行 URL 編碼，再取代佔位符。如果選取的內容本身是 URL 或本機絕對路徑，則會直接嘗試開啟。

## 使用結果視窗

翻譯、解釋、總結、潤飾和自訂 AI 操作會開啟獨立的結果視窗。

你可以在視窗中：

* 顯示或隱藏原文
* 複製原文或模型結果
* 暫停產生
* 重新產生
* 最小化或關閉
* 置頂
* 暫時調整透明度

翻譯視窗還可以直接切換目標語言，並設定目標語言和備用語言。

## 調整視窗行為

你可以在**功能視窗**設定中調整：

| 設定 | 作用 |
| --- | --- |
| 跟隨工具列 | 在工具列附近開啟結果視窗；關閉後會置中顯示 |
| 記住大小 | 在本次應用程式執行期間沿用上次調整的視窗大小 |
| 自動關閉 | 未置頂的結果視窗失去焦點時自動關閉 |
| 自動置頂 | 每次開啟結果視窗時預設置頂 |
| 透明度 | 設定結果視窗的預設不透明度，範圍為 20%–100% |

在結果視窗中手動調整透明度只會影響目前視窗；設定頁面的透明度會套用到之後開啟的視窗。

## 設定應用程式篩選

應用程式篩選可以讓劃詞助手只在指定應用程式中生效，或排除指定的應用程式。

1. 開啟**設定 → 劃詞助手 → 進階**。
2. 選擇白名單或黑名單。
3. 點選編輯，並以每行一個應用程式識別碼的方式填寫。

| 平台 | 填寫內容 | 範例 |
| --- | --- | --- |
| macOS | Bundle ID，可模糊比對 | `com.google.Chrome` |
| Windows | 執行檔名稱，可模糊比對 | `chrome.exe` |

輸入內容會統一轉換為小寫並移除重複項目。在 Wayland 模式下，應用程式篩選可能不會生效。

## 常見問題

### 選取文字後沒有出現工具列

確認功能已啟用、取詞方式正確，並檢查目前的應用程式是否遭篩選規則排除。在 macOS 上還需要檢查輔助使用權限。

### Windows 的 Ctrl 鍵方式沒有反應

部分應用程式或鍵盤對映工具會攔截 Ctrl。請改用直接劃詞或快捷鍵方式，並檢查 AHK 等工具是否重新對應了按鍵。

### Linux 工具列位置不正確

這通常與 Wayland 和 XWayland 的座標差異有關。請查看設定頁面的環境檢查；無法滿足條件時，請切換到 X11。

### AI 操作沒有結果

檢查預設模型或目標助手是否可用。翻譯操作還需要另外設定翻譯模型。

### 引用後沒有看到文字

「引用」會將所選內容傳送到 Cherry Studio 主視窗輸入框。請確認主視窗已開啟，並切換到對話頁面查看。

## 隱私提示

複製操作只會寫入系統剪貼簿；搜尋操作會將查詢傳送給所選搜尋引擎；引用操作會將文字傳送到 Cherry Studio 主視窗。

只有在執行翻譯、解釋、總結、潤飾或自訂 AI 操作時，所選文字才會傳送給相應的模型服務。處理敏感文字前，請確認操作類型和服務商的資料政策。
