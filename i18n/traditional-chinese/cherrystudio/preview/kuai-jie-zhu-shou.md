# 快捷助手

快捷助手是可以從其他應用程式上方叫出的輕量視窗。它適合臨時提問、翻譯、摘要或解釋一段文字，不必先切回 Cherry Studio 主視窗。

{% hint style="info" %}
快捷助手和[劃詞助手](selection-assistant.md)是兩個獨立功能。快捷助手由全域快捷鍵或系統匣叫出；劃詞助手會在選取文字後顯示操作工具列。
{% endhint %}

## 使用前準備

快捷助手會呼叫已設定的模型。啟用前，請先確認至少有一個可用的聊天模型；如果需要使用「文字翻譯」，還應設定翻譯模型。

相關設定請查看[預設模型](settings/default-models.md)。

## 啟用快捷助手

1. 開啟**設定 → 快捷助手**。
2. 開啟**啟用快捷助手**。
3. 選擇是否開啟**點選工具列圖示啟動**。
4. 選擇是否開啟**啟動時讀取剪貼簿**。
5. 在**快捷助手模型**中選擇「使用助手」或「預設模型」。

設定頁下方會顯示快捷助手預覽，可以先用它確認模型和介面是否正常。

### 選擇模型方式

| 方式 | 實際效果 |
| --- | --- |
| 使用助手 | 選擇一個現有助手，並使用其系統提示詞、模型和模型參數 |
| 預設模型 | 不套用特定助手，使用目前預設模型 |

「文字翻譯」使用另外設定的翻譯模型，不會使用此處選取的助手。

{% hint style="warning" %}
快捷助手中的回答、摘要和解釋會停用網頁搜尋、MCP 和知識庫。如果需要這些功能，請使用主視窗中的[對話](chat.md)。
{% endhint %}

## 設定叫出方式

### 全域快捷鍵

1. 開啟**設定 → 快捷鍵**。
2. 找到**快捷助手**。
3. 啟用該快捷鍵。
4. 如有需要，修改按鍵組合。

系統預先填入的組合是：

* macOS：Command + E
* Windows / Linux：Ctrl + E

此快捷鍵預設為關閉狀態。只開啟快捷助手主開關，不會自動啟用全域快捷鍵。

更多說明請查看[快捷鍵設定](settings/key-shortcut.md)。

### 系統匣

開啟**點選工具列圖示啟動**後，按一下 Cherry Studio 系統匣圖示會開啟快捷助手，同時也會啟用系統匣功能。

即使未開啟按一下圖示啟動，只要快捷助手已啟用，也可以在系統匣圖示上按一下滑鼠右鍵，從選單中選擇快捷助手。

## 開啟並執行操作

1. 在任意應用程式中按下已啟用的全域快捷鍵，或使用系統匣入口。
2. 輸入要處理的內容。
3. 選擇一項操作。

| 操作 | 用途 |
| --- | --- |
| 回答此問題 | 將輸入作為一般問題傳送給模型 |
| 文字翻譯 | 選擇目標語言並翻譯輸入內容 |
| 內容總結 | 使用內建摘要指令處理輸入內容 |
| 解釋說明 | 使用內建解釋指令處理輸入內容 |

可以使用向上、向下方向鍵切換操作，按 Enter 執行目前操作。

### 使用剪貼簿內容

開啟**啟動時讀取剪貼簿**後，每次顯示視窗時，快捷助手會嘗試讀取新的純文字剪貼簿內容，並將其顯示為參考文字。

此時可以：

* 直接選擇翻譯、摘要或解釋
* 繼續輸入要求，將剪貼簿文字和要求一起傳送
* 在首頁按 Backspace 清除剪貼簿參考文字

當剪貼簿為空白、內容不是純文字，或系統拒絕讀取權限時，視窗不會取得可用的參考文字。

## 查看結果和繼續提問

回答、摘要和解釋會以串流方式顯示。使用「回答此問題」後，可以在結果頁繼續輸入，形成一段臨時對話。

文字翻譯頁可以更換目標語言，結果會隨設定重新產生。

快捷助手內容是臨時工作階段。返回首頁或關閉視窗後，不應將它視為主視窗中的長期對話記錄。

## 視窗操作

| 操作 | 結果 |
| --- | --- |
| Esc（正在產生） | 暫停目前產生 |
| Esc（結果頁） | 返回快捷助手首頁 |
| Esc（首頁） | 隱藏視窗 |
| C（結果頁） | 複製最近一則模型輸出 |
| 按一下圖釘 | 將視窗保持在最上層，失去焦點時不會自動隱藏 |
| 按一下視窗外部 | 未固定時隱藏快捷助手 |

再次開啟視窗時，會繼續使用目前的模型方式、剪貼簿開關和翻譯目標語言。

## 使用建議

* 需要處理目前複製的一小段文字時，開啟剪貼簿讀取可以節省步驟。
* 經常使用固定語氣或格式時，請選擇一個專用助手。
* 只想快速提問時，使用預設模型可以減少額外設定。
* 處理長文件、附件、網頁搜尋或知識庫資料時，請改用主視窗對話。

## 常見問題

### 按 Command + E 或 Ctrl + E 沒有反應

請確認快捷助手主開關和快捷鍵本身都已啟用。如果快捷鍵由其他應用程式占用，請在快捷鍵設定中改用其他組合。

### 按一下系統匣圖示後沒有開啟

請確認**點選工具列圖示啟動**已開啟，並檢查系統匣區域是否隱藏了 Cherry Studio 圖示。也可以在圖示上按一下滑鼠右鍵，從選單中開啟。

### 按一下視窗外部後，視窗立即消失

這是視窗未固定時的正常行為。如果需要對照其他應用程式內容，請按一下右下角的圖釘。

### 未讀取到剪貼簿

請確認開關已開啟、剪貼簿中是純文字，並檢查系統剪貼簿權限。複製新內容後，再次叫出視窗。

### 翻譯沒有結果

「文字翻譯」使用翻譯模型。請檢查預設模型設定中的翻譯模型、服務商狀態和 API 設定。

### 助手中的知識庫或 MCP 沒有生效

快捷助手會主動關閉網頁搜尋、MCP 和知識庫。請在主視窗中使用該助手。

## 隱私權提示

開啟剪貼簿讀取後，快捷助手會在視窗顯示時讀取純文字剪貼簿。只有執行回答、翻譯、摘要或解釋後，相應文字才會隨要求傳送給所選模型服務。

處理密碼、金鑰或其他敏感內容前，請先清除剪貼簿參考文字，或關閉**啟動時讀取剪貼簿**。
