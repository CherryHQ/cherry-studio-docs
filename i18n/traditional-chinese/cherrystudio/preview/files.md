# 檔案

檔案頁面用於查看和清理 Cherry Studio 檔案索引中的內容，例如對話附件、貼上的圖片，以及部分由應用程式產生或儲存的檔案。

它不是電腦中的通用檔案管理器，也不會自動顯示磁碟上的所有檔案。

{% hint style="info" %}
知識庫的資料來源由知識庫頁面個別管理，不一定會顯示在這裡。如需更新、重新索引或刪除知識庫資料，請前往[知識庫](knowledge-base.md)。
{% endhint %}

## 開啟檔案頁面

1. 按一下視窗頂部標籤列右側的 **+**，開啟新的啟動台標籤頁。
2. 在啟動台按一下**檔案**。

頁面左側是類型篩選，右側是目前分類中的檔案。

## 查看和篩選檔案

左側提供四個分類：

| 分類 | 顯示內容 |
| --- | --- |
| 文件 | 識別為文件的檔案 |
| 圖片 | 圖片檔案 |
| 文字 | 純文字或文字類檔案 |
| 所有檔案 | 檔案索引中的全部內容 |

頁面預設會開啟**文件**分類。切換分類時，目前的多選狀態會清除。

### 排序

可以依照下列欄位排序：

* 建立時間
* 大小
* 檔名

第一次按一下某個欄位會依降冪排列；再次按一下相同欄位，會切換為升冪。

### 檔案資訊

文件、文字和「所有檔案」會以清單顯示。每個項目包含檔名、副檔名、建立時間、計數和檔案大小。

圖片分類會使用縮圖網格，方便快速瀏覽。

## 開啟或預覽

### 文件和文字

按一下清單中的檔名，Cherry Studio 會呼叫系統為該格式設定的預設應用程式開啟檔案。

如果檔案已移動、磁碟權限不足，或系統沒有可用的預設應用程式，開啟操作可能會失敗。

### 圖片

按一下圖片縮圖會開啟圖片檢視器。你可以在檢視器中切換目前分類中的其他圖片。

## 重新命名檔案

在文件、文字或「所有檔案」清單中：

1. 找到目標檔案。
2. 按一下該列右側的編輯按鈕。
3. 輸入新名稱並確認。

如果新名稱未包含原始副檔名，Cherry Studio 會自動保留原始副檔名。

{% hint style="warning" %}
重新命名只會變更 Cherry Studio 顯示和管理的檔名，不會修改檔案內容。
{% endhint %}

## 刪除單一檔案

### 文件和文字

按一下檔案列右側的刪除按鈕，然後在確認方塊中確認。

### 圖片

將滑鼠移到圖片縮圖上，按一下右上角的刪除按鈕，然後確認。

刪除時會同時清除檔案及其在訊息中的附件引用。此操作無法在 Cherry Studio 中復原。

如果圖片仍由繪畫記錄使用，Cherry Studio 會阻止刪除並顯示提示。需要先在繪畫中處理相關記錄。

## 批次刪除

批次操作適用於文件、文字和「所有檔案」分類；圖片分類不提供批次選擇。

1. 勾選要刪除的檔案，或按一下右上角的**全選**。
2. 開啟批次操作選單。
3. 選擇**批次刪除**並確認。

{% hint style="warning" %}
批次刪除也會移除這些檔案在訊息中的附件引用。執行前，請確認重要檔案已有獨立備份。
{% endhint %}

## 哪些檔案會顯示在這裡

通常會看到：

* 在對話中上傳或貼上，並儲存至應用程式檔案目錄的內容
* 聊天過程中產生並寫入檔案索引的圖片或其他結果
* 由舊版 Cherry Studio 檔案流程登記的本機檔案

下列內容不一定會顯示：

* 電腦磁碟中從未新增至 Cherry Studio 的檔案
* 只儲存在外部服務商伺服器上的檔案
* 由新版知識庫資料來源個別管理的原始資料
* 已從檔案索引中刪除的內容

如要在聊天中新增附件，請前往[對話](chat.md)，使用輸入框中的附件按鈕或直接拖入檔案。

## 儲存位置

檔案內容儲存在 Cherry Studio 的應用程式資料目錄中。建議透過**設定 → 資料設定 → 資料目錄**查看或移轉；請勿在應用程式執行時，手動移動、重新命名或刪除目錄中的內部檔案。

具體位置和移轉方法請查看[修改儲存位置](../../personalization-settings/storage.md)。

## 常見問題

### 刪除檔案後，舊訊息中的附件不見了

這是目前刪除行為的一部分：刪除檔案時，對應的訊息附件引用也會移除。如果需要保留歷史附件，請勿從檔案頁面刪除原始檔案。

### 找不到匯入知識庫的資料

知識庫使用自己的資料來源和索引管理流程。請在知識庫詳細資料頁面查看、重新索引或刪除資料。

### 按一下檔名沒有反應

請確認檔案仍然存在，並檢查系統是否已為該副檔名設定預設應用程式。如果曾手動移動應用程式資料目錄，也可能導致原始路徑失效。

### 無法刪除某張圖片

該圖片可能仍由繪畫記錄使用。請先開啟繪畫頁面處理相關記錄，再返回檔案頁面刪除。
