# 筆記

筆記是 Cherry Studio 內建的 Markdown 工作區。每篇筆記都會儲存為本機 `.md` 檔案，適合整理對話結果、撰寫草稿，以及維護其他 Markdown 工具也能讀取的資料。

{% hint style="info" %}
筆記不會自動成為聊天上下文。如果需要讓模型檢索筆記內容，可以將目標筆記匯出至[知識庫](knowledge-base.md)。
{% endhint %}

## 開啟筆記

1. 按一下視窗頂部標籤列右側的 **+**，開啟新的啟動台標籤頁。
2. 在啟動台按一下**筆記**。

頁面左側是筆記和資料夾，右側是目前筆記的編輯區。

## 建立第一篇筆記

1. 按一下左側頂部的**新增筆記**按鈕。
2. 在頁面頂部輸入筆記名稱。
3. 在編輯區輸入內容。

內容修改後會自動儲存至目前的 Markdown 檔案。切換筆記或離開頁面時，Cherry Studio 也會嘗試儲存尚未寫入的修改。

{% hint style="warning" %}
如果筆記檔案讀取失敗，編輯器會阻止寫入，避免用空白內容覆寫原始檔案。看到讀取或儲存錯誤時，請先檢查工作目錄和檔案權限。
{% endhint %}

## 使用資料夾整理筆記

按一下左側頂部的**新增資料夾**，可以在根目錄或目前選取的資料夾中建立目錄。

你還可以：

* 展開或收合資料夾
* 將筆記或資料夾拖入另一個資料夾
* 在資料夾上按一下滑鼠右鍵，建立子筆記或子資料夾
* 直接編輯頁面頂部的標題，重新命名目前筆記
* 在目錄樹中，以右鍵選單重新命名筆記或資料夾

筆記工作區只會讀取 Markdown 檔案，不會顯示隱藏檔案。

## 匯入現有 Markdown

可以使用下列方式匯入：

* 將 `.md` 檔案拖至左側目錄樹
* 將包含 Markdown 檔案的資料夾拖至左側目錄樹
* 在左側空白處按一下滑鼠右鍵，選擇上傳檔案或上傳資料夾
* 在空白筆記工作區按一下匯入提示，選擇一個資料夾

匯入資料夾時，系統會盡量保留原始目錄結構。其他格式會略過，匯入完成後會顯示成功、略過或失敗的數量。

## 編輯和閱讀

編輯器底部可以切換三種模式：

| 模式 | 適用情境 |
| --- | --- |
| 即時預覽 | 使用工具列編輯，同時查看 Markdown 的排版效果 |
| 原始碼模式 | 直接編輯 Markdown 原始碼 |
| 閱讀模式 | 只閱讀轉譯後的內容 |

即時預覽模式的工具列提供常用格式，例如標題、粗體、斜體、清單、引用、程式碼和表格。筆記編輯器目前不提供圖片和行內公式插入命令。

底部還會顯示字元數。在即時預覽模式中，可以按一下拼字檢查按鈕以開啟或關閉檢查。

### 頁面顯示

按一下右上角的更多選單，可以：

* 複製目前筆記內容
* 快速匯出為 Word
* 限制正文寬度
* 顯示或隱藏目錄大綱
* 切換預設字型或襯線字型
* 選擇小、中、大三種字級
* 開啟完整筆記設定

在完整設定中，還可以設定預設檢視、預設編輯模式、10–30 px 字級和目錄大綱。

## 搜尋和收藏

### 搜尋

按一下左側頂部的搜尋按鈕並輸入關鍵字。搜尋會同時比對：

* 筆記名稱
* 筆記正文

比對到正文時，結果會顯示比對類型和相關行。按一下相符內容可以開啟筆記並跳至對應位置。

### 收藏

開啟筆記後，可以按一下頂部的星號按鈕加入收藏。左側頂部的收藏入口只會顯示已收藏的筆記。

### 排序

目錄支援六種排序方式：

* 名稱從 A 到 Z
* 名稱從 Z 到 A
* 更新時間從新到舊
* 更新時間從舊到新
* 建立時間從新到舊
* 建立時間從舊到新

資料夾一律排列在同一層級的筆記之前。

## 右鍵選單

### 筆記

在筆記上按一下滑鼠右鍵，可以：

* 使用模型依照正文產生筆記名稱
* 重新命名
* 從外部開啟
* 收藏或取消收藏
* 匯出至知識庫
* 匯出為已啟用的格式
* 刪除

自動產生名稱需要可用的模型設定。匯出至知識庫前，需要先建立至少一個知識庫。

### 資料夾

在資料夾上按一下滑鼠右鍵，可以建立子筆記或子資料夾、重新命名、從外部開啟或刪除。

{% hint style="warning" %}
刪除資料夾時，其中的筆記也會一併刪除。刪除前，請確認目標目錄已完成備份。
{% endhint %}

## 匯出筆記

筆記右鍵選單中的匯出選項可能包括：

* 複製為圖片或匯出為圖片
* Markdown
* Word
* Notion
* 語雀
* Obsidian
* Joplin
* 思源

實際顯示的項目由**設定 → 資料設定 → 匯出選單**控制。頂部更多選單中的「匯出為 Word」是目前筆記的快速入口。

## 搭配對話和知識庫使用

### 從對話儲存到筆記

對話訊息和話題的匯出選單，可以將內容儲存至筆記工作目錄。是否顯示此選項取決於匯出選單設定。

### 將筆記加入知識庫

1. 先建立一個知識庫。
2. 在筆記目錄樹中的目標筆記上按一下滑鼠右鍵。
3. 選擇**匯出筆記到知識庫**。
4. 選擇目標知識庫並確認。
5. 等待知識庫完成索引，再於聊天中選擇該知識庫。

原始筆記和知識庫中的副本是兩個獨立資料來源。日後修改筆記後，需要再次匯出，或在知識庫中更新資料。

## 工作目錄與備份

開啟右上角的更多選單，進入**更多設定 → 資料設定**，可以查看目前筆記工作目錄、選擇其他目錄或恢復預設目錄。

{% hint style="warning" %}
切換工作目錄只會變更 Cherry Studio 目前讀取的位置，不會自動移轉舊目錄中的 Markdown 檔案。切換前，請手動複製或備份原始目錄。
{% endhint %}

筆記是一般 Markdown 檔案，可以使用檔案同步、版本控制或備份軟體加以保護。使用自訂工作目錄時，應另外備份該目錄，不要只依賴 Cherry Studio 的應用程式設定備份。

跨系統復原後，如果原始路徑不存在，Cherry Studio 會返回預設筆記目錄。此時需要將舊筆記手動複製到新目錄，或在設定中重新選擇有效目錄。

## 常見問題

### 新增筆記後沒有儲存

請檢查工作目錄是否存在且可寫入。如果目前檔案讀取失敗，Cherry Studio 會暫停儲存，以保護原始內容。

### 匯入後缺少部分檔案

筆記工作區只會匯入 `.md` 檔案。請檢查略過的檔案是否使用 `.md` 副檔名。

### 搜尋不到剛修改的內容

請等待自動儲存完成後再搜尋。如果檔案位於同步磁碟，也要確認外部同步未占用或覆寫檔案。

### 切換電腦後筆記為空白

筆記正文儲存在工作目錄中，而不是只儲存在設定中。請將原始目錄中的 Markdown 檔案複製到新電腦，並在筆記設定中選擇該目錄。
