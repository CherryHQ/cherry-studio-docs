# 助手庫

助手庫是 Cherry Studio 的對話助手預設市集。預設主要儲存名稱、圖示、提示詞和部分預設設定；將預設新增到對話後，它會成為一個可獨立編輯的助手。

{% hint style="warning" %}
助手庫中的「助手」用於角色對話，不等同於 [Cherry Agent 智能體](../../advanced-basic/agent.md)。如果需要存取工作區、讀寫檔案、執行命令或連續呼叫工具，請使用智能體。
{% endhint %}

## 助手庫、對話助手和資源庫

| 名稱 | 用途 |
| --- | --- |
| 助手庫 | 瀏覽內建預設、維護自己的預設，以及匯入或訂閱預設來源 |
| 對話助手 | 已新增到[對話頁](chat.md)的可用助手；擁有自己的話題和設定 |
| [資源庫](library.md) | 集中建立和編輯模型、助手、智能體等資源；適合進行完整設定 |

從助手庫新增預設時，Cherry Studio 會複製一份新的對話助手。之後修改或刪除原始預設，不會自動變更已建立的助手。

## 開啟助手庫

可以透過下列入口開啟：

* **啟動台 → 助手庫**。
* 對話頁助手列表中的新增按鈕。

如果只想快速增加一個助手，從對話頁的新增入口搜尋預設會更快；如果需要瀏覽分類、匯入、訂閱或批次管理，請進入完整的助手庫。

## 瀏覽和搜尋預設

助手庫左側依照「我的」和用途分類整理預設，主區域會顯示目前分類中的卡片。

* **分類**：查看目前內建或訂閱來源提供的分類。
* **搜尋**：依照名稱和描述跨分類尋找預設。
* **卡片預覽**：查看名稱、說明和提示詞摘要。
* **我的**：查看自己建立或匯入的預設。

分類和數量會隨應用程式版本、目前語言或訂閱來源而變化，因此本文件不列出固定清單。

## 從預設建立對話助手

1. 找到需要的預設。
2. 按一下卡片，查看提示詞和說明。
3. 選擇 **新增到助手**。
4. 返回[對話頁](chat.md)。
5. 在助手列表中選擇剛新增的助手，並在頂部選擇模型。

新增後，助手會擁有獨立 ID 和預設話題。你可以繼續修改提示詞、模型、知識庫、MCP 和模型參數，而不影響助手庫中的原始預設。

## 建立自己的助手

有兩種方式，分別適合不同需求。

### 在助手庫建立輕量預設

按一下 **建立助手**，填寫：

* **名稱**：用於搜尋和識別。
* **Emoji**：助手圖示；未選擇時，系統會嘗試從名稱中擷取。
* **提示詞**：定義角色、目標、界線和輸出方式。
* **知識庫**：選填；關聯已建立的知識庫。

名稱和提示詞不可留空。提示詞編輯區可以呼叫預設助手模型進行最佳化，也可以復原本次 AI 改寫。

儲存後，預設會顯示在「我的」中。如要在對話中使用，還需要按一下該預設並選擇 **新增到助手**。

### 在資源庫建立完整助手

如果需要一次設定模型、標籤和進階參數，建議前往[資源庫](library.md)建立助手。完整編輯器包含：

* 名稱、Emoji、描述、標籤和模型。
* 系統提示詞。
* Temperature、Top P、最大輸出、上下文數量和串流輸出。
* 工具呼叫模式、最大工具呼叫次數和自訂參數。
* 知識庫。
* MCP 模式和伺服器。

完整編輯器仍要求填寫名稱和提示詞。沒有明確需求時，模型參數保留預設值即可。

## 如何決定模型

透過助手庫建立或匯入輕量預設時，Cherry Studio 會使用目前的[預設助手模型](settings/default-models.md)作為預設模型。新增到對話後，可以在對話頂部切換模型。

透過資源庫建立完整助手時，可以在儲存前直接選擇模型。

模型設定不應寫入系統提示詞。如果需要更換模型，請使用模型選擇器，以便檢查服務商和實際模型 ID。

## 匯入助手預設

按一下 **匯入**，選擇下列其中一種方式：

### 從 URL 匯入

1. 選擇 **URL**。
2. 貼上可以直接傳回 JSON 的位址。
3. 按一下匯入。

### 從檔案匯入

1. 選擇 **檔案**。
2. 選擇 `.json` 檔案。
3. 按一下匯入。

匯入內容可以是一個物件或物件陣列。每個預設至少需要 `name` 和 `prompt`：

```json
[
  {
    "name": "文件審閱助手",
    "emoji": "📝",
    "description": "檢查結構、術語和可執行性",
    "prompt": "你負責審閱產品文件，並提出具體修改建議。"
  }
]
```

匯入時會為每個預設產生新的本機 ID，並使用目前的預設助手模型。來源檔案中的舊話題和訊息不會作為對話記錄匯入。

{% hint style="warning" %}
只匯入可信任的來源。預設提示詞可能包含隱藏目標、外部連結或不適合你的行為要求；新增到對話前，應先檢查提示詞。
{% endhint %}

## 訂閱助手來源

訂閱適合由團隊或社群維護一組遠端預設：

1. 按一下 **匯入**。
2. 在訂閱區域填寫可以直接傳回 JSON 陣列的 HTTP(S) 位址。
3. 按一下 **訂閱**。
4. Cherry Studio 重新載入後，會從該位址讀取系統預設。

訂閱來源可用時，會作為系統預設來源。遠端讀取失敗時，Cherry Studio 會回復使用應用程式內建預設。取消訂閱後，也會恢復使用內建預設。

訂閱與單次匯入的差異：

| | 單次匯入 | 訂閱 |
| --- | --- | --- |
| 資料位置 | 匯入為本機「我的」預設 | 啟動或重新載入時從遠端來源讀取 |
| 後續更新 | 不會自動變更 | 遠端來源更新後，可在重新載入時更新 |
| 是否適合本機修改 | 適合 | 建議由訂閱來源統一維護 |

詳細格式和維護方式請參閱[助手訂閱](../../data-settings/assistants-subscribe.md)。

## 管理「我的」預設

在「我的」分類中，可以透過卡片選單或 **管理助手** 執行下列操作：

* 編輯預設。
* 新增為對話助手。
* 將單一預設匯出為 JSON。
* 刪除預設。
* 拖曳以調整順序。
* 批次選擇、匯出或刪除。

批次匯出的 JSON 可以在其他裝置再次匯入。刪除預設前，請確認是否仍需要使用它來建立新助手；已新增到對話的助手不會隨預設一起刪除。

## 修改已新增的助手

預設新增到對話後，請在對話助手設定或資源庫中修改。常見設定包括：

* 系統提示詞。
* 目前和預設模型。
* 知識庫與網路搜尋。
* MCP 工具。
* 上下文和輸出參數。

完整對話操作請參閱[對話介面](chat.md)。

## 助手還是智能體

| 需求 | 建議 |
| --- | --- |
| 固定角色的問答、寫作、翻譯或分析 | 對話助手 |
| 重複使用和分享提示詞範本 | 助手庫預設 |
| 集中編輯模型、參數、知識庫和 MCP | 資源庫中的助手編輯器 |
| 存取工作區、讀寫檔案、執行命令 | [智能體](../../advanced-basic/agent.md) |
| 排程執行並向外部頻道傳送結果 | 智能體 + [排程任務](../../advanced-basic/scheduled-tasks.md) + [頻道](../../advanced-basic/agent-channels.md) |

如果遇到匯入失敗、無法讀取訂閱來源或預設異常，請透過[意見回饋與建議](../../question-contact/suggestions.md)提供 JSON 範例、位址傳回狀態和錯誤資訊；提交前請移除隱私資料或金鑰。
