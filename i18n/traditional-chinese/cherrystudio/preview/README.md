# 功能一覽

Cherry Studio V2 將多模型對話、智能體、內容創作、知識管理和自動化工具整合在同一個桌面工作空間。本頁可協助你快速判斷應該進入哪個模組；如需具體操作步驟，請繼續閱讀各功能的獨立教學。

## 如何找到功能

Cherry Studio 有三種常用入口：

* **啟動台**：集中開啟應用程式模組和已固定的小程式。
* **左側欄**：放置你經常使用的模組。可以在設定中調整要顯示哪些圖示。
* **頂部標籤列**：每次開啟功能或內容時都會建立標籤頁，方便在多個任務之間切換。

如果還不熟悉介面，請先閱讀[啟動台](launchpad.md)。

## 對話助手和智能體有什麼不同

兩個模組都可以使用模型，但著重點不同：

| | 對話助手 | 智能體 |
| --- | --- | --- |
| 適用情境 | 問答、寫作、分析和固定角色對話 | 需要讀寫檔案、呼叫工具或連續執行的任務 |
| 核心設定 | 提示詞、模型、知識庫、MCP | 工作區、權限、技能、工具、最大輪數 |
| 執行方式 | 以訊息往返為主 | 圍繞目標自主規劃並執行多步操作 |
| 風險控制 | 主要控制傳送給模型的內容 | 還需要控制檔案和命令權限 |

如果只需要討論和產生內容，請先使用對話助手。當任務需要存取本機工作區或執行操作時，再使用智能體。

## 常見工作流程

### 第一次使用

1. 在[模型服務](../../pre-basic/providers/)中新增服務商和模型。
2. 開啟[對話](chat.md)，傳送一則測試訊息。
3. 從[助手庫](agents.md)新增常用助手。
4. 在[資料設定](../../data-settings/)中設定備份。

### 根據資料進行問答

1. 在[知識庫](knowledge-base.md)中建立知識庫。
2. 匯入檔案、網址或其他支援的資料來源。
3. 等待資料處理完成。
4. 在對話中選擇知識庫後提問。

### 執行專案任務

1. 在[資源庫](library.md)中建立智能體。
2. 選擇模型、權限模式、技能和工具。
3. 開啟智能體並確認工作區。
4. 以清楚的目標開始任務，執行期間檢查權限要求和檔案變更。

### 隨時呼叫 AI

* 使用[快捷助手](kuai-jie-zhu-shou.md)，不必切換目前的應用程式即可提問。
* 使用[劃詞助手](selection-assistant.md)翻譯、摘要或改寫已選取的文字。

## 自動化與外部接入

當基本功能不足以涵蓋你的工作流程時，可以繼續使用：

* [MCP](../../advanced-basic/mcp/)：為對話助手連接外部工具和資料。
* [API 伺服器](../../advanced-basic/api-server.md)：透過相容介面呼叫本機 Cherry Studio 功能，也是 V2 智能體執行鏈路的一部分。
* [頻道](../../advanced-basic/agent-channels.md)：將智能體接入支援的訊息頻道。
* [排程任務](../../advanced-basic/scheduled-tasks.md)：依照時間觸發智能體工作階段。

{% hint style="info" %}
請先完成模型服務和資料備份，再逐步啟用智能體、MCP、頻道或排程任務。涉及檔案寫入、命令執行和外部傳送時，應使用足以完成任務的最低權限。
{% endhint %}
