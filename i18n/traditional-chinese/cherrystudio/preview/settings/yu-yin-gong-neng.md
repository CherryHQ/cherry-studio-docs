# 語音功能

{% hint style="warning" %}
Cherry Studio V2 社群版目前沒有內建的語音輸入、文字轉語音或即時語音通話功能。舊版文件中出現過的 TTS、ASR 和語音通話設定並未進入目前的 `main` 版本，請勿依照舊教學進行設定。
{% endhint %}

## 目前狀態

目前的設定頁面中沒有 **語音功能** 入口，聊天輸入區也沒有內建的錄音或語音通話按鈕。

以下能力目前不屬於 Cherry Studio V2 社群版的可用功能：

- 將 AI 回覆自動朗讀為語音（TTS）
- 使用麥克風將說話內容轉換為輸入文字（ASR / STT）
- 在浮動視窗中進行即時語音對話
- 設定語音服務供應商、音色、語速或語音辨識模型
- 為按住說話設定專用快速鍵

因此，你不需要為這些功能填寫 OpenAI、SiliconFlow 或其他語音服務的 API 金鑰，也不會在 **設定** 中找到對應選項。

## 音訊附件不等於語音輸入

Cherry Studio 可以辨識常見的音訊檔案類型，並允許在支援的情境中將檔案作為附件處理。但能否理解音訊內容取決於所選模型、服務供應商協定和模型能力。

上傳音訊檔案與應用程式內的語音功能有本質上的差異：

| 情境 | 目前狀態 |
| --- | --- |
| 上傳現有音訊檔案，交由支援音訊輸入的模型處理 | 取決於模型與服務供應商 |
| 直接使用麥克風錄音並轉寫到輸入框 | 暫不支援 |
| 自動朗讀模型回覆 | 暫不支援 |
| 與模型進行連續語音通話 | 暫不支援 |

如果模型選擇器或服務供應商沒有明確標示音訊輸入能力，請勿假定它可以處理音訊附件。

## 可用的替代方式

需要語音輸入時，可以先使用作業系統內建的聽寫功能或其他轉寫工具，將語音轉換為文字後貼到 Cherry Studio。具體的可用性、快速鍵和隱私策略由作業系統或所用工具決定。

需要朗讀回覆時，可以使用作業系統的輔助功能或外部文字朗讀工具。Cherry Studio 不會管理這些工具的音色、語速、音訊儲存或網路請求。

{% hint style="info" %}
使用第三方聽寫、轉寫或朗讀服務前，請先確認其資料處理與隱私政策。請勿將敏感對話傳送給不受信任的服務。
{% endhint %}

## 如何確認未來版本是否支援

如果語音相關功能重新進入社群版，應同時出現可存取的介面入口和正式的發行說明。請以目前版本的 **設定** 頁面和 [GitHub Releases](https://github.com/CherryHQ/cherry-studio/releases) 為準，請勿只根據舊截圖或歷史 PR 判斷。

如果目前安裝的版本出現了本文未提及的語音入口，請先確認版本號和安裝來源，再透過[意見回饋與建議](../../../question-contact/suggestions.md)提交介面截圖與重現資訊。
