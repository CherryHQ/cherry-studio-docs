# 一般設定

Cherry Studio V2 的一般設定分為四個頁面：

1. **顯示與語言**
2. **系統與啟動**
3. **隱私與進階**
4. **自訂 CSS**

進入：

> **設定 → 一般設定**

本頁說明各項設定的作用、相依關係和需要重新啟動的情境。

## 顯示與語言

### 介面語言

目前應用程式可選擇：

- 簡體中文
- 繁體中文
- English
- Deutsch
- 日本語
- Русский
- Ελληνικά
- Español
- Français
- Português
- Română
- Tiếng Việt

切換後介面會立即更新。第三方模型名稱、服務商傳回的錯誤、助理內容和使用者自訂文字不會自動翻譯。

{% hint style="info" %}
應用程式介面支援的語言數量與社群文件發布語言不是同一個概念。目前社群文件以簡體中文、繁體中文、English、日本語、Русский 維護。
{% endhint %}

### 主題與主色

主題可以選擇：

- 淺色
- 深色
- 跟隨系統

主色用於按鈕、選取狀態和部分強調元素。如果自訂 CSS 同時修改主題變數，最終效果可能覆寫主色設定。

### 透明視窗

macOS 會顯示透明視窗開關。它控制系統材質和視窗背景效果；其他平台不會顯示此項目。

如果透明效果導致文字對比度低、視窗閃爍或螢幕截圖不清楚，可以切回不透明視窗。

### 使用系統標題列

Linux 會顯示系統標題列開關。變更後，應用程式會要求確認並重新啟動。

系統標題列有助於相容部分桌面環境和視窗管理器，但外觀會與 Cherry Studio 內建標題列不同。

### 介面縮放

可以按 `10%` 級距放大或縮小，也可以還原預設縮放。

縮放會影響整個設定視窗和主介面的視覺尺寸。擷取螢幕截圖或排查版面配置問題時，應記錄縮放比例；非 `100%` 縮放可能讓相同視窗尺寸呈現不同內容。

### 全域字型與程式碼字型

可以從系統字型中分別選擇：

- 全域介面字型；
- 程式碼區塊和編輯器字型。

選擇清單來自目前作業系統。另一台裝置沒有相同字型時，介面會回復為預設字型。

更完整的外觀說明請參閱[顯示設定](display.md)和[字型設定](../../../personalization-settings/font.md)。

### 話題清單

話題清單支援：

- 顯示在左側或右側；
- 顯示話題時間；
- 將固定話題置頂。

當話題清單位於左側時，還可以開啟**點選助理後自動切換到話題清單**。清單位於右側時，這個開關不會顯示。

## 系統與啟動

### 開機自動啟動

開啟後，Cherry Studio 會嘗試在系統登入時啟動。

如果未生效，請檢查：

- 系統是否允許登入項目或自動啟動應用程式；
- 安全軟體是否攔截；
- 應用程式是否已移動或重新安裝；
- 目前使用者是否有權限修改登入項目。

### 啟動時最小化到系統匣

開啟後，應用程式啟動時不會直接顯示主視窗。

此設定依賴系統匣功能：開啟它時，Cherry Studio 會自動開啟**顯示系統匣圖示**。

### 顯示系統匣圖示

系統匣選單可用於顯示主視窗、開啟快捷助理或結束應用程式。關閉系統匣圖示時：

- **啟動時最小化到系統匣**會同時關閉；
- **關閉視窗時最小化到系統匣**會同時關閉。

這樣可以避免視窗隱藏後沒有入口可重新開啟。

### 關閉視窗時最小化到系統匣

開啟後，點選視窗關閉按鈕只會隱藏主視窗，Cherry Studio 程序仍在背景執行。

若要完全結束，應使用系統匣選單中的結束命令。關閉此開關後，視窗關閉行為會依系統和應用程式結束邏輯執行。

{% hint style="warning" %}
背景執行可能會讓正在進行的任務、頻道或排程任務繼續運作。需要停止所有執行時，不要只關閉視窗，應確認應用程式已結束。
{% endhint %}

## 代理設定

代理模式包括：

| 模式 | 行為 |
| --- | --- |
| 系統代理 | 使用作業系統目前的代理設定 |
| 自訂代理 | 使用 Cherry Studio 中填寫的代理位址和略過規則 |
| 不使用代理 | 不主動使用代理 |

### 自訂代理位址

可以填寫有效的 HTTP、HTTPS 或 SOCKS 代理 URL，例如：

```text
socks5://127.0.0.1:6153
```

實際通訊協定和連接埠必須與本機代理程式一致。如果代理需要驗證，請依代理程式支援的 URL 格式設定，並避免在螢幕截圖或意見回饋中暴露使用者名稱和密碼。

輸入無效位址時，Cherry Studio 會拒絕儲存。

### 代理略過規則

略過規則讓特定位址直接連線，不經過自訂代理。適合：

- `localhost` 和 `127.0.0.1`；
- 區域網路模型服務；
- 本機 SearXNG、Ollama 或 LM Studio；
- 不應經過代理的企業內部網域。

規則格式應參考設定項目提示。錯誤的略過規則可能導致本機服務使用代理，或讓外部服務略過代理後連線失敗。

### 代理疑難排解

模型服務逾時時，不要只反覆切換代理模式。請依序檢查：

1. 瀏覽器或終端機是否能存取服務商；
2. 代理程式是否正在監聽設定的連接埠；
3. Cherry Studio 的代理模式和位址是否正確；
4. 目標網域是否被略過規則誤判；
5. 本機服務是否應使用直接連線；
6. 修改代理後是否需要重新開啟視窗或重新啟動應用程式。

## 停用硬體加速

Electron 預設使用硬體加速轉譯介面。只有出現以下問題時，才建議開啟**停用硬體加速**：

- 黑畫面或白畫面；
- 視窗閃爍；
- 字型或圖像轉譯異常；
- 特定顯示卡驅動程式導致當機。

變更後，應用程式會要求確認並重新啟動。

停用硬體加速可能降低捲動、動畫和複雜介面的流暢度。它不是所有效能問題的通用解決方案。

## 拼字檢查

啟用後，輸入框會使用 Electron 的拼字檢查功能標示可能拼錯的單字。

在 Windows 和 Linux 上，還可以選擇檢查語言，包括英語、西班牙語、法語、德語、義大利語、葡萄牙語、俄語、荷蘭語、波蘭語、斯洛伐克語和希臘語。

macOS 使用系統提供的拼字檢查行為，因此介面不顯示相同的多語言選擇器。

拼字檢查只影響本機輸入提示，不會呼叫模型修正文案，也不會變更已傳送的訊息。

## 通知

可以分別控制：

| 通知 | 觸發情境 |
| --- | --- |
| 助理訊息 | 助理回答完成等訊息事件 |
| 備份 | 備份流程完成或產生結果 |
| 知識庫 | 知識庫嵌入或索引任務完成 |

即使應用程式內開關已開啟，作業系統仍可能阻止通知。請在系統通知設定中允許 Cherry Studio，並檢查專注模式或勿擾模式。

通知只表示任務產生了結果，不代表結果一定成功。備份和知識庫任務仍應查看最終狀態和錯誤資訊。

## 匿名錯誤報告和資料統計

**匿名傳送錯誤報告和資料統計**用於控制應用程式的資料收集開關。

是否開啟由使用者自行決定。若要了解收集範圍、保留方式和第三方處理規則，應查看目前版本顯示的隱私說明及專案正式隱私權政策；不要只依開關名稱推斷所有資料類別。

關閉此開關不會阻止使用者主動傳送意見回饋，也不會阻止已設定的模型服務、網路搜尋、MCP 或外部整合依功能需求傳輸資料。

## 開發者模式

開發者模式用於開啟供偵錯或開發使用的功能。

一般使用者可以保持關閉。需要排查問題時，可以依開發者或維護者指示暫時開啟；完成後再關閉。

開發者模式不會自動修復連線問題，也不會讓模型獲得額外能力。偵錯介面和記錄可能包含對話、路徑、請求參數或服務資訊，分享前必須進行遮蔽處理。

## 自訂 CSS

一般設定內建 CSS 編輯器，可以直接覆寫應用程式樣式。

適合調整：

- 字級與間距；
- 顏色和圓角；
- 特定元件的顯示方式；
- 社群主題。

有關編寫、還原和清除方法，請參閱[自訂 CSS](../../../personalization-settings/css.md)和[清除 CSS](../../../personalization-settings/clear-css.md)。

{% hint style="danger" %}
錯誤 CSS 可能隱藏按鈕、讓文字無法顯示或破壞版面配置。貼上第三方主題前，請先閱讀程式碼並備份現有 CSS；如果設定入口無法操作，可以依清除 CSS 文件還原。
{% endhint %}

Cherry Studio 更新後，內部類別名稱和結構可能變更，舊 CSS 不保證長期相容。

## 建議檢查順序

### 新使用者

1. 選擇介面語言；
2. 選擇淺色、深色或跟隨系統；
3. 保持 `100%` 縮放；
4. 依需要開啟開機啟動和系統匣；
5. 先使用系統代理，只有明確需要時才改為自訂代理；
6. 保持硬體加速啟用；
7. 依需要開啟通知。

### 發生網路問題

1. 檢查服務商 Key 和位址；
2. 檢查系統或自訂代理；
3. 檢查略過規則；
4. 使用相同網路測試服務商官方位址；
5. 重新啟動應用程式後再次測試。

### 發生顯示問題

1. 還原 `100%` 縮放；
2. 切換到預設主題與預設字型；
3. 暫時清空自訂 CSS；
4. 關閉透明視窗；
5. 最後再嘗試停用硬體加速並重新啟動。

## 常見問題

### 文件只有五種語言，為什麼應用程式中更多

應用程式本身和社群文件是兩套語言涵蓋範圍。應用程式目前提供十二種介面語言；本社群文件目前維護五種語言。

### 儲存自訂代理後仍無法連線

確認 URL 包含通訊協定，例如 `http://` 或 `socks5://`，連接埠正確、代理程式正在執行，並檢查目標網域是否被略過。

### 關閉視窗後應用程式仍在執行

檢查**關閉視窗時最小化到系統匣**。開啟時，關閉按鈕不會結束應用程式；請從系統匣選單結束。

### 系統匣相關開關自動變更

這是相依關係：

- 開啟「啟動時最小化到系統匣」或「關閉視窗時最小化到系統匣」會自動開啟系統匣；
- 關閉系統匣會同時關閉這兩個相依項目。

### 修改系統標題列或硬體加速後應用程式重新啟動

這是正常行為。這兩項需要在應用程式啟動階段生效，確認修改後 Cherry Studio 會重新啟動。

### 字型清單中沒有某個字型

清單來自目前系統已安裝的字型。先在作業系統中安裝字型，再重新開啟 Cherry Studio；從其他裝置同步設定不會同步字型檔案。

### 通知開關已開啟但沒有通知

檢查系統通知權限、勿擾模式，以及任務是否真的完成。Linux 桌面環境還可能需要可用的通知服務。
