# 資源庫

資源庫用於集中管理你在 Cherry Studio 中建立或安裝的助手、智能體、技能和提示詞。你可以依資源類型切換清單、搜尋現有資源，並在同一頁面新增、匯入、編輯或刪除資源。

{% hint style="info" %}
資源庫與[助手庫](agents.md)的用途不同。助手庫用於瀏覽和匯入社群助手；資源庫用於管理你所擁有的資源。
{% endhint %}

## 開啟資源庫

在啟動台中點選 **資源庫**。進入後，左側會顯示四種資源類型及其數量，右側則會顯示目前類型的資源卡片。

| 類型 | 可以完成的工作 |
| :--- | :--- |
| 助手 | 新增或匯入助手，設定模型、提示詞、知識庫和工具 |
| 智能體 | 新增智能體，設定模型、工作目錄、權限和可用工具 |
| 技能 | 從 ZIP 檔案或資料夾安裝技能，檢視技能內容並解除安裝 |
| 提示詞 | 建立和維護可重複使用的提示詞 |

## 搜尋和整理資源

1. 從左側選擇資源類型。
2. 在頂部搜尋框中輸入名稱或關鍵字。
3. 在「助手」清單中，還可以使用標籤進一步篩選。

助手卡片的操作選單支援管理標籤。新增標籤後，可以繼續將標籤指派給其他助手。

## 新增或匯入資源

點選頁面右上方的操作按鈕。按鈕會依目前選擇的資源類型顯示對應的操作：

* 助手、智能體和提示詞會開啟各自的設定頁面；填寫必填項目並儲存後，才會建立資源。
* 助手支援從 JSON 檔案匯入。
* 技能支援從本機 ZIP 檔案或資料夾安裝；如需搜尋技能市集，請前往「設定 → 技能」。

建立或安裝完成後，資源會返回對應類型的清單。

## 編輯和管理資源

點選資源卡片即可開啟編輯或詳細資訊頁面。你也可以使用卡片的操作選單：

* 編輯資源設定。
* 複製或匯出助手。
* 刪除助手、智能體或提示詞。
* 檢視技能詳細資訊，或解除安裝不再需要的技能。

刪除或解除安裝前，Cherry Studio 會顯示確認提示。此操作可能會影響正在引用該資源的工作流程，請先確認不再需要使用該資源。
