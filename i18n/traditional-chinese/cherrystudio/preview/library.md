# 資源管理入口

Cherry Studio V2 不再提供獨立的「資源庫」頁面。助手、Agent、技能和提示詞仍然可以管理，但入口已經移到各自的使用情境中。

{% hint style="warning" %}
舊版 `/app/library` 路由已停止提供，啟動台也沒有「資源庫」圖示。升級後，舊資源庫的固定分頁會自動移除；請勿繼續依照舊截圖尋找該頁面。
{% endhint %}

## 目前的入口

| 資源 | 在哪裡管理 | 主要操作 |
| :--- | :--- | :--- |
| 助手 | 開啟**對話**，從左側資源選單進入助手管理 | 新增、匯入、編輯、複製、匯出、分組和刪除助手 |
| Agent | 開啟**工作**，從左側資源選單進入 Agent 管理 | 新增、編輯、設定工作目錄與工具、刪除 Agent |
| 技能 | 開啟**設定 → 技能** | 搜尋、安裝、查看和解除安裝全域技能 |
| 提示詞 | 從對話輸入框開啟**快捷短語**，選擇**管理**或**新增** | 新增、編輯、搜尋、插入和刪除可重複使用的提示詞 |

這些入口會直接顯示在目前的工作情境中。例如，完成助手編輯後，可以直接返回對話繼續使用，不需要先離開到獨立的資源頁面。

## 助手庫與資源管理

[助手庫](agents.md)仍用於瀏覽和匯入社群助手。匯入後的助手會進入你的助手清單，並在**對話**頁面的助手管理入口中維護。

助手庫不是舊「資源庫」頁面的替代路由：

- 助手庫提供社群內容；
- 助手管理維護你已經擁有的助手；
- Agent、技能和提示詞使用上表中的獨立入口。

## 舊連結無法開啟

如果書籤、歷史記錄或舊教學包含 `/app/library`：

1. 請勿重複重新整理該位址。
2. 依資源類型開啟上表中的新入口。
3. 應用程式在還原分頁時會清理舊固定分頁，不會刪除實際的助手、Agent、技能或提示詞資料。

全域搜尋也會過濾舊資源庫路由記錄，避免再次開啟已移除的頁面。
