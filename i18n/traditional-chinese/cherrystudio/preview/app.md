# 小程式

小程式可以在 Cherry Studio 中開啟常用網站。內建目錄包含多種 AI、搜尋和開發服務，你也可以將自己的網頁位址新增為小程式，並透過頂部標籤在多個網頁之間切換。

{% hint style="info" %}
小程式載入的是第三方網站本身，不等同於 Cherry Studio 的模型 API。網站帳號、功能、區域限制和收費方式，均由對應的服務提供者決定。
{% endhint %}

## 開啟小程式

按一下頂部標籤列右側的 `+`，開啟**啟動台**，然後選擇**小程式**。

小程式首頁提供：

- **搜尋框**：依照名稱或網址篩選小程式；
- **小程式網格**：開啟目前可見的內建或自訂小程式；
- **新增按鈕**：建立自訂小程式；
- **顯示設定**：控制顯示、順序、區域和快取等行為。

按一下小程式後，網站會在新的頂部標籤中開啟。切換至其他標籤時，在快取範圍內的小程式網頁會保持載入狀態。

## 使用小程式網頁

開啟網站後，頁面頂部工具列會提供常用的瀏覽操作：

| 操作 | 用途 |
| --- | --- |
| 後退 / 前進 | 在目前小程式的瀏覽記錄中導覽 |
| 重新整理 | 重新載入目前網站 |
| 在瀏覽器中開啟 | 使用系統預設瀏覽器開啟目前網址 |
| 固定 | 將該小程式入口新增至啟動台 / 側邊欄，或從中移除 |
| 新視窗連結方式 | 切換網站彈出的新視窗連結要在 Cherry Studio 中開啟，還是在系統瀏覽器中開啟 |

在小程式網頁中，還可以使用下列快捷鍵：

| 快捷鍵 | 功能 |
| --- | --- |
| `Ctrl / Command + F` | 搜尋目前網頁；使用 `Enter` / `Shift + Enter` 切換相符項目 |
| `Ctrl / Command + P` | 將目前網頁列印為 PDF |
| `Ctrl / Command + S` | 將目前網頁儲存為 HTML |

不同網站可能會重新定義部分按鍵；以上操作應以 Cherry Studio 實際顯示的結果為準。

## 新增自訂小程式

按一下小程式首頁右上角的新增按鈕，填寫：

| 欄位 | 要求 |
| --- | --- |
| ID | 必填且唯一，只能使用英文字母、數字、底線和連字號 |
| 名稱 | 顯示在小程式網格和標籤上的名稱 |
| URL | 要開啟的完整網頁位址，通常使用 `https://` |
| 圖示 | 選填；可以填寫圖片網址，也可以從本機上傳圖片 |

儲存後，自訂小程式會加入可見清單並顯示在網格中。

{% hint style="warning" %}
只新增你信任的網址。自訂小程式會在 Cherry Studio 中載入該網站，網站仍可以接收你主動提交的登入資訊、檔案和表單內容。
{% endhint %}

目前版本無法直接修改已儲存小程式的 ID、名稱、URL 或圖示。如需變更，請先移除原本的自訂小程式，再使用新資訊重新建立。

## 固定、隱藏和移除

在小程式網格中的圖示上按一下滑鼠右鍵，可以依照目前狀態執行：

- **新增到啟動台 / 側邊欄**或取消固定；
- **隱藏**內建或自訂小程式；
- **移除自訂小程式**。

內建小程式無法刪除，但可以隱藏；只有自行建立的小程式可以完全移除。固定入口的位置會依照目前導覽列配置，顯示在啟動台或側邊欄。

隱藏小程式時，如果它正在快取清單中，相關網頁也會從目前保持載入的清單中移除。

## 管理顯示與排序

開啟小程式首頁右上角的顯示設定。面板上方分為**顯示的小程式**和**隱藏的小程式**兩個清單：

- 按一下項目，可以在顯示和隱藏之間移動；
- 在同一清單中拖曳，可以調整順序；
- **交換**會互換目前顯示和隱藏的項目；
- **重設**會將目前隱藏的項目恢復為顯示。

已固定的小程式會始終保持可見，不會和一般顯示項目一起隱藏。

## 區域篩選

區域設定提供**自動偵測**、**中國**和**全球**三個選項。它會依照內建目錄宣告的可用區域篩選網格，減少顯示目前區域通常無法存取的服務。

區域篩選只會影響目前顯示的範圍，不會代替你註冊帳號、繞過服務限制或保證網站可以存取。自訂小程式預設會在中國和全球檢視中顯示。

## 控制連結開啟方式

開啟**在瀏覽器中開啟新視窗連結**後，網站嘗試開啟的新視窗會交由系統預設瀏覽器處理；關閉時，新視窗會由 Cherry Studio 的小程式環境處理。

此開關可以在顯示設定中統一修改，也可以在已開啟小程式的頂部工具列中快速切換。無論此選項如何設定，工具列中的**在瀏覽器中開啟**按鈕都會直接開啟目前網址。

## 小程式快取數量

快取數量決定最多同時保持多少個小程式網頁處於載入狀態，可以在 `1` 到 `10` 之間調整。預設值為 `3`。

- 數量較大：切回網頁時更可能保留登入後的頁面狀態，但會占用較多記憶體；
- 數量較小：減少記憶體占用，但較早開啟且未固定的網頁可能會卸載，再次開啟時需要重新載入。

降低數量後，會在目前開啟清單後續變更至新限制時逐步生效。頂部標籤中已固定的網頁不會因為快取上限而自動移除。

## 登入狀態與資料

小程式使用獨立於系統瀏覽器的持久化網頁工作階段。因此：

- 第一次使用某個網站時，通常需要在小程式中另外登入；
- 關閉並再次開啟 Cherry Studio 後，網站 Cookie 和登入狀態通常仍可繼續使用；
- 系統瀏覽器中的登入狀態不會自動同步至小程式；
- 多個小程式共用同一個 Cherry Studio 網頁工作階段分區。

網站仍可能因帳號安全性政策、Cookie 過期、區域變更或本身更新而要求重新登入。

## 常見問題

### 網站持續載入或顯示空白

請先按一下重新整理；如果仍然失敗，使用工具列在系統瀏覽器中開啟，確認網址和帳號服務本身是否可用。也應檢查網路、代理伺服器和區域限制。部分網站會主動限制嵌入式瀏覽環境，此時只能改用系統瀏覽器。

代理伺服器設定請參閱[一般設定](settings/general.md)。

### 登入後反覆返回登入頁面

請嘗試重新整理，並確認系統時間正確、網站允許 Cookie，且登入過程未遭網路或代理伺服器攔截。如果服務不支援嵌入式網頁登入，請改用系統瀏覽器。

### 找不到小程式

請檢查搜尋文字、區域篩選，以及顯示設定中的隱藏清單。如果小程式已固定，也請查看啟動台或側邊欄中的對應入口。

### 無法儲存自訂小程式

請檢查 ID 是否只包含英文字母、數字、底線或連字號，且未與內建或現有小程式重複；同時確認名稱和 URL 都已填寫。

### 切回網頁後重新載入

可能是已開啟的小程式超過快取數量，較早開啟且未固定的網頁已卸載。你可以提高快取數量，或固定需要持續保留的頂部標籤。

## 隱私權與安全性

你在小程式中輸入的帳號、訊息、檔案和其他內容會傳送給對應網站，而不是傳送給目前對話所選的模型。Cherry Studio 的對話也不會自動讀取小程式網頁內容；需要引用時，請確認權限和敏感程度後，手動複製必要內容。
