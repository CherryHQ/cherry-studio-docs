# 對話介面

對話是 Cherry Studio 最常用的工作區。你可以為不同用途建立助手，在每個助手下管理多個獨立話題，並依照需要加入檔案、知識庫、網路搜尋、MCP 工具或多個模型。

{% hint style="info" %}
第一次使用前，請先在[模型服務](../../pre-basic/providers/)中新增服務商、啟用模型並通過連線檢查。
{% endhint %}

## 先了解助手和話題

對話頁採用「助手 → 話題」兩層結構：

* **助手**：儲存角色提示詞、目前模型、模型參數、知識庫、MCP 和網路搜尋等設定。
* **話題**：儲存一段獨立的對話記錄。

一個助手可以有多個話題。這些話題共用助手設定，但訊息記錄不會混合。例如，可以在同一個「程式碼審查助手」下，分別建立「專案 A」和「專案 B」兩個話題。

如果需要自主存取工作區、讀寫檔案或執行命令，應使用[智能體](../../advanced-basic/agent.md)，不要將對話助手和智能體視為同一類功能。更多概念請參閱[概念入門](../../advanced-basic/concepts-101.md)。

## 頁面組成

對話頁主要由四個部分組成：

1. **助手與話題列表**：切換助手、建立話題、搜尋或管理記錄。
2. **頂部列**：顯示目前助手和模型，並提供對話設定、搜尋和側邊欄開關。
3. **訊息區**：顯示使用者訊息、模型回覆、思考過程、工具呼叫和引用。
4. **輸入區**：輸入訊息並使用附件、網路搜尋、知識庫、MCP、多模型等工具。

話題列表可以依照顯示設定放在左側或右側；側邊欄也可以收合。介面位置不同不會改變助手和話題的層級關係。

## 開始第一次對話

1. 開啟側邊欄中的 **對話**。
2. 選擇一個助手，或從[助手庫](agents.md)新增助手。
3. 按一下 **新話題**。
4. 在頂部選擇要使用的模型。
5. 在輸入框中寫下問題，按下目前設定的傳送快捷鍵。

如果模型沒有回覆，請先檢查模型服務是否已啟用、API Key 和位址是否正確，以及目前模型是否可用。

## 選擇模型

### 目前助手模型

頂部的模型選擇器決定目前助手使用的基礎模型。切換後，後續訊息會使用新模型；可以在助手設定中調整助手的預設模型，以及建立新話題時是否重設模型。

請只選擇可用於對話的模型。嵌入模型和重新排序模型用於知識庫處理，不會出現在一般對話模型清單中。

### 使用多個模型平行回覆

在輸入區按一下提及模型按鈕，或輸入 `@`，即可選擇一個或多個模型。選取的模型會顯示在輸入框上方：

* 只選擇一個模型時，該模型會取代助手基礎模型進行回覆。
* 選擇多個模型時，Cherry Studio 會平行產生多份回覆，方便比較結果。
* 移除輸入框上方的模型標籤後，會恢復使用助手基礎模型。

上傳圖片時，所有提及的模型都應支援視覺輸入，否則可能無法選擇或傳送。

## 輸入工具

輸入區工具可以拖曳排序，也可以透過右鍵選單顯示或隱藏。視窗較窄或工具較多時，部分按鈕會收合。

| 工具 | 功能 | 說明 |
| --- | --- | --- |
| 新話題 | 在目前助手下建立獨立話題 | 不會刪除原話題 |
| 附件 | 新增圖片、文件或文字 | 可選類型取決於模型功能 |
| 網路搜尋 | 將搜尋結果加入回答依據 | 需要模型原生搜尋或已設定搜尋服務 |
| 知識庫 | 為助手選擇一個或多個知識庫 | 選擇會保留在助手設定中，直到移除 |
| MCP | 查看或呼叫已分配給助手的 MCP 工具 | 需要先設定 MCP 伺服器 |
| 提及模型 | 為輸入選擇一個或多個回覆模型 | 也可以輸入 `@` 開啟 |
| 快捷短語 | 插入常用提示詞範本 | 在設定中統一管理 |
| 思考 | 調整推理模型的思考模式或強度 | 僅在模型支援時顯示 |
| 網頁上下文 | 允許支援的模型讀取 URL | 只在相容的模型和服務商組合下顯示 |
| 產生圖片 | 讓支援圖片產生的模型傳回圖片 | 如需專門創作圖片，也可以使用[繪圖](drawing.md) |
| 清空訊息 | 刪除目前話題中的訊息 | 刪除後無法復原 |
| 新上下文 | 保留畫面上的記錄，但從此處截斷傳送給模型的上下文 | 適合話題尚未結束，但模型不應繼續參考舊內容的情況 |
| 展開輸入框 | 放大或還原輸入區 | 適合輸入較長的提示詞 |

工具是否顯示，由目前頁面、模型功能、助手設定和你的工具列設定共同決定。如果找不到某個按鈕，請先在輸入區工具列按一下滑鼠右鍵，檢查它是否已隱藏，再確認模型或助手是否符合使用條件。

### `@` 和 `/` 快速面板

啟用輸入快速面板後：

* 輸入 `@` 可以開啟模型選擇面板。
* 輸入 `/` 可以開啟可用操作和資源的快速面板。

快速面板顯示的內容取決於目前對話環境和已啟用的工具。你可以在輸入設定中關閉字元觸發，但仍可透過工具按鈕使用相關功能。

## 使用附件

1. 按一下 **附件**，或將檔案拖入輸入區。
2. 確認檔案預覽顯示在輸入框上方。
3. 在問題中清楚說明希望模型如何處理檔案。
4. 傳送訊息。

可選檔案類型會依照模型功能而變化：

* 圖片需要視覺模型，或支援圖片產生／編輯的模型。
* 文件和文字會先作為附件處理，再隨訊息加入上下文。
* 提及多個模型時，附件必須符合所有已選模型的共同功能。

長文字也可以依照輸入設定自動轉為檔案，以免占滿輸入框。涉及隱私或機密資訊時，傳送前請確認目前模型服務商和資料政策。

## 使用知識庫

1. 先在[知識庫](knowledge-base.md)中建立知識庫並完成資料處理。
2. 返回對話頁，按一下 **知識庫**。
3. 選擇一個或多個知識庫。
4. 提問時寫明希望檢索的主題、範圍或時間條件。

知識庫標籤會顯示在輸入框上方。目前版本中，附件和知識庫選擇在部分組合下可能互斥；如果按鈕無法使用，請先移除目前附件，再選擇知識庫。

知識庫檢索結果是模型回答的參考內容，不保證回答一定正確。重要結論仍應核對引用和原始資料。

## 使用網路搜尋和 MCP

### 網路搜尋

網路搜尋有兩類來源：

* 模型服務商提供的原生搜尋功能。
* 在 Cherry Studio 中設定的外部搜尋服務。

具體設定請參閱[聯網模式](../../websearch/)。啟用後，仍應檢查引用連結是否確實支援模型結論。

### MCP 工具

MCP 讓對話助手呼叫外部工具或資料。使用前需要：

1. 在 MCP 設定中安裝並啟用伺服器。
2. 將需要的 MCP 伺服器分配給目前助手。
3. 選擇支援工具呼叫的模型。
4. 傳送前檢查已啟用的工具和權限。

完整說明請參閱 [MCP](../../advanced-basic/mcp/)。

## 操作訊息

將滑鼠移到訊息附近，即可看到操作列。實際按鈕會依照訊息角色和設定而變化。

| 操作 | 用途 |
| --- | --- |
| 複製 | 複製訊息正文 |
| 編輯並重新傳送 | 修改使用者訊息，並從該位置重新產生 |
| 重新產生 | 讓模型再次回答 |
| 使用其他模型回答 | 從目前位置選擇模型，產生另一份回覆 |
| 翻譯 | 將模型回覆翻譯成所選語言 |
| 儲存到筆記 | 將回覆儲存到 Cherry Studio 筆記 |
| 刪除 | 刪除單一訊息 |
| 新建分支 | 從目前訊息建立新的對話分支 |
| 多選 | 批次選擇訊息以進行後續操作 |
| 儲存或匯出 | 儲存為檔案、加入知識庫或匯出內容 |

在重新產生、編輯歷史訊息或刪除前，請注意這些操作可能改變後續對話鏈。如果需要保留原始結果，請先新建分支。

## 管理長對話

| 操作 | 是否保留訊息 | 後續是否繼續攜帶舊上下文 | 適用情境 |
| --- | --- | --- | --- |
| 新話題 | 保留在原話題 | 否 | 開始新的任務或專案 |
| 新上下文 | 保留在目前話題 | 從標記處重新開始 | 同一任務進入新階段，或上下文已經混亂 |
| 清空訊息 | 刪除 | 否 | 確定不再需要目前話題內容 |
| 新建分支 | 保留原對話 | 從選取的訊息繼續 | 比較不同提示詞或模型路線 |

{% hint style="warning" %}
「清空訊息」會刪除目前話題內容；「新上下文」只會截斷傳送給模型的記錄。兩者不是相同的操作。
{% endhint %}

輸入區顯示的 Token 數為估算值，用於判斷上下文是否接近模型上限。不同模型的分詞方式和服務商計費規則不同，最終用量以服務商為準。

## 助手設定與全域設定

### 助手設定

助手設定會影響該助手下的所有話題，主要包括：

* 名稱、頭像和系統提示詞。
* 預設模型和模型參數。
* 知識庫、網路搜尋和 MCP。
* 上下文數量、最大輸出長度、串流輸出和服務商專用參數。

並非所有模型都支援相同參數。沒有明確需求時，請優先使用預設值；自訂參數可能會覆寫內建設定。

### 對話與輸入設定

對話設定還包含全域顯示和輸入偏好，例如：

* 訊息樣式、字型、程式碼區塊、數學公式和思考內容顯示。
* Token 估算、長文字貼上、輸入翻譯和傳送方式。
* 助手列表、話題位置和工具列顯示。

## 常見問題

### 傳送按鈕無法使用

請檢查輸入內容是否為空、模型是否仍在產生內容、目前模型是否支援附件類型，以及模型服務是否已啟用。

### 找不到知識庫或 MCP

請確認對應功能已建立或啟用，並檢查目前助手是否支援工具呼叫。知識庫按鈕無法使用時，請先移除輸入區附件。

### 沒有出現多模型回覆

請確認輸入框上方仍顯示已提及的模型，並檢查這些模型是否都可用。已停用、餘額不足或介面不相容的模型可能會個別失敗。

### 對話越來越慢或回答偏離主題

請先檢查 Token 估算和上下文數量。你可以使用 **新上下文** 在目前話題中重新開始，或建立新話題以分隔任務。

如果仍無法解決，請透過[意見回饋與建議](../../question-contact/suggestions.md)提交 Cherry Studio 版本、模型名稱、服務商、重現步驟和錯誤資訊。
