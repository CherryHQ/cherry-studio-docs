# 翻譯

翻譯頁面使用你已設定的語言模型進行文字翻譯。它支援自動偵測語言、串流顯示結果、匯入文字或文件、圖片 OCR、翻譯歷史和自訂語言，適合處理短文、電子郵件、程式碼片段和從檔案擷取的文字。

## 開始前的準備

翻譯至少需要一個已啟用的文字模型：

1. 開啟 `設定` → `模型服務`，完成服務商和模型設定。
2. 在翻譯頁面右上角選擇用於翻譯的模型。
3. 如果使用 LLM 自動偵測語言，還需要在 `設定` → `預設模型` 中設定**快捷助手模型**。

嵌入、重新排序和圖片生成模型不會顯示在翻譯模型清單中。如果還沒有可用模型，請先閱讀[設定模型服務](../../pre-basic/providers/README.md)。

## 開啟翻譯

按一下頂部標籤列右側的 `+`，開啟**啟動台**，然後選擇**翻譯**。

頁面由下列部分組成：

| 區域 | 用途 |
| --- | --- |
| 頂部語言列 | 選擇來源語言和目標語言、交換翻譯方向，以及開始或停止翻譯 |
| 左側輸入區 | 輸入、貼上或匯入待翻譯內容 |
| 右側結果區 | 串流顯示結果，並複製譯文 |
| 右上角工具 | 選擇模型、開啟翻譯歷史和翻譯設定 |

在較窄的視窗中，輸入區和結果區會改為上下排列。

## 完成一次翻譯

1. 選擇來源語言。無法確定時，請保留**自動偵測**。
2. 選擇目標語言。
3. 在左側輸入或貼上內容。
4. 按一下**翻譯**，或按 `Ctrl + Enter`（Windows / Linux）或 `Command + Enter`（macOS）。
5. 在右側查看串流結果，完成後按一下複製按鈕。

翻譯進行期間，可以按一下**停止**中斷本次要求。清空左側輸入時，右側結果也會一併清空。

{% hint style="info" %}
翻譯結果由目前選取的模型生成。專業術語、合約、醫療或其他高風險內容，仍應由具備相關能力的人員複核。
{% endhint %}

## 選擇來源語言和目標語言

### 自動偵測

來源語言選擇**自動偵測**後，Cherry Studio 會先判斷輸入語言，再開始翻譯。成功識別後，來源語言位置會顯示識別結果。

設定中有三種偵測方式：

| 方式 | 行為 |
| --- | --- |
| 自動 | 依照內容長度優先選擇 LLM 或本機演算法；本機演算法無法識別時，會改用 LLM |
| 本機演算法 | 在本機快速偵測，不呼叫模型，但支援的語言範圍較有限 |
| LLM | 使用快捷助手模型識別，通常更適合較短或不易判斷的文字，但會產生一次額外的模型呼叫 |

如果 LLM 偵測失敗，請檢查快捷助手模型是否已設定且可用。

### 交換翻譯方向

當來源語言不是**自動偵測**時，可以按一下中間的交換按鈕。Cherry Studio 會同時交換來源語言、目標語言、原文和現有譯文。

### 雙向翻譯

在設定中開啟**雙向翻譯**並指定一組語言後，Cherry Studio 會依照偵測到的輸入語言，自動選擇這組語言中的另一種作為目標語言。這適合在兩種固定語言之間反覆溝通。

如果輸入語言不屬於設定的語言組合，應用程式會提示無法確定翻譯方向。

## 匯入檔案或圖片

輸入區為空白時，左側會顯示檔案匯入區域。按一下該區域以選擇一個檔案，也可以將檔案拖入頁面；剪貼簿中的圖片還可以直接貼上。

| 內容類型 | 處理方式 |
| --- | --- |
| 圖片 | 先透過目前 OCR 設定識別文字，再附加到輸入區 |
| 純文字、Markdown、程式碼等文字檔案 | 直接讀取文字並附加到輸入區 |
| PDF、Word、PowerPoint、Excel 和 ODF 文件 | 擷取可讀取的文字並附加到輸入區 |

每次只能匯入一個檔案。文字檔案上限為 5 MB，文件上限為 20 MB；實際可讀取的內容仍取決於檔案格式、文件結構和本機檔案處理能力。

{% hint style="warning" %}
檔案匯入的作用是擷取文字，不會產生一份保留原始版面的翻譯文件。如果需要逐段控制格式，建議先擷取內容，再分段翻譯和整理。
{% endhint %}

如果無法從圖片識別文字，請檢查 `設定` → `文件處理` 中的 OCR 設定，並確認圖片清晰且方向正確。

## 選擇翻譯模型

按一下右上角的模型圖示，可以從已啟用的文字模型中選擇翻譯模型。選擇時可以參考：

- 日常短文字優先考慮回應快速、成本可控的模型；
- 長文字應注意模型的上下文長度和輸出限制；
- 專業內容可以比較不同模型對術語和語氣的處理；
- 專用翻譯模型可能依照自身協定運作，不一定使用自訂翻譯提示詞。

如果翻譯按鈕一直無法使用，請確認已輸入內容並選取有效模型。

## 翻譯設定

按一下右上角的設定按鈕以開啟側邊面板。

### 結果與操作

| 設定 | 功能 |
| --- | --- |
| Markdown 預覽 | 以 Markdown 轉譯譯文；關閉時顯示純文字 |
| 自動複製 | 翻譯完成後，自動將結果寫入剪貼簿 |
| 捲動同步 | 捲動長文字時，讓左右兩欄依照相對位置連動 |

### 翻譯提示詞

翻譯提示詞控制一般對話模型如何處理原文。預設範本包含：

- `{{target_language}}`：目前目標語言；
- `{{text}}`：待翻譯文字。

修改範本時應保留這兩個預留位置，否則模型可能無法收到目標語言或原文。如需復原，請按一下**重設**。

### 自訂語言

除了內建語言，也可以新增自訂語言。新增時請填寫顯示名稱、語言代碼並選擇圖示；建立後可以編輯名稱和圖示，或刪除該語言。

語言代碼必須唯一，不能與內建語言重複。能否取得可靠譯文，仍取決於所選模型是否理解該語言名稱和內容。

## 使用翻譯歷史

每次成功翻譯後，原文、譯文、語言方向和時間都會寫入翻譯歷史。開啟右上角的歷史面板後，可以：

- 查看並重新載入一筆翻譯；
- 複製歷史中的原文或譯文；
- 將常用記錄加入收藏，並只查看收藏項目；
- 刪除單筆記錄；
- 確認後清空全部歷史。

重新載入記錄會同時復原當時的原文、譯文和語言方向。

## 常見問題

### 翻譯按鈕無法使用

請確認輸入區不是空白、已選擇翻譯模型，並等待檔案讀取、語言偵測或上一項翻譯完成。

### 自動偵測發生錯誤

如果設定為 LLM 偵測，或自動方式改用 LLM，請檢查快捷助手模型。你也可以明確選擇來源語言，或嘗試本機演算法。

### 結果為空白或中途失敗

請檢查模型服務的金鑰、網路、餘額、呼叫頻率限制和模型可用狀態。長文字也可能超過模型的上下文或輸出限制，可以拆分為較短段落後重試。

### 無法交換來源語言和目標語言

來源語言為**自動偵測**、正在翻譯、正在偵測語言或正在處理檔案時，交換按鈕會暫時無法使用。請先明確選擇來源語言，並等待目前操作完成。

### 檔案匯入失敗

請確認每次只選擇一個支援的檔案，且沒有超過大小限制。掃描版文件、複雜表格、受密碼保護或已損壞的檔案，可能無法完整擷取文字。

## 隱私權與費用

一般翻譯內容會傳送給目前所選模型的服務商；LLM 自動偵測還會呼叫快捷助手模型。圖片在翻譯前會交由目前的 OCR 元件處理。請依照資料敏感程度選擇適合的服務和部署方式，並查看相應服務商的隱私權政策和計費規則。
