# 排程任務

排程任務可讓[智能體](agent.md)在指定時間自動執行提示詞，適合產生日報、定期檢查、定時提醒，或將結果傳送到訊息頻道。每次執行都會建立會話和執行記錄，方便你查看結果與錯誤。

排程任務由 Cherry Studio 本機的排程器執行，不是作業系統層級的背景服務。到了排定時間，Cherry Studio 必須處於執行狀態；重新開啟應用程式後，仍處於活躍狀態的任務會恢復排程。

{% hint style="warning" %}
排程任務屬於無人值守操作。執行任務的智能體必須啟用自主模式，或使用全自動權限模式；啟用自主模式時，Cherry Studio 會自動切換為全自動權限。工具呼叫不會逐次等待確認，請限制智能體可存取的工作目錄，並避免在提示詞中儲存密碼、API Key 或其他敏感資訊。
{% endhint %}

## 建立前準備

1. 建立或選擇一個[智能體](agent.md)，並設定可用的模型。
2. 在智能體設定中啟用**自主模式**。如果只打算在設定頁面手動建立任務，也可以使用全自動權限模式的智能體。
3. 先在一般會話中測試相同的提示詞，確認模型、工具及工作目錄權限符合預期。
4. 如果需要將結果傳送到即時通訊軟體，請先設定並連線對應的[頻道](agent-channels.md)。

設定頁面只會將已啟用自主模式或全自動權限模式的智能體列為可選項目。建立及執行排程任務不需要另外啟用 API Server。

## 透過對話建立

對於已啟用自主模式的智能體，你可以直接描述需求，例如：

> 每個工作日上午 9 點整理最近 24 小時的專案動態，輸出 5 點摘要。

智能體可以透過內建的排程任務工具建立、列出或刪除任務。說明中最好包含：

* 任務名稱及要完成的事項；
* 執行時間、重複間隔或一次性日期；
* 是否需要將結果傳送到特定頻道；
* 如果預計執行時間較長，請指定逾時時間。

建立完成後，前往**設定 → 排程工作**，檢查排程值、提示詞、接收頻道及下次執行時間。

## 在設定中建立

1. 開啟**設定 → 排程工作**。
2. 按一下左側的 **+ 新增**。
3. 選擇智能體並填寫表單。
4. 按一下**儲存**。任務會以「活躍」狀態開始等待排程。

| 欄位 | 用途 |
| :--- | :--- |
| 名稱 | 用於任務清單及會話名稱，例如「每日程式碼審查」 |
| 提示詞 | 每次執行時，作為使用者訊息傳送給智能體的完整指令 |
| 排程類型 | `Cron`、`間隔`或`一次性` |
| 排程值 | Cron 運算式、間隔分鐘數，或一次性日期及時間 |
| 逾時時間 | 單次執行允許的最長時間，單位為分鐘 |
| 傳送至頻道 | 選填；將產生過程及最終結果傳送到所選頻道 |

{% hint style="info" %}
目前版本的資料層預設逾時時間為 2 分鐘。介面中的空白預留位置雖然顯示「無限制」，但建立任務時若未填寫，仍會儲存為 2 分鐘。執行時間較長的任務，請明確填入較大的正整數。
{% endhint %}

### 選擇排程類型

{% tabs %}
{% tab title="間隔" %}
填寫正整數分鐘數。`60` 表示每 60 分鐘執行一次。間隔會以排定時間為基準計算；如果應用程式暫時關閉，不會為了補足所有錯過的週期而連續執行多次。
{% endtab %}

{% tab title="Cron" %}
填寫標準的 5 欄位 Cron 運算式：`分 時 日 月 星期`。

| 運算式 | 含義 |
| :--- | :--- |
| `0 9 * * *` | 每天 9:00 |
| `*/15 * * * *` | 每 15 分鐘 |
| `0 9 * * 1-5` | 每個工作日 9:00 |

Cron 會依裝置目前的時區計算。儲存後，請核對頁面顯示的「下次執行」時間。
{% endtab %}

{% tab title="一次性" %}
在日期時間選擇器中指定一次執行時間。任務執行後會標記為「已完成」，無法再編輯、執行或恢復；如需再次執行，請建立新任務。
{% endtab %}
{% endtabs %}

## 傳送至頻道

建立或編輯任務時，可以選擇一個或多個已設定的頻道。任務執行時，智能體的文字輸出會傳送到這些頻道；如果執行失敗，也會傳送錯誤通知。

頻道必須已連線，並且記錄了可接收通知的有效 Chat ID。如果頁面提示「所選頻道沒有可用的收件人（聊天 ID）」，請先在對應平台向 Bot 傳送一則訊息，讓 Cherry Studio 記錄會話目標，再回來選擇頻道。

未選擇頻道時，任務仍會正常執行，結果會保留在 Cherry Studio 的任務會話及執行歷史中。

## 管理任務

在左側選擇任務後，可以在詳細資料頁面：

* 修改名稱、智能體、提示詞、排程、逾時時間及接收頻道；
* 按一下執行按鈕立即觸發一次，不會變更後續排程；
* 暫停或恢復週期性任務；
* 刪除不再需要的任務。

修改排程或從暫停狀態恢復時，Cherry Studio 會重新計算「下次執行」。如果同一個任務已在執行，不會並行啟動第二次。

週期性任務會優先沿用上一次成功執行的會話，讓後續執行保留上下文；首次執行或原會話不存在時，會建立以任務名稱命名的新會話。

## 查看執行歷史

詳細資料頁面的**執行歷史**會顯示執行時間、耗時、狀態，以及結果或錯誤。你可以搜尋記錄，也可以按一下會話圖示，開啟該次任務的完整對話。

單次任務達到逾時時間後會被中止，並記錄為錯誤。一個任務連續執行失敗 3 次後，排程器會自動將它暫停；排除模型、網路、工具權限或提示詞問題後，再手動恢復。

## 未按時執行

請依序檢查：

1. Cherry Studio 在排定時間是否處於執行狀態。
2. 任務狀態是否為「活躍」，以及「下次執行」是否正確。
3. 智能體的模型是否可用，服務商餘額及網路是否正常。
4. 智能體是否仍處於自主模式或全自動權限模式。
5. 執行歷史中是否出現逾時、工具權限或頻道傳送錯誤。

排程器大約每分鐘檢查一次到期任務，因此實際開始時間可能比排定時間稍晚。長時間執行的任務會持續消耗模型 Token；建議先手動執行並確認輸出，再啟用高頻率排程。
