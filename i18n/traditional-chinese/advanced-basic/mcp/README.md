# MCP 使用教學

MCP（Model Context Protocol）是一種讓模型使用外部工具和資料的標準通訊協定。連接 MCP Server 後，Cherry Studio 中的助手或 Agent 可以在回答過程中讀取網頁、查詢資料庫、操作檔案、呼叫業務 API，或使用伺服器提供的提示和資源。

## MCP 的運作方式

一次典型呼叫包含以下角色：

| 角色 | 功能 |
| --- | --- |
| 模型 | 判斷是否需要使用工具，並產生工具參數 |
| Cherry Studio | 連接 MCP Server、執行權限檢查並顯示呼叫過程 |
| MCP Server | 提供工具、提示或資源，並執行實際操作 |

大致流程如下：

1. 你向助手或 Agent 提出任務；
2. 模型從已授權的工具中選擇一項工具；
3. Cherry Studio 根據伺服器和工具權限，判斷是否需要你確認；
4. MCP Server 執行操作並傳回結果；
5. 模型結合結果繼續回答。

模型並不是直接「登入電腦或帳號」，而是透過 MCP Server 提供的介面運作。但 MCP Server 本身可能是本機的可執行程式，也可能是遠端服務，因此仍需要審查來源和權限。

## 常見用途

- 讀取和搜尋本機檔案；
- 取得網頁、操作瀏覽器或呼叫網路介面；
- 查詢知識庫、資料庫和團隊文件；
- 執行 Python 或其他程式碼；
- 連接筆記、訊息、專案管理等線上服務；
- 在明確授權後執行寫入、刪除或業務操作。

實際功能取決於伺服器提供的工具。同類型的 MCP Server 在權限、資料去向和品質方面也可能不同。

## MCP Server 可以提供什麼

MCP 不只有「工具」：

- **Tools**：模型可以呼叫的操作，例如搜尋、讀取、寫入；
- **Prompts**：伺服器提供的可重複使用提示詞範本；
- **Resources**：伺服器提供的檔案、文件或其他上下文資源。

伺服器啟用後，可以在詳細資料頁面查看它實際提供哪些功能。如果未提供某類功能，對應的分頁可能空白或不會顯示。

## MCP 與 Skills 的差異

| 比較項目 | Skills | MCP |
| --- | --- | --- |
| 核心功能 | 告訴 Agent 如何完成某類任務 | 讓模型能夠呼叫外部工具或資料 |
| 主要內容 | 指示、流程和選用資源 | 工具、提示、資源和連線通訊協定 |
| 是否執行外部操作 | 取決於 Skill 呼叫的工具 | 通常會連接本機程式或遠端服務 |
| V2 使用位置 | 主要用於 Agent | 可用於一般助手和 Agent |

Skill 可以指導 Agent 何時、以哪些步驟使用 MCP；MCP 則負責真正執行工具呼叫。兩者可以搭配使用。詳細說明請參閱 [Skills](../../pre-basic/settings/skills.md)。

## 在 Cherry Studio 中使用 MCP

完整流程如下：

1. 在**設定 → MCP 伺服器**中安裝或新增伺服器；
2. 填寫指令、URL、參數、Header 或環境變數；
3. 啟用伺服器並檢查工具和日誌；
4. 在一般助手或 Agent 中新增該伺服器；
5. 使用支援工具呼叫的模型開始任務。

{% hint style="info" %}
只有使用 `uv`、`uvx`、`npx`、`bun` 等本機指令啟動的 STDIO 伺服器，才可能需要額外的執行環境。遠端伺服器和多數內建伺服器不需要預先安裝 UV 或 Bun。
{% endhint %}

詳細步驟請參閱[設定與使用 MCP](config.md)。

## 從哪裡尋找伺服器

Cherry Studio 的 MCP 設定提供多個入口：

- **內建伺服器**：Cherry Studio 已適配的常用伺服器；
- **MCP 市場**：從已接入的市場瀏覽伺服器；
- **服務提供者**：連接支援的 MCP 服務提供者；
- **從 JSON 或 DXT 匯入**：使用開發者提供的設定或擴充套件；
- **手動新增**：依官方文件填寫 STDIO、SSE 或 Streamable HTTP 設定。

第一次使用時，建議從[內建 MCP 伺服器](in-memory.md)開始。其設定路徑更明確，也更容易驗證權限。

## 安全界線

{% hint style="danger" %}
MCP 的工具聲明不是安全沙箱。STDIO Server 是以目前使用者權限執行的程式，惡意或遭入侵的伺服器可能存取其程序權限允許的資料；遠端 Server 也會收到你傳送給工具的內容。
{% endhint %}

安裝或啟用伺服器前：

- 核對開發者、軟體套件、下載位址和更新記錄；
- 只授權完成任務所需的目錄、帳號和 API Scope；
- 不要將真實金鑰寫入提示詞或共用 JSON；
- 在**工具**頁面關閉不需要的工具；
- 對寫入檔案、刪除資料、傳送訊息、建立訂單等操作保留人工確認；
- 不再使用時，停用或解除安裝伺服器。

自動核准只會減少確認步驟，不會降低工具本身的權限。請勿為不熟悉的伺服器批次開啟自動核准。
