# Agent

Agent 可以在受控權限下讀取工作區、呼叫工具並連續完成多步驟任務。它適合「需要真正執行」的工作，例如整理一批檔案、修改專案程式碼、呼叫 MCP 服務或依排程產生報告。

如果只需要固定角色設定、知識庫問答或日常聊天，先使用助手會更簡單。兩者的差異請參閱[概念入門](concepts-101.md)。

## 開始前

### 設定可用模型

Agent 的模型必須支援 Anthropic Messages 端點。模型選擇器會自動隱藏 Embedding、Rerank 和圖像產生模型，只顯示適合 Agent 對話執行的模型。

如果清單空白，請先在**設定 → 模型服務**中：

1. 設定 API 位址和 API Key。
2. 取得或手動新增模型。
3. 確認該模型支援 Anthropic Messages 端點。

模型服務的一般設定方法請參閱[模型服務](../pre-basic/providers/)。

### 確認本機 API 伺服器可用

Agent 頁面的底層依賴 Cherry Studio 的本機 API 伺服器。V2 會在建立 Agent 時自動嘗試啟動服務，通常不需要預先前往設定頁面操作。

如果 Agent 頁面顯示服務已停用或未執行，請直接按一下頁面中的啟動按鈕；如果仍無法啟動，再前往**設定 → API 伺服器**檢查連接埠和執行狀態。詳見 [API 伺服器](api-server.md)。

## 建立 Agent

透過啟動台或側邊欄開啟 **Agent**，然後按一下左側 Agent 清單上方的 **+ Agent**。

也可以開啟[資源庫](../cherrystudio/preview/library.md)，切換至 **Agent** 後按一下新增。資源庫會直接開啟完整設定頁面。

### 最少需要填寫哪些項目

| 欄位 | 是否必填 | 說明 |
| :--- | :--- | :--- |
| 名稱 | 是 | Agent 在清單和工作階段中的顯示名稱 |
| 模型 | 是 | 主要執行模型，只顯示支援 Anthropic Messages 的模型 |
| 可存取目錄 | 否 | 限定 Agent 可以存取的本機目錄；未指定時會建立預設工作目錄 |
| 說明 | 否 | 說明用途，方便在資源庫中辨識 |

{% hint style="warning" %}
可存取目錄也是安全界線。請勿直接授權整個使用者目錄、系統目錄或儲存金鑰的目錄；請優先為任務建立獨立工作區，只新增確實需要存取的位置。
{% endhint %}

儲存後，Agent 會出現在左側清單和資源庫中。技能會依 Agent 綁定，因此需要先完成首次儲存，才能為它啟用技能。

## 設定頁面

從資源庫按一下 Agent 卡片，或從 Agent 工作階段頂端開啟設定，可以繼續編輯以下部分：

| 設定區 | 可以設定的內容 |
| :--- | :--- |
| 基本設定 | 頭像、名稱、主要模型、規劃模型、小型模型、可存取目錄、自主模式、心跳和說明 |
| 提示詞設定 | Agent 的系統指令 |
| 權限模式 | 工具呼叫的預設核准方式 |
| 能力擴充 | 內建工具、MCP Server 和技能 |
| 進階設定 | 最大執行輪次和環境變數 |

### 主要模型、規劃模型和小型模型

* **主要模型**是必填項目，負責大部分對話和工具執行。
* **規劃模型**是選填項目，可用於需要獨立規劃的流程。
* **小型模型**是選填項目，可用於適合輕量模型的輔助步驟。

三個位置都只會顯示 Agent 相容模型。沒有明確需求時，只設定主要模型即可。

### 提示詞

提示詞用於定義角色、目標、工作規範和輸出要求。與其列出大量背景，更建議明確寫出：

* Agent 負責什麼、不負責什麼。
* 可以使用哪些目錄、資料來源和工具。
* 執行前需要確認哪些操作。
* 結果儲存在哪裡，以及使用什麼格式。

安全限制不能只依賴提示詞。目錄範圍、權限模式和工具開關仍應分別設定。

## 選擇權限模式

權限模式決定哪些工具會自動獲得核准。切換模式時，Cherry Studio 會同步更新由該模式自動新增的工具。

| 模式 | 預設行為 | 適用情境 |
| :--- | :--- | :--- |
| 一般模式 | 可自由讀取檔案；編輯檔案或執行指令前詢問 | 初次使用、互動式任務 |
| 規劃模式 | 只能讀取檔案並制定計畫；不能編輯檔案或執行指令 | 程式碼審閱、方案設計、風險評估 |
| 自動編輯模式 | 可自由讀取和編輯檔案；執行指令前詢問 | 文件整理、受控的程式碼修改 |
| 全自動模式 | 目前可用的工具無需逐次核准 | 無人值守且範圍受到嚴格控制的任務 |

除了模式自動新增的工具，你還可以在**能力擴充 → 內建工具**中手動新增其他工具。

{% hint style="danger" %}
全自動模式會略過工具核准。Agent 可能會寫入檔案、執行指令或呼叫外部服務。請只在隔離工作區中使用，並先以一般模式完整測試相同任務。
{% endhint %}

## 自主模式與心跳

### 自主模式

開啟自主模式後，Agent 會使用工作區中的靈魂檔案建立自訂系統提示詞，取得自主任務管理能力，並停用不適合無人值守執行的互動式工具。

開啟自主模式也會將權限模式切換為**全自動模式**；從全自動模式切換至其他模式時，自主模式會關閉。

自主模式適合長期執行、頻道和其他無人值守情境。它不是提高回答品質的一般開關：如果任務需要頻繁向使用者確認，使用一般 Agent 更合適。

### 心跳

心跳可以讓支援自主執行的 Agent 依設定的間隔檢查並繼續處理工作。你可以在基本設定中啟用或關閉，並設定間隔分鐘數。

只有在 Agent 已經具備明確目標、受限目錄和安全工具集時才開啟心跳，以免產生沒有意義的重複執行。

## 新增工具、MCP 和技能

開啟**能力擴充**，可以在三個分頁之間切換：

### 內建工具

內建工具提供檔案讀取、編輯、指令執行和任務管理等功能。權限模式會自動新增一部分工具；帶有模式標記的工具無法個別移除。

只啟用任務真正需要的工具。即使使用一般模式，過大的工具集合也會增加模型誤選工具的可能性。

### MCP

此處會列出 Cherry Studio 中現有的 MCP Server。未啟用的 Server 可以顯示在已綁定清單中，但無法從新增清單選取；需要先在**設定 → MCP 伺服器**中啟用。

MCP Server 可能會存取本機程式或遠端服務。綁定前，請檢查其指令、環境變數、目錄和遠端位址。完整說明請參閱 [MCP 使用教學](mcp/)。

### 技能

技能提供任務說明、流程、指令碼或範本。只有已儲存並取得 ID 的 Agent 才能啟用技能。

如果清單空白，請先在資源庫或**設定 → 技能**中安裝。詳見[技能](../pre-basic/settings/skills.md)。

## 設定進階選項

### 最大執行輪次

最大執行輪次用於限制一次任務可以持續的回合數。留空或設為 `0` 時會使用預設值；目前的預設上限為 100。

輪次不是「回答長度」。Agent 的每次規劃、工具呼叫和繼續執行都可能占用一個回合。任務異常循環時，應先檢查提示詞和工具結果，而不是一味提高上限。

### 環境變數

環境變數以每行一個 `KEY=VALUE` 的格式填寫，例如：

```text
PROJECT_ENV=staging
OUTPUT_FORMAT=markdown
```

環境變數會進入 Agent 的執行設定。請勿將密碼、API Key 或存取權杖寫入文件、提示詞或截圖；敏感值只應儲存在受控設定中，並依最小權限原則管理。

## 開始工作階段

1. 開啟 **Agent** 頁面。
2. 從左側選擇 Agent。
3. 建立工作階段，輸入一個界線清楚的任務。
4. 查看工具呼叫卡片；在一般、規劃或自動編輯模式下，依提示核准或拒絕操作。
5. 檢查產生或修改的檔案，再繼續下一步。

第一個測試任務應該範圍小且結果容易驗證，例如：

> 讀取目前工作區中的 `README.md`，列出需要更新的三項內容。請先不要修改檔案。

確認讀取範圍正確後，再逐步允許編輯、指令或外部工具。

## 工作區與記憶

Agent 的第一個可存取目錄會作為主要工作區。部分功能會在工作區中儲存持久檔案，例如自主模式的靈魂檔案和 Agent 工作區記憶。

如果兩個 Agent 使用同一個第一可存取目錄，它們可能會讀寫同一組工作區檔案。需要隔離專案或身分時，請為每個 Agent 使用不同目錄。

工作區記憶的檔案結構和使用方式請參閱 [Agent 工作區記憶](memory.md)。

## 常見問題

### Agent 頁面提示 API 伺服器未執行

請先按一下頁面中的啟動按鈕。如果啟動失敗：

1. 開啟**設定 → API 伺服器**。
2. 檢查連接埠是否由其他程式占用。
3. 重新啟動服務，再返回 Agent 頁面。

### 建立時沒有可選模型

Agent 只會顯示支援 Anthropic Messages 端點的對話模型。請檢查模型是否已新增至模型服務，以及端點功能是否正確；Embedding、Rerank 和圖像產生模型不會顯示。

### 無法啟用技能

請先儲存 Agent。技能的啟用狀態依 Agent ID 儲存；新建但尚未儲存的 Agent 沒有可以綁定的 ID。

### 找不到某個 MCP Server

前往**設定 → MCP 伺服器**，確認 Server 已新增並啟用。Agent 的新增清單只允許選擇處於啟用狀態的 Server。

### 每次編輯或執行指令都會詢問

這是一般模式的預期行為。請依風險選擇自動編輯模式，或在能力擴充中調整特定工具。不要只是為了減少提示就直接切換至全自動模式。

### 任務提前停止或重複執行

請依序檢查：

1. 模型是否穩定支援工具呼叫。
2. 工具傳回內容是否包含錯誤或缺少必要資料。
3. 提示詞是否提供明確的終止條件。
4. 最大執行輪次是否太低。
5. 自主模式或心跳是否讓任務在不適合的情境下持續執行。
