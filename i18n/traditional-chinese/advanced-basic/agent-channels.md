# 頻道

頻道可以將 Cherry Studio 中的 [Agent](agent.md) 接入即時通訊平台。成員在群組或私訊中傳送訊息後，綁定的 Agent 會在 Cherry Studio 中處理要求，並將結果回覆到原會話。

目前支援：

* 飛書 / Lark
* Telegram
* QQ
* 微信
* Discord
* Slack

例如，你可以讓知識助手回答飛書群組中的內部問題，讓個人助理透過 Telegram 接收指令，或讓[排程任務](scheduled-tasks.md)將日報主動傳送到指定頻道。

{% hint style="info" %}
頻道由 Cherry Studio 在本機執行。應用程式結束後，頻道連線及訊息處理也會停止；重新開啟應用程式後，已啟用且已綁定 Agent 的頻道會自動重新連線。頻道不依賴 API Server。
{% endhint %}

## 使用前準備

新增頻道前，請先：

1. 建立並設定一個可正常對話的 [Agent](agent.md)。
2. 為 Agent 選擇可用模型，並確認服務商設定有效。
3. 準備目標平台要求的機器人憑證，或使用飛書、微信提供的掃碼接入方式。

頻道可以綁定一般 Agent，也可以綁定已啟用自主模式的 Agent。手動建立頻道不要求自主模式；如果希望 Agent 自行建立頻道、排查連線或聯動任務，建議使用已啟用自主模式的 Agent，並謹慎檢查其工具權限。

## 新增頻道

開啟 `設定 → 頻道`，選擇目標平台，然後按一下**新增**。

需要設定的通用項目包括：

| 設定項目 | 說明 |
|---|---|
| 名稱 | 用於區分同一平台下的多個頻道實例 |
| 綁定代理 | 負責處理頻道訊息的 Agent；未綁定時，頻道不會建立連線 |
| 平台憑證 | 不同平台需要的 App ID、Token 或 Secret |
| 允許的聊天 ID | 限制哪些會話可以使用機器人 |
| 頻道權限模式 | 繼承 Agent 設定，或只為此頻道指定權限模式 |
| 啟用狀態 | 啟用後立即嘗試連線；關閉後保留設定但中斷連線 |

同一平台可以新增多個實例，一個 Agent 也可以綁定多個頻道。例如，同一個 Agent 可以同時連線飛書群組和 Telegram 私訊，但各個頻道實例仍可使用不同的憑證、允許清單及權限模式。

儲存後，可以在頻道詳細資料中查看連線狀態。修改啟用狀態、憑證或綁定 Agent 時，Cherry Studio 會重新連線該實例。

## 依平台填寫設定

{% tabs %}
{% tab title="飛書 / Lark" %}
飛書和 Lark 支援兩種接入方式：

* **掃碼接入**：不填寫 App ID 和 App Secret，啟用後掃描頁面中的 QR Code。註冊完成後，Cherry Studio 會儲存取得的憑證並重新連線。
* **手動接入**：填寫自建應用程式的 App ID 和 App Secret，並選擇 `飛書` 或 `Lark` 網域。Encrypt Key 和 Verification Token 依應用程式設定選填。

手動建立應用程式時，需要在對應的開放平台中啟用機器人功能、訊息權限及長連線事件訂閱。飛書與 Lark 的應用程式和網域不能混用。
{% endtab %}

{% tab title="Telegram" %}
使用 Telegram 的 Bot Token。你可以透過 BotFather 建立機器人並取得 Token。

允許清單使用 Telegram Chat ID。機器人連線成功後，可以在目標私訊或群組中傳送 `/whoami`，取得目前的 Chat ID。
{% endtab %}

{% tab title="QQ" %}
填寫 QQ 機器人應用程式的 App ID 和 Client Secret。

允許清單支援包含類型的會話 ID，例如：

* `c2c:openid`：一對一聊天
* `group:groupid`：群組聊天
* `channel:channelid`：頻道
* `dm:guildid`：頻道私訊

傳送 `/whoami` 可以查看目前會話的類型及 ID。
{% endtab %}

{% tab title="微信" %}
微信透過掃碼登入，不需要手動填寫 Token。新增實例並啟用後，使用微信掃描 QR Code 完成登入；登入憑證會儲存在 Cherry Studio 的本機資料目錄中。

允許清單填寫微信使用者 ID。你可以在會話中傳送 `/whoami` 取得目前的 ID。
{% endtab %}

{% tab title="Discord" %}
填寫 Discord Bot Token，並將機器人邀請到目標伺服器。

允許清單填寫 Discord Channel ID；也可以在目標頻道或私訊中傳送 `/whoami`，複製 Cherry Studio 傳回的會話 ID。
{% endtab %}

{% tab title="Slack" %}
Slack 使用 Socket Mode，需要同時填寫：

* Bot Token，通常以 `xoxb-` 開頭
* App-Level Token，通常以 `xapp-` 開頭

安裝應用程式並授予訊息權限後，將機器人加入目標頻道。允許清單填寫 Slack Channel ID，可以傳送 `/whoami` 取得。
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
機器人憑證等同於帳號存取憑證。不要將 Token 或 Secret 傳送到公開對話、截圖或文件中；如果懷疑憑證外洩，請立即前往對應平台撤銷並重新產生。
{% endhint %}

## 限制可存取的會話

「允許的聊天 ID」是頻道的存取控制：

* **留空**：任何能向機器人傳送訊息的會話都可以觸發 Agent。
* **填寫 ID**：只有清單中的會話可以觸發 Agent，其他訊息會被忽略。

允許清單留空時，Cherry Studio 會自動記錄曾與機器人成功互動的會話 ID。這些記錄也可以作為[排程任務](scheduled-tasks.md)的主動傳送目標。

建議先在目標會話中傳送 `/whoami`，複製傳回的 ID，再將它加入允許清單。用於群組或多人環境時，不建議長期留空。

## 設定頻道權限

頻道權限決定從該頻道進入的要求可以如何呼叫 Agent 工具。預設選擇**繼承智能體設定**；也可以為目前頻道覆寫為：

* **預設模式**：執行敏感操作前，依預設規則要求確認。
* **接受編輯**：自動接受檔案編輯，其他高風險操作仍會受到限制。
* **略過權限**：不再要求確認，風險最高。
* **規劃模式**：優先分析並制定方案，不直接執行修改。

頻道權限會在每次收到訊息時套用，因此修改後也會對現有會話生效。

{% hint style="danger" %}
即時通訊中的訊息屬於外部輸入。只有在 Agent 的工作區、工具和允許清單都受到嚴格限制時，才考慮使用「略過權限」。不要讓公開群組中的機器人存取敏感目錄或憑證。
{% endhint %}

## 在頻道中使用命令

連線成功後，可以向機器人傳送：

| 命令 | 作用 |
|---|---|
| `/new` | 為目前頻道切換到新會話 |
| `/compact` | 壓縮目前的會話上下文 |
| `/help` | 查看 Agent 資訊及可用命令 |
| `/whoami` | 查看目前的會話 ID，用於設定允許清單 |

如果同一頻道需要服務不同團隊，或承擔不同權限層級的工作，建議建立獨立的頻道實例，分別設定 Agent、允許清單及權限，而不是共用一套高權限設定。

## 與排程任務搭配使用

頻道既可以接收訊息，也可以作為[排程任務](scheduled-tasks.md)的傳送目標：

1. 先建立並連線頻道。
2. 至少在目標會話中與機器人互動一次，或直接填寫允許的聊天 ID。
3. 建立排程任務，並選擇要推送的頻道。

如果允許清單留空，且目標會話從未與機器人互動，Cherry Studio 可能沒有可用的主動傳送目標。

## 排查連線問題

### 儲存後仍顯示未連線

請依序檢查：

1. 頻道是否已啟用並綁定 Agent。
2. Agent 的模型及服務商是否可正常使用。
3. Token、Secret、App ID 及平台網域是否相符。
4. 機器人是否已安裝到目標工作區、伺服器或群組，並取得訊息權限。
5. 開啟頻道詳細資料中的**紀錄**，查看即時連線錯誤。

修正錯誤設定並儲存後，Cherry Studio 會重新連線頻道。你也可以先關閉，再重新啟用該實例。

### 機器人在線但未回覆

* 檢查目前的會話 ID 是否在允許清單中。
* 在群組中確認機器人可以讀取訊息；部分平台要求 @ 機器人，或額外授予群組訊息權限。
* 確認 Cherry Studio 仍在執行。
* 檢查 Agent 的模型是否可用，以及頻道權限是否阻止所需工具。

### 掃碼後未完成連線

* 確認 QR Code 尚未過期；過期後請重新發起掃碼。
* 飛書 / Lark 必須使用與所選網域一致的用戶端帳號。
* 微信登入失效時，重新掃碼會更新本機登入憑證。

{% hint style="warning" %}
各平台對機器人、訊息保存及自動化行為有不同的服務條款與組織管理要求。將機器人加入企業群組或對外提供服務前，請確認已取得相應授權。
{% endhint %}
