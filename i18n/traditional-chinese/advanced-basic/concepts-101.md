# 概念入門：助手、Agent、技能、MCP 與頻道

Cherry Studio V2 將「與模型對話」和「讓模型執行任務」分成不同層級。理解以下概念後，就能更快判斷應從哪裡開始設定。

## 先看結論

| 概念 | 主要功能 | 典型情境 |
| :--- | :--- | :--- |
| 模型服務 | 提供模型和 API 存取能力 | 接入 DeepSeek、Claude、GPT 等模型 |
| 助手 | 儲存一套可重複使用的對話設定 | 翻譯、寫作、問答、知識庫檢索 |
| Agent | 在受控權限下呼叫工具並完成多步驟任務 | 處理檔案、執行指令、執行工作流程 |
| 技能 | 向 Agent 提供特定任務的說明、流程和資源 | 產生簡報、審閱程式碼、依團隊規範撰寫文件 |
| MCP | 以統一通訊協定連接外部工具和資料 | 搜尋網頁、讀取資料庫、呼叫第三方服務 |
| 頻道 | 將 Agent 接入即時通訊平台 | 在飛書、Telegram、Slack 等平台中使用 Agent |
| 排程任務 | 依單次、間隔或 Cron 排程執行 Agent | 每日簡報、週期性檢查、定時彙整 |

最常見的選擇方式如下：

* 只需要穩定的角色設定、模型參數或知識庫問答：使用**助手**。
* 需要 AI 讀取目錄、修改檔案、執行指令或連續呼叫工具：使用 **Agent**。
* Agent 缺少某種工作方法：安裝並啟用**技能**。
* 助手或 Agent 需要 Cherry Studio 以外的工具：設定 **MCP**。
* 希望團隊成員從聊天軟體中使用 Agent：設定**頻道**。
* 希望 Agent 在無人值守的情況下依排程執行：建立**排程任務**。

## 模型服務是能力來源

模型服務會儲存 API 位址、金鑰和模型清單。助手和 Agent 都需要選擇模型，但兩者的模型要求不同：

* 助手面向日常對話，可依情境選擇支援文字、視覺、推理或工具呼叫的模型。
* Agent 的模型選擇器只會顯示支援 Anthropic Messages 端點且適合對話執行的模型；Embedding、Rerank 和圖像產生模型不會顯示在這裡。

請先在**設定 → 模型服務**中完成設定，再建立助手或 Agent。具體步驟請參閱[模型服務](../pre-basic/providers/)。

## 助手：可重複使用的對話設定

助手用於儲存一套可長期重複使用的對話行為。除了名稱和提示詞，還可以設定模型、取樣參數、上下文數量、知識庫和 MCP 模式。

例如，你可以建立：

* 使用固定術語和輸出格式的翻譯助手。
* 連接產品資料知識庫的客服助手。
* 可以呼叫搜尋 MCP 的研究助手。

助手適合以對話為中心的任務。它可以檢索知識庫或呼叫已設定的 MCP 工具，但不會像 Agent 一樣取得本機工作目錄、檔案編輯權限和指令執行權限。

助手會在[資源庫](../cherrystudio/preview/library.md)中建立和維護，並在主要對話頁面中使用。繼續閱讀[助手庫](../cherrystudio/preview/agents.md)和[對話](../cherrystudio/preview/chat.md)。

## Agent：可執行的任務設定

Agent 除了提示詞和模型，還可以設定：

* 允許存取的本機目錄。
* 工具權限模式。
* 內建工具、MCP Server 和技能。
* 主要模型、規劃模型和小型模型。
* 最大輪次、環境變數、心跳等執行設定。

這些設定讓 Agent 可以圍繞一個目標持續執行多步驟操作，而不只是提供操作建議。例如，它可以讀取工作區檔案、修改文件、呼叫 MCP 服務，並將結果儲存在本機。

{% hint style="warning" %}
Agent 的權限範圍決定它可以讀寫哪些目錄，以及是否能直接執行工具。開始使用時應限制可存取目錄，並優先採用需要確認的權限模式；只有在明確瞭解風險時，才使用略過確認的模式。
{% endhint %}

Agent 頁面的底層依賴 Cherry Studio 的本機 **API 伺服器**。V2 會在建立 Agent 時自動嘗試啟動它，通常不需要先前往設定頁面手動設定；如果服務已停用或未能執行，Agent 頁面會顯示啟動提示。API 伺服器也可以供其他應用程式透過本機 HTTP 介面呼叫 Cherry Studio。詳見 [Agent](agent.md)和 [API 伺服器](api-server.md)。

## 技能：告訴 Agent「如何完成一類工作」

技能是一組可安裝的任務說明和配套資源。它更像工作手冊：說明觸發條件、執行步驟、品質要求，以及可能需要使用的指令碼或範本。

技能與 Agent 依 Agent ID 綁定。建立 Agent 時需要先儲存，之後才能在該 Agent 的**能力擴充 → 技能**中啟用技能。

適合使用技能的情況包括：

* 希望同一類任務每次都遵循固定流程。
* 需要重複使用團隊規範、範本或檢查清單。
* 想將一套成熟的方法交給多個 Agent 使用。

安裝、搜尋和管理方式請參閱[技能](../pre-basic/settings/skills.md)。

## MCP：為 AI 連接外部能力

MCP（Model Context Protocol）是連接 AI 應用程式與外部工具、提示和資源的通訊協定。Cherry Studio 可以新增本機 STDIO Server，也可以連接 SSE 或 Streamable HTTP Server。

MCP Server 可以向模型提供三類能力：

| 能力 | 用途 |
| :--- | :--- |
| Tools | 執行搜尋、查詢、寫入或呼叫 API 等操作 |
| Prompts | 提供可重複使用的提示範本 |
| Resources | 提供可讀取的資料或上下文 |

助手支援停用、自動和手動三種 MCP 模式；Agent 可以從已啟用的 MCP Server 中選擇要綁定的服務。

{% hint style="warning" %}
MCP Server 可能在本機執行程式，也可能將內容傳送至遠端服務。新增前應確認來源、指令、環境變數、存取目錄和遠端位址，並只授予完成任務所需的權限。
{% endhint %}

設定方法請參閱 [MCP 使用教學](mcp/)。

## 技能與 MCP 有什麼差異

兩者經常搭配使用，但解決的問題不同：

| 比較 | 技能 | MCP |
| :--- | :--- | :--- |
| 核心問題 | 告訴 Agent「如何做」 | 為模型提供「可以呼叫什麼」 |
| 主要內容 | 說明、流程、範本、指令碼和資源 | 工具、提示和資源介面 |
| 主要使用位置 | Agent | 助手和 Agent |
| 是否依賴外部服務 | 不一定 | 取決於特定 Server |

例如，「依團隊範本撰寫週報」可以製作成技能；「從專案管理系統讀取本週任務」則可以透過 MCP 提供。將兩者組合後，Agent 既知道寫作流程，也能取得所需資料。

## 頻道：將 Agent 接入聊天平台

頻道會將一個 Agent 綁定至即時通訊平台。Cherry Studio V2 目前提供飛書 / Lark、Telegram、QQ、微信、Discord 和 Slack 的頻道設定。

頻道負責接收平台訊息、將訊息交給已綁定的 Agent 處理，再將結果傳回原平台。它不會取代 Agent 本身：模型、提示詞、工具、目錄和權限仍在 Agent 中設定。

頻道通常會在無人值守狀態下執行。啟用前應同時檢查：

* 綁定的 Agent 和模型是否正確。
* 允許回應的對話或頻道 ID 是否受到限制。
* Agent 是否具備完成任務所需的工具權限。
* 平台權杖和金鑰是否只儲存在對應設定中。

詳見[頻道](agent-channels.md)。

## 排程任務：依計畫執行 Agent

排程任務同樣以 Agent 為執行主體。你可以建立：

* 只執行一次的任務。
* 依固定間隔重複執行的任務。
* 使用 Cron 運算式排程的任務。

排程任務適合不需要等待人工輸入的工作。建立前，應先讓對應 Agent 在一般對話中成功完成相同任務，再為它設定適當的權限、逾時時間和執行排程。詳見[排程任務](scheduled-tasks.md)。

## 一套能力如何組合

以「每天彙整團隊專案進度並傳送至飛書群組」為例：

1. 在**模型服務**中設定 Agent 可以使用的模型。
2. 建立 **Agent**，寫明彙整規則和輸出格式。
3. 安裝並啟用團隊週報**技能**，固定寫作流程。
4. 透過 **MCP** 連接專案管理系統，讀取任務資料。
5. 建立**排程任務**，每天依計畫執行 Agent。
6. 建立飛書**頻道**，讓團隊成員也能從群組對話中繼續查詢。

並非每個情境都需要全部功能。請先從助手或 Agent 開始，只在出現明確需求時增加技能、MCP、頻道或排程任務，設定會更容易維護。

## 建議學習順序

1. 設定[模型服務](../pre-basic/providers/)，完成一次一般對話。
2. 透過[資源庫](../cherrystudio/preview/library.md)建立助手，熟悉提示詞、模型和知識庫。
3. 建立 [Agent](agent.md)，從受限目錄和需要確認的權限開始。
4. 依任務新增[技能](../pre-basic/settings/skills.md)或 [MCP](mcp/)。
5. Agent 穩定執行後，再設定[排程任務](scheduled-tasks.md)和[頻道](agent-channels.md)。
