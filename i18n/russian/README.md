# Cherry Studio Community Edition

Cherry Studio — это настольный AI-клиент с открытым исходным кодом, который позволяет единообразно использовать облачные или локальные большие модели в Windows, macOS и Linux. Помимо диалогов с несколькими моделями, он объединяет в одном рабочем пространстве ассистентов, агентов, базы знаний, навыки, MCP, перевод, генерацию изображений, файлы, заметки и другие возможности.

Community Edition подходит пользователям и разработчикам, которые хотят самостоятельно выбирать сервисы моделей, локально управлять рабочими материалами и при необходимости расширять рабочие процессы AI.

## Что можно делать в Cherry Studio

| Задача | Возможности Cherry Studio |
| :--- | :--- |
| Использовать модели разных поставщиков или локальные модели | Настроить сервисы моделей в одном месте, переключаться между моделями в диалоге или одновременно сравнивать несколько моделей |
| Сохранить постоянную роль и настройки диалога | Создать ассистента и настроить промпт, параметры модели, базу знаний и MCP |
| Разрешить AI читать рабочую область и выполнять задачи | Создать агента и управлять доступными каталогами, инструментами и режимом подтверждения |
| Обеспечить соблюдение специализированного рабочего процесса | Установить навык и включить его для нужных агентов |
| Подключить поиск, базу данных или сторонний сервис | Добавить локальный или удалённый MCP Server |
| Создать собственную библиотеку для поиска по материалам | Импортировать документы и настроить модель Embedding |
| Работать с изображениями, переводами, заметками и файлами | Использовать отдельные рабочие пространства для генерации изображений, перевода, заметок и файлов |
| Запускать агента через мессенджер или в заданное время | Настроить каналы и запланированные задачи |

## Основные рабочие пространства

На боковой панели Cherry Studio V2 можно по необходимости отображать следующие приложения:

* **Диалог** — общение с ассистентами и моделями, управление сеансами и сообщениями.
* **Агент** — выполнение задач, требующих работы с файлами, команд или многоэтапных вызовов инструментов.
* **Библиотека ресурсов** — централизованное управление ассистентами, агентами, навыками и промптами.
* **Генерация изображений** — создание изображений с помощью соответствующих моделей и управление ими.
* **Перевод** — двуязычный перевод и параллельное чтение.
* **Мини-программы** — открытие добавленных веб-инструментов внутри приложения.
* **База знаний** — импорт материалов, разбиение на фрагменты и поиск.
* **Файлы** — централизованный просмотр и управление файловыми ресурсами приложения.
* **Code Tools** — управление инструментами для разработчиков.
* **Заметки** — редактирование и упорядочивание заметок Markdown.
* **OpenClaw** — отдельное рабочее пространство автономного агента.

На боковой панели отображаются только включённые разделы. Если скрыть раздел, связанные с ним данные не удаляются.

## Быстрый старт

### 1. Загрузка и установка

Откройте страницу [Загрузка клиента](cherrystudio/download.md) и выберите версию для своей системы. При первой установке или появлении предупреждения системы безопасности обратитесь к [Инструкции по установке](pre-basic/installation/).

Cherry Studio поддерживает Windows, macOS и Linux. Установочные пакеты различаются в зависимости от системы и архитектуры процессора, поэтому следуйте пояснениям на странице загрузки.

### 2. Настройка сервиса моделей

Откройте **Настройки → Сервисы моделей**:

1. Выберите существующего поставщика или добавьте совместимого.
2. Укажите адрес API и API Key.
3. Получите список моделей и включите нужные.
4. Вернитесь на страницу диалога, выберите модель и отправьте первое сообщение.

Если используется локальный сервис, например Ollama или LM Studio, сначала убедитесь, что он запущен на компьютере. Подробные инструкции см. в разделе [Сервисы моделей](pre-basic/providers/).

### 3. Начните с одного сценария

* Повседневные вопросы, написание текстов или перевод: начните со страницы [Диалог](cherrystudio/preview/chat.md).
* Нужны постоянный промпт и параметры: создайте ассистента в [Библиотеке ресурсов](cherrystudio/preview/library.md).
* Нужно работать с локальными файлами или запускать инструменты: создайте [агента](advanced-basic/agent.md).
* Нужны ответы на основе личных материалов: создайте [базу знаний](knowledge-base/knowledge-base.md).

Необязательно настраивать сразу все возможности. Сначала выполните одну небольшую задачу с проверяемым результатом, а затем добавляйте навыки, MCP или автоматизацию — так будет проще находить причины проблем.

## Ассистенты, агенты и расширение возможностей

### Ассистент

Ассистент сохраняет повторно используемые настройки диалога: промпт, параметры модели, базу знаний и MCP. Он подходит для стабильных сценариев, основанных преимущественно на общении.

### Агент

Агент может обращаться к указанным каталогам и вызывать встроенные инструменты, MCP и навыки. Для него можно выбрать обычный режим, режим планирования, автоматического редактирования или полностью автоматический режим разрешений. Подробнее см. в разделе [Агент](advanced-basic/agent.md).

### Навыки и MCP

* [Навыки](pre-basic/settings/skills.md) объясняют агенту, как выполнять определённый тип работы по заданному процессу.
* [MCP](advanced-basic/mcp/) подключает ассистента или агента к внешним инструментам, промптам и ресурсам.

Если вы ещё не определились с выбором, начните с раздела [Основные понятия](advanced-basic/concepts-101.md).

## Данные и безопасность

Настройки приложения и рабочие материалы Cherry Studio преимущественно хранятся локально, но использование настольного приложения не означает, что вся обработка выполняется только на компьютере:

* При использовании облачной модели сообщения, вложения и найденный контекст отправляются выбранному поставщику модели в объёме, необходимом для выполнения запроса.
* При использовании удалённого MCP Server, канала или другого стороннего сервиса связанные данные могут быть переданы этому сервису.
* Агенты и локальные MCP Server могут читать файлы или выполнять команды в соответствии с предоставленными разрешениями.
* Локальные модели позволяют сократить передачу данных в облако, однако всё равно следует проверять подключённые сервисы моделей, плагины и сетевые инструменты.

{% hint style="warning" %}
Не добавляйте API Key, токены доступа, пароли или закрытые ключи в промпты, базы знаний, документы и снимки экрана. Ограничивайте каталоги, доступные агенту, предоставляйте MCP и каналам только минимально необходимые разрешения и проверяйте работу в контролируемой среде до включения полностью автоматического режима.
{% endhint %}

Регулярно создавайте резервные копии важных данных. Cherry Studio поддерживает локальный экспорт, а также резервное копирование в WebDAV, S3-совместимое хранилище и другие системы. Доступные варианты описаны в разделе [Настройки данных](data-settings/).
