# Настройки данных

Откройте **Настройки → Настройки данных**, чтобы управлять каталогом данных приложения, параметрами импорта и экспорта, кэшем, журналами и подключениями к сервисам заметок.

{% hint style="warning" %}
Встроенная функция Backup & Restore V2 пока недоступна. На страницах «Данные», «Локальная резервная копия», WebDAV, Nutstore и S3 отображается предупреждение о недоступности Backup & Restore V2, а элементы резервного копирования отключены. Не полагайтесь на эти разделы для сохранения или восстановления важных данных.
{% endhint %}

## Обзор страниц

| Группа | Страница | Текущее назначение |
| --- | --- | --- |
| Данные | Данные | Просмотр и перенос каталога данных приложения, открытие журналов, очистка кэша, сброс данных и параметры конфиденциальности |
| Облачное резервное копирование | Локальная копия, WebDAV, Nutstore, S3 | Страницы видимы, но резервное копирование, восстановление, автоматическая синхронизация и ввод учётных данных недоступны |
| Импорт | Импорт данных приложения | Выбор источников, отображаемых в меню импорта |
| Экспорт | Меню экспорта | Выбор форматов и назначений, отображаемых в меню экспорта диалога |

## Страница «Данные»

### Каталог данных приложения

В строке **Данные приложения** отображается каталог, который фактически использует текущий экземпляр. Нажмите путь или **Открыть каталог**, чтобы просмотреть его в системном файловом менеджере, либо значок смены каталога, чтобы начать перенос.

При переносе приложение перезапускается; могут копироваться база данных, внутренние файлы, базы знаний и заметки. Сначала прочитайте раздел [Изменение местоположения хранилища](../personalization-settings/storage.md), подготовьте автономную копию и выберите пустой целевой каталог.

### Журналы приложения

Нажмите **Открыть журналы**, чтобы открыть каталог журналов. При отправке отчёта прикладывайте только записи, относящиеся ко времени сбоя, и сначала проверьте их на наличие путей, запросов и других конфиденциальных данных.

### Очистка кэша

**Очистить кэш** удаляет восстанавливаемый кэш и локальные данные Trace. Это не равно удалению диалогов или полному сбросу приложения. Не используйте очистку кэша как универсальное решение проблем со входом, моделями или базами знаний.

### Сброс данных

**Сброс данных** — разрушительная операция: она очищает данные текущего экземпляра и возвращает его в начальное состояние. Встроенное резервное копирование сейчас недоступно, поэтому не выполняйте сброс без независимой копии.

## Настройки импорта

**Импорт данных приложения** определяет, какие источники отображаются в меню импорта. Изменяются только пункты меню; данные других приложений не считываются автоматически в фоновом режиме.

Перед импортом убедитесь, что файл получен из доверенного источника, и сохраните оригинал. Результат зависит от формата источника и поддержки в текущей версии.

## Настройки экспорта

### Меню экспорта

Выберите форматы и сторонние назначения, которые будут отображаться при экспорте диалога. Отключение пункта лишь скрывает его и не удаляет ранее экспортированные файлы.

### Экспорт Markdown

Настройте каталог сохранения, правила имени файла, а также включение сведений о модели, ссылок, формул и других данных. Используйте каталог вне каталога данных приложения, чтобы архивировать экспорт независимо.

### Экспорт заметок

Для Notion, Yuque, Joplin, Obsidian и SiYuan используются отдельные настройки. После ввода адреса сервиса, токена или локального каталога экспортируйте одну тестовую запись без конфиденциальных данных и проверьте назначение и формат перед массовым экспортом.

{% hint style="info" %}
Экспорт выполняется в одном направлении, не является двусторонней синхронизацией и не заменяет полную резервную копию. Внешние вложения, индексы баз знаний и внутреннее состояние приложения могут не входить в результат.
{% endhint %}

## Как защитить данные сейчас

До выпуска Backup & Restore V2:

1. Запишите текущий каталог, отображаемый в строке **Данные приложения**.
2. Полностью закройте Cherry Studio.
3. Скопируйте весь каталог на другой диск и убедитесь, что копия читается.
4. Сохраняйте оригинальные файлы важных материалов и экспортируйте необходимые диалоги.

Не копируйте и не объединяйте файлы базы данных во время работы приложения. После выпуска функции резервного копирования следуйте текущему состоянию приложения и последней версии этой страницы.
