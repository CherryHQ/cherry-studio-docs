# Настройка и экспорт Notion

Cherry Studio V2 может экспортировать тему или отдельное сообщение в базу данных Notion. При каждом экспорте в целевой базе создаётся новая страница, а преобразованное содержимое записывается в её тело.

Настройки перенесены в **Настройки > Интеграции > Notion**. Раздел **Настройки данных > Меню экспорта** только показывает или скрывает пункт «Экспортировать в Notion» и не предназначен для данных подключения.

{% hint style="warning" %}
Token Notion является учётными данными доступа интеграции. Не показывайте полный Token на снимках, в отчётах и общей конфигурации и не добавляйте его на публичные страницы.
{% endhint %}

## Обзор настройки

Для подключения нужны четыре шага:

1. Создать внутреннюю интеграцию Workspace в Notion.
2. Создать целевую базу данных и предоставить к ней доступ интеграции.
3. Получить ID базы данных и имя свойства заголовка.
4. Ввести три параметра в Cherry Studio и выполнить проверку.

## Создание внутренней интеграции Notion

1. Откройте [Notion Integrations](https://www.notion.so/profile/integrations).
2. Создайте новую внутреннюю интеграцию.
3. Выберите Workspace для экспортируемого содержимого.
4. Укажите понятное имя, например `Cherry Studio`.
5. Разрешите как минимум чтение и вставку содержимого.
6. После сохранения скопируйте внутренний Token интеграции.

Внутренняя интеграция относится только к выбранному Workspace. Если целевая база находится в другом Workspace, создайте или установите там отдельную доступную интеграцию.

Интерфейс и термины Notion могут измениться. Если путь создания отличается, см. [официальное руководство Notion по внутренним интеграциям](https://developers.notion.com/guides/get-started/internal-connections).

## Создание целевой базы данных

Создайте в Notion базу данных для страниц, экспортируемых Cherry Studio. Можно использовать таблицу, список или доску, но основой должна быть база данных, а не обычная страница или связанное представление только для просмотра.

В базе должно быть хотя бы одно свойство типа **Title**. Новая база обычно содержит столбец заголовка `Name`, который можно переименовать.

{% hint style="info" %}
Поле «Имя свойства заголовка страницы» в Cherry Studio зависит от фактического имени свойства, а не языка интерфейса Notion. В интерфейсе на любом языке свойство может называться `Name` или быть переименовано.
{% endhint %}

## Предоставление доступа интеграции

Создание Token само по себе не даёт доступа ко всем страницам. Предоставьте интеграции доступ к целевой базе:

1. Откройте исходную страницу целевой базы данных.
2. Откройте меню страницы или настройки общего доступа справа вверху.
3. Найдите **Connections / Добавить подключение**.
4. Найдите и выберите созданную внутреннюю интеграцию.
5. Убедитесь, что она появилась в списке подключений базы.

Также можно добавить целевую страницу через **Content access** интеграции в Notion Developer Portal. В любом случае предоставьте доступ самой базе данных, а не связанному представлению без доступа к исходным данным.

По документации Notion API обычно возвращает 404 для базы, не предоставленной интеграции, вместо явного сообщения об отсутствии прав.

## Получение ID базы данных

Откройте целевую базу в браузере и скопируйте ссылку. Например:

```text
https://www.notion.so/workspace/Tasks-0123456789abcdef0123456789abcdef?v=...
```

ID базы данных — 32-значный идентификатор до `?`:

```text
0123456789abcdef0123456789abcdef
```

Он также может выглядеть как UUID с дефисами. Не копируйте:

- ID представления после `v=`
- Полный URL страницы
- ID обычной родительской страницы
- Идентификатор связанного представления, не относящийся к исходной базе

Если в ссылке есть префикс заголовка, возьмите 32-значный ID из последней части. Если не уверены, откройте базу как полную страницу и скопируйте ссылку снова.

## Получение имени свойства заголовка

Найдите в свойствах целевой базы столбец типа **Title** и точно скопируйте его имя.

Например:

| Фактическое имя свойства Notion | Значение для Cherry Studio |
| --- | --- |
| `Name` | `Name` |
| `名称` | `名称` |
| `Title` | `Title` |
| `对话标题` | `对话标题` |

Важны символы, пробелы и регистр. Не указывайте имя базы, имя страницы или обычное текстовое свойство.

## Подключение в Cherry Studio

Откройте **Настройки > Интеграции > Notion** и введите по порядку:

1. **ID базы данных Notion**
2. **Имя свойства заголовка страницы**
3. **Секрет Notion**

Нажмите **Проверить** рядом с полем Token. Успешная проверка означает:

- Token действителен
- Cherry Studio может прочитать целевую базу через Token
- База с указанным Database ID доступна интеграции

Проверка не подтверждает правильность «Имени свойства заголовка страницы» и не создаёт тестовую страницу. После неё всё равно выполните реальный экспорт.

## Выбор экспорта содержимого рассуждений

Если включить **Включать цепочку рассуждений при экспорте**, Cherry Studio при наличии добавит в Notion содержимое размышлений и рассуждений сообщения.

Если выключить, экспортируется только обычный ответ. Рекомендуется оставить выключенным, когда:

- Экспорт будет передан клиенту или опубликован
- Рассуждения содержат черновики, внутренние сведения или нежелательные промежуточные этапы
- Нужно сохранить только окончательный ответ

Параметр не заставляет модель создавать рассуждения, которых у неё не было.

## Включение меню экспорта Notion

Если в меню чата нет пункта «Экспортировать в Notion»:

1. Откройте **Настройки > Настройки данных > Меню экспорта**.
2. Включите **Экспортировать в Notion**.
3. Вернитесь в чат и заново откройте меню темы или сообщения.

Этот параметр управляет только видимостью меню и не исправляет Token, права или конфигурацию базы.

## Первый экспорт

Сначала проверьте короткий чат без конфиденциальных данных:

1. Откройте меню темы или отдельного сообщения.
2. Выберите **Экспортировать в Notion**.
3. Дождитесь сообщения об успешном экспорте.
4. Откройте целевую базу.
5. Проверьте заголовок, абзацы, блоки кода, списки и формулы новой страницы.

Cherry Studio создаёт страницу базы с заголовком темы или сообщения. Заголовок длиннее 32 символов сокращается и получает многоточие.

Экспорт Notion использует процесс преобразования Markdown Cherry Studio. Некоторые параметры в **Настройки данных > Экспорт Markdown**, например обозначения формул, данные модели и обработка цитат, также могут влиять на результат.

## Границы прав и данных

- Cherry Studio вызывает Notion API напрямую через Token; вход в Notion в браузере не нужен.
- Интеграция видит только явно разрешённые страницы и базы данных.
- Экспорт создаёт новую страницу и добавляет блоки тела, не объединяя и не перезаписывая одноимённые страницы.
- Удаление чата в Cherry Studio не удаляет ранее экспортированную страницу Notion.
- После отзыва прав или удаления Token последующий экспорт завершится ошибкой, но существующие страницы сохранятся.

## Часто задаваемые вопросы

### Проверка сообщает, что API Key или Database ID не настроен

Убедитесь, что секрет Notion и ID базы не пусты. Не вставляйте полный URL базы в поле ID.

### Возвращается 401 или Token недействителен

Token мог быть скопирован не полностью, отозван или относиться к другому Workspace. Проверьте интеграцию в Notion Integrations и скопируйте Token снова.

### Возвращается 403

Убедитесь, что интеграция может читать и вставлять содержимое. Для проверки нужно чтение базы, а для экспорта — создание страницы и добавление содержимого.

### Возвращается 404, хотя база открывается в браузере

Обычно база не предоставлена интеграции или указан ID представления либо обычной страницы. Добавьте целевую базу в Connections и скопируйте её ID заново.

### Проверка успешна, но экспорт не работает

Наиболее частая причина — неверное **Имя свойства заголовка страницы**. Это должно быть имя свойства типа Title в целевой базе, а не её заголовок. Также проверьте право вставки содержимого.

### Страница создана, но тело отсутствует или формат нарушен

Дождитесь полного завершения экспорта и обновите Notion. Сложный Markdown, вложенное содержимое и ограничения Notion API могут повлиять на отдельные блоки. Проверьте короткий текст и настройки экспорта Markdown в Cherry Studio.

### В меню чата нет Notion

Включите **Экспортировать в Notion** в разделе **Настройки > Настройки данных > Меню экспорта**. Если уже включено, заново войдите в текущий чат и проверьте меню.

Если проблема сохраняется, отправьте через [Обратная связь и предложения](../../question-contact/suggestions.md) версию Cherry Studio, код состояния Notion, обезличенный Database ID, имя поля заголовка и полный текст ошибки.
