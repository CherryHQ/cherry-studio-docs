# Настройка подписки на ассистентов

Подписка на ассистентов позволяет назначить общедоступный адрес JSON **источником данных для библиотеки шаблонов ассистентов**. Команде достаточно поддерживать один список шаблонов, а участники увидят актуальные данные после повторной загрузки библиотеки ассистентов.

{% hint style="info" %}
Подписка предоставляет доступные для выбора **шаблоны**. Она не изменяет собственные шаблоны в группе «Мои» и не обновляет автоматически уже созданных ассистентов. После добавления шаблона из подписки в качестве ассистента он становится независимой локальной копией.
{% endhint %}

## Подготовка к подписке

Сначала подготовьте общедоступный адрес, который напрямую возвращает JSON, например Raw-файл в объектном хранилище, на статическом сайте или в репозитории кода.

Адрес подписки должен соответствовать следующим условиям:

- рекомендуется использовать `https://`;
- доступ не должен требовать входа, Cookie или заголовков запроса;
- адрес должен напрямую возвращать JSON, а не страницу загрузки, предпросмотра или HTML;
- корневой узел JSON является массивом;
- каждый шаблон содержит как минимум `id`, `name`, `prompt` и `group`;
- `id` уникален в пределах одной подписки, а `group` является массивом строк.

{% hint style="warning" %}
Cherry Studio напрямую считывает данные с этого адреса. Сейчас нет полей для ввода имени пользователя, пароля или пользовательских заголовков запроса. Не добавляйте токены доступа, API Key или другие учётные данные в URL подписки или файл JSON.
{% endhint %}

## Настройка подписки

1. Откройте **Панель запуска** Cherry Studio.
2. Перейдите в **Библиотеку ассистентов**.
3. Нажмите **Импортировать извне** в правом верхнем углу.
4. Найдите раздел **Подписка на ассистентов** в нижней части окна.
5. Вставьте адрес подписки и нажмите **Подписаться**.
6. После перезагрузки приложения вернитесь в библиотеку ассистентов и проверьте удалённые шаблоны и группы.

Успешная подписка означает только, что адрес доступен в данный момент. Если возвращённые данные не являются допустимым массивом шаблонов, библиотека ассистентов всё равно может отображаться неправильно. Рекомендуется проверить JSON по инструкции ниже.

## Формат JSON

Минимальный пример, который можно использовать как отправную точку:

```json
[
  {
    "id": "product-manager",
    "name": "Менеджер продукта",
    "emoji": "🧭",
    "description": "Помогает уточнить требования, границы и план продукта.",
    "group": ["Продукт", "Работа"],
    "prompt": "Вы опытный менеджер продукта. Сначала уточните цель и ограничения, затем предложите структурированные и выполнимые рекомендации.",
    "regularPhrases": []
  },
  {
    "id": "writing-editor",
    "name": "Литературный редактор",
    "emoji": "✍️",
    "description": "Проверяет структуру, формулировки и удобство чтения.",
    "group": ["Тексты"],
    "prompt": "Вы профессиональный редактор. Сохраните замысел автора, укажите конкретные проблемы и предложите готовую исправленную версию.",
    "regularPhrases": []
  }
]
```

### Описание полей

| Поле | Рекомендуется заполнять | Описание |
| --- | --- | --- |
| `id` | Да | Стабильный уникальный идентификатор шаблона. Не используйте одно значение для двух шаблонов. |
| `name` | Да | Имя шаблона, отображаемое в библиотеке ассистентов. |
| `prompt` | Да | Системный промпт, который используется после создания ассистента. |
| `group` | Да | Группы шаблона; обязательно задаются массивом, например `["写作", "工作"]`. Шаблон может входить в несколько групп. |
| `emoji` | Нет | Значок шаблона; без него в интерфейсе может не быть ожидаемого значка. |
| `description` | Нет | Краткое описание шаблона для предпросмотра и поиска. |
| `regularPhrases` | Нет | Массив часто используемых фраз; если он не нужен, укажите `[]` или пропустите поле. |

{% hint style="warning" %}
`group` необходимо задавать массивом, даже если значение только одно. Запись `"group": "写作"` не позволит правильно загрузить шаблон по группам.
{% endhint %}

## Проверка файла подписки

Перед публикацией проверьте как минимум следующее:

1. Откройте адрес подписки напрямую в браузере и убедитесь, что отображается исходный JSON.
2. Проверьте с помощью валидатора JSON, что нет лишних запятых, пропущенных кавычек или непарных скобок.
3. Убедитесь, что корневой узел — `[]`, а не `{}`.
4. Убедитесь, что у каждого шаблона есть непустые `name` и `prompt`.
5. Убедитесь, что каждый `group` является массивом, а каждый `id` уникален.
6. Сначала проверьте один-два шаблона, а затем постепенно расширяйте список.

Если вы знакомы с командной строкой, доступность адреса и корректность JSON можно проверить так:

```bash
curl -fsSL "https://example.com/assistants.json" | jq .
```

Замените адрес в примере своим общедоступным адресом подписки.

## Как обновляется подписка

Подписка на ассистентов не является службой push-уведомлений и не имеет фиксированного цикла фоновой синхронизации.

- Cherry Studio повторно запрашивает адрес подписки при загрузке шаблонов ассистентов;
- после изменения удалённого JSON перезагрузите приложение или повторно войдите в библиотеку ассистентов, чтобы увидеть новые данные;
- удалённый список заменяет встроенный источник шаблонов, но собственные шаблоны в группе «Мои» не удаляются;
- если удалённый адрес временно недоступен, приложение пытается вернуться к встроенным шаблонам;
- ассистент, уже созданный из шаблона, является независимой копией и не меняется вместе с удалённым JSON.

Чтобы изменить уже созданного ассистента, редактируйте его напрямую, а не только файл подписки.

## Отмена подписки или смена адреса

1. Откройте **Библиотека ассистентов > Импортировать извне**.
2. В разделе **Подписка на ассистентов** нажмите **Отписаться**.
3. Дождитесь перезагрузки приложения, после чего снова будут использоваться встроенные шаблоны.
4. Чтобы сменить источник данных, снова откройте это окно, введите новый адрес и подпишитесь.

Если подписка уже активна, кнопка выполняет отписку. Чтобы сменить адрес, сначала отмените текущую подписку, а затем подпишитесь по новому адресу.

## Отличия от импорта

В Cherry Studio есть несколько похожих функций с разным назначением:

| Функция | Результат | Подходящий сценарий |
| --- | --- | --- |
| Подписка на ассистентов | Удалённый JSON становится источником шаблонов ассистентов и считывается заново при загрузке библиотеки | Единое ведение и регулярное обновление набора шаблонов командой |
| Импорт URL / файла в библиотеке ассистентов | Шаблон сразу копируется в группу «Мои» и больше не связан с исходным файлом | Однократный импорт с последующим самостоятельным редактированием |
| [Импорт в библиотеку ресурсов V2](../cherrystudio/preview/library.md) | Создание ассистентов библиотеки ресурсов из файла, буфера обмена или поддерживаемого Raw URL | Централизованное управление ассистентами в библиотеке ресурсов V2 |

{% hint style="info" %}
Если нужно поделиться только одним ассистентом, лучше использовать экспорт и импорт. Подписка нужна, только когда требуется длительно поддерживать целый набор общедоступных шаблонов.
{% endhint %}

## Рекомендации по безопасности

- Подписывайтесь только на адреса, которыми управляете вы или доверенная команда;
- используйте HTTPS и ограничьте права на редактирование файла подписки;
- после обновления подписки выборочно проверяйте добавленные и изменённые промпты;
- не сохраняйте пароли, токены и личные данные в `prompt`, `description` или URL;
- включите контроль версий для важных файлов подписки, чтобы быстро откатиться при проблемах.

Промпты в шаблонах влияют на ответы ассистента. Прежде чем добавить шаблон в качестве ассистента, прочитайте промпт целиком и убедитесь, что в нём нет нежелательных инструкций.

## Частые вопросы

### После нажатия «Подписаться» по-прежнему видны встроенные шаблоны

Убедитесь, что адрес начинается с `http://` или `https://` и доступен без входа. Затем перезагрузите приложение и снова откройте библиотеку ассистентов.

### Адрес открывается, но группы не появляются

Проверьте, что корневой узел является массивом, а `group` каждого шаблона — массивом строк. Шаблон без допустимых групп не отображается правильно в списке категорий.

### Вместо JSON возвращается веб-страница

Возможно, скопирован адрес страницы предпросмотра файла в репозитории. Используйте адрес Raw-файла или разместите JSON по статическому адресу, который напрямую возвращает содержимое файла.

### После обновления JSON ассистент не изменился

Сначала перезагрузите приложение или снова откройте библиотеку ассистентов. Созданные ассистенты не синхронизируются автоматически: их нужно изменить вручную или создать заново из обновлённого шаблона.

### Удалённая служба временно недоступна

Cherry Studio попытается использовать встроенные шаблоны. После восстановления службы перезагрузите приложение; также рекомендуется проверить DNS, сертификат, перенаправления и междоменный доступ.
