# Резервное копирование WebDAV

Cherry Studio V2 может сохранять резервные копии в облачное хранилище, NAS или собственный сервер с поддержкой WebDAV. Резервную копию можно создать вручную либо настроить автоматическое создание по расписанию и ограничить число хранимых копий.

Здесь WebDAV — канал хранения для создания и восстановления резервных файлов, а не двусторонняя синхронизация между устройствами в реальном времени. Восстановление перезаписывает текущие данные и не объединяет чаты, добавленные на разных устройствах.

{% hint style="warning" %}
Резервная копия WebDAV может содержать чаты, конфигурацию провайдеров и другие конфиденциальные сведения. Используйте закрытый каталог и отдельный пароль приложения. Не публикуйте учётные данные и файлы резервных копий.
{% endhint %}

## Подготовка данных подключения

Получите на странице управления провайдера WebDAV или сервера:

| Поле | Что указать |
| --- | --- |
| Адрес WebDAV | Точка входа WebDAV, обычно полный адрес с `https://` |
| Имя пользователя WebDAV | Имя учётной записи, электронная почта или отдельное имя WebDAV, выданное провайдером |
| Пароль WebDAV | Обычный пароль или отдельный пароль приложения, созданный провайдером |
| Путь WebDAV | Удалённый каталог, в котором Cherry Studio хранит резервные копии |

Требования к адресу и аутентификации зависят от сервиса. Обычный адрес входа на сайт может не быть адресом WebDAV. После включения двухфакторной аутентификации обычно нужен пароль приложения, а не пароль учётной записи.

Удалённый путь по умолчанию — `/cherry-studio`. Если каталога нет, Cherry Studio попытается рекурсивно создать его при первой загрузке. Рекомендуется отдельный каталог Cherry Studio, чтобы резервные копии не смешивались с другими файлами.

{% hint style="info" %}
В Cherry Studio V2 также есть отдельная страница резервного копирования **Nutstore**. Если нужно подключиться через авторизацию учётной записи Nutstore, используйте её. Эта страница предназначена для ручного ввода универсальных параметров WebDAV.
{% endhint %}

## Настройка в Cherry Studio

1. Откройте **Настройки > Настройки данных > WebDAV**.
2. Введите **Адрес WebDAV**, сохранив `http://` или `https://`.
3. Введите **Имя пользователя WebDAV** и **Пароль WebDAV**.
4. Укажите удалённый путь, например `/cherry-studio`.
5. Пока оставьте **Автоматическое резервное копирование** выключенным.
6. Нажмите **Создать резервную копию в WebDAV** и создайте тестовую копию с именем по умолчанию.
7. После загрузки нажмите **Восстановить из WebDAV** и убедитесь, что созданный файл появился в диспетчере резервных копий.

На странице нет отдельной кнопки «Проверить соединение». Только успешная загрузка тестовой копии и её повторное отображение подтверждают работу адреса, аутентификации, создания пути и прав на запись.

При проверке используйте небольшой объём данных без конфиденциальных вложений, чтобы проще определить проблему. После подтверждения соединения решите, нужны ли полная и автоматическая резервные копии.

## Создание резервной копии вручную

После нажатия **Создать резервную копию в WebDAV** отображается имя по умолчанию, содержащее время, имя хоста и тип устройства. Его можно изменить. Если имя не заканчивается на `.zip`, Cherry Studio добавит расширение автоматически.

Параметр **Компактная резервная копия** исключает изображения, базы знаний и другие файловые данные из каталога приложения `Data`, сохраняя чаты, настройки и аналогичные данные. Это не инкрементная копия, и с её помощью нельзя вернуть исключённые файлы.

После завершения ручного копирования в удалённом каталоге остаётся отдельный ZIP-файл. Не закрывайте приложение, не отключайте сеть и не переводите систему в спящий режим во время загрузки.

## Настройка автоматического резервного копирования

Для **Автоматического резервного копирования** доступны:

- Выкл.
- 1, 5, 15 или 30 минут
- 1, 2, 6, 12 или 24 часа

Сначала выполните ручную проверку, затем выберите интервал. Чем выше частота, тем больше удалённых запросов и операций записи. Большие полные копии обычно не нужно создавать каждую минуту.

На странице отображаются время последней копии или последняя ошибка. «Ожидание следующего резервного копирования» означает, что успешной записи ещё нет, а не то, что соединение проверено.

### Ограничение числа копий

Для параметра **Максимальное число резервных копий** доступны: без ограничений, 1, 3, 5, 10, 20 или 50.

Автоматически удаляются только копии, созданные текущим устройством по стандартному шаблону имени. Cherry Studio определяет устройство по имени хоста и типу устройства в имени файла и удаляет старые файлы сверх лимита.

Файлы с пользовательским именем без идентификатора текущего устройства могут не удаляться автоматически. Режим «Без ограничений» также не освобождает удалённое пространство. Регулярно проверяйте объём в диспетчере резервных копий.

## Управление и восстановление

Нажмите **Восстановить из WebDAV**, чтобы открыть диспетчер резервных копий. В нём можно:

- Просматривать имя, время изменения и размер файла
- Обновлять список удалённых файлов
- Выбирать резервную копию для восстановления
- Удалять одну или несколько резервных копий

Перед восстановлением:

1. Создайте новую резервную копию текущего устройства.
2. Проверьте нужную версию по имени, времени изменения и размеру.
3. Убедитесь, что другое устройство не записывает данные в тот же каталог.
4. Нажмите **Восстановить** и подтвердите перезапись текущих данных.

После восстановления приложение может перезапуститься автоматически. Удаление резервной копии необратимо; перед массовым удалением ещё раз проверьте выбранные файлы.

{% hint style="warning" %}
Несколько устройств могут читать один удалённый каталог, но восстановление не объединяет данные. Чтобы использовать данные устройства A на устройстве B, сначала создайте копию B, а затем восстановите нужную версию A.
{% endhint %}

## Когда включать «Отключить потоковую загрузку»

По умолчанию Cherry Studio передаёт резервные копии потоком, что подходит для больших файлов и требует меньше памяти.

Некоторые сервисы WebDAV не поддерживают загрузку частями или потоком: небольшие файлы проходят, а большие копии завершаются ошибкой, либо возвращается ошибка длины запроса или передачи `chunked`. В таком случае включите **Отключить потоковую загрузку** и повторите попытку.

После включения Cherry Studio сначала полностью считывает файл резервной копии в память, а затем загружает его. Поэтому:

- Использование памяти приближается к размеру файла резервной копии
- Большие копии могут заметно замедлить приложение
- Это только средство совместимости, его не следует включать по умолчанию

Если ошибка сохраняется, проверьте серверные ограничения размера одного файла, тела запроса и тайм-аута, а не увеличивайте частоту резервного копирования.

## Рекомендации по безопасности

- В общедоступной сети используйте `https://`, чтобы не передавать пароль и копию по незашифрованному HTTP
- Создайте отдельную учётную запись или пароль приложения для Cherry Studio и предоставьте только необходимые права на целевой каталог
- Не показывайте на снимках, в отчётах и общей конфигурации закрытые части полного адреса, имя пользователя и пароль
- Не восстанавливайте ZIP-файл из неизвестного источника
- Регулярно проверяйте, что хотя бы одна полная копия отображается и распознаётся

## Часто задаваемые вопросы

### После запуска копирования отображается «Не авторизовано», 401 или 403

Проверьте, что имя пользователя и пароль предназначены для WebDAV, а не для обычного входа на сайт. При двухфакторной аутентификации используйте пароль приложения. Также убедитесь, что учётной записи разрешено создавать каталог и записывать файлы по целевому пути.

### Возвращается 404 или путь не найден

Убедитесь, что указан вход в сервис WebDAV, а не главная страница хранилища или ссылка общего доступа. Измените путь на простой каталог с начальным `/`, например `/cherry-studio`, и проверьте ручной резервной копией.

### Список файлов отображается, но большая копия не загружается

Сначала проверьте серверные ограничения размера одного файла, тела запроса обратного прокси и тайм-аута. Если ошибка связана с передачей частями, включите **Отключить потоковую загрузку**. Для полной копии в этом режиме предусмотрите достаточно памяти.

### Автоматическая копия не создаётся

Убедитесь, что интервал не равен «Выкл.», адрес WebDAV не пуст и проверьте состояние резервного копирования внизу страницы. Во время сна компьютера, отсутствия сети или недоступности сервиса запланированная копия не завершится.

### После достижения максимума старые файлы остаются

Автоматическое удаление отбирает файлы по идентификатору текущего устройства. Переименованные вручную файлы, копии других устройств и имена вне стандартного шаблона могут остаться; их нужно удалить вручную в диспетчере.

### После восстановления с другого компьютера исчезли новые локальные чаты

Восстановление перезаписывает, а не объединяет данные. Перед переносом между устройствами через удалённую копию отдельно сохраните оба устройства и восстанавливайте только проверенную целевую версию.

Если проблему решить не удалось, отправьте через [Обратную связь и предложения](../../question-contact/suggestions.md) версию Cherry Studio, операционную систему, обезличенные адрес и путь, код состояния HTTP и полный текст ошибки.
