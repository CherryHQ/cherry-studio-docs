# Настройка и экспорт в SiYuan

Cherry Studio V2 позволяет экспортировать тему целиком, отдельное сообщение или заметку Cherry Studio в указанный блокнот SiYuan. Экспортированные данные создаются как документ Markdown через SiYuan Kernel API.

Параметры находятся в разделе **Настройки > Интеграции > SiYuan**. Раздел **Настройки данных > Меню экспорта** управляет только отображением пункта «Экспортировать в SiYuan».

{% hint style="warning" %}
API Token предоставляет доступ к данным SiYuan. Не показывайте Token целиком на снимках экрана, в отзывах или общих конфигурациях. Для самостоятельно размещённого экземпляра не публикуйте незащищённый API напрямую в интернете.
{% endhint %}

## Подготовка SiYuan

1. Запустите SiYuan и убедитесь, что Kernel работает нормально.
2. Создайте или выберите блокнот, в который будут поступать экспортированные данные.
3. Получите API Token.
4. Скопируйте ID целевого блокнота.
5. Убедитесь, что устройство с Cherry Studio может обращаться к адресу API SiYuan.

Локальный Endpoint официального API SiYuan по умолчанию:

```text
http://127.0.0.1:6806
```

API Token можно посмотреть в разделе **SiYuan > Настройки > О программе**. Полное описание интерфейсов приведено в [официальной документации API SiYuan](https://github.com/siyuan-note/siyuan/blob/master/API.md).

## Получение ID блокнота

Откройте настройки целевого блокнота в SiYuan и выберите **Копировать ID блокнота**. ID обычно выглядит так:

```text
20210817205410-2kvfpfn
```

Не вводите имя блокнота, путь к рабочему пространству или ID документа. Cherry Studio передаёт это значение как параметр `notebook` в интерфейс создания документов SiYuan.

## Настройка в Cherry Studio

Откройте **Настройки > Интеграции > SiYuan** и заполните:

| Поле | Описание |
| --- | --- |
| Адрес API | Адрес доступа к SiYuan Kernel, например `http://127.0.0.1:6806` |
| Токен API | API Token из настроек SiYuan |
| ID блокнота | Notebook ID, в который будут сохраняться экспортированные документы |
| Корневой путь документов | Необязательно; родительский путь для всех экспортированных документов в блокноте |

Рекомендуется не добавлять `/` в конце адреса API, чтобы при объединении с путём `/api/...` не появлялся двойной слеш.

### Адреса для локального и самостоятельно размещённого экземпляра

- **SiYuan и Cherry Studio на одном компьютере:** обычно используется `http://127.0.0.1:6806`.
- **SiYuan на другом устройстве в локальной сети или NAS:** укажите IP-адрес и порт, доступные с устройства Cherry Studio; нельзя указывать `127.0.0.1` другого устройства.
- **Самостоятельное размещение в интернете:** используйте домен с HTTPS и ограничьте источники доступа в межсетевом экране или обратном прокси.

При подключении к SiYuan через Docker, NAS или обратный прокси также убедитесь, что путь `/api/` не переписывается и не блокируется.

## Проверка подключения

Введите **Адрес API** и **Токен API**, затем нажмите **Проверить**.

Cherry Studio вызывает:

```text
POST /api/notebook/lsNotebooks
```

Успешная проверка означает, что адрес доступен, Token работает, а интерфейс вернул `code: 0`. При этом не проверяется:

- существует ли указанный ID блокнота;
- открыт ли целевой блокнот;
- допустим ли корневой путь документов;
- можно ли успешно создать документ с текущей конфигурацией.

Поэтому после успешной проверки всё равно выполните один настоящий экспорт.

## Настройка корневого пути документов

Если оставить поле пустым, Cherry Studio использует:

```text
/CherryStudio
```

Можно указать другой путь, например:

```text
/Диалоги ИИ
```

Если путь не начинается с `/`, Cherry Studio добавит его автоматически.

### Использование шаблона даты

Сначала корневой путь обрабатывается интерфейсом `renderSprig` SiYuan, поэтому для упорядочивания по датам можно использовать поддерживаемые SiYuan шаблоны Sprig. Например:

```text
/CherryStudio/{{now | date "2006/01"}}
```

После обработки может получиться:

```text
/CherryStudio/2026/07
```

Ошибка в синтаксисе шаблона приведёт к сбою экспорта. При первой настройке рекомендуется использовать фиксированный путь и добавить шаблон только после успешного экспорта.

## Включение меню экспорта

Если в меню нет пункта «Экспортировать в SiYuan»:

1. Откройте **Настройки > Настройки данных > Меню экспорта**.
2. Включите **Экспортировать в SiYuan**.
3. Вернитесь к теме, сообщению или заметке и снова откройте меню экспорта.

Этот переключатель управляет только видимостью меню и не заполняет параметры интеграции автоматически.

## Первый экспорт

Рекомендуется сначала проверить короткое сообщение без конфиденциальных данных:

1. Откройте меню темы, сообщения или заметки Cherry Studio.
2. Выберите **Экспортировать в SiYuan**.
3. Дождитесь уведомления об успехе или ошибке.
4. Вернитесь к целевому блокноту SiYuan.
5. Проверьте, появился ли по корневому пути документ с названием темы или сообщения.
6. Откройте документ и проверьте заголовок, абзацы, списки, блоки кода и формулы.

Перед каждым экспортом Cherry Studio снова вызывает `lsNotebooks` для проверки подключения, а затем:

1. обрабатывает корневой путь документов;
2. удаляет из заголовка некоторые специальные символы;
3. объединяет корневой путь с заголовком документа;
4. вызывает `POST /api/filetree/createDocWithMd` для создания документа.

Официальный интерфейс SiYuan не перезаписывает существующий документ при повторном запросе по тому же пути. Чтобы обновить старые данные, обработайте старый документ в SiYuan либо измените заголовок или корневой путь и экспортируйте заново.

## Состав экспортируемых данных

- **Тема целиком:** преобразуется в Markdown в порядке сообщений текущей темы.
- **Отдельное сообщение:** экспортируется только выбранное сообщение.
- **Заметка Cherry Studio:** экспортируется текущее содержимое заметки в Markdown.

Сейчас для экспорта в SiYuan нет отдельного переключателя «Включать рассуждения». Если нужно сохранить определённые данные, сначала проверьте в Cherry Studio фактический экспортируемый текст.

## Рекомендации по безопасности

- При локальном использовании разрешайте API прослушивать только локальный компьютер или доверенную сеть.
- Для удалённого доступа включите HTTPS и ограничьте доступ в обратном прокси и межсетевом экране.
- При утечке Token немедленно замените его в SiYuan, а затем обновите Cherry Studio.
- Не записывайте настоящий Token в документы, снимки экрана, чаты или репозитории.
- Настройте надёжное резервное копирование важных блокнотов: экспорт не заменяет резервное копирование данных SiYuan.

## Частые вопросы

### При проверке отображается «Введите адрес API и токен»

Для проверки требуются только адрес API и Token. Убедитесь, что оба поля заполнены, а адрес содержит `http://` или `https://`.

### Не удаётся подключиться к локальному адресу

Убедитесь, что SiYuan работает, браузер на том же компьютере может открыть `127.0.0.1:6806`, а порт не был изменён. Если Cherry Studio и SiYuan находятся на разных устройствах, использовать `127.0.0.1` нельзя.

### Проверка успешна, но при экспорте указано, что конфигурация неполная

Для фактического экспорта также требуется **ID блокнота**. Убедитесь, что введён Notebook ID, а не имя блокнота или ID документа.

### Проверка успешна, но создать документ не удаётся

Убедитесь, что целевой блокнот существует и доступен, затем замените корневой путь на простой `/CherryStudio`. Если после этого экспорт работает, исходный шаблон Sprig или путь может быть недопустим.

### Самостоятельно размещённый экземпляр возвращает 401 или 403

Проверьте, что Token указан полностью, обратный прокси сохраняет заголовок запроса `Authorization: Token ...`, а политика доступа разрешает подключение с устройства Cherry Studio.

### Возвращается 404 или страница HTML

Возможно, адрес API указывает на подпуть веб-страницы или обратный прокси не передаёт `/api/` в SiYuan Kernel. Адрес API должен быть корневым адресом экземпляра и не должен содержать `/api/notebook/lsNotebooks`.

### Повторный экспорт не перезаписал старый документ

Это поведение интерфейса `createDocWithMd`: существующий документ по тому же пути не перезаписывается. Измените заголовок документа или корневой путь либо сначала обработайте старый документ в SiYuan.

### В меню диалога нет SiYuan

Откройте **Настройки > Настройки данных > Меню экспорта** и включите **Экспортировать в SiYuan**. Если параметр уже включён, снова откройте текущий диалог, а затем меню.

Если решить проблему не удалось, отправьте через [обратную связь и предложения](../../question-contact/suggestions.md) версии Cherry Studio и SiYuan, способ развёртывания, обезличенный адрес API, ID блокнота, корневой путь и сведения об ошибке интерфейса.
