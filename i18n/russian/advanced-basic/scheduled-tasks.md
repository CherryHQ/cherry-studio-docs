# Запланированные задачи

Запланированные задачи позволяют [агенту](agent.md) автоматически выполнять промпт в заданное время. Они подходят для подготовки ежедневных отчётов, периодических проверок, напоминаний и отправки результатов в каналы сообщений. При каждом запуске создаются сеанс и запись в истории, где можно просмотреть результат или ошибку.

Задачи выполняются локальным планировщиком Cherry Studio, а не фоновой службой операционной системы. В запланированное время приложение Cherry Studio должно быть запущено. После повторного открытия приложения расписание активных задач возобновляется.

{% hint style="warning" %}
Запланированные задачи выполняются без участия пользователя. У агента должен быть включён **Автономный режим** (Soul / Autonomous) либо выбран режим разрешений **Обход проверки разрешений** — полностью автоматический режим. При включении автономного режима Cherry Studio автоматически переключает разрешения в полностью автоматический режим. Перед каждым вызовом инструмента подтверждение не запрашивается. Ограничьте рабочий каталог, доступный агенту, и не сохраняйте в промпте пароли, API Key и другие конфиденциальные данные.
{% endhint %}

## Подготовка

1. Создайте или выберите [агента](agent.md) и настройте доступную модель.
2. В настройках агента включите **Автономный режим**. Если вы планируете создавать задачи только вручную на странице настроек, можно использовать агента с режимом разрешений **Обход проверки разрешений** (полностью автоматическим).
3. Проверьте тот же промпт в обычном сеансе и убедитесь, что модель, инструменты и разрешения рабочего каталога настроены правильно.
4. Если результат нужно отправлять в мессенджер, заранее настройте и подключите соответствующий [канал](agent-channels.md).

На странице настроек можно выбрать только агента с включённым автономным или полностью автоматическим режимом. Для создания и запуска запланированных задач не требуется отдельно включать API Server.

## Создание в чате

Создавать запланированные задачи в чате может только агент с включённым автономным режимом. Например, ему можно написать:

> Каждый рабочий день в 9:00 собери обновления проекта за последние 24 часа и изложи их в пяти пунктах.

С помощью встроенного инструмента запланированных задач агент может создавать, перечислять и удалять задачи. Рекомендуется указать:

* название задачи и ожидаемый результат;
* время запуска, интервал повторения или дату однократного запуска;
* нужно ли отправлять результат в какой-либо канал;
* тайм-аут, если выполнение может занять много времени.

После создания откройте **Настройки → Запланированные задачи** и проверьте значение расписания, промпт, канал получателя и время следующего запуска.

## Создание в настройках

1. Откройте **Настройки → Запланированные задачи**.
2. Нажмите **Добавить задачу** слева.
3. Выберите агента и заполните форму.
4. Нажмите **Сохранить**. Задача будет ожидать расписания со статусом **Активна**.

| Поле | Назначение |
| :--- | :--- |
| Название | Используется в списке задач и как название сеанса, например «Ежедневный обзор кода» |
| Промпт | Полная инструкция, которая при каждом запуске отправляется агенту как сообщение пользователя |
| Тип расписания | `Cron`, `Интервал` или `Однократно` |
| Значение расписания | Выражение Cron, интервал в минутах либо дата и время однократного запуска |
| Тайм-аут | Максимальная продолжительность одного запуска в минутах |
| Отправить в каналы | Необязательно; отправляет ход генерации и итоговый результат в выбранные каналы |

{% hint style="info" %}
В текущей версии внутреннее значение тайм-аута по умолчанию составляет 2 минуты. Хотя пустое поле в интерфейсе содержит подсказку **Без ограничений**, у новой задачи без введённого значения сохранится тайм-аут 2 минуты. Для длительных задач явно укажите большее положительное целое число.
{% endhint %}

### Выбор типа расписания

{% tabs %}
{% tab title="Интервал" %}
Введите положительное целое количество минут. Значение `60` означает запуск каждые 60 минут. Интервал рассчитывается от запланированного времени. Если приложение некоторое время было закрыто, задача не будет многократно запускаться подряд, чтобы выполнить все пропущенные интервалы.
{% endtab %}

{% tab title="Cron" %}
Введите стандартное пятикомпонентное выражение Cron: `минута час день месяц день_недели`.

| Выражение | Значение |
| :--- | :--- |
| `0 9 * * *` | Каждый день в 9:00 |
| `*/15 * * * *` | Каждые 15 минут |
| `0 9 * * 1-5` | Каждый рабочий день в 9:00 |

Cron рассчитывается в текущем часовом поясе устройства. После сохранения проверьте время **Следующего запуска** на странице.
{% endtab %}

{% tab title="Однократно" %}
Выберите дату и время единственного запуска. После выполнения задача получит статус **Завершена**. Её нельзя будет редактировать, запустить повторно или возобновить. Чтобы выполнить её ещё раз, создайте новую задачу.
{% endtab %}
{% endtabs %}

## Отправка в каналы

При создании или редактировании задачи можно выбрать один или несколько настроенных каналов. Во время выполнения текстовые сообщения агента отправляются в эти каналы; при ошибке туда же отправляется уведомление.

Канал должен быть подключён и иметь действующий Chat ID получателя. Если на странице указано, что **выбранные каналы не имеют доступных получателей (Chat ID)**, сначала отправьте сообщение боту на соответствующей платформе, чтобы Cherry Studio записал получателя, а затем вернитесь и выберите канал.

Если каналы не выбраны, задача всё равно выполняется, а результат сохраняется в сеансе задачи и истории запусков Cherry Studio.

## Управление задачами

Выберите задачу слева. На странице сведений можно:

* изменить название, агента, промпт, расписание, тайм-аут и каналы получателей;
* нажать **Запустить**, чтобы немедленно выполнить задачу один раз без изменения будущего расписания;
* приостановить или возобновить периодическую задачу;
* удалить ненужную задачу.

После изменения расписания или возобновления приостановленной задачи Cherry Studio пересчитывает время **Следующего запуска**. Если эта же задача уже выполняется, второй экземпляр не будет запущен параллельно.

Периодическая задача по возможности повторно использует последний успешно завершённый сеанс, сохраняя контекст между запусками. При первом запуске или отсутствии исходного сеанса создаётся новый сеанс с названием задачи.

## Просмотр истории запусков

В разделе **История запусков** отображаются время и длительность запуска, статус, результат или ошибка. Записи можно искать, а значок сеанса открывает полный диалог соответствующего запуска.

Если один запуск достигает тайм-аута, он прерывается и записывается как ошибка. После трёх последовательных ошибок планировщик автоматически приостанавливает задачу. Устраните проблему с моделью, сетью, разрешениями инструментов или промптом, а затем возобновите задачу вручную.

## Задача не запустилась вовремя

Проверьте по порядку:

1. Был ли Cherry Studio запущен в запланированное время.
2. Имеет ли задача статус **Активна** и правильно ли указано время **Следующего запуска**.
3. Доступна ли модель агента, достаточно ли средств у поставщика и работает ли сеть.
4. Остался ли агент в автономном или полностью автоматическом режиме.
5. Нет ли в истории запусков ошибок тайм-аута, разрешений инструментов или доставки в канал.

Планировщик проверяет наступившие задачи примерно раз в минуту, поэтому фактический запуск может немного отставать от расписания. Длительные задачи постоянно расходуют токены модели. Перед включением частого расписания сначала запустите задачу вручную и проверьте результат.
