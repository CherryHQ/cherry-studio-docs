# Автоматическая установка MCP

Встроенный в Cherry Studio `@cherry/mcp-auto-install` помогает модели находить MCP Server, читать инструкции по настройке и создавать команды запуска. Он может служить помощником по установке, когда точное имя пакета или формат конфигурации неизвестны.

{% hint style="warning" %}
Эта функция всё ещё находится на стадии тестирования. В текущей версии V2 помощник по установке работает в режиме JSON и не гарантирует, что созданная конфигурация Server будет напрямую записана в Cherry Studio. Рассматривайте его как средство поиска и создания конфигурации и проверяйте результат вручную перед импортом.
{% endhint %}

## Порядок работы

Полный процесс вспомогательной установки обычно состоит из четырёх этапов:

1. Модель использует помощник по установке, чтобы найти доступные Server и прочитать инструкции по настройке.
2. Помощник возвращает рекомендуемые команды, аргументы и переменные окружения.
3. Вы проверяете источник пакета и содержимое конфигурации, а затем импортируете JSON в Cherry Studio.
4. В настройках MCP включаете новый Server и проверяете инструменты и журнал.

Сам помощник запускается с помощью следующей предварительной конфигурации:

```text
npx -y @mcpmarket/mcp-auto-install connect --json
```

Cherry Studio управляет используемым им путём к локальному реестру, поэтому вручную заполнять `MCP_REGISTRY_PATH` не требуется.

## Включение помощника по установке

1. Откройте **Настройки → MCP Server**.
2. Найдите `@cherry/mcp-auto-install` среди встроенных Server.
3. Нажмите **Установить**, затем включите его в списке установленных.
4. Добавьте `@cherry/mcp-auto-install` в настройках инструментов нужного ассистента или Agent.
5. Выберите модель с поддержкой вызова инструментов.

При первом запуске требуется выполнить пакет NPX. Cherry Studio в первую очередь использует системный NPX, а если он недоступен — пробует встроенный Bun. При проблемах с зависимостями запустите установщик зависимостей в настройках MCP и перезапустите приложение.

## Создание конфигурации Server

Чтобы получить пригодный результат, сообщите модели назначение, платформу и требуемый формат вывода, а не ограничивайтесь просьбой «установить MCP». Например:

```text
Используй инструмент автоматической установки MCP и найди MCP Server, который может обращаться к локальной базе данных SQLite только для чтения.
Моя система — macOS.

Сначала объясни источник пакета и необходимые разрешения, затем создай конфигурацию JSON, которую можно импортировать в Cherry Studio.
Не включай Server вместо меня и не подставляй настоящие ключи.
```

Помощник по установке предоставляет следующие возможности:

- вывод списка MCP Server, доступных для обнаружения в реестре;
- чтение README и рекомендаций по настройке определённого Server;
- создание команды, аргументов и переменных окружения для Server;
- управление локальными регистрационными данными Server самого помощника.

После получения конфигурации от модели проверьте как минимум:

- заслуживают ли доверия имя npm-пакета, издатель и адрес документации;
- соответствуют ли `command` и `args` официальным инструкциям проекта;
- нет ли скриптов загрузки, команд Shell или ненужных аргументов с высокими правами;
- правильно ли указаны имена переменных окружения и не остались ли значения-заполнители;
- к каким локальным файлам, сетевым службам и учётным записям получит доступ Server.

## Импорт в Cherry Studio

Попросите модель привести результат к следующей структуре, оставив только один Server:

```json
{
  "mcpServers": {
    "example-server": {
      "command": "npx",
      "args": ["-y", "@example/mcp-server"],
      "env": {
        "EXAMPLE_API_KEY": "在 Cherry Studio 中替换"
      }
    }
  }
}
```

Затем:

1. Откройте **Настройки → MCP Server**.
2. Нажмите **Добавить → Импортировать из JSON**.
3. Вставьте проверенную конфигурацию.
4. После импорта откройте сведения о Server, замените заполнители и сохраните изменения.
5. Включите Server и проверьте фактически предоставляемые инструменты на странице **Инструменты**.
6. После завершения проверки добавьте Server к тем ассистентам или Agent, которым он нужен.

{% hint style="danger" %}
NPX может загружать и выполнять сторонний код. Не запускайте незнакомый пакет только по рекомендации модели и не отправляйте API Key непосредственно модели. Сначала проверьте пакет, версию, исходный код или официальную документацию, а затем введите ключ в настройках Server в Cherry Studio.
{% endhint %}

## Настройка области поиска

По умолчанию помощник обнаруживает Server в npm scope `@modelcontextprotocol`. Чтобы искать в других scope, добавьте следующую переменную окружения в сведениях о Server `@cherry/mcp-auto-install`:

```text
MCP_PACKAGE_SCOPES=@modelcontextprotocol,@your-scope
```

Несколько scope разделяются запятыми. Расширение области поиска также увеличивает количество сторонних пакетов, поэтому одновременно следует повысить требования к проверке источников.

## Часто задаваемые вопросы

### Помощник по установке не вызывается в диалоге

Убедитесь, что `@cherry/mcp-auto-install` включён, добавлен к текущему ассистенту или Agent и используется модель с поддержкой вызова инструментов. В подсказке можно явно потребовать: «Сначала вызови инструмент автоматической установки MCP».

### NPX не найден или запуск не удался

Запустите установщик зависимостей в настройках MCP, затем перезапустите Cherry Studio. Если ошибка сохраняется, откройте журнал Server и проверьте NPX, встроенный Bun, сетевой прокси и npm registry.

### Нужный Server не найден

Область поиска по умолчанию ограничена. Сначала определите npm scope пакета, затем добавьте его через `MCP_PACKAGE_SCOPES`. Можно также отказаться от автоматической установки и [настроить MCP вручную](config.md) по официальной документации проекта.

### Конфигурация создана, но список Server не изменился

Это нормальное поведение текущего режима JSON. Скопируйте подготовленный моделью JSON `mcpServers` и установите Server через **Добавить → Импортировать из JSON**.

### После импорта Server не включается

Помощник создаёт рекомендуемую конфигурацию, в которой по-прежнему могут отсутствовать путь, ключ или параметры платформы. Исправьте настройки по официальной документации целевого Server и проверьте журнал с помощью раздела [Часто задаваемые вопросы о MCP Server](chang-jian-wen-ti.md).
