# Подключение базы знаний Dify

Если ваша команда уже использует [Dify](https://dify.ai/) для хранения материалов, встроенный в Cherry Studio MCP Server `@cherry/dify-knowledge` позволяет искать по этим базам знаний без повторного импорта документов.

После подключения ассистент или Agent может сначала получить список баз знаний, доступных с текущим ключом, затем найти относящиеся к вопросу фрагменты и использовать их как основу ответа. Эта функция только читает базы знаний и не создаёт, не изменяет и не удаляет данные в Dify.

## Подготовка

Сначала выполните в Dify следующие действия:

1. Создайте хотя бы одну базу знаний, импортируйте документы и дождитесь завершения индексации.
2. На странице доступа к API базы знаний создайте **Knowledge API Key**. Не используйте API Key приложения (App).
3. Проверьте корневой адрес API:
   - облачный сервис Dify: `https://api.dify.ai/v1`;
   - частное развёртывание: используйте адрес API базы знаний своей инсталляции, который обычно заканчивается на `/v1`.

{% hint style="warning" %}
API Key позволяет читать содержимое баз знаний в пределах предоставленных ему прав. Не добавляйте настоящий ключ в документы, снимки экрана или общедоступные чаты. Если ключ раскрыт, немедленно отзовите его в Dify и создайте новый.
{% endhint %}

## Установка встроенного MCP Server

1. Откройте в Cherry Studio **Настройки → MCP Server**.
2. Найдите `@cherry/dify-knowledge` в списке встроенных MCP Server.
3. Нажмите **Установить**.
4. Нажмите `@cherry/dify-knowledge` в списке установленных Server, чтобы открыть страницу сведений.

Этот Server запускается встроенными средствами Cherry Studio. Отдельно устанавливать Node.js, Python или стороннюю программу MCP не требуется.

## Ввод данных подключения

Заполните следующие поля на странице **Настройки** в сведениях о Server:

| Поле | Что указать | Пример |
| --- | --- | --- |
| Аргументы | Корневой адрес API базы знаний Dify, одной строкой | `https://api.dify.ai/v1` |
| Переменные окружения | `DIFY_KEY=API Key базы знаний` | `DIFY_KEY=dataset-xxxxxxxx` |

Сохраните настройки и включите Server. При успешном подключении на странице **Инструменты** появятся два инструмента:

- `list_knowledges` — выводит доступные с текущим API Key базы знаний и их идентификаторы.
- `search_knowledge` — ищет содержимое по идентификатору базы знаний и тексту запроса; если `topK` не задан, возвращает не более 6 результатов.

{% hint style="info" %}
Не добавляйте `/datasets` к аргументу и не указывайте идентификатор отдельной базы знаний. Cherry Studio автоматически добавляет пути к API списка баз знаний и поиска в зависимости от вызова инструмента.
{% endhint %}

## Использование в диалоге

После установки и включения Server необходимо предоставить доступ к нему тому ассистенту или Agent, который будет его использовать:

1. Откройте настройки инструментов нужного ассистента или Agent.
2. Добавьте и включите `@cherry/dify-knowledge`.
3. Выберите модель с поддержкой вызова инструментов и начните диалог.

При первом использовании сначала попросите модель проверить доступные базы знаний:

```text
Перечисли базы знаний Dify, к которым у тебя сейчас есть доступ, и покажи название и идентификатор каждой из них.
```

Определив нужную базу знаний, задайте вопрос с указанием области поиска и требований к ответу:

```text
Найди в базе знаний «Центр помощи по продукту» инструкции по переносу учётной записи.
Отвечай только на основе найденных материалов и перечисли основные замечания.
```

Модель самостоятельно вызовет `list_knowledges` или `search_knowledge`. Результаты поиска, возвращаемые инструментом, содержат название документа, текст фрагмента, оценку релевантности и ключевые слова. Структура итогового ответа по-прежнему зависит от возможностей модели и подсказки.

## Часто задаваемые вопросы

### При включении сообщается об отсутствующих аргументах

Убедитесь, что в поле **Аргументы** указан корневой адрес API. Для запуска этого встроенного Server требуется хотя бы одна строка аргументов.

### Возвращается 401, 403 или ошибка доступа

Последовательно проверьте:

- полностью ли правильно указано имя `DIFY_KEY`;
- используется ли API Key базы знаний, а не API Key приложения;
- действителен ли ключ и есть ли у него доступ к нужной базе знаний;
- доступен ли адрес API частной инсталляции с текущего компьютера.

### Подключение работает, но список баз знаний пуст

Убедитесь, что в Dify есть хотя бы одна база знаний, и проверьте область прав текущего Knowledge API Key. Cherry Studio может вывести только те базы знаний, которые доступны этому ключу.

### Dify не вызывается в диалоге

Убедитесь, что Server включён и добавлен к текущему ассистенту или Agent. Также требуется модель с поддержкой вызова инструментов. При необходимости прямо укажите в вопросе: «Сначала выполни поиск по базе знаний Dify, затем ответь».

### Результаты поиска неудовлетворительны

Сначала проверьте в Dify, завершена ли индексация документов, а затем повторите вопрос с более точными ключевыми словами. Встроенный инструмент использует API семантического поиска Dify и не заменяет настройку сегментации, индексации и извлечения на стороне Dify.
