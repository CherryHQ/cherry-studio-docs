# Встроенные MCP Server

Cherry Studio предоставляет набор встроенных MCP Server, которые можно установить напрямую. Они выполняются внутри приложения или используют предварительно заданные подключения, поэтому вручную создавать конфигурацию JSON не требуется. Это позволяет быстро добавить ассистентам и Agent возможности чтения веб-страниц, работы с файлами, выполнения кода, памяти и сторонних сервисов.

{% hint style="info" %}
«Встроенный» не означает «включён автоматически». Сначала Server необходимо установить из списка встроенных. Для Server с меткой **Требуется настройка** также нужно заполнить аргументы или переменные окружения.
{% endhint %}

## Установка и использование

1. Откройте **Настройки → MCP Server**.
2. Найдите нужный Server в области **Встроенные Server**. Также можно выбрать фильтр **Доступные для установки**.
3. Нажмите **Установить**.
4. Если Server отмечен как **Требуется настройка**, вернитесь к списку установленных Server, откройте его и заполните параметры в соответствии с этой страницей.
5. Сохраните настройки и включите Server.
6. Добавьте этот MCP Server в настройках инструментов нужного ассистента или Agent.

Для диалога также требуется модель с поддержкой вызова инструментов. Если только установить Server, но не добавить его к текущему ассистенту или Agent, модель не сможет использовать его инструменты.

## Инструменты для веб-страниц и кода

### `@cherry/fetch`

Подходит для чтения веб-страниц и API, которые не требуют сложного взаимодействия. Поддерживает четыре формата: HTML, Markdown, обычный текст и JSON, а также позволяет передавать в запросе пользовательский Header.

Если странице требуется авторизованный сеанс, отрисовка JavaScript или нажатия, используйте `@cherry/browser`.

### `@cherry/browser`

Работает с веб-страницами в окне браузера Electron, которым управляет Cherry Studio. Поддерживает:

- открытие URL и выполнение скриптов страницы;
- получение снимка состояния страницы или снимка экрана;
- вывод списка вкладок, переключение и закрытие вкладок;
- сброс сеанса браузера.

Браузер получает доступ к содержимому страницы и, возможно, к состоянию авторизации. Перед использованием проверяйте сайт, который собирается открыть модель, и не позволяйте недоверенным подсказкам выполнять действия с конфиденциальными учётными записями.

### `@cherry/python`

Предоставляет инструмент `python_execute` для выполнения кода Python 3.12 в среде Pyodide. Подходит для вычислений, обработки текста и преобразования форматов; зависимости можно объявлять через метаданные PEP 723.

Тайм-аут каждого вызова по умолчанию составляет 60 секунд. Это не полноценная локальная среда Python: код, зависящий от нативных двоичных файлов, системных команд или определённого оборудования, может не выполняться.

### `@cherry/sequentialthinking`

Предоставляет модели инструменты пошагового мышления с возможностью исправлений и ветвления. Это полезно для сложного планирования и анализа, но не повышает автоматически качество каждого ответа. Для простых вопросов обычно включать Server не требуется.

## Локальные файлы и память

### `@cherry/filesystem`

Предоставляет инструменты `glob`, `ls`, `grep`, `read`, `edit`, `write` и `delete`. Server должен получать доступ только к рабочим каталогам, которые вы явно разрешили.

После установки настройте каталог на странице сведений о Server одним из способов:

- **Аргументы** — в первой строке укажите абсолютный путь к рабочему каталогу;
- **Переменные окружения** — укажите `WORKSPACE_ROOT=абсолютный_путь`.

Если заданы оба варианта, приоритет имеет `WORKSPACE_ROOT`. `~` можно развернуть в каталог пользователя, но для устранения неоднозначности рекомендуется указывать полный абсолютный путь.

{% hint style="warning" %}
По умолчанию операции `write`, `edit` и `delete` не утверждаются автоматически. Не расширяйте область разрешённого каталога и не утверждайте незнакомые операции записи или удаления сразу все только ради того, чтобы пропустить подтверждение.
{% endhint %}

### `@cherry/memory`

Сохраняет сущности, связи и наблюдения в локальном файле JSON, чтобы модель могла читать и обновлять их между диалогами. После установки настройте:

```text
MEMORY_FILE_PATH=/绝对路径/memory.json
```

Это память графа знаний самого MCP Server, отдельная от [глобальной памяти](../memory.md) Cherry Studio. Обычным пользователям рекомендуется сначала использовать глобальную память, а этот Server включать только при необходимости непосредственно управлять сущностями и связями.

### `@cherry/nowledge-mem`

Подключается к локальному адресу `http://127.0.0.1:14242/mcp`. Перед использованием установите и запустите [Nowledge Mem](https://mem.nowledge.co/); вводить удалённый URL в Cherry Studio не требуется.

## Поиск, базы знаний и сторонние сервисы

### `@cherry/brave-search`

Предоставляет веб-поиск и поиск местных организаций. Сначала получите ключ в [Brave Search API](https://brave.com/search/api/), затем укажите на странице сведений о Server:

```text
BRAVE_API_KEY=你的 API Key
```

### `@cherry/dify-knowledge`

Выводит список баз знаний Dify и выполняет поиск по ним. В поле **Аргументы** необходимо указать корневой адрес API базы знаний, а в **Переменные окружения** — `DIFY_KEY`. Полная последовательность действий описана на странице [Подключение базы знаний Dify](dify.md).

### `@cherry/flomo`

Подключает учётную запись через удалённый адрес MCP flomo. Если после установки и включения появится страница авторизации, выполните указанные на ней действия для входа в учётную запись flomo. Не вставляйте пароль flomo в аргументы или переменные окружения Cherry Studio.

### `@cherry/didi-mcp`

Предоставляет инструменты для поиска мест, оценки стоимости, создания или отмены заказа такси, просмотра заказа и местоположения водителя. После установки укажите:

```text
DIDI_API_KEY=你的 API Key
```

Сервис поддерживается только в материковом Китае. Создание и отмена заказа выполняют реальные внешние операции, поэтому рекомендуется отключить автоматическое утверждение этих инструментов на странице **Инструменты**.

### `@cherry/mcp-auto-install`

Позволяет модели искать и устанавливать другие MCP Server во время диалога. В настоящее время это тестовая функция. Предварительная конфигурация запускается через NPX. Если запуск не удался, сначала проверьте и установите зависимости среды выполнения в настройках MCP. Подробности приведены на странице [Автоматическая установка MCP](auto-install.md).

## Рекомендации по разрешениям

Встроенные Server используют общие настройки разрешений MCP. После установки рекомендуется проверить каждый пункт:

- включайте только Server и инструменты, необходимые для текущей задачи;
- предоставляйте инструментам работы с файлами, браузером, памятью и сторонними учётными записями только необходимый объём доступа;
- сохраняйте ручное подтверждение для записи и удаления файлов, создания и отмены заказов и подобных операций;
- своевременно выключайте или удаляйте Server, которые больше не используются;
- храните API Key только в настройках Server, не добавляйте их в подсказки, снимки экрана или общие записи.

## Часто задаваемые вопросы

### Server установлен, но инструмент не находится в диалоге

Убедитесь, что Server включён и добавлен к текущему ассистенту или Agent. Затем проверьте, поддерживает ли выбранная модель вызов инструментов.

### Отображается «Требуется настройка»

Нажмите соответствующую запись в списке установленных Server, заполните аргументы или переменные окружения на странице **Настройки** и сохраните изменения. Аргументы и переменные окружения указываются по одному на строку.

### Не удаётся включить Server

Откройте журнал в сведениях о Server и сначала проверьте отсутствие аргументов, недействительный API Key, права каталога и локальные зависимости. Другие способы диагностики приведены в разделе [Часто задаваемые вопросы о MCP Server](chang-jian-wen-ti.md).
