# OpenClaw

Cherry Studio позволяет устанавливать OpenClaw и управлять им, запускать локальный шлюз OpenClaw, а также синхронизировать с OpenClaw уже настроенные сервисы моделей. После успешного запуска Cherry Studio автоматически открывает встроенную панель управления OpenClaw. В ней можно продолжить настройку таких каналов, как WhatsApp, Telegram, Slack и Discord.

OpenClaw — это автономный персональный ИИ-ассистент, а не [агент](agent.md) Cherry Studio. Если вам нужны только диалоги или задачи с использованием инструментов внутри Cherry Studio, используйте агента. Включайте эту функцию, когда необходимы панель управления, каналы или отдельный режим работы OpenClaw.

{% hint style="warning" %}
OpenClaw обладает расширенными системными разрешениями, а задачи агентов могут потреблять значительное количество токенов. Запускайте его только на доверенных устройствах и в доверенных рабочих пространствах. Проверяйте, к каким файлам, командам и сторонним каналам ему предоставлен доступ.
{% endhint %}

## Открытие OpenClaw

1. Нажмите **+** справа на верхней панели вкладок, чтобы открыть **панель запуска**.
2. Нажмите **OpenClaw**.
3. Cherry Studio проверит, установлена ли управляемая им версия OpenClaw.

Cherry Studio использует только бинарный файл OpenClaw из собственного управляемого каталога. Даже если OpenClaw, установленный другим способом, уже доступен в системном `PATH`, на странице всё равно будет предложено установить управляемую версию или перейти на неё. Это предотвращает случайный запуск устаревшей версии.

## Установка управляемой версии

При первом открытии нажмите **Установить OpenClaw**. Cherry Studio скачает автономный бинарный пакет для текущей операционной системы и процессора и покажет журнал установки. Предварительно устанавливать Node.js или Git не требуется.

Поддерживаются x64 и ARM64 в macOS, Windows и Linux. Доступный источник загрузки выбирается автоматически; в сетях материкового Китая сначала используется зеркало.

После завершения установки на странице отобразится каталог OpenClaw. В macOS и Linux Cherry Studio также попытается создать ссылку `/usr/local/bin/openclaw`, а в Windows — добавить управляемый каталог в `PATH` текущего пользователя. Эти действия упрощают запуск из терминала, но не влияют на работу Cherry Studio: приложение запускает OpenClaw по управляемому пути.

## Выбор модели и запуск

Перед запуском включите в настройках сервисов моделей Cherry Studio хотя бы одного доступного поставщика и убедитесь, что выбранная модель отвечает на запросы. Затем:

1. Выберите модель на странице OpenClaw.
2. Нажмите **Запустить шлюз**.
3. Cherry Studio синхронизирует с OpenClaw настройки выбранного поставщика и модели.
4. Cherry Studio запустит локальный шлюз и дождётся успешной проверки его состояния.
5. После успешного запуска панель управления OpenClaw автоматически откроется внутри Cherry Studio.

В списке моделей отображаются только включённые и доступные поставщики. Для локальных сервисов, таких как Ollama и LM Studio, API Key можно не указывать. Для остальных поставщиков обычно требуется предварительно настроить API Key и модель.

Адрес шлюза по умолчанию — `127.0.0.1:18790`. Пока шлюз работает, на странице OpenClaw отображаются его состояние и порт. Закрытие панели управления не останавливает шлюз. Чтобы открыть её снова, нажмите **Открыть панель управления**.

{% hint style="info" %}
При каждом нажатии **Запустить шлюз** Cherry Studio сначала синхронизирует выбранную модель. Чтобы сменить модель, остановите шлюз, выберите другую модель и запустите его заново.
{% endhint %}

## Какие настройки синхронизируются

Cherry Studio объединяет настройки и записывает их в `~/.openclaw/openclaw.json`. В основном это:

* адрес API, данные аутентификации и список моделей текущего поставщика;
* текущая модель по умолчанию;
* локальный режим шлюза, порт и автоматически созданный токен аутентификации.

Существующая конфигурация OpenClaw не заменяется целиком. Cherry Studio сохраняет дополнительные настройки уже существующей модели и обновляет только управляемого поставщика и модель по умолчанию. Если обнаружен старый файл `openclaw.cherry.json`, он переносится в `openclaw.json`, а исходный файл при необходимости сохраняется как резервная копия.

{% hint style="warning" %}
Файл конфигурации OpenClaw содержит данные аутентификации сервиса моделей и токен шлюза. Не передавайте этот файл, конфиденциальные данные из журнала установки или адрес панели управления с токеном.
{% endhint %}

## Остановка, обновление и удаление

### Остановка шлюза

Вернитесь на страницу OpenClaw и нажмите **Остановиться**. При обычном завершении работы Cherry Studio приложение также попытается остановить управляемый им шлюз.

### Обновление OpenClaw

При переходе на страницу установленной управляемой версии Cherry Studio проверяет наличие обновлений. Если доступна новая версия, рядом с каталогом установки отображается её номер. Нажмите номер версии, а затем подтвердите действие кнопкой **Обновить сейчас**. Перед обновлением работающий шлюз будет остановлен. После завершения обновления снова нажмите **Запустить шлюз**.

### Удаление OpenClaw

Остановите шлюз, нажмите **Удалить** справа от области с каталогом установки, подтвердите действие и дождитесь завершения журнала. Cherry Studio удалит управляемый бинарный файл и созданную им командную ссылку или запись в `PATH`.

При удалении файл `~/.openclaw/openclaw.json` сохраняется. Если данные аутентификации поставщика в нём больше не нужны, удалите их самостоятельно, предварительно убедившись, что этот файл не используется другой установкой OpenClaw.

## Устранение неполадок

### Не удалось скачать установочные файлы

Убедитесь, что устройство может подключиться к источнику загрузки, и найдите конкретную ошибку в журнале установки. После восстановления сети можно повторно запустить установку. Установка также завершится ошибкой, если для текущей операционной системы или процессора нет подходящего бинарного пакета.

### OpenClaw установлен из терминала, но на странице указано, что он не установлен

Это ожидаемое поведение. Cherry Studio не запускает внешний OpenClaw из системного `PATH`. Установите управляемую Cherry Studio версию непосредственно на этой странице.

### Нет доступных моделей

Откройте настройки сервисов моделей, включите поставщика и настройте API Key, адрес API и модель. Убедитесь в обычном диалоге, что модель отвечает корректно, а затем вернитесь на страницу OpenClaw.

### Шлюз не запускается

Порт `18790`, используемый по умолчанию, может быть занят другой программой. Остановите существующий процесс OpenClaw или приложение, использующее этот порт, и повторите запуск. Страница ожидает прохождения проверки состояния не более 30 секунд. Если запуск по-прежнему завершается ошибкой, скопируйте сведения об ошибке для диагностики.

### Терминал не находит команду `openclaw`

Встроенная панель управления Cherry Studio не зависит от команды в терминале. Если вы хотите запускать OpenClaw из терминала, проверьте, добавлен ли управляемый каталог установки в `PATH`. В macOS или Linux создание ссылки `/usr/local/bin/openclaw` может завершиться ошибкой из-за недостаточных разрешений.

Подробнее о каналах OpenClaw и работе с панелью управления см. в [официальной документации OpenClaw](https://docs.openclaw.ai/).
