# Веб-поиск моделей Volcengine

Cherry Studio V2 позволяет диалоговым моделям Volcengine Ark использовать внешний поиск в интернете. Рекомендуемая комбинация:

```text
Модель Volcengine Ark
    + Провайдер поиска по умолчанию Cherry Studio
    + Провайдер получения URL по умолчанию Cherry Studio
```

В настоящее время V2 не регистрирует Web Search Volcengine Ark как отдельного провайдера веб-поиска и не добавляет автоматически облачный инструмент Web Search Ark во встроенный провайдер `doubao`.

{% hint style="warning" %}
Схема из старых руководств «Создать приложение без кода → Включить плагин веб-поиска → Подключить приложение как модель OpenAI» не рекомендуется для текущей версии V2. Интерфейс, плагины и API изменились, поэтому не копируйте старые снимки экрана и формат API Host.
{% endhint %}

## Сначала разграничьте два вида веб-поиска

| Способ | Кто выполняет поиск | Текущий статус в Cherry Studio V2 | Рекомендуемые сценарии использования |
| --- | --- | --- | --- |
| Внешний веб-поиск Cherry Studio | Поисковые сервисы, такие как ExaMCP, Tavily, SearXNG, Bocha и др. | Поддерживается | Обычный диалог, когда требуется унифицированное управление поисковыми сервисами |
| Облачный веб-поиск Volcengine Ark | Responses API Volcengine Ark или плагины приложений | Нет специальной адаптации | Когда приложение уже разработано на стороне Ark и пользователь готов самостоятельно проверять интерфейсы |

В данной статье описывается первый способ. Он не требует создания «Моего приложения» в Volcengine Ark и не зависит от старых плагинов для веб-поиска.

### Внешний веб-поиск Cherry Studio

Если текущая модель не распознана как модель с нативным веб-поиском, Cherry Studio предоставляет ей:

- Инструмент ключевых слов для поиска;
- Инструмент чтения URL.

Модель решает, когда выполнять поиск и чтение веб-страниц, используя Function Calling. Результаты поиска возвращаются в модель, которая затем генерирует ответ со ссылками.

### Облачный веб-поиск Volcengine Ark

На официальном сайте Volcengine Ark представлены облачные инструменты, такие как Responses API, Web Search, Knowledge Search и Remote MCP. Эти возможности относятся к интерфейсам Ark и не эквивалентны настройкам веб-поиска в Cherry Studio.

По умолчанию встроенный сервис `doubao` использует:

```text
OpenAI Chat Completions
```

API Host по умолчанию:

```text
https://ark.cn-beijing.volces.com/api/v3/
```

Наличие инструмента Responses API на официальном сайте не означает, что Cherry Studio уже адаптировала его поля запроса, поток событий и формат ссылок.

## Подготовка к использованию

Необходимо подготовить:

1. Аккаунт Volcengine;
2. API Key Volcengine Ark;
3. Доступный Model ID или Endpoint ID;
4. Диалоговая модель с поддержкой Function Calling;
5. Провайдер для поиска по ключевым словам;
6. Провайдер для получения URL.

Базовая конфигурация Volcengine Ark описана в разделе [Volcengine (Ark / Doubao)](../pre-basic/providers/doubao.md).

{% hint style="danger" %}
Не записывайте API Key Volcengine Ark, API Key сервиса поиска или приватные URL с токенами в чаты, скриншоты и публичные документы.
{% endhint %}

## Настройка моделей Volcengine Ark

### 1. Активация и копирование идентификатора модели

В консоли Volcengine Ark:

1. Создайте API Key;
2. Активируйте модель, которую планируете использовать;
3. Скопируйте текущий Model ID;
4. Если используется выделенная конечная точка инференса, скопируйте Endpoint ID формата `ep-...`;
5. Подтвердите проект, регион, баланс и лимиты.

Не копируйте:

- Отображаемое имя модели;
- URL страницы консоли;
- Bot ID из старых приложений;
- Endpoint ID из других проектов.

### 2. Включение провайдера в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`;
2. Переключите фильтр на **Все провайдеры**;
3. Выберите **Doubao / Volcengine Ark / Volcengine**;
4. Введите API Key Ark;
5. Оставьте API Host по умолчанию;
6. Включите переключатель провайдера;
7. Добавьте вручную текущий Model ID или Endpoint ID;
8. Запустите проверку работоспособности модели.

Сначала отправьте обычное текстовое сообщение и убедитесь, что диалог работает. После этого настройте веб-поиск.

## Выбор модели для веб-поиска

Для внешнего веб-поиска Cherry Studio предпочтительны модели со структурированным Function Calling.

Текущая версия V2 распознает несколько новых моделей Doubao Seed, например, с именами, соответствующими следующей серии:

```text
doubao-seed-1.6...
doubao-seed-1.8...
doubao-seed-2.0...
doubao-seed-code...
```

Конкретный Model ID будет обновляться; его следует копировать с текущей страницы моделей Volcengine Ark, а не использовать приведенные выше серии имен в качестве полного ID.

{% hint style="warning" %}
DeepSeek R1 из старых руководств исключён в текущей версии V2 из моделей со структурированным Function Calling и не подходит в качестве первого выбора для внешнего веб-поиска Cherry Studio. Даже при рабочем обычном диалоге он может не вызвать инструмент поиска.
{% endhint %}

В управлении моделями можно просматривать и изменять метки возможностей, но они влияют только на решение клиента и не добавляют модели Function Calling, если сервер его изначально не поддерживает.

## Настройка веб-поиска

Открыть:

```text
Настройки → Веб-поиск
```

Также настроить:

| Параметр | Описание | Примеры |
| --- | --- | --- |
| Провайдер поиска по умолчанию | Поиск страниц по ключевым словам | ExaMCP, Tavily, SearXNG, Bocha |
| Провайдер получения URL по умолчанию | Чтение основного текста конкретной страницы | Fetch, Jina |

Обе эти настройки обязательны.

Если вы не хотите запрашивать дополнительный API Key для поиска, вы можете начать с:

```text
Провайдер поиска по умолчанию: ExaMCP
Провайдер получения URL по умолчанию: Fetch
```

## Включение в диалоге

1. Вернитесь на страницу диалога;
2. Выберите модель Volcengine Ark, прошедшую проверку работоспособности;
3. Нажмите на **значок глобуса** под полем ввода;
4. Подтвердите подсветку значка;
5. Отправьте вопрос, требующий актуальной информации.

Тестовый вопрос:

```text
Проведи веб-поиск последней официальной версии Cherry Studio,
цитируя только официальный GitHub Release, и перечисли номер версии, дату выпуска и основные изменения.
```

Проверьте ответ на наличие:

- Фактического вызова инструмента поиска;
- Доступных цитат/ссылок;
- Цитирования с требуемого сайта;
- Соответствия даты и номера версии исходному тексту;
- Отсутствия использования устаревших знаний в качестве актуальных результатов.

## Что происходит во время веб-поиска

Для моделей Volcengine Ark без адаптации нативного веб-поиска в текущей версии V2 процесс обычно выглядит так:

1. Пользователь включает веб-поиск и отправляет вопрос;
2. Cherry Studio предоставляет модели внешний инструмент поиска;
3. Модель генерирует структурированный вызов инструмента;
4. Cherry Studio вызывает провайдера поиска по умолчанию;
5. Модель при необходимости вызывает провайдера получения URL по умолчанию;
6. Результаты поиска и текст веб-страницы передаются обратно модели;
7. Модель генерирует окончательный ответ с цитатами.

API Key службы поиска не отправляется модели Volcengine Ark, но текст результатов поиска отправляется в качестве контекста диалога для Volcengine Ark.

## Отличия от старых руководств

| Старый подход | Рекомендация в V2 |
| --- | --- |
| Создание «Мое приложение» без кода | Напрямую использовать Model ID или Endpoint ID Ark |
| Покупка или включение старого плагина веб-поиска в приложении Ark | Настройка внешнего провайдера поиска в Cherry Studio |
| Добавление пользовательского провайдера OpenAI | Предпочитать встроенный провайдер Doubao |
| Вставка полного `/chat/completions` в URL | Заполнять Base URL; V2 сам сформирует путь запроса |
| Добавление `#` в конец API Host | Не требуется |
| Использование мелкого ID приложения как названия модели | Использовать текущий Model ID или Endpoint ID |
| Использование старого примера веб-поиска с DeepSeek R1 | Выбрать актуальную модель с поддержкой Function Calling |

При миграции с помощью старых конфигураций рекомендуется создать новый чистый экземпляр провайдера Doubao или восстановить значения по умолчанию для встроенного провайдера, не накладывая совместимые параметры на старые адреса.

## Не отмечайте «Нативный веб-поиск» вручную

Метка веб-поиска в сведениях о модели влияет на выбор между нативным и внешним веб-поиском Cherry Studio.

Не помечайте обычную модель Volcengine Ark как модель с нативным веб-поиском только ради отображения значка глобуса. В текущей версии V2 нет соответствующей адаптации плагина Ark Web Search, поэтому неправильная метка может привести к следующим последствиям:

- Cherry Studio перестанет внедрять внешний инструмент поиска;
- Сторона Ark не получит корректный облачный инструмент веб-поиска;
- Переключатель веб-поиска будет подсвечен, но поиск фактически не выполнится.

Если метка изменена по ошибке, восстановите автоматическое распознавание модели и используйте настройку внешнего веб-поиска с этой страницы.

## Если необходимо использовать веб-поиск Volcengine Ark

Веб-поиск Volcengine Ark в основном осуществляется через Responses API или конфигурацию приложения Ark. Текущее встроенное подключение `doubao` в Cherry Studio V2 не предоставляет специальной страницы настроек для конфигурирования этих инструментов.

Не рекомендуется рассматривать приложение Ark как обычную модель, пока не будут подтверждены следующие условия:

1. Вы активировали веб-поиск Volcengine Ark согласно текущей официальной документации Volcengine Ark;
2. Подтверждено, что вызывается Chat API, Responses API или Bot API приложения;
3. Получен соответствующий Model ID, Endpoint ID или Bot ID;
4. Подтвержден адрес запроса и метод аутентификации;
5. Подтверждено, что возвращаемые события могут быть распарсены текущей конечной точкой Cherry Studio;
6. Подтверждены форматы цитирования, потоковой передачи и результатов работы инструментов;
7. Изучена стоимость модели и плагина поиска.

{% hint style="info" %}
Это расширенный сценарий совместимости, не относящийся к встроенному процессу веб-поиска V2. После обновления интерфейсов Ark старые URL приложений и параметры могут перестать работать.
{% endhint %}

Текущая документация по инструментам Volcengine Ark доступна в [документации продуктов Volcengine Ark](https://www.volcengine.com/docs/82379/) и [вызове инструментов](https://www.volcengine.com/docs/82379/1958524).

## Конфиденциальность и стоимость

При внешнем веб-поиске Cherry Studio данные могут отправляться разным получателям:

- Volcengine Ark: вопросы пользователя, результаты поиска и содержимое прочтенных веб-страниц;
- Поисковый сервис: поисковые ключевые слова;
- Целевой сайт: запросы на веб-страницу;
- Сервис получения URL: целевой URL, в зависимости от выбранного сервиса.

Стоимость может включать:

- Токены ввода и вывода модели Ark;
- Вызовы поисковых сервисов;
- Точки доступа или модули моделей для инференса Ark;
- Дополнительный сетевой трафик;
- Плату за плагин, если отдельно используется Ark Web Search.

Не следует планировать бюджет на основе бесплатных лимитов или цен из старых скриншотов; необходимо руководствоваться текущими консолями каждого сервиса.

## Часто задаваемые вопросы

### Переход в настройки веб-поиска после нажатия на значок глобуса

У текущей модели нет адаптации нативного веб-поиска, а **провайдер поиска по умолчанию** или **провайдер получения URL по умолчанию** не настроен. Настройте оба параметра и повторите попытку.

### Обычный диалог работает, но инструмент поиска не вызывается

Проверьте следующее:

1. Является ли значок глобуса подсвеченным;
2. Поддерживает ли текущая модель вызов функций (Function Calling);
3. Не помечен ли Model ID ошибочно как не поддерживающий инструменты;
4. Используется ли старая версия DeepSeek R1;
5. Явно ли в вопросе требуется сначала выполнить поиск и привести цитаты;
6. Успешно ли обнаружен провайдер поиска.

Переключитесь на актуальную модель Doubao Seed с поддержкой инструментов и повторите попытку в новом диалоге.

### Модель говорит «Я выполню поиск», но нет результатов

Это не успешный вызов инструмента. Проверьте, появился ли структурированный процесс инструмента в деталях сообщения; если нет, замените модель на более стабильную для вызова инструментов.

### Есть результаты поиска, но ссылки не открываются

Возможные причины: страница недоступна, требуется вход, действует защита от ботов или региональное ограничение, Fetch не смог прочитать страницу. Попросите модель использовать другой источник и вручную проверьте ключевые выводы.

### Все равно использует старые знания модели после включения

Четкое указание:

```text
Сначала обязательно выполни веб-поиск. Если поиск завершится ошибкой, сообщи об этом и не отвечай только на основании имеющихся знаний.
```

Если это по-прежнему не работает, создайте новый диалог, смените модель или проверьте провайдера поиска.

### Хочу использовать собственный веб-поиск Volcengine Ark

В Cherry Studio пока нет соответствующей встроенной настройки. Не используйте переключатель возможностей модели как адаптер. Самостоятельно проверьте интеграцию по актуальной документации Responses API или API приложений Ark либо временно используйте внешний веб-поиск Cherry Studio.

### Возврат кодов 401, 403, 404 или 429

Обычно это проблемы с подключением к модели Ark, а не сами настройки веб-поиска:

- `401`: Недействительный API Key;
- `403`: Нет прав на проект, модель или конечную точку (Endpoint);
- `404`: Ошибка API Host, Model ID или Endpoint ID;
- `429`: Достигнут лимит скорости, параллелизма или квоты.

Сначала отключите веб-поиск и убедитесь, что обычный диалог снова работает. Затем отдельно проверьте подключение модели и поисковый сервис.
