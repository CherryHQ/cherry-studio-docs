# Очистка настроек CSS

Синтаксические или селекторные ошибки в пользовательском CSS могут перекрывать кнопки, скрывать текст, предотвращать прокрутку или даже делать настройки недоступными. Выберите метод восстановления ниже в зависимости от того, осталась ли возможность использовать интерфейс.

## Метод 1: Очистка в настройках

Если вы все еще можете открыть «Настройки»:

1. Перейдите в **Настройки > Общие настройки > Пользовательский CSS**.
2. Скопируйте любой CSS, который вам нужно отладить, в текстовый файл.
3. Выделите и удалите все в редакторе.
4. Подождите, пока интерфейс восстановится.
5. Полностью закройте Cherry Studio, снова запустите приложение и убедитесь, что проблема не повторяется.

Это предпочтительный метод. Очистка редактора также удаляет сохраненную настройку Пользовательского CSS.

## Метод 2: Временное восстановление интерфейса с помощью инструментов разработчика

Если некорректные стили делают страницу «Настройки» непригодной для использования, сначала удалите внедренный узел стиля из текущего окна.

{% hint style="warning" %}
Команда ниже **временно восстанавливает только текущее окно**. Перед перезагрузкой или повторным запуском приложения вы должны вернуться в «Настройки» и очистить CSS, иначе некорректные стили снова появятся.
{% endhint %}

### 1. Открыть инструменты разработчика

Используйте любой из следующих методов:

- Windows / Linux: нажмите <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd>;
- macOS: нажмите <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>I</kbd>;
- Меню приложения: выберите **Вид > Переключить инструменты разработчика**;
- Щелкните правой кнопкой мыши в пустом месте страницы и выберите **Исследовать**.

### 2. Открыть консоль

Выберите **Консоль** в верхней части инструментов разработчика. Если закрепление инструментов разработчика оставляет слишком мало места, переместите их в отдельное окно.

### 3. Удалить текущие стили

Вручную введите следующую строку в Консоль, затем нажмите Enter:

```javascript
document.getElementById('user-defined-custom-css')?.remove()
```

После выполнения команды Пользовательский CSS должен быть немедленно удален из текущего основного окна.

Некоторые версии Chromium блокируют прямое вставление в Консоль. Следуйте инструкциям безопасности в инструментах разработчика или введите эту короткую команду вручную. Не вставляйте другие скрипты из неизвестных источников.

### 4. Удалить сохраненный CSS

Не перезагружайте и не закрывайте текущее окно. Сделайте это немедленно:

1. Вернитесь в Cherry Studio;
2. Откройте **Настройки > Общие настройки > Пользовательский CSS**;
3. Очистите редактор;
4. Закройте инструменты разработчика;
5. Полностью закройте приложение и снова откройте его.

Если после перезапуска интерфейс работает нормально, сохраненный CSS был очищен.

## Удалить только проблемные правила

Если вы хотите сохранить остальную часть темы:

1. Используйте Метод 2 для временного восстановления интерфейса;
2. Скопируйте весь CSS из редактора во внешний текстовый файл;
3. Очистите редактор и убедитесь, что приложение восстановилось;
4. Восстанавливайте только небольшими частями;
5. Проверяйте светлый режим, темный режим, чаты, «Настройки» и диалоговые окна по отдельности.

Когда проблема вернется, обычно лучше всего начинать отладку с последнего восстановленного правила.

Частые причины включают:

- Отсутствие `}`, `;` или кавычек;
- Глобальные переопределения, использующие `display: none`, `position: fixed` или очень высокий `z-index`;
- Правила, скрывающие каждую кнопку, поле ввода или контейнер прокрутки;
- Старые имена классов или устаревшие селекторы тем, такие как `body[theme-mode="dark"]`;
- Широкое использование `!important`;
- Сторонняя тема, несовместимая с текущей структурой DOM.

## Часто задаваемые вопросы

### Ничего не меняется после выполнения команды

Убедитесь, что Консоль подключена к основной странице Cherry Studio, а не к веб-странице мини-приложения или самим инструментам разработчика. Повторно выполните эту команду:

```javascript
document.getElementById('user-defined-custom-css')
```

Если она возвращает `null`, текущее окно не содержит этот узел стиля. Проблема может быть вызвана не Пользовательским CSS, или команда может выполняться в неправильном контексте страницы.

### Проблема возвращается после перезапуска

Это происходит потому, что вы удалили только узел стиля с текущей страницы, не очистив сохраненную настройку. Повторите Метод 2, затем откройте редактор CSS и очистите его содержимое, не перезагружая страницу.

### Сочетание клавиш не открывает инструменты разработчика

Попробуйте **Вид > Переключить инструменты разработчика** из меню приложения или щелкните правой кнопкой мыши и выберите **Исследовать**. Системная утилита горячих клавиш может перехватывать комбинацию клавиш по умолчанию.

### Страница «Настройки» все равно не открывается

Не удаляйте весь каталог данных приложения и не редактируйте базу данных напрямую. Сохраните текущий номер версии, системную информацию и каталог журналов, а затем обратитесь за помощью через официальный канал обратной связи.

### Пользовательский стиль остается после очистки CSS

Проверьте, включена ли какая-либо тема операционной системы, встроенный цвет темы Cherry Studio, настройки шрифта или сторонний инструмент для окон. Они отделены от Пользовательского CSS и не сбрасываются шагами на этой странице.

## Как предотвратить повторение проблемы

- Добавляйте правила небольшими частями;
- Сохраняйте рабочую версию перед внесением изменений;
- Предпочитайте переопределение семантических переменных, а не полагаться на внутренние имена классов и иерархию DOM;
- После обновления Cherry Studio отключайте сложные темы перед их проверкой по частям;
- Используйте только сторонний CSS, который вы можете прочитать и понять.

Больше рекомендаций по написанию см. в [Пользовательский CSS](css.md).
