# Пользовательский CSS

Пользовательский CSS позволяет переопределять стили интерфейса Cherry Studio и подходит для настройки цветов, отступов, скругления и внешнего вида компонентов, которых нет во встроенных параметрах.

{% hint style="warning" %}
Пользовательский CSS — функция для опытных пользователей. После обновления приложения структура компонентов, имена классов и переменных могут измениться; стиль, работающий сейчас, не обязательно сохранит работоспособность в следующих версиях.
{% endhint %}

## Когда это необходимо

Прежде чем писать CSS, проверьте раздел **Настройки > Общие настройки > Отображение и язык**. В V2 уже встроены следующие параметры:

- светлая, тёмная и системная темы;
- акцентный цвет темы;
- масштаб интерфейса;
- общий шрифт и шрифт кода;
- положение и способ отображения тем.

Встроенные параметры стабильнее, и их можно сбросить напрямую. Используйте пользовательский CSS, только если встроенные настройки не позволяют достичь цели.

## Открытие редактора CSS

1. Нажмите **Настройки** в левом нижнем углу Cherry Studio.
2. Перейдите в **Общие настройки**.
3. Выберите **Пользовательский CSS** в меню второго уровня.
4. Введите или вставьте CSS в редактор.

Изменения сохраняются в локальных настройках и применяются к интерфейсу при изменении содержимого. Нажимать отдельную кнопку сохранения не нужно.

Рекомендуется сначала сохранить копию текущего CSS, а затем изменять его небольшими частями. После каждого короткого фрагмента проверяйте чат, настройки, диалоговые и вспомогательные окна: так легче найти причину проблемы.

## Начните с минимального стиля

В следующем примере изменяется только фон сообщений пользователя и обычное скругление:

```css
:root {
  --chat-background-user: rgba(0, 185, 107, 0.08);
  --list-item-border-radius: 12px;
}
```

Чтобы задать отдельные параметры для светлой и тёмной темы, используйте классы темы корневого элемента:

```css
:root:not(.dark) {
  --chat-background-user: rgba(0, 120, 80, 0.08);
}

:root.dark {
  --chat-background-user: rgba(90, 220, 160, 0.12);
}
```

{% hint style="info" %}
В Cherry Studio V2 текущая тема обозначается классами `.light` / `.dark`. Распространённую в старых темах конструкцию `body[theme-mode="dark"]` не следует использовать как основу новых стилей.
{% endhint %}

## Часто используемые семантические переменные

Старайтесь переопределять семантические переменные: они реже перестают работать, чем прямые обращения к внутренним именам классов.

| Переменная | Назначение |
| --- | --- |
| `--color-primary` | Основной акцентный цвет |
| `--color-background` | Основной цвет фона |
| `--color-background-subtle` | Вторичный цвет фона |
| `--color-foreground` | Основной цвет текста |
| `--color-foreground-secondary` | Вторичный цвет текста |
| `--color-border` | Обычный цвет границ |
| `--color-card` | Цвет фона карточек |
| `--color-popover` | Цвет фона всплывающих элементов |
| `--chat-background-user` | Цвет фона сообщений пользователя |
| `--chat-background-assistant` | Цвет фона сообщений ассистента |
| `--font-family` | Стек общих шрифтов |
| `--code-font-family` | Стек шрифтов кода |

Например, следующий стиль задаёт фон и границы отдельно для двух тем:

```css
:root:not(.dark) {
  --color-background: #f7f8f6;
  --color-background-subtle: #f0f2ef;
  --color-border: rgba(20, 35, 28, 0.12);
}

:root.dark {
  --color-background: #171a18;
  --color-background-subtle: #1e221f;
  --color-border: rgba(235, 255, 244, 0.12);
}
```

{% hint style="warning" %}
Для цвета темы и шрифтов уже есть встроенные параметры. Если переопределять те же переменные в CSS, итог зависит от приоритета селекторов и порядка загрузки и может не соответствовать значению на странице настроек.
{% endhint %}

## Изменение отдельных компонентов

Если переменных недостаточно, исследуйте элемент с помощью инструментов разработчика браузера, а затем создайте селектор.

```css
/* Пример: сделать границы карточек на странице настроек заметнее */
[class*="border-border"] {
  border-color: color-mix(in srgb, var(--color-border) 75%, var(--color-foreground) 25%);
}
```

Такие селекторы сильнее семантических переменных зависят от обновлений версии. Соблюдайте следующие правила:

- ограничивайте область действия и не переопределяйте напрямую все `div`, `button` или `input`;
- реже используйте селекторы, зависящие от иерархии и номера, например `:nth-child()`;
- не рассчитывайте, что автоматически созданные имена классов останутся неизменными;
- не используйте `!important` повсеместно;
- добавляйте к каждой группе правил короткий комментарий с её назначением;
- после изменений проверяйте светлую и тёмную темы.

Приведённый выше селектор компонента только демонстрирует синтаксис и не является стабильным общедоступным интерфейсом.

## Поиск текущих переменных

Cherry Studio переходит на новую систему дизайна V2, поэтому переменные делятся на две группы:

- [Переменные темы V2](https://github.com/CherryHQ/cherry-studio/blob/main/packages/ui/src/styles/theme.css);
- [Переменные совместимости со старым интерфейсом](https://github.com/CherryHQ/cherry-studio/blob/main/src/renderer/assets/styles/legacy-vars.css).

Переменные совместимости всё ещё используются, но в будущем могут быть удалены. В новых темах отдавайте предпочтение семантическим переменным V2 и проверяйте оформление после каждого крупного обновления.

Ссылка **cherrycss.com** в верхней части редактора открывает сайт тем сообщества. Перед использованием темы сообщества прочитайте весь CSS и убедитесь, что доверяете его источнику.

## Рекомендации по безопасности

CSS сам по себе не является JavaScript, но может запрашивать сетевые ресурсы через `url()`, `@import` или внешние шрифты. При использовании сторонней темы:

- проверьте, нет ли ссылок на незнакомые домены;
- не записывайте токены, Cookie, имена пользователей или локальные пути в CSS;
- сохраняйте необходимые изображения и шрифты в надёжном месте;
- записывайте источник и номер версии исходной темы;
- не запускайте дополнительные консольные скрипты автора темы, назначение которых непонятно.

## Восстановление стиля по умолчанию

В обычной ситуации:

1. Откройте **Настройки > Общие настройки > Пользовательский CSS**.
2. Скопируйте и сохраните резервную копию нужных данных.
3. Удалите весь CSS из редактора.
4. Убедитесь, что интерфейс восстановился; при необходимости перезапустите приложение.

Если ошибочный стиль скрыл кнопку настроек или сделал страницу недоступной, обратитесь к разделу [Очистка настроек CSS](clear-css.md).

## Частые вопросы

### После ввода CSS ничего не изменилось

Сначала убедитесь, что синтаксис полон и правая фигурная скобка не пропущена. Затем проверьте, соответствует ли селектор элементам текущей версии и существует ли переменная.

### Светлая тема работает, а тёмная отображается неправильно

Разделите правила для двух тем, используя `:root:not(.dark)` и `:root.dark`, и проверьте контраст между текстом и фоном.

### Изменение цвета темы не применяется

Встроенная настройка записывает цвет темы в переменную среды выполнения. Сначала используйте **Отображение и язык > Цвет темы**. Если переопределение через CSS необходимо, проверьте `--cs-theme-primary` и приоритет селектора, но вести два набора значений одновременно не рекомендуется.

### После обновления нарушилось расположение элементов

Временно удалите весь пользовательский CSS и проверьте, исчезла ли проблема. Затем возвращайте его частями, удаляя правила, которые зависят от старых имён классов, старой иерархии DOM или переменных совместимости.

### Вспомогательные окна отображаются неправильно

Пользовательский CSS может применяться и к быстрому ассистенту, инструменту выделенного текста и другим окнам. Избегайте слишком широких глобальных селекторов и проверяйте часто используемые окна по одному.
