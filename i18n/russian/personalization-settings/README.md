# Настройки персонализации

В Cherry Studio V2 часто используемые параметры оформления собраны в разделе **Настройки > Общие настройки > Отображение и язык**. Без написания кода можно изменить тему, цвет, масштаб, шрифты и расположение тем. Пользовательский CSS нужен, только если встроенных параметров недостаточно.

{% hint style="info" %}
«Настройки персонализации» — название раздела в этой документации, а не отдельное меню в приложении. Откройте **Настройки** в левом нижнем углу и перейдите в **Общие настройки**.
{% endhint %}

## Сначала выберите подходящий способ

| Что требуется сделать | Рекомендуемый раздел | Риск |
| --- | --- | --- |
| Переключить светлую, тёмную или системную тему | Настройки > Общие настройки > Отображение и язык | Низкий |
| Изменить акцентный цвет темы | Настройки > Общие настройки > Отображение и язык | Низкий |
| Увеличить или уменьшить весь интерфейс | Настройки > Общие настройки > Отображение и язык | Низкий |
| Изменить общий шрифт или шрифт кода | Настройки > Общие настройки > Отображение и язык | Низкий |
| Настроить положение, время и закрепление тем | Настройки > Общие настройки > Отображение и язык | Низкий |
| Глубоко изменить оформление компонентов | Настройки > Общие настройки > Пользовательский CSS | Средний |
| Перенести данные приложения на другой диск | Настройки > Настройки данных > Каталог данных | Высокий, рекомендуется сначала сделать резервную копию |

Рекомендуется начать со встроенных параметров. Они поддерживаются при обновлении версий и обычно стабильнее пользовательского CSS.

## Отображение и язык

В разделе **Настройки > Общие настройки > Отображение и язык** доступны следующие параметры.

### Язык и тема

- **Язык**: переключает язык интерфейса Cherry Studio;
- **Тема**: светлая, тёмная или системная;
- **Цвет темы**: выбор из готовых цветов или ввод пользовательского цвета;
- **Прозрачность окна**: отображается только в macOS;
- **Использовать системную строку заголовка**: отображается только в Linux; после изменения необходимо перезапустить приложение.

### Масштаб интерфейса

Используйте кнопки «минус» и «плюс», чтобы поэтапно изменить масштаб всего приложения. Кнопка сброса восстанавливает масштаб по умолчанию.

Если мелким кажется только текст сообщений, сначала измените размер шрифта сообщений. Если малы также кнопки, боковая панель и окна, измените масштаб всего интерфейса.

### Шрифты

V2 считывает шрифты, установленные в операционной системе, и предлагает отдельные настройки:

- **Общий шрифт**: используется в большей части интерфейса и основном тексте;
- **Шрифт кода**: используется для моноширинного содержимого, включая блоки и редактор кода.

Выбранный шрифт применяется сразу. Кнопка сброса рядом с соответствующим параметром восстанавливает шрифт по умолчанию. Инструкции по установке нового шрифта приведены в разделе [Рекомендуемые шрифты](font.md).

{% hint style="info" %}
Список шрифтов формируется из данных текущей операционной системы. Если после установки нового шрифта список не обновился, полностью закройте и снова откройте Cherry Studio.
{% endhint %}

### Расположение тем

Список тем можно разместить слева или справа, а также настроить:

- нужно ли автоматически переключаться на тему при выборе ассистента;
- показывать ли время темы;
- закреплять ли выбранную тему вверху.

Параметр «Автоматически переключаться на тему при выборе ассистента» отображается, только когда темы расположены слева.

## Пользовательский CSS

Если встроенных тем и параметров расположения недостаточно, откройте **Настройки > Общие настройки > Пользовательский CSS** и измените стили напрямую.

Пользовательский CSS подходит для изменения отступов, цветов, скругления и внешнего вида отдельных компонентов. Однако после обновления приложения структура компонентов может измениться, а старые правила — перестать работать. Перед началом прочитайте раздел [Пользовательский CSS](css.md) и сохраните копию рабочего стиля.

Если из-за ошибочного стиля страница настроек стала недоступна, восстановите её по инструкции [Очистка настроек CSS](clear-css.md).

{% hint style="warning" %}
Не используйте CSS как основной способ изменения шрифта или цвета темы. В V2 для этого есть встроенные параметры: их проще отменить, и они реже перестают работать после обновления.
{% endhint %}

## Каталог данных

Изменение места хранения — это перенос данных, а не настройка оформления. Параметр находится в разделе **Настройки > Настройки данных > Каталог данных**.

При переносе могут затрагиваться диалоги, ассистенты, базы знаний и другие локальные данные. Перед операцией сделайте резервную копию и убедитесь, что целевой каталог:

- не является корнем диска;
- не находится внутри текущего каталога данных;
- не находится внутри каталога установки приложения;
- доступен для записи;
- имеет достаточно свободного места.

Подробные инструкции и предостережения приведены в разделе [Изменение места хранения](storage.md).

## Рекомендуемый порядок

Чтобы быстро настроить интерфейс, действуйте в следующем порядке:

1. Выберите тему и её цвет;
2. настройте масштаб интерфейса;
3. выберите общий шрифт и шрифт кода;
4. настройте расположение тем;
5. добавляйте пользовательский CSS только после того, как убедитесь, что встроенных параметров недостаточно.

Такой порядок уменьшает конфликты стилей и упрощает последующее восстановление оформления по умолчанию.
