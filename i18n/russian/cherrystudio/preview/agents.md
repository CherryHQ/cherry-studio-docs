# Библиотека ассистентов

Библиотека ассистентов — это каталог пресетов диалоговых ассистентов Cherry Studio. Пресет в основном хранит название, значок, промпт и некоторые настройки по умолчанию. После добавления пресета в диалог он становится самостоятельным ассистентом, которого можно отдельно редактировать.

{% hint style="warning" %}
«Ассистент» из библиотеки предназначен для ролевых диалогов и отличается от [агента Cherry Agent](../../advanced-basic/agent.md). Если требуется доступ к рабочей области, чтение и запись файлов, выполнение команд или последовательный вызов инструментов, используйте агента.
{% endhint %}

## Библиотека ассистентов, диалоговые ассистенты и библиотека ресурсов

| Название | Назначение |
| --- | --- |
| Библиотека ассистентов | Просмотр встроенных пресетов, управление собственными пресетами, импорт или подписка на источники |
| Диалоговый ассистент | Доступный ассистент, уже добавленный на [страницу диалога](chat.md); у него есть собственные темы и настройки |
| [Библиотека ресурсов](library.md) | Централизованное создание и редактирование моделей, ассистентов, агентов и других ресурсов; подходит для полной настройки |

При добавлении пресета из библиотеки Cherry Studio создаёт его копию как нового диалогового ассистента. Последующее изменение или удаление исходного пресета не изменяет уже созданного ассистента автоматически.

## Открытие библиотеки ассистентов

Её можно открыть следующими способами:

* **Стартовый экран → Библиотека ассистентов**.
* Кнопка добавления в списке ассистентов на странице диалога.

Если нужно только быстро добавить ассистента, удобнее искать пресеты через кнопку добавления на странице диалога. Для просмотра категорий, импорта, подписки или пакетного управления откройте полную библиотеку ассистентов.

## Просмотр и поиск пресетов

Слева в библиотеке пресеты сгруппированы по разделу «Мои» и категориям назначения, а в основной области показаны карточки текущей категории.

* **Категории** — просмотр категорий, предоставленных встроенными пресетами или текущим источником подписки.
* **Поиск** — поиск по названиям и описаниям во всех категориях.
* **Предпросмотр карточки** — просмотр названия, описания и краткого содержимого промпта.
* **Мои** — просмотр самостоятельно созданных или импортированных пресетов.

Категории и их количество зависят от версии приложения, выбранного языка и источника подписки, поэтому фиксированный список здесь не приводится.

## Создание диалогового ассистента из пресета

1. Найдите нужный пресет.
2. Нажмите его карточку и проверьте промпт и описание.
3. Выберите **Добавить к ассистентам**.
4. Вернитесь на [страницу диалога](chat.md).
5. Выберите добавленного ассистента в списке и укажите модель в верхней части страницы.

После добавления ассистент получает собственный ID и тему по умолчанию. Можно изменять его промпт, модель, базу знаний, MCP и параметры модели, не затрагивая исходный пресет в библиотеке.

## Создание собственного ассистента

Доступны два способа для разных задач.

### Создание облегчённого пресета в библиотеке ассистентов

Нажмите **Создать ассистента** и заполните:

* **Название** — используется для поиска и распознавания.
* **Emoji** — значок ассистента; если не выбран, приложение попытается извлечь его из названия.
* **Промпт** — определяет роль, цель, ограничения и формат результата.
* **База знаний** — необязательно; связывает уже созданную базу знаний.

Название и промпт обязательны. В редакторе промпта можно вызвать модель ассистента по умолчанию для оптимизации, а также отменить выполненное AI изменение.

После сохранения пресет появится в разделе «Мои». Чтобы использовать его в диалоге, нажмите пресет и выберите **Добавить к ассистентам**.

### Создание полного ассистента в библиотеке ресурсов

Чтобы сразу настроить модель, теги и расширенные параметры, рекомендуется создать ассистента в [Библиотеке ресурсов](library.md). Полный редактор включает:

* название, Emoji, описание, теги и модель;
* системный промпт;
* Temperature, Top P, максимальную длину ответа, число сообщений контекста и потоковый вывод;
* режим вызова инструментов, максимальное число вызовов и пользовательские параметры;
* базу знаний;
* режим MCP и Server.

В полном редакторе название и промпт также обязательны. Если особых требований нет, оставьте параметры модели по умолчанию.

## Выбор модели

При создании или импорте облегчённого пресета через библиотеку Cherry Studio использует текущую [модель ассистента по умолчанию](settings/default-models.md) в качестве модели пресета. После добавления в диалог модель можно переключить в верхней части страницы.

При создании полного ассистента в библиотеке ресурсов модель можно выбрать непосредственно перед сохранением.

Не записывайте настройку модели в системный промпт. Для смены модели используйте селектор, чтобы можно было проверить поставщика и фактический ID модели.

## Импорт пресета ассистента

Нажмите **Импортировать** и выберите один из вариантов:

### Импорт из URL

1. Выберите **URL**.
2. Вставьте адрес, напрямую возвращающий JSON.
3. Нажмите кнопку импорта.

### Импорт из файла

1. Выберите **Файл**.
2. Выберите файл `.json`.
3. Нажмите кнопку импорта.

Импортируемое содержимое может быть одним объектом или массивом объектов. Каждый пресет должен содержать как минимум `name` и `prompt`:

```json
[
  {
    "name": "Ассистент проверки документации",
    "emoji": "📝",
    "description": "Проверяет структуру, терминологию и применимость инструкций",
    "prompt": "Проверь документацию продукта и предложи конкретные исправления."
  }
]
```

При импорте для каждого пресета создаётся новый локальный ID и используется текущая модель ассистента по умолчанию. Старые темы и сообщения из исходного файла не импортируются как история диалога.

{% hint style="warning" %}
Импортируйте только из доверенных источников. Промпт пресета может содержать скрытые цели, внешние ссылки или требования к поведению, которые вам не подходят. Проверьте промпт до добавления пресета в диалог.
{% endhint %}

## Подписка на источник ассистентов

Подписка подходит для удалённого набора пресетов, который поддерживается командой или сообществом:

1. Нажмите **Импортировать**.
2. В области подписки укажите адрес HTTP(S), напрямую возвращающий массив JSON.
3. Нажмите **Подписаться**.
4. После перезагрузки Cherry Studio считает системные пресеты с этого адреса.

Если источник подписки доступен, он используется как источник системных пресетов. При ошибке удалённого чтения Cherry Studio возвращается к встроенным пресетам приложения. После отмены подписки снова используются встроенные пресеты.

Различия между подпиской и разовым импортом:

| | Разовый импорт | Подписка |
| --- | --- | --- |
| Расположение данных | Импортируются как локальные пресеты «Мои» | Считываются из удалённого источника при запуске или перезагрузке |
| Последующие обновления | Не изменяются автоматически | Могут обновиться после изменения источника и перезагрузки |
| Подходит ли для локального изменения | Да | Рекомендуется централизованное управление в источнике подписки |

Подробный формат и способы управления см. в разделе [Подписка на ассистентов](../../data-settings/assistants-subscribe.md).

## Управление пресетами «Мои»

В категории «Мои» через меню карточки или **Управление ассистентами** можно:

* изменить пресет;
* добавить его как диалогового ассистента;
* экспортировать отдельный пресет в JSON;
* удалить пресет;
* перетащить для изменения порядка;
* выбрать несколько пресетов для экспорта или удаления.

JSON пакетного экспорта можно повторно импортировать на другом устройстве. Перед удалением пресета убедитесь, что он больше не нужен для создания новых ассистентов. Уже добавленные в диалог ассистенты не удаляются вместе с пресетом.

## Изменение уже добавленного ассистента

После добавления пресета в диалог изменяйте его в настройках диалогового ассистента или в библиотеке ресурсов. Распространённые параметры:

* системный промпт;
* текущая модель и модель по умолчанию;
* база знаний и веб-поиск;
* инструменты MCP;
* параметры контекста и ответа.

Полное описание работы с диалогом см. в разделе [Интерфейс диалога](chat.md).

## Ассистент или агент

| Задача | Рекомендация |
| --- | --- |
| Вопросы и ответы, написание текстов, перевод или анализ с постоянной ролью | Диалоговый ассистент |
| Повторное использование и обмен шаблонами промптов | Пресет библиотеки ассистентов |
| Централизованное редактирование модели, параметров, базы знаний и MCP | Редактор ассистента в библиотеке ресурсов |
| Доступ к рабочей области, чтение и запись файлов, выполнение команд | [Агент](../../advanced-basic/agent.md) |
| Запуск по расписанию и отправка результата во внешний канал | Агент + [Запланированные задачи](../../advanced-basic/scheduled-tasks.md) + [Каналы](../../advanced-basic/agent-channels.md) |

При ошибке импорта, недоступности источника подписки или неправильной работе пресета отправьте через раздел [Отзывы и предложения](../../question-contact/suggestions.md) пример JSON, состояние ответа URL и сведения об ошибке. Перед отправкой удалите личные данные и секреты.
