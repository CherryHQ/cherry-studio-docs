# Файлы

Страница «Файлы» предназначена для просмотра и очистки содержимого файлового индекса Cherry Studio, например вложений из диалогов, вставленных изображений и некоторых файлов, созданных или сохранённых приложением.

Это не универсальный файловый менеджер компьютера: он не отображает автоматически все файлы на диске.

{% hint style="info" %}
Источники данных базы знаний управляются отдельно на странице базы знаний и могут здесь не отображаться. Для обновления, повторной индексации или удаления материалов перейдите в раздел [База знаний](knowledge-base.md).
{% endhint %}

## Как открыть страницу «Файлы»

1. Нажмите **+** справа на верхней панели вкладок, чтобы открыть новую вкладку стартового экрана.
2. На стартовом экране выберите **Файлы**.

Слева расположены фильтры по типу, а справа — файлы текущей категории.

## Просмотр и фильтрация файлов

Слева доступны четыре категории:

| Категория | Отображаемое содержимое |
| --- | --- |
| Документ | Файлы, распознанные как документы |
| Изображение | Файлы изображений |
| Текст | Простые текстовые файлы и файлы текстовых форматов |
| Все файлы | Всё содержимое файлового индекса |

По умолчанию открывается категория **Документ**. При переключении категории текущий множественный выбор сбрасывается.

### Сортировка

Доступна сортировка по следующим полям:

* Дата создания
* Размер
* Имя файла

При первом нажатии поля применяется сортировка по убыванию, а при повторном нажатии того же поля — по возрастанию.

### Сведения о файле

Документы, текст и категория «Все файлы» отображаются в виде списка. Для каждого элемента указаны имя файла, расширение, дата создания, счётчик и размер.

Изображения отображаются сеткой миниатюр для быстрого просмотра.

## Открытие или предварительный просмотр

### Документы и текст

Нажмите имя файла в списке, и Cherry Studio откроет его в системном приложении, назначенном по умолчанию для этого формата.

Открытие может завершиться ошибкой, если файл был перемещён, недостаточно прав доступа к диску или в системе нет подходящего приложения по умолчанию.

### Изображения

При нажатии миниатюры открывается средство просмотра изображений. В нём можно переключаться между другими изображениями текущей категории.

## Переименование файла

В списке документов, текста или всех файлов:

1. Найдите нужный файл.
2. Нажмите кнопку редактирования справа в его строке.
3. Введите новое имя и подтвердите.

Если новое имя не содержит исходного расширения, Cherry Studio автоматически сохранит его.

{% hint style="warning" %}
Переименование изменяет только имя, которое Cherry Studio отображает и использует для управления файлом. Содержимое файла не меняется.
{% endhint %}

## Удаление одного файла

### Документы и текст

Нажмите кнопку удаления справа в строке файла и подтвердите действие в диалоговом окне.

### Изображения

Наведите указатель на миниатюру, нажмите кнопку удаления в правом верхнем углу и подтвердите действие.

При удалении очищается сам файл и ссылки на него как на вложение в сообщениях. Отменить эту операцию в Cherry Studio невозможно.

Если изображение всё ещё используется в истории рисунков, Cherry Studio заблокирует удаление и покажет сообщение. Сначала обработайте соответствующую запись в разделе рисунков.

## Массовое удаление

Массовые операции доступны для категорий документов, текста и всех файлов. Для изображений множественный выбор не предусмотрен.

1. Отметьте файлы для удаления или нажмите **Выделить всё** в правом верхнем углу.
2. Откройте меню массовых операций.
3. Выберите **массовое удаление** и подтвердите.

{% hint style="warning" %}
При массовом удалении также удаляются ссылки на эти файлы как на вложения в сообщениях. Перед выполнением операции убедитесь, что для важных файлов существует отдельная резервная копия.
{% endhint %}

## Какие файлы здесь отображаются

Обычно здесь можно увидеть:

* содержимое, загруженное или вставленное в диалоге и сохранённое в файловом каталоге приложения;
* изображения и другие результаты, созданные во время диалога и внесённые в файловый индекс;
* локальные файлы, зарегистрированные прежним механизмом работы с файлами в Cherry Studio.

Следующее содержимое может не отображаться:

* файлы на диске компьютера, которые никогда не добавлялись в Cherry Studio;
* файлы, сохранённые только на сервере внешнего провайдера;
* исходные материалы, отдельно управляемые новыми источниками данных базы знаний;
* содержимое, удалённое из файлового индекса.

Чтобы добавить новое вложение в диалог, откройте [Диалог](chat.md) и используйте кнопку вложения в поле ввода либо перетащите туда файл.

## Место хранения

Содержимое файлов хранится в каталоге данных приложения Cherry Studio. Рекомендуется просматривать и переносить его через **Настройки → Настройки данных → Каталог данных**. Не перемещайте, не переименовывайте и не удаляйте внутренние файлы в этом каталоге вручную, пока приложение запущено.

Точное расположение и порядок переноса описаны в разделе [Изменение места хранения](../../personalization-settings/storage.md).

## Частые вопросы

### После удаления файла вложение исчезло из старого сообщения

Это часть текущего поведения при удалении: вместе с файлом удаляется ссылка на вложение из соответствующего сообщения. Если историческое вложение нужно сохранить, не удаляйте исходный файл на странице «Файлы».

### Не удаётся найти материал, импортированный в базу знаний

База знаний использует собственные источники данных и процесс управления индексом. Просматривайте, повторно индексируйте и удаляйте материалы на странице сведений о базе знаний.

### Нажатие имени файла ничего не делает

Убедитесь, что файл всё ещё существует, а в системе настроено приложение по умолчанию для его расширения. Если каталог данных приложения был перемещён вручную, исходный путь также мог стать недействительным.

### Не удаётся удалить изображение

Возможно, изображение всё ещё используется в истории рисунков. Сначала обработайте соответствующую запись на странице рисунков, затем вернитесь на страницу файлов и удалите изображение.
