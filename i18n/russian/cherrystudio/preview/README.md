# Обзор возможностей

Cherry Studio V2 объединяет диалоги с несколькими моделями, агентов, создание контента, управление знаниями и инструменты автоматизации в одном рабочем пространстве настольного приложения. Эта страница поможет быстро выбрать нужный модуль; подробные инструкции приведены в отдельных руководствах по каждой функции.

## Где найти функции

В Cherry Studio есть три основных способа открыть функции:

* **Стартовый экран** — централизованно открывает модули приложения и закреплённые мини-программы.
* **Левая боковая панель** — содержит часто используемые модули. Отображаемые значки можно выбрать в настройках.
* **Верхняя панель вкладок** — создаёт вкладку при каждом открытии функции или содержимого, что удобно для переключения между задачами.

Если интерфейс пока незнаком, сначала прочитайте раздел [Стартовый экран](launchpad.md).

## Различия между диалоговым ассистентом и агентом

Оба модуля используют модели, но предназначены для разных задач:

| | Диалоговый ассистент | Агент |
| --- | --- | --- |
| Подходит для | Вопросов и ответов, написания текстов, анализа и диалогов с постоянной ролью | Задач, требующих чтения и записи файлов, вызова инструментов или последовательного выполнения |
| Основные настройки | Промпт, модель, база знаний, MCP | Рабочая область, разрешения, навыки, инструменты, максимальное число циклов |
| Способ выполнения | Преимущественно обмен сообщениями | Автономно планирует и выполняет несколько действий для достижения цели |
| Управление рисками | В основном контролируется содержимое, отправляемое модели | Дополнительно требуется контролировать разрешения файлов и команд |

Если нужно только обсудить или создать содержимое, начните с диалогового ассистента. Используйте агента, когда задаче требуется доступ к локальной рабочей области или выполнение операций.

## Распространённые рабочие процессы

### Первое использование

1. Добавьте поставщика и модель в разделе [Сервисы моделей](../../pre-basic/providers/).
2. Откройте [Диалог](chat.md) и отправьте тестовое сообщение.
3. Добавьте часто используемого ассистента из [Библиотеки ассистентов](agents.md).
4. Настройте резервное копирование в разделе [Настройки данных](../../data-settings/).

### Ответы на основе материалов

1. Создайте новую [базу знаний](knowledge-base.md).
2. Импортируйте файлы, веб-страницы или другие поддерживаемые источники данных.
3. Дождитесь завершения обработки материалов.
4. Выберите базу знаний в диалоге и задайте вопрос.

### Выполнение задачи проекта

1. Создайте агента в [Библиотеке ресурсов](library.md).
2. Выберите модель, режим разрешений, навыки и инструменты.
3. Откройте агента и проверьте рабочую область.
4. Начните задачу с чётко сформулированной цели, проверяя запросы разрешений и изменения файлов в процессе выполнения.

### Вызов AI в любой момент

* Используйте [Быстрого ассистента](kuai-jie-zhu-shou.md), чтобы задать вопрос, не переключаясь из текущего приложения.
* Используйте [Ассистента выделенного текста](selection-assistant.md), чтобы перевести, обобщить или переписать уже выделенный текст.

## Автоматизация и внешнее подключение

Если базовых функций недостаточно для рабочего процесса, доступны:

* [MCP](../../advanced-basic/mcp/) — подключает диалогового ассистента к внешним инструментам и данным.
* [API Server](../../advanced-basic/api-server.md) — предоставляет совместимый интерфейс для вызова локальных возможностей Cherry Studio и также является частью пути выполнения агента V2.
* [Каналы](../../advanced-basic/agent-channels.md) — подключают агента к поддерживаемым каналам сообщений.
* [Запланированные задачи](../../advanced-basic/scheduled-tasks.md) — запускают сеанс агента по расписанию.

{% hint style="info" %}
Сначала настройте сервис моделей и резервное копирование данных, а затем постепенно включайте агента, MCP, каналы и запланированные задачи. Для записи файлов, выполнения команд и отправки данных во внешние сервисы предоставляйте только минимальные разрешения, необходимые задаче.
{% endhint %}
