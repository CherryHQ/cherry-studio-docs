# Перевод

Страница «Перевод» использует уже настроенные языковые модели для перевода текста. Она поддерживает автоматическое определение языка, потоковое отображение результата, импорт текста и документов, OCR изображений, историю переводов и пользовательские языки. Эти возможности подходят для работы с короткими текстами, письмами, фрагментами кода и текстом, извлечённым из файлов.

## Подготовка к работе

Для перевода нужна как минимум одна включённая текстовая модель:

1. Откройте `Настройки` → `Провайдеры моделей` и настройте провайдера и модель.
2. Выберите модель для перевода в правом верхнем углу страницы.
3. Если вы используете автоматическое определение языка с помощью LLM, также настройте **модель быстрого помощника** в разделе `Настройки` → `Модели по умолчанию`.

Модели для создания эмбеддингов, повторного ранжирования и генерации изображений не отображаются в списке моделей перевода. Если доступной модели ещё нет, сначала ознакомьтесь с разделом [Настройка провайдеров моделей](../../pre-basic/providers/README.md).

## Как открыть «Перевод»

Нажмите `+` справа на верхней панели вкладок, чтобы открыть **Запуск**, а затем выберите **Перевод**.

Страница состоит из следующих частей:

| Область | Назначение |
| --- | --- |
| Верхняя панель языков | Выбор исходного и целевого языков, смена направления перевода, запуск или остановка перевода |
| Левая область ввода | Ввод, вставка или импорт содержимого для перевода |
| Правая область результата | Потоковое отображение результата и копирование перевода |
| Инструменты в правом верхнем углу | Выбор модели, открытие истории и настроек перевода |

В узком окне области ввода и результата располагаются одна над другой.

## Как выполнить перевод

1. Выберите исходный язык. Если определить его заранее не удаётся, оставьте **Автоматическое обнаружение**.
2. Выберите целевой язык.
3. Введите или вставьте текст в левую область.
4. Нажмите **Перевести** либо используйте `Ctrl + Enter` в Windows / Linux или `Command + Enter` в macOS.
5. Просмотрите потоковый результат справа и после завершения нажмите кнопку копирования.

Во время перевода можно нажать **Остановить перевод**, чтобы прервать текущий запрос. При очистке левой области результат справа также удаляется.

{% hint style="info" %}
Результат генерируется выбранной в данный момент моделью. Профессиональную терминологию, договоры, медицинские и другие материалы с высоким уровнем риска должен дополнительно проверять квалифицированный специалист.
{% endhint %}

## Выбор исходного и целевого языков

### Автоматическое обнаружение

Если для исходного языка выбрано **Автоматическое обнаружение**, Cherry Studio сначала определит язык введённого текста и затем начнёт перевод. После успешного определения результат появится в поле исходного языка.

В настройках доступны три метода определения:

| Метод | Поведение |
| --- | --- |
| Автоматически | В зависимости от длины текста приоритет получает LLM или локальный алгоритм; если локальный алгоритм не определит язык, приложение обратится к LLM |
| Локальный алгоритм | Быстро определяет язык на устройстве без обращения к модели, но поддерживает сравнительно мало языков |
| LLM | Использует модель быстрого помощника; обычно лучше подходит для коротких или неоднозначных текстов, но требует одного дополнительного обращения к модели |

Если определение с помощью LLM завершается ошибкой, проверьте, настроена и доступна ли модель быстрого помощника.

### Смена направления перевода

Если исходный язык не установлен на **Автоматическое обнаружение**, можно нажать центральную кнопку смены направления. Cherry Studio одновременно поменяет местами исходный и целевой языки, оригинал и существующий перевод.

### Двунаправленный перевод

Если включить **Настройки двунаправленного перевода** и указать пару языков, Cherry Studio будет автоматически выбирать второй язык этой пары как целевой с учётом определённого языка ввода. Это удобно для регулярного общения на двух фиксированных языках.

Если язык ввода не входит в заданную пару, приложение сообщит, что не может определить направление.

## Импорт файла или изображения

Когда поле ввода пусто, слева отображается область импорта. Нажмите её, чтобы выбрать один файл, либо перетащите файл на страницу. Изображение из буфера обмена также можно вставить напрямую.

| Тип содержимого | Способ обработки |
| --- | --- |
| Изображение | Текст сначала распознаётся с помощью текущих настроек OCR, а затем добавляется в область ввода |
| Простой текст, Markdown, код и другие текстовые файлы | Текст считывается напрямую и добавляется в область ввода |
| Документы PDF, Word, PowerPoint, Excel и ODF | Доступный для чтения текст извлекается и добавляется в область ввода |

За один раз можно импортировать только один файл. Ограничение для текстовых файлов составляет 5 МБ, а для документов — 20 МБ. Фактически доступное для чтения содержимое зависит от формата, структуры документа и возможностей обработки файлов на устройстве.

{% hint style="warning" %}
При импорте из файла извлекается текст, но не создаётся переведённый документ с исходным форматированием. Если формат нужно контролировать для каждого фрагмента, сначала извлеките содержимое, а затем переводите и оформляйте его по частям.
{% endhint %}

Если текст на изображении не распознаётся, проверьте настройки OCR в разделе `Настройки` → `Обработка документов`, а также убедитесь, что изображение чёткое и правильно ориентировано.

## Выбор модели перевода

Нажмите значок модели в правом верхнем углу, чтобы выбрать модель перевода среди включённых текстовых моделей. При выборе учитывайте следующее:

- для повседневных коротких текстов выбирайте модели с быстрым откликом и приемлемой стоимостью;
- для длинных текстов учитывайте длину контекста и ограничение объёма вывода модели;
- для профессиональных материалов сравните, как разные модели обрабатывают терминологию и стиль;
- специализированная модель перевода может работать по собственному протоколу и не всегда использовать пользовательский промпт для перевода.

Если кнопка перевода постоянно недоступна, убедитесь, что текст введён и выбрана действующая модель.

## Настройки перевода

Нажмите кнопку настроек в правом верхнем углу, чтобы открыть боковую панель.

### Результат и действия

| Настройка | Назначение |
| --- | --- |
| Предпросмотр Markdown | Отображает перевод с разметкой Markdown; если настройка отключена, результат показывается как простой текст |
| Автоматически копировать после завершения перевода | После завершения перевода автоматически записывает результат в буфер обмена |
| Настройки синхронизации прокрутки | При прокрутке длинного текста синхронизирует обе области по их относительному положению |

### Промпт для перевода

Промпт для перевода определяет, как обычная диалоговая модель обрабатывает исходный текст. Шаблон по умолчанию содержит:

- `{{target_language}}`: текущий целевой язык;
- `{{text}}`: текст для перевода.

При изменении шаблона сохраните оба заполнителя. В противном случае модель может не получить целевой язык или исходный текст. Чтобы восстановить шаблон, нажмите **Сбросить**.

### Пользовательские языки

Помимо встроенных языков, можно добавить пользовательский. Для этого укажите отображаемое имя и код языка, а затем выберите значок. После создания можно изменить имя и значок либо удалить язык.

Код языка должен быть уникальным и не совпадать с кодом встроенного языка. Надёжность перевода по-прежнему зависит от того, понимает ли выбранная модель название и содержимое этого языка.

## История переводов

После каждого успешного перевода исходный текст, перевод, направление и время сохраняются в истории. Открыв панель истории в правом верхнем углу, можно:

- просмотреть и повторно загрузить перевод;
- скопировать исходный текст или перевод из истории;
- добавить часто используемую запись в избранное и показывать только избранные записи;
- удалить одну запись;
- после подтверждения очистить всю историю.

При повторной загрузке записи также восстанавливаются исходный текст, перевод и выбранное направление.

## Частые вопросы

### Кнопка перевода недоступна

Убедитесь, что область ввода не пуста и выбрана модель перевода, а затем дождитесь завершения чтения файла, определения языка или предыдущего перевода.

### Ошибка автоматического определения

Если используется определение с помощью LLM или автоматический метод переключился на LLM, проверьте модель быстрого помощника. Также можно явно выбрать исходный язык или попробовать локальный алгоритм.

### Результат пуст или перевод прерывается

Проверьте ключ провайдера модели, сеть, баланс, ограничение частоты запросов и доступность модели. Длинный текст также может превышать ограничения контекста или вывода модели — разделите его на короткие фрагменты и повторите попытку.

### Невозможно поменять местами исходный и целевой языки

Кнопка смены направления временно недоступна, если для исходного языка выбрано **Автоматическое обнаружение**, выполняется перевод, определяется язык или обрабатывается файл. Явно выберите исходный язык и дождитесь завершения текущей операции.

### Не удалось импортировать файл

Убедитесь, что за один раз выбран только один поддерживаемый файл и его размер не превышает ограничение. Из отсканированных документов, сложных таблиц, защищённых паролем или повреждённых файлов текст может извлекаться не полностью.

## Конфиденциальность и стоимость

Обычный текст для перевода отправляется провайдеру выбранной модели. При автоматическом определении с помощью LLM также вызывается модель быстрого помощника. До перевода изображение обрабатывается текущим компонентом OCR. Выбирайте службу и способ развёртывания с учётом конфиденциальности данных, а также ознакомьтесь с политикой конфиденциальности и тарифами соответствующего провайдера.
