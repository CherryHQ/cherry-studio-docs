# Помощник выбора

Помощник выбора показывает плавающую панель инструментов после выделения текста в другом приложении. С её помощью можно сразу перевести, объяснить, кратко изложить, найти или скопировать выделенный текст, а также добавить собственные действия ИИ.

{% hint style="info" %}
Помощник выбора и [Быстрый помощник](kuai-jie-zhu-shou.md) — две отдельные функции. Помощник выбора обрабатывает только что выделенный текст, а быстрый помощник открывает окно для ввода с помощью сочетания клавиш или значка в трее.
{% endhint %}

## Поддержка платформ

| Платформа | Текущее описание |
| --- | --- |
| macOS | Поддерживается; при первом включении нужно предоставить права универсального доступа |
| Windows | Поддерживается вызов при выделении, по клавише Ctrl и по сочетанию клавиш |
| Linux X11 | Поддерживаются основные функции; для отслеживания клавиш может потребоваться доступ к группе `input` |
| Linux Wayland | Возможности ограничены средой рабочего стола; панель может отображаться только по центру, а фильтрация приложений — не работать |

В среде Wayland страница настроек проверяет XWayland, доступ к группе `input` и совместимость композитора рабочего стола. Если текущая среда несовместима, рекомендуется использовать X11.

## Включение помощника выбора

1. Откройте **Настройки → Помощник выбора**.
2. Включите **Включить помощник выбора**.
3. Выберите способ получения текста.

Пока функция выключена, на странице настроек отображается демонстрационная панель. С её помощью можно проверить компактный режим и расположение действий.

### Права универсального доступа в macOS

При первом включении в macOS:

1. Нажмите переход к системным настройкам в запросе разрешения.
2. Откройте **Конфиденциальность и безопасность → Универсальный доступ**.
3. Предоставьте разрешение Cherry Studio.
4. Вернитесь в Cherry Studio и снова включите помощник выбора.

Если разрешение будет отозвано, Cherry Studio автоматически отключит помощник выбора.

### Права доступа в Linux

Если на странице настроек указано, что доступа к группе `input` нет, выполните:

```bash
sudo usermod -aG input $USER
```

После этого нужно выйти из текущего системного сеанса и войти снова. В Wayland также может потребоваться запуск в режиме XWayland; ориентируйтесь на результат проверки среды на странице настроек.

## Выбор способа получения текста

| Способ | Платформа | Поведение |
| --- | --- | --- |
| При выделении | macOS, Windows, Linux | Панель появляется сразу после выделения текста |
| По Ctrl | Windows | Панель появляется, только если после выделения удерживать Ctrl |
| По сочетанию клавиш | macOS, Windows | Панель появляется после нажатия настроенного сочетания для выделения |

Для способа с сочетанием клавиш откройте **Настройки → Горячие клавиши**, назначьте и включите сочетание «Помощник выбора: выделить текст». Предустановленной комбинации сейчас нет.

Если прямое выделение слишком часто вызывает панель по ошибке, используйте Ctrl или сочетание клавиш.

## Использование панели инструментов

1. Выделите текст в поддерживаемом приложении.
2. Дождитесь появления панели или нажмите выбранную клавишу вызова.
3. Нажмите нужное действие.

Значок Cherry Studio слева служит областью перетаскивания: с его помощью можно перемещать всю панель. Если включить **Компактный режим**, на панели останутся только значки; название по-прежнему отображается при наведении указателя.

## Встроенные действия

Помощник выбора содержит семь встроенных действий.

| Действие | Состояние по умолчанию | Поведение |
| --- | --- | --- |
| Перевести | Включено | Определяет язык оригинала и выбирает целевой язык между предпочтительным и альтернативным |
| Объяснить | Включено | Объясняет выделенное содержимое с помощью модели |
| Суммаризировать | Включено | Кратко излагает выделенное содержимое с помощью модели |
| Поиск | Включено | Открывает запрос в настроенной поисковой системе |
| Копировать | Включено | Записывает выделенное содержимое в буфер обмена |
| Уточнить | Выключено | Улучшает выделенное содержимое с помощью модели |
| Цитировать | Выключено | Вставляет выделенное содержимое в поле ввода главного окна Cherry Studio |

Для перевода используется настроенная модель перевода. Для объяснения, краткого изложения, уточнения и пользовательских действий ИИ без указанного ассистента используется модель по умолчанию.

{% hint style="warning" %}
В окне результата ИИ помощника выбора отключены веб-поиск, MCP и база знаний. Если эти инструменты нужны, процитируйте содержимое в главное окно и продолжите работу там.
{% endhint %}

## Настройка действий и порядка

В разделе **Настройки → Помощник выбора → Действия** верхний список содержит включённые действия, а нижний — выключенные.

Можно:

* перетаскивать действия, изменяя порядок на панели;
* перетащить действие в верхний список, чтобы включить;
* перетащить действие в нижний список, чтобы выключить;
* восстановить стандартный порядок и состояние встроенных действий.

Одновременно на панели можно включить не более восьми действий, при этом включённым должно оставаться хотя бы одно. Сброс не удаляет пользовательские действия, но перемещает их в область выключенных.

Промпты встроенных действий здесь изменить нельзя. Для действия «Поиск» можно отдельно выбрать поисковую систему.

## Добавление пользовательского действия

Можно создать до десяти пользовательских действий.

1. В настройках действий нажмите добавление пользовательского действия.
2. Введите название действия.
3. Выберите или случайным образом создайте значок Lucide.
4. Выберите модель по умолчанию или ассистента.
5. Введите промпт.
6. После сохранения перетащите новое действие в область включённых.

В промпте можно использовать `{{text}}` для обозначения выделенного текста. Если плейсхолдер не указан, выделенный текст автоматически добавится в конец промпта.

При выборе ассистента также используются его системный промпт, модель и параметры модели.

## Настройка поисковой системы

1. Найдите **Поиск** в списке действий.
2. Нажмите кнопку настроек справа.
3. Выберите Google, Baidu или Bing либо добавьте пользовательскую поисковую систему.

Пользовательский URL должен:

* начинаться с `http://` или `https://`;
* содержать плейсхолдер `{{queryString}}`.

При выполнении поиска Cherry Studio кодирует выделенный текст для URL и подставляет его вместо плейсхолдера. Если выделенное содержимое само является URL или локальным абсолютным путём, приложение попытается открыть его напрямую.

## Использование окна результата

Перевод, объяснение, краткое изложение, уточнение и пользовательские действия ИИ открывают отдельное окно результата.

В окне можно:

* показать или скрыть исходный текст;
* скопировать оригинал или результат модели;
* приостановить генерацию;
* повторно сгенерировать результат;
* свернуть или закрыть окно;
* закрепить поверх других окон;
* временно изменить прозрачность.

В окне перевода также можно напрямую изменить целевой язык и настроить предпочтительный и альтернативный языки.

## Настройка поведения окна

В разделе **Окно действий** можно изменить:

| Настройка | Назначение |
| --- | --- |
| Следовать за панелью | Открывает окно результата рядом с панелью; если выключено, окно появляется по центру |
| Запомнить размер | Во время текущего запуска приложения используется последний настроенный размер окна |
| Автозакрытие | Незакреплённое окно результата закрывается при потере фокуса |
| Автозакрепление | При каждом открытии окно результата по умолчанию закрепляется поверх остальных |
| Прозрачность | Задаёт непрозрачность окна результата по умолчанию в диапазоне 20%–100% |

Прозрачность, изменённая вручную в окне результата, применяется только к этому окну; значение на странице настроек используется для последующих окон.

## Настройка фильтрации приложений

Фильтрация позволяет включить помощник выбора только в указанных приложениях либо исключить указанные приложения.

1. Откройте **Настройки → Помощник выбора → Расширенные**.
2. Выберите белый или чёрный список.
3. Нажмите редактирование и введите по одному идентификатору приложения на строку.

| Платформа | Что вводить | Пример |
| --- | --- | --- |
| macOS | Bundle ID, допускается частичное совпадение | `com.google.Chrome` |
| Windows | Имя исполняемого файла, допускается частичное совпадение | `chrome.exe` |

Введённые значения преобразуются в нижний регистр, а повторы удаляются. В режиме Wayland фильтрация приложений может не работать.

## Частые вопросы

### После выделения текста панель не появляется

Убедитесь, что функция включена и выбран правильный способ получения текста, а текущее приложение не исключено правилами фильтрации. В macOS также проверьте права универсального доступа.

### В Windows способ по Ctrl не работает

Некоторые приложения и средства переназначения клавиш перехватывают Ctrl. Используйте вызов при выделении или сочетание клавиш и проверьте, не переназначают ли клавишу такие инструменты, как AHK.

### В Linux панель расположена неправильно

Обычно это связано с различием координат в Wayland и XWayland. Проверьте среду на странице настроек; если выполнить условия невозможно, переключитесь на X11.

### Действие ИИ не выдаёт результат

Проверьте доступность модели по умолчанию или выбранного ассистента. Для перевода также требуется отдельно настроенная модель перевода.

### После цитирования текст не появился

Действие «Цитировать» отправляет выделенный текст в поле ввода главного окна Cherry Studio. Убедитесь, что главное окно открыто, и перейдите на страницу диалога.

## Конфиденциальность

Действие копирования записывает данные только в системный буфер обмена; поиск отправляет запрос выбранной поисковой системе; цитирование передаёт текст в главное окно Cherry Studio.

Выделенный текст отправляется соответствующему сервису модели только при выполнении перевода, объяснения, краткого изложения, уточнения или пользовательского действия ИИ. Перед обработкой конфиденциального текста проверьте тип действия и политику обработки данных провайдера.
