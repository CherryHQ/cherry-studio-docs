# Встроенные приложения

Встроенные приложения позволяют открывать часто используемые сайты прямо в Cherry Studio. В готовом каталоге собраны различные сервисы для ИИ, поиска и разработки. Кроме того, можно добавить собственный веб-адрес как пользовательское приложение и переключаться между несколькими сайтами с помощью верхних вкладок.

{% hint style="info" %}
Встроенное приложение загружает сторонний сайт, а не модельный API Cherry Studio. Учётная запись, функции, региональные ограничения и способ оплаты определяются поставщиком соответствующего сервиса.
{% endhint %}

## Как открыть встроенные приложения

Нажмите `+` справа на верхней панели вкладок, чтобы открыть **Запуск**, а затем выберите **Приложения**.

На главной странице доступны:

- **Поиск**: фильтрация приложений по имени или URL;
- **Сетка приложений**: открытие отображаемых встроенных и пользовательских приложений;
- **Кнопка добавления**: создание пользовательского приложения;
- **Настройки отображения**: управление видимостью, порядком, регионом и кэшем.

После нажатия приложения сайт откроется в новой верхней вкладке. При переходе на другую вкладку страницы приложений, входящие в лимит кэша, останутся загруженными.

## Работа с веб-страницей приложения

После открытия сайта на верхней панели доступны основные действия браузера:

| Действие | Назначение |
| --- | --- |
| Назад / вперёд | Переход по истории текущего приложения |
| Обновить | Повторная загрузка текущего сайта |
| Открыть в браузере | Открытие текущего URL в системном браузере по умолчанию |
| Закрепить | Добавление приложения на стартовый экран / боковую панель или удаление оттуда |
| Способ открытия ссылок в новом окне | Выбор, будут ли новые окна сайта открываться внутри Cherry Studio или в системном браузере |

На веб-странице приложения также доступны следующие сочетания клавиш:

| Сочетание клавиш | Назначение |
| --- | --- |
| `Ctrl / Command + F` | Поиск на текущей странице; `Enter` / `Shift + Enter` переключают совпадения |
| `Ctrl / Command + P` | Печать текущей страницы в PDF |
| `Ctrl / Command + S` | Сохранение текущей страницы в формате HTML |

Некоторые сайты могут переназначать отдельные клавиши. Ориентируйтесь на фактический результат, отображаемый в Cherry Studio.

## Добавление пользовательского приложения

Нажмите кнопку добавления в правом верхнем углу главной страницы и заполните следующие поля:

| Поле | Требование |
| --- | --- |
| ID | Обязательный и уникальный; разрешены только латинские буквы, цифры, знаки подчёркивания и дефисы |
| Название | Имя, которое отображается в сетке приложений и на вкладке |
| URL | Полный веб-адрес для открытия, обычно с `https://` |
| Значок | Необязательное поле; можно указать URL изображения или загрузить изображение с компьютера |

После сохранения пользовательское приложение добавляется в список отображаемых и появляется в сетке.

{% hint style="warning" %}
Добавляйте только URL, которым доверяете. Пользовательское приложение загружает сайт внутри Cherry Studio, но сайт по-прежнему получает отправленные вами данные для входа, файлы и содержимое форм.
{% endhint %}

В текущей версии нельзя напрямую изменить ID, название, URL или значок уже сохранённого приложения. Чтобы изменить данные, сначала удалите исходное пользовательское приложение, а затем создайте его заново.

## Закрепление, скрытие и удаление

Нажмите правой кнопкой значок в сетке приложений, чтобы выполнить доступное для текущего состояния действие:

- **Добавить на стартовый экран / боковую панель** или открепить;
- **Скрыть** встроенное или пользовательское приложение;
- **Удалить пользовательское приложение**.

Встроенное приложение нельзя удалить, но можно скрыть. Полностью удаляются только созданные пользователем приложения. Закреплённый пункт появляется на стартовом экране или боковой панели в зависимости от текущего расположения панели навигации.

Если скрываемое приложение находится в списке кэша, соответствующая страница также удаляется из текущего списка загруженных страниц.

## Управление отображением и порядком

Откройте настройки отображения в правом верхнем углу главной страницы. В верхней части панели находятся два списка: **Отображаемые мини-приложения** и **Скрытые мини-приложения**.

- нажмите элемент, чтобы переместить его между отображаемыми и скрытыми;
- перетащите элемент внутри одного списка, чтобы изменить порядок;
- нажмите **Поменять местами**, чтобы поменять отображаемые и скрытые элементы;
- нажмите **Сбросить**, чтобы снова показать все скрытые элементы.

Закреплённое приложение всегда остаётся видимым и не скрывается вместе с обычными отображаемыми элементами.

## Фильтрация по региону

В настройках региона доступны варианты **Автоопределение**, **Китай** и **Весь мир**. Сетка фильтруется по доступным регионам из встроенного каталога, чтобы реже показывать сервисы, которые обычно недоступны в текущем регионе.

Фильтр региона влияет только на текущий набор отображаемых приложений. Он не регистрирует учётную запись, не обходит ограничения сервиса и не гарантирует доступ к сайту. По умолчанию пользовательские приложения отображаются в представлениях для Китая и всего мира.

## Управление открытием ссылок

Если включить **Открывать новые окна в браузере**, новые окна, которые пытается открыть сайт, будут передаваться системному браузеру по умолчанию. Если настройка отключена, новое окно обрабатывается средой встроенных приложений Cherry Studio.

Этот переключатель можно изменить для всех приложений в настройках отображения или быстро переключить на верхней панели уже открытого приложения. Независимо от настройки кнопка **Открыть в браузере** на панели всегда открывает текущий URL напрямую.

## Количество кэшируемых приложений

Количество кэшируемых приложений определяет, сколько веб-страниц могут одновременно оставаться загруженными. Значение можно выбрать от `1` до `10`, по умолчанию используется `3`.

- Большое значение: при возвращении на страницу состояние после входа, скорее всего, сохранится, но расход памяти увеличится;
- Малое значение: расход памяти уменьшится, однако ранее открытая незакреплённая страница может быть выгружена и при следующем открытии загрузится заново.

После уменьшения значения оно будет применяться постепенно по мере последующих изменений в списке открытых страниц, пока не будет достигнут новый лимит. Закреплённые верхние вкладки не удаляются автоматически из-за ограничения кэша.

## Состояние входа и данные

Встроенные приложения используют постоянный веб-сеанс, отдельный от системного браузера. Поэтому:

- при первом использовании сайта обычно нужно отдельно войти в него внутри приложения;
- после закрытия и повторного запуска Cherry Studio файлы Cookie и состояние входа обычно сохраняются;
- состояние входа из системного браузера не синхронизируется с приложениями автоматически;
- несколько приложений используют один раздел веб-сеанса Cherry Studio.

Сайт всё равно может запросить повторный вход из-за политики безопасности учётной записи, истечения срока действия Cookie, смены региона или собственного обновления.

## Частые вопросы

### Сайт постоянно загружается или остаётся пустым

Сначала нажмите кнопку обновления. Если это не помогло, откройте страницу в системном браузере с помощью верхней панели и проверьте, доступны ли сам URL и сервис учётной записи. Также проверьте сеть, прокси и региональные ограничения. Некоторые сайты намеренно ограничивают работу во встроенной браузерной среде — в этом случае используйте системный браузер.

Сведения о настройке прокси приведены в разделе [Основные настройки](settings/general.md).

### После входа снова открывается страница авторизации

Обновите страницу и убедитесь, что системное время установлено правильно, сайт разрешает Cookie, а сеть или прокси не прерывают процесс входа. Если сервис не поддерживает авторизацию во встроенной браузерной среде, используйте системный браузер.

### Приложение исчезло

Проверьте поисковый запрос, фильтр региона и список скрытых приложений в настройках отображения. Если приложение закреплено, также проверьте соответствующий пункт на стартовом экране или боковой панели.

### Не удаётся сохранить пользовательское приложение

Проверьте, что ID содержит только латинские буквы, цифры, знаки подчёркивания или дефисы и не совпадает с ID встроенного или существующего приложения. Также должны быть заполнены название и URL.

### При возвращении страница загружается заново

Возможно, число открытых приложений превысило лимит кэша и ранее открытая незакреплённая страница была выгружена. Увеличьте количество кэшируемых приложений или закрепите верхнюю вкладку, состояние которой нужно сохранять.

## Конфиденциальность и безопасность

Учётная запись, сообщения, файлы и другие данные, вводимые во встроенном приложении, отправляются соответствующему сайту, а не выбранной в текущем диалоге модели. Диалоги Cherry Studio также не считывают содержимое веб-страниц приложений автоматически. Если нужно сослаться на содержимое страницы, проверьте права доступа и конфиденциальность, а затем вручную скопируйте только необходимую часть.
