# Разделы управления ресурсами

В Cherry Studio V2 больше нет отдельной страницы «Библиотека ресурсов». Помощниками, Agent, навыками и промптами по-прежнему можно управлять, но точки входа перенесены в соответствующие рабочие разделы.

{% hint style="warning" %}
Старый маршрут `/app/library` больше не обслуживается, а на стартовом экране нет плитки библиотеки. После обновления закреплённые вкладки старого маршрута удаляются автоматически. Не ищите страницу, показанную на старых снимках экрана.
{% endhint %}

## Текущие точки входа

| Ресурс | Где управлять | Основные действия |
| :--- | :--- | :--- |
| Помощник | Откройте **Диалог**, затем перейдите к управлению помощниками через меню ресурсов слева | Создание, импорт, изменение, копирование, экспорт, группировка и удаление помощников |
| Agent | Откройте **Работа**, затем перейдите к управлению Agent через меню ресурсов слева | Создание, изменение, настройка рабочего каталога и инструментов, удаление Agent |
| Навык | Откройте **Настройки → Навыки** | Поиск, установка, просмотр и удаление глобальных навыков |
| Промпт | Откройте **Быстрые фразы** в поле ввода диалога, затем выберите **Управление** или **Добавить** | Создание, изменение, поиск, вставка и удаление повторно используемых промптов |

Эти точки входа доступны прямо в текущем рабочем контексте. Например, после изменения помощника можно вернуться к диалогу, не переходя через отдельную страницу ресурсов.

## Библиотека помощников и управление ресурсами

[Библиотека помощников](agents.md) по-прежнему предназначена для просмотра и импорта помощников сообщества. Импортированный помощник появляется в вашем списке и редактируется через управление помощниками на странице **Диалог**.

Библиотека помощников не является новым маршрутом старой библиотеки ресурсов:

- библиотека помощников предоставляет материалы сообщества;
- управление помощниками предназначено для уже добавленных помощников;
- для Agent, навыков и промптов используются отдельные точки входа из таблицы выше.

## Старый маршрут не открывается

Если закладка, история или старое руководство содержит `/app/library`:

1. Не обновляйте этот адрес повторно.
2. Откройте новую точку входа для нужного типа ресурса.
3. При восстановлении вкладок приложение удаляет старую закреплённую вкладку, но не удаляет данные помощников, Agent, навыков и промптов.

Глобальный поиск также исключает записи старого маршрута библиотеки, чтобы удалённая страница не открывалась снова.
