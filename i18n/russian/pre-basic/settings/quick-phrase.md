# Промпты и быстрая вставка

Промпты позволяют сохранять часто используемый текст: требования к стилю, схемы анализа или формат ответа. Сохраненный промпт можно быстро найти и вставить из поля ввода сообщения, не набирая его заново.

В Cherry Studio V2 такие материалы объединены под названием «Промпты», которое заменяет «Быстрые фразы» из предыдущих версий.

## Создание промпта

### Создание из библиотеки ресурсов

1. Откройте [библиотеку ресурсов](../../cherrystudio/preview/library.md).
2. Выберите **Промпты** слева.
3. Нажмите кнопку создания и укажите имя и содержимое.
4. Нажмите кнопку сохранения.

Имя используется для поиска и идентификации, а содержимое — это текст, который будет вставлен в поле сообщения. После сохранения промпт появится в библиотеке ресурсов и в списке промптов поля ввода.

### Создание из поля ввода

1. Нажмите значок молнии под полем ввода сообщения, чтобы открыть список промптов.
2. Выберите «Добавить промпт…» в нижней части списка.
3. Укажите имя и содержимое, затем сохраните промпт.

Для редактирования или удаления существующего промпта перейдите в библиотеку ресурсов.

## Вставка промпта в поле ввода

Открыть список промптов можно любым из следующих способов:

* Нажмите значок молнии под полем ввода сообщения.
* Введите `/` в поле сообщения, чтобы открыть быстрое меню, затем выберите «Управление промптами».

Найдите и выберите промпт. Cherry Studio вставит его содержимое в текущую позицию курсора. Если перед вставкой с помощью значка молнии был выделен текст, он будет заменен. При открытии быстрого меню с помощью `/` заменяется текст, введенный для вызова меню и поиска.

После вставки промпт можно отредактировать перед отправкой модели.

## Переменные

В редакторе промпта можно вставить `${variable}` в качестве заполнителя. Текущая версия сохраняет и вставляет этот текст без изменений, но не подставляет значение автоматически.

Нажатие Tab в поле сообщения выделяет следующий заполнитель `${...}`. После последнего заполнителя выбор возвращается к первому. Замените выделенный заполнитель нужным текстом вручную.

{% hint style="warning" %}
Перед отправкой сообщения вручную замените `${variable}` фактическим содержимым. Не сохраняйте в промптах пароли, API-ключи и другие конфиденциальные данные.
{% endhint %}

## Рекомендации

* Используйте названия, описывающие задачу, например «Проверить документацию продукта» или «Подготовить краткий отчет о встрече».
* Сохраняйте в промпте постоянные требования, а изменяющиеся данные добавляйте после вставки.
* Регулярно удаляйте устаревшие и повторяющиеся промпты, чтобы результаты поиска оставались понятными.
