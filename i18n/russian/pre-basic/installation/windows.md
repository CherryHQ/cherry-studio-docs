# Windows

На этой странице описано, как выбрать установочный пакет для Windows, установить Cherry Studio и устранить распространённые проблемы с предупреждениями безопасности или средой выполнения при первом запуске. Если у вас ещё нет установочного пакета, сначала откройте страницу [Загрузка клиента](../../cherrystudio/download.md).

{% hint style="warning" %}
Cherry Studio не поддерживает Windows 7. Загружайте установочные пакеты только с официального сайта Cherry Studio или из официального GitHub Releases репозитория `CherryHQ/cherry-studio`.
{% endhint %}

## Выбор установочного пакета

В Windows Release доступны архитектуры x64 и ARM64, а также два типа пакетов: Setup и Portable.

| Установочный пакет | Подходящий сценарий |
| --- | --- |
| `x64-setup.exe` | Обычные компьютеры Windows с процессором Intel или AMD; подходит большинству пользователей |
| `arm64-setup.exe` | Компьютеры Windows с процессором ARM, например некоторые устройства Snapdragon |
| `x64-portable.exe` | Компьютеры x64; установка не требуется, а программу и данные можно хранить в выбранном каталоге |
| `arm64-portable.exe` | Компьютеры ARM64; установка не требуется, а программу и данные можно хранить в выбранном каталоге |

Если архитектура неизвестна, откройте **Параметры → Система → О системе** и проверьте «Тип системы»:

* Если указано «процессор x64», выберите x64.
* Если указано «процессор ARM», выберите ARM64.

Устанавливаемая версия Setup подходит для повседневного использования. Портативная версия Portable удобнее для временного тестирования, запуска с USB-накопителя или использования отдельного каталога данных.

## Проверка загруженного файла

В официальном GitHub Release для установочных пакетов публикуется SHA256. После загрузки можно выполнить в PowerShell:

```powershell
Get-FileHash ".\Cherry-Studio-*-setup.exe" -Algorithm SHA256
```

Для портативной версии замените имя файла на соответствующее `*-portable.exe`. Полученное значение должно полностью совпадать с SHA256 на странице Release.

Если браузер или Windows сообщает о неизвестном источнике файла, сначала проверьте домен загрузки, имя файла и SHA256. Не запускайте файл, источник которого невозможно подтвердить.

## Установка версии Setup

1. Полностью закройте запущенное приложение Cherry Studio.
2. Дважды щёлкните `*-setup.exe`.
3. Выберите каталог с помощью мастера установки.
4. Проверьте параметры и завершите установку.
5. Запустите Cherry Studio с ярлыка на рабочем столе или из меню «Пуск».

Для обновления существующей установки используйте новый пакет Setup для той же архитектуры системы. Перед обновлением рекомендуется создать резервную копию в разделе **Настройки → Настройки данных**.

## Использование версии Portable

1. Создайте новый каталог с разрешением на запись, например `D:\Apps\CherryStudio`.
2. Поместите `*-portable.exe` в этот каталог.
3. Дважды щёлкните исполняемый файл, чтобы запустить программу.
4. Не перемещайте исполняемый файл или каталог данных во время работы программы.

Если другое расположение данных не задано, портативная версия хранит данные приложения в каталоге `data` рядом с исполняемым файлом. При резервном копировании или переносе портативной версии сохраняйте и исполняемый файл, и этот каталог.

{% hint style="info" %}
Не помещайте портативную версию в каталог, для записи в который требуются права администратора. Если вы планируете пользоваться программой постоянно, хотите автоматически создавать ярлыки и обновляться через мастер установки, выберите устанавливаемую версию Setup.
{% endhint %}

## Первый запуск

После первого запуска рекомендуется проверить:

1. Откройте **Настройки → Сервисы моделей**, добавьте поставщика и включите хотя бы одну модель.
2. Вернитесь на страницу диалога и отправьте тестовое сообщение.
3. Откройте **Настройки → Настройки данных** и проверьте способ резервного копирования и расположение данных.

Если Windows Defender SmartScreen показывает предупреждение защиты, сначала убедитесь, что файл получен из официального источника и прошёл проверку SHA256, а затем откройте подробные сведения по подсказке системы. Не отключайте системные средства безопасности ради установочного пакета из неизвестного источника.

## Среда выполнения Visual C++

Некоторые нативные компоненты Cherry Studio зависят от Microsoft Visual C++ Redistributable. Если при установке или запуске система сообщает об отсутствии среды выполнения:

1. Сначала разрешите установщику Cherry Studio установить зависимости.
2. Если автоматическая установка не удалась, откройте [официальную страницу Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).
3. Загрузите версию x64 или ARM64 в соответствии с архитектурой системы, установите её и перезапустите Cherry Studio.

Не загружайте среду выполнения со сторонних сайтов программного обеспечения.

## Обновление и смена версии

Перед обновлением:

1. Создайте резервную копию в разделе **Настройки → Настройки данных**.
2. Полностью закройте Cherry Studio.
3. Загрузите новый установочный пакет для архитектуры текущего компьютера.

Пользователи Setup могут просто запустить установочный пакет новой версии. Пользователям Portable следует сохранить существующий каталог `data` и заменить старый исполняемый файл новым.

При откате с новой версии на старую могут возникнуть проблемы совместимости базы данных или конфигурации. Не выполняйте откат без резервной копии и полного понимания последствий. Предварительная или ежедневная сборка также не должна быть единственной рабочей средой для важных данных.

## Частые вопросы

### Программа не запускается после двойного щелчка

Проверьте по порядку:

1. Соответствует ли архитектура установочного пакета системе.
2. Полностью ли загружен файл и совпадает ли SHA256.
3. Правильно ли установлен Microsoft Visual C++ Redistributable.
4. Не поместило ли защитное ПО файл программы в карантин.
5. Не запущен ли уже процесс Cherry Studio.

Если программа по-прежнему не запускается, запишите версию Windows, архитектуру системы, версию Cherry Studio и сообщение об ошибке, а затем отправьте их через раздел [Отзывы и предложения](../../question-contact/suggestions.md).

### Portable выглядит как новая установка после запуска

Проверьте, остался ли рядом с исполняемым файлом каталог `data`, разрешена ли запись в текущий каталог и не перемещался ли исполняемый файл. Перед восстановлением скопируйте текущий каталог, чтобы не перезаписать данные, которые ещё можно использовать.
