# Инструкция по установке

На этой странице описан общий процесс установки Cherry Studio и приведены ссылки на подробные инструкции для каждой операционной системы. Если у вас ещё нет установочного пакета, сначала откройте страницу [Загрузка клиента](../../cherrystudio/download.md).

## Перед установкой

1. Убедитесь, что установочный пакет получен с официального сайта Cherry Studio или из официального GitHub Releases репозитория `CherryHQ/cherry-studio`.
2. Проверьте операционную систему и архитектуру CPU, чтобы не перепутать пакеты x64, ARM64, amd64 и aarch64.
3. Закройте запущенное приложение Cherry Studio.
4. Перед обновлением, откатом версии или проверкой предварительной сборки создайте резервную копию в разделе **Настройки → Настройки данных**.

{% hint style="warning" %}
Не выполняйте откат с новой версии на старую без резервной копии. Новая версия могла изменить локальную базу данных или конфигурацию, и старая версия не всегда сможет прочитать данные после миграции.
{% endhint %}

## Windows

Для Windows доступны устанавливаемая и портативная версии:

* **Устанавливаемая версия Setup**: выберите каталог в мастере и завершите установку. Подходит большинству пользователей.
* **Портативная версия Portable**: запустите исполняемый файл напрямую. Подходит для временного использования или если вы не хотите выполнять установку.

Cherry Studio не поддерживает Windows 7. Если при первом запуске появилось предупреждение защиты системы, сначала проверьте источник пакета и контрольную сумму файла, а затем следуйте [Инструкции по установке в Windows](windows.md).

## macOS

1. Загрузите `.dmg`, соответствующий процессору: для чипа Apple выберите `arm64`, для процессора Intel — `x64`.
2. Откройте DMG и перетащите Cherry Studio в папку «Программы».
3. Запустите приложение из папки «Программы».

При первом запуске macOS может показать предупреждение о проверке разработчика или безопасности. Способы решения описаны в [Инструкции по установке в macOS](macos.md).

## Linux

Linux Release обычно включает три формата: AppImage, deb и rpm. Выберите один из них и не устанавливайте несколько форматов одновременно.

### AppImage

```bash
chmod +x ./Cherry-Studio-*.AppImage
./Cherry-Studio-*.AppImage
```

AppImage не требует установки на уровне системы. Если файл не запускается, сначала проверьте соответствие его архитектуры. В некоторых дистрибутивах также требуется FUSE-совместимый компонент для AppImage.

### Debian / Ubuntu

```bash
sudo apt install ./Cherry-Studio-*-amd64.deb
```

На устройствах ARM64 используйте deb-пакет, имя которого содержит `arm64`.

### Fedora / RHEL / Rocky Linux

```bash
sudo dnf install ./Cherry-Studio-*.rpm
```

Выберите пакет `x86_64` или `aarch64` в соответствии с устройством.

## Обновление

При установке более новой стабильной версии для той же системы и архитектуры локальные данные обычно сохраняются. Чтобы снизить риск:

1. Сначала создайте локальную или удалённую резервную копию.
2. Полностью закройте Cherry Studio.
3. Выполните обновление с помощью нового пакета для текущей системы и архитектуры.
4. После запуска проверьте работу сервисов моделей, диалогов, базы знаний и агента.

Предварительные версии и ежедневные сборки могут включать ещё не стабилизированные изменения данных. Не храните единственную копию важных данных только в среде предварительной версии.

## После установки

После первого запуска рекомендуется:

1. Добавить поставщика и модели в разделе **Настройки → Сервисы моделей**.
2. Вернуться на страницу диалога и отправить тестовое сообщение.
3. Проверить расположение данных и резервных копий.
4. Затем при необходимости включить базу знаний, агента, MCP и другие расширенные возможности.
