# macOS

На этой странице описано, как выбрать установочный пакет для Mac с процессором Intel или чипом Apple, установить Cherry Studio и устранить предупреждения безопасности macOS при первом запуске. Если у вас ещё нет установочного пакета, сначала откройте страницу [Загрузка клиента](../../cherrystudio/download.md).

## Проверка типа чипа

1. Нажмите меню Apple  в левом верхнем углу экрана.
2. Выберите **Об этом Mac**.
3. Проверьте поле «Чип» или «Процессор».

| Что указано на Mac | Архитектура для загрузки |
| --- | --- |
| Чип Apple серии M | `arm64` |
| Процессор Intel | `x64` |

Для Mac с чипом Apple предпочтительнее нативный пакет arm64. Если по ошибке загрузить пакет x64, система может предложить установить Rosetta. Обычно лучше повторно загрузить пакет arm64.

## Выбор DMG или ZIP

В macOS Release обычно одновременно доступны `.dmg` и `.zip`:

| Формат | Использование | Рекомендация |
| --- | --- | --- |
| DMG | Откройте образ диска и перетащите приложение в папку «Программы» | Подходит большинству пользователей |
| ZIP | Распакуйте архив и переместите приложение в папку «Программы» | Используйте, если DMG не удаётся подключить или приложение нужно распространять вручную |

Оба формата содержат одно и то же приложение, поэтому устанавливать их одновременно не требуется.

## Проверка загруженного файла

В официальном GitHub Release для установочного пакета публикуется SHA256. Откройте «Терминал» и выполните:

```bash
shasum -a 256 ~/Downloads/Cherry-Studio-*.dmg
```

При использовании ZIP замените расширение на `*.zip`. Полученное значение должно полностью совпадать с SHA256 на странице Release.

Если браузер или macOS сообщает о неизвестном источнике файла, сначала проверьте домен загрузки, имя файла и SHA256. Не открывайте файл, источник которого невозможно подтвердить.

## Установка из DMG

1. Дважды щёлкните загруженный файл `.dmg`.
2. В открывшемся окне перетащите Cherry Studio в папку «Программы».
3. Дождитесь завершения копирования.
4. Извлеките образ диска Cherry Studio через боковую панель Finder.
5. Откройте **Finder → Программы → Cherry Studio**.

Не запускайте приложение постоянно непосредственно из окна DMG. Сначала скопируйте его в папку «Программы» — так последующие обновления и управление разрешениями будут работать стабильнее.

## Установка из ZIP

1. Дважды щёлкните файл `.zip`, чтобы распаковать его.
2. Переместите распакованное приложение Cherry Studio в папку «Программы».
3. Запустите приложение из папки «Программы».

Если в папке «Программы» уже есть старая версия, перед обновлением полностью закройте Cherry Studio и создайте резервную копию в разделе **Настройки → Настройки данных**.

## Устранение предупреждения безопасности при первом запуске

При первом запуске приложения, загруженного из интернета, macOS выполняет проверку Gatekeeper.

Если система только спрашивает, действительно ли вы хотите открыть приложение, проверьте его название и источник загрузки, а затем выберите «Открыть». Если указано, что разработчика невозможно проверить или приложение не удалось проверить на наличие вредоносного ПО:

1. Убедитесь, что файл получен с официального сайта Cherry Studio или из официального GitHub Releases.
2. Проверьте SHA256.
3. Один раз попробуйте открыть приложение, чтобы macOS зарегистрировала блокировку.
4. Откройте **Системные настройки → Конфиденциальность и безопасность**.
5. Найдите соответствующее сообщение в разделе «Безопасность» и выберите **Всё равно открыть**.
6. Подтвердите личность по запросу системы, а затем ещё раз подтвердите открытие.

{% hint style="warning" %}
Не отключайте Gatekeeper и не используйте «Всё равно открыть» для файла из неизвестного источника или с несовпадающим SHA256. Если система прямо сообщает, что приложение повредит компьютер или содержит вредоносное ПО, удалите файл и загрузите его повторно из официального источника.
{% endhint %}

Актуальные инструкции Apple см. в разделе [Безопасное открытие приложений на Mac](https://support.apple.com/102445).

## Предоставление системных разрешений

Cherry Studio запрашивает разрешения только тогда, когда они необходимы соответствующей функции, например:

* разрешение на доступ к микрофону при использовании голосовых или аудиофункций;
* разрешение на доступ к камере при использовании связанных с ней функций;
* разрешение на доступ к папкам «Документы» или «Загрузки» при чтении или сохранении файлов.

Предоставляйте только разрешения, необходимые используемым функциям. Чтобы изменить их, откройте **Системные настройки → Конфиденциальность и безопасность** и настройте Cherry Studio в соответствующей категории.

## Обновление Cherry Studio

Перед обновлением:

1. Создайте резервную копию в разделе **Настройки → Настройки данных**.
2. Полностью закройте Cherry Studio.
3. Загрузите новую версию для чипа вашего Mac.

Откройте новый DMG или распакуйте ZIP, переместите новую версию Cherry Studio в папку «Программы» и подтвердите замену старой версии по запросу системы. После первого запуска новой версии проверьте работу сервисов моделей, диалогов, базы знаний и агента.

При откате с новой версии на старую могут возникнуть проблемы совместимости базы данных или конфигурации. Не выполняйте откат без резервной копии и полного понимания последствий.

## Частые вопросы

### Приложение не открывается

Проверьте по порядку:

1. Соответствует ли архитектура установочного пакета чипу Mac.
2. Полностью ли загружен файл и совпадает ли SHA256.
3. Перемещено ли приложение в папку «Программы».
4. Есть ли соответствующее сообщение о блокировке в разделе **Системные настройки → Конфиденциальность и безопасность**.
5. Не запущен ли уже процесс Cherry Studio.

### Сообщение о повреждении приложения

Удалите текущий файл, повторно загрузите его из официального источника и проверьте SHA256. Не копируйте без проверки команды из интернета для удаления атрибутов безопасности: если файл действительно повреждён или изменён, это приведёт к обходу системной защиты.

### Приложение закрывается сразу после запуска

Запишите версию macOS, тип чипа, версию Cherry Studio и полный текст ошибки, а затем отправьте их через раздел [Отзывы и предложения](../../question-contact/suggestions.md). Если используется предварительная версия, укажите также дату сборки или источник загрузки.
