# Anthropic

Встроенный шаблон Anthropic в Cherry Studio V2 предназначен для подключения к официальному API Anthropic и по умолчанию использует конечную точку **Anthropic Messages**. После настройки API Key можно синхронизировать модели Claude и использовать их для чата, рассуждений и вызова инструментов.

{% hint style="info" %}
Наличие конечной точки Anthropic у провайдера не означает, что каждая его модель поддерживает вызов инструментов или Agent. Проверьте метки возможностей модели и перед использованием выполните один практический тест инструмента.
{% endhint %}

## Перед началом

- Учётная запись с доступом к Anthropic API
- API Key, созданный на странице [Anthropic API Keys](https://console.anthropic.com/settings/keys)
- Модели и квота, доступные учётной записи
- Сетевая среда, соответствующая текущим требованиям Anthropic к учётным записям и регионам

Anthropic API Key и вход на сайте настраиваются отдельно. Cherry Studio требуется Key, пригодный для запросов API.

## Настройка Anthropic

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **Anthropic**.
3. Введите API Key.
4. Оставьте Base URL по умолчанию: `https://api.anthropic.com`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите модели Claude, которые планируете использовать.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно отзовите его в Anthropic Console и создайте новый.
{% endhint %}

## Синхронизация и выбор моделей

Названия и версии моделей Anthropic меняются, поэтому эта страница не фиксирует конкретный список. Нажмите **Добавить**, чтобы синхронизировать модели, доступные учётной записи в данный момент, и проверьте полный ID модели.

- Включайте только действительно необходимые модели.
- У разных версий одной серии могут различаться контекст, рассуждения и возможности инструментов.
- Если API не возвращает модели, нажмите **Пользовательский** и введите ID модели из официальной документации Anthropic.
- Не добавляйте ID модели стороннего шлюза напрямую в официальный шаблон Anthropic.

Наличие модели в реестре Cherry Studio не означает, что ваша учётная запись Anthropic уже получила к ней доступ.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую модель.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.

Если вы планируете использовать MCP или Agent, включите один простой инструмент и проверьте, действительно ли модель начинает вызов.

## Agent и вызов инструментов

Шаблон Anthropic отображается в фильтре **Agent** списка провайдеров моделей, потому что у него есть совместимая конечная точка Anthropic. Для использования также должны одновременно выполняться следующие условия:

- Целевая модель поддерживает вызов инструментов.
- Текущая конечная точка API предоставляет вызов инструментов.
- MCP или другие инструменты правильно включены.
- Инструменты не отключены в ассистенте.
- Запрос не заблокирован правами или политикой безопасности провайдера.

Если модель выводит только план вызова инструмента, но не выполняет его, сначала проведите диагностику с одним простым инструментом, а затем проверьте возможности модели и конечную точку.

## Prompt Cache

Prompt Cache для конечной точки Anthropic можно настроить в разделе Cherry Studio **Настройки API**:

- **Порог кэширования токенов**: кэш включается только после превышения этого количества токенов; значение `0` отключает его.
- **Кэшировать системное сообщение**: определяет, следует ли кэшировать системную подсказку.
- **Кэшировать последние N сообщений**: задаёт число последних сообщений диалога, которые требуется кэшировать.

{% hint style="warning" %}
Работа кэша, правила оплаты и список поддерживаемых моделей определяются провайдером. Если правила провайдера неизвестны, оставьте значения по умолчанию. Неверная настройка не обязательно уменьшит стоимость.
{% endhint %}

## Подключение совместимого шлюза Anthropic

Если используется не официальный API Anthropic:

1. Нажмите Anthropic правой кнопкой мыши в списке провайдеров слева.
2. Выберите копирование или создание аналогичного провайдера.
3. Укажите для копии Base URL и API Key, предоставленные шлюзом.
4. Оставьте Anthropic Messages основной конечной точкой.
5. Синхронизируйте или вручную добавьте модели, фактически предоставляемые шлюзом.

Отдельная копия позволяет не перезаписывать официальный шаблон Anthropic и раздельно диагностировать конечную точку и права.

## Частые вопросы

### Возвращается 401

API Key недействителен, отозван или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается 403

Учётная запись, регион, рабочее пространство или права на модель могут не соответствовать требованиям. Проверьте состояние учётной записи в Anthropic Console.

### Возвращается 404 или сообщение «Модель не существует»

Снова нажмите **Добавить**, синхронизируйте список и проверьте полный ID модели. При использовании стороннего шлюза убедитесь, что Base URL и путь Anthropic Messages соответствуют документации шлюза.

### Модель не отображается в фильтре Agent

Фильтр Agent определяет наличие конечной точки Anthropic у провайдера. Для пользовательского шлюза необходимо правильно настроить конечную точку Anthropic Messages, а сама модель должна поддерживать вызов инструментов.

### Prompt Cache не работает

Убедитесь, что порог кэширования больше `0`, а провайдер и модель поддерживают кэш. Короткий диалог может не достигать заданного порога.
