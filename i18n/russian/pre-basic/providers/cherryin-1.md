# CherryIN

CherryIN — встроенный в Cherry Studio шаблон провайдера моделей, который позволяет подключать разные модели через одну учётную запись. В V2 для него предварительно настроены конечные точки OpenAI Chat Completions и Anthropic Messages, а также доступны вход в учётную запись, отображение баланса, переход к пополнению и переключение линий подключения.

{% hint style="info" %}
CherryIN отличается от [бесплатного пробного доступа CherryAI](cherryin/). CherryIN использует вашу учётную запись, учётные данные и баланс. CherryAI — пробный источник внутри приложения, который не отображается в обычном списке провайдеров моделей.
{% endhint %}

## Выбор способа входа

Откройте `Настройки → Провайдеры моделей → CherryIN`. Доступен любой из следующих способов.

### Способ 1: вход в учётную запись CherryIN

1. Нажмите **Войти в CherryIN**.
2. Выполните вход и авторизацию в браузере.
3. Вернитесь в Cherry Studio.
4. Убедитесь, что на странице отображаются данные учётной записи и баланс.
5. Проверьте, включён ли переключатель CherryIN в верхней части страницы.

После успешной авторизации Cherry Studio получает доступный для учётной записи API Key и добавляет Key, полученный через OAuth, в настройки CherryIN. Для пополнения баланса откройте консоль CherryIN кнопкой **Пополнить** на карточке учётной записи.

### Способ 2: ввод API Key вручную

1. Откройте [управление Key CherryIN](https://open.cherryin.ai/console/token).
2. Создайте или скопируйте действующий Key.
3. Вернитесь на страницу CherryIN в Cherry Studio.
4. Добавьте Key в область API Key.
5. Включите переключатель провайдера.

{% hint style="danger" %}
Не вставляйте API Key в сообщения чата, документы или снимки экрана с описанием проблемы. При диагностике оставляйте видимыми только несколько символов в начале и конце, скрыв остальную часть.
{% endhint %}

## Выбор линии подключения

В V2 для CherryIN доступны три группы доменов:

| Параметр на странице | Домен | Рекомендация |
|---|---|---|
| Ускоренная линия | `open.cherryin.cc` | Сначала попробуйте в сетях материкового Китая |
| Международная линия | `open.cherryin.net` | Сначала попробуйте за пределами Китая или в международных сетях |
| Резервная линия | `open.cherryin.ai` | Используйте, если основная линия временно недоступна |

Если на странице есть раскрывающийся список линий, переключение линии одновременно заменяет домен во всех конечных точках провайдера и сохраняет исходный путь. Если списка нет, проверьте текущий Base URL в области адресов API.

{% hint style="warning" %}
Название линии обозначает только предварительно настроенную точку входа и не гарантирует одинаковую скорость во всех сетях. После выбора запустите проверку подключения и ориентируйтесь на фактический результат.
{% endhint %}

## Синхронизация и включение моделей

1. В области **Список моделей** нажмите **Добавить**.
2. Проверьте добавляемые, обновляемые и удаляемые элементы в предварительном просмотре синхронизации.
3. Примените изменения.
4. Найдите модель, которую планируете использовать.
5. Включите переключатель нужной модели.
6. Запустите проверку работоспособности модели.

Список моделей, цены и доступные квоты CherryIN могут меняться, поэтому эта страница не фиксирует конкретные модели. См. [Модели и цены CherryIN](https://open.cherryin.ai/pricing) и ориентируйтесь на результат синхронизации в приложении.

## API и модели

В шаблоне CherryIN предварительно настроены совместимые конечные точки OpenAI и Anthropic. Cherry Studio отправляет запрос с учётом информации о модели и типа конечной точки.

- Обычные модели для чата, как правило, используют совместимый API OpenAI.
- Модели Claude могут использовать совместимый API Anthropic.
- Некоторые модели Gemini и модели изображений используют специализированную маршрутизацию.
- Возможности и параметры одноимённых моделей могут различаться, если их предоставляют разные конечные точки.

Не определяйте поддержку Agent, зрения, рассуждений или вызова инструментов только по названию модели. Проверьте метки модели и выполните практический тест.

## Проверка конфигурации

Рекомендуется выполнить следующие действия по порядку:

1. Запустите проверку подключения в области аутентификации.
2. Запустите проверку работоспособности в списке моделей.
3. Вернитесь на экран чата и выберите нужную модель.
4. Отправьте простое текстовое сообщение.
5. Если нужны изображения или вызов инструментов, проведите отдельные минимальные тесты.

Модель отображается в средстве выбора моделей, только если включены переключатели и провайдера, и самой модели.

## Учётная запись и выход

После входа в учётную запись Cherry Studio может отображать сведения об учётной записи CherryIN и её баланс. Нажатие **Выйти** очищает сохранённое на устройстве состояние входа CherryIN через OAuth и удаляет Key, добавленный через OAuth.

Добавленный вручную Key и OAuth Key получены из разных источников. Если ручной Key всё ещё нужен, после выхода убедитесь, что он остаётся включённым.

## Частые вопросы

### После входа не происходит возврат в Cherry Studio

Оставьте Cherry Studio запущенным и повторно выполните авторизацию в браузере. Если система блокирует обратную ссылку приложения, разрешите браузеру открыть Cherry Studio.

### Вход выполнен, но список моделей пуст

Сначала нажмите **Добавить**. Если список остаётся пустым, проверьте наличие доступного Key в учётной записи, доступность текущей линии и наличие моделей для учётной записи в консоли CherryIN.

### Возвращается 401 или 403

Key может быть недействителен, отключён или не иметь прав на модель. Выполните вход ещё раз или создайте новый Key на странице управления и замените старый.

### Истекает время ожидания запроса или подключение недоступно

Переключитесь на ускоренную, международную или резервную линию и повторно запустите проверку подключения. Также проверьте системный прокси, межсетевой экран и локальную сеть.

### Сбой запроса Claude или Agent

Убедитесь, что выбранная модель поддерживает вызов инструментов, а запрос использует совместимую конечную точку Anthropic. Поддержка конечной точки Anthropic провайдером не означает, что каждая его модель поддерживает Agent.

Дополнительные сведения об общей настройке и нескольких Key см. в разделах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Если проблема сохраняется, отправьте версию Cherry Studio, операционную систему, ID модели и текст ошибки без конфиденциальных данных. Каналы обратной связи перечислены на странице [Отзывы и предложения](../../question-contact/suggestions.md).
