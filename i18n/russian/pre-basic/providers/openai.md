# OpenAI

Встроенный шаблон OpenAI в Cherry Studio V2 предназначен для подключения к официальному API OpenAI и по умолчанию использует интерфейс **OpenAI Responses**. Подготовив OpenAI API Key, можно синхронизировать доступные учётной записи модели и использовать их в чате.

{% hint style="warning" %}
Шаблон OpenAI больше не предназначен для сторонних шлюзов, совместимых с OpenAI. Если Base URL не является официальным адресом OpenAI, создайте [Пользовательского провайдера](zi-ding-yi-fu-wu-shang.md) и выберите OpenAI Chat Completions или OpenAI Responses согласно требованиям шлюза.
{% endhint %}

## Перед началом

- Учётная запись с доступом к OpenAI API
- API Key, созданный на странице [OpenAI API Keys](https://platform.openai.com/api-keys)
- Модели и квота, доступные для учётной записи API
- Сетевая среда, соответствующая текущим требованиям OpenAI к регионам и учётным записям

Вход на сайте или в клиенте ChatGPT не переносится в Cherry Studio автоматически. Для вызова OpenAI API приложению Cherry Studio требуется API Key.

## Настройка OpenAI

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **OpenAI**.
3. Введите API Key.
4. Оставьте Base URL по умолчанию: `https://api.openai.com`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите модели, которые планируете использовать.

{% hint style="danger" %}
API Key полностью отображается только в момент создания. Не добавляйте его в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно отзовите Key в консоли OpenAI и создайте новый.
{% endhint %}

## Почему по умолчанию используется Responses

В шаблоне OpenAI в V2 предварительно настроена конечная точка `openai-responses`. Шаблон предназначен для текущего официального API OpenAI, а приложение обрабатывает запросы текста, рассуждений, вызова инструментов и других возможностей с учётом выбранной модели.

Если сторонний шлюз поддерживает только `/v1/chat/completions`:

1. Не изменяйте встроенный шаблон OpenAI для подключения к этому шлюзу.
2. Нажмите `+` рядом с полем поиска в списке провайдеров.
3. Создайте пользовательского провайдера.
4. Установите OpenAI Chat Completions в качестве основной конечной точки.
5. Введите Base URL, API Key и ID модели, предоставленные шлюзом.

Так официальный шаблон OpenAI останется без изменений, а несовместимость протоколов Responses и Chat Completions не приведёт к ошибкам.

## Синхронизация и включение моделей

После нажатия **Добавить** Cherry Studio синхронизирует список моделей провайдера и перед применением показывает добавляемые, обновляемые и удаляемые элементы.

- Включайте только действительно нужные модели, чтобы упростить средство выбора моделей.
- Если у одноимённой модели есть несколько версий, проверьте полный ID модели.
- Если API не возвращает модели, нажмите **Пользовательский** и вручную введите официальный ID модели.
- Не добавляйте ID моделей другого шлюза напрямую в официальный шаблон OpenAI.

Доступность моделей определяется правами учётной записи OpenAI. Если Cherry Studio распознаёт модель, это ещё не означает, что у вашей учётной записи есть доступ к ней.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую модель.
3. Убедитесь, что проверка завершена успешно.
4. Затем запустите проверку работоспособности модели.
5. Вернитесь на экран чата и отправьте простое сообщение.

Если используется модель для рассуждений или вызова инструментов, отдельно проверьте настройки мышления и вызов инструментов. Не определяйте возможности только по названию модели.

## Дополнительные настройки

Шаблон OpenAI поддерживает параметры запросов, включая уровень обслуживания. В настройках модели в верхней части чата может отображаться **Уровень обслуживания**; обычно достаточно оставить значение **Авто**.

Выбирайте другой уровень, только если точно понимаете поддержку и правила оплаты соответствующей модели OpenAI. Переключатели возможностей в настройках запросов провайдера также не следует менять без необходимости: ошибочно заявленная поддержка может привести к сбою запроса.

## Частые вопросы

### Отображается сообщение «Старый способ вызова больше не поддерживается»

Это подсказка V2 для встроенного шаблона OpenAI. Для официального OpenAI API используйте текущий шаблон, а для стороннего совместимого API создайте пользовательского провайдера.

### Возвращается 401

API Key недействителен, отозван или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается 403

Учётная запись, регион, организация или права на модель могут не соответствовать требованиям. Проверьте состояние учётной записи и доступ к модели в консоли OpenAI.

### Возвращается ошибка баланса или квоты

Проверьте квоту, состояние оплаты и ограничения использования учётной записи API. Смена модели не позволяет обойти ограничения уровня учётной записи.

### Возвращается 404 или сообщение «Модель не существует»

Снова нажмите **Добавить**, синхронизируйте список и проверьте ID модели. При подключении к стороннему шлюзу используйте пользовательского провайдера и выберите правильную конечную точку.

### Модель отвечает в чате, но не вызывает инструменты

Проверьте метки возможностей модели и поддержку инструментов для неё со стороны OpenAI. Сначала протестируйте один простой инструмент, а затем постепенно добавляйте MCP или другие инструменты.

Дополнительные общие настройки см. в разделах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Каналы обратной связи перечислены на странице [Отзывы и предложения](../../question-contact/suggestions.md).
