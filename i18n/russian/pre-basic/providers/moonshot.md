# Moonshot AI (Kimi)

Встроенный шаблон Moonshot AI в Cherry Studio V2 предназначен для подключения к открытой платформе Kimi API. По умолчанию шаблон использует протокол OpenAI Chat Completions и также предоставляет совместимую конечную точку Anthropic от Moonshot.

Текущие модели Kimi предназначены для универсального чата, продолжительного программирования, понимания изображений, Agent и других задач. Разные поколения используют разные параметры мышления, поэтому сначала проверьте ID модели и только потом выбирайте параметр мышления в Cherry Studio.

{% hint style="info" %}
Веб-версия Kimi, подписка Kimi, Kimi Code и открытая платформа Kimi API — разные продукты. Вход на сайте или подписка не переносятся в Cherry Studio автоматически. Для вызова через Cherry Studio необходимо отдельно создать API Key, а оплата производится по правилам открытой платформы.
{% endhint %}

## Перед началом

- Учётная запись с доступом к [открытой платформе Kimi API](https://platform.kimi.com/)
- API Key, созданный в разделе [API Keys](https://platform.moonshot.cn/console/api-keys)
- Баланс и права доступа, необходимые для целевой модели
- Проверенные текущие [список моделей](https://platform.kimi.com/docs/models) и ограничения параметров

Рекомендуется создать отдельный Key для Cherry Studio, чтобы различать использование и при необходимости отзывать права.

## Настройка Moonshot AI

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **Moonshot AI**.
3. Введите Kimi API Key.
4. Оставьте Base URL по умолчанию: `https://api.moonshot.cn`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите только модели, которые планируете использовать.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно удалите его на открытой платформе и создайте новый.
{% endhint %}

В документации официального SDK адрес обычно указан как `https://api.moonshot.cn/v1`. Шаблон Cherry Studio обрабатывает путь API, поэтому при использовании встроенного шаблона оставьте адрес по умолчанию и не добавляйте путь запроса повторно.

## Выбор модели

Ориентируйтесь на фактический список синхронизации. Текущие основные модели можно выбирать следующим образом:

| ID модели | Основное назначение | Рекомендация для Cherry Studio |
| --- | --- | --- |
| `kimi-k3` | Флагманская универсальная модель, контекст 1M, продолжительное программирование, работа со знаниями и сложные рассуждения | В текущей V2 рекомендуется оставить мышление **По умолчанию** |
| `kimi-k2.7-code` | Модель программирования и Agent с контекстом 256K | Всегда использует мышление; оставьте **По умолчанию** |
| `kimi-k2.7-code-highspeed` | Более быстрый вывод в той же серии K2.7 Code | Возможны колебания при высокой загрузке ресурсов |
| `kimi-k2.6` | Контекст 256K, универсальный чат, зрение и Agent | Можно использовать мышление по умолчанию или отключать по необходимости |

Официально Kimi K3, K2.7 Code и K2.6 поддерживают ввод текста, изображений и видео. Фактическая доступность вложений также зависит от того, правильно ли текущая версия Cherry Studio распознаёт возможности модели.

Названия, условия доступа и жизненный цикл моделей меняются. Не вводите ID вручную только по старому снимку экрана. Сначала снова нажмите **Добавить**, синхронизируйте список и проверьте официальную документацию Kimi.

## Настройка режима мышления

Разные серии моделей Kimi используют разные параметры рассуждений:

- Kimi K3 всегда использует мышление и принимает на верхнем уровне `reasoning_effort` со значениями `low`, `high` или `max`; значение по умолчанию — `max`.
- Kimi K2.7 Code всегда использует мышление и не поддерживает отключение.
- Kimi K2.6 управляет включением и отключением мышления с помощью `thinking`.

{% hint style="warning" %}
Сейчас Cherry Studio V2 одинаково распознаёт Kimi K2.5 и более новые модели как модели Kimi с мышлением и для любого значения, кроме значения по умолчанию, отправляет параметр `thinking`. Kimi K3 использует `reasoning_effort`, а K2.7 Code не позволяет отключать мышление. Поэтому для K3 и K2.7 Code оставляйте **По умолчанию**, чтобы несовместимый параметр не привёл к ошибке 400.
{% endhint %}

Три уровня рассуждений Kimi K3 — низкий, высокий и максимальный — могут пока не отображаться полностью в меню мышления Cherry Studio. При значении по умолчанию K3 использует значение провайдера `max`. Если требуется точное управление интенсивностью, дождитесь обновления соответствующей поддержки Cherry Studio.

При использовании K2.6:

- **По умолчанию**: не переопределяет поведение провайдера по умолчанию.
- **Выключить**: отправляет параметр, отключающий мышление.
- **Авто**: текущая V2 отправляет параметр, включающий мышление.

K2.5 и более новые модели имеют фиксированные или ограниченные параметры сэмплирования. При ошибке параметров сначала верните температуру, Top P и штрафы к значениям по умолчанию.

## Использование изображений, видео и файлов

Официальные возможности модели и текущий результат распознавания клиентом следует проверять отдельно:

1. Повторно синхронизируйте список моделей.
2. Выберите целевую модель.
3. Проверьте наличие кнопки изображения или файла в области ввода.
4. Сначала загрузите одно обычное изображение для проверки работоспособности.
5. Затем протестируйте видео или большое вложение.

Текущая V2 автоматически распознаёт возможности зрения K2.6. Официальные возможности K3 и K2.7 Code появились позднее, поэтому текущая версия может не показывать все метки зрения. Если кнопки вложений нет, сначала обновите Cherry Studio и список моделей. Если это не помогло, временно используйте `kimi-k2.6` и не отправляйте неподдерживаемое содержимое как текст.

Для PDF встроенный шаблон Moonshot сейчас не использует нативный API загрузки файлов Kimi напрямую. Cherry Studio сначала локально извлекает текст PDF, а затем отправляет его модели:

- Текстовый PDF обычно можно обработать напрямую.
- Для сканированного документа может сначала потребоваться OCR.
- Таблицы, сложная вёрстка и информация на изображениях могут потеряться при извлечении.
- Извлечённый текст расходует Token ввода модели.

## Вызов инструментов и MCP

Официальные модели Kimi поддерживают вызов инструментов, но отображение возможностей MCP в Cherry Studio также зависит от распознавания возможностей модели.

Рекомендуемый порядок проверки:

1. Сначала завершите один обычный диалог.
2. Включите один простой инструмент MCP.
3. Используйте подсказку, явно требующую вызова инструмента.
4. Убедитесь, что модель действительно начинает вызов.
5. Затем добавьте несколько инструментов или длинную цепочку задач.

Текущая V2 содержит правила распознавания инструментов для серии Kimi K2, но автоматическое распознавание K3 и K2.7 Code может отставать от официального выпуска модели. Если кнопка MCP отсутствует, сначала обновите Cherry Studio. Если модель по-прежнему не распознана, временно используйте модель, которую текущая версия распознаёт.

Когда MCP возвращает изображение, аудио или ресурс с большим объёмом двоичных данных, Cherry Studio преобразует результат в текстовую сводку, чтобы base64 не превысил ограничение размера запроса Kimi. Модель увидит текстовое описание результата инструмента, но не сможет напрямую анализировать заменённые исходные медиа.

## Базы знаний и модели эмбеддингов

Во встроенном шаблоне Moonshot AI сейчас настроены конечные точки чата; моделей эмбеддингов в нём нет. При использовании базы знаний или [глобальной памяти](../../advanced-basic/memory.md):

- В качестве модели чата по-прежнему можно выбрать Kimi.
- Модель эмбеддингов необходимо выбрать у другого провайдера.
- Модель чата и модель эмбеддингов не обязаны принадлежать одному провайдеру.
- После настройки отдельно запустите проверку работоспособности каждой модели.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую модель.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.
6. Затем отдельно протестируйте мышление, вложения и MCP.

Успешная проверка подключения подтверждает только пригодность основных учётных данных. Она не означает, что учётная запись имеет права на все модели или что текущий клиент распознаёт все возможности каждой модели.

## Частые вопросы

### Возвращается 401

API Key недействителен, удалён или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается ошибка баланса или условий доступа

Проверьте баланс открытой платформы, уровень учётной записи и условия доступа к целевой модели. Баланс подписки на веб-версию Kimi не заменяет баланс API.

### Возвращается 404 или сообщение «Модель не существует»

ID модели изменён, модель снята с обслуживания или у учётной записи пока нет доступа. Снова нажмите **Добавить**, синхронизируйте список и проверьте [список моделей](https://platform.kimi.com/docs/models).

### Возвращается 400 или сообщение о недействительном параметре `thinking`

При использовании Kimi K3 или K2.7 Code верните параметр мышления к значению **По умолчанию**, а температуру, Top P и другие параметры — к значениям по умолчанию. K3 не принимает переключатель `thinking`, используемый K2.6.

### Возвращается 429 или запрос перегружен

Учётная запись достигла ограничения параллелизма, RPM, TPM или TPD либо ресурсы высокоскоростной модели временно перегружены. Уменьшите параллелизм, сократите контекст или повторите попытку позже.

### У K3 или K2.7 Code нет кнопки изображения, видео или MCP

Это означает, что официальные возможности модели и текущие правила автоматического распознавания Cherry Studio ещё не синхронизированы. Обновите Cherry Studio и повторно синхронизируйте модель. Если кнопка всё ещё отсутствует, временно используйте K2.6 и дождитесь обновления клиента.

### Содержимое PDF распознаётся не полностью

Проверьте, является ли PDF сканированным. Сначала выполните OCR или преобразуйте важные страницы в изображения и используйте модель Kimi, которую Cherry Studio распознаёт как модель со зрением.

Дополнительные общие настройки см. в разделах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Различия параметров Kimi приведены в [справочнике параметров моделей](https://platform.kimi.com/docs/api/models-overview), а каналы обратной связи — на странице [Отзывы и предложения](../../question-contact/suggestions.md).
