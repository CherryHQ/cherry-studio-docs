# PPIO

PPIO предоставляет API больших языковых моделей, моделей зрения, Embedding, Rerank и генерации изображений. В Cherry Studio V2 встроен провайдер PPIO, который может напрямую синхронизировать доступные сейчас модели без создания пользовательского провайдера.

Встроенный в V2 Base URL чата и Embedding:

```text
https://api.ppinfra.com/v3/openai/
```

{% hint style="info" %}
В некоторых примерах официального руководства PPIO используется `api.ppio.com/openai/v1`, но встроенный провайдер Cherry Studio V2 сейчас использует указанный выше совместимый адрес. При первой настройке сохраните шаблон приложения и меняйте его только при явном требовании PPIO или Cherry Studio.
{% endhint %}

## Подготовка к использованию

Перед первым использованием API моделей PPIO обычно требуется:

1. Зарегистрироваться и войти в PPIO.
2. Пройти проверку настоящего имени физического или юридического лица.
3. Пополнить счёт или убедиться в доступном балансе.
4. Создать API Key.
5. Убедиться, что нужная модель ещё предоставляется.

Модели, цены и состояние выпуска PPIO меняются. На этой странице не фиксируются цены или подарочные квоты; ориентируйтесь на консоль и [страницу сервисов моделей](https://ppio.com/model-api/product/llm-api).

## Получение API Key

1. Войдите в [консоль PPIO](https://ppio.com/).
2. Откройте [управление ключами API](https://ppio.com/settings/key-management).
3. Нажмите **Создать**.
4. Введите понятное имя ключа.
5. Сразу после создания скопируйте и сохраните его.

PPIO проверяет API Key способом Bearer. Сейчас одна учётная запись может создать не более 10 ключей, а после создания ключ нельзя просмотреть повторно.

{% hint style="danger" %}
API Key равнозначен учётным данным. Не помещайте его в чат, документацию, репозиторий кода или снимки экрана с проблемой. При потере или утечке немедленно удалите ключ в PPIO и создайте новый.
{% endhint %}

## Настройка в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики**.
3. Выберите **PPIO**.
4. Вставьте ключ PPIO в поле API Key.
5. Сохраните шаблонный Base URL `https://api.ppinfra.com/v3/openai/`.
6. Включите провайдера переключателем в верхней части страницы.
7. Нажмите **Добавить** или синхронизируйте модели.
8. Проверьте предварительный результат и примените изменения.
9. Включите только нужные модели.
10. Запустите проверку состояния модели.

Проверка подключения подтверждает только доступность учётных данных и базового запроса, но не возможность вызова каждой модели из списка. Разрешения, баланс, региональные ограничения и состояние выпуска по-прежнему определяет PPIO.

## Синхронизация моделей

Cherry Studio V2 параллельно считывает три списка:

```text
/models
/models?model_type=embedding
/models?model_type=reranker
```

Результаты объединяются и дедуплицируются по Model ID, поэтому одна синхронизация может найти модели чата, Embedding и Rerank.

После синхронизации рекомендуется:

1. Просмотреть добавленные, обновлённые и удалённые элементы.
2. Проверить тип каждой модели.
3. Применить результат синхронизации.
4. Удалить устаревшие модели, сохранённые вручную.
5. Отдельно запустить проверки состояния.

{% hint style="warning" %}
Встроенный шаблон V2 предназначен для первого отображения и может быть старше отключения или переименования модели PPIO. Приоритет имеют текущий список платформы и официальные объявления; не продолжайте использовать старый Model ID только потому, что он остался локально.
{% endhint %}

## Выбор модели чата

Модели чата PPIO подключаются через совместимый с OpenAI Chat Completions. Поддержка длинного контекста, зрения, инструментов и параметров мышления различается.

Рекомендуемый порядок проверки:

1. Отправьте короткое текстовое сообщение.
2. Проверьте потоковый вывод.
3. Добавьте системный запрос.
4. Проверьте более длинный контекст.
5. В конце проверьте изображения, мышление и инструменты.

Model ID должен полностью совпадать с текущим списком PPIO, включая префикс организации, регистр, косую черту и суффикс версии. Не используйте отображаемое имя или URL страницы продукта как Model ID.

## Модели зрения

Получать изображения может только Model ID, явно отмеченный PPIO как модель языка и зрения.

В Cherry Studio:

1. Синхронизируйте последние модели.
2. Выберите модель с отображаемой возможностью изображений.
3. Сначала загрузите одно небольшое изображение.
4. Проверьте, действительно ли модель понимает его.
5. Затем попробуйте несколько изображений или высокое разрешение.

Текстовая версия и версия зрения одной серии могут иметь разные ID. Изображение также увеличивает размер запроса, расход контекста и стоимость.

## Режим мышления

Cherry Studio создаёт параметры мышления по серии модели. Для гибридных моделей рассуждения DeepSeek в PPIO V2 использует совместимое с платформой управление `thinking`.

Если после включения мышления возникает ошибка параметра:

1. Верните параметр к значению **По умолчанию**.
2. Удалите пользовательские параметры модели.
3. Убедитесь, что Model ID не указывает на старую версию.
4. Повторно синхронизируйте модели.
5. Сравните с текущим описанием модели PPIO.

Не копируйте параметр мышления одной модели в другую серию. PPIO только передаёт поддерживаемые платформой параметры, а итоговое поведение зависит от конкретной модели.

## MCP и вызов инструментов

Для MCP Cherry Studio модель должна поддерживать структурированный Tool Calling.

1. Сначала убедитесь, что обычный чат работает.
2. Включите только один простой инструмент MCP.
3. Явно попросите модель его вызвать.
4. Проверьте появление структурированного вызова.
5. Убедитесь, что результат инструмента возвращается модели.
6. Затем постепенно добавляйте инструменты.

Если модель только пишет, что «вызовет инструмент», но не выполняет вызов, проблема обычно связана с возможностями модели, распознаванием или совместимостью параметров; это не означает успешной работы сервера MCP.

## Embedding, Rerank и база знаний

PPIO также предоставляет совместимые с OpenAI интерфейсы Embedding и Rerank. V2 запрашивает эти два типа моделей отдельно при синхронизации.

Текущие примеры официального руководства:

- Embedding: `baai/bge-m3`.
- Rerank: `baai/bge-reranker-v2-m3`.

Эти имена также могут измениться. При использовании ориентируйтесь на результат синхронизации и страницу моделей PPIO.

При создании базы знаний:

1. Сначала синхронизируйте модели PPIO.
2. Выберите модель, явно распознанную как Embedding.
3. Определите размерность вектора.
4. Запустите проверку состояния.
5. Выберите доступную сейчас модель Rerank.
6. Импортируйте несколько документов для проверки.
7. После проверки поиска и ранжирования выполните пакетный импорт.

После использования модели Embedding или размерности в существующей базе знаний не меняйте их напрямую, иначе обычно требуется перестроить векторный индекс.

## Генерация и редактирование изображений

Cherry Studio V2 реализует отдельный канал передачи изображений PPIO. Он использует другой хост, чем интерфейс чата:

| Назначение | Адрес V2 |
| --- | --- |
| Чат и Embedding | `https://api.ppinfra.com/v3/openai/` |
| Генерация изображений и запрос задач | `https://api.ppio.com` |

Страница изображений выбирает синхронный или асинхронный интерфейс по регистрации модели и показывает только заявленные режимы и параметры, например:

- генерацию из текста;
- редактирование изображения;
- размер изображения;
- Seed;
- водяной знак;
- LoRA или эталонное изображение у некоторых моделей.

Не каждая модель изображений на сайте PPIO уже поддерживается текущей V2. Начинайте проверку с моделей PPIO, доступных на странице рисования Cherry Studio.

31 января 2026 года PPIO отключила ряд старых Image API, включая прежние `txt2img`, `img2img`, удаление и замену фона, локальное редактирование, стирание текста и объектов, а также слияние лиц. Не следуйте старым инструкциям или снимкам экрана с этими интерфейсами.

{% hint style="warning" %}
Генерация изображений может иметь заметную стоимость. Сначала проверьте небольшой размер и одно изображение; не отправляйте запрос повторно во время ожидания асинхронной задачи, иначе могут создаться несколько оплачиваемых задач.
{% endhint %}

## PDF и вложения

Текущая V2 сначала локально извлекает текст PDF, а затем отправляет его модели чата PPIO:

- PDF с текстовым слоем обычно обрабатывается.
- Для сканированного документа сначала нужен OCR.
- Таблицы, сложная вёрстка и изображения могут потеряться.
- Извлечённый текст расходует контекст и средства.
- Изображения PDF нужно отдельно отправлять модели зрения.

PPIO — облачный сервис. Перед загрузкой документа, изображения или базы знаний убедитесь в соответствии требованиям конфиденциальности, авторского права и безопасности организации.

## Баланс, ограничения и отключение моделей

PPIO взимает плату по модели и использованию; цена, частота и ограничение параллельности могут меняться.

Рекомендации:

1. Настройте в консоли бюджет или предупреждение о балансе.
2. Проверяйте новую модель коротким запросом.
3. Не допускайте бесконечных повторов нескольких автоматических задач с одним ключом.
4. При 429 уменьшите параллельность и подождите.
5. Следите за отключением моделей и интерфейсов в [официальных объявлениях](https://ppio.com/docs/announcement/announcement).
6. Регулярно синхронизируйте модели и удаляйте старые ID.

Документация сообщества не фиксирует временные цены, коды приглашений, бонусы или обещания «бесплатно навсегда», чтобы не вводить в заблуждение после завершения акции.

## Частые вопросы

### Возвращается 401

API Key неверен, удалён, содержит пробелы после копирования или запрос неправильно использует Bearer-авторизацию. Создайте и скопируйте новый ключ со страницы управления.

### Возвращается 402 или недостаточный баланс

На счёте недостаточно средств или модель не включена в доступные права. Проверьте счета, баланс и цену модели PPIO.

### Возвращается 403

Учётная запись могла не пройти проверку настоящего имени, не иметь разрешения модели или содержимое запроса нарушило политику платформы. Сначала проверьте состояние в консоли PPIO.

### Возвращается 404

Base URL, Model ID или интерфейс изображения устарел. Сначала восстановите шаблонный адрес V2, синхронизируйте модели и проверьте официальное объявление об отключении.

### Возвращается 429

Достигнута частота модели, параллельность или ограничение учётной записи. Уменьшите параллельность, сократите запрос и дождитесь восстановления; не запускайте немедленный цикл повторов.

### Список моделей пуст

Проверьте API Key, Base URL и сетевой прокси. Восстановите шаблонный Base URL и повторно синхронизируйте; при необходимости скопируйте полный Model ID с текущей страницы PPIO.

### Модель из шаблона не работает

Шаблон мог появиться до отключения, переименования или изменения разрешений платформы. Ориентируйтесь на текущую синхронизацию, удалите недействительную модель и выберите доступную версию.

### Embedding работает, а Rerank — нет

Они используют разные модели и интерфейсы. Синхронизируйте и проверяйте их отдельно; убедитесь, что модель Rerank не отключена, а в базе знаний выбрана модель ранжирования, а не Embedding.

### Задача изображения продолжает ожидать

Задача может оставаться в очереди, платформа загружена, сетевой опрос завершился ошибкой или баланс недостаточен. Сначала подождите и проверьте ошибку, не отправляйте одну задачу повторно.

### Не удаётся найти модель изображения из старой инструкции

PPIO отключила часть старых Image API, а V2 показывает только поддерживаемые сейчас модели. Синхронизируйте модели и используйте фактический выбор на странице рисования.

### После изменения Base URL не работают чат и рисование

Каналы чата и изображений PPIO используют разные хосты. Не переопределяйте внутренний адрес изображения V2 ради соответствия одному примеру API; восстановите настройки встроенного провайдера.

Дополнительные настройки описаны на страницах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Текущие требования, ключи и интерфейсы PPIO описаны в [кратком руководстве](https://ppio.com/docs/model/get-start), [управлении API Key](https://ppio.com/docs/support/api-key), [Embedding](https://ppio.com/docs/models/reference-llm-create-embeddings) и [Rerank](https://ppio.com/docs/models/reference-llm-create-rerank), а каналы обратной связи — на странице [Отзывы и предложения](../../question-contact/suggestions.md).
