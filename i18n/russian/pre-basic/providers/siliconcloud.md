# SiliconFlow

SiliconFlow предоставляет API для диалогов, компьютерного зрения, Embedding, Rerank и генерации изображений. В Cherry Studio V2 встроен провайдер SiliconFlow, а для диалогов, Embedding и генерации изображений реализованы специальные адаптеры.

Предустановленный API Host в V2:

```text
https://api.siliconflow.cn
```

Фактические OpenAI-совместимые запросы используют путь `/v1`, например `https://api.siliconflow.cn/v1/chat/completions`.

{% hint style="info" %}
При первой настройке оставьте предустановленный адрес V2. Не указывайте в API Host адрес страницы консоли, каталога моделей или документации.
{% endhint %}

## Подготовка к работе

1. Зарегистрируйтесь в SiliconFlow и войдите в аккаунт.
2. Пройдите требуемую платформой проверку аккаунта.
3. Создайте API Key.
4. Пополните баланс или убедитесь, что на аккаунте еще есть доступные средства.
5. Проверьте, что нужная модель по-прежнему доступна.
6. Уточните стоимость модели и ограничения частоты запросов.

SiliconFlow может изменять модели, возможности, цены и их доступность. В этом руководстве не фиксируются бонусы, бесплатные модели и цены. Актуальные сведения смотрите в [каталоге моделей](https://cloud.siliconflow.cn/models) и консоли.

## Получение API Key

1. Войдите в [консоль SiliconFlow](https://cloud.siliconflow.cn/).
2. Откройте раздел [API Keys](https://cloud.siliconflow.cn/account/ak).
3. Нажмите **New Key**.
4. Укажите понятное имя.
5. Скопируйте созданный Key.
6. Сохраните его в надежном менеджере паролей.

{% hint style="danger" %}
API Key является учетными данными аккаунта. Не добавляйте его в чаты, документы, репозитории кода и снимки экрана для отчетов о проблемах. При утечке немедленно удалите ключ и создайте новый.
{% endhint %}

## Настройка в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`.
2. В фильтре слева выберите **Все провайдеры**.
3. Выберите **Silicon / SiliconFlow**.
4. Вставьте ключ SiliconFlow в поле API Key.
5. Оставьте API Host `https://api.siliconflow.cn`.
6. Включите провайдера переключателем в верхней части страницы.
7. Нажмите **Добавить** или синхронизируйте модели.
8. Проверьте предварительный результат синхронизации и примените изменения.
9. Включите только те модели, которые собираетесь использовать.
10. Запустите проверку работоспособности модели.

Проверка подключения подтверждает только действительность ключа и базового запроса. Она не гарантирует, что аккаунт может вызывать каждую модель из списка. Окончательные права доступа, баланс и ограничения определяет SiliconFlow.

## Синхронизация и добавление моделей

Cherry Studio получает актуальные модели через API списка моделей SiliconFlow. Интерфейс SiliconFlow `/v1/models` также позволяет фильтровать модели по следующим типам:

- `chat`
- `embedding`
- `reranker`
- `text-to-image`
- `image-to-image`
- другие типы аудио и видео

После синхронизации рекомендуется:

1. Просмотреть добавленные, обновленные и удаляемые позиции.
2. Проверить тип каждой модели.
3. Применить результат синхронизации.
4. Удалить старые модели, которые ранее были сохранены вручную.
5. Отдельно проверить работоспособность каждой модели.

Встроенные модели V2 являются лишь кандидатами: приоритет имеют актуальные данные платформы. Если модель не распознана автоматически как Embedding, Rerank, визуальная модель или модель генерации изображений, проверьте ее возможности в управлении моделями. Не пытайтесь обойти различия интерфейсов, меняя только отображаемое имя.

{% hint style="warning" %}
Model ID должен полностью совпадать с актуальным списком SiliconFlow, включая префикс `Pro/`, имя организации, регистр, косые черты и суффикс версии.
{% endhint %}

## Выбор диалоговой модели

Для диалогов SiliconFlow используется OpenAI-совместимый интерфейс Chat Completions.

Рекомендуемый порядок проверки:

1. Отправьте короткое текстовое сообщение.
2. Проверьте потоковый вывод.
3. Добавьте системный промпт.
4. Проверьте более длинный контекст.
5. Затем проверьте изображения, режим рассуждения и вызов инструментов.

Версии с `Pro/` и обычные версии могут различаться по цене, пропускной способности и доступности. Считайте их разными Model ID и проверяйте работоспособность каждой отдельно.

## Визуальные модели

Изображения могут принимать только те Model ID, которые SiliconFlow явно обозначает как визуально-языковые модели.

В Cherry Studio:

1. Синхронизируйте актуальные модели.
2. Выберите модель, у которой указана поддержка изображений.
3. Сначала загрузите одно небольшое изображение.
4. Убедитесь, что модель действительно понимает его содержимое.
5. Затем попробуйте несколько изображений или изображение высокого разрешения.

У текстовой и визуальной версий одной серии моделей могут быть разные ID. Изображения также увеличивают размер запроса, расход контекста и стоимость.

## Режим рассуждения

Некоторые модели DeepSeek, GLM, Qwen и Hunyuan в SiliconFlow используют параметры `enable_thinking` и `thinking_budget`.

Для поддерживаемых моделей рассуждения SiliconFlow Cherry Studio V2:

- использует переключатель `enable_thinking`;
- при заданном бюджете рассуждения увеличивает любое ненулевое значение как минимум до 32,768;
- при отключении рассуждения отправляет `enable_thinking: false`.

Поэтому текущая версия V2 не подходит для точной установки небольшого бюджета рассуждения в SiliconFlow. Чтобы сократить расход, прежде всего отключите рассуждение, уменьшите контекст или выберите модель без рассуждения.

Если после включения рассуждения возникает ошибка:

1. Верните настройку рассуждения к значению **По умолчанию**.
2. Удалите пользовательские параметры модели.
3. Убедитесь, что Model ID по-прежнему доступен.
4. Сверьтесь с актуальным описанием модели в SiliconFlow.
5. Повторно запустите проверку работоспособности.

## MCP и вызов инструментов

Chat Completions в SiliconFlow поддерживает `tools`, но корректность вызова зависит от конкретной модели.

1. Сначала убедитесь, что обычный диалог работает.
2. Включите только один простой инструмент MCP.
3. Явно попросите модель вызвать его.
4. Проверьте, сформирован ли структурированный вызов.
5. Убедитесь, что результат инструмента возвращается модели.
6. Только после этого добавляйте другие инструменты.

Если модель лишь пишет, что «собирается вызвать инструмент», это не является реальным вызовом. В таком случае проверьте возможности модели, промпт и описание инструмента.

## Embedding, Rerank и база знаний

SiliconFlow предоставляет следующие интерфейсы:

```text
POST /v1/embeddings
POST /v1/rerank
```

Среди видимых примеров моделей могут быть `BAAI/bge-m3`, Qwen Embedding, Qwen Reranker и BGE Reranker, но фактический список следует получать из каталога моделей или результата синхронизации.

При создании базы знаний:

1. Синхронизируйте модели.
2. Выберите модель, однозначно распознанную как Embedding.
3. Определите размерность векторов.
4. Запустите проверку работоспособности.
5. Затем выберите актуальную модель Rerank.
6. Для проверки импортируйте небольшое количество документов.
7. Убедитесь, что поиск и повторное ранжирование работают правильно, и только потом запускайте массовый импорт.

Некоторые модели Qwen Embedding позволяют выбирать выходную размерность. После использования размерности в существующей базе знаний не меняйте ее напрямую: обычно потребуется перестроить векторный индекс.

Rerank и Embedding используют разные конечные точки и модели. Доступность Embedding не означает доступность Rerank, поэтому проверяйте их отдельно.

## Генерация и редактирование изображений

В Cherry Studio V2 реализованы специальные модели изображений SiliconFlow. Запросы отправляются по адресу:

```text
POST /v1/images/generations
```

Текущая регистрация моделей в V2 в основном охватывает генерацию и редактирование Qwen Image. Другие модели изображений с официального сайта могут распознаваться некорректно в текущей версии. Ориентируйтесь на варианты, доступные на странице рисования Cherry Studio.

В зависимости от возможностей модели V2 может передавать:

- `image_size`
- `batch_size`
- `seed`
- `negative_prompt`
- `num_inference_steps`
- `guidance_scale`
- `cfg`
- `prompt_enhancement`
- до трех исходных изображений для редактирования

SiliconFlow использует явный параметр `image_size`. V2 не преобразует отдельный параметр соотношения сторон в корректный запрос автоматически. Ввод маски также не поддерживается текущим специальным адаптером.

{% hint style="warning" %}
Стоимость модели изображений может рассчитываться по количеству результатов. При первой проверке задайте количество в пакете равным 1 и используйте распространенный размер, поддерживаемый моделью.
{% endhint %}

Если ответ содержит URL изображения, своевременно сохраните результат. Срок действия временной ссылки определяет SiliconFlow.

## PDF и вложения

Текущая версия V2 сначала извлекает текст PDF локально, а затем отправляет его диалоговой модели SiliconFlow:

- текстовые PDF обычно можно обработать;
- для отсканированных документов сначала требуется OCR;
- таблицы, сложное форматирование и сведения из изображений могут быть потеряны;
- извлеченный текст расходует контекст модели и оплачиваемые токены;
- изображения из PDF необходимо отдельно отправлять визуальной модели.

SiliconFlow является облачным сервисом. Перед загрузкой документов, изображений или содержимого базы знаний убедитесь, что это соответствует требованиям к конфиденциальности, авторским правам и безопасности вашей организации.

## Ограничения, баланс и данные для диагностики

Ограничения SiliconFlow могут рассчитываться отдельно для каждой модели и одновременно учитывать RPM, TPM, RPD, TPD, IPM, IPD и другие показатели.

Рекомендуется:

1. Проверять баланс и стоимость моделей в консоли.
2. Задавать для автоматических задач предел параллельности и количества повторных попыток.
3. При ошибке 429 снизить частоту запросов и подождать.
4. Регулярно синхронизировать модели.
5. Сохранять `x-siliconcloud-trace-id` из ответа с ошибкой для обращения в поддержку.

Не создавайте несколько Key для обхода ограничения на уровне аккаунта: ограничения платформы обычно не рассчитываются независимо для каждого Key.

## Частые проблемы

### Возвращается 401

API Key неверен, удален, содержит случайно скопированные пробелы или запрос неправильно использует Bearer-аутентификацию. Скопируйте ключ заново или создайте новый.

### Возвращается 403

У аккаунта нет доступа к модели или содержимому. Проверьте подтверждение личности, баланс, право использования модели и правила платформы.

### Возвращается 404

Указан неверный API Host, Model ID или тип интерфейса. Верните предустановленный адрес V2 и повторно синхронизируйте модели.

### Возвращается 429

Достигнуто ограничение RPM, TPM, RPD, TPD, IPM или IPD модели. Уменьшите параллельность, сократите контекст и дождитесь восстановления.

### Возвращается 503 или 504

Модель перегружена либо вышестоящий сервис не ответил вовремя. Уменьшите параллельность и повторите запрос. Если ошибка сохраняется, выберите другую доступную модель и запишите Trace ID.

### Список моделей пуст

Проверьте API Key, API Host и сетевой прокси. Можно также скопировать полный Model ID из каталога моделей и добавить его вручную.

### Предустановленная модель недоступна

Предустановка V2 могла быть создана до снятия модели с публикации, переименования или изменения прав доступа. Ориентируйтесь на актуальный результат синхронизации и удалите недоступную модель.

### Бюджет рассуждения не совпадает с настройкой

Текущая версия V2 увеличивает любой ненулевой бюджет рассуждения поддерживаемой модели SiliconFlow как минимум до 32,768. Это поведение адаптера клиента. Чтобы снизить расход, отключите рассуждение или используйте модель без него.

### Embedding доступен, а Rerank недоступен

Они используют разные модели и интерфейсы. Проверьте Model ID, баланс и метку возможностей Rerank, затем отдельно запустите проверку работоспособности.

### Модель изображений есть на официальном сайте, но нет на странице рисования

В текущей версии V2 для этой модели еще не зарегистрирован режим генерации изображений. Не используйте ее как диалоговую модель: дождитесь адаптации или выберите модель, уже доступную на странице рисования.

### При редактировании обработано только первое изображение

Проверьте, поддерживает ли модель редактирование нескольких изображений. V2 отправляет не более трех исходных изображений, но конкретная модель может принимать только одно.

Актуальные интерфейсы и модели SiliconFlow смотрите в документации: [список моделей](https://docs.siliconflow.cn/cn/api-reference/models/get-model-list), [Chat Completions](https://docs.siliconflow.cn/cn/api-reference/chat-completions/chat-completions), [Embedding](https://docs.siliconflow.cn/cn/api-reference/embeddings/create-embeddings), [Rerank](https://docs.siliconflow.cn/cn/api-reference/rerank/create-rerank) и [генерация изображений](https://docs.siliconflow.cn/cn/userguide/capabilities/images).
