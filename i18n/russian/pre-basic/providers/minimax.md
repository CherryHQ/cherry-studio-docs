# MiniMax

В Cherry Studio V2 встроены два провайдера: **MiniMax** и **MiniMax (международная версия)**. Оба позволяют подключиться к API языковых моделей MiniMax, но используют разные открытые платформы, Base URL и API Key.

На этой странице описано, как использовать серию MiniMax M в Cherry Studio для чатов, программирования и задач Agent. Для генерации речи, изображений, видео и музыки MiniMax использует отдельные API, которые не относятся к описываемому здесь сервису языковых моделей.

{% hint style="info" %}
Для открытой платформы в материковом Китае выберите **MiniMax**, а для международной открытой платформы — **MiniMax (международная версия)**. Учётные записи, ключи, балансы и подписки этих платформ могут быть независимыми: не смешивайте их.
{% endhint %}

## Подготовка

Подготовьте учётные данные в соответствии с платформой вашей учётной записи:

| Платформа | Провайдер в Cherry Studio | Base URL по умолчанию |
| --- | --- | --- |
| Материковый Китай | MiniMax | `https://api.minimaxi.com/v1/` |
| Международная | MiniMax (международная версия) | `https://api.minimax.io/v1/` |

- Пользователи в материковом Китае могут создать API Key на [открытой платформе MiniMax](https://platform.minimaxi.com/).
- Международные пользователи могут создать API Key на [MiniMax API Platform](https://platform.minimax.io/).
- Убедитесь, что для ключа доступен баланс с оплатой по факту использования или действующий Token Plan.
- Проверьте доступные модели, контекст и ограничения частоты запросов.

API Key с оплатой по факту использования и ключ Token Plan расходуют разные балансы или квоты. Если подключение устанавливается, но возвращается ошибка квоты, откройте страницу оплаты, соответствующую месту создания этого ключа, а не проверяйте только баланс другой учётной записи.

## Настройка MiniMax

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики**.
3. Для учётной записи материкового Китая выберите **MiniMax**, для международной — **MiniMax (международная версия)**.
4. Введите API Key, созданный на соответствующей платформе.
5. Оставьте встроенный Base URL по умолчанию.
6. Включите провайдера переключателем в верхней части страницы.
7. Нажмите **Добавить** в списке моделей, проверьте предварительный результат синхронизации и примените изменения.
8. Включите только те модели, которые собираетесь использовать.

{% hint style="danger" %}
Не помещайте API Key в сообщения чата, документацию, репозиторий кода или снимки экрана с описанием проблемы. Если ключ раскрыт, немедленно удалите его на соответствующей открытой платформе MiniMax и создайте новый.
{% endhint %}

Если ввести ключ платформы `.com` у провайдера `.io` или наоборот, обычно возвращается ошибка авторизации. Сначала проверьте, правильно ли выбран провайдер, и не переопределяйте встроенный адрес без необходимости.

## Выбор модели

Сейчас Cherry Studio V2 содержит следующие основные модели в шаблонах обоих провайдеров MiniMax:

| ID модели | Основное назначение |
| --- | --- |
| `MiniMax-M3` | Флагманская мультимодальная модель для программирования и Agent с официально заявленным контекстом 1M |
| `MiniMax-M2.7` | Программирование, вызов инструментов, офисные задачи и сложные рабочие процессы Agent |
| `MiniMax-M2.7-highspeed` | Та же серия, что и M2.7, с приоритетом более низкой задержки вывода |

В синхронизированном списке также могут появиться M2.5, M2.1 и другие модели. Ориентируйтесь на фактический результат синхронизации и официальную документацию MiniMax по ID и жизненному циклу моделей; не полагайтесь на названия серии `abab` из старой документации.

- Для повседневных комплексных задач сначала попробуйте M3.
- Если основная работа связана с кодом и вызовом инструментов, сравните M3 и M2.7.
- Если важна скорость вывода, выберите `MiniMax-M2.7-highspeed`.
- Для воспроизводимых результатов записывайте полный ID модели, а не только отображаемое имя.

## Совместимые конечные точки OpenAI и Anthropic

Оба встроенных провайдера содержат адреса, совместимые с OpenAI Chat Completions и Anthropic Messages:

| Платформа | Совместимость с OpenAI | Совместимость с Anthropic |
| --- | --- | --- |
| Материковый Китай | `https://api.minimaxi.com/v1/` | `https://api.minimaxi.com/anthropic` |
| Международная | `https://api.minimax.io/v1/` | `https://api.minimax.io/anthropic` |

По умолчанию Cherry Studio использует OpenAI Chat Completions. Для обычных чатов и синхронизации моделей сначала можно сохранить настройку по умолчанию.

Для обработки блоков мышления и чередующегося мышления MiniMax рекомендует конечную точку с совместимостью Anthropic. Если вы вручную меняете тип конечной точки модели в Cherry Studio, также убедитесь в следующем:

- Base URL соответствует региону учётной записи.
- Модель использует протокол Anthropic Messages.
- Ключ получен на той же платформе.
- Обычный чат, отображение мышления и вызов инструментов повторно прошли проверку состояния.

Не меняйте только Base URL, оставляя неверный тип протокола. Структуры сообщений в совместимых API OpenAI и Anthropic не полностью совпадают.

## Содержимое мышления и многоэтапный вызов инструментов

Серия MiniMax M возвращает содержимое рассуждений. Cherry Studio распознаёт модели серии M2 как модели рассуждений. Поскольку M3 выпущена недавно, в текущей V2 специальные элементы управления мышлением могут отображаться не полностью.

Рекомендации по использованию:

- Оставьте настройку мышления **По умолчанию**.
- Не отправляйте принудительное отключение или пользовательский бюджет модели с фиксированным мышлением.
- Используйте потоковый вывод для длинных ответов.
- Не изменяйте без необходимости температуру, Top P и штрафы.
- После смены протокола повторно проверьте правильность отображения содержимого мышления.

{% hint style="warning" %}
Многоэтапный вызов инструментов MiniMax зависит от полного сообщения assistant, включая содержимое мышления и `tool_calls`. Cherry Studio поддерживает историю диалога; не удаляйте и не переписывайте вручную предыдущее сообщение во время выполнения инструмента, иначе модель может потерять непрерывность рассуждения.
{% endhint %}

Если при использовании конечной точки с совместимостью OpenAI отображаются теги `<think>`, обычно провайдер помещает содержимое мышления в `content`. Перед переходом на конечную точку с совместимостью Anthropic протестируйте её в отдельной копии провайдера, чтобы не повлиять на существующие чаты.

## Вызов инструментов и MCP

Cherry Studio V2 распознаёт возможность вызова инструментов у серий MiniMax M2, M2.x и M3. Их можно использовать в сценариях MCP и Agent.

Рекомендуемый порядок проверки:

1. Выберите синхронизированную и включённую M3 или M2.7.
2. Проведите один обычный обмен сообщениями.
3. Включите один простой инструмент MCP.
4. Используйте запрос, явно требующий вызова инструмента.
5. Убедитесь, что модель действительно инициировала вызов инструмента.
6. Затем добавьте несколько инструментов или длинную последовательность действий.

В длинных последовательностях действий сохраняйте полный контекст. Если модель повторно вызывает один и тот же инструмент, сначала сократите число инструментов и системный запрос, а также чётко укажите условие остановки.

## Изображения, видео и файлы

Официально MiniMax M3 поддерживает ввод текста, изображений и видео, но текущие правила автоматического распознавания моделей зрения в Cherry Studio V2 могут ещё не включать M3. Поэтому:

- Если в поле ввода отображается кнопка изображения или видео, сначала выполните проверку с небольшим файлом.
- Если кнопка не появилась, сначала обновите Cherry Studio и повторно синхронизируйте модели.
- Не имитируйте возможности модели, изменяя только отображаемое имя.
- Если возможность всё ещё недоступна в текущей версии, дождитесь обновления поддержки клиента.

Старые модели M2 в совместимых API MiniMax OpenAI и Anthropic обычно поддерживают только текст и вызов инструментов. Не добавляйте отдельные модели MiniMax для генерации изображений, видео или речи как модели чата.

Для PDF текущая версия Cherry Studio сначала извлекает текст локально, а затем отправляет его MiniMax:

- PDF с текстовым слоем обычно можно обработать напрямую.
- Для сканированных документов сначала требуется OCR.
- Информация в таблицах, сложной вёрстке и изображениях может потеряться при извлечении.
- Извлечённый текст расходует контекст и входную квоту.

## Мультимодальная генерация — не модель чата

MiniMax также предоставляет API для генерации речи, изображений, видео и музыки, однако у этих интерфейсов собственные форматы запросов и процессы выполнения задач. Наличие модели на открытой платформе не означает, что её можно вызвать напрямую через провайдера чата Cherry Studio.

Например, ручное добавление модели генерации видео в список моделей чата обычно приводит только к ошибке параметра или конечной точки. Для такой возможности используйте специальный раздел, поддерживаемый Cherry Studio. Неподдерживаемый сейчас интерфейс нельзя заменить изменением имени модели.

## База знаний и модели эмбеддингов

Встроенный провайдер MiniMax сейчас настроен на конечные точки языковых моделей и не предоставляет модели эмбеддингов. При использовании базы знаний или [глобальной памяти](../../advanced-basic/memory.md):

- В качестве модели чата по-прежнему можно выбрать MiniMax.
- Модель эмбеддингов нужно выбрать у другого провайдера.
- Эти два типа моделей не обязаны принадлежать одному провайдеру.
- После настройки отдельно запустите проверку состояния каждой модели.

## Проверка подключения

1. Убедитесь, что выбран правильный провайдер для материкового Китая или международной платформы.
2. Запустите проверку подключения в области API Key.
3. Выберите синхронизированную и включённую модель.
4. Запустите проверку состояния в списке моделей.
5. Вернитесь в чат и отправьте простое сообщение.
6. Затем отдельно проверьте длинный ответ, отображение мышления и MCP.

Успешная проверка подключения означает лишь, что базовые учётные данные работают. Она не подтверждает доступ ключа ко всем моделям или наличие квоты Token Plan.

## Частые вопросы

### Возвращается ошибка авторизации или код 1004

API Key недействителен, удалён либо ключ не соответствует провайдеру `.com` / `.io`. Проверьте регион провайдера и создайте новый ключ.

### Возвращается сообщение о недостаточном балансе или код 1008

Проверьте тип оплаты и учётную запись, где создан текущий ключ. Баланс с оплатой по факту использования и квоту Token Plan необходимо проверять отдельно.

### Возвращается ограничение частоты, 1002 или 1041

Запрос достиг ограничения частоты или параллельности. Уменьшите число параллельных запросов, сократите контекст и повторите попытку позднее. Если ошибка сохраняется, проверьте уровень учётной записи и официальные ограничения.

### Возвращается превышение Token или код 1039

Текущий чат, текст вложений и ожидаемый вывод превышают контекст модели. Создайте новый чат, сократите вложения и историю либо выберите модель с более длинным контекстом.

### В списке моделей остаются старые версии

Снова нажмите **Добавить**, чтобы синхронизировать список, и убедитесь, что Base URL не изменён на неверный. Если удалённый список ещё не возвращает новую модель, используйте встроенную модель или добавьте её вручную по полному официальному ID.

### У M3 нет кнопки мышления или изображения

Официальные возможности M3 новее текущих правил автоматического распознавания Cherry Studio. Сначала обновите клиент и повторите синхронизацию. Если элементы по-прежнему не отображаются, не переопределяйте тип модели принудительно, а дождитесь обновления поддержки.

### Вызов MCP прерывается или контекст нарушается

Сначала включите только один инструмент и убедитесь, что используется M3 или M2.7. Не удаляйте сообщение assistant перед вызовом инструмента; при необходимости создайте новый чат и повторите проверку.

Дополнительные настройки описаны на страницах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Возможности моделей см. в [MiniMax Models](https://platform.minimax.io/docs/guides/models-intro), а каналы обратной связи — на странице [Отзывы и предложения](../../question-contact/suggestions.md).
