# DeepSeek

Встроенный шаблон DeepSeek в Cherry Studio V2 предназначен для подключения к официальному API DeepSeek. Сейчас шаблон по умолчанию использует **OpenAI Chat Completions**, также содержит официальную совместимую конечную точку Anthropic и поддерживает переключатель мышления и интенсивность рассуждений DeepSeek V4.

{% hint style="info" %}
Чтобы сначала просто попробовать модель, используйте встроенный в Cherry Studio [бесплатный пробный доступ CherryAI](cherryin/README.md). Эта страница предназначена для пользователей с официальным DeepSeek API Key.
{% endhint %}

## Перед началом

- Учётная запись с доступом к [открытой платформе DeepSeek](https://platform.deepseek.com/)
- API Key, созданный в разделе [API Keys](https://platform.deepseek.com/api_keys)
- Доступный баланс или квота учётной записи
- Проверенные сведения о текущих моделях и изменениях официального API

Вход на сайте или в приложении DeepSeek не переносится в Cherry Studio автоматически. Для вызова официального API необходимо отдельно создать API Key.

## Настройка DeepSeek

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **deepseek**.
3. Введите DeepSeek API Key.
4. Оставьте Base URL по умолчанию: `https://api.deepseek.com`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите модели, которые планируете использовать.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно удалите его на открытой платформе DeepSeek и создайте новый.
{% endhint %}

## Выбор текущей модели

Официальный API DeepSeek сейчас предоставляет следующие основные ID моделей:

| ID модели | Подходящие задачи |
| --- | --- |
| `deepseek-v4-flash` | Повседневный чат, быстрые задачи и работа, чувствительная к задержке |
| `deepseek-v4-pro` | Сложные рассуждения, код, длинный контекст и задачи Agent |

Старые псевдонимы моделей `deepseek-chat` и `deepseek-reasoner` перестали предоставляться в июле 2026 года. Если прежняя конфигурация возвращает сообщение «Модель не существует», снова нажмите **Добавить**, синхронизируйте список и перейдите на текущие ID моделей V4.

{% hint style="warning" %}
Список и жизненный цикл моделей могут меняться. Ориентируйтесь на [документацию API DeepSeek](https://api-docs.deepseek.com/) и фактический результат синхронизации, а не на фиксированные названия моделей со старых снимков экрана.
{% endhint %}

## Настройка режима мышления

DeepSeek V4 поддерживает режимы с мышлением и без него, причём мышление включено по умолчанию. В кнопке мышления области ввода Cherry Studio отображаются следующие варианты:

- **По умолчанию**: используется поведение провайдера по умолчанию.
- **Выключить**: отправляется параметр, отключающий мышление.
- **Стараюсь думать**: используется интенсивность рассуждений DeepSeek `high`.
- **Сверхвысокое**: соответствует интенсивности рассуждений DeepSeek `max`.

`Сверхвысокое` обычно расходует больше времени на рассуждения и Token. Для повседневных вопросов начните со значения по умолчанию или отключения, а для сложного кода, планирования и задач Agent увеличьте интенсивность.

В режиме мышления некоторые параметры сэмплирования могут не действовать. Если результаты различаются, сначала оставьте параметры по умолчанию и изменяйте только переключатель и интенсивность мышления.

## Вызов инструментов и Agent

DeepSeek V4 поддерживает вызов инструментов в режиме мышления, а Cherry Studio сохраняет содержание рассуждений, необходимое для процесса вызова. Перед использованием проведите практический тест:

1. Включите один простой инструмент MCP.
2. Выберите `deepseek-v4-pro` или `deepseek-v4-flash`.
3. Сначала используйте интенсивность мышления по умолчанию.
4. Отправьте запрос, для которого явно требуется инструмент.
5. Убедитесь, что модель действительно вызывает инструмент, а не только выводит план вызова.

Если последовательные вызовы инструментов возвращают 400, сначала обновите Cherry Studio и список моделей, а затем проверьте, действительно ли шлюз является официальной конечной точкой DeepSeek.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую модель V4.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.
6. Отдельно проверьте режим мышления и вызов инструментов.

Успешная проверка подключения не означает, что у учётной записи неограниченная квота или доступны все модели.

## Базы знаний и модели эмбеддингов

Во встроенном шаблоне DeepSeek сейчас настроены только конечные точки чата; моделей эмбеддингов в нём нет. При использовании [глобальной памяти](../../advanced-basic/memory.md) или базы знаний:

- В качестве модели чата по-прежнему можно выбрать DeepSeek.
- Модель эмбеддингов необходимо выбрать у другого провайдера.
- Модель эмбеддингов и модель чата не обязаны принадлежать одному провайдеру.
- После настройки отдельно запустите проверку работоспособности каждой модели.

## Подключение совместимого шлюза DeepSeek

Если используется не официальный API DeepSeek:

1. Создайте [Пользовательского провайдера](zi-ding-yi-fu-wu-shang.md).
2. Выберите OpenAI Chat Completions или Anthropic Messages согласно документации шлюза.
3. Введите Base URL и API Key, предоставленные шлюзом.
4. Синхронизируйте или вручную добавьте ID моделей, фактически предоставляемых шлюзом.
5. Проверьте полную поддержку параметров мышления и вызова инструментов со стороны шлюза.

Не перезаписывайте официальный шаблон DeepSeek. Отдельный провайдер упрощает различение официальной учётной записи, сторонних названий моделей и протоколов.

## Частые вопросы

### Возвращается 401

API Key недействителен, удалён или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается ошибка баланса или квоты

Проверьте баланс, использование и состояние учётной записи на открытой платформе DeepSeek. Смена модели не позволяет обойти ограничения уровня учётной записи.

### Возвращается 404 или сообщение «Модель не существует»

Снова нажмите **Добавить**, синхронизируйте модели и убедитесь, что используется `deepseek-v4-flash` или `deepseek-v4-pro`. Старые псевдонимы больше не предоставляются.

### Возвращается 429 или сервер занят

Запрос достиг ограничения скорости или служба временно перегружена. Повторите попытку позже, уменьшите параллелизм или проверьте ограничения учётной записи.

### Кнопка мышления не показывает все варианты

Убедитесь, что ID модели соответствует текущему ID V4, и повторно синхронизируйте модели. При добавлении вручную не меняйте ID модели; отображаемое имя можно настроить.

### При вызове инструмента выводится только текст

Убедитесь, что модель поддерживает вызов инструментов, MCP включён и используется официальный Endpoint DeepSeek или шлюз с явной поддержкой полного протокола инструментов. Сначала проведите диагностику с одним простым инструментом.

Дополнительные общие настройки см. в разделах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Каналы обратной связи перечислены на странице [Отзывы и предложения](../../question-contact/suggestions.md).
