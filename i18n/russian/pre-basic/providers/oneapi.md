# OneAPI

OneAPI — это шлюз, преобразующий несколько вышестоящих каналов больших языковых моделей в API с совместимостью OpenAI. Администратор настраивает в OneAPI вышестоящие ключи, модели и маршрутизацию, а обычный пользователь подключает Cherry Studio с помощью токена, выданного OneAPI.

В Cherry Studio V2 нет отдельного встроенного провайдера OneAPI. OneAPI и NewAPI используют общий адаптер совместимости **New API**. Для стандартного экземпляра OneAPI обычно выбирают тип конечной точки модели **OpenAI Chat Completions**.

{% hint style="warning" %}
Запросы проходят через экземпляр OneAPI и его вышестоящие каналы. Используйте только развёрнутый вами сервис либо заведомо надёжный сервис, у которого есть законные права на вышестоящие сервисы и ответственность за соблюдение требований. Неизвестный общедоступный экземпляр может записывать запросы, раскрывать вложения или неверно рассчитывать оплату.
{% endhint %}

## Различия между OneAPI и NewAPI

OneAPI — более ранний проект единого шлюза. NewAPI продолжает развивать сходную архитектуру, добавляя больше нативных протоколов, типов конечных точек и метаданных моделей.

| Проект | Рекомендация для Cherry Studio |
| --- | --- |
| OneAPI | Использовать совместимый провайдер New API; по умолчанию обрабатывать запросы через OpenAI Chat Completions |
| NewAPI | Использовать специальный тип New API и выбирать для каждой модели Chat, Responses, Anthropic, Gemini, изображения или Rerank |

Если экземпляр доработан или использует пользовательскую тему, по внешнему виду страницы нельзя определить, к какому проекту он относится. Уточните у администратора версию сервера и поддерживаемые протоколы API.

## Сначала определите свою роль

Обычному пользователю нужны только адрес экземпляра и пользовательский токен. Администратор также должен обслуживать вышестоящие каналы:

| Роль | Подготовка |
| --- | --- |
| Обычный пользователь | Создать отдельный токен, проверить квоту, группу и разрешения моделей |
| Администратор | Настроить вышестоящие каналы, сопоставление моделей, коэффициенты, группы и переключение при сбое |

Не вводите ключ вышестоящего провайдера OpenAI, Anthropic или другого сервиса непосредственно в подключение OneAPI в Cherry Studio. Клиент должен использовать токен, выданный OneAPI.

## Создание токена в OneAPI

1. Войдите в надёжный экземпляр OneAPI.
2. Откройте страницу **Токены**.
3. Создайте отдельный токен для Cherry Studio.
4. При необходимости задайте имя, квоту, срок действия и доступные модели.
5. Скопируйте токен и сохраните его в безопасном месте.
6. Проверьте одну модель встроенными средствами OneAPI.

Не рекомендуется долго использовать общий токен по умолчанию. Отдельный токен упрощает аудит расхода, настройку лимита и индивидуальный отзыв.

{% hint style="danger" %}
Не помещайте токен OneAPI в сообщения чата, документацию, репозиторий кода или снимки экрана с описанием проблемы. Если токен раскрыт, немедленно удалите его в консоли OneAPI и создайте новый.
{% endhint %}

## Получение API Base URL

Официальный формат совместимости OneAPI с OpenAI обычно выглядит так:

```text
https://your-oneapi.example.com/v1
```

Адаптер совместимости New API в Cherry Studio добавляет `/v1` к корневому адресу сайта, поэтому подходят оба варианта:

- `https://your-oneapi.example.com`
- `https://your-oneapi.example.com/v1`

Для локального развёртывания или локальной сети также можно использовать:

- `http://localhost:3000`
- `http://192.168.1.20:3000`

Обратите внимание:

- `http` и `https` должны соответствовать фактической конфигурации сервера.
- Общедоступный сервис должен использовать действительный сертификат HTTPS.
- `/console/...`, страница входа и страница токенов — не API Base URL.
- Не вводите конкретный путь `/chat/completions`.

## Настройка в Cherry Studio

Если другие шлюзы NewAPI не используются, можно сразу настроить встроенный **New API**. Если уже подключён другой экземпляр, сначала скопируйте или добавьте совместимый провайдер New API, чтобы не перезаписать существующую конфигурацию.

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики**.
3. Выберите **New API** или добавьте провайдера на основе шаблона New API.
4. Измените имя на понятное название экземпляра OneAPI.
5. Введите пользовательский токен OneAPI.
6. Введите Base URL OneAPI.
7. Включите провайдера переключателем в верхней части страницы.
8. Нажмите **Добавить**, чтобы синхронизировать список моделей.
9. Для стандартной модели OneAPI установите тип конечной точки **OpenAI Chat Completions**.
10. Включите только те модели, которые собираетесь использовать.

Ответ `/models` OneAPI обычно не содержит `supported_endpoint_types` из новых версий NewAPI. Поэтому Cherry Studio может предложить выбрать тип конечной точки при пакетном добавлении — это нормально.

## Добавление модели

Предпочтительно синхронизируйте модели с сервера, а не копируйте названия из другого экземпляра.

Если синхронизация не удалась, модель можно добавить вручную:

1. В консоли OneAPI проверьте полный ID модели, видимый этому токену.
2. В Cherry Studio нажмите **Добавить модель**.
3. Введите точно такой же ID модели.
4. Выберите тип конечной точки **OpenAI Chat Completions**.
5. Сохраните и запустите проверку состояния.

Отображаемое имя модели можно изменить, однако фактический ID модели должен совпадать с доступной моделью OneAPI или именем в сопоставлении.

{% hint style="info" %}
OneAPI сопоставляет ID модели из запроса клиента с вышестоящей моделью. Если модель не найдена, одновременно проверьте ID в Cherry Studio, модель канала OneAPI и сопоставление, настроенное администратором.
{% endhint %}

## Границы возможностей

OneAPI главным образом приводит разные вышестоящие сервисы к формату с совместимостью OpenAI. Обычный чат, как правило, работает наиболее стабильно, но новые нативные возможности могут сохраняться не полностью.

- Нативный thinking block Claude может быть преобразован или потерян.
- Нативная мультимодальная структура Gemini может быть ограничена версией экземпляра.
- Возможности OpenAI Responses не равнозначны Chat Completions.
- Для вызова инструментов OneAPI и вышестоящий сервис должны правильно преобразовывать `tools` и `tool_calls`.
- Параметры провайдера, такие как веб-поиск, кеширование и уровень обслуживания, могут не работать.
- Видимость модели в списке не означает, что доступны все сочетания параметров.

Если рабочий процесс зависит от новой нативной возможности провайдера, предпочтительно используйте официальный сервис модели или новую версию NewAPI с поддержкой соответствующей нативной конечной точки.

## Вызов инструментов и MCP

Модель OneAPI с поддержкой Function Calling можно подключить к MCP, но сначала выполните минимальную проверку:

1. Выберите модель с явно заявленной поддержкой вызова инструментов.
2. Проведите один обычный обмен сообщениями.
3. Включите только один простой инструмент MCP.
4. Явно попросите модель вызвать этот инструмент.
5. Убедитесь, что запрос инструмента появился в журнале OneAPI.
6. Затем добавьте другие инструменты.

Если модель выводит только план вызова, вышестоящая модель может не поддерживать инструменты, преобразование OneAPI может быть неполным или канал удаляет поля инструментов. Сначала напрямую проверьте ту же модель в OneAPI.

## База знаний и модели эмбеддингов

Если экземпляр OneAPI предоставляет совместимый интерфейс Embeddings, модель эмбеддингов можно использовать в базе знаний или [глобальной памяти](../../advanced-basic/memory.md).

- Добавляйте только те модели эмбеддингов, которые действительно предоставляет экземпляр.
- Не используйте модель чата как модель эмбеддингов.
- Для чата и эмбеддингов можно использовать разных провайдеров.
- Отдельно запустите проверки состояния.
- Проверьте коэффициенты оплаты OneAPI и вышестоящего сервиса.

В старом экземпляре или отдельном канале интерфейс эмбеддингов может отсутствовать. Наличие имени модели не гарантирует доступность `/v1/embeddings`.

## PDF и вложения

OneAPI — агрегирующий шлюз. Cherry Studio не предполагает поддержку нативного PDF только по имени модели.

Текущая V2 сначала локально извлекает текст PDF, а затем отправляет его в OneAPI:

- PDF с текстовым слоем обычно можно обработать.
- Для сканированных документов сначала требуется OCR.
- Информация в таблицах, сложной вёрстке и изображениях может потеряться.
- Извлечённый текст расходует входные Token.
- Мультимодальные вложения, включая изображения, по-прежнему зависят от возможностей экземпляра и вышестоящего сервиса.

## Контрольный список администратора

Перед выдачей токена пользователю администратору рекомендуется проверить следующее:

1. Тест вышестоящего канала прошёл успешно.
2. Включённые в канале модели соответствуют фактическим разрешениям.
3. В сопоставлении моделей нет опечаток.
4. Группа пользователя имеет доступ к целевому каналу.
5. Коэффициенты модели и группы верны.
6. Ограничения токена соответствуют задачам пользователя.
7. `/v1/models` и `/v1/chat/completions` доступны.
8. Для критически важных моделей проверен вызов инструментов.

При балансировке нагрузки между несколькими каналами одна модель может маршрутизироваться к разным вышестоящим сервисам. Если требуется стабильное поведение, сократите число несовместимых каналов или попросите администратора закрепить канал поддерживаемым OneAPI способом.

## Проверка подключения

1. Проверьте тот же токен встроенным тестом OneAPI или совместимым запросом.
2. Запустите проверку подключения провайдера в Cherry Studio.
3. Нажмите **Добавить** и убедитесь, что список моделей синхронизируется.
4. Проверьте, что выбран тип конечной точки OpenAI Chat Completions.
5. Запустите проверку состояния модели.
6. Вернитесь в чат и отправьте простое сообщение.
7. Затем проверьте вызов инструментов, вложения или базу знаний.

Если запрос не работает и на сервере, в первую очередь проверьте канал OneAPI, токен и вышестоящий сервис. Если не работает только Cherry Studio, проверьте Base URL, ID модели и тип конечной точки.

## Частые вопросы

### Возвращается 401

Токен недействителен, удалён, просрочен или скопирован не полностью. Убедитесь, что введён пользовательский токен OneAPI, а не ключ вышестоящего провайдера.

### Возвращается 403

Токен не имеет разрешения на целевую модель, квота исчерпана или группа не может обратиться к доступному каналу. Обратитесь к администратору экземпляра.

### Возвращается 404

В Base URL введена административная страница или конкретный путь API либо экземпляр не предоставляет стандартный маршрут с совместимостью OpenAI. Верните корневой адрес сайта или `/v1`.

### Список моделей пуст

У токена нет видимых моделей, канал не включён, группа не совпадает или ответ `/models` этой версии экземпляра несовместим. Сначала выполните тест в OneAPI и проверьте `/v1/models`.

### Модель существует, но вызов завершается ошибкой

Проверьте сопоставление модели OneAPI и вышестоящий канал. Имя модели в списке — только точка входа; фактический маршрут может отсутствовать или не иметь разрешения.

### Нет содержимого мышления, веб-поиска или инструментов

Преобразование OneAPI в формат OpenAI могло не сохранить нативные поля провайдера. Сравните с простыми возможностями Chat Completions. Если нужны полные нативные возможности, используйте официальный сервис или соответствующую конечную точку NewAPI.

### Результаты запросов нестабильны

В разных каналах могут отличаться версии моделей, поддержка параметров или балансы. Попросите администратора проверить тесты каналов, приоритет, вес и состояние автоматического отключения.

Дополнительные настройки описаны на страницах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Если экземпляр на самом деле является NewAPI, перейдите к странице [NewAPI](newapi.md). О проекте OneAPI см. в [официальном репозитории](https://github.com/songquanpeng/one-api), а каналы обратной связи — на странице [Отзывы и предложения](../../question-contact/suggestions.md).
