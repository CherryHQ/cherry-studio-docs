# OpenRouter

OpenRouter — единый шлюз для нескольких моделей. Встроенный шаблон OpenRouter в Cherry Studio V2 позволяет синхронизировать модели чата и эмбеддингов OpenRouter с помощью одного API Key и адаптирован для содержания рассуждений, плагина веб-поиска и возможностей моделей.

{% hint style="warning" %}
OpenRouter не является разработчиком моделей. Запрос проходит через OpenRouter и может направляться нескольким вышестоящим провайдерам вывода. Перед использованием конфиденциальных данных проверьте в консоли OpenRouter политику конфиденциальности, журналирования и маршрутизации провайдеров.
{% endhint %}

## Перед началом

- Учётная запись с доступом к [OpenRouter](https://openrouter.ai/)
- API Key, созданный в разделе [OpenRouter Keys](https://openrouter.ai/settings/keys)
- Доступный баланс или квота бесплатных моделей
- Проверенные цены, контекст, инструменты и политика данных выбранной модели

Рекомендуется создать отдельный Key для Cherry Studio и задать в OpenRouter подходящий лимит расходов. Так проще различать использование и снизить риск при утечке Key.

## Настройка OpenRouter

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **OpenRouter**.
3. Введите OpenRouter API Key.
4. Оставьте Base URL по умолчанию: `https://openrouter.ai/api/v1/`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите только модели, которые планируете использовать.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно отзовите его в OpenRouter и создайте новый.
{% endhint %}

## Формат ID модели

ID модели OpenRouter обычно имеет формат `<организация>/<модель>`. Примеры:

| Тип | Пример |
| --- | --- |
| Фиксированная модель | `openai/gpt-oss-120b` |
| Последний псевдоним разработчика | `~anthropic/claude-sonnet-latest` |
| Автоматическая маршрутизация | `openrouter/auto` |
| Бесплатная маршрутизация | `openrouter/free` |
| Бесплатный вариант | Суффикс `:free` после конкретного ID модели |

- Полный ID модели определяет вышестоящую модель и поведение маршрутизации.
- Фактическая модель для `latest`, автоматической или бесплатной маршрутизации может меняться.
- Для воспроизводимых результатов выбирайте фиксированную версию, а не динамический псевдоним.
- Бесплатный вариант может иметь ограничения скорости, доступности или политики данных.
- Не определяйте цену и возможности только по отображаемому имени.

Нажатие **Добавить** синхронизирует текущие модели, поэтому включать несколько сотен моделей не требуется. Оставьте небольшое число моделей, которые действительно использует команда, чтобы упростить средство выбора моделей.

## Модели чата и эмбеддингов

Cherry Studio отдельно запрашивает API моделей чата и эмбеддингов OpenRouter и объединяет результаты синхронизации.

- Модели чата можно использовать в ассистентах, переводе и обычном чате.
- Модели с поддержкой вызова инструментов можно использовать для MCP или Agent.
- Модели эмбеддингов можно использовать для баз знаний и [глобальной памяти](../../advanced-basic/memory.md).
- Права, цены и ограничения разных моделей для одного Key могут различаться.
- Наличие модели в списке не означает доступность каждого вышестоящего провайдера.

При выборе модели для базы знаний убедитесь, что это действительно модель эмбеддингов, а не ориентируйтесь только на название разработчика.

## Настройка режима мышления

OpenRouter объединяет разные параметры рассуждений моделей в конфигурацию `reasoning`. Cherry Studio отправляет отключение, интенсивность или бюджет с учётом возможностей модели и сохраняет содержание рассуждений, необходимое для вызова инструментов между ходами.

- При выборе **По умолчанию** по возможности используется поведение OpenRouter или вышестоящего провайдера по умолчанию.
- При выборе **Выключить** поддерживаемой модели отправляется отключение рассуждений.
- Низкая, средняя и высокая интенсивность действует только для моделей, поддерживающих соответствующий уровень.
- Token рассуждений обычно учитываются в объёме вывода.
- Некоторые модели не возвращают видимое содержание рассуждений.

Изменение вариантов кнопки мышления после смены модели — нормальное поведение. Не применяйте конфигурацию рассуждений одной модели ко всем остальным.

## Использование веб-поиска

Если включить **Веб-поиск** в области ввода чата, текущая версия Cherry Studio V2 добавляет плагин Web Search к запросу OpenRouter и передаёт максимальное число результатов из настроек веб-поиска.

Порядок использования:

1. Выберите модель OpenRouter.
2. Включите **Веб-поиск** в области ввода.
3. Задайте вопрос, для которого требуется текущая информация из интернета.
4. Дождитесь завершения поиска и ответа модели.
5. Разверните и проверьте цитаты.

{% hint style="info" %}
Веб-поиск OpenRouter оплачивается дополнительно, даже если базовая модель относится к бесплатному варианту. OpenRouter переходит со старого Web-плагина на серверные инструменты поиска. Если веб-поиск внезапно перестал работать, сначала обновите Cherry Studio и проверьте последнюю документацию OpenRouter.
{% endhint %}

Модели со встроенным поиском, например Perplexity Sonar или OpenAI Search, могут вести себя иначе. Обязательность веб-поиска для самой модели также определяется возможностями OpenRouter и вышестоящего провайдера.

## Вызов инструментов и Agent

Встроенный шаблон OpenRouter содержит конечные точки OpenAI Chat Completions и Anthropic Messages, но фактические возможности инструментов зависят от модели и вышестоящей маршрутизации.

Перед использованием:

1. Выберите модель с явной поддержкой вызова инструментов.
2. Выполните проверку работоспособности обычного чата.
3. Включите один простой инструмент MCP.
4. Убедитесь, что модель действительно начинает вызов.
5. Затем добавьте несколько инструментов или длинную цепочку Agent.

Если Agent работает нестабильно, сравните результат с прямым подключением к разработчику модели, Anthropic или CherryIN. Единая точка входа OpenRouter удобна, но добавляет переменную вышестоящей маршрутизации.

## Конфиденциальность и вышестоящая маршрутизация

По умолчанию OpenRouter направляет запросы между доступными вышестоящими провайдерами для повышения доступности. Сейчас Cherry Studio не настраивает за пользователя все поля маршрутизации и конфиденциальности OpenRouter.

Проверьте в консоли OpenRouter:

- Включено ли журналирование ввода и вывода.
- Разрешено ли OpenRouter использовать ввод и вывод.
- Ограничены ли вышестоящие провайдеры, которые могут сохранять данные.
- Требуется ли Zero Data Retention.
- Разрешён ли fallback.
- Ограничения моделей и квоты организации или Key.

Эти параметры относятся к политике учётной записи OpenRouter и не меняются автоматически из-за того, что Cherry Studio является локальным клиентом.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую модель.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.
6. Затем отдельно проверьте рассуждения, веб-поиск и вызов инструментов.

Успешная проверка подключения подтверждает только пригодность основных учётных данных. Конкретная модель всё равно может завершиться ошибкой из-за баланса, сбоя вышестоящего провайдера, политики конфиденциальности или несовместимых параметров.

## Частые вопросы

### Возвращается 401

API Key недействителен, отозван или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается ошибка баланса или квоты

Проверьте баланс OpenRouter, лимит Key и политику организации. Бесплатные модели также могут иметь отдельные ограничения скорости.

### Возвращается 404 или сообщение «Модель не существует»

ID модели изменён, модель удалена или динамический псевдоним временно недоступен. Снова нажмите **Добавить**, синхронизируйте список и проверьте [OpenRouter Models](https://openrouter.ai/models).

### Возвращается 429

Текущая модель, вышестоящий провайдер или Key достигли ограничения скорости. Уменьшите параллелизм, повторите попытку позже или выберите другой доступный маршрут.

### Результат или цена одной модели меняется

Динамический псевдоним, автоматическая маршрутизация или вышестоящий fallback могут выбирать разные версии или провайдеров. Для стабильного поведения используйте фиксированный ID модели и ограничьте маршрутизацию в консоли OpenRouter.

### В веб-поиске нет цитат

Убедитесь, что веб-поиск включён в области ввода, и проверьте совместимость поиска OpenRouter с текущей версией Cherry Studio. Поисковый плагин и встроенный поиск модели используют разные механизмы.

### Вызов инструментов нестабилен

Убедитесь, что страница модели отмечает поддержку инструментов, а вышестоящий провайдер поддерживает все параметры запроса. Можно закрепить маршрут за конкретным провайдером или сравнить с прямым подключением к разработчику модели.
