# Google Gemini

Встроенный шаблон Gemini в Cherry Studio V2 предназначен для подключения к официальному API Google Gemini и по умолчанию использует нативную конечную точку **Google Generate Content**. После настройки API Key можно синхронизировать модели Gemini, доступные текущей учётной записи.

{% hint style="info" %}
Gemini API и Google Cloud Vertex AI — два разных способа подключения. На этой странице используется API Key, созданный в Google AI Studio. Если используются проект Google Cloud, регион и сервисная учётная запись, обратитесь к документации Vertex AI.
{% endhint %}

## Перед началом

- Учётная запись Google с доступом к Google AI Studio и Gemini API
- Соответствие вашего региона текущим [требованиям Google к доступным регионам](https://ai.google.dev/gemini-api/docs/available-regions)
- Ознакомление с условиями Gemini API и их принятие
- Действующий API Key и доступная квота модели

Google AI Studio может автоматически создать для нового пользователя проект Google Cloud и API Key по умолчанию. Пользователи с существующим проектом могут импортировать или выбрать его в AI Studio, не создавая новый проект специально для Cherry Studio.

## Создание API Key

1. Откройте [Google AI Studio API Keys](https://aistudio.google.com/app/apikey).
2. Войдите и выберите проект Google Cloud, который планируете использовать.
3. Создайте новый Gemini API Key.
4. Скопируйте Key и сразу сохраните в безопасном месте.
5. Вернитесь в Cherry Studio и завершите настройку.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. Google может заблокировать публично раскрытый Key или Key, не соответствующий требованиям ограничений. В случае утечки удалите его в AI Studio и создайте новый.
{% endhint %}

## Настройка Gemini

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **Gemini**.
3. Введите API Key, созданный в Google AI Studio.
4. Оставьте Base URL по умолчанию: `https://generativelanguage.googleapis.com`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите модели, которые планируете использовать.

Встроенный шаблон Gemini использует нативную конечную точку Google. Не меняйте её на OpenAI Chat Completions или OpenAI Responses для официального Gemini API.

## Синхронизация и выбор моделей

После нажатия **Добавить** Cherry Studio вызывает API списка моделей Gemini и показывает объединённые удалённые результаты и встроенную информацию о моделях.

- Включайте только действительно необходимые модели.
- Проверяйте полный ID модели, а не только отображаемое имя.
- Версии Stable, Preview, Latest и Experimental различаются стабильностью и жизненным циклом.
- Если API не возвращает нужную модель, нажмите **Пользовательский** и введите ID модели из официальной документации Google.
- Наличие модели в списке не означает, что текущий Key обязательно имеет право на вызов или оставшуюся квоту.

Google постоянно изменяет версии моделей. Ориентируйтесь на [документацию моделей Gemini](https://ai.google.dev/gemini-api/docs/models/gemini) и фактический результат синхронизации, а не на фиксированный список со старого снимка экрана.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую текстовую модель.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.

Если планируется использовать понимание или генерацию изображений, рассуждения либо вызов инструментов, отдельно протестируйте каждую возможность. Сходство названий моделей не означает полного совпадения возможностей и параметров запроса.

## Рассуждения и вызов инструментов

Cherry Studio отображает возможности рассуждений и инструментов согласно данным реестра моделей и преобразует параметры мышления для поддерживаемых моделей Gemini. Для использования также должны выполняться следующие условия:

- Текущая версия модели поддерживает соответствующую возможность.
- API Key имеет права и квоту для этой модели.
- Метки возможностей модели соответствуют фактической конечной точке.
- MCP или другие инструменты включены.
- Параметры запроса не превышают ограничения модели.

Если после обновления модели нарушились рассуждения или вызов инструментов, сначала повторно синхронизируйте модель, а затем отдельно проведите диагностику с простым диалогом и одним инструментом.

## Подключение совместимого шлюза Gemini

Если используется не официальный API Google Gemini:

1. Создайте [Пользовательского провайдера](zi-ding-yi-fu-wu-shang.md).
2. Установите Google Generate Content в качестве основной конечной точки.
3. Введите Base URL и API Key, предоставленные шлюзом.
4. Синхронизируйте или вручную добавьте модели, фактически предоставляемые шлюзом.
5. Запустите проверку подключения и проверку работоспособности моделей.

Отдельный пользовательский провайдер позволяет сохранить официальный шаблон Gemini и не смешивать пути шлюза или ID моделей с официальной конфигурацией.

## Частые вопросы

### Возвращается 400

Модель не поддерживает текущий параметр или запрос превышает ограничение ввода. Сначала протестируйте короткое текстовое сообщение, а затем постепенно включайте изображения, рассуждения и инструменты.

### Возвращается 401 или сообщение о недействительном API Key

Key скопирован не полностью, удалён или заблокирован. Проверьте его состояние в Google AI Studio. Если Key был публично раскрыт, создайте новый.

### Возвращается 403

Учётная запись, проект, регион или права на модель не соответствуют требованиям. Проверьте проект текущего Key, [доступные регионы](https://ai.google.dev/gemini-api/docs/available-regions) и состояние учётной записи Google.

### Возвращается 404 или сообщение «Модель не существует»

Снова нажмите **Добавить**, синхронизируйте модели и проверьте полный ID. Модели Preview, Latest или Experimental могли быть переименованы или сняты с обслуживания.

### Возвращается 429

Текущий проект или модель достигли ограничения скорости или квоты. Проверьте использование и состояние оплаты в Google AI Studio, повторите попытку позже или выберите модель с доступной квотой.

### Не удаётся синхронизировать модели

Убедитесь, что используется Gemini API Key из Google AI Studio и сохранён официальный Base URL. Можно также проверить, способен ли Key вывести список моделей, обратившись к официальному [API списка моделей](https://ai.google.dev/api/models).

Дополнительные общие настройки см. в разделах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Каналы обратной связи перечислены на странице [Отзывы и предложения](../../question-contact/suggestions.md).
