# CherryAI (бесплатный пробный доступ)

CherryAI — встроенная в Cherry Studio облачная пробная служба. Она включается автоматически вместе с приложением и не требует предварительного ввода API Key, поэтому сразу после установки можно быстро попробовать чат и выбор моделей.

{% hint style="info" %}
CherryAI — пробная служба внутри приложения, а [CherryIN](../cherryin-1.md) — провайдер моделей, для которого можно настроить API Key. Названия похожи, но точки входа, квоты и способы настройки различаются.
{% endhint %}

## Как сразу начать работу

1. Откройте [экран чата](../../../cherrystudio/preview/chat.md).
2. Нажмите название модели в области ввода или заголовке ассистента, чтобы открыть средство выбора моделей.
3. Найдите `CherryAI` или отфильтруйте доступные пробные модели по метке **Бесплатно**.
4. Выберите модель и отправьте сообщение.

Модели CherryAI отмечаются в средстве выбора моделей как пробная служба. Доступные модели могут меняться в зависимости от версии приложения и состояния службы, поэтому ориентируйтесь на фактический список в приложении.

## Почему CherryAI нет в разделе «Провайдеры моделей»

Это нормальное поведение. V2 добавляет CherryAI в качестве доступного источника моделей, но намеренно не показывает его в обычном списке провайдеров в разделе `Настройки → Провайдеры моделей`. Пользователь также не может изменять его API Key или Base URL.

Если вы хотите стабильно использовать собственную учётную запись и квоту, настройте CherryIN, официальный API разработчика модели, локальную модель или другой шлюз по инструкции [Провайдеры моделей](../README.md).

## Бесплатная квота

Запросы CherryAI расходуют пробную квоту. Когда она закончится, приложение покажет соответствующее уведомление. Вы можете:

- дождаться восстановления пробной квоты;
- переключиться на другую настроенную и включённую модель;
- перейти по подсказке к нужному провайдеру и настроить собственный API Key.

{% hint style="warning" %}
Бесплатная квота, время её восстановления и доступные модели могут меняться. Эта страница не гарантирует фиксированный объём квоты. Также не рекомендуется использовать пробную службу для рабочих задач, длительной автоматизации или как единственную доступную модель.
{% endhint %}

## Ограничения использования

- **Отсутствие настройки не означает работу без сети**: сообщения всё равно отправляются в облачный API CherryAI.
- **Возможности моделей различаются**: поддержку зрения, рассуждений, доступа к интернету и вызова инструментов проверяйте по меткам модели и фактическим ответам.
- **Страницу провайдера нельзя редактировать**: CherryAI отображается в средстве выбора моделей, но отсутствует в настройках провайдеров моделей — это предусмотренное поведение.
- **Пробные модели могут меняться**: если сохранённая в ассистенте модель стала недоступна, снова откройте средство выбора моделей и замените её.

## Совместное использование с собственными моделями

Сначала можно познакомиться с приложением с помощью CherryAI, а затем настроить собственного провайдера. После настройки:

1. Включите нужного провайдера и модель на странице провайдеров моделей.
2. Вернитесь в средство выбора моделей и выберите новую модель.
3. При необходимости укажите модели по умолчанию, для быстрых задач, перевода или создания названий тем в разделе [Настройки моделей по умолчанию](../../../cherrystudio/preview/settings/default-models.md).

Даже если пробная квота временно недоступна, вы сможете сразу переключиться на собственную модель.

Если CherryAI не отображается в средстве выбора моделей или запросы ко всем пробным моделям завершаются ошибкой, сначала проверьте подключение к сети и перезапустите приложение. Если проблема сохраняется, отправьте версию Cherry Studio, название операционной системы и текст ошибки без конфиденциальных данных. Каналы обратной связи перечислены на странице [Отзывы и предложения](../../../question-contact/suggestions.md).
