# ZhiPu GLM-4.5-Air

Cherry Studio распознаёт GLM-4.5-Air и его распространённые варианты у разных провайдеров. Стандартная модель распознаётся как модель для текстовых рассуждений и вызова инструментов. Фактическая доступность этих возможностей зависит от API провайдера и результатов тестирования.

{% hint style="warning" %}
Эта страница больше не гарантирует, что GLM-4.5-Air всегда входит в число бесплатных пробных моделей CherryAI или CherryIN. Возможность бесплатного использования и текущую доступность проверяйте в средстве выбора моделей, консоли провайдера и по фактическому результату запроса.
{% endhint %}

## Сначала проверьте доступность модели

1. Откройте средство выбора моделей на экране чата.
2. Найдите `GLM-4.5-Air`.
3. Проверьте провайдера модели и метки её возможностей.
4. Выберите модель и отправьте простое тестовое сообщение.

Если найдено несколько записей с одинаковым названием, различайте их по имени провайдера и полному ID модели.

## Подключение через провайдера

Если GLM-4.5-Air отсутствует в средстве выбора моделей:

1. Откройте `Настройки → Провайдеры моделей`.
2. Выберите ZhiPu или агрегирующего провайдера, который предоставляет эту модель для вашей учётной записи.
3. Введите API Key и проверьте Base URL.
4. Нажмите **Добавить** и примените изменения моделей.
5. Найдите и включите GLM-4.5-Air.
6. Запустите проверку подключения или проверку работоспособности модели.

Реестр моделей Cherry Studio содержит идентификаторы GLM-4.5-Air, используемые разными провайдерами. Эти сопоставления нужны для распознавания модели и не означают, что у вашей учётной записи обязательно есть доступ или бесплатная квота.

## Выбор подходящего варианта

Провайдер может предлагать стандартную версию, AirX, FP8 или запись с суффиксом `free`.

- Стандартная версия, AirX и FP8 — разные модели или развёртывания.
- `free` означает только то, что провайдер пометил ID модели как бесплатный, но не гарантирует постоянный бесплатный доступ.
- Контекст, скорость, вызов инструментов и управление рассуждениями у одноимённых моделей могут различаться в зависимости от конечной точки.
- Не копируйте ID модели от одного провайдера напрямую к другому.

{% hint style="danger" %}
Скопируйте ID модели из консоли или документации API текущего провайдера. Ручной ввод похожего, но фактически неподдерживаемого ID приведёт к ошибке 404 или сообщению «Модель не существует».
{% endhint %}

## Рассуждения и вызов инструментов

Если средство выбора моделей показывает поддержку рассуждений, в чате можно использовать настройки мышления Cherry Studio. Разные провайдеры могут управлять рассуждениями через параметры, варианты модели или подсказки. Cherry Studio выбирает подходящий способ согласно настройкам провайдера.

Для использования MCP или других инструментов:

1. Убедитесь, что у модели есть метка поддержки вызова инструментов.
2. Включите один простой инструмент с проверяемым результатом.
3. Отправьте чёткую инструкцию и проверьте, действительно ли модель начинает вызов.
4. Если модель выводит только план вызова, но не выполняет его, проверьте конечную точку провайдера и возможности модели.

## Частые вопросы

### Переключатель рассуждений отсутствует

Текущий провайдер или вариант модели может не поддерживать управляемые рассуждения. Повторно синхронизируйте модель и проверьте метки возможностей. Не судите только по названию модели.

### Неверный формат вызова инструментов

Смените конечную точку провайдера или вариант модели и повторите попытку. Агрегирующие шлюзы могут по-разному поддерживать параметры вызова инструментов.

### Возвращается 401, 403 или сообщение о недостаточном балансе

Проверьте API Key, права на модель, баланс учётной записи и региональные ограничения. Если пробная квота закончилась, настройте собственные учётные данные или смените модель.

### ID модели не существует

Удалите ошибочную запись, добавленную вручную, повторно синхронизируйте список или используйте полный ID модели из документации провайдера.

Общие правила бесплатного пробного доступа приведены на странице [CherryAI (бесплатный пробный доступ)](README.md), а процесс настройки провайдера — на странице [Провайдеры моделей](../README.md).
