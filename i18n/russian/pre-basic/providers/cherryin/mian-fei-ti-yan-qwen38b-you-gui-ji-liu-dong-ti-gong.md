# Qwen3-8B

Cherry Studio распознаёт Qwen3-8B у разных провайдеров. В некоторых версиях `Qwen/Qwen3-8B` предлагается как пробная модель внутри приложения, а точка входа службы ведёт к CherryIN. Другие провайдеры могут использовать тот же или другой ID модели.

{% hint style="warning" %}
Наличие модели в списке пробных не означает, что она останется бесплатной надолго. Ориентируйтесь на метку **Бесплатно** в средстве выбора моделей, консоль провайдера и фактический результат запроса.
{% endhint %}

## Сначала проверьте доступность модели

1. Откройте средство выбора моделей на экране чата.
2. Найдите `Qwen3-8B` или включите фильтр **Бесплатно**.
3. Проверьте провайдера модели.
4. Выберите модель и отправьте простое тестовое сообщение.

Если рядом с пробной меткой указано CherryIN, нажмите метку, чтобы открыть настройки соответствующего провайдера. Сам CherryAI не отображается в обычном списке провайдеров моделей.

## Подключение через провайдера

Если Qwen3-8B отсутствует в средстве выбора моделей:

1. Откройте `Настройки → Провайдеры моделей`.
2. Выберите ModelScope, OpenRouter или другого провайдера, который предоставляет эту модель для вашей учётной записи.
3. Введите API Key и проверьте Base URL.
4. Нажмите **Добавить** и примените изменения моделей.
5. Найдите и включите Qwen3-8B.
6. Запустите проверку подключения или проверку работоспособности модели.

Одни провайдеры используют `Qwen/Qwen3-8B`, другие — `qwen/qwen3-8b`. Регистр символов, пространство имён и суффиксы могут влиять на маршрутизацию.

## Добавление вручную, если синхронизация недоступна

Если провайдер не предоставляет API списка моделей, нажмите **Пользовательский** и скопируйте полный ID модели из консоли этого провайдера или документации API.

{% hint style="danger" %}
Не копируйте ID модели напрямую с другой платформы. Даже при одинаковом названии разные провайдеры могут использовать разные пространства имён, настройки возможностей или пути API.
{% endhint %}

## Рассуждения и вызов инструментов

Серия Qwen3 может поддерживать управляемые рассуждения. Cherry Studio использует параметр `enable_thinking` с учётом возможностей провайдера, а в API без поддержки этого параметра управляет режимом мышления совместимым способом.

Рекомендации по использованию:

- полагайтесь на настройки мышления, только если средство выбора моделей показывает поддержку рассуждений;
- перед использованием MCP или других инструментов проверьте метку вызова инструментов и выполните один простой тест;
- не добавляйте `/think` или `/no_think` вручную во все подсказки, а используйте настройки мышления Cherry Studio;
- если одноимённую модель предоставляют разные провайдеры, отдельно проверяйте рассуждения и вызов инструментов у каждого.

## Частые вопросы

### Qwen3-8B отсутствует в фильтре «Бесплатно»

В текущей версии или регионе эта пробная модель может не предоставляться. Вы по-прежнему можете настроить поддерживающего её провайдера и использовать собственный API Key.

### Нажатие пробной метки открывает CherryIN

Это предусмотренное поведение. V2 направляет точку входа для определённых пробных моделей Qwen в CherryIN, чтобы после окончания пробной квоты можно было настроить провайдера.

### Режим мышления не меняется

Проверьте, поддерживает ли провайдер `enable_thinking` и позволяет ли текущий вариант модели переключать рассуждения. Некоторые конечные точки игнорируют неподдерживаемые параметры.

### Возвращается сообщение «Модель не существует»

Проверьте регистр символов и полный ID модели, затем повторно синхронизируйте список. Для записи, добавленной вручную, укажите ID текущего провайдера.

Общие правила бесплатного пробного доступа приведены на странице [CherryAI (бесплатный пробный доступ)](README.md), а процесс настройки провайдера — на странице [Провайдеры моделей](../README.md).
