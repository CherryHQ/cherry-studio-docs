# ModelScope (魔搭)

ModelScope предоставляет некоторые открытые модели как готовые онлайн-API через API-Inference. В Cherry Studio V2 встроен провайдер ModelScope, поддерживающий совместимый с OpenAI чат, модели зрения, модели эмбеддингов и асинхронную генерацию изображений.

Base URL по умолчанию:

```text
https://api-inference.modelscope.cn/v1/
```

{% hint style="info" %}
Не все модели библиотеки ModelScope поддерживают API-Inference. Напрямую подключить к Cherry Studio можно только модель, на странице которой есть отметка API-Inference и пример вызова.
{% endhint %}

## Проверка перед использованием

Сейчас для бесплатного API-Inference ModelScope требуется:

1. Зарегистрироваться и войти в ModelScope.
2. Привязать учётную запись Alibaba Cloud.
3. Пройти проверку настоящего имени соответствующей учётной записи Alibaba Cloud.
4. Создать ModelScope Access Token.
5. Использовать модель, которая сейчас поддерживает API-Inference.

API-Inference — бесплатный сервис для ознакомления без производственного SLA. Для коммерческого, высокопараллельного или стабильного сервиса используйте коммерческого провайдера API либо разверните модель самостоятельно.

## Получение Access Token

1. Войдите в [ModelScope](https://modelscope.cn/).
2. Откройте [токены доступа](https://modelscope.cn/my/myaccesstoken).
3. Создайте токен и укажите понятное имя.
4. Скопируйте созданный Access Token.
5. Сохраните Token в безопасном месте.

{% hint style="danger" %}
Access Token равнозначен учётным данным. Не помещайте его в чат, документацию, репозиторий кода или снимки экрана с проблемой. При утечке немедленно удалите токен в ModelScope и создайте новый.
{% endhint %}

## Настройка в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики**.
3. Выберите **ModelScope 魔搭**.
4. Вставьте Access Token в поле API Key.
5. Сохраните Base URL `https://api-inference.modelscope.cn/v1/`.
6. Включите провайдера переключателем в верхней части страницы.
7. Нажмите **Добавить** или синхронизируйте модели.
8. Проверьте предварительный результат и примените изменения.
9. Включите только нужные модели.
10. Запустите проверку состояния модели.

Если в синхронизированном списке есть старая модель, не считайте её автоматически доступной. По мере выпуска новых моделей ModelScope изменяет или отключает старые; проверьте состояние API-Inference на странице модели.

## Поиск доступной модели

1. Откройте [библиотеку моделей ModelScope](https://modelscope.cn/models).
2. Отфильтруйте модели с поддержкой **API-Inference**.
3. Откройте страницу модели.
4. Убедитесь, что справа есть вход API и пример вызова.
5. Скопируйте полный Model ID.
6. Синхронизируйте или вручную добавьте этот ID в Cherry Studio.
7. Запустите проверку состояния.

Model ID обычно содержит организацию и имя модели, например:

```text
Qwen/Qwen3.5-35B-A3B
```

Регистр, косая черта и суффикс являются частью ID. Не используйте отображаемое имя, URL репозитория или имя локального файла как API Model ID.

{% hint style="warning" %}
Встроенный список V2 — только набор кандидатов; приоритет имеет текущее состояние платформы. При 404 или недоступности модели сначала проверьте страницу ModelScope и не повторяйте запрос к отключённой модели.
{% endhint %}

## Модели чата

LLM API-Inference ModelScope использует совместимый с OpenAI Chat Completions. Убедитесь, что выбрана модель чата или инструктивная модель, а не базовая, Embedding или модель генерации изображений.

Рекомендуемый порядок проверки:

1. Отправьте короткое текстовое сообщение.
2. Проверьте потоковый вывод.
3. Добавьте системный запрос.
4. Проверьте длинный контекст.
5. В конце проверьте мышление, изображения или инструменты.

Параметры и шаблоны запросов открытых моделей могут различаться. ModelScope рекомендует ориентироваться на пример API на странице конкретной модели, особенно для моделей мышления.

## Модели зрения

Модель зрения может получать URL изображения или Base64-изображение в совместимом с OpenAI сообщении.

В Cherry Studio:

1. Выберите Model ID с явно заявленной поддержкой зрения.
2. Убедитесь, что у модели отображается возможность изображений.
3. Сначала загрузите одно небольшое изображение.
4. Проверьте, действительно ли модель понимает изображение.
5. Затем попробуйте несколько изображений или высокое разрешение.

Одинаковое название серии не означает поддержку зрения всеми вариантами. Изображение также расходует больше контекста и бесплатной квоты.

## Мышление и вызов инструментов

### Мышление

Модель мышления может использовать собственные параметры или формат ответа. Если после изменения параметра мышления возникает ошибка:

1. Верните значение **По умолчанию**.
2. Удалите пользовательские параметры.
3. Сравните с примером на странице модели.
4. Повторите проверку состояния.

### MCP и вызов инструментов

Для MCP Cherry Studio модель должна выводить структурированный Tool Calling.

1. Сначала проведите обычный чат.
2. Включите только один простой инструмент MCP.
3. Явно попросите выполнить вызов.
4. Проверьте, что структурированный вызов действительно создан.
5. Убедитесь, что результат возвращается модели.
6. Затем добавьте инструменты.

Площадка MCP ModelScope и сервис моделей ModelScope — разные возможности. Access Token модели может использоваться для соответствующих возможностей платформы, но в Cherry Studio «Провайдеры моделей» и «Серверы MCP» всё равно настраиваются отдельно.

## Генерация и редактирование изображений

Cherry Studio V2 реализует для ModelScope специальный асинхронный процесс генерации:

1. Отправляет задачу в `/v1/images/generations`.
2. Получает `task_id`.
3. Опрашивает `/v1/tasks/{task_id}`.
4. После успеха считывает URL изображения.

После выбора AIGC-модели, которую сейчас поддерживает ModelScope, на странице рисования доступны:

- размер изображения;
- негативный запрос;
- число шагов сэмплирования;
- Guidance;
- Seed;
- вход изображения для редактирования у поддерживаемой модели;
- LoRA у поддерживаемой модели.

Поддерживаемые размеры, шаги, Guidance и возможности редактирования различаются. Ориентируйтесь на диапазоны страницы модели.

Задача изображения выполняется асинхронно, поэтому ожидание может быть заметно дольше чата. Отмена задачи, обрыв сети, нехватка квоты или высокая нагрузка платформы могут нарушить опрос.

## Модели эмбеддингов и база знаний

Провайдер ModelScope в Cherry Studio реализует совместимый с OpenAI вызов Embeddings, но использовать можно только модель ModelScope, которая фактически предоставляет совместимый Embedding API.

1. Проверьте тип задачи и пример API на странице модели.
2. Добавьте полный Model ID.
3. Убедитесь, что Cherry Studio распознаёт модель как модель эмбеддингов.
4. Определите размерность в базе знаний.
5. Запустите проверку состояния.
6. Затем импортируйте документы.

После использования модели или размерности в существующей базе знаний не меняйте её без необходимости, иначе обычно требуется перестроить векторный индекс.

## PDF и вложения

Текущая V2 сначала локально извлекает текст PDF, затем отправляет его модели чата ModelScope:

- PDF с текстовым слоем обычно обрабатывается.
- Для сканированного документа сначала нужен OCR.
- Таблицы, сложная вёрстка и изображения могут потеряться.
- Извлечённый текст расходует контекст и бесплатную квоту вызовов.
- Изображения PDF нужно отдельно отправлять модели зрения.

ModelScope — облачный сервис. Перед загрузкой убедитесь, что документ соответствует требованиям конфиденциальности и безопасности организации.

## Квота и ограничения

Текущие правила бесплатного API-Inference ModelScope включают:

- не более 2,000 вызовов в день суммарно для зарегистрированного пользователя;
- обычно не более 200 вызовов в день для одной модели;
- для некоторых крупных моделей — 100 или меньше вызовов в день;
- параллельность динамически меняется с нагрузкой платформы;
- AIGC-модели могут иметь отдельные ограничения;
- квота конкретной модели может динамически измениться в любое время.

Заголовки ответа сервиса могут содержать:

| Заголовок ответа | Значение |
| --- | --- |
| `modelscope-ratelimit-requests-limit` | Общая дневная квота пользователя |
| `modelscope-ratelimit-requests-remaining` | Оставшаяся дневная квота пользователя |
| `modelscope-ratelimit-model-requests-limit` | Дневная квота текущей модели |
| `modelscope-ratelimit-model-requests-remaining` | Оставшаяся квота текущей модели |

Сейчас Cherry Studio не показывает эти заголовки как полноценную страницу оплаты. Оценивайте квоту по ошибкам, странице ModelScope и последним правилам платформы.

Не обходите ограничения платформы созданием или переключением резервных учётных записей. Бесплатная квота предназначена для ознакомления и прототипов; пакетные вызовы следует перенести в подходящий коммерческий сервис.

## API-Inference и API-Provider

ModelScope также предоставляет API-Provider для привязки внешнего провайдера API. Источник квоты и оплаты отличается от бесплатного API-Inference.

- API-Inference: ModelScope предоставляет ознакомительные ресурсы вывода.
- API-Provider: вызывает привязанного внешнего провайдера; не ограничен той же бесплатной квотой API-Inference, но подчиняется оплате и ограничениям внешнего сервиса.

Конфигурация `api-inference.modelscope.cn` по умолчанию на этой странице указывает на API-Inference. Не смешивайте учётные данные внешнего провайдера, не понимая источник оплаты.

## Частые вопросы

### Возвращается 401

Access Token неверен, удалён, содержит пробелы или отправлен неправильно. Скопируйте Token заново и убедитесь, что прокси не изменил Base URL.

### Возвращается 403

Возможно, учётная запись Alibaba Cloud не привязана, проверка настоящего имени не завершена или разрешение модели ограничено. Сначала выполните требования учётной записи на сайте ModelScope.

### Возвращается 404

ID модели неверен, модель отключена или Base URL неправильный. Проверьте полный ID и состояние API-Inference на странице модели.

### Возвращается 429

Возможно, достигнута общая пользовательская квота, квота модели, отдельная квота AIGC или динамическое ограничение параллельности. Уменьшите частоту и дождитесь восстановления; для производства используйте коммерческий сервис.

### Список моделей пуст

Проверьте Token, Base URL и сеть. Также можно скопировать со страницы модели полный поддерживаемый Model ID и добавить вручную.

### Модель из шаблона не работает

Шаблон V2 может быть старше отключения или переименования на платформе. Ориентируйтесь на текущую страницу ModelScope, повторно синхронизируйте или выберите поддерживаемую модель.

### Генерация изображения продолжает ожидать

Задача всё ещё в очереди, платформа загружена, сетевой опрос завершился ошибкой или квоты недостаточно. Проверьте состояние задачи ModelScope и уменьшите параллельность.

### Ошибка параметра редактирования изображения

Целевая модель может не поддерживать редактирование, размер входа может не соответствовать требованиям или нужен конкретный `image_url`. Сравните с примером и диапазоном параметров на странице модели.

### MCP не работает

Сначала убедитесь, что модель поддерживает инструменты. Сервис площадки MCP ModelScope также нужно отдельно синхронизировать или добавить в настройках MCP Cherry Studio.

### Нужна стабильная высокая параллельность

Бесплатный API-Inference не подходит для SLA или коммерческой высокой параллельности. Используйте ModelScope API-Provider, другой коммерческий модельный сервис или разверните открытую модель.
