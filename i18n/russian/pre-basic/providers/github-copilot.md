# GitHub Copilot

Cherry Studio может подключиться к вашей учётной записи Copilot через авторизацию устройства GitHub и получить доступные сейчас модели. Создавать API Key вручную не требуется, но учётная запись GitHub должна иметь действующее право на использование Copilot.

{% hint style="info" %}
GitHub Copilot, GitHub Models и GitHub Copilot CLI — три разных способа доступа. На этой странице описан раздел `Настройки → Провайдеры моделей → GitHub Copilot`, который позволяет вызывать модели Copilot в чатах Cherry Studio.
{% endhint %}

## Проверка перед использованием

Перед началом убедитесь в следующем:

1. У вас есть учётная запись GitHub, в которую можно войти.
2. Для неё включён Copilot Free, Student, Pro, Pro+ или Max либо организация предоставила разрешение Business / Enterprise.
3. Политика организации или предприятия не запрещает нужные модели или возможности Copilot.
4. Текущая сеть имеет доступ к входу GitHub и сервисам Copilot.
5. Вы понимаете доступный в текущем плане набор моделей и правила [GitHub AI Credits](https://docs.github.com/en/copilot/concepts/billing).

Модели, квоты и правила оплаты разных планов могут меняться. Cherry Studio синхронизирует через интерфейс Copilot модели, которые сейчас видны учётной записи и не запрещены политикой. Не ориентируйтесь на фиксированные списки из старых инструкций.

GitHub Copilot Free и Student сейчас в основном предоставляют ограниченный доступ к моделям через автоматический выбор. Платные и организационные планы предлагают больше моделей, но выбор по-прежнему зависит от учётной записи, региона, политики организации и текущего состояния выпуска GitHub.

## Авторизация в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики**.
3. Выберите **GitHub Copilot**.
4. Нажмите **Начать авторизацию**.
5. Подождите, пока Cherry Studio создаст Device Code.
6. Скопируйте код авторизации. Обычно приложение копирует его автоматически, но можно сделать это вручную.
7. Нажмите **Открыть страницу авторизации**.
8. В браузере войдите в учётную запись GitHub, которую хотите использовать.
9. Введите Device Code и подтвердите авторизацию.
10. Вернитесь в Cherry Studio.
11. Нажмите **Подключить GitHub**, чтобы завершить подключение.

После успешного подключения на странице появятся имя пользователя GitHub и аватар, а провайдер включится автоматически.

{% hint style="warning" %}
Учётная запись, уже открытая в браузере, может отличаться от той, которую вы хотите подключить. Перед авторизацией проверьте имя пользователя, особенно при переключении между личной, рабочей и управляемой предприятием учётными записями.
{% endhint %}

## Что происходит во время авторизации

Cherry Studio использует GitHub Device Flow:

1. Запрашивает у GitHub временный Device Code.
2. Пользователь подтверждает авторизацию на странице GitHub.
3. Обменивает результат авторизации на токен доступа GitHub.
4. Получает временный токен для запросов Copilot.
5. Шифрует токен доступа GitHub средствами безопасного системного хранилища и сохраняет его локально.
6. При последующей синхронизации моделей или чатах обновляет токен Copilot.

Поэтому сообщение об успешной авторизации на странице GitHub — только первый этап. Чтобы показать успешное подключение, Cherry Studio также должна получить токен Copilot.

{% hint style="danger" %}
Не передавайте другим Device Code, токен доступа или токен Copilot и не помещайте их в документацию, чаты, репозитории кода или снимки экрана. Код авторизации временный, но им всё равно можно злоупотребить до истечения срока.
{% endhint %}

## Синхронизация моделей

После успешной авторизации:

1. Убедитесь, что провайдер GitHub Copilot включён.
2. Нажмите **Добавить** или синхронизируйте модели.
3. Проверьте предварительный результат синхронизации.
4. Примените изменения.
5. Включите только нужные модели.
6. Запустите проверку состояния каждой модели.

Cherry Studio обращается к интерфейсу Copilot `/models` и отфильтровывает:

- модели, отмеченные политикой GitHub как недоступные;
- записи, которые не являются прямыми моделями, например маршрутизацию учётной записи;
- модели речи, транскрипции и другие, пока не подходящие для списка чата.

Внезапное появление, исчезновение или переименование моделей обычно вызвано изменением плана GitHub, политики организации или серверного выпуска. Повторная синхронизация загружает текущий список.

## Планы, модели и стоимость

Использование GitHub Copilot учитывается в учётной записи GitHub и не становится бесплатным из-за запуска из Cherry Studio.

- Разные планы включают разное количество GitHub AI Credits.
- Расход модели зависит от входа, выхода, кешированных token и цены модели.
- Организация или предприятие может задать общую квоту, бюджет пользователя и дополнительные ограничения.
- После исчерпания квоты вызовы могут блокироваться или оплачиваться дополнительно.
- Некоторые старые годовые планы до окончания срока могут использовать прежний учёт premium request.

Наличие модели в Cherry Studio не означает одинаковую стоимость в вашем плане. Перед использованием проверьте выставление счетов GitHub и страницу использования Copilot.

## Ограничение частоты

На странице провайдера GitHub Copilot есть ползунок **Ограничение частоты** от 1 до 60 со значением по умолчанию 10. Он задаёт в секундах минимальную паузу между последовательными запросами Cherry Studio к этому провайдеру.

- Для обычного чата сначала сохраните значение по умолчанию.
- При ограничении частоты увеличьте значение.
- Для быстрых последовательных тестов его можно уменьшить, но это не обходит серверное ограничение GitHub.
- Несколько окон, автоматические задачи и параллельные запросы всё равно могут суммарно достичь лимита учётной записи.

GitHub также применяет серверные ограничения на основе ёмкости, справедливого использования и защиты от злоупотреблений. При ограничении подождите и повторите запрос, проверьте расход и план, а не отправляйте запросы непрерывно.

## Выбор модели и возможностей

### Обычный чат

Выберите доступную сейчас модель из списка и отправьте короткое сообщение. После успешной проверки обычного чата тестируйте длинный контекст, изображения и инструменты.

### Обработка изображений

Cherry Studio добавляет к запросам Copilot заголовок поддержки зрения, но фактическая обработка изображений зависит от модели и разрешений учётной записи.

1. Выберите модель с явно заявленной поддержкой изображений.
2. Загрузите одно небольшое изображение.
3. Убедитесь, что модель действительно понимает его содержимое.
4. Затем проверьте несколько изображений или изображения высокого разрешения.

Возможности одной модели могут измениться после обновления GitHub. Ориентируйтесь на текущую проверку состояния и фактический результат.

### MCP и вызов инструментов

Для MCP Cherry Studio модель должна поддерживать структурированный Tool Calling.

1. Сначала проведите обычный чат.
2. Включите только один простой инструмент MCP.
3. Явно попросите модель вызвать его.
4. Проверьте, что структурированный вызов действительно создан.
5. Убедитесь, что после возврата результата инструмента модель продолжает отвечать.
6. Затем постепенно добавляйте инструменты.

Доступ учётной записи к Copilot не означает поддержку инструментов всеми видимыми моделями. Если модель только описывает намерение вызвать инструмент, но не делает этого, выберите модель с более сильными возможностями инструментов.

### Мышление и параметры

Разные модели Copilot используют разные параметры рассуждений. Cherry Studio применяет настройки по распознанной модели, однако серверное обновление может опередить правила распознавания клиента.

При ошибке параметра:

1. Верните параметр мышления к значению **По умолчанию**.
2. Удалите пользовательские параметры.
3. Повторно синхронизируйте модели.
4. Повторите проверку состояния.
5. Затем включайте необходимые параметры по одному.

## PDF и вложения

Текущая V2 сначала локально извлекает текст PDF, а затем отправляет его модели через совместимый с OpenAI интерфейс Copilot:

- PDF с текстовым слоем обычно обрабатывается.
- Для сканированного документа сначала нужен OCR.
- Таблицы, сложная вёрстка и изображения могут потеряться.
- Извлечённый текст расходует контекст и GitHub AI Credits.
- Изображения из PDF нужно отдельно отправлять модели зрения.

Перед загрузкой файла убедитесь, что его содержимое соответствует требованиям организации по использованию и конфиденциальности данных. Copilot — облачный сервис, не рассматривайте его как локальную офлайн-модель.

## Организационные и корпоративные учётные записи

Организация или предприятие может управлять возможностями Copilot, моделями и сетевым доступом. Даже если учётной записи назначен Copilot, политика может запретить некоторые модели.

При проблеме с организационной учётной записью попросите администратора проверить:

- назначено ли пользователю место Copilot;
- включены ли Copilot Chat и соответствующие модели;
- есть ли ограничения политики на уровне моделей;
- не исчерпаны ли бюджет или GitHub AI Credits;
- разрешает ли корпоративная сеть только определённые конечные точки подписки Copilot;
- не блокируют ли GitHub Copilot брандмауэр, прокси или проверка TLS.

Политика организации применяется к нескольким способам доступа с этой идентификацией, а не только к Cherry Studio.

## Прокси и сеть

Для авторизации и вызова моделей необходим доступ как минимум к входу GitHub, GitHub API и сервисам Copilot. Корпоративный прокси, брандмауэр, VPN или защитное ПО могут разрешать только часть адресов, что приводит к следующему:

- Device Code не создаётся.
- Авторизация в браузере успешна, но Cherry Studio не подключается.
- Сведения о пользователе доступны, но токен Copilot получить не удаётся.
- Список моделей пуст.
- Запрос чата завершается по тайм-ауту или отклоняется.

Предпочтительно используйте поддерживаемый сейчас системный или HTTP-прокси Cherry Studio и попросите сетевого администратора разрешить нужные адреса по [GitHub Copilot allowlist](https://docs.github.com/en/copilot/reference/copilot-allowlist-reference).

Не добавляйте без необходимости пользовательские заголовки неизвестного происхождения. Редактор заголовков на странице GitHub Copilot предназначен в основном для особых прокси и сценариев совместимости. Неверные `Authorization`, `Host`, идентификатор клиента или заголовок маршрутизации могут нарушить авторизацию.

## Выход и смена учётной записи

Чтобы сменить учётную запись:

1. На странице провайдера GitHub Copilot нажмите **Выйти из GitHub**.
2. Убедитесь, что имя пользователя и аватар исчезли.
3. Переключитесь в браузере на нужную учётную запись GitHub.
4. Повторите авторизацию устройства.
5. Повторно синхронизируйте модели.

Выход в Cherry Studio удаляет локально сохранённые учётные данные Copilot и ключ провайдера, но не отзывает OAuth-авторизацию в учётной записи GitHub. Если устройство потеряно или есть подозрение на утечку, также отзовите доступ в настройках авторизованных приложений GitHub и проверьте журнал безопасности учётной записи.

## Частые вопросы

### Не удалось получить Device Code

Проверьте сеть, прокси, брандмауэр и состояние сервисов GitHub. Убедитесь, что системное время верно, отключите защитное ПО, которое может перехватывать запросы входа GitHub, и повторите попытку.

### Страница GitHub авторизована, но подключение не выполнено

Cherry Studio ещё не получила токен GitHub или Copilot. Вернитесь в приложение и нажмите **Подключить GitHub**. При тайм-ауте создайте новый Device Code и не используйте старый повторно.

### Имя пользователя отображается, но модели не синхронизируются

Действительный вход GitHub не означает наличия права Copilot. Проверьте план Copilot, место организации, политику моделей и квоту, затем выйдите и авторизуйтесь снова.

### Список моделей пуст

У учётной записи может быть доступ только к автоматическому выбору моделей, организация могла отключить модели или сеть блокирует запрос Copilot `/models`. Сначала убедитесь, что учётная запись работает на официальной странице GitHub Copilot, затем повторите синхронизацию.

### Модель внезапно исчезла

GitHub мог изменить состояние выпуска модели, диапазон плана или политику организации. Повторно синхронизируйте и проверьте текущий список моделей GitHub.

### Возвращается 401 или 403

Учётные данные истекли, авторизация отозвана, у учётной записи нет права Copilot или доступ запрещён политикой организации. Выйдите и авторизуйтесь снова; если ошибка сохраняется, проверьте план и политику администратора.

### Возвращается 429 или ограничение частоты

Подождите и повторите запрос, увеличьте значение ограничения частоты Cherry Studio и проверьте GitHub AI Credits, бюджет и серверные ограничения.

### Недоступны изображения или MCP

Убедитесь, что выбранная модель поддерживает соответствующую возможность. Успешный обычный чат не доказывает поддержку зрения или инструментов.

### Не работает в корпоративной сети

Попросите сетевого администратора проверить Copilot allowlist, домены подписки, авторизацию прокси и проверку TLS. Не отключайте все политики безопасности для решения проблемы.

Планы, расход и политика Copilot описаны в [официальной документации GitHub Copilot](https://docs.github.com/en/copilot), а каналы обратной связи — на странице [Отзывы и предложения](../../question-contact/suggestions.md).
