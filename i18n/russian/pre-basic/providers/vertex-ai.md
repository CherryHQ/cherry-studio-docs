# Vertex AI

Встроенный шаблон Vertex AI в Cherry Studio V2 подключается к Vertex AI с помощью **Service Account** Google Cloud. Для него требуются ID проекта, местоположение, email клиента и приватный ключ Service Account; Gemini API Key не используется.

V2 позволяет вызывать модели Gemini в Vertex AI, а для доступных моделей Claude выбирать маршрут Vertex Anthropic. Фактическая доступность зависит от проекта, местоположения, прав и наличия модели в Model Garden.

{% hint style="info" %}
Gemini API Key из Google AI Studio нельзя напрямую использовать для настройки на этой странице. Если у вас есть только Gemini API Key, используйте провайдера [Google Gemini](google-gemini.md).
{% endhint %}

## Перед началом

Выполните следующие действия в Google Cloud:

- Выберите или создайте проект Google Cloud.
- Включите оплату для проекта.
- Включите Vertex AI API.
- Создайте отдельную Service Account для Cherry Studio.
- Предоставьте этой учётной записи минимальные права, необходимые для вызова целевой модели.
- Создайте и безопасно скачайте JSON-ключ Service Account.
- Уточните Location, в котором доступна целевая модель.

Официальное краткое руководство Google обычно требует, чтобы вызывающая сторона имела право **Vertex AI User** (`roles/aiplatform.user`). В корпоративном проекте могут использоваться пользовательские роли IAM; администратор должен предоставить права согласно политике организации.

Полезные страницы:

- [Краткое руководство по Vertex AI](https://cloud.google.com/vertex-ai/generative-ai/docs/start/quickstart)
- [Service Accounts](https://console.cloud.google.com/iam-admin/serviceaccounts)
- [Vertex AI Model Garden](https://console.cloud.google.com/vertex-ai/model-garden)

## Получение полей из JSON-ключа

Сейчас в Cherry Studio необходимо вручную заполнить следующие поля:

| Поле Cherry Studio | Значение из Service Account JSON или Google Cloud |
| --- | --- |
| Email клиента | `client_email` |
| Приватный ключ | `private_key`, включая полные строки BEGIN/END |
| ID проекта | `project_id` |
| Местоположение | Location, в котором фактически доступна целевая модель, например `us-central1` |

При копировании приватного ключа сохраните исходные переносы строк, а также `-----BEGIN PRIVATE KEY-----` и `-----END PRIVATE KEY-----`.

{% hint style="danger" %}
Приватный ключ Service Account — особо конфиденциальные учётные данные. Не добавляйте полный JSON, `private_key` или страницу настроек клиента в сообщения чата, документы, репозитории кода и снимки экрана с описанием проблемы. В случае утечки немедленно удалите этот ключ в Google Cloud и создайте новый.
{% endhint %}

## Настройка Vertex AI

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **VertexAI**.
3. В поле **Email клиента** введите значение `client_email` из JSON.
4. В поле **Приватный ключ** введите полное значение `private_key`.
5. В поле **ID проекта** введите `project_id`.
6. В поле **Местоположение** введите Location, в котором доступна целевая модель.
7. Оставьте адрес API пустым.
8. Включите переключатель провайдера в верхней части страницы.
9. Добавьте и включите модели, которые планируете использовать.

{% hint style="warning" %}
Адрес API Vertex AI обычно создаётся автоматически на основе проекта и местоположения, поэтому вводить его вручную не рекомендуется. Изменяйте его только при осознанном использовании обратного прокси и знании полного пути.
{% endhint %}

## Добавление и выбор моделей

Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения. Если удалённая служба не возвращает нужную модель, нажмите **Пользовательский** и введите ID модели из Model Garden или официальной документации Google.

- Модели Gemini используют возможности Google Generate Content.
- Модели Claude используют маршрут Vertex Anthropic.
- Модель должна быть доступна в текущем проекте и Location.
- Сторонняя модель может требовать дополнительного включения, авторизации или принятия условий.
- Название, местоположение и версия модели должны соответствовать друг другу; нельзя просто скопировать ID модели из другого проекта.

Утверждение старой документации о том, что Claude пока не поддерживается, больше не относится к V2. Однако поддержка маршрута в коде не означает, что проект Google Cloud уже получил права на эту модель.

## Проверка подключения

1. Убедитесь, что все четыре обязательных поля относятся к одной Service Account и одному проекту.
2. Убедитесь, что Vertex AI API включён.
3. Убедитесь, что у Service Account есть необходимые права IAM.
4. Выберите добавленную и включённую модель.
5. Запустите проверку подключения.
6. Затем запустите проверку работоспособности модели.
7. Вернитесь на экран чата и отправьте простое сообщение.

Если Gemini доступен, а Claude — нет, сначала проверьте наличие Claude в текущем проекте, местоположении и Model Garden, не изменяя конфигурацию Gemini.

## Управление несколькими проектами или местоположениями

Если разные проекты или местоположения используют разные учётные данные, скопируйте провайдера VertexAI и настройте каждый экземпляр отдельно:

- Укажите проект или местоположение в названии.
- В каждой копии оставьте только модели, доступные в этой среде.
- Не сочетайте Service Account проекта A с ID проекта B.
- При смене ключа проверяйте копии по очереди.
- Используйте разные Service Account для рабочей и тестовой среды.

Так можно сократить область прав и упростить различение проблем с квотами, местоположением и доступностью моделей.

## Частые вопросы

### Отображается сообщение, что VertexAI не настроен

Не заполнено хотя бы одно из полей: ID проекта, Location, email клиента или приватный ключ. Проверьте полноту приватного ключа, уберите фокус с поля и дождитесь сохранения настройки.

### Возвращается 401 или ошибка аутентификации

Ключ Service Account недействителен или удалён, формат приватного ключа повреждён либо email клиента не соответствует приватному ключу. Повторно проверьте поля по одному JSON-файлу.

### Возвращается 403

Vertex AI API не включён, у Service Account недостаточно прав IAM или целевая модель ещё не доступна проекту. Проверьте проект, API и роли в Google Cloud.

### Возвращается 404 или сообщение «Модель не существует»

ID модели, проект или Location не совпадают. Проверьте поддерживаемые целевой моделью местоположения в Model Garden и обновите Cherry Studio.

### Возвращается 429

Текущий проект, местоположение или модель достигли ограничения квоты. Проверьте квоту и использование в Google Cloud Console.

### Gemini работает, а Claude — нет

Убедитесь, что модель Claude доступна в текущем проекте и местоположении, и используйте полный правильный ID модели. Права на Gemini в Vertex AI не предоставляют автоматически права на сторонние модели.

Дополнительные общие настройки см. в разделах [Провайдеры моделей](README.md) и [Настройки провайдеров моделей](../../cherrystudio/preview/settings/providers.md). Каналы обратной связи перечислены на странице [Отзывы и предложения](../../question-contact/suggestions.md).
