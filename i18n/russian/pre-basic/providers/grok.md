# Grok

Встроенный шаблон Grok в Cherry Studio V2 предназначен для подключения к официальному API xAI. V2 использует для этого провайдера адаптер xAI Responses, поддерживая чат, рассуждения, вызов инструментов, а также официальные xAI Web Search и X Search.

{% hint style="warning" %}
Grok не получает информацию в реальном времени автоматически. Cherry Studio запрашивает у xAI Web Search и X Search, только если в чате включён веб-поиск. За серверные инструменты поиска может взиматься дополнительная плата.
{% endhint %}

## Перед началом

- Учётная запись с доступом к [xAI Console](https://console.x.ai/)
- API Key, созданный в xAI Console
- Доступная квота команды или учётной записи
- Проверенные сведения о текущих моделях и регионах обслуживания

Вход на сайте x.com или в веб-версии Grok не переносится в Cherry Studio автоматически. Для использования xAI API необходимо отдельно создать API Key.

## Настройка Grok

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **Grok**.
3. Введите xAI API Key.
4. Оставьте Base URL по умолчанию: `https://api.x.ai`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите модели, которые планируете использовать.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно отзовите его в xAI Console и создайте новый.
{% endhint %}

## Выбор модели

xAI постоянно обновляет модели и псевдонимы. Нажмите **Добавить**, чтобы синхронизировать список, который сейчас доступен учётной записи, и ориентируйтесь на [документацию моделей xAI](https://docs.x.ai/developers/models).

Текущие распространённые варианты:

| ID модели | Подходящие задачи |
| --- | --- |
| `grok-4.5` | Сложная работа со знаниями, код и задачи Agent |
| `grok-4.3` | Универсальный чат, понимание изображений и настраиваемые рассуждения |
| `grok-build-0.1` | Задачи программирования для Agent |

- Включайте только действительно необходимые модели.
- Проверяйте полный ID модели, а не только отображаемое имя.
- Псевдоним `-latest` может автоматически перейти на новую версию.
- ID модели с датой лучше подходит для процессов, которым требуется фиксированное поведение.
- Наличие модели в списке синхронизации не означает, что у учётной записи неограниченная квота.

## Использование веб-поиска

Когда в области ввода чата включён **Веб-поиск**, Cherry Studio настраивает для Grok:

- xAI Web Search
- xAI X Search
- понимание изображений на страницах поиска и в публикациях X
- возврат источников поиска и цитат

Если в настройках веб-поиска заданы исключённые домены, официальный поиск Grok получает не более первых 5 действительных правил доменов.

Порядок использования:

1. Выберите включённую текстовую модель Grok.
2. Включите **Веб-поиск** в области ввода.
3. Задайте вопрос, для которого явно требуются актуальные сведения из интернета или X.
4. Дождитесь завершения серверного поиска.
5. Разверните цитаты и проверьте источники.

{% hint style="info" %}
«Более новые знания модели» и «веб-поиск» — не одно и то же. Если веб-поиск не включён, Grok отвечает только на основе знаний модели. Для получения текущей информации явно включите веб-поиск и проверьте цитаты.
{% endhint %}

## Рассуждения и вызов инструментов

Cherry Studio показывает параметры рассуждений согласно ID модели:

- `grok-4.3` поддерживает отключение, низкую, среднюю и высокую интенсивность рассуждений.
- Версия Grok 4 Fast с рассуждениями и версия без них — разные модели, которые нельзя заменить друг другом одним переключателем.
- Параметры других новых моделей зависят от текущей версии Cherry Studio и данных реестра моделей.

Перед использованием MCP или других инструментов:

1. Сначала выполните проверку работоспособности обычного чата.
2. Включите один простой инструмент.
3. Отправьте запрос, для которого явно требуется инструмент.
4. Убедитесь, что модель действительно вызывает инструмент.
5. Затем добавьте веб-поиск или несколько инструментов.

Веб-поиск — серверный инструмент xAI, а MCP — локальный или удалённый инструмент Cherry Studio. Их можно использовать одновременно, но при диагностике следует тестировать отдельно.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую модель.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.
6. Затем включите веб-поиск и протестируйте запрос с цитатами.

Успешная проверка подключения не означает, что инструменты поиска обязательно доступны. Поиск также зависит от возможностей модели, прав учётной записи и состояния оплаты инструментов.

## Подключение совместимого шлюза Grok

Если используется не официальный API xAI:

1. Создайте [Пользовательского провайдера](zi-ding-yi-fu-wu-shang.md).
2. Выберите OpenAI Chat Completions или OpenAI Responses согласно документации шлюза.
3. Введите Base URL и API Key, предоставленные шлюзом.
4. Синхронизируйте или вручную добавьте модели, фактически предоставляемые шлюзом.
5. Отдельно проверьте рассуждения, вызов инструментов и веб-поиск.

Наличие модели Grok у стороннего шлюза не означает поддержку официальных xAI Web Search или X Search. Не перезаписывайте официальный шаблон Grok.

## Частые вопросы

### Возвращается 401

API Key недействителен, отозван или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается 403

Права команды, региона, модели или инструмента не соответствуют требованиям. Проверьте состояние учётной записи и доступа к моделям в xAI Console.

### Возвращается 404 или сообщение «Модель не существует»

Снова нажмите **Добавить**, синхронизируйте список и проверьте полный ID модели. Старая модель могла быть перенесена, перенаправлена или снята с обслуживания.

### Возвращается 429

Текущая команда или модель достигли ограничения скорости. Уменьшите параллелизм, повторите попытку позже и проверьте ограничения и использование в xAI Console.

### После включения веб-поиска нет цитат

Убедитесь, что веб-поиск включён в области ввода и вопрос явно требует актуальной информации. Сторонний шлюз может не поддерживать серверные инструменты поиска xAI.

### Стоимость веб-поиска выше ожидаемой

xAI может учитывать и Token модели, и вызовы серверных инструментов. Сократите ненужные запросы с веб-поиском и проверьте фактическое использование в xAI Console.

### Параметры рассуждений отличаются от документации

Повторно синхронизируйте модель и убедитесь, что Cherry Studio обновлён. Новые модели xAI могут выходить раньше правил возможностей приложения; в таком случае ориентируйтесь на текущий интерфейс и фактическую проверку работоспособности.
