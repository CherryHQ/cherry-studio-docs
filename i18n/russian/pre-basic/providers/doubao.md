# Volcengine (Ark / Doubao)

Volcengine Ark — платформа сервисов больших языковых моделей от Volcengine, предоставляющая модели Doubao и ряда сторонних разработчиков. ID встроенного провайдера в Cherry Studio V2 — `doubao`; в интерфейсе он может отображаться как **Doubao**, **Volcengine Ark** или **Volcengine**.

API Host по умолчанию в V2:

```text
https://ark.cn-beijing.volces.com/api/v3/
```

{% hint style="info" %}
В настоящее время встроенный провайдер V2 по умолчанию использует OpenAI-совместимый интерфейс Chat Completions. На официальном сайте Volcengine Ark также доступны Responses API, Files API и встроенные облачные инструменты, но поддержка на стороне платформы не означает, что эти возможности автоматически интегрированы в Cherry Studio.
{% endhint %}

## Подготовка к работе

1. Зарегистрируйтесь в Volcengine и войдите в аккаунт.
2. Откройте консоль Volcengine Ark.
3. Проверьте проект и регион.
4. Активируйте нужную модель или способ оплаты.
5. Создайте API Key.
6. Скопируйте Model ID из актуального списка моделей.
7. Проверьте баланс, квоты и ограничения частоты запросов.

Volcengine Ark может изменять модели, версии, цены и их доступность. В этом руководстве не фиксируются цены и бонусные квоты. Актуальные сведения смотрите в [списке моделей](https://www.volcengine.com/docs/82379/1554711) и консоли.

## Получение API Key

1. Откройте [консоль Volcengine Ark](https://console.volcengine.com/ark/).
2. Проверьте текущий проект и регион China North 2 (Beijing).
3. Откройте [управление API Key](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey).
4. Нажмите **Create API Key**.
5. Укажите понятное имя.
6. Скопируйте ключ и сохраните его в надежном месте.

{% hint style="danger" %}
API Key является учетными данными аккаунта. Не добавляйте его в чаты, документы, репозитории кода и снимки экрана для отчетов о проблемах. При утечке немедленно удалите или смените ключ в консоли Ark.
{% endhint %}

## Получение Model ID

В настоящее время Volcengine Ark позволяет использовать Model ID стандартной модели, а в некоторых сценариях — ID пользовательской конечной точки инференса.

| Идентификатор | Обычный формат | Сценарий использования |
| --- | --- | --- |
| Model ID | `doubao-seed-...` | Предустановленная модель платформы с оплатой по факту использования |
| Endpoint ID | `ep-...` | Пользовательская модель, выделенный ресурс или созданная конечная точка инференса |

Чтобы получить актуальный Model ID:

1. Откройте [список моделей](https://www.volcengine.com/docs/82379/1554711).
2. Выберите нужную модель и версию.
3. Убедитесь, что она поддерживает Chat API.
4. Скопируйте полный Model ID.
5. Не копируйте отображаемое имя модели или URL страницы консоли.

Если организация использует пользовательские модели, модельные блоки или выделенные конечные точки инференса, скопируйте ID `ep-...` в разделе [конечных точек инференса](https://console.volcengine.com/ark/region:ark+cn-beijing/endpoint).

## Настройка в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`.
2. В фильтре слева выберите **Все провайдеры**.
3. Выберите **Doubao / Volcengine**.
4. Вставьте ключ Ark в поле API Key.
5. Оставьте API Host `https://ark.cn-beijing.volces.com/api/v3/`.
6. Включите провайдера переключателем в верхней части страницы.
7. Нажмите **Добавить модель**.
8. Вставьте актуальный Model ID или Endpoint ID.
9. Включите только те модели, которые собираетесь использовать.
10. Запустите проверку работоспособности модели.

Предустановленный список V2 может содержать старые модели Doubao, DeepSeek и Embedding. Предустановки являются лишь кандидатами и не гарантируют, что модель по-прежнему доступна.

## Синхронизация и ручное добавление

Каталог моделей Volcengine Ark и пользовательские конечные точки инференса не всегда полностью возвращаются через стандартный OpenAI-совместимый список моделей. Поэтому результат синхронизации может быть пустым или неполным.

Наиболее надежный способ:

1. Скопируйте Model ID с актуальной страницы моделей Ark.
2. Добавьте его в Cherry Studio вручную.
3. Проверьте метки возможностей модели.
4. Запустите проверку работоспособности.
5. Удалите старые предустановки, которые невозможно вызвать.

{% hint style="warning" %}
Не продолжайте использовать старый Model ID только потому, что он остается в предустановках V2. Версии моделей Ark часто содержат суффикс с датой, а старые версии могут быть сняты с публикации.
{% endhint %}

## API Host

Оставьте значение по умолчанию:

```text
https://ark.cn-beijing.volces.com/api/v3/
```

Cherry Studio добавляет путь запроса в зависимости от типа модели. Старые руководства могут предлагать указывать полный путь `/chat/completions` в API Host и добавлять в конце `#`; это устаревший способ обеспечения совместимости, который не нужен в V2.

Если используется регион, отличный от Beijing, прокси или корпоративный домен, полностью замените API Host и убедитесь, что:

- API Key относится к тому же проекту и региону;
- домен поддерживает `/api/v3`;
- прокси передает потоковые ответы;
- Model ID или Endpoint ID действует в целевом окружении.

## Диалоговые модели

В настоящее время встроенный провайдер в основном использует для диалогов OpenAI-совместимый интерфейс Chat Completions.

Рекомендуемый порядок проверки:

1. Отправьте короткое текстовое сообщение.
2. Проверьте потоковый вывод.
3. Добавьте системный промпт.
4. Проверьте более длинный контекст.
5. Затем проверьте изображения, режим рассуждения и вызов инструментов.

В новых примерах на официальном сайте Volcengine Ark может в первую очередь использоваться Responses API. Работающий пример Responses не означает, что текущие диалоги V2 уже используют тот же интерфейс или поддерживают все поля, доступные только в Responses.

## Режим рассуждения

Разные версии Doubao используют разные параметры рассуждения. Cherry Studio V2 подбирает их по Model ID:

- новые модели Doubao Seed используют `reasoningEffort`;
- некоторые старые модели рассуждения используют `thinking: enabled`;
- старые модели с автоматическим рассуждением могут использовать `thinking: auto`;
- для других комбинаций поля рассуждения могут не отправляться.

Если после изменения интенсивности рассуждения возникает ошибка:

1. Верните настройку рассуждения к значению **По умолчанию**.
2. Удалите пользовательские параметры модели.
3. Убедитесь, что Model ID совпадает с актуальной официальной версией.
4. Проверьте пример Chat API для этой модели.
5. Повторно запустите проверку работоспособности.

Не копируйте параметр `thinking` из примера Responses API без изменений в модель Chat Completions.

## Компьютерное зрение и мультимодальность

Изображения и видео могут принимать только модели, которые Ark явно обозначает как визуальные или мультимодальные.

В Cherry Studio:

1. Добавьте актуальный Model ID визуальной модели.
2. Убедитесь, что для модели указана поддержка изображений.
3. Сначала загрузите одно небольшое изображение.
4. Проверьте, действительно ли модель понимает его содержимое.
5. Затем попробуйте несколько изображений или более крупное вложение.

На официальном сайте Ark доступны нативный ввод файлов и видео, однако возможность их прямого использования в текущей версии V2 зависит от поддержки формата вложения в клиенте. Если платформа поддерживает определенный тип ввода, это не означает, что Cherry Studio загружает его через Files API.

## MCP и вызов инструментов

MCP в Cherry Studio использует структурированный Function Calling модели.

1. Сначала настройте обычный диалог.
2. Включите только один простой инструмент MCP.
3. Явно попросите модель вызвать его.
4. Проверьте, сформирован ли структурированный вызов.
5. Убедитесь, что результат инструмента возвращается модели.
6. Только после этого добавляйте другие инструменты.

Web Search, Image Process, Knowledge Search и Remote MCP в Volcengine Ark являются облачными инструментами Ark, которые в основном настраиваются через Responses API. Это не та же конфигурация, что у MCP-серверов, добавленных в Cherry Studio.

Если модель лишь пишет, что «собирается вызвать инструмент», это не является реальным вызовом. Проверьте Model ID, интерфейс и описание инструмента.

## Embedding и база знаний

Volcengine Ark предоставляет API текстовой и мультимодальной векторизации. В предустановках V2 могут сохраняться старые Embedding Model ID, но следует отдавать предпочтение версиям из актуальной документации Ark.

При создании базы знаний:

1. Скопируйте Model ID с актуальной страницы модели векторизации Ark.
2. Добавьте его в Cherry Studio вручную.
3. Убедитесь, что модель распознана как Embedding.
4. Определите размерность векторов.
5. Запустите проверку работоспособности.
6. Для проверки импортируйте небольшое количество документов.
7. Затем запускайте массовый импорт.

Формат ввода мультимодальной модели векторизации может отличаться от текстовых фрагментов, которые сейчас используются в базе знаний Cherry Studio. Для базы знаний с документами сначала проверьте обычный текстовый Embedding.

После использования модели Embedding или размерности векторов в существующей базе знаний не меняйте их напрямую: обычно потребуется перестроить векторный индекс.

В текущей версии V2 для `doubao` не зарегистрирована специальная модель Rerank. Если требуется повторное ранжирование, выберите другого провайдера, который поддерживается в V2 и проходит проверку работоспособности.

## Генерация изображений

На официальном сайте Volcengine Ark доступен API генерации изображений, использующий Model ID или ID конечной точки инференса изображений.

Однако в текущей ветке `main` V2 для встроенного провайдера `doubao` не зарегистрированы специальная модель генерации изображений и соответствующий канал передачи. Поэтому:

- поддержка Seedream на официальном сайте не означает, что модель автоматически появится на странице рисования Cherry Studio;
- не используйте Model ID изображения как обычную диалоговую модель;
- не пытайтесь угадать Endpoint Type вручную по старому снимку экрана;
- ориентируйтесь на провайдеров и модели, фактически доступные на текущей странице рисования.

Если в будущей версии V2 появится адаптер изображений Ark, повторно синхронизируйте или добавьте актуальный Model ID и сначала проверьте одно изображение распространенного размера.

{% hint style="warning" %}
Генерация изображений может оплачиваться по числу успешно созданных результатов. Не отправляйте задание многократно подряд только для проверки совместимости.
{% endhint %}

## PDF и вложения

Текущая версия V2 сначала извлекает текст PDF локально, а затем отправляет его диалоговой модели Ark:

- текстовые PDF обычно можно обработать;
- для отсканированных документов сначала требуется OCR;
- таблицы, сложное форматирование и сведения из изображений могут быть потеряны;
- извлеченный текст расходует контекст модели и оплачиваемые токены;
- изображения из PDF необходимо отдельно отправлять визуальной модели.

Этот процесс отличается от нативного Files API или API понимания документов Ark. Поддержка загрузки файлов в Ark не означает, что Cherry Studio автоматически обрабатывает PDF как файловый объект Ark.

Перед загрузкой документов, изображений или содержимого базы знаний убедитесь, что это соответствует требованиям к конфиденциальности, безопасности данных и нормативным правилам вашей организации.

## Оплата, ограничения и использование

В Ark могут одновременно действовать следующие ограничения:

- баланс аккаунта;
- бюджет проекта;
- оплата по факту использования, модельный блок или возможности пакета;
- RPM / TPM;
- ограничение конечной точки инференса;
- параллельность модели;
- политика безопасности содержимого.

Рекомендуется просматривать статистику использования и настраивать предупреждения о бюджете в консоли. Для пользовательского Endpoint также проверьте его состояние, характеристики ресурсов и настройки ограничений.

## Частые проблемы

### Возвращается 401

API Key неверен, удален, содержит случайно скопированные пробелы либо ключ не соответствует API Host. Скопируйте API Key Ark заново.

### Возвращается 403

Нет доступа к проекту, модели, Endpoint или содержимому. Проверьте активацию модели, проект, IAM и политику безопасности содержимого.

### Возвращается 404

Указан неверный API Host, Model ID или Endpoint ID либо модель снята с публикации. Верните адрес по умолчанию и заново скопируйте ID с актуальной страницы модели.

### Возвращается 429

Достигнуто ограничение RPM, TPM или параллельности для модели, проекта или конечной точки инференса. Уменьшите параллельность и дождитесь восстановления.

### Список моделей пуст

Ark не обязательно возвращает все модели и пользовательские Endpoint через стандартный список моделей. Скопируйте ID с официальной страницы модели или конечной точки инференса и добавьте его вручную.

### Предустановленная модель недоступна

Предустановки V2 могут содержать старые версии с датой, уже снятые с публикации. Удалите недоступную модель и добавьте актуальный Model ID.

### Model ID работает, а Endpoint ID — нет

Endpoint может быть не запущен, связан с неправильной моделью, относиться к другому проекту или лишиться выделенного ресурса. Проверьте состояние Endpoint в консоли Ark.

### Ошибка параметров рассуждения

Верните настройки рассуждения к значениям по умолчанию. Параметры `reasoningEffort` и `thinking` для новых и старых моделей Doubao нельзя смешивать.

### Обычный диалог работает, но MCP не вызывается

Убедитесь, что модель поддерживает Function Calling. Облачный Remote MCP Ark и MCP Cherry Studio — разные возможности; недостаточно включить инструмент только в консоли Ark.

### Не удается добавить модель Embedding

Убедитесь, что используется Model ID модели векторизации, и отметьте ее как Embedding в управлении моделями. Не используйте отображаемое имя или URL страницы Endpoint как ID модели.

### Seedream работает на официальном сайте, но отсутствует на странице рисования

Во встроенном провайдере `doubao` текущей версии V2 еще не зарегистрирован специальный канал генерации изображений. Дождитесь адаптации клиента или используйте провайдера, доступного на странице рисования.
