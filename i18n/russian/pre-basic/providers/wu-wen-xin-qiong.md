# Infini-AI GenStudio

Infini-AI GenStudio предоставляет API больших языковых моделей, визуальных моделей, Embedding, Rerank и других возможностей. В Cherry Studio V2 уже встроен провайдер **Infini-AI (Infini)**, который подключается через OpenAI-совместимые интерфейсы.

Предустановленный API Host в V2:

```text
https://cloud.infini-ai.com/maas
```

Cherry Studio добавляет `/v1` при отправке запроса. Фактический интерфейс диалога:

```text
https://cloud.infini-ai.com/maas/v1/chat/completions
```

{% hint style="info" %}
При использовании встроенного провайдера рекомендуется оставить предустановленный API Host. Не указывайте в API Host URL каталога моделей, консоли или страницы документации.
{% endhint %}

## Подготовка к работе

1. Зарегистрируйтесь на платформе Infini-AI Intelligent Computing Cloud и войдите в аккаунт.
2. Проверьте, к какому тенанту относится текущий аккаунт.
3. Создайте GenStudio API Key.
4. Найдите Model ID нужной модели в списке сервисов или каталоге моделей.
5. Проверьте стоимость модели, уровень сервиса и ограничения частоты запросов.
6. Убедитесь, что на аккаунте есть средства или продолжает действовать приобретенный пакет параллельных вызовов.

Модели, цены и ограничения могут меняться. В этом руководстве не фиксируются «бесплатные модели» и бонусные квоты. Актуальные сведения смотрите в [списке сервисов](https://cloud.infini-ai.com/genstudio/usage/limit) и [списке предустановленных моделей](https://docs.infini-ai.com/gen-studio/models/supported-models.html).

## Получение API Key

1. Войдите на [платформу Intelligent Computing Cloud](https://cloud.infini-ai.com/).
2. Откройте [управление API Key](https://cloud.infini-ai.com/iam/secret/key).
3. Создайте новый GenStudio API Key.
4. Скопируйте полный ключ.
5. Сохраните его в надежном менеджере паролей.

В настоящее время GenStudio использует API Key с префиксом `sk-` и отправляет запросы с Bearer-аутентификацией.

{% hint style="danger" %}
API Key является учетными данными аккаунта. Не добавляйте его в чаты, документы, репозитории кода, снимки экрана и обращения в поддержку. При утечке немедленно удалите ключ и создайте новый.
{% endhint %}

## Настройка в Cherry Studio

1. Откройте `Настройки → Провайдеры моделей`.
2. В фильтре слева выберите **Все провайдеры**.
3. Выберите **Infini-AI / Infini**.
4. Вставьте ключ GenStudio в поле API Key.
5. Оставьте API Host `https://cloud.infini-ai.com/maas`.
6. Включите провайдера переключателем в верхней части страницы.
7. Нажмите **Добавить** или синхронизируйте модели.
8. Просмотрите предварительный результат синхронизации и примените изменения.
9. Включите только те модели, которые собираетесь использовать.
10. Запустите проверку работоспособности модели.

Успешная проверка подтверждает только то, что текущие Key, адрес и тестовая модель позволяют выполнить базовый запрос. Она не означает, что у аккаунта есть доступ ко всем моделям из списка.

## Синхронизация и добавление моделей

Cherry Studio использует следующий OpenAI-совместимый интерфейс списка моделей:

```text
GET /maas/v1/models
```

После синхронизации рекомендуется:

1. Просмотреть добавленные, обновленные и удаляемые позиции.
2. Убедиться, что Model ID полностью совпадает со списком сервисов.
3. Применить результат синхронизации.
4. Удалить старые модели, снятые с публикации.
5. Отдельно проверить модели диалога, Embedding и Rerank.

Если синхронизация не удалась, скопируйте Model ID из списка сервисов или каталога моделей и добавьте его вручную. Регистр, дефисы, суффикс версии и префикс `pro-` являются частью Model ID.

{% hint style="warning" %}
Пакет параллельных вызовов обычно использует специальный Model ID с префиксом `pro-`. Не считайте обычную модель с оплатой по факту использования и модель из пакета параллельных вызовов одним ID.
{% endhint %}

Встроенные модели-кандидаты V2 могли быть добавлены до появления актуального списка платформы. При использовании отдавайте приоритет результату синхронизации в реальном времени и списку сервисов.

## Выбор диалоговой модели

Диалоговые модели GenStudio используют OpenAI-совместимый интерфейс Chat Completions.

При первой проверке рекомендуется:

1. Выбрать модель, явно доступную текущему аккаунту.
2. Отправить короткое текстовое сообщение.
3. Проверить потоковый вывод.
4. Добавить системный промпт.
5. Затем проверить длинный контекст, рассуждение, изображения и вызов инструментов.

Серии и версии моделей обновляются. Не полагайтесь на фиксированные примеры из старых руководств: копируйте актуальный Model ID непосредственно из списка сервисов.

## Визуальные модели

Изображения могут понимать только те Model ID, которые GenStudio явно обозначает как визуально-языковые модели.

В Cherry Studio:

1. Синхронизируйте актуальные модели.
2. Убедитесь, что в описании модели указана поддержка ввода изображений.
3. Сначала загрузите одно небольшое изображение.
4. Задайте вопрос о содержимом, которое можно непосредственно проверить на изображении.
5. После успешной проверки попробуйте несколько изображений или изображение высокого разрешения.

У текстовой и визуальной моделей одной серии могут быть разные Model ID. Похожие имена моделей не означают одинаковые входные модальности.

## Режим рассуждения

GenStudio предоставляет несколько моделей рассуждения. Разные серии могут использовать разные параметры рассуждения и форматы ответа. Cherry Studio применяет общую адаптацию на основе распознанной серии модели, но у провайдера Infini-AI сейчас нет отдельной панели параметров рассуждения.

При первом использовании модели рассуждения:

1. Оставьте настройку рассуждения **По умолчанию**.
2. Не добавляйте пользовательские параметры запроса.
3. Убедитесь, что базовый диалог работает.
4. Затем попробуйте включить или отключить рассуждение.
5. Сверьтесь с описанием модели и проверьте поддерживаемые параметры.

Если после включения рассуждения возвращается 400, сначала восстановите настройки по умолчанию, а не изменяйте Model ID несколько раз.

## MCP и вызов инструментов

Некоторые модели GenStudio поддерживают Function Calling. Cherry Studio может передавать определения инструментов MCP модели через Chat Completions, но стабильность вызова зависит от конкретной модели.

Рекомендуемый порядок проверки:

1. Убедитесь, что обычный диалог работает.
2. Включите только один инструмент MCP с простыми параметрами.
3. Явно попросите модель вызвать этот инструмент.
4. Проверьте, сформирован ли структурированный вызов инструмента.
5. Убедитесь, что результат инструмента возвращается.
6. Только после этого постепенно добавляйте другие инструменты.

Если модель лишь пишет, что «собирается вызвать инструмент», это не является реальным вызовом. В таком случае проверьте описание модели, определение инструмента и промпт.

## Embedding и база знаний

GenStudio предоставляет следующий OpenAI-совместимый интерфейс Embedding:

```text
POST /maas/v1/embeddings
```

Среди доступных сервисов могут быть векторные модели, например `bge-m3`, но фактический Model ID следует брать из списка сервисов. Cherry Studio определяет модель Embedding по ее ID и вручную заданной метке типа.

Перед созданием базы знаний:

1. Синхронизируйте или вручную добавьте модель Embedding.
2. Убедитесь, что модель распознана как тип **Embedding**.
3. Запустите проверку работоспособности.
4. Определите размерность векторов.
5. Создайте тестовую базу знаний с небольшим количеством документов.
6. Проверьте результаты поиска и только потом запускайте массовый импорт.

Размерность векторов является частью индекса базы знаний. После создания базы знаний при смене модели Embedding или размерности обычно требуется перестроить индекс.

## Rerank

GenStudio предоставляет следующий интерфейс Rerank:

```text
POST /maas/v1/rerank
```

В актуальном официальном примере используется модель `bge-reranker-v2-m3`, но ее доступность все равно следует проверять в списке сервисов.

В Cherry Studio:

1. Синхронизируйте или вручную добавьте модель Rerank.
2. Убедитесь, что модель распознана как тип **Rerank**.
3. Выберите ее в настройках базы знаний.
4. Сравните результаты до и после включения на небольшом количестве запросов.
5. Затем решите, следует ли использовать ее в рабочей базе знаний.

Embedding и Rerank используют разные модели и конечные точки. Доступность Embedding не означает доступность Rerank, поэтому проверяйте их отдельно.

## Генерация изображений и видео

Платформа GenStudio также предлагает генерацию изображений и видео. Однако встроенный в Cherry Studio V2 провайдер Infini-AI сейчас в основном работает через OpenAI-совместимые интерфейсы диалога, Embedding и Rerank, а специальный транспортный слой Infini-AI для генерации изображений и видео не зарегистрирован.

Поэтому:

- не добавляйте модель генерации изображений или видео как диалоговую модель;
- ориентируйтесь на провайдеров и модели, фактически доступные на странице рисования Cherry Studio;
- наличие модели генерации на официальном сайте не означает, что соответствующая адаптация уже реализована в текущей версии V2.

## PDF и вложения

Cherry Studio V2 сначала извлекает текст PDF локально, а затем отправляет результат диалоговой модели:

- текстовые PDF обычно можно обработать напрямую;
- для отсканированных документов сначала требуется OCR;
- таблицы, сложное форматирование и сведения из изображений могут быть потеряны;
- извлеченный текст расходует контекст модели и Token;
- изображения из PDF необходимо отдельно отправлять визуальной модели.

Infini-AI является облачным сервисом. Перед загрузкой документов, изображений или содержимого базы знаний убедитесь, что это соответствует требованиям к конфиденциальности, авторским правам и безопасности вашей организации.

## Оплата и ограничения

На вызовы API GenStudio влияют уровень сервиса аккаунта, стоимость модели и ограничения частоты запросов. Платформа может одновременно ограничивать:

- RPM: количество запросов в минуту;
- RPD: количество запросов в день;
- TPM: количество Token в минуту;
- число слотов параллельности пакетного сервиса.

Актуальные правила оплаты и ограничения могут меняться. Перед запуском автоматической задачи в рабочем окружении:

1. Проверьте актуальные правила оплаты.
2. Убедитесь, что на аккаунте достаточно средств.
3. Задайте предел параллельности и количества повторных попыток.
4. Контролируйте расход Token.
5. При ошибке 429 используйте повторные попытки с увеличивающейся задержкой.
6. Сохраняйте `id` и `traceresponse` из ответа для диагностики.

Не создавайте несколько Key для обхода ограничений на уровне тенанта: Key одного тенанта могут использовать общую квоту.

## Частые проблемы

### Возвращается 401

API Key неверен, удален, содержит случайно скопированные пробелы или запрос неправильно использует Bearer-аутентификацию. Скопируйте ключ заново или создайте новый.

### Возвращается 403

У аккаунта, тенанта или целевой модели нет прав доступа. Проверьте, требуется ли заявка на модель, состояние аккаунта и текущего тенанта.

### Возвращается 404

Указан неверный API Host, путь интерфейса или Model ID. Верните встроенный предустановленный адрес и скопируйте полный Model ID из списка сервисов.

### Возвращается 429

Достигнуто ограничение RPM, RPD, TPM или параллельности пакетного сервиса. Уменьшите параллельность, сократите контекст и дождитесь восстановления.

### Возвращается 400

Модель не поддерживает текущие параметры, формат изображения или настройку рассуждения. Удалите пользовательские параметры, верните настройку рассуждения по умолчанию и повторите проверку.

### Список моделей пуст

Проверьте API Key, API Host, сетевой прокси и права тенанта. Можно также скопировать Model ID из списка сервисов и добавить его вручную.

### Не удается вызвать предустановленную модель

Встроенная модель-кандидат V2 могла быть снята с публикации, переименована или недоступна текущему аккаунту. Синхронизируйте актуальный список и удалите недоступную модель.

### Ошибка при вызове модели из пакета параллельности

Убедитесь, что приобретенный пакет по-прежнему действует, и используйте полный специальный Model ID, назначенный платформой. Не удаляйте префикс `pro-`.

### Модель Embedding отображается в списке диалогов

Проверьте метку типа модели. Model ID должен содержать полное имя, предоставленное платформой, а в управлении моделями необходимо выбрать Embedding, а не обычную диалоговую модель.

### Проверка работоспособности Rerank не запускается

Общая проверка подключения модели в текущей версии V2 пропускает Rerank. Фактически проверьте запрос повторного ранжирования в процессе поиска по базе знаний.

### После загрузки файла возвращается ошибка неподдерживаемого формата

Сначала убедитесь, что текст успешно извлечен из файла, затем проверьте, поддерживает ли текущая диалоговая модель соответствующий ввод. Для отсканированного PDF требуется OCR, а для изображения — визуальная модель.
