# Groq

Groq — платформа моделей с низкой задержкой вывода, предоставляющая разные модели с открытыми весами и системы Groq Compound. Встроенный шаблон Groq в Cherry Studio V2 использует официальную совместимую с OpenAI конечную точку Groq и позволяет синхронизировать модели, доступные учётной записи в данный момент.

{% hint style="warning" %}
**Groq** и **Grok** от xAI — два независимых провайдера. Groq предоставляет платформу вывода моделей, а Grok — серия моделей xAI. Перед настройкой убедитесь, что выбран правильный пункт.
{% endhint %}

## Перед началом

- Учётная запись с доступом к [GroqCloud Console](https://console.groq.com/)
- API Key, созданный на странице [Groq API Keys](https://console.groq.com/keys)
- Доступная квота и ограничения скорости учётной записи
- Подтверждение, что выбранная модель всё ещё доступна

Список и жизненный цикл моделей Groq меняются. Не добавляйте снятые с обслуживания модели по фиксированному списку из старой документации.

## Настройка Groq

1. Откройте `Настройки → Провайдеры моделей`.
2. Переключите фильтр слева на **Все поставщики** и выберите **Groq**.
3. Введите Groq API Key.
4. Оставьте Base URL по умолчанию: `https://api.groq.com/openai`.
5. Включите переключатель провайдера в верхней части страницы.
6. Нажмите **Добавить** в списке моделей, проверьте предварительный просмотр синхронизации и примените изменения.
7. Включите модели, которые планируете использовать.

{% hint style="danger" %}
Не добавляйте API Key в сообщения чата, документы, репозитории кода или снимки экрана с описанием проблемы. В случае утечки немедленно отзовите его в GroqCloud Console и создайте новый.
{% endhint %}

## Синхронизация и выбор моделей

После нажатия **Добавить** Cherry Studio вызывает API списка моделей Groq и показывает модели, доступные текущему Key. Модели быстро меняются, поэтому ориентируйтесь на [Groq Supported Models](https://console.groq.com/docs/models) и результат синхронизации.

Распространённые типы:

| Тип | Пример ID модели | Подходящие задачи |
| --- | --- | --- |
| Лёгкая текстовая модель | `llama-3.1-8b-instant` | Вопросы и ответы с низкой задержкой, классификация и простое извлечение |
| Большая универсальная модель | `openai/gpt-oss-120b` | Сложный текст, код и рассуждения |
| Другие размещённые модели | `qwen/qwen3.6-27b` | Несколько языков, структурированный вывод и задачи с инструментами |
| Система Compound | `groq/compound`, `groq/compound-mini` | Серверный поиск Groq и выполнение кода |

- Включайте только действительно необходимые модели.
- Проверяйте полный ID модели, включая косую черту и регистр символов.
- После снятия модели с обслуживания повторно синхронизируйте список, а не меняйте только отображаемое имя.
- Для одной модели на разных планах могут действовать разные ограничения скорости.
- Аудио, голосовые или специализированные модели могут не подходить для обычного чата.

## Настройка уровня сервиса

В настройках Groq для чата можно выбрать **Уровень сервиса**:

| Параметр | Значение |
| --- | --- |
| Игнорировать | Не отправлять `service_tier` и использовать поведение Groq по умолчанию |
| Авто | Использовать подходящий уровень, доступный учётной записи |
| по требованию | Использовать обычную обработку по требованию |
| Гибкий | Отдавать приоритет высокой пропускной способности, но быстро завершать запрос ошибкой при нехватке мощности |

Работа уровня сервиса зависит от текущей модели, плана учётной записи и распознавания возможностей Cherry Studio. Если различия неизвестны, оставьте **Игнорировать** или **Авто**.

{% hint style="info" %}
Гибкая обработка может вернуть `498 capacity_exceeded`, если мощности недостаточно. Она подходит для пакетных задач с повторными попытками, но не для интерактивных запросов, которые должны завершиться успешно с первого раза.
{% endhint %}

## Использование MCP и вызова инструментов

Обычные модели, размещённые Groq, могут использовать MCP и другие инструменты Cherry Studio согласно своим возможностям:

1. Выберите модель с поддержкой вызова инструментов.
2. Включите один простой инструмент MCP.
3. Отправьте запрос, для которого явно требуется инструмент.
4. Убедитесь, что модель действительно вызывает инструмент.
5. Затем добавьте параллельные инструменты или сложные параметры.

Groq Compound использует другой механизм:

- `groq/compound` может использовать несколько серверных инструментов Groq в одном запросе.
- `groq/compound-mini` использует только один серверный инструмент в запросе и обеспечивает меньшую задержку.
- Поиск, доступ к веб-страницам и выполнение кода происходят на серверах Groq.
- Compound не равен MCP Cherry Studio и не позволяет напрямую передавать пользовательские инструменты в Compound.

Для собственных инструментов MCP выберите обычную размещённую модель с поддержкой локального вызова инструментов, а не используйте Compound как среду выполнения MCP.

## Проверка подключения

1. Запустите проверку подключения в области API Key.
2. Выберите синхронизированную и включённую текстовую модель.
3. Убедитесь, что проверка завершена успешно.
4. Запустите проверку работоспособности в списке моделей.
5. Вернитесь на экран чата и отправьте простое сообщение.
6. При использовании инструментов или Compound отдельно протестируйте соответствующую возможность.

Успешная проверка подключения подтверждает только работоспособность базового запроса и не означает, что все модели имеют одинаковый контекст, инструменты и ограничения скорости.

## Подключение совместимого шлюза Groq

Если используется не официальный API Groq:

1. Создайте [Пользовательского провайдера](zi-ding-yi-fu-wu-shang.md).
2. Установите OpenAI Chat Completions в качестве основной конечной точки.
3. Введите Base URL и API Key, предоставленные шлюзом.
4. Синхронизируйте или вручную добавьте модели, фактически предоставляемые шлюзом.
5. Проверьте поддержку вызова инструментов и уровня сервиса.

Не перезаписывайте официальный шаблон Groq. Сторонний шлюз также не получает автоматически доступ к серверным инструментам Groq Compound.

## Частые вопросы

### Возвращается 401

API Key недействителен, отозван или скопирован не полностью. Создайте новый Key и убедитесь, что в нём нет лишних пробелов.

### Возвращается 404 или сообщение «Модель не существует»

Модель снята с обслуживания, ID модели указан неверно или у текущей учётной записи нет доступа. Снова нажмите **Добавить** и синхронизируйте список.

### Возвращается 429

Запрос достиг ограничения скорости модели или учётной записи. Уменьшите параллелизм, повторите попытку позже и проверьте ограничения в GroqCloud Console.

### Возвращается 498

Для гибкого уровня сейчас нет доступной мощности. Переключитесь на авто, обработку по требованию или игнорирование либо добавьте в задачу повторные попытки с задержкой.

### Ответ приходит быстро, но обрезан

Проверьте контекст и ограничение максимального вывода модели, уменьшите длину ввода или скорректируйте максимальное число Token вывода. Скорость вывода не меняет собственные ограничения модели.

### Compound не вызывает мой MCP

Compound использует серверные инструменты Groq и не принимает пользовательские инструменты MCP Cherry Studio. Выберите размещённую модель, поддерживающую обычный вызов инструментов.

### Уровень сервиса не изменился

Текущая модель или учётная запись может не поддерживать выбранный уровень. Оставьте игнорирование или авто и ориентируйтесь на фактические записи запросов в GroqCloud Console.
