# DeepSeek V3.2

Cherry Studio распознаёт DeepSeek V3.2 и его распространённые варианты у разных провайдеров. Возможность бесплатного использования, текущая доступность и конкретный ID модели зависят от выбранного провайдера.

{% hint style="warning" %}
Эта страница больше не гарантирует, что DeepSeek V3.2 всегда входит в число бесплатных пробных моделей CherryAI или CherryIN. Ориентируйтесь на метку **Бесплатно** в средстве выбора моделей, консоль провайдера и фактический результат запроса.
{% endhint %}

## Сначала проверьте доступность модели

1. Откройте средство выбора моделей на экране чата.
2. Найдите `DeepSeek V3.2`.
3. Если модель найдена, проверьте, какому провайдеру она принадлежит.
4. Выберите модель и отправьте простое тестовое сообщение.

Одну и ту же модель могут предоставлять несколько провайдеров, а её отображаемое имя и ID модели API могут различаться. Перед выбором проверьте квоту учётной записи, региональную доступность и правила оплаты провайдера.

## Подключение через провайдера

Если DeepSeek V3.2 отсутствует в средстве выбора моделей:

1. Откройте `Настройки → Провайдеры моделей`.
2. Выберите официальный сервис [DeepSeek](../deepseek.md) или агрегирующего провайдера, который предоставляет эту модель для вашей учётной записи.
3. Введите API Key и проверьте Base URL.
4. Нажмите **Добавить** и примените изменения моделей в предварительном просмотре синхронизации.
5. Найдите DeepSeek V3.2 и включите переключатель нужной модели.
6. Запустите проверку подключения или проверку работоспособности модели.

Реестр моделей Cherry Studio содержит идентификаторы DeepSeek V3.2, используемые разными провайдерами. Они нужны только для распознавания возможностей модели и не означают, что она доступна каждой учётной записи у всех провайдеров.

## Добавление вручную, если модели не удаётся синхронизировать

Некоторые шлюзы не предоставляют API списка моделей. В таком случае нажмите **Пользовательский** и без изменений введите ID модели из консоли провайдера.

Распространённые варианты названия могут включать:

- `deepseek-v3.2`
- `deepseek/deepseek-v3.2`
- варианты с датой или суффиксом `thinking`, `exp` либо `speciale`

{% hint style="danger" %}
Не угадывайте ID модели по этой странице. ID, возможности и маршрутизация различаются у разных провайдеров. Всегда копируйте фактическое значение из консоли провайдера или документации API.
{% endhint %}

## Использование в чате

Серия DeepSeek V3.2 подходит для работы с кодом, анализа длинных текстов, многоэтапных рассуждений и других задач. Рекомендации по использованию:

- включайте возможности рассуждения модели для сложных задач; в простых вопросах не стоит намеренно увеличивать затраты на рассуждение;
- перед вызовом MCP или других инструментов убедитесь, что у модели есть метка поддержки вызова инструментов, и выполните один тест;
- если в длинном диалоге достигнут лимит контекста или вывода, создайте новую тему или уменьшите число вложенных файлов;
- самостоятельно проверяйте важные результаты и не используйте вывод модели напрямую как окончательное решение.

Возможности разных вариантов модели отличаются. Например, версия для рассуждений со специальным суффиксом может не поддерживать вызов инструментов. Ориентируйтесь на возможности модели, показанные в Cherry Studio, и фактические результаты тестирования.

## Частые вопросы

### Модель находится при поиске, но её нельзя выбрать

Убедитесь, что включены и провайдер, и переключатель этой модели. Если модель осталась от прежней конфигурации, снова получите список моделей и повторите проверку.

### Возвращается 401, 403 или сообщение о недостаточном балансе

Проверьте API Key, права учётной записи, баланс и региональные ограничения. После исчерпания пробной квоты можно сменить провайдера или настроить собственный API Key.

### Возвращается сообщение «Модель не существует»

Обычно это означает, что ID модели не соответствует провайдеру. Удалите ошибочную запись и снова получите список либо скопируйте полный ID из документации провайдера и добавьте его вручную.

### Инструменты недоступны

Наличие у провайдера модели с таким названием не означает, что соответствующая конечная точка поддерживает вызов инструментов. Проверьте метки возможностей модели и при необходимости выберите вариант или провайдера с поддержкой вызова инструментов.

Общие правила бесплатного пробного доступа приведены на странице [CherryAI (бесплатный пробный доступ)](../cherryin/README.md), а процесс настройки провайдера — на странице [Провайдеры моделей](../README.md).
