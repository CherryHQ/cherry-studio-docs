# ZhiPu GLM-4.6V

Cherry Studio распознаёт GLM-4.6V и его распространённые варианты у разных провайдеров. Стандартная версия распознаётся как мультимодальная модель с поддержкой изображений, файлов, рассуждений и вызова инструментов. Фактически доступные возможности зависят от API, предоставленного провайдером.

{% hint style="warning" %}
Эта страница больше не гарантирует, что GLM-4.6V всегда входит в число бесплатных пробных моделей CherryAI или CherryIN. Возможность бесплатного использования и текущую доступность проверяйте в средстве выбора моделей, консоли провайдера и по фактическому результату запроса.
{% endhint %}

## Сначала проверьте доступность модели

1. Откройте средство выбора моделей на экране чата.
2. Найдите `GLM-4.6V`.
3. Проверьте провайдера модели и метки поддержки зрения, файлов, рассуждений и вызова инструментов.
4. Выберите модель и загрузите для проверки изображение без конфиденциальных данных.

Одну и ту же модель могут предоставлять несколько провайдеров, а её отображаемое имя, ID и метки возможностей могут различаться.

## Подключение через провайдера

Если GLM-4.6V отсутствует в средстве выбора моделей:

1. Откройте `Настройки → Провайдеры моделей`.
2. Выберите ZhiPu или агрегирующего провайдера, который предоставляет эту модель для вашей учётной записи.
3. Введите API Key и проверьте Base URL.
4. Нажмите **Добавить** и примените изменения моделей из предварительного просмотра синхронизации.
5. Найдите и включите GLM-4.6V.
6. Запустите проверку подключения или проверку работоспособности модели.

Реестр моделей Cherry Studio распознаёт идентификаторы GLM-4.6V, используемые разными провайдерами, но это не гарантирует, что модель уже доступна для вашей учётной записи.

## Выбор подходящего варианта

Провайдер может одновременно предлагать стандартную версию, Flash, FP8 или версии с другими суффиксами. Это отдельные модели, поэтому сходство названий не означает одинаковых возможностей.

- Для понимания изображений убедитесь, что у модели есть возможность **Зрение** или **Распознавание изображений**.
- Для загрузки документов убедитесь, что модель поддерживает **Ввод файлов**.
- Для работы с MCP или другими инструментами убедитесь, что модель поддерживает **Вызов инструментов**.
- Для задач только с текстом выберите подходящий вариант с учётом скорости, квоты и тарифов провайдера.

{% hint style="danger" %}
Не угадывайте ID модели по этой странице. Скопируйте полный ID из консоли провайдера или документации API. Ошибочный ID может привести к ответу «Модель не существует» или перенаправить запрос к другому варианту.
{% endhint %}

## Использование изображений в чате

1. Выберите GLM-4.6V с поддержкой зрения.
2. Перетащите изображение в область ввода, вставьте его или добавьте с помощью кнопки вложений.
3. В том же сообщении опишите задачу, например извлечение таблицы, объяснение диаграммы или анализ интерфейса.
4. Перед отправкой убедитесь, что изображение не содержит API Key, персональных или других конфиденциальных данных.

Если область ввода не позволяет добавить изображение, текущая модель, как правило, не распознана как модель с поддержкой зрения. Повторно синхронизируйте модель или проверьте настройки возможностей на странице её редактирования.

## Частые вопросы

### Изображение загружено, но модель не может его распознать

Убедитесь, что выбран вариант GLM-4.6V с поддержкой зрения, а конечная точка провайдера поддерживает ввод изображений. Одинакового названия недостаточно, чтобы подтвердить одинаковые возможности API.

### Модель отвечает в чате, но не вызывает инструменты

Сначала проверьте метку поддержки вызова инструментов, а затем протестируйте простой инструмент. Провайдер может не предоставлять вызов инструментов для этого варианта или использовать несовместимый API.

### GLM-4.6V отсутствует в списке синхронизации

Проверьте в консоли провайдера, доступна ли эта модель для вашей учётной записи. Если API не возвращает список моделей, нажмите **Пользовательский** и введите ID модели, указанный провайдером.

### Возвращается сообщение о слишком большом файле или контексте

Уменьшите число или разрешение изображений, разделите длинный документ и повторите попытку в новой теме. Конкретные ограничения зависят от провайдера и варианта модели.

Общие правила бесплатного пробного доступа приведены на странице [CherryAI (бесплатный пробный доступ)](../cherryin/README.md), а процесс настройки провайдера — на странице [Провайдеры моделей](../README.md).
