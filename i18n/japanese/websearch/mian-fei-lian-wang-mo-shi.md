# 無料 Web 検索モード

検索サービス用の API Key を別途申請したくない場合は、Cherry Studio V2 で次の組み合わせを使用できます。

```text
デフォルト検索プロバイダー：ExaMCP
デフォルト URL 取得プロバイダー：Fetch
```

現在のバージョンでは、この組み合わせに追加の検索 API Key は必要ありません。

- ExaMCP はキーワードから Web ページを検索します。
- Fetch は検索結果または指定された URL の本文を直接読み取ります。
- 通常のモデルは、ツール呼び出しを通じてこの 2 つの機能を使用します。

{% hint style="warning" %}
ここでの「無料」とは、Cherry Studio で追加の検索 API Key を設定する必要がないという意味です。関連するすべてのサービスが永久に無料という意味ではありません。モデルの呼び出しには料金が発生する場合があり、ExaMCP の公開ポリシー、クォータ、利用可能性も変更される可能性があります。
{% endhint %}

## 適した用途

適しているケース：

- Web 検索を初めて試す場合。
- ときどき最新情報を調べる場合。
- 複数の検索プラットフォームのアカウント登録をしたくない場合。
- Tavily、Exa、Bocha などのサービスの API Key をまだ取得していない場合。
- モデルのツール呼び出し性能を先に確認したい場合。

安定した大量利用、一定のサービスレベル、企業向けコンプライアンス、または完全な管理権限が必要な場合は、正式なアカウントで検索 API を使用するか、独自の SearXNG をデプロイしてください。

## 動作の仕組み

一般的な外部 Web 検索の流れは次のとおりです。

1. モデルが質問には検索が必要だと判断します。
2. モデルが ExaMCP を呼び出し、検索キーワードを送信します。
3. ExaMCP が候補となる Web ページを返します。
4. モデルが必要に応じて Fetch を呼び出し、特定の URL を読み取ります。
5. Cherry Studio が Web ページの主要な本文を抽出します。
6. モデルが返された内容に基づいて回答と引用を構成します。

ExaMCP と Fetch は役割が異なり、互いに置き換えることはできません。

| プロバイダー | 機能 | 通常モデルの Web 検索設定を単独で完結できるか |
| --- | --- | --- |
| ExaMCP | キーワード検索 | 不可。デフォルト URL 取得プロバイダーが必要 |
| Fetch | URL の読み取り | 不可。デフォルト検索プロバイダーが必要 |
| ExaMCP + Fetch | Web ページの検索と読み取り | 可能 |

{% hint style="info" %}
現在のモデルが独自のネイティブ Web 検索を使用する場合、Cherry Studio はこの外部の組み合わせへ切り替えません。ネイティブ Web 検索はモデルプロバイダーが実行し、料金と引用形式もそのプロバイダーの規定に従います。
{% endhint %}

## ExaMCP と Fetch の設定

### 1. Web 検索設定を開く

以下からアクセスします：

```text
設定 → Web 検索
```

ページ上部には2つの独立したオプションがあります：

- **デフォルト検索プロバイダー**。
- **デフォルト URL 取得プロバイダー**。

### 2. ExaMCP を選択する

**デフォルト検索プロバイダー**で次を選択します：

```text
ExaMCP
```

ExaMCP の詳細ページを開き、**デフォルトに設定**をクリックすることもできます。

現在のデフォルトアドレスは以下の通りです：

```text
https://mcp.exa.ai/mcp
```

通常は変更する必要がなく、API Key の入力も不要です。**検出**をクリックし、現在のネットワークからこのサービスへアクセスできることを確認してください。

{% hint style="warning" %}
出所不明の MCP アドレスへ安易に API アドレスを変更しないでください。検索語はそのアドレスへ送信され、悪意のあるサービスから誤解を招く内容が返される可能性があります。
{% endhint %}

### 3. Fetch を選択する

**デフォルト URL 取得プロバイダー**で次を選択します：

```text
Fetch
```

Fetch は Cherry Studio 組み込みの Web ページ読み取り機能です。API Key は不要で、リモート抽出サービスのアドレスを入力する項目もありません。

### 4. 2つのデフォルト項目を確認する

最終的には両方が同時に表示されている必要があります：

| 設定項目 | 選択 |
| --- | --- |
| デフォルト検索プロバイダー | ExaMCP |
| デフォルト URL 取得プロバイダー | Fetch |

どちらか一方しか設定していない場合、通常のモデルで Web 検索アイコンをクリックすると、引き続き設定画面へ移動するよう案内されます。

## 対話での使用方法

1. 対話ページに戻ります。
2. ツール呼び出しの動作が安定しているチャットモデルを選択します。
3. 入力ボックスの下にある**地球**アイコンをクリックします。
4. リアルタイムの情報が必要な質問を送信します。

初回テストには以下を使用できます：

```text
Cherry Studio の直近の正式リリースを検索し、公式 GitHub Release だけを引用して、
バージョン番号、リリース日、および主な変更点を 3 つ挙げてください。
```

回答後、以下の点を確認してください：

- 実際に検索が実行されたか。
- 開ける引用が表示されているか。
- 引用が要求されたソースから来ているか。
- バージョン番号とリリース日が原文と一致しているか。

## Fetch で読み取れるもの

Fetch は、Cherry Studio が動作するコンピューターから対象 URL へ直接リクエストを送り、返された HTML から主要な本文を抽出して、モデルが読みやすいテキストへ変換します。

通常適しているのは：

- ニュースやブログの本文。
- 製品ドキュメント。
- 静的な Web ページ。
- ログインが不要な公開ページ。
- 検索結果内の記事リンク。

以下のようなページは失敗するか、内容が不完全になる可能性があります：

- ログイン後にのみ閲覧できるページ。
- 主要なコンテンツがブラウザスクリプトに依存して読み込まれるページ。
- CAPTCHA や強力なボット対策がある Web サイト。
- 特定の地域またはネットワークでのみアクセスが許可されるページ。
- PDF、音声・動画、または HTML 以外のファイル。
- 有効期限切れ、異常なリダイレクト、または証明書エラーがあるリンク。

Fetch の 1 回の読み取りにはタイムアウトがあります。対象サイトの応答が遅すぎる場合、モデルが本文を取得できないことがあります。

## 「追加キー不要」＝「コストゼロ」ではない

以下の費用が発生する可能性があります：

- モデルの入力および出力トークン料金。
- 検索結果が占有するコンテキスト。
- ローカルまたはサーバーのネットワークトラフィック。
- セルフホストした SearXNG の機器、ドメイン、運用費用。
- サードパーティサービスが将来調整した場合の呼び出し費用。

検索結果が多く、Web ページの本文が長いほど、モデルのコンテキスト消費は通常増えます。**設定 → Web 検索**で**検索結果数**を減らすか、**切り詰め**を有効にできます。

## プライバシーに関する説明

ExaMCP + Fetch を使用する場合：

- 検索キーワードは ExaMCP サービスに送信されます。
- Fetch はローカルから対象サイトへ直接アクセスします。
- 対象サイトは通常、リクエスト元のネットワークアドレスを確認できます。
- 検索結果と Web ページの本文は、現在のモデルプロバイダーにコンテキストとして送信されます。

以下の内容を検索語や URL に含めないでください：

- API Key、パスワード、または認証コード。
- アクセストークンを含むプライベートシステムへのリンク。
- 顧客データや個人識別情報。
- 企業の内部機密。

{% hint style="danger" %}
Web ページの内容は信頼できない入力です。Web ページやモデルの回答に含まれる出所不明のコマンドを実行したり、指示に従ってセキュリティソフトを無効にしたり、キーをアップロードしたり、不審なファイルをダウンロードしたりしないでください。
{% endhint %}

## その他の低コストな方法

### モデルネイティブ Web 検索を使用する

ネイティブ Web 検索に対応するモデルを使用している場合、通常は検索 API Key を別途設定する必要はありません。ただし、モデルの Web 検索がモデル料金に含まれる場合があるため、無料とは限りません。

### SearXNG + Fetch をセルフホストする

検索のエントリーポイントを自分で制御したい場合は、以下を使用できます：

```text
デフォルト検索プロバイダー：SearXNG
デフォルト URL 取得プロバイダー：Fetch
```

SearXNG 自体は Cherry Studio に検索 API Key の入力を要求しませんが、アクセス可能なインスタンスが必要です。セルフホストする場合、デプロイ、更新、セキュリティ、および上流検索エンジンの制限は自分で管理する必要があります。

詳細は [SearXNG の設定](searxng.md)を参照してください。

### プロバイダーの無料枠を使用する

一部の検索 API は、新規アカウント向けに試用枠や無料枠を提供する場合がありますが、条件は変更される可能性があります。登録前に、プロバイダーの最新の公式料金、地域制限、プライバシーポリシーを確認してください。古いチュートリアルの枠数を前提に長期計画を立てないでください。

## よくある質問

### ExaMCP の検出に失敗する

以下の項目を順に確認してください：

1. 現在のネットワークから `https://mcp.exa.ai/mcp` にアクセスできるか。
2. プロキシが正しく設定され、Cherry Studio から利用できるか。
3. DNS、ファイアウォール、またはセキュリティソフトウェアによってブロックされていないか。
4. ExaMCP サービスが一時的に利用できない状態ではないか。
5. API アドレスが誤って変更されていないか。

デフォルトアドレスへ戻してから再度検出してください。それでも失敗する場合は、別の検索プロバイダーへ切り替えるか、SearXNG をセルフホストしてください。

### Fetch で読み取れない

まず通常のブラウザで同じ URL を開いてください。ブラウザでもアクセスできない場合は、ネットワーク、ログイン、地域、または証明書の問題を先に解決してください。

ブラウザでは開けるのに Fetch が失敗する場合、一般的な原因は次のとおりです：

- ページが JavaScript に依存している。
- Web サイトが Cookie、ログイン状態、または CAPTCHA を要求している。
- Web サイトが自動リクエストをブロックしている。
- 返された内容が、本文を抽出できる HTML ではない。
- 応答時間が制限を超えている。

別の情報源へ切り替えるか、分析したい Web ページの本文を手動でコピーして会話へ貼り付けてください。

### 2 項目を設定したが、モデルが検索しない

Web 検索スイッチはツールを利用可能にするだけで、呼び出すかどうかはモデルが判断します。次を試してください：

- 地球アイコンがハイライトされているか確認する。
- 「まず Web 検索を行い、その後回答し、出典を引用してください」と明確に要求する。
- ツール呼び出し能力がより安定しているモデルに切り替える。
- 問題をより具体的に記述し、時間範囲や優先ソースを与える。
- 新しい対話を開始して再試行する。

### 検索結果はあるが、Web ページの本文がない

ExaMCP が候補リンクを返しても、Fetch が一部のページを読み取れない場合があります。結果数を減らす、別の情報源へ切り替える、または公開アクセスできる具体的な URL をモデルへ直接渡してください。
