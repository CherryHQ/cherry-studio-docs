# チャンネル

チャンネルを使うと、Cherry Studio の[エージェント](agent.md)をインスタントメッセージングプラットフォームに接続できます。グループチャットや個人チャットでメンバーがメッセージを送ると、バインドされたエージェントが Cherry Studio でリクエストを処理し、元の会話に結果を返信します。

現在、次のプラットフォームに対応しています。

* Feishu / Lark
* Telegram
* QQ
* WeChat
* Discord
* Slack

たとえば、ナレッジアシスタントに Feishu グループ内の社内質問へ回答させたり、パーソナルアシスタントに Telegram から指示を受け取らせたり、[スケジュールタスク](scheduled-tasks.md)の日報を指定したチャンネルへ送信したりできます。

{% hint style="info" %}
チャンネルは Cherry Studio 上でローカルに動作します。アプリを終了すると、チャンネル接続とメッセージ処理も停止します。アプリをもう一度開くと、有効でエージェントがバインドされているチャンネルは自動的に再接続されます。チャンネルは API サーバーに依存しません。
{% endhint %}

## 使用前の準備

チャンネルを追加する前に、次の準備を行います。

1. 正常にチャットできる[エージェント](agent.md)を作成し、設定します。
2. エージェントに利用可能なモデルを選択し、プロバイダー設定が有効であることを確認します。
3. 対象プラットフォームで必要なボットの認証情報を用意するか、Feishu または WeChat の QR コード連携を使用します。

チャンネルには通常のエージェントも、自律モードを有効にしたエージェントもバインドできます。手動でチャンネルを作成する場合、自律モードは必要ありません。エージェント自身にチャンネルを作成させたり、接続問題を調べさせたり、タスクと連携させたりする場合は、自律モードを有効にしたエージェントを使用し、ツール権限を慎重に確認することをおすすめします。

## チャンネルを追加する

`設定 → チャンネル` を開き、対象プラットフォームを選択して **追加** をクリックします。

共通して設定する項目は次のとおりです。

| 設定項目 | 説明 |
|---|---|
| 名前 | 同じプラットフォーム上の複数のチャンネルインスタンスを区別します |
| バインドエージェント | チャンネルメッセージを処理するエージェント。バインドされていない場合、チャンネルは接続されません |
| プラットフォーム認証情報 | プラットフォームごとに必要な App ID、Token、Secret |
| 許可するチャット ID | ボットを使用できる会話を制限します |
| チャンネル権限モード | エージェント設定を継承するか、このチャンネル専用の権限モードを指定します |
| 有効状態 | 有効にするとすぐに接続を試みます。無効にすると設定を残したまま切断します |

同じプラットフォームに複数のインスタンスを追加でき、1 つのエージェントを複数のチャンネルにバインドすることもできます。たとえば、同じエージェントを Feishu グループと Telegram の個人チャットへ同時に接続しながら、各チャンネルインスタンスで異なる認証情報、許可リスト、権限モードを使用できます。

保存後、チャンネルの詳細で接続状態を確認できます。有効状態、認証情報、バインドするエージェントを変更すると、Cherry Studio はそのインスタンスへ再接続します。

## プラットフォーム別の設定

{% tabs %}
{% tab title="Feishu / Lark" %}
Feishu と Lark には、2 種類の接続方法があります。

* **QR コード連携**：App ID と App Secret を入力せずに有効化し、ページに表示される QR コードをスキャンします。登録が完了すると、Cherry Studio が取得した認証情報を保存して再接続します。
* **手動連携**：自作アプリの App ID と App Secret を入力し、`Feishu` または `Lark` のドメインを選択します。Encrypt Key と Verification Token は、アプリの設定に応じて任意で入力します。

アプリを手動で作成する場合は、対応するオープンプラットフォームでボット機能、メッセージ権限、長時間接続のイベントサブスクリプションを有効にしてください。Feishu と Lark のアプリおよびドメインを混在させることはできません。
{% endtab %}

{% tab title="Telegram" %}
Telegram の Bot Token を使用します。BotFather でボットを作成し、Token を取得できます。

許可リストには Telegram Chat ID を使用します。ボットが接続されたら、対象の個人チャットまたはグループチャットで `/whoami` を送信すると、現在の Chat ID を確認できます。
{% endtab %}

{% tab title="QQ" %}
QQ ボットアプリの App ID と Client Secret を入力します。

許可リストでは、次のように種類を付けた会話 ID を使用できます。

* `c2c:openid`：個人チャット
* `group:groupid`：グループチャット
* `channel:channelid`：チャンネル
* `dm:guildid`：チャンネルのダイレクトメッセージ

`/whoami` を送信すると、現在の会話の種類と ID を確認できます。
{% endtab %}

{% tab title="WeChat" %}
WeChat は QR コードでログインするため、Token を手動で入力する必要はありません。インスタンスを追加して有効にした後、WeChat で QR コードをスキャンしてログインします。ログイン認証情報は Cherry Studio のローカルデータディレクトリに保存されます。

許可リストには WeChat のユーザー ID を入力します。会話で `/whoami` を送信すると、現在の ID を確認できます。
{% endtab %}

{% tab title="Discord" %}
Discord Bot Token を入力し、ボットを対象サーバーに招待します。

許可リストには Discord Channel ID を入力します。対象チャンネルまたはダイレクトメッセージで `/whoami` を送信し、Cherry Studio が返した会話 ID をコピーすることもできます。
{% endtab %}

{% tab title="Slack" %}
Slack は Socket Mode を使用するため、次の 2 つが必要です。

* 通常 `xoxb-` で始まる Bot Token
* 通常 `xapp-` で始まる App-Level Token

アプリをインストールしてメッセージ権限を付与した後、ボットを対象チャンネルに追加します。許可リストには Slack Channel ID を入力します。`/whoami` を送信して取得することもできます。
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
ボットの認証情報は、アカウントへのアクセス資格情報と同等です。Token や Secret を公開チャット、スクリーンショット、ドキュメントに含めないでください。漏えいした可能性がある場合は、すぐに対象プラットフォームで取り消し、新しい認証情報を生成してください。
{% endhint %}

## アクセスできる会話を制限する

**許可するチャット ID** は、チャンネルのアクセス制御に使用します。

* **空欄**：ボットへメッセージを送信できるすべての会話から、エージェントを呼び出せます。
* **ID を入力**：リスト内の会話だけがエージェントを呼び出せます。それ以外のメッセージは無視されます。

許可リストが空欄の場合、Cherry Studio はボットと正常にやり取りした会話 ID を自動的に記録します。この記録は、[スケジュールタスク](scheduled-tasks.md)から能動的に送信する宛先としても使用できます。

まず対象の会話で `/whoami` を送信し、返された ID をコピーして許可リストへ追加することをおすすめします。グループチャットや複数人が参加する環境では、長期間空欄のままにしないでください。

## チャンネル権限を設定する

チャンネル権限は、そのチャンネルから受信したリクエストがエージェントのツールをどのように呼び出せるかを決めます。デフォルトでは **エージェントから継承** が選択されます。現在のチャンネルだけ、次のモードで上書きすることもできます。

* **デフォルトモード**：機密性の高い操作を実行する前に、デフォルトのルールに従って確認します。
* **編集を受け入れる**：ファイル編集を自動的に承認しますが、その他の高リスク操作は引き続き制限されます。
* **権限チェックをバイパス**：確認を求めなくなる、最もリスクの高いモードです。
* **プランモード**：分析と計画の作成を優先し、変更は直接実行しません。

チャンネル権限はメッセージを受信するたびに適用されるため、変更後は既存の会話にも反映されます。

{% hint style="danger" %}
インスタントメッセージングのメッセージは外部入力です。**権限チェックをバイパス** を使用するのは、エージェントのワークスペース、ツール、許可リストが厳密に制限されている場合だけにしてください。公開グループのボットに機密ディレクトリや認証情報へアクセスさせないでください。
{% endhint %}

## チャンネルでコマンドを使用する

接続後、ボットへ次のコマンドを送信できます。

| コマンド | 機能 |
|---|---|
| `/new` | 現在のチャンネルを新しいセッションへ切り替えます |
| `/compact` | 現在のセッションのコンテキストを圧縮します |
| `/help` | エージェント情報と使用可能なコマンドを表示します |
| `/whoami` | 許可リストの設定に使用する、現在の会話 ID を表示します |

同じチャンネルで異なるチームに対応する場合や、権限レベルの異なる作業を行う場合は、1 つの高権限設定を共用せず、チャンネルインスタンスを分けて、それぞれにエージェント、許可リスト、権限を設定することをおすすめします。

## スケジュールタスクと連携する

チャンネルはメッセージを受信できるだけでなく、[スケジュールタスク](scheduled-tasks.md)の送信先としても使用できます。

1. チャンネルを作成し、接続します。
2. 対象の会話で少なくとも 1 回ボットとやり取りするか、許可するチャット ID を直接入力します。
3. スケジュールタスクを作成し、送信先のチャンネルを選択します。

許可リストが空欄で、対象の会話が一度もボットとやり取りしていない場合、Cherry Studio には能動的に送信できる宛先がない可能性があります。

## 接続問題を解決する

### 保存後も未接続と表示される

次の項目を順に確認してください。

1. チャンネルが有効で、エージェントがバインドされているか。
2. エージェントのモデルとプロバイダーが正常に使用できるか。
3. Token、Secret、App ID、プラットフォームのドメインが一致しているか。
4. ボットが対象のワークスペース、サーバー、グループチャットにインストールされ、メッセージ権限を付与されているか。
5. チャンネル詳細の **ログ** を開き、リアルタイムの接続エラーを確認します。

誤った設定を修正して保存すると、Cherry Studio がチャンネルへ再接続します。そのインスタンスを一度無効にしてから、もう一度有効にすることもできます。

### ボットはオンラインだが返信しない

* 現在の会話 ID が許可リストに含まれているか確認します。
* グループチャットで、ボットがメッセージを読み取れることを確認します。一部のプラットフォームでは、ボットへのメンションやグループメッセージの追加権限が必要です。
* Cherry Studio が引き続き起動していることを確認します。
* エージェントのモデルが利用可能で、チャンネル権限によって必要なツールがブロックされていないことを確認します。

### QR コードをスキャンしても接続が完了しない

* QR コードの有効期限が切れていないか確認します。期限切れの場合は、もう一度 QR コード連携を開始してください。
* Feishu / Lark では、選択したドメインと一致するクライアントアカウントを使用してください。
* WeChat のログインが無効になった場合は、もう一度 QR コードをスキャンすると、ローカルのログイン認証情報が更新されます。

{% hint style="warning" %}
各プラットフォームでは、ボット、メッセージの保存、自動化された動作に関する利用規約や組織管理要件が異なります。ボットを企業グループや外部向けサービスへ追加する前に、必要な許可を得ていることを確認してください。
{% endhint %}
