# トレース（Trace）

トレース（Trace）を使うと、1 回の会話が Cherry Studio 内部でどのような処理を経たかを確認できます。OpenTelemetry の Trace と Span を基盤に、モデルリクエスト、ツール呼び出し、ナレッジベース検索などの処理をツリー構造で整理し、各ノードの所要時間、状態、入出力、Token 使用量を表示します。

回答が期待どおりでない、ツール呼び出しが失敗する、または応答が遅い場合、トレースは問題がどの層で発生したかを判断するのに役立ちます。

* 正しいコンテキストがモデルに渡されたか。
* Web 検索またはナレッジベース検索から何が返されたか。
* MCP ツールにどのパラメーターが渡されたか。
* どの処理に最も時間がかかったか、またはエラーが返されたか。
* 複数モデルの各回答で何 Token 使用されたか。

{% hint style="warning" %}
トレースは開発者向けの診断機能で、プロンプト、モデルの出力、ツールのパラメーター、検索内容が保存される場合があります。機密情報を含む本番環境の会話で長期間有効にしたり、内容を確認せずに完全な Trace を共有したりしないでください。
{% endhint %}

## トレースを有効にする

1. `設定 → 一般設定` を開きます。
2. **開発者モード** を探します。
3. **開発者モードを有効にする** をオンにします。
4. Cherry Studio を完全に終了し、もう一度起動します。
5. 新しい会話を作成してメッセージを送信します。

{% hint style="info" %}
アプリの再起動が必要です。Trace ウィンドウとキャッシュサービスは、Cherry Studio の起動時に開発者モードの状態に応じて有効化されます。スイッチを切り替えただけで再起動しない場合、入口が表示されない、またはデータを読み取れないことがあります。
{% endhint %}

有効化する前に生成されたメッセージにトレースがさかのぼって作成されることはありません。再起動後に新しく実行され、Trace ID が正常に記録されたメッセージだけに入口が表示されます。

## 1 件のトレースを開く

通常の会話ページで確認したいメッセージを探し、メッセージの操作バーにマウスポインターを合わせて、**トレース** アイコンをクリックします。

現在、この入口が表示されるのは通常の会話メッセージだけです。Agent Session のメッセージ操作バーにはトレースボタンが表示されません。

ボタンは、次の条件をすべて満たした場合にだけ表示されます。

* 開発者モードが有効になっている。
* 現在のメッセージに Trace ID が含まれている。
* 今回のアプリ起動時に Trace サービスが有効化されている。

Cherry Studio は独立したトレースウィンドウを開きます。別のメッセージのトレースボタンをクリックすると、既存のウィンドウが対応する Trace に切り替わります。

同じ質問に対して複数モデルの回答が生成された場合は、各モデルの回答メッセージでトレースを個別に開いてください。ウィンドウ内の Trace データは、そのメッセージのモデルで絞り込まれます。

## Trace ツリーの見方

1 回の完全なリクエストが 1 つの Trace に対応し、各処理ステップが 1 つの Span に対応します。子ノードは、その処理が親ノードのコンテキスト内で発生したことを表します。

ノードを選択すると、詳細エリアに次の情報が表示される場合があります。

| 情報 | 用途 |
|---|---|
| 開始時刻と終了時刻 | 処理の順序を確認する |
| Duration | 時間のかかった処理を特定する |
| エラー表示 | ノード名が赤くなった場合に、その処理の異常出力を確認する |
| Input / Attributes | 入力、パラメーター、コンテキストを確認する |
| Outputs | 戻り値を確認する。エラー情報もここに表示される |
| Token Usage | Prompt Token と Completion Token を比較する |

すべてのリクエストに同じノードが表示されるわけではありません。実際の構造は、使用したモデル、Web 接続の有無、ナレッジベースの関連付け、MCP ツールの呼び出し状況によって変わります。

### モデル呼び出し

モデルノードでは、次の項目を確認できます。

* 実際に呼び出されたモデル。
* モデルに送信された入力。
* モデルが返したテキストまたはストリーミング結果。
* Prompt Token と Completion Token。
* リクエストの所要時間とエラー状態。

回答に明らかな情報漏れがある場合は、まず関連するコンテキストがモデルの入力に含まれていたかを確認してください。

### Web 検索

Web 検索を使用した場合、Trace には検索リクエスト、結果の整理、モデル呼び出しなどのノードが含まれることがあります。特に次の点を確認してください。

* 検索語句が適切か。
* 検索結果が正常に返されたか。
* 結果が選別されたうえでモデルに渡されたか。
* 検索の所要時間が主なボトルネックになっていないか。

### ナレッジベース検索

[ナレッジベース](../knowledge-base/knowledge-base.md)を関連付けると、期待する内容が検索されたかをトレースで確認できます。検索クエリ、返された断片、類似度情報、最終的にモデルへ渡されたコンテキストを確認してください。

ナレッジベースノードに結果がない場合は、埋め込みモデル、ドキュメントの処理状態、検索しきい値、ユーザーの質問表現も確認します。

### MCP ツール呼び出し

[MCP](mcp/README.md) を使用した場合、Trace でツール名、呼び出しパラメーター、戻り値、所要時間、エラーを確認できます。

ツールの実行に失敗した場合は、次の状況を区別してください。

* モデルが誤ったツールを選択した。
* ツールのパラメーターが不足している、または形式が正しくない。
* MCP Server が実行されていない、または接続に失敗した。
* ツールは実行されたが、戻り値がモデルに正しく使用されなかった。

{% hint style="info" %}
Trace は診断データを表示するだけで、失敗した処理を自動的に再試行または修復することはありません。原因を確認したら、会話、モデル、ナレッジベース、または MCP の設定に戻って変更してください。
{% endhint %}

## データの保存と削除

Trace データは、現在のユーザーのホームディレクトリに保存されます。

```
~/.cherrystudio/trace
```

その下に、トピック ID と Trace ID ごとにデータが整理されます。Windows の `~` は現在のユーザーディレクトリを表します。たとえば `C:\Users\<ユーザー名>` です。

メッセージまたはトピックを削除すると、Cherry Studio は対応する一部の Trace データを削除します。ローカルの Trace をすべて削除するには：

1. `設定 → データ設定` を開きます。
2. キャッシュ情報を探します。
3. **キャッシュをクリア** をクリックして確認します。

キャッシュをクリアすると、他のアプリキャッシュも同時に削除されます。実行前に、残しておく必要がある診断データがないことを確認してください。

{% hint style="danger" %}
Cherry Studio の実行中に Trace ファイルを手動で編集しないでください。共有が必要な場合は、必要なノードだけをスクリーンショットに撮り、API キー、個人データ、ファイルパス、業務内容を事前にマスキングしてください。
{% endhint %}

## よくある質問

### 開発者モードを有効にしたが、トレースボタンがない

次の順に確認してください。

1. 有効化した後、Cherry Studio を完全に再起動したか。
2. 現在のメッセージが再起動後に新しく生成されたものか。
3. 通常の会話メッセージを表示しているか。Trace ID のない過去のメッセージには入口が表示されません。
4. 新しいトピックを作成し、簡単なメッセージを 1 件送信してテストする。

### トレースウィンドウが空

* 現在のモデル出力とツール呼び出しが完了するまで待ってから、もう一度開きます。
* 対応するメッセージが削除されておらず、Trace キャッシュも消去されていないことを確認します。
* 開発者モードを有効にした直後の場合は、アプリを再起動して新しい会話を作成してから再試行します。
* 複数モデルの回答では、各モデルの回答メッセージからトレースを個別に開きます。

### ナレッジベース、検索、MCP ノードが表示されない

対応する機能が今回のリクエストで実際に実行された場合にだけ、関連する Span が表示されます。まず、会話結果とモデルのツール呼び出し履歴から、その処理が本当に発生したかを確認してください。

### Trace データが多すぎる

調査が終わったら開発者モードを無効にし、Cherry Studio を再起動してください。すぐにローカルストレージを解放する必要がある場合は、データ設定からキャッシュを消去できます。

***

### 💡 ヘルプとフィードバック

トレースデータに異常がある場合は、必要な Trace のスクリーンショット、Cherry Studio のバージョン、使用したモデル、ナレッジベース、Web 検索、MCP を有効にしていたかを添えてフィードバックを送信することを推奨します。公式窓口は [フィードバックと提案](../question-contact/suggestions.md) を参照してください。
