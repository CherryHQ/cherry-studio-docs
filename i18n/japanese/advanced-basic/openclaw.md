# OpenClaw

Cherry Studio では OpenClaw をインストールして管理し、ローカル環境で OpenClaw Gateway を起動できます。また、Cherry Studio に設定済みのモデルサービスを OpenClaw に同期できます。起動に成功すると、Cherry Studio 内に OpenClaw のダッシュボードが自動的に表示され、WhatsApp、Telegram、Slack、Discord などのチャンネルを引き続き設定できます。

OpenClaw は独立して動作するパーソナル AI アシスタントであり、Cherry Studio の[エージェント](agent.md)とは異なります。Cherry Studio 内でチャットやツールを使ったタスクを行うだけなら、エージェントを使用してください。OpenClaw のダッシュボード、チャンネル、実行方式が必要な場合に、この機能を有効にします。

{% hint style="warning" %}
OpenClaw には高いシステム権限があり、エージェントのタスクによっては多くのトークンを消費することもあります。信頼できるデバイスとワークスペースでのみ実行し、許可されているファイル、コマンド、外部チャンネルへのアクセスを確認してください。
{% endhint %}

## OpenClaw を開く

1. 上部のタブバー右側にある **+** をクリックして、**ランチャー**を開きます。
2. **オープンクロー**をクリックします。
3. Cherry Studio が、自身で管理している OpenClaw がインストール済みか確認します。

Cherry Studio が使用するのは、自身の管理ディレクトリにある OpenClaw バイナリだけです。システムの `PATH` に別の方法でインストールした OpenClaw が存在していても、ページには管理対象バージョンのインストールまたは移行が案内されます。これにより、古いバージョンを誤って使用することを防ぎます。

## 管理対象バージョンをインストールする

初めて開いたときは、**OpenClawをインストール** をクリックします。Cherry Studio が現在の OS とプロセッサに合ったスタンドアロンバイナリをダウンロードし、インストールログを表示します。Node.js や Git を事前にインストールする必要はありません。

macOS、Windows、Linux の x64 または ARM64 に対応しています。ダウンロード時には利用可能な配布元が自動的に選択され、中国本土のネットワーク環境ではミラーが優先的に試されます。

インストールが完了すると、OpenClaw のインストール先がページに表示されます。macOS と Linux では、Cherry Studio は `/usr/local/bin/openclaw` へのリンク作成も試みます。Windows では、管理ディレクトリを現在のユーザーの `PATH` に追加します。これらはターミナルからの実行を便利にするための処理であり、Cherry Studio は引き続き管理対象のパスから OpenClaw を起動します。

## モデルを選択して起動する

起動する前に、Cherry Studio のモデルサービス設定で少なくとも 1 つの利用可能なプロバイダーを有効にし、そのモデルが正常に呼び出せることを確認してください。次に、以下の手順を行います。

1. OpenClaw ページでモデルを選択します。
2. **スタートゲートウェイ** をクリックします。
3. Cherry Studio が、選択したプロバイダーとモデルの設定を OpenClaw に同期します。
4. ローカル環境で Gateway を起動し、ヘルスチェックが完了するまで待機します。
5. 起動に成功すると、OpenClaw のダッシュボードが Cherry Studio 内に自動的に表示されます。

モデル一覧には、有効で利用可能なプロバイダーだけが表示されます。Ollama や LM Studio などのローカルサービスでは API Key を空欄にできますが、その他のプロバイダーでは通常、API Key とモデルの設定が必要です。

Gateway のデフォルトアドレスは `127.0.0.1:18790` です。実行中は、OpenClaw ページにステータスとポートが表示されます。ダッシュボードを閉じても Gateway は停止しません。もう一度開くには、**ダッシュボードを開く** をクリックしてください。

{% hint style="info" %}
**スタートゲートウェイ** をクリックするたびに、Cherry Studio は現在選択されているモデルを先に同期します。モデルを変更する場合は、Gateway を停止してから別のモデルを選び、再度起動してください。
{% endhint %}

## 同期される設定

Cherry Studio は `~/.openclaw/openclaw.json` に設定をマージして書き込みます。主な内容は次のとおりです。

* 現在のプロバイダーの API アドレス、認証情報、モデル一覧
* 現在選択されているデフォルトモデル
* ローカル Gateway モード、ポート、自動生成された認証トークン

既存の OpenClaw 設定全体が上書きされることはありません。Cherry Studio は同じモデルにすでに存在する拡張設定を保持しながら、自身が管理するプロバイダーとデフォルトモデルを更新します。古い `openclaw.cherry.json` が見つかった場合は `openclaw.json` に移行し、必要に応じて元のファイルをバックアップします。

{% hint style="warning" %}
OpenClaw の設定ファイルには、モデルサービスの認証情報と Gateway トークンが含まれます。このファイル、インストールログ内の機密情報、トークンを含むダッシュボード URL を共有しないでください。
{% endhint %}

## 停止・更新・アンインストール

### Gateway を停止する

OpenClaw ページに戻り、**止まれ** をクリックします。Cherry Studio を通常どおり終了した場合も、アプリは自身が管理する Gateway の停止を試みます。

### OpenClaw を更新する

Cherry Studio は、インストール済みのページを開いたときに管理対象バージョンの更新を確認します。新しいバージョンが見つかると、インストール先の横にバージョン番号が表示されます。バージョン番号をクリックし、**今すぐアップデート** で確定してください。更新前に実行中の Gateway は停止します。更新後は、もう一度 **スタートゲートウェイ** をクリックする必要があります。

### OpenClaw をアンインストールする

Gateway が停止している状態で、インストール先の右側にある **アンインストール** をクリックします。確認後、ログの処理が完了するまで待ってください。Cherry Studio は管理対象のバイナリと、作成したコマンドリンクまたは `PATH` の項目を削除します。

アンインストールしても `~/.openclaw/openclaw.json` は削除されません。ファイル内のプロバイダー認証情報が不要になった場合は、そのファイルを使用する別の OpenClaw がないことを確認してから、自分で処理してください。

## トラブルシューティング

### インストール用ファイルをダウンロードできない

デバイスからダウンロード元にアクセスできることを確認し、インストールログで具体的なエラーを確認してください。ネットワークが復旧したら、インストールをもう一度クリックできます。現在の OS またはプロセッサに対応するバイナリがない場合も、インストールは失敗します。

### ターミナルではインストール済みなのに、未インストールと表示される

これは想定された動作です。Cherry Studio はシステムの `PATH` にある外部の OpenClaw を実行しません。ページから Cherry Studio の管理対象バージョンをインストールしてください。

### 選択できるモデルがない

モデルサービス設定を開き、プロバイダーを有効にして、API Key、API アドレス、モデルを設定してください。通常のチャットでモデルが正常に応答することを確認してから、OpenClaw ページに戻ります。

### Gateway を起動できない

別のプログラムがデフォルトポート `18790` を使用している可能性があります。既存の OpenClaw プロセスまたはそのポートを使用しているアプリを停止し、もう一度起動してください。ページは最大約 30 秒間、ヘルスチェックの完了を待ちます。それでも失敗する場合は、表示されたエラー情報をコピーして調査に使用できます。

### ターミナルで `openclaw` が見つからない

Cherry Studio 内のダッシュボードはターミナルコマンドに依存しません。ターミナルから使用する場合は、管理対象のインストール先が `PATH` に追加されているか確認してください。macOS または Linux では、権限不足のため `/usr/local/bin/openclaw` へのリンク作成に失敗することがあります。

OpenClaw のチャンネルとダッシュボードの詳しい使い方については、[OpenClaw 公式ドキュメント](https://docs.openclaw.ai/)を参照してください。
