# Agent の事例

このセクションでは、Cherry Studio のエージェントを使って実際のタスクを完了する事例を紹介します。各事例は最終結果だけでなく、目標、モデル、作業ディレクトリ、スキル、ツール権限、検収方法を分解して説明するため、自分の用途に合わせて変更できます。

アシスタント、エージェント、スキル、MCP の違いがまだ分からない場合は、先に[基本概念](../concepts-101.md)と[エージェントの使い方](../agent.md)をお読みください。

## 現在の事例

| 事例 | 適した課題 | 学べること |
| :--- | :--- | :--- |
| [金市場レビュー Agent](gold-price-case.md) | 公開資料をまとめ、市場イベントを分析し、読みやすいレビューを作成する | 調査範囲の定義、スキルの整理、ファイル権限の制限、データソースの確認方法 |

事例に登場するモデル、第三者サービス、ウェブページは時間とともに変わる場合があります。長期間そのまま動く固定テンプレートではなく、変更できるワークフローとして扱ってください。

## 事例を読むときの着眼点

信頼できるエージェント設定には、通常、次の要素があります。

1. **目標**：解決する問題と最終成果物を示し、「分析して」のような広すぎる依頼を避けます。
2. **入力**：読み取りを許可するファイル、ウェブページ、ディレクトリ、ユーザー提供データを列挙します。
3. **能力**：適切なモデルを選び、必要に応じて組み込みツール、スキル、MCP Server を有効にします。
4. **権限**：必要なディレクトリとツールだけを許可します。ファイルの書き込み、コマンドの実行、外部サービスへのアクセスには確認手順を残します。
5. **出力**：ファイル形式、保存場所、引用方法、失敗時の処理規則を決めます。
6. **検収**：回答が「本物らしい」かだけでなく、事実の出所、生成ファイル、重要な計算、異常時の動作を確認します。

各事例では、できるだけこの流れに沿って設定理由を説明します。再現するときにモデルやデータソースを変更してもかまいませんが、権限と検収の手順を省略しないでください。

## 再現を始める前に

### 1. 利用できるモデルを準備する

エージェントのモデル選択欄には、**Anthropic Messages** エンドポイントに対応し、Embedding、Rerank、画像生成の種類ではないモデルだけが表示されます。先に[モデルサービス](../../pre-basic/providers/)で設定し、正常に会話できることを確認してください。

モデル名は設定の一部にすぎません。ツール呼び出しを使う場合は、小さなタスクで、選択したプロバイダー、エンドポイント、モデルが現在のワークフローに本当に対応するかを確認します。

### 2. 専用の作業ディレクトリを作る

事例ごとに別のディレクトリを用意し、エージェント設定には必要なパスだけを追加します。こうすると、作成・変更されたファイルを確認しやすくなり、他のプロジェクトへの誤操作も防げます。

事例にサンプルファイルがある場合は、コピーを作ってから変更してください。書き込みを伴うタスクを唯一の原本に対して実行しないでください。

### 3. 制限した権限から始める

初回実行では、ツール操作に確認が必要な権限モードを優先します。ツール要求が表示されたら、次を確認してください。

* 呼び出すツールが現在の手順に関係しているか。
* 読み書きするパスが許可済みディレクトリ内にあるか。
* コマンドやネットワーク要求が費用を発生させる、または外部データを変更するか。
* 出力に API Key、個人情報、未公開ファイルが含まれる可能性があるか。

同じ手順を安定して再現でき、すべての副作用を理解してから、確認手順を減らすことを検討してください。

### 4. 最小タスクを先に実行する

最初から完全なプロジェクトをエージェントに渡さないでください。まず次のように依頼できます。

1. 作業ディレクトリを読み取り、使用するファイルを列挙する。
2. 呼び出す予定のスキルとツールを説明する。
3. 小さなサンプルまたは下書きだけを作成する。
4. 参照元と出力ファイルの場所を示す。

サンプルが合格してから、対象期間、データ量、成果物の規模を拡大します。こうすると、モデルの非互換、パスの誤り、外部ページの無効化、権限不足を早く発見できます。

## 結果を検収する方法

事例によって検収基準は異なりますが、少なくとも次を確認してください。

* **出所を追跡できる**：重要な事実とデータを実在する情報源まで戻れ、リンクと公開日が一致する。
* **入出力が一致する**：レポートがモデルの古い記憶ではなく、今回取得したデータを使用している。
* **ファイルを開ける**：生成した Markdown、HTML、CSV などを対応するアプリで正常に開ける。
* **失敗が見える**：要求失敗、データ不足、ツール利用不可を明示し、推測で埋めていない。
* **範囲が制御されている**：許可したディレクトリ以外を読み取り、または変更していない。

{% hint style="warning" %}
事例が生成する分析は、専門家の助言ではありません。金融、医療、法律、その他の高リスクな判断では、原典を確認し、必要な資格を持つ専門家のレビューを受けてください。
{% endhint %}
