# Dify ナレッジベースに接続する

チームですでに [Dify](https://dify.ai/) を使って資料を管理している場合、Cherry Studio 内蔵の `@cherry/dify-knowledge` MCP Server からナレッジベースを直接検索できます。ドキュメントをもう一度インポートする必要はありません。

接続後、アシスタントまたは Agent は、現在のキーでアクセスできるナレッジベースの一覧を取得し、質問に応じて関連する断片を検索し、その結果を回答の根拠として利用できます。この機能はナレッジベースを読み取るだけで、Dify 内のデータを作成、変更、削除することはありません。

## 使用前の準備

最初に Dify で次の作業を完了してください。

1. ナレッジベースを少なくとも 1 つ作成し、ドキュメントをインポートして、インデックス作成が完了するまで待ちます。
2. ナレッジベースの API アクセスページで **Knowledge API Key** を生成します。アプリ（App）の API Key は使用しないでください。
3. API のルートアドレスを確認します。
   - Dify クラウドサービス：`https://api.dify.ai/v1`
   - プライベート環境：その環境のナレッジベース API アドレスを使用します。通常は `/v1` で終わります。

{% hint style="warning" %}
API Key を使うと、その権限範囲内のナレッジベースの内容を読み取れます。実際のキーをドキュメント、スクリーンショット、公開チャットに含めないでください。キーが漏えいした場合は、Dify ですぐに無効化して再生成してください。
{% endhint %}

## 内蔵 MCP Server をインストールする

1. Cherry Studio の **設定 → MCP Server** を開きます。
2. 内蔵 MCP Server の一覧で `@cherry/dify-knowledge` を検索します。
3. **インストール** をクリックします。
4. インストール済み Server の一覧で `@cherry/dify-knowledge` をクリックし、詳細ページを開きます。

この Server は Cherry Studio によって内蔵実行されるため、Node.js、Python、またはサードパーティ製の MCP プログラムを別途インストールする必要はありません。

## 接続情報を入力する

Server 詳細の **設定** ページに次の内容を入力します。

| フィールド | 入力内容 | 例 |
| --- | --- | --- |
| 引数 | Dify ナレッジベース API のルートアドレス。1 行だけ入力します | `https://api.dify.ai/v1` |
| 環境変数 | `DIFY_KEY=ナレッジベースのAPI Key` | `DIFY_KEY=dataset-xxxxxxxx` |

保存して Server を有効にします。接続が正常であれば、**ツール** ページに次の 2 つのツールが表示されます。

- `list_knowledges`：現在の API Key でアクセスできるナレッジベースとその ID を一覧表示します。
- `search_knowledge`：ナレッジベース ID と検索テキストで内容を検索します。`topK` を指定しない場合は、最大 6 件の結果を返します。

{% hint style="info" %}
引数には `/datasets` を追加せず、特定のナレッジベース ID も入力しないでください。Cherry Studio がツール呼び出しに応じて、ナレッジベース一覧と検索 API のパスを自動的に追加します。
{% endhint %}

## 会話で使用する

Server をインストールして有効にした後、実際に使用するアシスタントまたは Agent に権限を与える必要があります。

1. 対象のアシスタントまたは Agent のツール設定を開きます。
2. `@cherry/dify-knowledge` を追加して有効にします。
3. ツール呼び出しに対応したモデルを選択し、会話を開始します。

初めて使用するときは、まずアクセス可能なナレッジベースをモデルに確認させます。

```text
現在アクセスできる Dify ナレッジベースを一覧表示し、それぞれの名前と ID を示してください。
```

対象のナレッジベースを確認したら、検索範囲と出力要件を含む質問をします。

```text
「製品ヘルプセンター」ナレッジベースで、アカウント移行の手順を検索してください。
検索で得られた資料だけに基づいて回答し、重要な注意事項を列挙してください。
```

モデルは `list_knowledges` または `search_knowledge` を自動的に呼び出します。ツールが返す検索結果には、ドキュメント名、断片の内容、関連度スコア、キーワードが含まれます。最終回答の構成は、引き続きモデルの能力とプロンプトによって変わります。

## よくある質問

### 有効化すると引数不足と表示される

**引数** に API のルートアドレスが入力されているか確認してください。この内蔵 Server を起動するには、少なくとも 1 行の引数が必要です。

### 401、403、またはアクセスエラーが返される

次の項目を順に確認してください。

- `DIFY_KEY` という名前が完全に正しいか。
- アプリ API Key ではなく、ナレッジベース API Key を使用しているか。
- キーが有効で、対象のナレッジベースにアクセスする権限があるか。
- プライベート環境の API アドレスに現在のコンピューターからアクセスできるか。

### 接続できるが、ナレッジベースの一覧が空

Dify にナレッジベースが少なくとも 1 つあることを確認し、現在の Knowledge API Key の権限範囲を確認してください。Cherry Studio に表示できるのは、そのキーでアクセス可能なナレッジベースだけです。

### 会話で Dify が呼び出されない

Server が有効で、現在のアシスタントまたは Agent に追加されていることを確認してください。ツール呼び出しに対応したモデルも必要です。必要に応じて、質問内で「先に Dify ナレッジベースを検索してから回答する」と明示してください。

### 検索結果が期待どおりでない

まず Dify でドキュメントのインデックス作成が完了しているか確認し、より具体的なキーワードで質問し直してください。現在の内蔵ツールは Dify のセマンティック検索 API を使用しますが、Dify 側の分割、インデックス、検索設定を置き換えるものではありません。
