# エージェントのワークスペースメモリ

Cherry Studio V2 のエージェントは、同じワークスペースで行う複数のセッション間に重要な情報を保持できます。メモリは、エージェントの最初のアクセス可能なディレクトリ内にある `memory` フォルダーに保存されます。グローバルメモリの有効化や Embedding モデルの設定は必要ありません。

この機能はエージェントのタスク用であり、通常の会話内容が自動的に追加されることはありません。メモリはワークスペース単位です。複数のエージェントが同じディレクトリを最初のアクセス可能なディレクトリとして使用すると、同じメモリファイルを参照します。

## 使用条件

エージェントにはアクセス可能なディレクトリを設定する必要があります。最初のアクセス可能なディレクトリがワークスペースとなり、メモリファイルは次の場所に保存されます。

```text
<workspace>/memory/
├── FACT.md
└── JOURNAL.jsonl
```

アクセス可能なディレクトリが設定されていない場合、ワークスペースメモリを読み書きできません。

## 2 種類のメモリ

| ファイル | 保存する内容 | 使用方法 |
| :--- | :--- | :--- |
| `FACT.md` | 長期間有効な事実、取り決め、技術上の決定 | 後続のセッションでエージェントに読み込まれ、事実が変わったときに更新される |
| `JOURNAL.jsonl` | 完了したタスク、一度限りの出来事、セッション記録 | 時系列で追記され、必要なときにエージェントが検索する。内容全体がコンテキストに読み込まれることはない |

情報を `FACT.md` に保存するか判断するときは、「6 か月後もこの情報は重要か」と考えてください。特定のタスクの過程や結果だけを記録する場合は、Journal のほうが適しています。

## エージェントに情報を記憶させる

エージェントとの会話で、残しておきたい内容を直接伝えます。例：

> 覚えておいてください。このプロジェクトでは pnpm を使用し、コミット前に lint とユニットテストを実行します。

長期的なルールは永続的な事実として更新するよう依頼し、一度限りの進捗は Journal に記録するよう依頼します。エージェントは組み込みのワークスペースメモリツールを使って書き込みます。

{% hint style="warning" %}
メモリファイルはローカルのワークスペースに保存されます。パスワード、API キー、アクセストークン、その他の機密情報を記録するようエージェントに依頼しないでください。
{% endhint %}

## 後続のセッションで使用する

ワークスペースメモリに対応するエージェントで、同じワークスペースから新しいセッションを開始すると、Cherry Studio は `FACT.md` の永続的な事実をエージェントに提供します。以前の出来事を調べる必要がある場合は、Journal を検索するよう依頼します。例：

> 先週のリリース失敗に関する記録を調べてください。

検索ではテキストやタグで絞り込み、最近の一致する記録を取得できます。

現在、`FACT.md` の自動読み込みは Soul Mode と通常のカスタムエージェントで利用できます。組み込みの Cherry Assistant は、このワークスペースの事実を自動的には読み込みません。

## メモリを確認、管理する

ワークスペースの `memory/FACT.md` を開くと、現在保存されている長期的な情報を確認できます。事実を訂正する場合は、会話でエージェントにメモリの更新を依頼し、メモリツールを使って安全に書き込ませることを推奨します。

`JOURNAL.jsonl` は 1 行ごとに 1 件の JSON レコードを保存します。手動で一括編集せず、エージェントから検索することを推奨します。

## 記憶されていない場合

次の順に確認してください。

1. 現在のエージェントにアクセス可能なディレクトリが設定されているか。
2. 現在のエージェントの最初のアクセス可能なディレクトリが、以前と同じワークスペースを指しているか。
3. `memory/FACT.md` に該当する情報が書き込まれているか。
4. 探している情報が長期的な事実か、Journal に保存された一度限りの記録か。

旧バージョンのグローバルメモリと V2 のエージェント用ワークスペースメモリは別の仕組みです。V2 のメモリを確認するときは、現在のワークスペースにある `memory/FACT.md` と `memory/JOURNAL.jsonl` を基準にしてください。
