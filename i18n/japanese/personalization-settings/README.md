# パーソナライズ設定

Cherry Studio V2 では、よく使う外観オプションが **設定 > 一般設定 > 表示と言語** にまとめられています。コードを書かなくても、テーマ、色、ズーム、フォント、トピックのレイアウトを調整できます。組み込みオプションで要件を満たせない場合にだけ、カスタム CSS を使用してください。

{% hint style="info" %}
「パーソナライズ設定」はこのドキュメント内のトピック名であり、アプリ内の独立した設定メニューではありません。左下の **設定** から **一般設定** を開いてください。
{% endhint %}

## 適切な方法を先に選ぶ

| 実行したい操作 | 推奨する設定画面 | リスク |
| --- | --- | --- |
| ライト、ダーク、システム連動を切り替える | 設定 > 一般設定 > 表示と言語 | 低 |
| テーマのアクセントカラーを変更する | 設定 > 一般設定 > 表示と言語 | 低 |
| 画面全体を拡大または縮小する | 設定 > 一般設定 > 表示と言語 | 低 |
| グローバルフォントまたはコードフォントを変更する | 設定 > 一般設定 > 表示と言語 | 低 |
| トピックの位置、時刻、固定方法を調整する | 設定 > 一般設定 > 表示と言語 | 低 |
| コンポーネントのスタイルを詳細に変更する | 設定 > 一般設定 > カスタム CSS | 中 |
| アプリデータを別のディスクへ移行する | 設定 > データ設定 > データディレクトリ | 高。先にバックアップを推奨 |

まず組み込みオプションから試すことを推奨します。組み込み設定はバージョンに合わせて保守されるため、通常はカスタム CSS より安定しています。

## 表示と言語

**設定 > 一般設定 > 表示と言語** を開くと、次の項目を調整できます。

### 言語とテーマ

- **言語**：Cherry Studio の表示言語を切り替えます。
- **テーマ**：ライト、ダーク、システム連動から選択します。
- **テーマカラー**：プリセット色から選ぶか、カスタム色を入力します。
- **ウィンドウの透明効果**：macOS でのみ表示されます。
- **システムタイトルバーを使用**：Linux でのみ表示され、変更後はアプリの再起動が必要です。

### 画面のズーム

マイナスボタンとプラスボタンでアプリ全体のズーム率を段階的に調整します。リセットボタンをクリックするとデフォルトのズームに戻ります。

メッセージの文字だけが小さい場合は、先にメッセージのフォントサイズを調整してください。ボタン、サイドバー、ダイアログも小さい場合は、画面全体のズームを調整します。

### フォント

V2 は OS にインストール済みのフォントを読み取り、次の項目を個別に提供します。

- **グローバルフォント**：画面の大部分と本文に使用されます。
- **コードフォント**：コードブロック、コードエディターなどの等幅表示に使用されます。

フォントを選択するとすぐに反映されます。各項目のリセットボタンをクリックするとデフォルトフォントに戻ります。新しいフォントをインストールする場合は、[おすすめフォント](font.md)を参照してください。

{% hint style="info" %}
フォント一覧は現在の OS から取得されます。新しいフォントをインストールしても一覧が更新されない場合は、Cherry Studio を完全に終了してから開き直してください。
{% endhint %}

### トピックのレイアウト

トピック一覧を左側または右側に配置し、次の項目を設定できます。

- アシスタントをクリックしたときにトピックへ自動的に切り替えるか。
- トピックの時刻を表示するか。
- 選択中のトピックを上部に固定するか。

「アシスタントをクリックしたときにトピックへ自動的に切り替える」は、トピックを左側に配置した場合にだけ表示されます。

## カスタム CSS

組み込みのテーマやレイアウトオプションで要件を満たせない場合は、**設定 > 一般設定 > カスタム CSS** を開いてスタイルを直接編集できます。

カスタム CSS は余白、色、角丸、特定コンポーネントの外観変更に適しています。ただし、アプリのアップデートでコンポーネント構造が変わり、古いルールが無効になる場合があります。始める前に[カスタム CSS](css.md)を読み、利用可能なスタイルのコピーを保存してください。

誤ったスタイルにより設定画面を操作できなくなった場合は、[CSS 設定を消去する](clear-css.md)を参照して復元できます。

{% hint style="warning" %}
フォントやテーマカラーの変更に CSS を優先しないでください。V2 には対応する組み込みオプションがあり、組み込み設定のほうが復元しやすく、アップデート後も無効になりにくくなります。
{% endhint %}

## データディレクトリ

保存場所の変更は外観設定ではなく、データ移行の操作です。設定画面は **設定 > データ設定 > データディレクトリ** にあります。

移行には会話、アシスタント、ナレッジベース、その他のローカルデータが含まれる場合があります。操作前にバックアップを完了し、移行先ディレクトリが次の条件を満たすことを確認してください。

- ディスクのルートディレクトリではない。
- 現在のデータディレクトリ内にない。
- アプリのインストールディレクトリ内にない。
- 書き込み権限がある。
- 十分な空き容量がある。

詳しい手順と注意事項は、[保存場所を変更する](storage.md)を参照してください。

## 推奨する設定順序

画面をすばやく調整したい場合は、次の順序で設定できます。

1. テーマとテーマカラーを選択します。
2. 画面のズームを調整します。
3. グローバルフォントとコードフォントを選択します。
4. トピックのレイアウトを調整します。
5. 組み込みオプションで要件を満たせないことを確認してから、カスタム CSS を追加します。

この順序にするとスタイルの競合を減らし、後でデフォルトの外観へ戻す操作も簡単になります。
