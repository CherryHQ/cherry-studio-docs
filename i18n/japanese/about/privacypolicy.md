# プライバシーポリシー

**更新日：2026 年 5 月 31 日**

**発効日：2026 年 5 月 31 日**

Cherry Studio（以下「本ソフトウェア」または「当社」）をご利用いただきありがとうございます。当社はお客様のプライバシー保護を重視しています。本プライバシーポリシーでは、個人情報およびデータの取り扱いと保護について説明します。本ソフトウェアを使用する前に、以下の内容をよくお読みいただき、ご理解ください。

### 1. 収集する情報の範囲

本ソフトウェアの正常な動作を維持し、ユーザー体験と製品品質を向上させるため、完全に匿名化された非個人的な動作情報（以下「匿名の基本動作情報」）を段階別に収集します。すべての情報は匿名化され、個人を特定できるデータを含まず、お客様の個人情報と関連付けることもできません。お客様はすべての情報収集を常に管理できます。具体的な方法は以下のとおりです。

#### （1）基本動作情報

本ソフトウェアの基本機能、安全性、バージョン互換性を確保するため、次の情報を既定で収集します。

1. ソフトウェアのバージョン情報：バージョン互換性の確認やセキュリティ更新の通知などに使用します。
2. 機能利用の集計情報：各機能の全体的な利用状況の集計であり、具体的な操作内容は含みません。

#### （2）製品改善情報

製品体験を継続的に改善するため、次の情報を既定で収集します。

1. 機能の利用状況と頻度：各機能の利用の活発さ、呼び出し頻度など。
2. エラーログとクラッシュ情報：問題の調査と安定性の向上に使用する、匿名のエラーログやクラッシュスタックなど。

上記は高度に集約された匿名データであり、会話内容、API Key、個人を特定できる情報は含みません。

無効化する方法：設定 → 共通設定 → プライバシーと高度な設定にある「匿名エラーレポートとデータ統計の送信」をいつでもオフにできます。オフにしても本ソフトウェアの主要機能には影響しません。

#### 本ポリシー更新に関する特記事項：

今回の更新にはデータ収集アーキテクチャの変更が含まれるため、新しいバージョンを起動すると、上記の設定 → 共通設定 → プライバシーと高度な設定にある関連スイッチが既定のオン状態に統一してリセットされます。以前のオフ設定を維持する場合は、アップグレード後に同じ画面で再度設定してください。ご不便をおかけしますが、ご了承ください。

#### （3）当社の約束

基本動作情報と製品改善情報のいずれについても、当社は次を約束します。

* すべてのデータを匿名化し、個人と関連付けられないようにします。
* ユーザープロファイリング、広告配信、外部への販売には使用しません。
* 会話内容、API Key、ナレッジベースの内容など、いかなる機密データも含みません（第 2 条を参照）。

### 2. 収集しない情報

プライバシーを最大限に保護するため、当社は次のデータを収集、保存、送信、処理しないことを明確に約束します。

* API Key：本ソフトウェアに入力したモデルサービスの API Key。

* 会話データ：チャット内容、指示、ナレッジベース情報、ベクトルデータ、その他のカスタム内容を含む、本ソフトウェアの利用中に生成されたすべての会話データ。

* 個人を特定できる機密情報：個人を直接特定できる機密情報。

### 3. ローカル保存とデータ通信

* ローカル保存：API Key、会話履歴、個人設定などのデータは、お客様のローカルデバイスに完全に保存されます。Cherry Studio はクラウド同期サービスを提供せず、これらのデータを当社のサーバーにアップロードしません。

* 直接通信：本ソフトウェアは、ローカルツールとして第三者のモデルサービスを呼び出すインターフェースだけを提供します。お客様の端末は、設定した第三者モデルプロバイダー（OpenAI、Anthropic など）のサーバーに直接接続します。ただし、本ソフトウェアを利用して、中華人民共和国およびお客様の所在国の法令に違反する情報、国家安全保障を脅かす情報、国家の名誉や利益を害する情報、民族の団結を損なう情報、虚偽情報、社会秩序を乱す情報、わいせつ・性的または暴力的な情報、他者の正当な権利を侵害する情報など、違法または有害な情報を作成、複製、公開、配布してはなりません。

### 4. 第三者モデルプロバイダーのプライバシーポリシー

本ソフトウェアでは、お客様自身が取得して設定した第三者モデルプロバイダーの API Key を使用します。そのため、AI チャット機能の利用時には、実際には当該第三者モデルプロバイダーから直接サービスを受けます。

* 第三者モデルプロバイダーの利用に伴うプライバシーおよびコンプライアンス上のリスクは、お客様自身が負うものとします。

* 各モデルプロバイダーは、独自のプライバシーポリシーやデータ保護措置に従って、お客様が入力したデータ（会話内容など）を処理し、そのサービスの範囲内でその他の関連データを独自に収集する場合があります。これらの処理と収集は本ソフトウェアの管理外であり、設定 → 共通設定 → プライバシーと高度な設定のスイッチで停止することもできません。

* 関連するデータ処理や収集について確認または停止を希望する場合は、選択したモデルプロバイダーの公式サイトにあるプライバシーポリシーを確認し、プロバイダーに停止方法をお問い合わせください。当社はこれについて責任を負いません。

### 5. 第三者サービスに関する特記事項

データの管理と処理を容易にするため、本ソフトウェアの設定 → データ設定では、API アドレス、ユーザー名、パスワードなどをお客様自身が入力し、任意で設定して利用できる次の第三者サービス機能を提供しています。

* クラウドバックアップ設定：WebDAV、S3 互換ストレージ、Nutstore。

* 第三者連携：Notion、Yuque、Joplin、Obsidian、SiYuan Note。

本ソフトウェアを通じて上記の第三者サービスを利用する場合：

* 入力した API Key、パスワードなどの認証情報は、お客様のデバイス上でのみ使用されます。本ソフトウェアは情報やデータを収集または保存しません。認証情報はお客様自身で適切に管理してください。

* 第三者サービスは各プロバイダーが独立して運営しており、データの収集、利用、保存、共有などの取り扱いには、当該プロバイダーのプライバシーポリシーと規約が適用されます。接続前に関連するポリシーと利用規約をよく読み、理解したうえで、法令に従って利用し、すべてのリスクと責任を負ってください。第三者サービスの利用によるデータ漏えい、紛失、不適切な処理などについて、当社は責任を負いません。

* 上記の第三者プロバイダーが、そのサービスの範囲内でお客様のデータを独自に収集する場合があります。この収集は本ソフトウェアの管理外であり、設定 → 共通設定 → プライバシーと高度な設定のスイッチで停止することもできません。停止する場合は、各第三者プロバイダーにお問い合わせください。
