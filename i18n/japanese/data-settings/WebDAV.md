# WebDAV バックアップ

Cherry Studio V2 は、WebDAV に対応するクラウドストレージ、NAS、独自サーバーへバックアップファイルを保存できます。手動バックアップのほか、一定の間隔で自動バックアップを作成し、保存数を管理できます。

ここでの WebDAV は、バックアップファイルの作成と復元に使う保存先であり、複数デバイス間のリアルタイム双方向同期ではありません。復元は現在のデータを上書きし、双方で追加されたチャットを統合しません。

{% hint style="warning" %}
WebDAV バックアップには、チャット、プロバイダー設定、その他の機密情報が含まれる場合があります。非公開ディレクトリとアプリ専用パスワードを使用し、認証情報やバックアップファイルを公開共有しないでください。
{% endhint %}

## 接続情報を準備する

WebDAV プロバイダーまたはサーバーの管理画面で、次を確認します。

| フィールド | 入力内容 |
| --- | --- |
| WebDAV アドレス | WebDAV サービスの入口。通常は `https://` を含む完全なアドレス |
| WebDAV ユーザー名 | プロバイダーが割り当てたアカウント名、メールアドレス、WebDAV 専用ユーザー名 |
| WebDAV パスワード | 通常のパスワードまたはプロバイダーが発行したアプリ専用パスワード |
| WebDAV パス | Cherry Studio がバックアップを保存するリモートディレクトリ |

アドレスと認証方法の要件はサービスによって異なります。通常の Web ログインアドレスが WebDAV アドレスとは限りません。2 段階認証を有効にした場合は、通常、アカウントのログインパスワードではなくアプリ専用パスワードが必要です。

デフォルトのリモートパスは `/cherry-studio` です。対象ディレクトリがない場合、Cherry Studio は初回アップロード時に再帰的な作成を試みます。バックアップ管理ファイルと他のファイルが混在しないよう、Cherry Studio 専用のディレクトリを推奨します。

{% hint style="info" %}
Cherry Studio V2 には、**Nutstore** 専用のバックアップ画面もあります。Nutstore アカウントの認可で接続する場合は、その入口を使用してください。このページは汎用 WebDAV パラメーターを手動入力する場合に使用します。
{% endhint %}

## Cherry Studio で設定する

1. **設定 > データ設定 > WebDAV**を開きます。
2. **WebDAV アドレス**を入力し、`http://` または `https://` を残します。
3. **WebDAV ユーザー名**と**WebDAV パスワード**を入力します。
4. `/cherry-studio` などのリモートパスを入力します。
5. 一時的に**自動バックアップ**をオフにしておきます。
6. **WebDAV にバックアップ**をクリックし、デフォルトのファイル名でテストバックアップを作成します。
7. アップロード後に**WebDAV から復元**をクリックし、作成したファイルがバックアップ管理画面に表示されることを確認します。

この画面には独立した「接続テスト」ボタンがありません。テストバックアップをアップロードし、管理画面で再度一覧表示できて初めて、アドレス、認証、パス作成、書き込み権限が利用可能だと確認できます。

テストでは、機密性のある添付ファイルを含まない小さなデータを使うと問題を切り分けやすくなります。接続確認後に、完全バックアップと自動バックアップを有効にするか判断してください。

## 手動バックアップを作成する

**WebDAV にバックアップ**をクリックすると、時刻、ホスト名、デバイス種別を含むデフォルトのファイル名が表示されます。名前は変更できます。末尾が `.zip` でない場合、Cherry Studio が拡張子を自動追加します。

**コンパクトバックアップ**を有効にすると、アプリの `Data` ディレクトリ内にある画像、ナレッジベースなどのファイルデータを除外し、チャット履歴や設定などだけを保存します。増分バックアップではなく、除外されたファイルの復元には使用できません。

手動バックアップが完了すると、リモートディレクトリに独立した ZIP ファイルが残ります。アップロード中にアプリを終了したり、ネットワークを切断したり、システムをスリープさせたりしないでください。

## 自動バックアップを設定する

**自動バックアップ**で選択できる間隔：

- オフ
- 1、5、15、30 分
- 1、2、6、12、24 時間

最初に手動テストを完了してから間隔を選びます。頻度が高いほどリモートリクエストとストレージへの書き込みが増えます。容量の大きな完全バックアップを分単位で実行する必要は通常ありません。

画面には前回のバックアップ時刻または最新のエラーが表示されます。「次のバックアップを待機中」は、成功した記録がまだないことを意味し、接続済みであることを保証しません。

### 保存数を制御する

**最大バックアップ数**には、無制限、1、3、5、10、20、50 を設定できます。

自動削除の対象は、現在のデバイスがデフォルトの命名規則で作成したバックアップだけです。Cherry Studio は、ファイル名に含まれるホスト名とデバイス種別で現在のデバイスを識別し、上限を超えた古いファイルを削除します。

現在のデバイス識別子を含まないカスタムファイル名は、自動削除されない場合があります。「無制限」でもリモート容量は自動解放されません。定期的にバックアップ管理画面で容量を確認してください。

## バックアップを管理、復元する

**WebDAV から復元**をクリックしてバックアップ管理画面を開きます。ここでは次の操作ができます。

- ファイル名、更新時刻、サイズを確認する
- リモートファイル一覧を更新する
- バックアップを選んで復元する
- 1 件または複数のバックアップを削除する

復元前の手順：

1. 現在のデバイスで新しいバックアップを作成します。
2. ファイル名、更新時刻、サイズから対象バージョンを確認します。
3. 他のデバイスが同じディレクトリへ書き込んでいないことを確認します。
4. **復元**をクリックし、現在のデータを上書きすることを確認します。

復元後、アプリが自動的に再起動する場合があります。バックアップの削除は取り消せません。複数削除の前に、選択したファイルを再確認してください。

{% hint style="warning" %}
複数のデバイスから同じリモートディレクトリを読み取れますが、復元でデータは統合されません。デバイス B でデバイス A のデータを使用する場合は、最初に B をバックアップしてから、A の対象バージョンを復元してください。
{% endhint %}

## 「ストリーミングアップロードを無効化」を使う場面

Cherry Studio はデフォルトでバックアップをストリーミングアップロードします。大きなファイルに適し、メモリ使用量も少なくなります。

一部の WebDAV サービスは、分割またはストリーミングアップロードに対応していません。小さなファイルは成功しても大きなバックアップだけが失敗する、リクエスト長や `chunked` 転送に関するエラーが返る、といった場合があります。そのときは**ストリーミングアップロードを無効化**して再試行します。

有効にすると、Cherry Studio はバックアップファイル全体をメモリへ読み込んでからアップロードします。そのため：

- メモリ使用量がバックアップファイルのサイズに近くなる
- 大きなバックアップではアプリが大幅に遅くなる場合がある
- 互換性のための回避策としてのみ使用し、デフォルトでは有効にしない

引き続き失敗する場合は、バックアップ頻度を上げるのではなく、サーバー側の単一ファイルサイズ、リクエスト本文、タイムアウト制限を確認してください。

## セキュリティに関する推奨事項

- 公開ネットワークでは `https://` を優先し、平文 HTTP でパスワードやバックアップを送信しない
- Cherry Studio 専用アカウントまたはアプリ専用パスワードを作成し、対象ディレクトリに必要な権限だけを与える
- スクリーンショット、フィードバック、共有設定に、完全なアドレス内の非公開情報、ユーザー名、パスワードを表示しない
- 出所不明の ZIP ファイルを復元しない
- 少なくとも 1 つの完全バックアップが一覧表示され、認識されることを定期的に検証する

## よくある質問

### バックアップ時に未認証、401、403 が表示される

ユーザー名とパスワードが通常の Web ログイン用ではなく WebDAV 用であることを確認します。2 段階認証が有効な場合は、アプリ専用パスワードを使用します。また、対象パスでディレクトリを作成し、ファイルを書き込む権限があることも確認してください。

### 404 またはパスが見つからない

クラウドストレージのトップページや共有リンクではなく、WebDAV サービスの入口を入力したことを確認します。パスを `/` で始まる単純なディレクトリ（例：`/cherry-studio`）へ変更し、手動バックアップでテストしてください。

### ファイル一覧は表示できるが、大きなバックアップをアップロードできない

まずサーバー側の単一ファイルサイズ、リバースプロキシのリクエスト本文、タイムアウト制限を確認します。エラーが分割アップロードに関係する場合は、**ストリーミングアップロードを無効化**します。この設定で完全バックアップを行うときは、十分なメモリを確保してください。

### 自動バックアップが実行されない

間隔が「オフ」ではなく、WebDAV アドレスが空でないことを確認し、画面下部のバックアップ状態を確認します。コンピューターのスリープ、ネットワーク切断、サービス停止中は、予定されたバックアップを完了できません。

### 最大バックアップ数に達しても古いファイルが残る

自動削除は現在のデバイス識別子でファイルを絞り込みます。手動で名前を変更したファイル、別のデバイスからのファイル、デフォルトの命名形式に合わないファイルは残る場合があり、管理画面で手動削除する必要があります。

### 別のコンピューターから復元すると、このデバイスの新しいチャットが消えた

復元は上書き操作で、データを統合しません。リモートバックアップでデバイス間を移行する前に、両方のデバイスを個別にバックアップし、確認済みの対象バージョンだけを復元してください。

解決しない場合は、[フィードバックと提案](../../question-contact/suggestions.md)から Cherry Studio のバージョン、OS、匿名化したアドレスとパス、HTTP ステータス、エラー全文を送信してください。
