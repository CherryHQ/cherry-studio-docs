# データ設定

Cherry Studio V2 のデータ設定は **設定 > データ設定** にあります。ここでは、手動でのバックアップや復元のほか、ローカルまたはクラウドへの自動バックアップの設定、データの他のディレクトリへの移行、およびインポートとエクスポートのオプション管理を行うことができます。

{% hint style="warning" %}
バックアップの復元、データディレクトリの移行、データのリセットはすべて既存の内容を上書きする可能性があります。操作を行う前に、必ず使用可能なバックアップを作成し、そのバックアップファイルがアプリデータディレクトリの外に保存されていることを確認してください。
{% endhint %}

## ページ構造

データ設定の左側には、以下のページが含まれています。

| ページ | 用途 |
| --- | --- |
| データ | 手動バックアップと復元、スマートフォンへエクスポート、アプリデータの移行、ログの確認、キャッシュの消去、およびデータのリセットを行います。 |
| ローカルバックアップ | バックアップをローカル、外付けドライブ、またはマウントされたネットワークディレクトリに書き込み、自動バックアップを設定します。 |
| WebDAV | WebDAV をサポートするリモートストレージを使用して、バックアップの保存と復元を行います。 |
| Nutstore | Nutstore にログインし、リモートディレクトリを選択してバックアップを管理します。 |
| S3 | S3 または S3 互換のオブジェクトストレージを使用して、バックアップを保存します。 |
| インポート設定 | サポートされている外部アプリデータをインポートします。 |
| エクスポートメニュー | ダイアログのエクスポートメニューにどの形式と宛先を表示するかを決定します。 |
| Markdown エクスポート | デフォルトのディレクトリ、数式、モデル情報、および引用形式を設定します。 |

## バックアップ方法の選択

| 使用シーン | 推奨される方法 |
| --- | --- |
| 移動可能なバックアップをすぐに保存したい場合 | **データ** ページで**バックアップ**をクリックする |
| 本機、外付け HDD、またはマウント済みの NAS に定期的にバックアップする場合 | **ローカルバックアップ**を使用する |
| WebDAV に対応したクラウドストレージやサーバーがある場合 | [WebDAV バックアップ](WebDAV.md)を使用する |
| Nutstore を利用し、アカウント認証で接続したい場合 | **Nutstore**を使用する |
| AWS S3、Cloudflare R2、MinIO などのオブジェクトストレージを既に持っている場合 | [S3 互換ストレージバックアップ](s3-compatible.md)を使用する |

クラウドおよびローカルのページにおける「自動バックアップ」は、周期的に新しいバックアップファイルを作成することを意味し、2台のデバイス間のリアルタイム双方向同期ではありません。複数のコンピューターで同じバックアップ位置を使用する場合、まず1台のデバイスでバックアップを完了させ、その後、別のデバイスで対応するバージョンを手動で選択して復元する必要があります。同時に編集した後に相互に復元を行うと、より新しいデータが上書きされる可能性があります。

## バックアップに含まれるもの

通常のバックアップには、Cherry Studio のデータベース、設定、およびアプリ管理のファイルデータが含まれます。これには、チャット履歴、アシスタントの設定、画像、知識ベース関連のファイルなどが含まれます。

**コンパクトバックアップ** を開くと、バックアップは引き続きチャット履歴と設定を保持しますが、アプリ `Data` ディレクトリ内の画像や知識ベースなどのファイルデータはスキップされます。これによりファイルサイズが縮小し、バックアップが高速化されますが、復元後にスキップされたファイルをこのバックアップから復元することはできません。

{% hint style="info" %}
「コンパクトバックアップ」は増分バックアップではありません。毎回独立したバックアップファイルが生成されますが、ファイルデータのみが除外されます。
{% endhint %}

バックアップには、会話の内容、サービスプロバイダーの設定、その他の機密情報が含まれる可能性があります。バックアップを公開で共有したり、出所不明のファイルを復元したりしないでください。リモートストレージを使用する場合は、プライベートディレクトリ、強力なパスワード、および最小権限の認証情報を使用してください。

## 手動バックアップと復元

**設定 > データ設定 > データ** に進みます：

1. バックアップのサイズを小さくしたい場合は、まず **コンパクトバックアップ** をオンにします。画像やナレッジベースファイルを完全に保持する必要がある場合はオフのままにしてください。
2. **バックアップ** をクリックし、アプリデータディレクトリ以外の保存場所を選択します。
3. バックアップが完了するまで待ちます。書き込み中にアプリを終了したり、ディスクを取り外したりしないでください。

復元時は **復元** をクリックし、Cherry Studio のバックアップファイルを選択します。復元は、バックアップ内のデータで現在のデータを置き換えます。完了後、アプリが自動的に再起動する場合があります。

定期的に復元検証を行うことをお勧めします。現在のデータに別のバックアップがあることを確認した後、バックアップファイルが認識できるか、バージョンと時間が正しいかを確認してください。元のデータが失われてから初めて検証するのは避けてください。

## 自動バックアップと保持数

ローカル、WebDAV、Nutstore、S3 の各ページには、個別の自動バックアップ設定が保存されます。現在選択できる周期は次のとおりです：

- オフ。
- 1、5、15 または 30 分間隔。
- 1、2、6、12 または 24 時間間隔。

保持できる最大バックアップ数は無制限、1、3、5、10、20、または 50 です。上限に達した場合、Cherry Studio はより古い自動バックアップをクリーンアップします。「無制限」はストレージ使用量を積極的に制御しません。

各バックアップ方式には個別の **コンパクトバックアップ** スイッチがあります。**データ**ページのスイッチを変更しても、ローカル、WebDAV、Nutstore、S3 ページの設定は置き換わりません。

### ローカル自動バックアップの設定

1. **ローカルバックアップ** を開きます。
2. 書き込み可能なディレクトリを選択します。このディレクトリは、Cherry Studio のアプリデータディレクトリまたはインストールディレクトリ内であってはなりません。
3. 自動バックアップ周期と最大バックアップ数を選択します。
4. 復元時に必要な内容に応じて、**コンパクトバックアップ**を有効にするか決めます。
5. **バックアップステータス**で、直近の実行時刻またはエラーメッセージを確認します。

有効なディレクトリを選択すると、ローカル自動バックアップが有効になります。バックアップディレクトリを外付けハードドライブやネットワークマウントポイントに配置する場合、実行中にデバイスがオンラインであり、十分な空き容量があることを確認してください。

## スマートフォンへエクスポート

**データ > スマートフォンへエクスポート**では、2つの方法が提供されます：

- **ローカルネットワーク経由の転送：** 同じローカルネットワーク上の Cherry Studio モバイルアプリを検索し、接続後に一時バックアップを送信します。
- **ファイルとしてエクスポート：** モバイルアプリがファイルからインポートできる ZIP バックアップを生成します。

どちらもチャット履歴や設定など一部のデータだけを転送し、`Data` ディレクトリ内のファイルデータは除外します。完全なバックアップの代わりにはなりません。

ローカルネットワークでデバイスが見つからない場合は、PCとスマートフォンが同じネットワークに接続されているか、モバイル側でローカルネットワーク転送ページが開いているか、システムファイアウォールがデバイスの検出やファイルの転送を妨げていないかを確認してください。

## アプリデータディレクトリの変更

**データ > アプリデータ**で現在のディレクトリが表示されます。変更アイコンをクリックすると、Cherry Studio のデータを別のディスク位置に移動できます。

新しいディレクトリは以下の条件を満たす必要があります：

- ディスクのルートディレクトリではないこと。
- 現在のアプリデータディレクトリ内部ではないこと。
- Cherry Studio のインストールディレクトリ内部ではないこと。
- 現在のユーザーが書き込み権限を持っていること。

確認時には、元のディレクトリ内のデータをコピーするかどうかを選択できます。ターゲットディレクトリが空でない場合、操作を続行するとターゲット内のファイルが上書きされる可能性があるため、アプリから再度警告が表示されます。移行中は強制終了したり、ディスクを取り外したり、デバイスをスリープさせたりしないでください。完了後、アプリは再起動し、状況によっては複数回再起動する場合があります。

パスだけを変更してデータをコピーしない場合、新しい場所に既にある内容で起動します。これは現在のデータを移行する操作ではありません。完全に移行する場合は **データをコピー** を有効にしたままにし、開始前にバックアップを作成してください。

## ログ、キャッシュとリセット

- **アプリのログ：** ログが保存されているディレクトリを開き、問題のトラブルシューティングやフィードバック提出要件に基づくログの送信に使用します。共有する前に、機密情報がないか確認し、削除してください。
- **キャッシュを消去：** アプリのキャッシュとミニプログラムのローカルデータを削除しますが、チャット履歴は削除されません。この操作は元に戻せません。
- **データをリセット：** Cherry Studio のデータを空にし、再起動します。ページで2回の確認が行われるため、利用可能なバックアップがあり、本当に最初からやり直したい場合にのみ使用してください。

{% hint style="danger" %}
「キャッシュを消去」と「データをリセット」を混同しないでください。前者はキャッシュに対して適用され、後者はローカルデータベースおよびアプリ管理のデータを空にします。
{% endhint %}

## 外部アプリデータのインポート

現在の **インポート設定** ページには **ChatGPT データをインポート** があります。**ファイルをインポート**をクリックし、ダイアログで ChatGPT からエクスポートしたデータファイルを選択します。

インポート前に、現在の Cherry Studio データをバックアップしてください。ページに他のアプリが表示されていない場合、現在のバージョンにはそのアプリ用のインポーターがありません。他のソフトウェアのデータベースやバックアップを Cherry Studio のバックアップとして復元しないでください。

## エクスポートメニュー

**エクスポートメニュー**は、チャットページに表示されるエクスポートオプションを制御します。現在含まれる項目は以下の通りです：

- 画像
- Markdown
- Markdown（思考を含む）
- Notion、Yuque、Joplin、Obsidian、SiYuan Note
- Word（DOCX）
- 純テキストとしてコピー

スイッチをオンにすると、その項目がエクスポートメニューへ表示されますが、サードパーティサービスは自動設定されません。Notion や Yuque などは、引き続き **設定 > 連携** で接続を設定する必要があります。

## 設定 Markdown エクスポート

**Markdown エクスポート**では、以下の項目を設定できます：

- デフォルトのエクスポートパス。空欄の場合、都度保存ダイアログが表示されます。
- LaTeX 公式に強制的に `$$` タグを使用するかどうか。
- トピック名メッセージのタイトルとして使用するかどうか。
- モデル名とモデルプロバイダーを表示するかどうか。
- 引用内容をエクスポートしないかどうか。
- 引用マークを Markdown の脚注形式に標準化するかどうか。

一部の項目は、Notion や Yuque など Markdown ベースのサードパーティエクスポートにも影響します。「引用内容をエクスポートしない」または「引用形式を標準化」を有効にする前に、引用を含む会話で結果が期待どおりか確認してください。

## よくある質問

### 自動バックアップでファイルが生成されない場合

バックアップ周期が「オフ」になっていないか、目標ディレクトリまたはリモートサービスにアクセス可能かを確認し、ページ下部の最新のバックアップ時間やエラーメッセージを確認してください。ローカルディレクトリがモバイルデバイスまたはネットワークマウントポイントにある場合は、現在オンラインであることを確認してください。

### コンパクトバックアップからの復元後に画像やナレッジベースファイルが不足している場合

これはコンパクトバックアップの仕様です。チャット履歴と設定のみを保持し、`Data` ディレクトリ内のファイルデータは含まれません。この場合は、「コンパクトバックアップ」をオフにした後に作成された完全なバックアップを使用してください。

### データディレクトリを変更した後、まるで新規インストールしたように見える場合

移行時に**データをコピー**するのを忘れたか、アプリが空のディレクトリで起動している可能性があります。大量の新しいデータを書き込むのは一旦やめ、元のディレクトリがまだ存在するか確認してから、設定から戻すかバックアップから復元してください。

### 複数のPCで復元した後、データが自動的に統合されない場合

バックアップからの復元は上書きプロセスであり、両側の新規コンテンツをマージすることはありません。復元する前にバックアップ時間を比較し、現在のデバイスのバックアップを別途保存するようにしてください。

解決しない場合は、[フィードバックと提案](../question-contact/suggestions.md)から、OS、Cherry Studio のバージョン、使用したバックアップ方法、エラーメッセージ、機密情報を隠した設定のスクリーンショットを送信してください。
