# SiYuan の設定とエクスポート

Cherry Studio V2 では、トピック全体、単一のメッセージ、Cherry Studio のノートを指定した SiYuan ノートブックへエクスポートできます。エクスポート内容は SiYuan Kernel API を通じて Markdown ドキュメントとして作成されます。

設定画面は **設定 > 連携 > SiYuan** にあります。**データ設定 > エクスポートメニュー** は、「SiYuan にエクスポート」を表示するかどうかだけを制御します。

{% hint style="warning" %}
API Token を使うと SiYuan のデータにアクセスできます。スクリーンショット、フィードバック、共有設定に完全な Token を表示しないでください。セルフホスト環境では、保護されていない API をインターネットへ直接公開しないでください。
{% endhint %}

## SiYuan を準備する

1. SiYuan を起動し、Kernel が正常に動作していることを確認します。
2. エクスポート内容を保存するノートブックを作成または選択します。
3. API Token を取得します。
4. 対象ノートブックの ID をコピーします。
5. Cherry Studio を実行しているデバイスから SiYuan API のアドレスへアクセスできることを確認します。

SiYuan 公式 API のローカルデフォルト Endpoint は次のとおりです。

```text
http://127.0.0.1:6806
```

API Token は **SiYuan > 設定 > 情報** で確認できます。完全なインターフェース仕様は [SiYuan 公式 API ドキュメント](https://github.com/siyuan-note/siyuan/blob/master/API.md)を参照してください。

## ノートブック ID を取得する

SiYuan で対象ノートブックの設定を開き、**ノートブック ID をコピー** を使用します。ID は通常、次のような形式です。

```text
20210817205410-2kvfpfn
```

ノートブック名、ワークスペースのパス、ドキュメント ID は入力しないでください。Cherry Studio はこの値を `notebook` パラメーターとして SiYuan のドキュメント作成 API に渡します。

## Cherry Studio で設定する

**設定 > 連携 > SiYuan** を開き、次の項目を入力します。

| 項目 | 説明 |
| --- | --- |
| API アドレス | SiYuan Kernel のアクセス先。例：`http://127.0.0.1:6806` |
| API トークン | SiYuan の設定に表示される API Token |
| ノートブック ID | エクスポートしたドキュメントを保存する Notebook ID |
| ドキュメントのルートパス | 任意。ノートブック内で、すべてのエクスポート先となる親パス |

API アドレスの末尾には `/` を付けないことを推奨します。`/api/...` パスと結合したときの二重スラッシュを避けられます。

### ローカル環境とセルフホスト環境のアドレス

- **SiYuan と Cherry Studio が同じコンピューターにある場合：** 通常は `http://127.0.0.1:6806` を使用します。
- **SiYuan が LAN 内の別デバイスまたは NAS にある場合：** Cherry Studio を実行するデバイスからアクセスできる IP アドレスとポートを使用します。相手側デバイスの `127.0.0.1` は入力できません。
- **インターネット上のセルフホスト環境：** HTTPS 対応ドメインを使用し、ファイアウォールまたはリバースプロキシでアクセス元を制限します。

Docker、NAS、リバースプロキシ経由の SiYuan に接続するときは、`/api/` パスが書き換えられたり遮断されたりしていないことも確認してください。

## 接続をテストする

**API アドレス** と **API トークン** を入力し、**テスト** をクリックします。

Cherry Studio は次の API を呼び出します。

```text
POST /api/notebook/lsNotebooks
```

テスト成功は、アドレスへアクセスでき、Token が有効で、API が `code: 0` を返したことを示します。ただし、次の項目は検証されません。

- 入力したノートブック ID が存在するか。
- 対象ノートブックが開かれているか。
- ドキュメントのルートパスが有効か。
- 現在の設定でドキュメントを正常に作成できるか。

そのため、テスト成功後も実際に一度エクスポートしてください。

## ドキュメントのルートパスを設定する

空欄の場合、Cherry Studio は次のパスを使用します。

```text
/CherryStudio
```

次のように別のパスを入力することもできます。

```text
/AI 対話
```

パスの先頭に `/` がない場合、Cherry Studio が自動的に補います。

### 日付テンプレートを使用する

ルートパスは最初に SiYuan の `renderSprig` API でレンダリングされるため、SiYuan が対応する Sprig テンプレートを使って日付別に整理できます。例：

```text
/CherryStudio/{{now | date "2006/01"}}
```

レンダリング結果は次のようになります。

```text
/CherryStudio/2026/07
```

テンプレート構文に誤りがあるとエクスポートに失敗します。初回設定では固定パスを使い、エクスポート成功を確認してからテンプレートを追加することを推奨します。

## エクスポートメニューを有効にする

メニューに「SiYuan にエクスポート」がない場合：

1. **設定 > データ設定 > エクスポートメニュー** を開きます。
2. **SiYuan にエクスポート** を有効にします。
3. トピック、メッセージ、またはノートに戻り、エクスポートメニューを開き直します。

このスイッチはメニューの表示だけを制御し、連携設定を自動入力するものではありません。

## 最初のエクスポートを実行する

機密情報を含まない短いメッセージでのテストを推奨します。

1. トピック、メッセージ、または Cherry Studio ノートのメニューを開きます。
2. **SiYuan にエクスポート** を選択します。
3. 成功またはエラーの通知を待ちます。
4. 対象の SiYuan ノートブックに戻ります。
5. ルートパスの下に、トピックまたはメッセージのタイトルを名前とするドキュメントが作成されたか確認します。
6. ドキュメントを開き、タイトル、段落、リスト、コードブロック、数式を確認します。

エクスポートのたびに、Cherry Studio はまず `lsNotebooks` を再度呼び出して接続を確認し、次の処理を行います。

1. ドキュメントのルートパスをレンダリングします。
2. タイトルから一部の特殊文字を取り除きます。
3. ルートパスとドキュメントタイトルを結合します。
4. `POST /api/filetree/createDocWithMd` を呼び出してドキュメントを作成します。

SiYuan の公式 API は、同じパスへの重複リクエストで既存ドキュメントを上書きしません。古い内容を更新する場合は SiYuan 側で既存ドキュメントを処理するか、タイトルまたはルートパスを変更してから再度エクスポートしてください。

## エクスポートする内容の範囲

- **トピック全体：** 現在のトピックのメッセージ順に Markdown へ変換します。
- **単一のメッセージ：** 選択したメッセージだけをエクスポートします。
- **Cherry Studio ノート：** 現在のノートの Markdown 内容をエクスポートします。

現在、SiYuan へのエクスポートには「思考内容を含める」ための個別スイッチがありません。特定の内容を残す必要がある場合は、実際にエクスポートされるテキストを Cherry Studio で事前に確認してください。

## セキュリティに関する推奨事項

- ローカルで使う場合は、API の待ち受け先をローカルホストまたは信頼できるネットワークに限定します。
- リモートで使う場合は HTTPS を有効にし、リバースプロキシとファイアウォールでアクセスを制限します。
- Token が漏えいした場合は SiYuan ですぐに変更し、Cherry Studio の設定も更新します。
- 実際の Token をドキュメント、スクリーンショット、チャット、リポジトリへ書き込まないでください。
- 重要なノートブックには信頼できるバックアップを設定してください。エクスポート機能は SiYuan データのバックアップに代わるものではありません。

## よくある質問

### テスト時に「API アドレスとトークンを入力してください」と表示される

テストに必要なのは API アドレスと Token だけです。両方の入力欄が空でなく、アドレスに `http://` または `https://` が含まれていることを確認してください。

### ローカルアドレスに接続できない

SiYuan が起動しており、同じコンピューターのブラウザーから `127.0.0.1:6806` へアクセスできることを確認し、ポートが変更されていないか確認してください。Cherry Studio と SiYuan が別のデバイスにある場合、`127.0.0.1` は使用できません。

### テストは成功するが、エクスポート時に設定不完全と表示される

実際のエクスポートには **ノートブック ID** も必要です。ノートブック名やドキュメント ID ではなく、Notebook ID が入力されていることを確認してください。

### テストは成功するが、ドキュメントの作成に失敗する

対象ノートブックが存在し、利用可能な状態か確認してから、ルートパスを単純な `/CherryStudio` に変更してください。これでエクスポートできる場合、元の Sprig テンプレートまたはパスが無効な可能性があります。

### セルフホスト環境が 401 または 403 を返す

Token が完全か、リバースプロキシが `Authorization: Token ...` リクエストヘッダーを保持しているか、アクセスポリシーが Cherry Studio を実行するデバイスを許可しているかを確認してください。

### 404 または HTML ページが返される

API アドレスに Web ページのサブパスを入力しているか、リバースプロキシが `/api/` を SiYuan Kernel へ転送していない可能性があります。API アドレスにはインスタンスのルートアドレスを使い、`/api/notebook/lsNotebooks` を含めないでください。

### 再度エクスポートしても古いドキュメントが上書きされない

これは `createDocWithMd` API の動作です。同じパスにある既存ドキュメントは上書きされません。ドキュメントのタイトルまたはルートパスを変更するか、先に SiYuan 側で古いドキュメントを処理してください。

### 会話メニューに SiYuan がない

**設定 > データ設定 > エクスポートメニュー** を開き、**SiYuan にエクスポート** を有効にします。すでに有効な場合は、現在の会話を開き直してからメニューを再表示します。

解決しない場合は、[フィードバックと提案](../../question-contact/suggestions.md)から Cherry Studio と SiYuan のバージョン、導入方式、マスキング済みの API アドレス、ノートブック ID、ルートパス、API エラー情報を送信してください。
