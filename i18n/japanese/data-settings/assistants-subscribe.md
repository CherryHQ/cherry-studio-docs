# アシスタント購読の設定

アシスタント購読では、公開 JSON URL を**アシスタントテンプレートライブラリのデータソース**として設定できます。チームは 1 つのテンプレート一覧だけを管理し、メンバーはアシスタントライブラリを再読み込みすることで最新の内容を確認できます。

{% hint style="info" %}
購読で提供されるのは選択可能な**テンプレート**です。「マイ」グループで自作したテンプレートを変更したり、作成済みのアシスタントを自動更新したりすることはありません。購読テンプレートをアシスタントとして追加すると、独立したローカルコピーになります。
{% endhint %}

## 購読前の準備

オブジェクトストレージ、静的 Web サイト、コードリポジトリの Raw ファイルなど、JSON を直接返す公開 URL を準備してください。

購読 URL は次の条件を満たす必要があります。

- `https://` の使用を推奨します。
- ログイン、Cookie、リクエストヘッダーなしでアクセスできる必要があります。
- URL を開くとダウンロードページ、プレビューページ、HTML ページではなく、JSON が直接返される必要があります。
- JSON のルートノードは配列です。
- 各テンプレートに少なくとも `id`、`name`、`prompt`、`group` が含まれます。
- 同じ購読内で `id` は一意で、`group` は文字列の配列である必要があります。

{% hint style="warning" %}
Cherry Studio はこの URL から直接内容を読み取ります。現在、ユーザー名、パスワード、カスタムリクエストヘッダーを入力する項目はありません。アクセストークン、API Key、その他の認証情報を購読 URL や JSON ファイルへ書き込まないでください。
{% endhint %}

## 購読を設定する

1. Cherry Studio の**ランチャー**を開きます。
2. **アシスタントライブラリ**に移動します。
3. 右上の**外部からインポート**をクリックします。
4. ダイアログ下部の**アシスタント購読**を探します。
5. 購読 URL を貼り付け、**購読**をクリックします。
6. アプリが再読み込みされたら、アシスタントライブラリに戻り、リモートテンプレートとグループを確認します。

購読成功は、その時点で URL にアクセスできたことだけを示します。返された内容が有効なテンプレート配列でない場合、アシスタントライブラリは正常に表示されない可能性があります。以下の説明に沿って JSON を確認してください。

## JSON の形式

そのまま出発点として使用できる最小構成の例です。

```json
[
  {
    "id": "product-manager",
    "name": "プロダクトマネージャー",
    "emoji": "🧭",
    "description": "要件、範囲、製品計画の整理を支援します。",
    "group": ["製品", "仕事"],
    "prompt": "あなたは経験豊富なプロダクトマネージャーです。まず目標と制約を明確にし、構造化された実行可能な提案を提示してください。",
    "regularPhrases": []
  },
  {
    "id": "writing-editor",
    "name": "ライティングエディター",
    "emoji": "✍️",
    "description": "文章の構成、表現、読みやすさを確認します。",
    "group": ["執筆"],
    "prompt": "あなたはプロの編集者です。作者の意図を保ちながら具体的な問題を指摘し、そのまま使える修正文を提示してください。",
    "regularPhrases": []
  }
]
```

### フィールドの説明

| フィールド | 入力の推奨 | 説明 |
| --- | --- | --- |
| `id` | 必須 | テンプレートの安定した一意識別子。同じ値を 2 つのテンプレートで使用しないでください。 |
| `name` | 必須 | アシスタントライブラリに表示されるテンプレート名。 |
| `prompt` | 必須 | アシスタント作成後に使用されるシステムプロンプト。 |
| `group` | 必須 | テンプレートが属するグループ。`["写作", "工作"]` のような配列にする必要があります。1 つのテンプレートを複数のグループに表示できます。 |
| `emoji` | 任意 | テンプレートアイコン。省略すると、想定したアイコンが画面に表示されない場合があります。 |
| `description` | 任意 | プレビューや検索に使用するテンプレートの概要。 |
| `regularPhrases` | 任意 | 定型フレーズの配列。不要な場合は `[]` とするか省略できます。 |

{% hint style="warning" %}
`group` は値が 1 つだけでも配列にする必要があります。`"group": "写作"` と書くと、グループ別にテンプレートを正常に読み込めません。
{% endhint %}

## 購読ファイルを検証する

公開前に少なくとも次の項目を確認してください。

1. ブラウザーで購読 URL を直接開き、JSON 本文が表示されることを確認します。
2. JSON 検証ツールを使い、余分なカンマ、引用符の不足、対応していない括弧がないか確認します。
3. ルートノードが `[]` であり、`{}` ではないことを確認します。
4. 各テンプレートに空でない `name` と `prompt` があることを確認します。
5. 各 `group` が配列で、各 `id` が一意であることを確認します。
6. まず 1～2 個のテンプレートでテストし、その後、一覧を段階的に増やします。

コマンドラインに慣れている場合は、次の方法で URL にアクセスできるか、JSON を解析できるかを確認できます。

```bash
curl -fsSL "https://example.com/assistants.json" | jq .
```

例の URL は自分の公開購読 URL に置き換えてください。

## 購読の更新方法

アシスタント購読はプッシュサービスではなく、一定間隔でバックグラウンド同期されるものでもありません。

- Cherry Studio はアシスタントテンプレートを読み込むときに購読 URL へ再度リクエストします。
- リモート JSON を変更した後、アプリを再読み込みするか、アシスタントライブラリへ入り直すと新しい内容を確認できます。
- リモート一覧が組み込みテンプレートのデータソースに置き換わりますが、「マイ」グループの自作テンプレートは削除されません。
- リモート URL が一時的に利用できない場合、アプリは組み込みテンプレートへのフォールバックを試みます。
- テンプレートから作成済みのアシスタントは独立したコピーであり、以後リモート JSON に合わせて変化しません。

作成済みのアシスタントを変更する場合は、購読ファイルだけを変更するのではなく、そのアシスタントを直接編集してください。

## 購読解除または URL の変更

1. **アシスタントライブラリ > 外部からインポート**を開きます。
2. **アシスタント購読**の領域で**購読解除**をクリックします。
3. アプリの再読み込みを待ちます。組み込みテンプレートの使用に戻ります。
4. データソースを変更する場合は、同じダイアログを再度開き、新しい URL を入力して購読します。

すでに購読中の場合、ボタンは購読解除を実行します。URL を変更するときは、先に購読を解除してから新しい URL を購読してください。

## インポート機能との違い

Cherry Studio には、似ていますが用途の異なる入口がいくつかあります。

| 機能 | 結果 | 適した場面 |
| --- | --- | --- |
| アシスタント購読 | リモート JSON がアシスタントテンプレートのデータソースになり、アシスタントライブラリを開くたびに再取得される | チームで多数のテンプレートを一元管理し、継続的に更新する |
| アシスタントライブラリの URL／ファイルインポート | テンプレートをただちに「マイ」グループへコピーし、その後は元ファイルと連動しない | 一度インポートし、自分で編集する |
| [V2 リソースライブラリへのインポート](../cherrystudio/preview/library.md) | ファイル、クリップボード、対応する Raw URL からリソースライブラリのアシスタントを作成する | V2 リソースライブラリでアシスタントを一元管理する |

{% hint style="info" %}
アシスタントを 1 つだけ共有する場合は、エクスポートとインポートを優先してください。公共テンプレート一式を長期間管理する必要がある場合にだけ購読を設定します。
{% endhint %}

## セキュリティに関する推奨事項

- 自分または信頼できるチームが管理する URL だけを購読します。
- HTTPS を使用し、購読ファイルの編集権限を制限します。
- 購読の更新後、追加または変更されたプロンプトを抜き取り確認します。
- `prompt`、`description`、URL にパスワード、トークン、個人情報を保存しないでください。
- 重要な購読ファイルにはバージョン管理を設定し、問題発生時にすぐ戻せるようにします。

テンプレート内のプロンプトはアシスタントの回答方法に影響します。テンプレートをアシスタントとして追加する前に、プロンプト全文を読み、意図しない指示が含まれていないことを確認してください。

## よくある質問

### 購読をクリックしても組み込みテンプレートが表示される

URL が `http://` または `https://` で始まり、ログインなしでアクセスできることを確認してください。その後アプリを再読み込みし、アシスタントライブラリへ入り直します。

### URL は開けるが、グループが表示されない

ルートノードが配列であり、各テンプレートの `group` が文字列の配列になっているか確認してください。有効なグループがないテンプレートはカテゴリ一覧に正しく表示されません。

### JSON ではなく Web ページが返される

リポジトリのファイルプレビューページをコピーした可能性があります。Raw ファイルの URL を使用するか、ファイル内容を直接返す静的 URL に JSON を配置してください。

### JSON 更新後もアシスタントが変わらない

まずアプリを再読み込みするか、アシスタントライブラリへ入り直してください。作成済みのアシスタントは自動同期されないため、手動で編集するか、更新後のテンプレートから作成し直す必要があります。

### リモートサービスが一時的に利用できない

Cherry Studio は組み込みテンプレートの使用を試みます。サービス復旧後にアプリを再読み込みしてください。また、DNS、証明書、リダイレクト、クロスオリジンアクセスが正常か確認することを推奨します。
