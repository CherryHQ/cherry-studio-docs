# ビジネスに関するお問い合わせ

Cherry Studio のビジネス窓口：

**[bd@cherry-ai.com](mailto:bd@cherry-ai.com)**

このメールアドレスは、Enterprise Edition、購入、商用ライセンス、提携に関する相談用です。Community Edition の日常的な使用方法について、優先的なサポートを提供する窓口ではありません。

## ビジネス窓口に適した内容

### Cherry Studio Enterprise Edition

Enterprise Edition は、AI リソース、組織メンバー、ナレッジ資産を一元管理する必要があるチーム向けです。現在公式に案内されている方向性は次のとおりです。

* クラウドモデルとローカルのプライベートモデルを統合して接続する。
* チームでナレッジベースを共有する。
* 従業員と権限を管理する。
* プライベート環境に導入する。
* エンタープライズ向けのデータバックアップと復元。

まず [Cherry Studio Enterprise Edition](https://enterprise.cherry-ai.com) で公開情報を確認し、デモ、見積もり、対応範囲についてビジネス窓口にお問い合わせください。

{% hint style="info" %}
具体的な機能、導入方法、サービス範囲、価格、納期については、実際の要件に基づいてビジネス担当者が提示する提案と契約が優先されます。
{% endhint %}

### 商用ライセンス

Cherry Studio Community Edition は **GNU Affero General Public License v3.0（AGPL-3.0）** で提供されています。商用利用が一律に禁止されているわけではありませんが、ライセンス条件を遵守する必要があります。

組織が AGPL-3.0 の一部要件に拘束されない商用ライセンスを希望する場合は、ビジネス窓口にお問い合わせください。ライセンスの概要は [Cherry Studio オープンソースライセンス](questions/cherrystudio-xu-ke-xie-yi.md)を参照してください。

### エコシステムと共同プロジェクト

次のような提携について、簡単な提案を送付できます。

* モデルサービスと API の接続。
* エンタープライズソリューションとプライベート環境への導入。
* ハードウェア、OS、販売チャネルに関する提携。
* 教育、研究、コミュニティの共同イベント。
* 許可を得たブランド、メディア、マーケティングの提携。

メールを送信しただけでは、提携は成立しません。製品名、Logo、広報表現、顧客事例を扱う場合は、事前に書面で確認を得てください。

## メールに含める内容

確認の往復を減らすため、最初のメールに次の情報を記載してください。

1. **組織情報**：会社または団体名、公式サイト、所在地域、担当者。
2. **相談の種類**：Enterprise Edition、商用ライセンス、モデル接続、販売チャネル、その他の提携。
3. **利用規模**：想定ユーザー数、端末数、導入範囲。
4. **導入環境**：パブリッククラウド、プライベートクラウド、LAN、完全なオフライン環境。
5. **主要な要件**：解決すべき業務上の課題と必須機能。
6. **セキュリティ要件**：データ所在地、認証、権限、監査、コンプライアンス要件。
7. **予定時期**：評価、テスト、稼働開始を希望する時期。
8. **連絡先**：その後の連絡に使える業務用メールアドレスとタイムゾーン。

### 件名の例

```text
[Enterprise Edition] 企業名 / 200 名 / プライベート環境への導入
[商用ライセンス] 製品名への Cherry Studio Community Edition の統合
[エコシステム提携] モデルプロバイダーの API 接続
```

### メールテンプレート

```text
組織名：
公式サイト：
担当者と役職：
相談の種類：

利用場面：
想定規模：
導入環境：
必須機能：
セキュリティとコンプライアンスの要件：
予定時期：

ビジネス担当者に希望する対応：
```

最初のメールに、本番用 API Key、パスワード、秘密鍵、実在するユーザーのデータ、匿名化していない社内文書を含めないでください。
