# リソース管理の入口

Cherry Studio V2 では、独立した「リソースライブラリ」ページが廃止されました。アシスタント、Agent、スキル、プロンプトは引き続き管理できますが、入口はそれぞれを使用する画面へ移動しています。

{% hint style="warning" %}
旧 `/app/library` ルートは提供されておらず、ランチパッドにもリソースライブラリのタイルはありません。アップグレード後、旧ルートの固定タブは自動的に削除されます。古いスクリーンショットのページを探し続けないでください。
{% endhint %}

## 現在の入口

| リソース | 管理する場所 | 主な操作 |
| :--- | :--- | :--- |
| アシスタント | **チャット**を開き、左側のリソースメニューからアシスタント管理へ移動 | 作成、インポート、編集、複製、エクスポート、グループ化、削除 |
| Agent | **ワーク**を開き、左側のリソースメニューから Agent 管理へ移動 | 作成、編集、作業ディレクトリとツールの設定、削除 |
| スキル | **設定 → スキル**を開く | グローバルスキルの検索、インストール、確認、アンインストール |
| プロンプト | 会話入力欄から**クイックフレーズ**を開き、**管理**または**追加**を選択 | 再利用できるプロンプトの作成、編集、検索、挿入、削除 |

これらの入口は現在の作業画面に直接表示されます。たとえばアシスタントを編集した後、独立したリソースページを経由せず、そのまま会話へ戻れます。

## アシスタントライブラリとリソース管理

[アシスタントライブラリ](agents.md)では、引き続きコミュニティのアシスタントを探してインポートできます。インポートしたアシスタントは自分の一覧へ追加され、**チャット**ページのアシスタント管理から編集します。

アシスタントライブラリは、旧リソースライブラリの代替ルートではありません。

- アシスタントライブラリはコミュニティのコンテンツを提供します。
- アシスタント管理では、自分が所有するアシスタントを管理します。
- Agent、スキル、プロンプトは上表の個別入口を使用します。

## 古いリンクが開かない場合

ブックマーク、履歴、古いガイドに `/app/library` が含まれる場合：

1. そのアドレスを繰り返し再読み込みしないでください。
2. リソースの種類に対応する新しい入口を開きます。
3. アプリはタブ復元時に旧固定タブを削除しますが、実際のアシスタント、Agent、スキル、プロンプトのデータは削除しません。

グローバル検索も旧リソースライブラリのルート履歴を除外し、削除済みページが再び開かれないようにします。
