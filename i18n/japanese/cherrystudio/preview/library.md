# リソースライブラリ

リソースライブラリでは、Cherry Studio で作成またはインストールしたアシスタント、エージェント、スキル、プロンプトをまとめて管理できます。リソースの種類を切り替えて一覧を表示し、既存のリソースを検索したり、同じ画面から新規作成、インポート、編集、削除を行ったりできます。

{% hint style="info" %}
リソースライブラリと[アシスタントライブラリ](agents.md)は用途が異なります。アシスタントライブラリではコミュニティのアシスタントを探してインポートし、リソースライブラリでは自分が所有しているリソースを管理します。
{% endhint %}

## リソースライブラリを開く

ランチパッドで **リソースライブラリ** をクリックします。画面左側には 4 種類のリソースとそれぞれの件数が表示され、右側には選択中の種類のリソースカードが表示されます。

| 種類 | できること |
| :--- | :--- |
| アシスタント | アシスタントを作成またはインポートし、モデル、プロンプト、ナレッジベース、ツールを設定する |
| エージェント | エージェントを作成し、モデル、作業ディレクトリ、権限、使用できるツールを設定する |
| スキル | ZIP ファイルまたはローカルディレクトリからスキルをインストールし、内容の確認やアンインストールを行う |
| プロンプト | 再利用できるプロンプトを作成して管理する |

## リソースを検索、整理する

1. 左側でリソースの種類を選択します。
2. 上部の検索ボックスに名前またはキーワードを入力します。
3. 「アシスタント」の一覧では、タグを使ってさらに絞り込むこともできます。

アシスタントカードの操作メニューでは、タグを管理できます。新しいタグを作成した後、ほかのアシスタントにもそのタグを割り当てられます。

## リソースを新規作成、インポートする

画面右上の新規作成またはインポートボタンをクリックし、選択中のリソースに応じた操作を行います。

* アシスタント、エージェント、プロンプトでは、それぞれの設定画面が開きます。必須項目を入力して保存すると作成されます。
* アシスタントは JSON ファイルからインポートできます。
* スキルはローカルの ZIP ファイル、または `SKILL.md` を含むディレクトリからインストールできます。スキルマーケットは「設定 → スキル」から利用します。

作成またはインストールが完了すると、対応する種類の一覧にリソースが表示されます。

## リソースを編集、管理する

リソースカードをクリックすると、編集画面または詳細画面が開きます。カードの操作メニューから次の操作を行うこともできます。

* リソースの設定を編集する。
* アシスタントを複製またはエクスポートする。
* アシスタント、エージェント、プロンプトを削除する。
* スキルの詳細を確認し、不要なスキルをアンインストールする。

削除またはアンインストールの前に、Cherry Studio に確認メッセージが表示されます。そのリソースを参照しているワークフローに影響する可能性があるため、使用されていないことを確認してから操作してください。
