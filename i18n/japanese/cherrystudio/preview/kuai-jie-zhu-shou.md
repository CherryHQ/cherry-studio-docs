# クイックアシスタント

クイックアシスタントは、他のアプリの上に呼び出せる軽量ウィンドウです。Cherry Studio のメインウィンドウへ切り替えなくても、一時的な質問、翻訳、要約、文章の説明に使用できます。

{% hint style="info" %}
クイックアシスタントと[選択アシスタント](selection-assistant.md)は別の機能です。クイックアシスタントはグローバルショートカットまたはトレイから呼び出します。選択アシスタントはテキストを選択すると操作ツールバーを表示します。
{% endhint %}

## 使用前の準備

クイックアシスタントは設定済みのモデルを呼び出します。有効にする前に、利用可能なチャットモデルが少なくとも 1 つあることを確認してください。「テキスト翻訳」を使用する場合は、翻訳モデルも設定する必要があります。

関連する設定については、[デフォルトモデル](settings/default-models.md)を参照してください。

## クイックアシスタントを有効にする

1. **設定 → クイックアシスタント**を開きます。
2. **クイックアシスタントを有効にする**をオンにします。
3. **トレイアイコンをクリックして起動**をオンにするか選択します。
4. **起動時にクリップボードを読み取る**をオンにするか選択します。
5. **クイックアシスタントモデル**で「アシスタントを使用」または「デフォルトモデル」を選択します。

設定ページの下部にはクイックアシスタントのプレビューが表示されます。先にここでモデルと画面が正常に動作するか確認できます。

### モデルの選択方法

| 方法 | 実際の動作 |
| --- | --- |
| アシスタントを使用 | 既存のアシスタントを選択し、そのシステムプロンプト、モデル、モデルパラメーターを使用します |
| デフォルトモデル | 特定のアシスタントを適用せず、現在のデフォルトモデルを使用します |

「テキスト翻訳」では個別に設定された翻訳モデルを使用し、ここで選択したアシスタントは使用しません。

{% hint style="warning" %}
クイックアシスタントの回答、要約、説明では、ウェブ検索、MCP、ナレッジベースが無効になります。これらの機能が必要な場合は、メインウィンドウの[チャット](chat.md)を使用してください。
{% endhint %}

## 呼び出し方法を設定する

### グローバルショートカット

1. **設定 → ショートカット**を開きます。
2. **クイックアシスタント**を見つけます。
3. このショートカットを有効にします。
4. 必要に応じてキーの組み合わせを変更します。

システムには次の組み合わせがあらかじめ入力されています。

* macOS：Command + E
* Windows / Linux：Ctrl + E

このショートカットは初期状態では無効です。クイックアシスタントのメインスイッチをオンにするだけでは、グローバルショートカットは自動的に有効になりません。

詳しくは[ショートカット設定](settings/key-shortcut.md)を参照してください。

### システムトレイ

**トレイアイコンをクリックして起動**をオンにすると、Cherry Studio のトレイアイコンを 1 回クリックしてクイックアシスタントを開けるようになり、システムトレイ機能も有効になります。

クリックでの起動をオンにしていない場合でも、クイックアシスタントが有効であれば、トレイアイコンを右クリックしてメニューからクイックアシスタントを選択できます。

## 開いて操作を実行する

1. 任意のアプリで有効なグローバルショートカットを押すか、トレイの入口を使用します。
2. 処理する内容を入力します。
3. 操作を 1 つ選択します。

| 操作 | 用途 |
| --- | --- |
| この質問に回答 | 入力を通常の質問としてモデルへ送信します |
| テキスト翻訳 | 目標言語を選択し、入力内容を翻訳します |
| 内容要約 | 組み込みの要約指示で入力内容を処理します |
| 説明 | 組み込みの説明指示で入力内容を処理します |

上／下の方向キーで操作を切り替え、Enter で現在の操作を実行できます。

### クリップボードの内容を使用する

**起動時にクリップボードを読み取る**をオンにすると、ウィンドウが表示されるたびに、クイックアシスタントは新しいプレーンテキストのクリップボード内容を読み取り、参照テキストとして表示します。

この状態では次の操作を行えます。

* 翻訳、要約、説明を直接選択する
* 指示を続けて入力し、クリップボードのテキストと指示を一緒に送信する
* ホーム画面で Backspace を押し、クリップボードの参照テキストを消去する

クリップボードが空、プレーンテキストではない、またはシステムが読み取り権限を拒否した場合、ウィンドウには利用可能な参照テキストが表示されません。

## 結果を確認して質問を続ける

回答、要約、説明はストリーミング形式で表示されます。「この質問に回答」を使用した後は、結果ページで入力を続け、一時的なチャットとしてやり取りできます。

テキスト翻訳ページでは目標言語を変更でき、設定に応じて結果が再生成されます。

クイックアシスタントの内容は一時的なセッションです。ホーム画面へ戻るかウィンドウを閉じた後は、メインウィンドウの長期的なチャット履歴として扱わないでください。

## ウィンドウ操作

| 操作 | 結果 |
| --- | --- |
| Esc（生成中） | 現在の生成を一時停止します |
| Esc（結果ページ） | クイックアシスタントのホーム画面へ戻ります |
| Esc（ホーム画面） | ウィンドウを非表示にします |
| C（結果ページ） | 最新のモデル出力をコピーします |
| ピンをクリック | ウィンドウを最前面に固定し、フォーカスを失っても自動的に非表示にならないようにします |
| ウィンドウの外側をクリック | 最前面に固定していない場合、クイックアシスタントを非表示にします |

ウィンドウをもう一度開いたときは、現在のモデル選択方法、クリップボードのスイッチ、翻訳の目標言語が引き続き使用されます。

## 使用上のヒント

* 現在コピーしている短い文章を処理する場合は、クリップボードの読み取りを有効にすると手順を最小限にできます。
* 決まった文体や形式をよく使う場合は、専用のアシスタントを選択します。
* すばやく質問したいだけの場合は、デフォルトモデルを使用すると追加設定を減らせます。
* 長い文書、添付ファイル、ウェブ検索、ナレッジベースの資料を扱う場合は、メインウィンドウのチャットを使用します。

## よくある質問

### Command + E または Ctrl + E を押しても反応しない

クイックアシスタントのメインスイッチとショートカット自体が両方とも有効になっていることを確認してください。他のアプリがショートカットを使用している場合は、ショートカット設定で別の組み合わせに変更します。

### トレイアイコンをクリックしても開かない

**トレイアイコンをクリックして起動**がオンになっていることを確認し、システムトレイ領域で Cherry Studio のアイコンが隠れていないか確認してください。アイコンを右クリックしてメニューから開くこともできます。

### 他の場所をクリックするとウィンドウが消える

最前面に固定していない場合の通常の動作です。他のアプリの内容と見比べる必要がある場合は、右下のピンをクリックします。

### クリップボードを読み取れない

スイッチがオンで、クリップボードの内容がプレーンテキストであることを確認し、システムのクリップボード権限を確認してください。新しい内容をコピーしてから、ウィンドウをもう一度呼び出します。

### 翻訳結果が表示されない

「テキスト翻訳」は翻訳モデルを使用します。デフォルトモデル設定の翻訳モデル、プロバイダーの状態、API 設定を確認してください。

### アシスタントのナレッジベースや MCP が機能しない

クイックアシスタントはウェブ検索、MCP、ナレッジベースを意図的に無効にします。メインウィンドウでそのアシスタントを使用してください。

## プライバシーに関する注意

クリップボードの読み取りを有効にすると、クイックアシスタントはウィンドウが表示されたときにプレーンテキストのクリップボードを読み取ります。回答、翻訳、要約、説明を実行した場合に限り、該当するテキストがリクエストとともに選択したモデルプロバイダーへ送信されます。

パスワード、キー、その他の機密情報を扱う前に、クリップボードの参照テキストを消去するか、**起動時にクリップボードを読み取る**をオフにしてください。
