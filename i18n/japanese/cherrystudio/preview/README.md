# 機能一覧

Cherry Studio V2 は、複数モデルとの対話、エージェント、コンテンツ作成、ナレッジ管理、自動化ツールを 1 つのデスクトップワークスペースにまとめています。このページでは、目的に合うモジュールをすばやく選べるように案内します。具体的な操作は、各機能のガイドを続けてお読みください。

## 機能を見つける方法

Cherry Studio には、主に 3 つの入口があります。

* **ランチパッド**：アプリモジュールや固定済みのミニプログラムをまとめて開きます。
* **左サイドバー**：よく使うモジュールを配置します。表示するアイコンは設定で変更できます。
* **上部タブバー**：機能やコンテンツを開くたびにタブを作成し、複数のタスクを切り替えられます。

画面構成がわからない場合は、まず[ランチパッド](launchpad.md)をお読みください。

## 目的に合うモジュールを選ぶ

| 目的 | 使用するモジュール | 主な機能 |
| --- | --- | --- |
| モデルと日常的な質疑応答を行う | [会話](chat.md) | アシスタント、トピック、添付ファイル、ナレッジベース、ツール呼び出し、複数モデルからの回答 |
| 役割やプロンプト設定を再利用する | [アシスタントライブラリ](agents.md) | 対話アシスタントの閲覧、追加、作成 |
| AI にファイルを読み取らせ、タスクを継続実行する | [エージェント](../../advanced-basic/agent.md) | ワークスペース、権限モード、スキル、ツール、複数ターンのタスク実行 |
| モデル、アシスタント、エージェントなどの設定を管理する | [リソースライブラリ](library.md) | リソースの分類表示、検索、編集、再利用 |
| 画像を生成または編集する | [画像生成](drawing.md) | 画像モデルの選択、プロンプトの入力、生成結果の管理 |
| 2 言語間の変換をすばやく行う | [翻訳](translation.md) | 原文言語、訳文言語、翻訳モデルの選択 |
| プロバイダーの Web アプリを利用する | [ミニプログラム](app.md) | Cherry Studio のタブで Web アプリを開き、固定する |
| 自分の資料を使って回答を補助する | [ナレッジベース](knowledge-base.md) | 資料のインポート、ベクトル化、検索、会話での引用 |
| アプリで使用した添付ファイルを探す | [ファイル](files.md) | 文書、画像、テキスト別にファイルを閲覧、整理する |
| Markdown コンテンツを記録、整理する | [ノート](notes.md) | フォルダ、検索、編集、閲覧、エクスポート |
| 他のアプリからすばやく質問する | [クイックアシスタント](kuai-jie-zhu-shou.md) | グローバルショートカットで軽量な会話ウインドウを開く |
| 選択したテキストをすぐに処理する | [テキスト選択アシスタント](selection-assistant.md) | 他のアプリでテキストを選択し、プリセット操作を呼び出す |
| Claude Code、Codex などのコーディングツールを使用する | [コードツール](../../advanced-basic/code-tools-shi-yong-jiao-cheng.md) | CLI、プロバイダー、プロジェクトセッションを管理する |
| 個人用 AI アシスタントゲートウェイを実行する | [OpenClaw](../../advanced-basic/openclaw.md) | ゲートウェイ、モデル、外部チャンネルを設定する |

## 対話アシスタントとエージェントの違い

どちらのモジュールもモデルを使用しますが、重視する点が異なります。

| | 対話アシスタント | エージェント |
| --- | --- | --- |
| 適した用途 | 質疑応答、執筆、分析、固定された役割との対話 | ファイルの読み書き、ツール呼び出し、継続実行が必要なタスク |
| 主な設定 | プロンプト、モデル、ナレッジベース、MCP | ワークスペース、権限、スキル、ツール、最大ターン数 |
| 実行方法 | メッセージのやり取りが中心 | 目標に沿って自律的に計画し、複数ステップを実行する |
| リスク管理 | 主にモデルへ送信する内容を管理する | ファイルとコマンドの権限も管理する必要がある |

内容の検討と生成だけが必要なら、まず対話アシスタントを使用してください。ローカルワークスペースへのアクセスや実際の操作が必要な場合は、エージェントを使用します。

## 一般的なワークフロー

### 初めて使う

1. [モデルサービス](../../pre-basic/providers/)でプロバイダーとモデルを追加します。
2. [会話](chat.md)を開き、テストメッセージを送信します。
3. [アシスタントライブラリ](agents.md)から、よく使うアシスタントを追加します。
4. [データ設定](../../data-settings/)でバックアップを設定します。

### 資料に基づいて質問する

1. [ナレッジベース](knowledge-base.md)で新しいナレッジベースを作成します。
2. ファイル、Web ページ、その他の対応データソースをインポートします。
3. 資料の処理が完了するまで待ちます。
4. 会話でナレッジベースを選択してから質問します。

### プロジェクトのタスクを実行する

1. [リソースライブラリ](library.md)でエージェントを作成します。
2. モデル、権限モード、スキル、ツールを選択します。
3. エージェントを開き、ワークスペースを確認します。
4. 明確な目標を入力してタスクを開始し、実行中は権限要求とファイル変更を確認します。

### いつでも AI を呼び出す

* [クイックアシスタント](kuai-jie-zhu-shou.md)を使用すると、現在のアプリを切り替えずに質問できます。
* [テキスト選択アシスタント](selection-assistant.md)を使用すると、選択済みのテキストを翻訳、要約、書き換えできます。

## 自動化と外部連携

基本機能だけではワークフローを実現できない場合は、次の機能も使用できます。

* [MCP](../../advanced-basic/mcp/)：対話アシスタントを外部のツールやデータに接続します。
* [API サーバー](../../advanced-basic/api-server.md)：互換インターフェースを通じて Cherry Studio のローカル機能を呼び出します。V2 エージェントの実行経路の一部でもあります。
* [チャンネル](../../advanced-basic/agent-channels.md)：エージェントを対応するメッセージングチャンネルに接続します。
* [スケジュールタスク](../../advanced-basic/scheduled-tasks.md)：指定した時刻にエージェントのセッションを開始します。

{% hint style="info" %}
最初にモデルサービスとデータバックアップを設定してから、エージェント、MCP、チャンネル、スケジュールタスクを段階的に有効にしてください。ファイルの書き込み、コマンド実行、外部送信を伴う場合は、タスクに必要な最小限の権限を使用します。
{% endhint %}
