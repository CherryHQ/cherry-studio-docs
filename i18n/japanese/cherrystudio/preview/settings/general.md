# 一般設定

Cherry Studio V2 の一般設定は、次の 4 ページに分かれています。

1. **表示と言語**
2. **システムと起動**
3. **プライバシーと詳細設定**
4. **カスタム CSS**

アクセス方法：

> **設定 → 一般設定**

このページでは、各設定の役割、設定間の依存関係、再起動が必要になる場面について説明します。

## 表示と言語

### インターフェース言語

現在、以下の言語を選択できます：

- 简体中文
- 繁體中文
- English
- Deutsch
- 日本語
- Русский
- Ελληνικά
- Español
- Français
- Português
- Română
- Tiếng Việt

切り替えるとインターフェースはすぐに更新されます。サードパーティ製モデルの名前、プロバイダーから返されるエラー、アシスタントの内容、ユーザーが入力したテキストは自動翻訳されません。

{% hint style="info" %}
アプリのインターフェースとコミュニティドキュメントでは、対応言語が異なります。現在のコミュニティドキュメントは、简体中文、繁體中文、English、日本語、Русскийの 5 言語でメンテナンスされています。
{% endhint %}

### テーマとアクセントカラー

テーマは以下のいずれかを選択できます：

- ライト
- ダーク
- システムに合わせる

アクセントカラーは、ボタン、選択状態、一部の強調要素に使用されます。カスタム CSS でもテーマ変数を変更している場合、CSS の指定がアクセントカラー設定を上書きすることがあります。

### 透明ウィンドウ

macOS では透明ウィンドウのトグルが表示されます。これはシステムのマテリアルとウィンドウの背景エフェクトを制御します。他のプラットフォームではこの項目は表示されません。

透明なエフェクトにより文字のコントラストが低くなったり、ウィンドウがちらついたり、スクリーンショットが鮮明でない場合は、不透明なウィンドウに戻すことができます。

### システムタイトルバーの使用

Linux ではシステムタイトルバーのトグルが表示されます。変更後、アプリケーションは確認を求め、再起動します。

システムタイトルバーは一部のデスクトップ環境やウィンドウマネージャーとの互換性に役立ちますが、外観は Cherry Studio に標準搭載されているタイトルバーとは異なります。

### インターフェースのズーム

`10%` 単位で拡大または縮小でき、デフォルトのズームにも戻せます。

ズームは設定ウィンドウ全体とメイン画面の表示サイズに影響します。スクリーンショットの撮影時やレイアウト問題の調査時には、ズーム率も記録してください。`100%` 以外では、同じウィンドウサイズでも表示範囲が変わる場合があります。

### グローバルフォントとコードフォント

システムフォントからそれぞれ選択できます：

- グローバルインターフェースフォント；
- コードブロックおよびエディタフォント。

選択肢は現在の OS にインストールされているフォントから取得されます。別のデバイスに同じフォントがない場合、インターフェースはデフォルトフォントにフォールバックします。

外観について詳しくは、[表示設定](display.md)と[フォント設定](../../../personalization-settings/font.md)を参照してください。

### トピックリスト

トピックリストは以下の機能に対応しています：

- 左側または右側に表示；
- トピックの時刻を表示；
- 固定したトピックを先頭に表示。

トピックリストが左側にある場合、**アシスタントをクリックした後に自動的にトピックリストに切り替える**を有効にすることもできます。リストが右側にある場合、このスイッチは表示されません。

## システムと起動

### ログイン時に自動起動

有効にすると、Cherry Studio はシステムログイン時に起動を試みます。

機能しない場合は、以下を確認してください：

- システムがログイン項目または自動起動アプリケーションを許可しているか；
- セキュリティソフトウェアがブロックしていないか；
- アプリケーションが移動または再インストールされていないか；
- 現在のユーザーにログイン項目の変更権限があるか。

### 起動時にトレイへ最小化

有効にすると、アプリは起動時にメインウィンドウを直接表示しません。

この設定はトレイ機能に依存します。これをオンにすると、Cherry Studio は自動的に**トレイアイコンを表示**をオンにします。

### トレイアイコンを表示

トレイメニューからは、メインウィンドウの表示、クイックアシスタントの起動、またはアプリの終了が可能です。トレイアイコンを非表示にした場合：

- **起動時にトレイへ最小化**も同時にオフになります；
- **ウィンドウを閉じたときにトレイへ最小化**も同時にオフになります。

これにより、ウィンドウを非表示にした後で再表示する手段がなくなる事態を防ぎます。

### ウィンドウを閉じたときにトレイへ最小化

有効にすると、ウィンドウの閉じるボタンをクリックしてもメインウィンドウは隠れるだけで、Cherry Studio プロセスはバックグラウンドで実行され続けます。

完全に終了するには、トレイメニューから終了コマンドを使用する必要があります。このスイッチをオフにした場合、ウィンドウを閉じる動作はシステムおよびアプリケーションの終了ロジックに従って実行されます。

{% hint style="warning" %}
バックグラウンドでは、実行中のタスク、チャンネル、定期タスクが動作を続ける場合があります。すべての処理を停止する必要があるときは、ウィンドウを閉じるだけでなく、アプリが完全に終了したことを確認してください。
{% endhint %}

## プロキシ設定

プロキシモードには以下が含まれます。

| モード | 動作 |
| --- | --- |
| システムプロキシ | オペレーティングシステムの現在のプロキシ設定を使用します |
| カスタムプロキシ | Cherry Studio に入力したプロキシアドレスとバイパスルールを使用します |
| プロキシ不使用 | Cherry Studio からプロキシを使用しません |

### カスタムプロキシアドレス

有効な HTTP、HTTPS、または SOCKS プロキシ URL を入力できます。例：

```text
socks5://127.0.0.1:6153
```

実際のプロトコルとポートは、ローカルのプロキシプログラムと一致する必要があります。プロキシに認証が必要な場合は、プロキシプログラムがサポートする URL 形式で設定し、スクリーンショットやフィードバックでユーザー名とパスワードを公開しないようにしてください。

無効なアドレスを入力した場合、Cherry Studio は保存を拒否します。

### プロキシバイパスルール

バイパスルールは、特定のアドレスへの直接接続を可能にし、カスタムプロキシを経由させません。適しているのは以下のような場合です：

- `localhost` および `127.0.0.1`；
- ローカルネットワーク上のモデルサービス；
- ローカルの SearXNG、Ollama、または LM Studio；
- プロキシ経由にすべきでない企業内ネットワークのドメイン。

ルール形式については、設定項目のヒントを参照してください。誤ったバイパスルールは、ローカルサービスがプロキシを経由してしまう、または外部サービスがプロキシを迂回した後に接続に失敗する原因となる可能性があります。

### プロキシのトラブルシューティング

モデルサービスのタイムアウトが発生した場合、単にプロキシモードを切り替えるだけでは不十分です。以下の項目を順に確認してください：

1. ブラウザまたはターミナルからサービスプロバイダーへアクセスできるか；
2. プロキシプログラムが設定されたポートでリッスンしているか；
3. Cherry Studio のプロキシモードとアドレスが正しいか；
4. ターゲットドメインがバイパスルールによって誤ってマッチしていないか；
5. ローカルサービスが直結すべきかどうか；
6. プロキシを変更した後、ウィンドウを再開するかアプリケーションを再起動する必要があるか。

## ハードウェアアクセラレーションを無効化

デフォルトでは、Electron はハードウェアアクセラレーションを使用してインターフェースをレンダリングします。**ハードウェアアクセラレーションを無効化**することは、以下の問題が発生した場合にのみ推奨されます。

- 黒画面または白画面；
- ウィンドウのちらつき；
- フォントや画像のレンダリング異常；
- 特定のグラフィックカードドライバーによるクラッシュ。

変更時に確認ダイアログが表示され、同意するとアプリが再起動します。

ハードウェアアクセラレーションを無効化すると、スクロール、アニメーション、複雑なインターフェースのスムーズさが低下する可能性があります。これはすべてのパフォーマンス問題に対する万能な解決策ではありません。

## スペルチェック

有効にすると、入力フィールドは Electron のスペルチェック機能を使用して、スペルミスと思われる単語に印を付けます。

Windows および Linux では、英語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語、オランダ語、ポーランド語、スロバキア語、ギリシャ語などを含む、チェックしたい言語を選択することもできます。

macOS はシステム提供のスペルチェック機能を使用するため、同じ言語選択欄は表示されません。

スペルチェックはローカル入力候補にのみ影響し、モデルによる文章の修正を呼び出したり、すでに送信されたメッセージを変更したりすることはありません。

## 通知

個別に制御できます：

| 通知 | トリガーされるシナリオ |
| --- | --- |
| アシスタントメッセージ | アシスタントの回答完了などのメッセージイベント |
| バックアップ | バックアップ処理の完了、または結果の生成時 |
| 知識ベース | 知識ベースへの埋め込みやインデックス作成タスクの完了時 |

アプリケーション内のスイッチがオンになっていても、オペレーティングシステムによって通知がブロックされる場合があります。システムの通知設定で Cherry Studio の許可を行い、集中モードやおやすみモードを確認してください。

通知はタスクから結果が返ったことを示すだけで、処理の成功を保証するものではありません。バックアップと知識ベースのタスクでは、最終ステータスとエラーメッセージも確認してください。

## 匿名エラーレポートと使用統計

**匿名のエラー報告と使用統計を送信**で、アプリのデータ収集を有効または無効にできます。

オンにするかどうかはユーザーが決定します。収集範囲、保持方法、サードパーティによる処理ルールを理解するには、現在のバージョンで表示されているプライバシーに関する説明およびプロジェクトの正式なプライバシーポリシーを確認してください。スイッチの名前だけですべてのデータカテゴリを推測しないでください。

このスイッチをオフにしても、ユーザーが能動的にフィードバックを送信することは阻止されず、また、設定されたモデルサービス、ネットワーク検索、MCP、または外部統合が機能要件に基づいてデータを送信することも阻止されません。

## 開発者モード

開発者モードは、デバッグや開発向けの機能を有効にします。

一般ユーザーはオフのままにしておくことができます。問題の調査が必要な場合のみ、開発者または保守担当者の指示に従って一時的にオンにし、完了したら必ずオフにしてください。

開発者モードは接続の問題を自動的に修正したり、モデルに追加の能力を与えたりすることはありません。デバッグインターフェースやログには、会話の内容、パス、リクエストパラメータ、サービス情報などが含まれる場合があるため、共有する前には必ず匿名化を行ってください。

## カスタム CSS

一般設定に内蔵された CSS エディターで、アプリのスタイルを直接上書きできます。

調整に適している項目：

- フォントサイズと間隔；
- 色と角の丸み；
- 特定コンポーネントの表示方法；
- コミュニティテーマ。

記述、復元、クリアの方法については、[カスタム CSS](../../../personalization-settings/css.md)と[CSS 設定のクリア](../../../personalization-settings/clear-css.md)を参照してください。

{% hint style="danger" %}
誤った CSS は、ボタンを隠したり、文字を見えなくしたり、レイアウトを崩したりする可能性があります。サードパーティ製テーマを貼り付ける前にコードを読み、既存の CSS をバックアップしてください。設定画面を操作できなくなった場合は、「CSS 設定のクリア」の手順で復元できます。
{% endhint %}

Cherry Studio のアップデート後は内部クラス名や構造が変わる場合があり、古い CSS の長期的な互換性は保証されません。

## 推奨確認順序

### 新規ユーザー向け

1. インターフェース言語を選択します。
2. ライト、ダーク、またはシステムに合わせるを選択します。
3. `100%` のズームを維持します。
4. 必要に応じて「ログイン時に自動起動」とトレイ関連機能をオンにします。
5. まずシステムプロキシを使用し、明示的に必要になった場合のみカスタムプロキシに変更します。
6. ハードウェアアクセラレーションは有効のままにします。
7. 必要に応じて通知をオンにします。

### ネットワークの問題が発生した場合

1. プロバイダーの Key とアドレスを確認します。
2. システムまたはカスタムプロキシを確認します。
3. バイパスルールを確認します。
4. 同じネットワークを使用して、プロバイダーの公式アドレスでテストします。
5. アプリケーションを再起動してから再テストします。

### 表示の問題が発生した場合

1. `100%` のズームに戻します。
2. デフォルトテーマとデフォルトフォントに切り替えます。
3. 一時的にカスタム CSS をクリアします。
4. 透明ウィンドウをオフにします。
5. 最後に、ハードウェアアクセラレーションを無効化して再起動を試みます。

## よくある質問

### ドキュメントは5つの言語しかないのに、アプリ内ではもっと多いのはなぜですか？

アプリとコミュニティドキュメントでは、対応言語が異なります。現在、アプリは 12 種類のインターフェース言語に対応し、コミュニティドキュメントは 5 言語でメンテナンスされています。

### カスタムプロキシを設定しても接続できない場合

URLにプロトコル（例: `http://` や `socks5://`）が含まれているか、ポートが正しいか、プロキシプログラムが実行中であるかを確認し、ターゲットドメインがバイパスされていないかも確認してください。

### ウィンドウを閉じた後もアプリが動作している場合

**ウィンドウを閉じたときにトレイへ最小化**の設定を確認してください。この設定がオンの場合、閉じるボタンを押してもアプリは終了しませんので、トレイメニューから終了してください。

### トレイ関連のスイッチが自動で変化する場合

これらは依存関係によるものです：

- 「起動時にトレイへ最小化」または「ウィンドウを閉じたときにトレイへ最小化」をオンにすると、トレイ機能が自動的に有効になります。
- トレイ機能をオフにすると、上記2つの依存設定も同時にオフになります。

### システムタイトルバーやハードウェアアクセラレーションを変更した後にアプリが再起動する場合

これは正常な動作です。これら2つの項目はアプリの起動段階で適用される必要があるため、変更後は Cherry Studio が再起動します。

### フォントリストに特定のフォントがない場合

このリストは現在システムにインストールされているフォントに基づいています。まずOS側でフォントをインストールしてから、Cherry Studio を再起動してください。他のデバイスから設定を同期しても、フォントファイルは同期されません。

### 通知スイッチがオンなのに通知が来ない場合

システムの通知権限やおやすみモードを確認し、タスクが本当に完了したか確認してください。Linuxのデスクトップ環境では、利用可能な通知サービスが必要な場合があります。

***

### ヘルプの取得とフィードバックの送信

一般設定で問題が発生した場合は、[フィードバックと提案](../../../question-contact/suggestions.md)に記載された公式窓口から報告してください。Cherry Studio のバージョン、OS、関連するスイッチ、プロキシモードまたは表示設定を添え、ログやスクリーンショットに含まれる認証情報、ドメイン、個人用パスは伏せてください。
