# 音声機能

{% hint style="warning" %}
現在の Cherry Studio V2 コミュニティ版には、音声入力、テキスト読み上げ、リアルタイム音声通話の内蔵機能はありません。旧版ドキュメントに掲載されていた TTS、ASR、音声通話の設定は、現在の `main` バージョンには含まれていません。旧版の手順に従って設定しないでください。
{% endhint %}

## 現在の状況

現在の設定画面に **音声機能** の項目はなく、チャット入力欄にも録音や音声通話の内蔵ボタンはありません。

現在、以下の機能は Cherry Studio V2 コミュニティ版では利用できません。

- AI の応答を音声で自動的に読み上げる（TTS）
- マイクで話した内容を入力テキストに変換する（ASR / STT）
- フローティングウィンドウでリアルタイム音声会話を行う
- 音声プロバイダー、音声の種類、読み上げ速度、音声認識モデルを設定する
- プッシュトゥトーク専用のショートカットを設定する

したがって、これらの機能のために OpenAI、SiliconFlow、その他の音声サービスの API キーを入力する必要はなく、**設定** にも対応する項目はありません。

## 音声ファイルの添付は音声入力とは異なります

Cherry Studio は一般的な音声ファイル形式を認識し、対応する場面ではファイルを添付として処理できます。ただし、音声の内容を理解できるかどうかは、選択したモデル、プロバイダーのプロトコル、モデルの機能によって決まります。

音声ファイルのアップロードと、アプリ内の音声機能は本質的に異なります。

| 場面 | 現在の状況 |
| --- | --- |
| 既存の音声ファイルをアップロードし、音声入力対応モデルで処理する | モデルとプロバイダーによって異なる |
| マイクで直接録音し、入力欄に文字起こしする | 現在は非対応 |
| モデルの応答を自動的に読み上げる | 現在は非対応 |
| モデルと連続して音声通話を行う | 現在は非対応 |

モデルセレクターまたはプロバイダーに音声入力対応の明記がない場合は、音声ファイルを処理できると判断しないでください。

## 利用できる代替方法

音声入力が必要な場合は、OS の音声入力機能や他の文字起こしツールで音声をテキストに変換し、Cherry Studio に貼り付けてください。利用可否、ショートカット、プライバシーポリシーは、OS または使用するツールによって異なります。

応答を読み上げたい場合は、OS のアクセシビリティ機能または外部のテキスト読み上げツールを利用できます。Cherry Studio は、それらのツールの音声、読み上げ速度、音声データの保存、ネットワークリクエストを管理しません。

{% hint style="info" %}
サードパーティの音声入力、文字起こし、読み上げサービスを利用する前に、データの取り扱いとプライバシーポリシーを確認してください。信頼できないサービスに機密性の高い会話を送信しないでください。
{% endhint %}

## 将来のバージョンでの対応を確認する方法

音声関連機能がコミュニティ版に再び追加された場合は、利用可能な画面上の入口と正式なリリースノートの両方が提示されます。現在のバージョンの **設定** 画面と [GitHub Releases](https://github.com/CherryHQ/cherry-studio/releases) を確認し、古いスクリーンショットや過去の PR だけで判断しないでください。

現在インストールしているバージョンに、このページで説明していない音声機能の項目がある場合は、バージョン番号と入手元を確認したうえで、[フィードバックと提案](../../../question-contact/suggestions.md)から画面のスクリーンショットと再現情報を送信してください。
