# テキスト選択ツール

テキスト選択ツールは、他のアプリでテキストを選択するとフローティングツールバーを表示します。選択した内容を直接翻訳、説明、要約、検索、コピーでき、独自の AI 操作も追加できます。

{% hint style="info" %}
テキスト選択ツールと[クイックアシスタント](kuai-jie-zhu-shou.md)は別の機能です。テキスト選択ツールは直前に選択したテキストを処理します。クイックアシスタントはショートカットまたはトレイから、能動的に入力するウィンドウを開きます。
{% endhint %}

## 対応プラットフォーム

| プラットフォーム | 現在の説明 |
| --- | --- |
| macOS | 対応。初めて有効にする際はアクセシビリティー権限が必要です |
| Windows | 選択時、Ctrl キー、ショートカットキーによる起動に対応しています |
| Linux X11 | 主な機能に対応。キー入力の監視には `input` グループの権限が必要な場合があります |
| Linux Wayland | デスクトップ環境の制限を受けます。ツールバーが中央にしか表示されない場合や、アプリの絞り込みが機能しない場合があります |

Wayland 環境では、設定ページで XWayland、`input` グループの権限、デスクトップコンポジターとの互換性を確認します。現在の環境に互換性がない場合は、X11 の使用をおすすめします。

## テキスト選択ツールを有効にする

1. **設定 → テキスト選択ツール**を開きます。
2. **テキスト選択ツールを有効にする**をオンにします。
3. テキストの取得方法を選択します。

無効な場合、設定ページにはデモ用のツールバーが表示されます。先にコンパクトモードと操作の配置を確認できます。

### macOS のアクセシビリティー権限

macOS で初めて有効にする場合は、次の操作を行います。

1. 権限の案内でシステム設定へ移動します。
2. **プライバシーとセキュリティ → アクセシビリティ**を開きます。
3. Cherry Studio の権限をオンにします。
4. Cherry Studio に戻り、テキスト選択ツールをもう一度有効にします。

権限を無効にすると、Cherry Studio はテキスト選択ツールを自動的にオフにします。

### Linux の権限に関する案内

設定ページで `input` グループの権限がないと表示された場合は、次のコマンドを実行できます。

```bash
sudo usermod -aG input $USER
```

実行後は、現在のシステムセッションからログアウトして再度ログインする必要があります。Wayland では XWayland モードでの起動も必要になる場合があります。設定ページに表示される環境チェックの結果に従ってください。

## テキストの取得方法を選択する

| 方法 | プラットフォーム | 動作 |
| --- | --- | --- |
| 選択時 | macOS、Windows、Linux | テキストを選択するとすぐにツールバーを表示します |
| Ctrl キー | Windows | テキストを選択した後、Ctrl を長押しした場合にだけツールバーを表示します |
| ショートカットキー | macOS、Windows | テキストを選択した後、設定済みの選択用ショートカットを押すと表示します |

ショートカット方式では、**設定 → ショートカット**を開き、「テキスト選択ツール：テキストを選択」のキーの組み合わせを設定して有効にする必要があります。現在、プリセットのキーはありません。

直接選択したときに頻繁に誤作動する場合は、Ctrl キーまたはショートカット方式へ変更できます。

## ツールバーを使用する

1. 対応するアプリでテキストを選択します。
2. ツールバーが表示されるまで待つか、選択した起動キーを押します。
3. 必要な操作をクリックします。

ツールバー左側の Cherry Studio アイコンはドラッグ領域で、ツールバー全体を移動できます。**コンパクトモード**を有効にすると、ツールバーにはアイコンだけが表示されます。アイコンにポインターを合わせると、引き続き名前を確認できます。

## 組み込み操作

テキスト選択ツールには 7 つの組み込み操作があります。

| 操作 | デフォルトの状態 | 動作 |
| --- | --- | --- |
| 翻訳 | 有効 | 原文の言語を検出し、優先言語と予備言語のどちらかを目標言語に選択します |
| 解説 | 有効 | モデルを使って選択内容を説明します |
| 要約 | 有効 | モデルを使って選択内容を要約します |
| 検索 | 有効 | 設定済みの検索エンジンでクエリを開きます |
| コピー | 有効 | 選択内容をクリップボードへ書き込みます |
| 最適化 | 無効 | モデルを使って選択内容を整えます |
| 引用 | 無効 | 選択内容を Cherry Studio メインウィンドウの入力ボックスへ引用します |

翻訳では設定済みの翻訳モデルを使用します。解説、要約、最適化、およびアシスタントを指定していないカスタム AI 操作では、デフォルトモデルを使用します。

{% hint style="warning" %}
テキスト選択ツールの AI 結果ウィンドウでは、ウェブ検索、MCP、ナレッジベースが無効になります。これらのツールが必要な場合は、内容をメインウィンドウへ引用してから処理を続けてください。
{% endhint %}

## 操作と順序を調整する

**設定 → テキスト選択ツール → 機能**では、上の一覧に有効な操作、下の一覧に無効な操作が表示されます。

次の操作を行えます。

* 操作をドラッグしてツールバーの順序を変更する
* 操作を上の一覧へドラッグして有効にする
* 操作を下の一覧へドラッグして無効にする
* 組み込み操作のデフォルトの順序と状態にリセットする

ツールバーで同時に有効にできる操作は最大 8 個で、少なくとも 1 個の操作を有効な状態にしておく必要があります。リセットしてもカスタム操作は削除されませんが、無効な操作の領域へ移動します。

組み込み操作のプロンプトはここでは変更できません。「検索」では検索エンジンを個別に変更できます。

## カスタム操作を追加する

カスタム操作は最大 10 個作成できます。

1. 機能設定でカスタム機能の追加をクリックします。
2. 操作名を入力します。
3. Lucide アイコンを選択するか、ランダムに生成します。
4. デフォルトモデルを使用するか、アシスタントを選択します。
5. プロンプトを入力します。
6. 保存後、新しい操作を有効な操作の領域へドラッグします。

プロンプトでは、選択したテキストを `{{text}}` で表せます。プレースホルダーを入力しなかった場合、選択したテキストがプロンプトの末尾へ自動的に追加されます。

「アシスタントを使用」を選択すると、そのアシスタントのシステムプロンプト、モデル、モデルパラメーターも使用されます。

## 検索エンジンを設定する

1. 機能一覧で**検索**を見つけます。
2. 右側の設定ボタンをクリックします。
3. Google、Baidu、Bing のいずれかを選択するか、カスタム検索エンジンを追加します。

カスタム URL は次の条件を満たす必要があります。

* `http://` または `https://` で始まる
* `{{queryString}}` プレースホルダーを含む

検索を実行すると、Cherry Studio は選択したテキストを URL エンコードしてプレースホルダーを置き換えます。選択内容そのものが URL またはローカルの絶対パスである場合は、その内容を直接開こうとします。

## 結果ウィンドウを使用する

翻訳、解説、要約、最適化、カスタム AI 操作では、独立した結果ウィンドウが開きます。

ウィンドウでは次の操作を行えます。

* 原文を表示または非表示にする
* 原文またはモデルの結果をコピーする
* 生成を一時停止する
* 再生成する
* 最小化または閉じる
* 最前面に固定する
* 一時的に透明度を調整する

翻訳ウィンドウでは、目標言語を直接切り替え、優先言語と予備言語を設定することもできます。

## ウィンドウの動作を調整する

**機能ウィンドウ**設定では、次の項目を調整できます。

| 設定 | 役割 |
| --- | --- |
| ツールバーに追従 | ツールバーの近くに結果ウィンドウを開きます。無効にすると中央に表示します |
| サイズを記憶 | 今回のアプリ実行中は、最後に調整したウィンドウサイズを使用します |
| 自動閉じる | 最前面に固定していない結果ウィンドウがフォーカスを失うと閉じます |
| 自動で最前面に固定 | 結果ウィンドウを開くたびに、デフォルトで最前面に固定します |
| 透明度 | 結果ウィンドウのデフォルトの不透明度を 20%～100% の範囲で設定します |

結果ウィンドウで手動調整した透明度は、現在のウィンドウだけに影響します。設定ページの透明度は、今後開くウィンドウに適用されます。

## アプリの絞り込みを設定する

アプリの絞り込みを使用すると、テキスト選択ツールを指定したアプリだけで有効にしたり、指定したアプリを除外したりできます。

1. **設定 → テキスト選択ツール → 詳細設定**を開きます。
2. ホワイトリストまたはブラックリストを選択します。
3. 編集をクリックし、1 行につき 1 つのアプリ識別子を入力します。

| プラットフォーム | 入力内容 | 例 |
| --- | --- | --- |
| macOS | Bundle ID。部分一致が可能です | `com.google.Chrome` |
| Windows | 実行ファイル名。部分一致が可能です | `chrome.exe` |

入力内容はすべて小文字に変換され、重複が削除されます。Wayland モードではアプリの絞り込みが機能しない場合があります。

## よくある質問

### テキストを選択してもツールバーが表示されない

機能が有効で取得方法が正しいことを確認し、現在のアプリが絞り込みルールによって除外されていないか確認してください。macOS ではアクセシビリティー権限も確認します。

### Windows で Ctrl キー方式が機能しない

一部のアプリやキーマッピングツールは Ctrl を遮断します。選択時またはショートカット方式へ変更し、AHK などのツールがキーを再割り当てしていないか確認してください。

### Linux でツールバーの位置が正しくない

通常は Wayland と XWayland の座標の違いが原因です。設定ページの環境チェックを確認し、条件を満たせない場合は X11 へ切り替えてください。

### AI 操作の結果が表示されない

デフォルトモデルまたは対象のアシスタントが利用可能か確認してください。翻訳操作には、別途設定した翻訳モデルも必要です。

### 引用してもテキストが表示されない

「引用」は選択内容を Cherry Studio メインウィンドウの入力ボックスへ送ります。メインウィンドウが開いていることを確認し、チャットページへ切り替えて確認してください。

## プライバシーに関する注意

コピー操作はシステムのクリップボードへ書き込むだけです。検索操作は選択した検索エンジンへクエリを送信します。引用操作はテキストを Cherry Studio メインウィンドウへ渡します。

選択したテキストが対応するモデルサービスへ送信されるのは、翻訳、解説、要約、最適化、カスタム AI 操作を実行した場合だけです。機密テキストを処理する前に、操作の種類とプロバイダーのデータポリシーを確認してください。
