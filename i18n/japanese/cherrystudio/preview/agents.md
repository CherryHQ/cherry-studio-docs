# アシスタントライブラリ

アシスタントライブラリは、Cherry Studio の対話アシスタント用プリセットマーケットです。プリセットには主に名前、アイコン、プロンプト、一部のデフォルト設定が保存されています。プリセットを会話へ追加すると、個別に編集できるアシスタントになります。

{% hint style="warning" %}
アシスタントライブラリの「アシスタント」は役割に基づく対話用であり、[Cherry Agent エージェント](../../advanced-basic/agent.md)とは異なります。ワークスペースへのアクセス、ファイルの読み書き、コマンドの実行、ツールの連続呼び出しが必要な場合は、エージェントを使用してください。
{% endhint %}

## アシスタントライブラリ、対話アシスタント、リソースライブラリ

| 名前 | 用途 |
| --- | --- |
| アシスタントライブラリ | 組み込みプリセットの閲覧、自分のプリセットの管理、プリセットソースのインポートや購読 |
| 対話アシスタント | [会話ページ](chat.md)に追加済みで利用できるアシスタント。独自のトピックと設定を持つ |
| [リソースライブラリ](library.md) | モデル、アシスタント、エージェントなどのリソースをまとめて作成、編集する。詳細な設定に適している |

アシスタントライブラリからプリセットを追加すると、Cherry Studio は新しい対話アシスタントとしてコピーします。その後、元のプリセットを変更または削除しても、作成済みのアシスタントは自動的に変更されません。

## アシスタントライブラリを開く

次の入口から開けます。

* **ランチパッド → アシスタントライブラリ**。
* 会話ページのアシスタント一覧にある追加ボタン。

アシスタントをすばやく追加するだけなら、会話ページの追加画面でプリセットを検索するほうが簡単です。カテゴリの閲覧、インポート、購読、一括管理を行う場合は、完全なアシスタントライブラリを開いてください。

## プリセットを閲覧、検索する

アシスタントライブラリの左側では、「マイ」と用途別カテゴリに分けてプリセットが表示され、メイン領域には現在のカテゴリのカードが表示されます。

* **カテゴリ**：現在の組み込みプリセットまたは購読ソースが提供するカテゴリを表示します。
* **検索**：名前と説明を使って、すべてのカテゴリから検索します。
* **カードのプレビュー**：名前、説明、プロンプトの要約を確認します。
* **マイ**：自分で作成またはインポートしたプリセットを表示します。

カテゴリと件数は、アプリのバージョン、現在の言語、購読ソースによって変わるため、このページでは固定の一覧を記載しません。

## プリセットから対話アシスタントを作成する

1. 使用するプリセットを探します。
2. カードをクリックし、プロンプトと説明を確認します。
3. **アシスタントに追加**を選択します。
4. [会話ページ](chat.md)へ戻ります。
5. アシスタント一覧から追加したアシスタントを選択し、上部でモデルを選びます。

追加後のアシスタントには、独自の ID とデフォルトトピックが作成されます。アシスタントライブラリ内の元のプリセットに影響を与えることなく、プロンプト、モデル、ナレッジベース、MCP、モデルパラメータを変更できます。

## 自分のアシスタントを作成する

目的に応じて、次の 2 つの方法があります。

### アシスタントライブラリで軽量プリセットを作成する

**アシスタントを作成**をクリックし、次の項目を入力します。

* **名前**：検索と識別に使用します。
* **Emoji**：アシスタントのアイコン。選択しない場合は、名前から抽出を試みます。
* **プロンプト**：役割、目標、境界、出力方法を定義します。
* **ナレッジベース**：任意。作成済みのナレッジベースを関連付けます。

名前とプロンプトは必須です。プロンプト編集領域では、デフォルトのアシスタントモデルを使って最適化でき、今回の AI による書き換えを元に戻すこともできます。

保存すると、プリセットが「マイ」に表示されます。会話で使用するには、そのプリセットをクリックし、さらに**アシスタントに追加**を選択してください。

### リソースライブラリで完全なアシスタントを作成する

モデル、タグ、高度なパラメータをまとめて設定する場合は、[リソースライブラリ](library.md)でアシスタントを作成することをおすすめします。完全なエディターには、次の項目があります。

* 名前、Emoji、説明、タグ、モデル。
* システムプロンプト。
* Temperature、Top P、最大出力、コンテキスト数、ストリーミング出力。
* ツール呼び出しモード、最大ツール呼び出し回数、カスタムパラメータ。
* ナレッジベース。
* MCP モードと Server。

完全なエディターでも、名前とプロンプトは必須です。明確な必要性がなければ、モデルパラメータはデフォルト値のままにしてください。

## モデルの決まり方

アシスタントライブラリから軽量プリセットを作成またはインポートすると、Cherry Studio は現在の[デフォルトアシスタントモデル](settings/default-models.md)をプリセットのデフォルトモデルとして使用します。会話へ追加した後は、会話ページ上部でモデルを切り替えられます。

リソースライブラリで完全なアシスタントを作成する場合は、保存前にモデルを直接選択できます。

モデル設定をシステムプロンプトに記載しないでください。モデルを変更するときはモデル選択欄を使用すると、プロバイダーと実際のモデル ID を確認しやすくなります。

## アシスタントプリセットをインポートする

**インポート**をクリックし、次のいずれかの方法を選択します。

### URL からインポートする

1. **URL**を選択します。
2. JSON を直接返す URL を貼り付けます。
3. インポートをクリックします。

### ファイルからインポートする

1. **ファイル**を選択します。
2. `.json` ファイルを選択します。
3. インポートをクリックします。

インポートする内容には、1 つのオブジェクトまたはオブジェクトの配列を使用できます。各プリセットには、少なくとも `name` と `prompt` が必要です。

```json
[
  {
    "name": "ドキュメントレビューアシスタント",
    "emoji": "📝",
    "description": "構成、用語、実行可能性を確認する",
    "prompt": "製品ドキュメントをレビューし、具体的な修正案を提示してください。"
  }
]
```

インポート時に各プリセットへ新しいローカル ID が生成され、現在のデフォルトアシスタントモデルが使用されます。元ファイル内の古いトピックやメッセージが会話履歴としてインポートされることはありません。

{% hint style="warning" %}
信頼できる提供元からだけインポートしてください。プリセットのプロンプトには、隠れた目的、外部リンク、自分の用途に適さない動作要件が含まれている場合があります。会話へ追加する前に、プロンプトを確認してください。
{% endhint %}

## アシスタントソースを購読する

購読は、チームやコミュニティがリモートのプリセット集を管理する場合に適しています。

1. **インポート**をクリックします。
2. 購読領域に、JSON 配列を直接返す HTTP(S) アドレスを入力します。
3. **購読**をクリックします。
4. Cherry Studio を再読み込みすると、そのアドレスからシステムプリセットが読み込まれます。

購読ソースを利用できる場合、そのソースがシステムプリセットの提供元になります。リモートからの読み込みに失敗すると、Cherry Studio はアプリ内の組み込みプリセットへ戻ります。購読を解除すると、組み込みプリセットが再び使用されます。

購読と 1 回限りのインポートの違い：

| | 1 回限りのインポート | 購読 |
| --- | --- | --- |
| データの場所 | ローカルの「マイ」プリセットとしてインポートされる | 起動または再読み込み時にリモートソースから読み取る |
| その後の更新 | 自動では変わらない | リモートソースの更新後、再読み込み時に更新できる |
| ローカルでの変更に適しているか | 適している | 購読ソースでの一元管理を推奨 |

詳しい形式と管理方法は、[アシスタント購読](../../data-settings/assistants-subscribe.md)を参照してください。

## 「マイ」プリセットを管理する

「マイ」カテゴリでは、カードメニューまたは**アシスタントを管理**から次の操作を行えます。

* プリセットを編集する。
* 対話アシスタントとして追加する。
* 1 つのプリセットを JSON としてエクスポートする。
* プリセットを削除する。
* ドラッグして順序を変更する。
* 複数選択して、エクスポートまたは削除する。

一括エクスポートした JSON は、別のデバイスへ再度インポートできます。プリセットを削除する前に、新しいアシスタントの作成にまだ必要かを確認してください。会話へ追加済みのアシスタントは、プリセットと一緒に削除されません。

## 追加済みのアシスタントを変更する

会話へ追加したプリセットは、対話アシスタントの設定またはリソースライブラリで変更します。主な設定：

* システムプロンプト。
* 現在のモデルとデフォルトモデル。
* ナレッジベースと Web 検索。
* MCP ツール。
* コンテキストと出力パラメータ。

会話の詳しい操作については、[会話インターフェース](chat.md)を参照してください。

## アシスタントとエージェントの選び方

| 目的 | 推奨 |
| --- | --- |
| 固定された役割での質疑応答、執筆、翻訳、分析 | 対話アシスタント |
| プロンプトテンプレートの再利用と共有 | アシスタントライブラリのプリセット |
| モデル、パラメータ、ナレッジベース、MCP をまとめて編集する | リソースライブラリのアシスタントエディター |
| ワークスペースへのアクセス、ファイルの読み書き、コマンドの実行 | [エージェント](../../advanced-basic/agent.md) |
| スケジュール実行して外部チャンネルへ結果を送る | エージェント + [スケジュールタスク](../../advanced-basic/scheduled-tasks.md) + [チャンネル](../../advanced-basic/agent-channels.md) |

インポートの失敗、購読ソースの読み取りエラー、プリセットの異常が発生した場合は、JSON の例、URL の応答状態、エラー内容を添えて、[フィードバックと提案](../../question-contact/suggestions.md)からお知らせください。送信前に個人情報や秘密情報を削除してください。
