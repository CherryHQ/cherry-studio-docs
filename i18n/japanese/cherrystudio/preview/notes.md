# ノート

ノートは Cherry Studio に組み込まれた Markdown ワークスペースです。各ノートはローカルの `.md` ファイルとして保存され、チャット結果の整理、下書きの作成、他の Markdown ツールでも読み取れる資料の管理に適しています。

{% hint style="info" %}
ノートの内容が自動的にチャットのコンテキストになることはありません。モデルからノートの内容を検索できるようにするには、対象のノートを[ナレッジベース](knowledge-base.md)へエクスポートします。
{% endhint %}

## ノートを開く

1. ウィンドウ上部のタブバー右側にある **+** をクリックし、新しいランチパッドのタブを開きます。
2. ランチパッドで**ノート**をクリックします。

ページ左側にはノートとフォルダー、右側には現在のノートの編集エリアが表示されます。

## 最初のノートを作成する

1. 左側上部の**新規ノート作成**ボタンをクリックします。
2. ページ上部にノートの名前を入力します。
3. 編集エリアに内容を入力します。

内容を変更すると、現在の Markdown ファイルへ自動的に保存されます。ノートを切り替えたりページを離れたりするときも、Cherry Studio はまだ書き込まれていない変更の保存を試みます。

{% hint style="warning" %}
ノートファイルの読み取りに失敗すると、空の内容で元のファイルを上書きしないように、エディターへの書き込みがブロックされます。読み取りまたは保存のエラーが表示された場合は、先に作業ディレクトリとファイルのアクセス権を確認してください。
{% endhint %}

## フォルダーでノートを整理する

左側上部の**新しいフォルダーを作成する**をクリックすると、ルートディレクトリまたは現在選択しているフォルダー内にディレクトリを作成できます。

次の操作も行えます。

* フォルダーを展開または折りたたむ
* ノートまたはフォルダーを別のフォルダーへドラッグする
* フォルダーを右クリックし、子ノートまたは子フォルダーを作成する
* ページ上部のタイトルを直接編集し、現在のノートの名前を変更する
* ディレクトリツリーでノートまたはフォルダーを右クリックして名前を変更する

ノートワークスペースは Markdown ファイルだけを読み込みます。隠しファイルは表示されません。

## 既存の Markdown をインポートする

次の方法でインポートできます。

* `.md` ファイルを左側のディレクトリツリーへドラッグする
* Markdown ファイルを含むフォルダーを左側のディレクトリツリーへドラッグする
* 左側の空白部分を右クリックし、ファイルまたはフォルダーのアップロードを選択する
* 空のノートワークスペースでインポート案内をクリックし、フォルダーを 1 つ選択する

フォルダーをインポートする際は、元のディレクトリ構造が可能な限り維持されます。その他の形式はスキップされ、インポート完了後に成功、スキップ、失敗した件数が表示されます。

## 編集と閲覧

エディター下部で 3 つのモードを切り替えられます。

| モード | 適した用途 |
| --- | --- |
| ライブプレビュー | ツールバーで編集しながら、Markdown のレイアウトを確認する |
| ソースコードモード | Markdown のソースを直接編集する |
| 読み取りモード | レンダリング後の内容だけを読む |

ライブプレビューモードのツールバーには、見出し、太字、斜体、リスト、引用、コード、表など、よく使う書式が用意されています。現在のノートエディターには、画像やインライン数式を挿入するコマンドはありません。

下部には文字数も表示されます。ライブプレビューモードでは、スペルチェックボタンをクリックしてチェックの有効・無効を切り替えられます。

### ページ表示

右上のその他メニューをクリックすると、次の操作を行えます。

* 現在のノートの内容をコピーする
* Word へすばやくエクスポートする
* 本文の幅を制限する
* 目次アウトラインを表示または非表示にする
* デフォルトフォントとセリフフォントを切り替える
* 小、中、大の 3 段階からフォントサイズを選択する
* ノートのすべての設定を開く

すべての設定では、デフォルトビュー、デフォルト編集モード、10～30 px のフォントサイズ、目次アウトラインも設定できます。

## 検索とお気に入り

### 検索

左側上部の検索ボタンをクリックしてキーワードを入力します。検索では次の項目が同時に照合されます。

* ノート名
* ノート本文

本文に一致した場合は、一致の種類と該当行が結果に表示されます。一致した内容をクリックするとノートが開き、対応する位置へ移動します。

### お気に入り

ノートを開いた後、上部の星ボタンをクリックするとお気に入りに追加できます。左側上部のお気に入り入口には、お気に入りに追加したノートだけが表示されます。

### 並べ替え

ディレクトリでは 6 種類の並べ替えを利用できます。

* 名前：A から Z
* 名前：Z から A
* 更新日時：新しい順
* 更新日時：古い順
* 作成日時：新しい順
* 作成日時：古い順

フォルダーは常に同じ階層のノートより前に表示されます。

## 右クリックメニュー

### ノート

ノートを右クリックすると、次の操作を行えます。

* モデルを使い、本文からノート名を生成する
* 名前を変更する
* 外部で開く
* お気に入りに追加、またはお気に入りから削除する
* ナレッジベースへエクスポートする
* 有効になっている形式でエクスポートする
* 削除する

名前の自動生成には、利用可能なモデル設定が必要です。ナレッジベースへエクスポートする前に、少なくとも 1 つのナレッジベースを作成してください。

### フォルダー

フォルダーを右クリックすると、子ノートまたは子フォルダーの作成、名前の変更、外部で開く、削除を行えます。

{% hint style="warning" %}
フォルダーを削除すると、その中のノートも同時に削除されます。削除前に、対象のディレクトリがバックアップ済みであることを確認してください。
{% endhint %}

## ノートをエクスポートする

ノートの右クリックメニューに表示されるエクスポート項目には、次のものがあります。

* 画像としてコピーまたはエクスポート
* Markdown
* Word
* Notion
* Yuque
* Obsidian
* Joplin
* SiYuan

実際に表示される項目は、**設定 → データ設定 → エクスポートメニュー**で制御します。上部のその他メニューにある「Word にエクスポート」は、現在のノート用のショートカットです。

## チャットやナレッジベースと組み合わせる

### チャットからノートへ保存する

チャットメッセージやトピックのエクスポートメニューから、内容をノートの作業ディレクトリへ保存できます。この項目が表示されるかどうかは、エクスポートメニューの設定によって決まります。

### ノートをナレッジベースに追加する

1. 先にナレッジベースを 1 つ作成します。
2. ノートのディレクトリツリーで対象のノートを右クリックします。
3. **ノートをナレッジベースにエクスポートする**を選択します。
4. 対象のナレッジベースを選択して確定します。
5. ナレッジベースのインデックス作成が完了するまで待ち、その後でチャットからそのナレッジベースを選択します。

元のノートとナレッジベース内のコピーは、別々のデータソースです。その後ノートを変更した場合は、再度エクスポートするか、ナレッジベース内の資料を更新する必要があります。

## 作業ディレクトリとバックアップ

右上のその他メニューを開いて**その他のオプション → データ設定**へ進むと、現在のノート作業ディレクトリの確認、別のディレクトリの選択、デフォルトディレクトリへの復元ができます。

{% hint style="warning" %}
作業ディレクトリを切り替えても、Cherry Studio が現在読み取る場所が変わるだけで、元のディレクトリにある Markdown ファイルは自動的に移行されません。切り替える前に、元のディレクトリを手動でコピーまたはバックアップしてください。
{% endhint %}

ノートは通常の Markdown ファイルなので、ファイル同期、バージョン管理、バックアップソフトウェアで保護できます。カスタム作業ディレクトリを使用する場合は、そのディレクトリを個別にバックアップし、Cherry Studio のアプリ設定バックアップだけに依存しないでください。

異なるシステムで復元した後、元のパスが存在しない場合、Cherry Studio はデフォルトのノートディレクトリへ戻ります。この場合、古いノートを新しいディレクトリへ手動でコピーするか、設定で有効なディレクトリを選択し直す必要があります。

## よくある質問

### 新しいノートを作成しても保存されない

作業ディレクトリが存在し、書き込み可能であることを確認してください。現在のファイルを読み取れない場合、Cherry Studio は元の内容を保護するために保存を一時停止します。

### インポート後に一部のファイルが見つからない

ノートワークスペースがインポートするのは `.md` ファイルだけです。スキップされたファイルに `.md` 拡張子が付いているか確認してください。

### 変更したばかりの内容を検索できない

自動保存が完了するまで待ってから検索してください。ファイルが同期ドライブにある場合は、外部の同期処理がファイルを使用したり上書きしたりしていないことも確認します。

### コンピューターを変えるとノートが空になる

ノート本文は設定だけでなく、作業ディレクトリに保存されています。元のディレクトリにある Markdown ファイルを新しいコンピューターへコピーし、ノート設定でそのディレクトリを選択してください。
