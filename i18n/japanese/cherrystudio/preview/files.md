# ファイル

ファイルページでは、チャットの添付ファイル、貼り付けた画像、アプリが生成または保存した一部のファイルなど、Cherry Studio のファイルインデックスに登録されている内容を確認・整理できます。

コンピューター内の汎用ファイルマネージャーではなく、ディスク上のすべてのファイルを自動的に表示する機能もありません。

{% hint style="info" %}
ナレッジベースのデータソースはナレッジベースページで個別に管理されるため、ここに表示されない場合があります。ナレッジベースの資料を更新、再インデックス、削除する場合は、[ナレッジベース](knowledge-base.md)を開いてください。
{% endhint %}

## ファイルページを開く

1. ウィンドウ上部のタブバー右側にある **+** をクリックし、新しいランチパッドのタブを開きます。
2. ランチパッドで**ファイル**をクリックします。

ページ左側には種類の絞り込み、右側には現在のカテゴリーにあるファイルが表示されます。

## ファイルを表示・絞り込む

左側には 4 つのカテゴリーがあります。

| カテゴリー | 表示される内容 |
| --- | --- |
| ドキュメント | ドキュメントとして認識されたファイル |
| 画像 | 画像ファイル |
| テキスト | プレーンテキストまたはテキスト形式のファイル |
| すべてのファイル | ファイルインデックス内のすべての内容 |

ページを開くと、デフォルトで**ドキュメント**カテゴリーが表示されます。カテゴリーを切り替えると、現在の複数選択状態は解除されます。

### 並べ替え

次の項目で並べ替えられます。

* 作成日
* サイズ
* ファイル名

初めて項目をクリックすると降順に並び、同じ項目をもう一度クリックすると昇順に切り替わります。

### ファイル情報

ドキュメント、テキスト、「すべてのファイル」は一覧で表示されます。各項目には、ファイル名、拡張子、作成日、カウント、ファイルサイズが表示されます。

画像カテゴリーはサムネイルのグリッドで表示され、すばやく確認できます。

## 開く／プレビューする

### ドキュメントとテキスト

一覧でファイル名をクリックすると、Cherry Studio はその形式に設定されているシステムのデフォルトアプリを使ってファイルを開きます。

ファイルが移動済み、ディスクへのアクセス権が不足している、または利用可能なデフォルトアプリがシステムにない場合は、ファイルを開けないことがあります。

### 画像

画像のサムネイルをクリックすると画像ビューアーが開きます。ビューアー内では、現在のカテゴリーにある他の画像へ切り替えられます。

## ファイル名を変更する

ドキュメント、テキスト、「すべてのファイル」の一覧で次の操作を行います。

1. 対象のファイルを見つけます。
2. その行の右側にある編集ボタンをクリックします。
3. 新しい名前を入力して確定します。

新しい名前に元の拡張子が含まれていない場合、Cherry Studio が元の拡張子を自動的に維持します。

{% hint style="warning" %}
名前の変更で変わるのは、Cherry Studio が表示・管理するファイル名だけです。ファイルの内容は変更されません。
{% endhint %}

## ファイルを 1 件削除する

### ドキュメントとテキスト

ファイル行の右側にある削除ボタンをクリックし、確認ダイアログで確定します。

### 画像

画像のサムネイルにポインターを合わせ、右上の削除ボタンをクリックして確定します。

削除すると、ファイルとメッセージ内の添付ファイル参照が同時に消去されます。この操作は Cherry Studio では元に戻せません。

画像がペインティング履歴で使用されている場合、Cherry Studio は削除をブロックしてメッセージを表示します。先にペインティングで関連する履歴を処理してください。

## 一括削除

一括操作はドキュメント、テキスト、「すべてのファイル」カテゴリーで使用できます。画像カテゴリーでは複数選択を利用できません。

1. 削除するファイルにチェックを入れるか、右上の**すべて選択**をクリックします。
2. 一括操作メニューを開きます。
3. **一括削除**を選択して確定します。

{% hint style="warning" %}
一括削除でも、該当するファイルへのメッセージ内の添付ファイル参照が削除されます。実行前に、重要なファイルが別途バックアップされていることを確認してください。
{% endhint %}

## ここに表示されるファイル

通常は次の内容が表示されます。

* チャットでアップロードまたは貼り付けられ、アプリのファイルディレクトリに保存された内容
* チャット中に生成され、ファイルインデックスへ登録された画像やその他の結果
* 旧バージョンの Cherry Studio のファイル処理で登録されたローカルファイル

次の内容は表示されない場合があります。

* Cherry Studio に一度も追加していないコンピューター上のファイル
* 外部プロバイダーのサーバーだけに保存されているファイル
* 新しいナレッジベースのデータソースで個別に管理される元の資料
* ファイルインデックスから削除済みの内容

チャットへ新しい添付ファイルを追加するには、[チャット](chat.md)を開き、入力ボックスの添付ボタンを使用するか、ファイルを直接ドラッグしてください。

## 保存場所

ファイルの内容は Cherry Studio のアプリデータディレクトリに保存されます。**設定 → データ設定 → データディレクトリ**から場所の確認または移行を行うことをおすすめします。アプリの実行中に、ディレクトリ内の内部ファイルを手動で移動、名前変更、削除しないでください。

具体的な場所と移行方法については、[ストレージ位置の変更](../../personalization-settings/storage.md)を参照してください。

## よくある質問

### ファイルを削除すると、以前のメッセージから添付ファイルが消えた

これは現在の削除処理の一部です。ファイルを削除すると、対応するメッセージの添付ファイル参照も削除されます。過去の添付ファイルを残す必要がある場合は、ファイルページから元のファイルを削除しないでください。

### ナレッジベースにインポートした資料が見つからない

ナレッジベースは独自のデータソースとインデックス管理処理を使用します。ナレッジベースの詳細ページで資料の確認、再インデックス、削除を行ってください。

### ファイル名をクリックしても反応しない

ファイルがまだ存在することを確認し、その拡張子に対応するデフォルトアプリがシステムに設定されているか確認してください。アプリデータディレクトリを手動で移動した場合も、元のパスが無効になることがあります。

### 画像を削除できない

その画像がペインティング履歴で使用されている可能性があります。先にペインティングページを開いて関連する履歴を処理し、ファイルページに戻って画像を削除してください。
