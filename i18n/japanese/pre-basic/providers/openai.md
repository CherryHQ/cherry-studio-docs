# OpenAI

Cherry Studio V2 の組み込み OpenAI テンプレートは、OpenAI 公式 API への接続に使用し、初期状態では **OpenAI Responses** API を使用します。OpenAI API Key を準備すると、アカウントで利用できるモデルを同期してチャットで使用できます。

{% hint style="warning" %}
OpenAI テンプレートは、サードパーティの OpenAI 互換ゲートウェイには使用しません。Base URL が OpenAI の公式アドレスでない場合は、[カスタムプロバイダー](zi-ding-yi-fu-wu-shang.md)を新規作成し、ゲートウェイの要件に従って OpenAI Chat Completions または OpenAI Responses を選択してください。
{% endhint %}

## 始める前の準備

- OpenAI API を利用できるアカウント
- [OpenAI API Keys](https://platform.openai.com/api-keys) で作成した API Key
- API アカウントで利用可能になっているモデルと利用枠
- OpenAI の最新の地域およびアカウント要件を満たすネットワーク環境

ChatGPT のウェブ版やクライアントへのログイン状態は、Cherry Studio に自動的に反映されません。Cherry Studio から OpenAI API を呼び出すには API Key が必要です。

## OpenAI を設定する

1. `設定 → モデルプロバイダー` を開きます。
2. 左側のフィルターを**すべてのプロバイダー**に切り替え、**OpenAI** を選択します。
3. API Key を入力します。
4. 既定の Base URL `https://api.openai.com` を変更せずに使用します。
5. 画面上部にあるプロバイダーのスイッチをオンにします。
6. モデルリストで**追加**をクリックし、同期プレビューを確認して変更を適用します。
7. 使用するモデルを有効にします。

{% hint style="danger" %}
API Key の全体が表示されるのは作成時だけです。チャットメッセージ、ドキュメント、コードリポジトリ、または問題報告用のスクリーンショットに Key を含めないでください。漏えいした場合は、OpenAI のコンソールですぐに無効化して作り直してください。
{% endhint %}

## Responses が初期設定になっている理由

V2 の OpenAI テンプレートには `openai-responses` エンドポイントが設定されています。このテンプレートは現在の OpenAI 公式 API 向けで、アプリはモデルの機能に応じてテキスト、推論、ツール呼び出しなどのリクエストを処理します。

サードパーティのゲートウェイが `/v1/chat/completions` だけに対応している場合は、次の手順を行います。

1. OpenAI の組み込みテンプレートを変更して接続しないでください。
2. プロバイダー一覧の検索ボックス横にある `+` をクリックします。
3. カスタムプロバイダーを作成します。
4. OpenAI Chat Completions を主要エンドポイントに設定します。
5. ゲートウェイから提示された Base URL、API Key、モデル ID を入力します。

これにより、OpenAI の公式テンプレートを維持しながら、Responses と Chat Completions のプロトコル不一致を避けられます。

## モデルを同期して有効にする

**追加**をクリックすると、Cherry Studio はプロバイダーからモデルリストを同期し、適用前に追加、更新、削除される項目を表示します。

- 実際に必要なモデルだけを有効にすると、モデル選択がすっきりします。
- 同名モデルに複数のバージョンがある場合は、完全なモデル ID を確認します。
- API からモデルが返されない場合は、**カスタム**をクリックして公式のモデル ID を手動で入力できます。
- 別のゲートウェイのモデル ID を OpenAI の公式テンプレートへ直接追加しないでください。

モデルの利用可否は、OpenAI アカウントの権限によって決まります。Cherry Studio がモデルを識別できても、アカウントにアクセス権があるとは限りません。

## 接続を確認する

1. API Key エリアで接続チェックをクリックします。
2. 同期して有効にしたモデルを 1 つ選択します。
3. チェックに成功することを確認します。
4. 続いてモデルのヘルスチェックを実行します。
5. チャット画面に戻り、簡単なメッセージを送信します。

推論またはツール呼び出しモデルを使用する場合は、思考設定とツール呼び出しもそれぞれ 1 回テストしてください。モデル名だけで機能を判断しないでください。

## オプション設定

OpenAI テンプレートでは、サービス階層などのリクエストオプションを使用できます。チャット上部のモデル設定に**サービス階層**が表示される場合がありますが、通常は既定の**自動**を使用してください。

OpenAI が該当モデルで提供する機能と料金体系を明確に理解している場合にのみ、別の階層を選択してください。プロバイダーのリクエスト設定にある機能スイッチも安易に変更しないでください。対応していない機能を誤って指定すると、リクエストが失敗する場合があります。

## よくある質問

### 「従来の呼び出し方法はサポートされていません」と表示される

これは OpenAI の組み込みテンプレートに関する V2 の案内です。OpenAI の公式 API には現在のテンプレートを使用し、サードパーティの互換 API にはカスタムプロバイダーを作成してください。

### 401 が返される

API Key が無効、取り消し済み、または正しくコピーされていません。Key を作り直し、余分な空白が含まれていないことを確認してください。

### 403 が返される

アカウント、地域、組織、またはモデルの権限が要件を満たしていない可能性があります。OpenAI のコンソールでアカウントの状態とモデルへのアクセス権を確認してください。

### 残高またはクォータのエラーが返される

API アカウントの利用枠、課金状態、利用制限を確認してください。モデルを切り替えても、アカウント単位の制限を回避することはできません。

### 404 または「モデルが存在しません」と返される

もう一度**追加**をクリックしてリストを同期し、モデル ID を確認してください。サードパーティのゲートウェイに接続している場合は、カスタムプロバイダーへ切り替えて正しいエンドポイントを選択します。

### チャットはできるが、ツールを呼び出せない

モデルの機能タグと、そのモデルに対する OpenAI のツール対応を確認してください。まず簡単なツールでテストしてから、MCP などのツールを少しずつ追加します。

一般的な設定は[モデルプロバイダー](README.md)と[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。フィードバック先は[フィードバックとご提案](../../question-contact/suggestions.md)を参照してください。
