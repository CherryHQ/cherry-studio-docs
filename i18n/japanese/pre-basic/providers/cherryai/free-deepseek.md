# DeepSeek V3.2

Cherry Studio は、複数のプロバイダーが提供する DeepSeek V3.2 と一般的な派生モデルを識別できます。モデルが無料か、現在も利用できるか、また具体的なモデル ID が何かは、利用するプロバイダーによって異なります。

{% hint style="warning" %}
このページでは、DeepSeek V3.2 が CherryAI または CherryIN の無料トライアルモデルとして常に提供されることを保証しません。モデル選択の**無料**ラベル、プロバイダーのコンソール、実際のリクエスト結果を確認してください。
{% endhint %}

## すでに利用できるか確認する

1. チャット画面でモデル選択を開きます。
2. `DeepSeek V3.2` を検索します。
3. モデルが見つかった場合は、提供元のプロバイダーを確認します。
4. モデルを選択して、簡単なテストメッセージを送信します。

同じモデルを複数のプロバイダーが提供している場合があり、表示名や API のモデル ID も異なることがあります。選択する前に、アカウントの利用枠、利用可能な地域、プロバイダーの料金ルールを確認してください。

## プロバイダー経由で接続する

モデル選択に DeepSeek V3.2 がない場合は、次の手順を行います。

1. `設定 → モデルプロバイダー` を開きます。
2. [DeepSeek](../deepseek.md) の公式サービス、またはアカウントでこのモデルを提供している集約プロバイダーを選択します。
3. API Key を入力し、Base URL を確認します。
4. **追加**をクリックし、同期プレビューでモデルの変更を適用します。
5. DeepSeek V3.2 を検索し、使用するモデルのスイッチをオンにします。
6. 接続チェックまたはモデルのヘルスチェックを実行します。

Cherry Studio のモデルレジストリには、複数のプロバイダーで使われている DeepSeek V3.2 の識別情報が含まれます。これはモデルの機能を識別するための情報にすぎず、すべてのプロバイダーのアカウントでそのモデルを呼び出せるという意味ではありません。

## 同期できない場合に手動で追加する

一部のゲートウェイはモデルリスト API を提供していません。その場合は **カスタム**をクリックし、プロバイダーのコンソールに表示されるモデル ID をそのまま入力します。

一般的な名前には、次のようなものがあります。

- `deepseek-v3.2`
- `deepseek/deepseek-v3.2`
- 日付、`thinking`、`exp`、`speciale` などの接尾辞が付いた派生モデル

{% hint style="danger" %}
このページの情報からモデル ID を推測しないでください。ID、機能、ルーティングはプロバイダーごとに異なる場合があります。必ずプロバイダーのコンソールまたは API ドキュメントに記載された実際の値をコピーしてください。
{% endhint %}

## チャットで使用する

DeepSeek V3.2 シリーズは、コード、長文分析、複数段階の推論などのタスクに適しています。使用時は次の点をおすすめします。

- 複雑なタスクでのみモデルの推論機能を有効にします。単純な質問では、意図的に推論の負荷を増やす必要はありません。
- MCP などのツールを呼び出す場合は、モデルにツール呼び出し機能のタグが付いていることを確認し、一度テストしてください。
- 長い会話でコンテキストや出力の上限に達した場合は、新しいトピックを作成するか、添付ファイルを減らしてください。
- 重要な結果は自分で再確認し、モデルの出力をそのまま最終判断に使用しないでください。

派生モデルによって機能は異なります。たとえば、特殊な接尾辞を持つ推論モデルはツール呼び出しに対応していない場合があります。Cherry Studio に表示されるモデル機能と実際のテスト結果を確認してください。

## よくある質問

### モデルは検索できるが選択できない

提供元のプロバイダーとモデルのスイッチが、どちらも有効になっていることを確認してください。モデルが以前の設定から残っている場合は、モデルリストを取得し直してから確認します。

### 401、403、または残高不足が返される

API Key、アカウント権限、残高、地域制限を確認してください。トライアル利用枠を使い切った場合は、プロバイダーを切り替えるか、自分の API Key を設定できます。

### 「モデルが存在しません」と返される

通常は、モデル ID とプロバイダーが一致していないことを示します。誤った項目を削除してモデルリストを取得し直すか、プロバイダーのドキュメントに記載された完全な ID をコピーして手動で追加してください。

### ツールを使用できない

プロバイダーが同名のモデルを提供していても、そのエンドポイントでツール呼び出しが有効とは限りません。モデル機能のタグを確認し、必要に応じてツール呼び出しに対応する派生モデルまたはプロバイダーへ変更してください。

無料トライアルの一般的なルールは [CherryAI（無料トライアル）](../cherryin/README.md)、プロバイダーの設定手順は[モデルプロバイダー](../README.md)を参照してください。
