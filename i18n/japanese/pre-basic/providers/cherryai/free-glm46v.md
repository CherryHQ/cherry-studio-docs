# ZhiPu GLM-4.6V

Cherry Studio は、複数のプロバイダーが提供する GLM-4.6V と一般的な派生モデルを識別できます。標準版は画像、ファイル、推論、ツール呼び出しに対応するマルチモーダルモデルとして識別されます。最終的に利用できる機能は、プロバイダーが実際に提供する API によって異なります。

{% hint style="warning" %}
このページでは、GLM-4.6V が CherryAI または CherryIN の無料トライアルモデルとして常に提供されることを保証しません。モデルが無料か、現在も利用できるかは、モデル選択、プロバイダーのコンソール、実際のリクエスト結果を確認してください。
{% endhint %}

## すでに利用できるか確認する

1. チャット画面でモデル選択を開きます。
2. `GLM-4.6V` を検索します。
3. モデルの提供元を確認し、ビジョン、ファイル、推論、ツール呼び出しのタグを確認します。
4. モデルを選択し、機密情報を含まない画像を 1 枚アップロードしてテストします。

同じモデルを複数のプロバイダーが提供している場合があり、表示名、モデル ID、機能タグも異なることがあります。

## プロバイダー経由で接続する

モデル選択に GLM-4.6V がない場合は、次の手順を行います。

1. `設定 → モデルプロバイダー` を開きます。
2. ZhiPu、またはアカウントでこのモデルを提供している集約プロバイダーを選択します。
3. API Key を入力し、Base URL を確認します。
4. **追加**をクリックし、同期プレビューに表示されたモデルの変更を適用します。
5. GLM-4.6V を検索して有効にします。
6. 接続チェックまたはモデルのヘルスチェックを実行します。

Cherry Studio のモデルレジストリは、複数のプロバイダーで使われている GLM-4.6V の識別情報を認識できます。ただし、アカウントですでにこのモデルを利用できることを保証するものではありません。

## 適切な派生モデルを選ぶ

プロバイダーは、標準版、Flash、FP8、または別の接尾辞を持つモデルを同時に提供する場合があります。これらは独立したモデルであり、名前が似ているだけで同じ機能を持つとは限りません。

- 画像を理解させる場合は、モデルに **ビジョン**または**画像認識**機能があることを確認します。
- ドキュメントをアップロードする場合は、モデルに**ファイル入力**機能があることを確認します。
- MCP などのツールを使用する場合は、モデルに**ツール呼び出し**機能があることを確認します。
- テキストタスクだけに使う場合は、プロバイダーの速度、利用枠、料金説明を基に適切な派生モデルを選択できます。

{% hint style="danger" %}
このページの情報からモデル ID を推測しないでください。プロバイダーのコンソールまたは API ドキュメントから完全な ID をコピーしてください。誤った ID を入力すると、「モデルが存在しません」と返される場合や、別の派生モデルへルーティングされる場合があります。
{% endhint %}

## チャットで画像を使用する

1. ビジョン機能を持つ GLM-4.6V を選択します。
2. 画像を入力欄へドラッグする、貼り付ける、または添付ボタンをクリックして追加します。
3. 表の抽出、グラフの説明、画面の分析など、行うタスクを同じメッセージに記述します。
4. 送信する前に、画像に API Key、個人情報、その他の機密情報が含まれていないことを確認します。

入力欄に画像を追加できない場合は、通常、現在のモデルがビジョンモデルとして認識されていません。モデルを再同期するか、モデル編集ページで機能設定を確認してください。

## よくある質問

### 画像をアップロードしたが、モデルが認識できない

ビジョン対応の GLM-4.6V 派生モデルを選択していること、プロバイダーのエンドポイントが画像入力に対応していることを確認してください。名前が同じだけでは、API の機能が同じとは限りません。

### チャットはできるが、ツールを呼び出せない

まずツール呼び出し機能のタグを確認し、簡単なツールでテストしてください。プロバイダーがその派生モデルでツール呼び出しを提供していない場合や、互換性のない API を使用している場合があります。

### 同期リストに GLM-4.6V がない

プロバイダーのコンソールで、アカウントにこのモデルが提供されているか確認してください。API がモデルリストを返さない場合は、**カスタム**をクリックし、プロバイダーから提示されたモデル ID を入力します。

### ファイルまたはコンテキストが大きすぎると返される

画像の枚数または解像度を減らし、長いドキュメントを分割して、新しいトピックで再試行してください。具体的な上限は、プロバイダーとモデルの派生版によって異なります。

無料トライアルの一般的なルールは [CherryAI（無料トライアル）](../cherryin/README.md)、プロバイダーの設定手順は[モデルプロバイダー](../README.md)を参照してください。
