# DeepSeek

Cherry Studio V2 の組み込み DeepSeek テンプレートは、DeepSeek の公式 API への接続に使用します。現在のテンプレートは **OpenAI Chat Completions** を初期設定として使用し、DeepSeek 公式の Anthropic 互換エンドポイントも含みます。また、DeepSeek V4 の思考スイッチと推論強度に対応しています。

{% hint style="info" %}
まずモデルを試すだけなら、Cherry Studio に組み込まれている [CherryAI 無料トライアル](cherryin/README.md)を使用できます。このページは DeepSeek 公式の API Key を持っているユーザー向けです。
{% endhint %}

## 始める前の準備

- [DeepSeek オープンプラットフォーム](https://platform.deepseek.com/)にログインできるアカウント
- [API Keys](https://platform.deepseek.com/api_keys) で作成した API Key
- 利用可能な残高またはクォータがあるアカウント
- 現在利用できるモデルと公式 API の変更を確認済みであること

DeepSeek のウェブ版やアプリへのログイン状態は、Cherry Studio に自動的に反映されません。公式 API を呼び出すには、別途 API Key を作成する必要があります。

## DeepSeek を設定する

1. `設定 → モデルプロバイダー` を開きます。
2. 左側のフィルターを**すべてのプロバイダー**に切り替え、**deepseek** を選択します。
3. DeepSeek API Key を入力します。
4. 既定の Base URL `https://api.deepseek.com` を変更せずに使用します。
5. 画面上部にあるプロバイダーのスイッチをオンにします。
6. モデルリストで**追加**をクリックし、同期プレビューを確認して変更を適用します。
7. 使用するモデルを有効にします。

{% hint style="danger" %}
API Key をチャットメッセージ、ドキュメント、コードリポジトリ、または問題報告用のスクリーンショットに含めないでください。漏えいした場合は、DeepSeek オープンプラットフォームですぐに削除して作り直してください。
{% endhint %}

## 現在のモデルを選ぶ

DeepSeek の公式 API では、現在、次の主なモデル ID が提供されています。

| モデル ID | 適した用途 |
| --- | --- |
| `deepseek-v4-flash` | 日常的なチャット、高速なタスク、遅延の影響を受けやすい作業 |
| `deepseek-v4-pro` | 複雑な推論、コード、長いコンテキスト、Agent タスク |

従来のモデル別名 `deepseek-chat` と `deepseek-reasoner` は、2026 年 7 月に提供終了となりました。以前の設定で「モデルが存在しません」と返される場合は、もう一度**追加**をクリックしてリストを同期し、現在の V4 モデル ID へ変更してください。

{% hint style="warning" %}
モデルリストとライフサイクルは今後も変更される可能性があります。[DeepSeek API ドキュメント](https://api-docs.deepseek.com/)と実際の同期結果を確認し、古いスクリーンショットの固定されたモデル名に依存しないでください。
{% endhint %}

## 思考モードを設定する

DeepSeek V4 は思考モードと非思考モードの両方に対応し、初期状態では思考が有効です。Cherry Studio は入力欄の思考ボタンに次の選択肢を表示します。

- **デフォルト**：プロバイダーの既定の動作を使用します。
- **オフ**：思考を無効にするパラメーターを送信します。
- **最大限の思考**：DeepSeek の `high` 推論強度を使用します。
- **超高**：DeepSeek の `max` 推論強度へマッピングされます。

`超高` は通常、より多くの推論時間と Token を消費します。日常的な質問ではデフォルトまたはオフから試し、複雑なコード、計画、Agent タスクで強度を上げてください。

思考モードでは、一部のサンプリングパラメーターが機能しない場合があります。結果に違いが生じた場合は、まず既定のパラメーターを維持し、思考スイッチと強度だけを調整してください。

## ツール呼び出しと Agent

DeepSeek V4 は思考モードでのツール呼び出しに対応し、Cherry Studio はツール呼び出しの処理に必要な思考内容も維持します。使用前に実際のテストを行ってください。

1. 簡単な MCP ツールを 1 つ有効にします。
2. `deepseek-v4-pro` または `deepseek-v4-flash` を選択します。
3. まず既定の思考強度を使用します。
4. ツールが明確に必要になるリクエストを送信します。
5. モデルが呼び出し計画だけを出力せず、実際にツールを呼び出すことを確認します。

連続したツール呼び出しで 400 が返される場合は、まず Cherry Studio とモデルリストを更新し、ゲートウェイが本当に DeepSeek の公式エンドポイントか確認してください。

## 接続を確認する

1. API Key エリアで接続チェックを実行します。
2. 同期して有効にした V4 モデルを 1 つ選択します。
3. チェックに成功することを確認します。
4. モデルリストでヘルスチェックを実行します。
5. チャット画面に戻り、簡単なメッセージを送信します。
6. 続いて思考モードとツール呼び出しを個別にテストします。

接続チェックに成功しても、アカウントに無制限のクォータがある、またはすべてのモデルが提供されているとは限りません。

## ナレッジベースと埋め込みモデル

組み込み DeepSeek テンプレートには現在チャットエンドポイントだけが設定され、埋め込みモデルは提供されません。[グローバルメモリ](../../advanced-basic/memory.md)またはナレッジベースを使用する場合：

- チャットモデルには引き続き DeepSeek を選択できます。
- 埋め込みモデルは別のプロバイダーから選択する必要があります。
- 埋め込みモデルとチャットモデルを同じプロバイダーから選ぶ必要はありません。
- 設定後、それぞれでモデルのヘルスチェックを実行します。

## DeepSeek 互換ゲートウェイに接続する

DeepSeek の公式 API 以外を使用する場合は、次の手順を行います。

1. [カスタムプロバイダー](zi-ding-yi-fu-wu-shang.md)を新規作成します。
2. ゲートウェイのドキュメントに従って OpenAI Chat Completions または Anthropic Messages を選択します。
3. ゲートウェイから提示された Base URL と API Key を入力します。
4. ゲートウェイが実際に提供するモデル ID を同期するか、手動で追加します。
5. 思考パラメーターとツール呼び出しがゲートウェイで完全にサポートされることを検証します。

DeepSeek の公式テンプレートを直接上書きしないでください。個別のプロバイダーに分けると、公式アカウント、サードパーティのモデル名、プロトコルの違いを区別しやすくなります。

## よくある質問

### 401 が返される

API Key が無効、削除済み、または正しくコピーされていません。Key を作り直し、余分な空白が含まれていないことを確認してください。

### 残高またはクォータのエラーが返される

DeepSeek オープンプラットフォームで残高、使用量、アカウントの状態を確認してください。モデルを切り替えても、アカウント単位の制限を回避することはできません。

### 404 または「モデルが存在しません」と返される

もう一度**追加**をクリックしてモデルを同期し、`deepseek-v4-flash` または `deepseek-v4-pro` を使用していることを確認してください。従来の別名は提供終了となっています。

### 429 または「サーバーが混雑しています」と返される

現在のリクエストがレート制限に達したか、サービスが一時的に混雑しています。後でもう一度試す、同時実行数を減らす、またはアカウントの制限を確認してください。

### 思考ボタンにすべての選択肢が表示されない

モデル ID が現在の V4 ID であることを確認し、モデルを再同期してください。手動で追加するときはモデル ID を変更しないでください。表示名は変更できます。

### ツール呼び出しがテキストだけを出力する

モデルがツール呼び出しに対応していること、MCP が有効になっていること、DeepSeek の公式エンドポイントまたは完全なツールプロトコルに明確に対応するゲートウェイを使用していることを確認してください。まず単一の簡単なツールで問題を切り分けます。

一般的な設定は[モデルプロバイダー](README.md)と[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。フィードバック先は[フィードバックとご提案](../../question-contact/suggestions.md)を参照してください。
