# Grok

Cherry Studio V2 の組み込み Grok テンプレートは、xAI の公式 API への接続に使用します。V2 はこのプロバイダーに xAI Responses のアダプターを使用し、チャット、推論、ツール呼び出しに加えて、xAI 公式の Web Search と X Search に対応します。

{% hint style="warning" %}
Grok が自動的にリアルタイム情報を取得するわけではありません。チャットでウェブ検索を有効にした場合にのみ、Cherry Studio は xAI に Web Search と X Search をリクエストします。サーバー側の検索ツールには追加料金がかかる場合があります。
{% endhint %}

## 始める前の準備

- [xAI Console](https://console.x.ai/) にログインできるアカウント
- xAI Console で作成した API Key
- 利用可能なクレジットがあるチームまたはアカウント
- 現在利用できるモデルとサービス地域を確認済みであること

x.com や Grok のウェブ版へのログイン状態は、Cherry Studio に自動的に反映されません。xAI API を使用するには、別途 API Key を作成する必要があります。

## Grok を設定する

1. `設定 → モデルプロバイダー` を開きます。
2. 左側のフィルターを**すべてのプロバイダー**に切り替え、**Grok** を選択します。
3. xAI API Key を入力します。
4. 既定の Base URL `https://api.x.ai` を変更せずに使用します。
5. 画面上部にあるプロバイダーのスイッチをオンにします。
6. モデルリストで**追加**をクリックし、同期プレビューを確認して変更を適用します。
7. 使用するモデルを有効にします。

{% hint style="danger" %}
API Key をチャットメッセージ、ドキュメント、コードリポジトリ、または問題報告用のスクリーンショットに含めないでください。漏えいした場合は、xAI Console ですぐに取り消して作り直してください。
{% endhint %}

## モデルを選ぶ

xAI はモデルと別名を継続的に更新しています。**追加**をクリックしてアカウントから現在確認できるリストを同期し、[xAI モデルのドキュメント](https://docs.x.ai/developers/models)を参照してください。

現在の主な選択肢：

| モデル ID | 適した用途 |
| --- | --- |
| `grok-4.5` | 複雑な知識作業、コード、Agent タスク |
| `grok-4.3` | 一般的なチャット、画像理解、調整可能な推論 |
| `grok-build-0.1` | Agent 向けのコードタスク |

- 実際に必要なモデルだけを有効にします。
- 表示名だけでなく、完全なモデル ID を確認します。
- `-latest` の別名は、新しいバージョンへ自動的に移行される場合があります。
- 日付を含むモデル ID は、動作を固定する必要があるワークフローに適しています。
- モデルが同期リストに表示されても、アカウントに無制限のクレジットがあるとは限りません。

## ウェブ検索を使用する

チャットの入力欄で**ウェブ検索**を有効にすると、Cherry Studio は Grok に次の機能を設定します。

- xAI Web Search
- xAI X Search
- 検索ページと X の投稿に含まれる画像の理解
- 検索元と引用の返却

ウェブ検索の設定で除外ドメインを指定した場合、Grok の公式検索に渡される有効なドメインルールは先頭の 5 件までです。

使用方法：

1. 有効にした Grok のテキストモデルを選択します。
2. 入力欄の**ウェブ検索**を有効にします。
3. 最新のウェブ情報または X の情報を明確に必要とする質問を入力します。
4. モデルがサーバー側の検索を完了するまで待ちます。
5. 引用を展開して情報源を確認します。

{% hint style="info" %}
「モデルの知識が新しい」ことと「ウェブ検索」は同じではありません。ウェブ検索を有効にしていない場合、Grok はモデルが保持する知識だけを基に回答します。現在の情報が必要な場合は、明示的にウェブ検索を有効にして引用を確認してください。
{% endhint %}

## 推論とツール呼び出し

Cherry Studio はモデル ID に応じた推論オプションを表示します。

- `grok-4.3` は、オフ、低、中、高などの推論強度に対応します。
- Grok 4 Fast の推論版と非推論版は別のモデルであり、スイッチだけで相互に切り替えることはできません。
- その他の新しいモデルで使えるオプションは、現在の Cherry Studio のバージョンとモデル登録情報によって異なります。

MCP などのツールを使用する前に：

1. まず通常のチャットでヘルスチェックを完了します。
2. 簡単なツールを 1 つ有効にします。
3. ツールが明確に必要になるリクエストを送信します。
4. モデルが実際にツールを呼び出すことを確認します。
5. その後でウェブ検索や複数のツールを追加します。

ウェブ検索は xAI のサーバー側ツール、MCP は Cherry Studio のローカルまたはリモートツールです。両方を同時に使用できますが、問題を調査するときは個別にテストしてください。

## 接続を確認する

1. API Key エリアで接続チェックを実行します。
2. 同期して有効にしたモデルを 1 つ選択します。
3. チェックに成功することを確認します。
4. モデルリストでヘルスチェックを実行します。
5. チャット画面に戻り、簡単なメッセージを送信します。
6. 続いてウェブ検索を有効にし、引用を含むクエリを一度テストします。

接続チェックに成功しても、検索ツールを利用できるとは限りません。検索はモデルの機能、アカウントの権限、ツールの課金状態にも影響されます。

## Grok 互換ゲートウェイに接続する

xAI の公式 API 以外を使用する場合は、次の手順を行います。

1. [カスタムプロバイダー](zi-ding-yi-fu-wu-shang.md)を新規作成します。
2. ゲートウェイのドキュメントに従って OpenAI Chat Completions または OpenAI Responses を選択します。
3. ゲートウェイから提示された Base URL と API Key を入力します。
4. ゲートウェイが実際に提供するモデルを同期するか、手動で追加します。
5. 推論、ツール呼び出し、ウェブ検索の機能を個別に検証します。

サードパーティゲートウェイが Grok モデルを提供していても、xAI 公式の Web Search または X Search に対応するとは限りません。Grok の公式テンプレートを直接上書きしないでください。

## よくある質問

### 401 が返される

API Key が無効、取り消し済み、または正しくコピーされていません。Key を作り直し、余分な空白が含まれていないことを確認してください。

### 403 が返される

チーム、地域、モデル、またはツールの権限が要件を満たしていません。xAI Console でアカウントとモデルへのアクセス状態を確認してください。

### 404 または「モデルが存在しません」と返される

もう一度**追加**をクリックしてリストを同期し、完全なモデル ID を確認してください。以前のモデルは移行、リダイレクト、または提供終了になっている場合があります。

### 429 が返される

現在のチームまたはモデルがレート制限に達しています。同時実行数を減らして後でもう一度試し、xAI Console で制限と使用量を確認してください。

### ウェブ検索を有効にしても引用がない

入力欄のウェブ検索が有効で、最新情報を明確に必要とする質問を入力していることを確認してください。サードパーティゲートウェイを使用している場合は、xAI のサーバー側検索ツールに対応していない可能性があります。

### ウェブ検索の料金が予想より高い

xAI はモデルの Token とサーバー側ツールの呼び出しを両方計算する場合があります。不要なウェブ検索リクエストを減らし、xAI Console で実際の使用量を確認してください。

### 推論オプションがドキュメントと異なる

モデルを再同期し、Cherry Studio が最新であることを確認してください。xAI の新しいモデルがアプリ内の機能ルールより先に公開される場合があります。そのときは、現在の画面と実際のヘルスチェックを優先してください。

一般的な設定は[モデルプロバイダー](README.md)、[ウェブ検索モード](../../websearch/README.md)、[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。フィードバック先は[フィードバックとご提案](../../question-contact/suggestions.md)を参照してください。
