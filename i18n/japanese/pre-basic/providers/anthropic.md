# Anthropic

Cherry Studio V2 の組み込み Anthropic テンプレートは Anthropic の公式 API への接続に使用し、初期状態では **Anthropic Messages** エンドポイントを使用します。API Key を設定すると、Claude モデルを同期してチャット、推論、ツール呼び出しに利用できます。

{% hint style="info" %}
プロバイダーに Anthropic エンドポイントがあっても、すべてのモデルがツール呼び出しまたは Agent に対応するとは限りません。モデルの機能タグを確認し、使用前に実際のツールで一度テストしてください。
{% endhint %}

## 始める前の準備

- Anthropic API を利用できるアカウント
- [Anthropic API Keys](https://console.anthropic.com/settings/keys) で作成した API Key
- アカウントで利用可能になっているモデルと利用枠
- Anthropic の最新のアカウントおよび地域要件を満たすネットワーク環境

Anthropic API Key とウェブ版へのログイン状態は別の設定です。Cherry Studio には、API リクエストに使用できる Key が必要です。

## Anthropic を設定する

1. `設定 → モデルプロバイダー` を開きます。
2. 左側のフィルターを**すべてのプロバイダー**に切り替え、**Anthropic** を選択します。
3. API Key を入力します。
4. 既定の Base URL `https://api.anthropic.com` を変更せずに使用します。
5. 画面上部にあるプロバイダーのスイッチをオンにします。
6. モデルリストで**追加**をクリックし、同期プレビューを確認して変更を適用します。
7. 使用する Claude モデルを有効にします。

{% hint style="danger" %}
API Key をチャットメッセージ、ドキュメント、コードリポジトリ、または問題報告用のスクリーンショットに含めないでください。漏えいした場合は、Anthropic Console ですぐに取り消して作り直してください。
{% endhint %}

## モデルを同期して選択する

Anthropic のモデル名とバージョンは変更されるため、このページでは特定の一覧を固定して記載していません。**追加**をクリックしてアカウントで現在利用できるモデルを同期し、完全なモデル ID を確認してください。

- 実際に必要なモデルだけを有効にします。
- 同じシリーズでも、バージョンによってコンテキスト、推論、ツールの機能が異なる場合があります。
- API からモデルが返されない場合は、**カスタム**をクリックし、Anthropic の公式ドキュメントに記載されたモデル ID を入力できます。
- サードパーティゲートウェイのモデル ID を Anthropic の公式テンプレートへ直接追加しないでください。

モデルが Cherry Studio のレジストリに含まれていても、Anthropic アカウントにアクセス権があるとは限りません。

## 接続を確認する

1. API Key エリアで接続チェックを開始します。
2. 同期して有効にしたモデルを 1 つ選択します。
3. チェックに成功することを確認します。
4. モデルリストでヘルスチェックを実行します。
5. チャット画面に戻り、簡単なメッセージを送信します。

MCP または Agent を使用する場合は、簡単なツールを 1 つ有効にして、モデルが実際に呼び出しを開始するか確認してください。

## Agent とツール呼び出し

Anthropic テンプレートは Anthropic 互換エンドポイントを持つため、モデルプロバイダー一覧の **Agent** フィルターに表示されます。ただし、使用するには次の条件もすべて満たす必要があります。

- 対象モデルにツール呼び出し機能がある
- 現在の API エンドポイントでツール呼び出しが提供されている
- MCP などのツールが正しく有効になっている
- アシスタントでツールが無効になっていない
- プロバイダーの権限またはセキュリティポリシーによってリクエストがブロックされていない

モデルがツール呼び出しの計画だけを出力して実行しない場合は、まず単純なツール 1 つで問題を切り分け、その後にモデルの機能とエンドポイントを確認してください。

## Prompt Cache

Anthropic エンドポイントの Prompt Cache は、Cherry Studio の **API 設定**で構成できます。

- **キャッシュ Token しきい値**：メッセージがこの数を超えたときにだけキャッシュを有効にします。`0` に設定すると無効になります。
- **システムメッセージをキャッシュ**：システムプロンプトをキャッシュするかどうかを指定します。
- **直近 N 件のメッセージをキャッシュ**：最近の会話メッセージを何件キャッシュするかを指定します。

{% hint style="warning" %}
キャッシュが有効になるか、どのように課金されるか、どのモデルが対応するかは、プロバイダーによって決まります。プロバイダーのルールが分からない場合は既定値を使用してください。設定を変更しても、必ずコストが下がるとは限りません。
{% endhint %}

## Anthropic 互換ゲートウェイに接続する

Anthropic の公式 API 以外を使用する場合は、次の手順を行います。

1. 左側のプロバイダー一覧で Anthropic を右クリックします。
2. 複製するか、同種のプロバイダーを新規作成します。
3. 複製した項目に、ゲートウェイから提示された Base URL と API Key を入力します。
4. Anthropic Messages を主要エンドポイントとして維持します。
5. ゲートウェイが実際に提供するモデルを同期するか、手動で追加します。

個別の複製を使用すると、Anthropic の公式テンプレートを上書きせず、エンドポイントと権限の問題も別々に調査できます。

## よくある質問

### 401 が返される

API Key が無効、取り消し済み、または正しくコピーされていません。Key を作り直し、余分な空白が含まれていないことを確認してください。

### 403 が返される

アカウント、地域、ワークスペース、またはモデルの権限が要件を満たしていない可能性があります。Anthropic Console でアカウントの状態を確認してください。

### 404 または「モデルが存在しません」と返される

もう一度**追加**をクリックしてリストを同期し、完全なモデル ID を確認してください。サードパーティゲートウェイを使用する場合は、Base URL と Anthropic Messages のパスがゲートウェイのドキュメントに従っていることを確認します。

### Agent フィルターにモデルが表示されない

Agent フィルターは、プロバイダーに Anthropic エンドポイントがあるかどうかで判定されます。カスタムゲートウェイには Anthropic Messages エンドポイントを正しく設定する必要があり、モデル自体もツール呼び出しに対応している必要があります。

### Prompt Cache が機能しない

キャッシュのしきい値が `0` より大きいこと、プロバイダーとモデルがキャッシュに対応していることを確認してください。短い会話では設定したしきい値に達しない場合があります。

一般的な設定は[モデルプロバイダー](README.md)と[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。フィードバック先は[フィードバックとご提案](../../question-contact/suggestions.md)を参照してください。
