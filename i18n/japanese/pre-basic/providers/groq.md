# Groq

Groq は低遅延の推論を特長とするモデルサービスプラットフォームで、複数のオープンウェイトモデルと Groq Compound システムを提供しています。Cherry Studio V2 の組み込み Groq テンプレートは、Groq 公式の OpenAI 互換エンドポイントを使用し、アカウントで現在利用できるモデルを同期できます。

{% hint style="warning" %}
**Groq** と xAI の **Grok** は別のプロバイダーです。Groq はモデル推論プラットフォームを提供し、Grok は xAI のモデルシリーズです。設定する前に正しい項目を選択していることを確認してください。
{% endhint %}

## 始める前の準備

- [GroqCloud Console](https://console.groq.com/) にログインできるアカウント
- [Groq API Keys](https://console.groq.com/keys) で作成した API Key
- 利用可能なクォータとレート制限があるアカウント
- 使用するモデルが現在も提供されていることを確認済みであること

Groq のモデル一覧とライフサイクルは変更されます。古いドキュメントを基に提供終了したモデルを固定して追加しないでください。

## Groq を設定する

1. `設定 → モデルプロバイダー` を開きます。
2. 左側のフィルターを**すべてのプロバイダー**に切り替え、**Groq** を選択します。
3. Groq API Key を入力します。
4. 既定の Base URL `https://api.groq.com/openai` を変更せずに使用します。
5. 画面上部にあるプロバイダーのスイッチをオンにします。
6. モデルリストで**追加**をクリックし、同期プレビューを確認して変更を適用します。
7. 使用するモデルを有効にします。

{% hint style="danger" %}
API Key をチャットメッセージ、ドキュメント、コードリポジトリ、または問題報告用のスクリーンショットに含めないでください。漏えいした場合は、GroqCloud Console ですぐに取り消して作り直してください。
{% endhint %}

## モデルを同期して選択する

**追加**をクリックすると、Cherry Studio は Groq のモデルリスト API を呼び出し、現在の Key でアクセスできるモデルを表示します。モデルは頻繁に変わるため、[Groq Supported Models](https://console.groq.com/docs/models)と同期結果を確認してください。

主な種類：

| 種類 | モデル ID の例 | 適した用途 |
| --- | --- | --- |
| 軽量テキストモデル | `llama-3.1-8b-instant` | 低遅延の質問応答、分類、単純な抽出 |
| 大規模な汎用モデル | `openai/gpt-oss-120b` | 複雑なテキスト、コード、推論 |
| その他のホストモデル | `qwen/qwen3.6-27b` | 多言語、構造化出力、ツールタスク |
| Compound システム | `groq/compound`、`groq/compound-mini` | Groq のサーバー側検索とコード実行 |

- 実際に必要なモデルだけを有効にします。
- スラッシュと大文字・小文字を含む完全なモデル ID を確認します。
- モデルが提供終了になった場合は、表示名だけを変更せず、再同期してください。
- 同じモデルでも、プランによってレート制限が異なる場合があります。
- 音声、スピーチ、専用モデルは通常のチャットに適さない場合があります。

## サービスティアを設定する

チャットの Groq 設定では、**サービスティア**を選択できます。

| オプション | 意味 |
| --- | --- |
| 無視 | `service_tier` を送信せず、Groq の既定の動作を使用 |
| 自動 | アカウントで現在利用できる適切なティアを使用 |
| オンデマンド | 通常のオンデマンド処理を使用 |
| フレックス | 高スループットを優先するが、容量不足時はすぐに失敗する場合がある |

サービスティアが有効になるかは、現在のモデル、アカウントプラン、Cherry Studio の機能判定によって異なります。違いが分からない場合は、**無視**または**自動**のままにしてください。

{% hint style="info" %}
フレックス処理は、容量不足時に `498 capacity_exceeded` を返す場合があります。再試行できるバッチタスクには適していますが、1 回で成功する必要がある対話型リクエストには適していません。
{% endhint %}

## MCP とツール呼び出しを使用する

通常の Groq ホストモデルは、対応する機能に応じて Cherry Studio の MCP などのツールを使用できます。

1. ツール呼び出しに対応するモデルを選択します。
2. 簡単な MCP ツールを 1 つ有効にします。
3. ツールが明確に必要になるリクエストを送信します。
4. モデルが実際にツールを呼び出すことを確認します。
5. その後で並列ツールまたは複雑なパラメーターを追加します。

Groq Compound は別の仕組みです。

- `groq/compound` は、1 回のリクエストで複数の Groq サーバー側ツールを使用できます。
- `groq/compound-mini` は、1 回のリクエストでサーバー側ツールを 1 つだけ使用し、遅延が小さくなります。
- 検索、ウェブページへのアクセス、コード実行は Groq のサーバーで行われます。
- Compound は Cherry Studio の MCP と同じものではなく、ユーザー定義ツールを Compound に直接渡すこともできません。

独自の MCP ツールを使用する場合は、Compound を MCP の実行環境として扱わず、通常のツール呼び出しに対応するホストモデルを選択してください。

## 接続を確認する

1. API Key エリアで接続チェックを実行します。
2. 同期して有効にしたテキストモデルを 1 つ選択します。
3. チェックに成功することを確認します。
4. モデルリストでヘルスチェックを実行します。
5. チャット画面に戻り、簡単なメッセージを送信します。
6. ツールまたは Compound を使用する場合は、その機能も個別にテストします。

接続チェックに成功しても、すべてのモデルが同じコンテキスト、ツール、レート制限を持つとは限りません。

## Groq 互換ゲートウェイに接続する

Groq の公式 API 以外を使用する場合は、次の手順を行います。

1. [カスタムプロバイダー](zi-ding-yi-fu-wu-shang.md)を新規作成します。
2. OpenAI Chat Completions を主要エンドポイントに設定します。
3. ゲートウェイから提示された Base URL と API Key を入力します。
4. ゲートウェイが実際に提供するモデルを同期するか、手動で追加します。
5. ツール呼び出しとサービスティアへの対応を検証します。

Groq の公式テンプレートを上書きしないでください。サードパーティゲートウェイが Groq Compound のサーバー側ツールを自動的に利用できるわけでもありません。

## よくある質問

### 401 が返される

API Key が無効、取り消し済み、または正しくコピーされていません。Key を作り直し、余分な空白が含まれていないことを確認してください。

### 404 または「モデルが存在しません」と返される

モデルが提供終了になった、モデル ID が間違っている、または現在のアカウントにアクセス権がありません。もう一度**追加**をクリックしてリストを同期してください。

### 429 が返される

リクエストがモデルまたはアカウントのレート制限に達しています。同時実行数を減らして後でもう一度試し、GroqCloud Console で制限を確認してください。

### 498 が返される

フレックスティアに現在利用できる容量がありません。自動、オンデマンド、無視のいずれかへ切り替えるか、タスクにバックオフ再試行を追加してください。

### 応答は速いが、内容が途中で切れる

モデルのコンテキストと最大出力の上限を確認し、入力を短くするか最大出力 Token を調整してください。推論速度によってモデル自体の上限が変わることはありません。

### Compound が MCP を呼び出さない

Compound は Groq のサーバー側ツールを使用し、Cherry Studio のカスタム MCP ツールを受け取りません。通常のツール呼び出しに対応するホストモデルへ変更してください。

### サービスティアを変更しても反映されない

現在のモデルまたはアカウントが選択したティアに対応していない可能性があります。無視または自動のままにし、GroqCloud Console の実際のリクエスト記録を確認してください。

一般的な設定は[モデルプロバイダー](README.md)と[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。フィードバック先は[フィードバックとご提案](../../question-contact/suggestions.md)を参照してください。
