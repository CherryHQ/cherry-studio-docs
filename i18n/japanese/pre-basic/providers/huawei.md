# Huawei Cloud ModelArts Studio（MaaS）

Huawei Cloud ModelArts Studio（MaaS）は、組み込みモデルとカスタムデプロイモデルの推論 API を提供します。現在の Cherry Studio V2 には「Huawei Cloud」プロバイダーが組み込まれていないため、**OpenAI 互換のカスタムプロバイダー**を作成する必要があります。

{% hint style="info" %}
古いチュートリアルでは、完全な `/chat/completions` アドレスを API Host に入力し、末尾に `#` を追加するよう案内していました。V2 ではこの過去の互換設定は不要です。完全な呼び出しアドレスから `/chat/completions` を削除し、Base URL だけを残してください。
{% endhint %}

## 接続方法を先に選択する

Huawei Cloud MaaS では、主に次の 2 種類の呼び出し方法があります。

| 方法 | アドレスの特徴 | Cherry Studio の設定 |
| --- | --- | --- |
| MaaS Standard API | 複数の組み込みモデルが `/v1` または `/v2` の Base URL を共有 | 通常は 1 つのカスタムプロバイダーで対応可能 |
| カスタムリアルタイム推論サービス | サービスごとに個別の URL、Endpoint、パスを使用する場合がある | Base URL が異なる場合はプロバイダーを個別に作成 |

本書は、Bearer API Key を使用する OpenAI 互換 MaaS サービスだけを対象とします。旧版 ModelArts の IAM Token、AppKey/AppSecret、AppCode、署名認証は、Cherry Studio の通常の API Key 入力欄に直接設定できません。

## リージョンとバージョン

MaaS の利用可能なリージョン、API Key、モデル一覧は相互に関連しており、異なるリージョン間で混在させることはできません。

Huawei Cloud の現在の国際サイトのドキュメントでは、MaaS Standard API V2 の例として次のアドレスが示されています。

```text
https://api-ap-southeast-1.modelarts-maas.com/v2/chat/completions
```

Cherry Studio には次のように入力します。

```text
https://api-ap-southeast-1.modelarts-maas.com/v2
```

MaaS Standard API V1 は今後の機能拡張が行われません。新しい設定では、コンソールが提供する V2 アドレスを優先してください。既存の V1 サービスについては、引き続きコンソールの「呼び出し説明」を基準にします。

{% hint style="warning" %}
本書のサンプルアドレスをそのままコピーしないでください。まず、自分の Huawei Cloud リージョンとサービスページで呼び出し説明を確認します。コンソールに表示されるドメインまたはバージョンが異なる場合は、コンソールのアドレスを使用してください。
{% endhint %}

## MaaS の有効化

1. [Huawei Cloud](https://auth.huaweicloud.com/authui/login)に登録してログインします。
2. MaaS が現在対応しているリージョンへ切り替えます。
3. ModelArts Studio（MaaS）を開きます。
4. コンソールの案内に従って IAM 認証を完了します。
5. モデル広場でモデルを選択します。
6. 組み込みサービスを有効にするか、リアルタイム推論サービスとしてデプロイします。
7. サービスの状態が呼び出し可能になるまで待ちます。

カスタムデプロイではコンピューティングおよびストレージリソースが使用され、料金が発生します。課金方式を理解しないまま「すべてデプロイ」を選択しないでください。

## API Key の作成

### 組み込み MaaS サービス

1. MaaS の API Key 管理を開きます。
2. **API Key を作成**をクリックします。
3. ラベルを設定します。
4. 必要に応じて、IP、モデル、カスタム Endpoint の許可リストを設定します。
5. 作成後、すぐにコピーして保存します。

### カスタムリアルタイム推論サービス

1. `モデル推論 → リアルタイム推論 → マイサービス`を開きます。
2. 実行中のサービスを見つけます。
3. `その他 → 呼び出し説明を表示`を選択します。
4. **API Key を作成**をクリックします。
5. 権限を設定し、Key をコピーします。
6. 完全な API URL とモデルパラメーターもコピーします。

MaaS Key は、作成後に有効になるまで数分かかる場合があります。

{% hint style="danger" %}
API Key は作成時に一度だけ表示されます。チャット、ドキュメント、コードリポジトリ、問題報告用のスクリーンショットに記載しないでください。紛失または漏えいした場合は、削除して再作成してください。
{% endhint %}

## 完全な URL から Base URL を抽出する

コンソールに表示された完全なアドレスが次のとおりだとします。

```text
https://example.com/v2/chat/completions
```

Cherry Studio には次のように入力します。

```text
https://example.com/v2
```

処理ルール：

1. 末尾の `/chat/completions` を削除します。
2. `/v1` または `/v2` は残します。
3. `#` を追加しません。
4. モデル名を URL に連結しません。
5. コンソールの Web ページ URL を API URL として使用しません。

カスタムサービスの呼び出し説明に別のパスが記載されている場合は、まず OpenAI Chat Completions と互換性があることを確認してください。互換性のないインターフェースは、パスを削除するだけでは接続できません。

## Cherry Studio でカスタムプロバイダーを作成する

1. `設定 → モデルサービス`を開きます。
2. **プロバイダーを追加**をクリックします。
3. `Huawei Cloud MaaS` などの名前を入力します。
4. **OpenAI 互換**タイプを選択します。
5. MaaS API Key を貼り付けます。
6. 抽出した Base URL を入力します。
7. プロバイダーのスイッチをオンにします。
8. モデルを同期するか、Model ID を手動で追加します。
9. 使用するモデルだけを有効にします。
10. モデルのヘルスチェックを実行します。

すべてのモデルが同じ MaaS Standard API Base URL を共有する場合は、1 つのプロバイダーにまとめることができます。Base URL、認証、プロキシパスのいずれかが異なる場合に限り、別のプロバイダーを作成してください。

## モデルの取得と同期

MaaS Standard API は、次のモデル一覧インターフェースを提供します。

```text
GET /v1/models
GET /v2/models
```

使用するバージョンは、コンソールが提供する Base URL によって決まります。

同期後：

1. 返された Model ID を確認します。
2. 同期結果を適用します。
3. モデルタイプを確認します。
4. 各モデルでヘルスチェックを実行します。

カスタムサービスがモデル一覧インターフェースを提供しない場合：

1. 「呼び出し説明」から `model` パラメーターをコピーします。
2. Cherry Studio で手動追加します。
3. 大文字・小文字と記号を完全に一致させます。
4. ヘルスチェックを実行します。

{% hint style="warning" %}
API Key には、モデルおよびカスタム Endpoint の許可リストを設定できます。モデルが存在しているのに 401 が返される場合は、Key をコピーし直すだけでなく、その権限も確認してください。
{% endhint %}

## チャットモデル

MaaS Standard API は、OpenAI 互換の Chat Completions を使用します。

次の順序でテストすることをおすすめします。

1. 短いテキストメッセージを送信します。
2. ストリーミング出力を確認します。
3. システムプロンプトを追加します。
4. 長めのコンテキストをテストします。
5. その後、思考、画像、ツール呼び出しをテストします。

モデルごとに、使用可能な `role`、コンテキスト長、出力パラメーターが異なります。400 が発生した場合は、そのモデルの MaaS API 呼び出し仕様と照合してください。

## 思考モード

Huawei Cloud MaaS のモデルによって、次の項目を使用する場合があります。

- `reasoning_content`
- `thinking`
- `chat_template_kwargs`
- モデル専用スイッチ

現在の Cherry Studio には、Huawei Cloud 専用のパラメーターアダプターがありません。V2 が一般的な OpenAI 互換プロバイダー向けに生成する思考パラメーターは、特定の MaaS モデルと完全には一致しない場合があります。

思考を有効にした後にエラーが発生した場合：

1. 思考設定を**デフォルト**に戻します。
2. モデルのカスタムパラメーターを消去します。
3. まず通常のチャットが動作することを確認します。
4. MaaS でそのモデルのリクエスト例を確認します。
5. 公式に必須と明記されたパラメーターだけを追加します。

あるモデルの `chat_template_kwargs` を別のモデルへコピーしないでください。

## ビジョンとマルチモーダル

画像を受け取れるのは、MaaS が明確にビジョンまたはマルチモーダルとして指定しているモデルだけです。

テスト手順：

1. 正確な Model ID を追加します。
2. Cherry Studio に画像機能が表示されることを確認します。
3. まず小さな画像を 1 枚アップロードします。
4. モデルが実際に内容を理解できているか確認します。
5. その後、複数画像または大きなファイルを試します。

カスタムリアルタイムサービスにビジョンモデルをデプロイしていても、Cherry Studio から直接接続するには、OpenAI 互換の画像メッセージ形式を使用する必要があります。

## MCP とツール呼び出し

MaaS Standard API V2 の一部のモデルは Tool Calling に対応していますが、最終的な機能はモデルによって異なります。

1. まず通常のチャットを動作させます。
2. 単純な MCP ツールを 1 つだけ有効にします。
3. ツールを呼び出すよう明示的に指示します。
4. 構造化された呼び出しが生成されているか確認します。
5. ツールの結果がモデルに返されることを確認します。
6. その後、ツールを追加します。

モデルが「ツールを呼び出す」とテキストで説明するだけでは、実際の呼び出しではありません。モデル、API バージョン、ツール形式を確認してください。

## Embedding、Rerank、画像生成

現在の Cherry Studio には、Huawei Cloud 専用の Embedding、Rerank、画像生成アダプターがありません。

次の条件をすべて満たす場合に限り、試してください。

1. MaaS サービスが対応する OpenAI 互換インターフェースを提供している。
2. Cherry Studio でモデルに正しい Endpoint Type を選択できる。
3. リクエストとレスポンスの形式が V2 と互換性がある。
4. ヘルスチェックまたは実際の小規模テストに合格している。

MaaS コンソールがあるタイプのモデルに対応しているという理由だけで、Cherry Studio のナレッジベースや描画ページにも統合済みだと判断しないでください。

ナレッジベースでは、V2 が明確に対応している Embedding および Rerank プロバイダーを使用するのが最も確実です。画像生成では、描画ページに実際に表示されているプロバイダーとモデルを使用してください。

## PDF と添付ファイル

現在の V2 は、まずローカルで PDF のテキストを抽出し、その後 MaaS のチャットモデルへ送信します。

- テキスト形式の PDF は通常処理できます。
- スキャンされた文書には、先に OCR が必要です。
- 表、複雑なレイアウト、画像の情報は失われる場合があります。
- 抽出されたテキストはモデルのコンテキストと料金を消費します。
- PDF 内の画像は、ビジョンモデルへ個別に送信する必要があります。

これは、Huawei Cloud のネイティブなファイルアップロード API やドキュメント理解 API と同じものではありません。

ドキュメント、画像、ナレッジベースの内容をアップロードする前に、データリージョン、プライバシー、組織のセキュリティ要件を満たしていることを確認してください。

## カスタムリアルタイムサービス

カスタムリアルタイムサービスでは、次の点にも注意してください。

- サービスが実行中であるか
- リソースプールと OBS が MaaS と同じリージョンにあるか
- Endpoint が Key の許可リストに含まれているか
- コンテンツ審査が有効になっているか
- QPS とタイムアウト
- コンピューティングおよびストレージ料金
- サービスのアップグレードまたは停止状態

カスタムサービスごとに Base URL が異なる場合は、URL ごとに個別のプロバイダーを作成してください。複数のモデルが同じ標準 Base URL を共有する場合は、重複して作成する必要はありません。

## よくある問題

### 401 が返される

API Key が正しくない、まだ有効になっていない、リージョンが一致しない、または IP、モデル、Endpoint が Key の許可リストに含まれていません。Key の権限を確認してから再試行してください。

### 403 が返される

IAM 認証、モデル権限、コンテンツ審査、アカウント状態のいずれかに制限があります。MaaS コンソールで具体的なエラーコードを確認してください。

### 404 が返される

Base URL、API バージョン、パス、Model ID のいずれかが正しくありません。「呼び出し説明を表示」から完全な URL をコピーし直し、規則に従って `/chat/completions` を削除してください。

### 429 が返される

MaaS、モデル、カスタムリアルタイムサービスの QPS または同時実行数の上限に達しています。同時実行数を減らして、回復するまで待機してください。

### 400 が返される

モデルが現在のメッセージロール、添付ファイル、思考パラメーターを受け付けていません。カスタムパラメーターを消去し、最小限のテキストリクエストをテストしてください。

### モデル一覧が空

カスタムサービスは `/models` を提供しない場合があります。呼び出し説明から `model` パラメーターをコピーし、手動で追加してください。

### 作成直後の Key が無効と表示される

MaaS Key は有効になるまで数分かかる場合があります。Key、リージョン、Base URL を確認してから、しばらく待って再試行してください。

### モデルごとにプロバイダーを作成する必要がありますか

必ずしも必要ではありません。同じ MaaS Standard API Base URL と Key を共有するモデルは、1 つのプロバイダーにまとめられます。呼び出しアドレスまたは認証が異なる場合に限り、分けてください。

### 古いチュートリアルで `#` の追加が必要なのはなぜですか

これは、旧版 Cherry Studio で完全なインターフェースアドレスを使用するための過去の互換設定です。V2 では、`/chat/completions` を削除した Base URL を入力し、`#` は追加しません。

### カスタムサービスは Web ページで呼び出せるが Cherry Studio では利用できない

そのサービスが OpenAI 形式ではない、旧版の AppCode または署名認証を使用している、カスタムパスを持つ、あるいは Key の許可リストに Endpoint が含まれていない可能性があります。通常のカスタムプロバイダーは、これらの差異を自動的には調整できません。

### 思考を有効にするとパラメーターエラーになる

思考設定をデフォルトに戻してください。現在の V2 には、Huawei Cloud MaaS 専用の思考パラメーターアダプターがありません。

一般的な設定については、[モデルサービス](README.md)と[モデルサービス設定](../../cherrystudio/preview/settings/providers.md)を参照してください。Huawei Cloud MaaS の現在の呼び出し方法については、[API 呼び出し仕様](https://support.huaweicloud.com/intl/zh-cn/model-call-maas/model-call-017.html)、[MaaS Standard API V2](https://support.huaweicloud.com/intl/zh-cn/model-call-maas/model-call-019.html)、[モデルサービスの呼び出し](https://support.huaweicloud.com/intl/zh-cn/inference-maas/maas-modelarts-0011.html)、[API URL 形式の説明](https://support.huaweicloud.com/intl/zh-cn/maas_faq/maas_faq_0005.html)を参照してください。フィードバック方法については、[フィードバックと提案](../../question-contact/suggestions.md)を参照してください。
