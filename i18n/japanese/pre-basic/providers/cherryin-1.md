# CherryIN

CherryIN は Cherry Studio に組み込まれたモデルプロバイダーのテンプレートで、1 つのアカウントからさまざまなモデルに接続できます。V2 では OpenAI Chat Completions と Anthropic Messages のエンドポイントが設定済みで、アカウントへのログイン、残高表示、チャージ画面、回線の切り替えも利用できます。

{% hint style="info" %}
CherryIN と [CherryAI 無料トライアル](cherryin/)は異なります。CherryIN は自分のアカウント、認証情報、残高を使用します。CherryAI はアプリ内のトライアルソースで、通常のモデルプロバイダー一覧には表示されません。
{% endhint %}

## ログイン方法を選ぶ

`設定 → モデルプロバイダー → CherryIN` を開きます。次のいずれかの方法を使用できます。

### 方法 1：CherryIN アカウントでログインする

1. **CherryIN にログイン**をクリックします。
2. ブラウザでログインと認可を完了します。
3. Cherry Studio に戻ります。
4. 画面にアカウント情報と残高が表示されることを確認します。
5. CherryIN の画面上部にあるスイッチがオンになっていることを確認します。

認可に成功すると、Cherry Studio はアカウントで利用できる API Key を取得し、OAuth で取得した Key を CherryIN の設定に追加します。チャージする場合は、アカウントカードの**チャージ**ボタンから CherryIN のコンソールを開きます。

### 方法 2：API Key を手動で入力する

1. [CherryIN Key 管理](https://open.cherryin.ai/console/token)を開きます。
2. 利用可能な Key を作成するかコピーします。
3. Cherry Studio の CherryIN ページに戻ります。
4. API Key エリアに Key を追加します。
5. プロバイダーのスイッチをオンにします。

{% hint style="danger" %}
API Key をチャットメッセージ、ドキュメント、または問題報告用のスクリーンショットに貼り付けないでください。問題を調査するときは、前後の数文字だけを残して、ほかの部分を隠してください。
{% endhint %}

## 接続回線を選ぶ

CherryIN は V2 で 3 種類のドメインを提供しています。

| 画面の選択肢 | ドメイン | 推奨用途 |
|---|---|---|
| 高速回線 | `open.cherryin.cc` | 中国本土のネットワーク環境で最初に試します |
| 国際回線 | `open.cherryin.net` | 海外または国際ネットワーク環境で最初に試します |
| 予備回線 | `open.cherryin.ai` | メイン回線へ一時的に接続できない場合に試します |

画面に回線のドロップダウンリストが表示される場合、回線を切り替えると、元のパスを維持したまま各エンドポイントのドメインが同時に変更されます。ドロップダウンリストがない場合は、API アドレスのエリアで現在の Base URL を確認できます。

{% hint style="warning" %}
回線名は設定済みの入口を示すだけで、すべてのネットワークで同じ速度になることを保証しません。選択後に接続チェックを実行し、実際の結果を確認してください。
{% endhint %}

## モデルを同期して有効にする

1. **モデルリスト**で**追加**をクリックします。
2. 同期プレビューで追加、更新、削除される項目を確認します。
3. 変更を適用します。
4. 使用するモデルを検索します。
5. 対象モデルのスイッチをオンにします。
6. モデルのヘルスチェックを実行します。

CherryIN のモデル一覧、料金、利用可能な残高は変更されることがあるため、このページでは具体的なモデルを固定して記載していません。[CherryIN のモデルと料金](https://open.cherryin.ai/pricing)を確認し、アプリで同期した結果を優先してください。

## API とモデル

CherryIN テンプレートには、OpenAI と Anthropic の互換エンドポイントが設定されています。Cherry Studio はモデル情報とエンドポイントの種類を組み合わせてリクエストを送信します。

- 通常のチャットモデルでは、一般に OpenAI 互換 API を使用します。
- Claude などのモデルでは、Anthropic 互換 API を使用できます。
- 一部の Gemini または画像モデルでは、専用ルーティングが使用されます。
- 同名モデルでも、提供するエンドポイントによって機能とパラメーターが異なる場合があります。

モデル名だけで Agent、ビジョン、推論、ツール呼び出しの機能を判断しないでください。モデルタグを確認し、実際にテストしてください。

## 設定を検証する

次の順序で確認することをおすすめします。

1. 認証エリアで接続チェックを実行します。
2. モデルリストでヘルスチェックを実行します。
3. チャット画面に戻り、対象モデルを選択します。
4. 簡単なテキストメッセージを送信します。
5. 画像またはツール呼び出しが必要な場合は、それぞれ最小限のテストを行います。

プロバイダーとモデルの両方のスイッチが有効な場合にのみ、モデル選択にモデルが表示されます。

## アカウントとログアウト

アカウントでログインすると、Cherry Studio に CherryIN のアカウント情報と残高を表示できます。**ログアウト**をクリックすると、このデバイスに保存された CherryIN の OAuth ログイン状態が消去され、OAuth で追加された Key も削除されます。

手動で追加した Key と OAuth Key は取得元が異なります。手動 Key を引き続き使用する場合は、ログアウト後も有効になっていることを確認してください。

## よくある質問

### ログイン後に Cherry Studio へ戻らない

Cherry Studio を起動したまま、ブラウザでもう一度認可を完了してください。アプリへのリンクがシステムによってブロックされた場合は、ブラウザが Cherry Studio を開くことを許可します。

### ログインに成功したが、モデルリストが空

まず**追加**をクリックします。それでも空の場合は、アカウントに利用できる Key があるか、現在の回線へ接続できるか、CherryIN のコンソールでアカウントにモデルが提供されているかを確認してください。

### 401 または 403 が返される

Key が無効、停止済み、またはモデルを使用する権限がない可能性があります。もう一度ログインするか、Key 管理ページで新しい Key を作成して置き換えてください。

### リクエストがタイムアウトする、または接続できない

高速、国際、予備のいずれかの回線に切り替え、接続チェックをもう一度実行します。システムプロキシ、ファイアウォール、ローカルネットワークも確認してください。

### Claude または Agent のリクエストに失敗する

選択したモデルにツール呼び出し機能があること、リクエストが Anthropic 互換エンドポイントを使用していることを確認してください。プロバイダーが Anthropic エンドポイントに対応していても、すべてのモデルが Agent に対応するとは限りません。

一般的な設定と複数 Key の説明は[モデルプロバイダー](README.md)と[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。それでも利用できない場合は、Cherry Studio のバージョン、OS、モデル ID、機密情報を除いたエラー内容を添えて報告してください。フィードバック先は[フィードバックとご提案](../../question-contact/suggestions.md)を参照してください。
