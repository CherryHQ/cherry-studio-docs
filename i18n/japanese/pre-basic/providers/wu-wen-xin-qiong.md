# Infini-AI GenStudio

Infini-AI GenStudio は、大規模言語モデル、ビジョンモデル、Embedding、Rerank などの API を提供します。Cherry Studio V2 には**Infini-AI（Infini）**プロバイダーが組み込まれており、OpenAI 互換インターフェースを介して接続します。

V2 のプリセット API Host：

```text
https://cloud.infini-ai.com/maas
```

Cherry Studio はリクエスト時に `/v1` を補完します。実際のチャットインターフェースは次のとおりです。

```text
https://cloud.infini-ai.com/maas/v1/chat/completions
```

{% hint style="info" %}
組み込みプロバイダーを使用する場合は、プリセットの API Host をそのまま使うことを優先してください。モデル広場、コンソール、ドキュメントページの URL を API Host に入力しないでください。
{% endhint %}

## 利用前の準備

1. Infini-AI Intelligent Computing Cloud Platform に登録してログインします。
2. 現在のアカウントが属するテナントを確認します。
3. GenStudio API Key を作成します。
4. サービス一覧またはモデル広場で対象モデルの Model ID を確認します。
5. モデルの料金、サービスレベル、レート制限を確認します。
6. アカウント残高または購入済みのパッケージ同時実行サービスが利用可能であることを確認します。

モデル、料金、制限は変更されることがあります。本書では「無料モデル」やボーナスクォータを固定情報として掲載しません。[サービス一覧](https://cloud.infini-ai.com/genstudio/usage/limit)と[プリセットモデル一覧](https://docs.infini-ai.com/gen-studio/models/supported-models.html)で最新情報を確認してください。

## API Key の取得

1. [Intelligent Computing Cloud Platform](https://cloud.infini-ai.com/)にログインします。
2. [API Key 管理](https://cloud.infini-ai.com/iam/secret/key)を開きます。
3. 新しい GenStudio API Key を作成します。
4. 完全なキーをコピーします。
5. 安全なパスワード管理ツールに保存します。

現在、GenStudio は `sk-` で始まる API Key を使用し、Bearer 認証でリクエストを送信します。

{% hint style="danger" %}
API Key はアカウントの認証情報に相当します。チャット、ドキュメント、コードリポジトリ、スクリーンショット、サポートチケットに記載しないでください。漏えいした場合は、直ちに削除して再作成してください。
{% endhint %}

## Cherry Studio での設定

1. `設定 → モデルサービス`を開きます。
2. 左側のフィルターを**すべてのプロバイダー**に切り替えます。
3. **Infini-AI / Infini**を選択します。
4. API Key 欄に GenStudio のキーを貼り付けます。
5. API Host は `https://cloud.infini-ai.com/maas` のままにします。
6. ページ上部のプロバイダースイッチをオンにします。
7. **追加**をクリックするか、モデルを同期します。
8. 同期プレビューを確認して変更を適用します。
9. 使用するモデルだけを有効にします。
10. モデルのヘルスチェックを実行します。

ヘルスチェックの成功は、現在の Key、アドレス、テストモデルで基本リクエストが完了したことだけを示します。アカウントがリスト内のすべてのモデルへのアクセス権を持つとは限りません。

## モデルの同期と追加

Cherry Studio は、次の OpenAI 互換モデル一覧インターフェースを使用します。

```text
GET /maas/v1/models
```

同期後の推奨手順：

1. 追加、更新、削除される項目を確認します。
2. Model ID がサービス一覧と完全に一致することを確認します。
3. 同期結果を適用します。
4. 提供終了になった古いモデルを削除します。
5. チャット、Embedding、Rerank モデルを個別にテストします。

同期に失敗した場合は、サービス一覧またはモデル広場から Model ID をコピーして手動で追加できます。Model ID の大文字・小文字、ハイフン、バージョンサフィックス、`pro-` プレフィックスは、すべて識別子の一部です。

{% hint style="warning" %}
パッケージ同時実行サービスでは、通常 `pro-` で始まる専用の Model ID を使用します。通常の従量課金モデルとパッケージ同時実行モデルを同じ ID として扱わないでください。
{% endhint %}

V2 の組み込み候補モデルは、プラットフォームの現在のリストより古い場合があります。実際に使用する際は、リアルタイムの同期結果とサービス一覧を優先してください。

## チャットモデルの選択

GenStudio のチャットモデルは、OpenAI 互換の Chat Completions を使用します。

初回テストの推奨手順：

1. 現在のアカウントで明確に利用可能なモデルを選択します。
2. 短いテキストメッセージを送信します。
3. ストリーミング出力を確認します。
4. システムプロンプトを追加します。
5. その後、長いコンテキスト、思考、画像、ツール呼び出しをテストします。

モデルシリーズとバージョンは更新されます。古いチュートリアルの固定例に依存せず、サービス一覧から現在の Model ID を直接コピーしてください。

## ビジョンモデル

画像を理解できるのは、GenStudio が明確に視覚言語モデルとして指定している Model ID だけです。

Cherry Studio では、次の手順で確認します。

1. 最新のモデルを同期します。
2. モデル詳細に画像入力機能が含まれていることを確認します。
3. まず小さな画像を 1 枚アップロードします。
4. 画像から直接確認できる内容について質問します。
5. 成功を確認してから、複数画像または高解像度画像を試します。

同じシリーズでも、テキストモデルとビジョンモデルでは異なる Model ID を使用する場合があります。モデル名が似ていても、入力モダリティが同じとは限りません。

## 思考モード

GenStudio は複数の推論モデルを提供しており、シリーズごとに異なる思考パラメーターとレスポンス形式を使用する場合があります。Cherry Studio は、認識したモデルシリーズに応じて一般的なアダプターを適用しますが、現在の Infini-AI プロバイダーには独立した思考パラメーターのパネルがありません。

推論モデルを初めて使用する場合：

1. 思考設定を**デフォルト**のままにします。
2. カスタムリクエストパラメーターを追加しません。
3. 基本的なチャットが正常に動作することを確認します。
4. その後、思考の有効化または無効化を試します。
5. モデル詳細と照合して、対応パラメーターを確認します。

思考を有効にした後に 400 が返された場合は、Model ID を繰り返し変更するのではなく、まずデフォルト設定に戻してください。

## MCP とツール呼び出し

GenStudio の一部のモデルは Function Calling に対応しています。Cherry Studio は Chat Completions を介して MCP ツールの定義をモデルへ送信できますが、安定して呼び出せるかどうかは具体的なモデルによって異なります。

次の順序で確認することをおすすめします。

1. 通常のチャットが動作することを確認します。
2. パラメーターが単純な MCP ツールを 1 つだけ有効にします。
3. モデルにそのツールを呼び出すよう明示的に指示します。
4. 構造化されたツール呼び出しが生成されているか確認します。
5. ツールの結果が返されることを確認します。
6. その後、ツールを段階的に追加します。

モデルが「ツールを呼び出す」とテキストで説明するだけでは、実際の呼び出しではありません。この場合は、モデル詳細、ツール定義、プロンプトを確認してください。

## Embedding とナレッジベース

GenStudio は、次の OpenAI 互換 Embedding インターフェースを提供します。

```text
POST /maas/v1/embeddings
```

現在のサービスでは `bge-m3` などのベクトルモデルが提供される場合がありますが、実際の Model ID はサービス一覧を基準にしてください。Cherry Studio は、モデル ID と手動で設定したタイプラベルから Embedding モデルを識別します。

ナレッジベースを作成する前に：

1. Embedding モデルを同期または手動追加します。
2. モデルが**埋め込み**タイプとして認識されていることを確認します。
3. ヘルスチェックを実行します。
4. ベクトル次元を検出します。
5. 少量のドキュメントでテスト用ナレッジベースを作成します。
6. 検索結果を確認してから一括インポートします。

ベクトル次元はナレッジベースのインデックスの一部です。ナレッジベースの作成後に Embedding モデルまたは次元を変更すると、通常はインデックスの再構築が必要です。

## Rerank

GenStudio は、次の Rerank インターフェースを提供します。

```text
POST /maas/v1/rerank
```

現在の公式例では `bge-reranker-v2-m3` が使用されていますが、利用可能かどうかは引き続きサービス一覧を基準にしてください。

Cherry Studio では、次の手順で設定します。

1. Rerank モデルを同期または手動追加します。
2. モデルが**再ランキング**タイプとして認識されていることを確認します。
3. ナレッジベース設定でそのモデルを選択します。
4. 少量のクエリで、有効化前後の結果を比較します。
5. その後、正式なナレッジベースで使用するかどうかを決定します。

Embedding と Rerank は、異なるモデルとエンドポイントを使用します。Embedding が利用できても Rerank が利用できるとは限らないため、個別に確認してください。

## 画像と動画の生成

GenStudio プラットフォームでは画像と動画の生成機能も提供されていますが、現在 Cherry Studio V2 に組み込まれている Infini-AI プロバイダーは、主に OpenAI 互換のチャット、Embedding、Rerank インターフェースとして動作し、Infini-AI 専用の画像または動画生成の転送レイヤーは登録されていません。

そのため、次の点に注意してください。

- 画像または動画生成モデルをチャットモデルとして追加しないでください。
- Cherry Studio の描画ページで実際に選択できるプロバイダーとモデルを基準にしてください。
- 公式サイトに生成モデルが存在しても、現在の V2 が対応済みとは限りません。

## PDF と添付ファイル

Cherry Studio V2 は、まずローカルで PDF のテキストを抽出し、その結果をチャットモデルへ送信します。

- テキスト形式の PDF は通常そのまま処理できます。
- スキャンされた文書には、先に OCR が必要です。
- 表、複雑なレイアウト、画像の情報は失われる場合があります。
- 抽出されたテキストはモデルのコンテキストと Token を消費します。
- PDF 内の画像は、ビジョンモデルへ個別に送信する必要があります。

Infini-AI はクラウドサービスです。ドキュメント、画像、ナレッジベースの内容をアップロードする前に、プライバシー、著作権、組織のセキュリティ要件を満たしていることを確認してください。

## 課金とレート制限

GenStudio の API 呼び出しは、アカウントのサービスレベル、モデル料金、頻度制限の影響を受けます。プラットフォームでは、次の項目が同時に制限される場合があります。

- RPM：1 分あたりのリクエスト数
- RPD：1 日あたりのリクエスト数
- TPM：1 分あたりの Token 数
- パッケージ同時実行サービスの同時実行スロット

現在の課金と制限は今後変更される場合があります。自動タスクを本番運用する前に：

1. 最新の課金規則を確認します。
2. アカウント残高を確認します。
3. 同時実行数と再試行回数の上限を設定します。
4. Token 使用量を監視します。
5. 429 が発生した場合は、バックオフして再試行します。
6. 問題調査に備えて、レスポンスの `id` と `traceresponse` を保存します。

複数の Key を作成してテナント単位の制限を回避しないでください。同じテナント内の Key はクォータを共有する場合があります。

## よくある問題

### 401 が返される

API Key が正しくない、削除済み、コピー時に空白が入った、またはリクエストで Bearer 認証が正しく使用されていません。Key をコピーし直すか、再作成してください。

### 403 が返される

アカウント、テナント、対象モデルへの権限がありません。モデルの利用申請が必要か、アカウントの状態、現在のテナントを確認してください。

### 404 が返される

API Host、インターフェースパス、Model ID のいずれかが正しくありません。組み込みのプリセットアドレスに戻し、サービス一覧から完全な Model ID をコピーしてください。

### 429 が返される

RPM、RPD、TPM、パッケージ同時実行数のいずれかの上限に達しています。同時実行数を減らし、コンテキストを短くして、回復するまで待機してください。

### 400 が返される

モデルが現在のパラメーター、画像形式、思考設定に対応していません。カスタムパラメーターを消去し、思考設定をデフォルトに戻してから再テストしてください。

### モデル一覧が空

API Key、API Host、ネットワークプロキシ、テナント権限を確認してください。サービス一覧から Model ID をコピーして手動で追加することもできます。

### プリセットモデルを呼び出せない

V2 の組み込み候補は、すでに提供終了、名称変更、または現在のアカウントの権限外になっている場合があります。最新のリストを同期して、無効なモデルを削除してください。

### パッケージ同時実行モデルの呼び出しに失敗する

購入状態が現在も有効であることを確認し、プラットフォームから割り当てられた完全な専用 Model ID を使用してください。`pro-` プレフィックスを削除しないでください。

### Embedding モデルがチャット一覧に表示される

モデルタイプのラベルを確認してください。Model ID にはプラットフォームが提供する完全な名前を使用し、モデル管理で通常のチャットモデルではなく Embedding として設定します。

### Rerank のヘルスチェックが実行されない

現在の V2 の一般的なモデル接続チェックでは、Rerank がスキップされます。ナレッジベースの検索フローで、実際の再ランキングリクエストを検証してください。

### ファイルをアップロードすると未対応エラーが返される

まずファイルからテキストが正常に抽出されたことを確認し、次に現在のチャットモデルがその入力に対応しているか確認してください。スキャン PDF には OCR が必要で、画像にはビジョンモデルが必要です。

一般的な設定については、[モデルサービス](README.md)と[モデルサービス設定](../../cherrystudio/preview/settings/providers.md)を参照してください。Infini-AI の現在の機能と設定については、[GenStudio API クイック統合](https://docs.infini-ai.com/gen-studio/api/get-started/)、[Cherry Studio 統合チュートリアル](https://docs.infini-ai.com/gen-studio/integrations/use-cherrystudio.html)、[プリセットモデル一覧](https://docs.infini-ai.com/gen-studio/models/supported-models.html)、[Rerank チュートリアル](https://docs.infini-ai.com/gen-studio/api/retrieval/tutorial-rerank.html)、[課金規則](https://docs.infini-ai.com/gen-studio/api/usage-and-billing/billing.html)、[呼び出し制限](https://docs.infini-ai.com/gen-studio/api/usage-and-billing/rate-limit.html)を参照してください。フィードバック方法については、[フィードバックと提案](../../question-contact/suggestions.md)を参照してください。
