# Qwen3-8B

Cherry Studio は、複数のプロバイダーが提供する Qwen3-8B を識別できます。一部のバージョンでは `Qwen/Qwen3-8B` がアプリ内のトライアルモデルとして提供され、サービスの入口が CherryIN にリンクされます。別のプロバイダーが同じモデル ID または異なる ID を使用する場合もあります。

{% hint style="warning" %}
モデルがトライアルリストに表示されても、長期間無料で提供されるとは限りません。モデル選択の**無料**ラベル、プロバイダーのコンソール、実際のリクエスト結果を確認してください。
{% endhint %}

## すでに利用できるか確認する

1. チャット画面でモデル選択を開きます。
2. `Qwen3-8B` を検索するか、**無料**タグを有効にします。
3. モデルの提供元を確認します。
4. モデルを選択して、簡単なテストメッセージを送信します。

トライアルタグの横に CherryIN と表示されている場合は、そのタグをクリックすると該当するプロバイダー設定へ移動できます。CherryAI 自体は、通常のモデルプロバイダー一覧には表示されません。

## プロバイダー経由で接続する

モデル選択に Qwen3-8B がない場合は、次の手順を行います。

1. `設定 → モデルプロバイダー` を開きます。
2. ModelScope、OpenRouter、またはアカウントでこのモデルを提供している別のプロバイダーを選択します。
3. API Key を入力し、Base URL を確認します。
4. **追加**をクリックして、モデルの変更を適用します。
5. Qwen3-8B を検索して有効にします。
6. 接続チェックまたはモデルのヘルスチェックを実行します。

一部のプロバイダーは `Qwen/Qwen3-8B` を使用し、別のプロバイダーは `qwen/qwen3-8b` を使用します。大文字と小文字、名前空間、接尾辞の違いがルーティングに影響する場合があります。

## 同期できない場合に手動で追加する

プロバイダーがモデルリスト API を提供していない場合は、**カスタム**をクリックし、そのプロバイダーのコンソールまたは API ドキュメントに記載された完全なモデル ID をコピーします。

{% hint style="danger" %}
別のプラットフォームのモデル ID をそのままコピーしないでください。名前が同じでも、プロバイダーによって名前空間、機能設定、API パスが異なる場合があります。
{% endhint %}

## 推論とツール呼び出し

Qwen3 シリーズは、制御可能な推論に対応する場合があります。Cherry Studio はプロバイダーの機能に応じて `enable_thinking` パラメーターを使用するか、そのパラメーターに対応していない API では互換方式で思考モードを制御します。

使用時は次の点をおすすめします。

- モデル選択に推論機能が表示されている場合にのみ、思考設定を使用します。
- MCP などのツールを使用する場合は、まずツール呼び出しのタグを確認し、簡単なテストを 1 回行います。
- `/think` や `/no_think` をすべてのプロンプトに手動で固定せず、Cherry Studio の思考設定を優先します。
- 同名モデルが複数のプロバイダーから提供されている場合は、それぞれの推論とツール呼び出しを検証します。

## よくある質問

### 「無料」フィルターに Qwen3-8B がない

現在のバージョンまたは地域では、そのトライアルモデルが提供されていない可能性があります。その場合も、対応するプロバイダーを設定して自分の API Key で使用できます。

### トライアルの印をクリックすると CherryIN が開く

これは想定された動作です。V2 は特定の Qwen トライアルモデルのサービス入口を CherryIN にリンクし、トライアル利用枠の終了後にプロバイダーを設定しやすくしています。

### 思考モードが変化しない

プロバイダーが `enable_thinking` に対応しているか、現在のモデルが推論を切り替えられる派生版かを確認してください。一部のエンドポイントは、対応していないパラメーターを無視します。

### 「モデルが存在しません」と返される

大文字と小文字を含む完全なモデル ID を確認して、リストを再同期してください。手動で追加した項目の場合は、現在のプロバイダーから提示された ID に置き換えます。

無料トライアルの一般的なルールは [CherryAI（無料トライアル）](README.md)、プロバイダーの設定手順は[モデルプロバイダー](../README.md)を参照してください。
