# CherryAI（無料トライアル）

CherryAI は Cherry Studio に組み込まれたクラウドトライアルサービスです。アプリとともに自動的に有効になり、事前に API Key を入力する必要がないため、初回インストール後すぐにチャットやモデル選択を試すことができます。

{% hint style="info" %}
CherryAI はアプリ内のトライアルサービスです。[CherryIN](../cherryin-1.md) は API Key を設定できるモデルプロバイダーです。名称は似ていますが、入口、利用枠、設定方法が異なります。
{% endhint %}

## すぐに使い始める

1. [チャット画面](../../../cherrystudio/preview/chat.md)を開きます。
2. 入力欄またはアシスタントのタイトルバーにあるモデル名をクリックして、モデル選択を開きます。
3. `CherryAI` を検索するか、**無料**タグで利用できるトライアルモデルを絞り込みます。
4. モデルを選択してメッセージを送信します。

CherryAI のモデルには、モデル選択でトライアルサービスの印が表示されます。利用できるモデルはアプリのバージョンやサービスの状態によって変わることがあるため、アプリ内に実際に表示される一覧を確認してください。

## 「モデルプロバイダー」に CherryAI が表示されない理由

これは正常な動作です。V2 では CherryAI が選択可能なモデルソースとして追加されますが、`設定 → モデルプロバイダー` の通常のプロバイダー一覧には意図的に表示されません。CherryAI の API Key や Base URL をユーザーが変更することもできません。

自分のアカウントと利用枠で安定して使用する場合は、[モデルプロバイダー](../README.md)の手順に従って CherryIN、モデル提供元の公式 API、ローカルモデル、または別のゲートウェイを設定してください。

## 無料利用枠

CherryAI のリクエストにはトライアル利用枠が使われます。利用枠を使い切ると、アプリに案内が表示されます。その場合は次のいずれかを行います。

- トライアル利用枠が回復してから再度使用する
- 設定して有効にした別のモデルへ切り替える
- 案内に従って、該当するプロバイダーに自分の API Key を設定する

{% hint style="warning" %}
無料利用枠、回復時期、利用可能なモデルは変更される場合があります。このページでは固定の利用枠を保証していません。トライアルサービスを本番タスク、長期的な自動処理、または唯一利用できるモデルとして使うこともおすすめしません。
{% endhint %}

## 利用上の制限

- **設定不要でもオフラインではありません**：メッセージは CherryAI のクラウド API に送信されます。
- **モデルごとに機能が異なります**：ビジョン、推論、ウェブアクセス、ツール呼び出しなどの対応は、モデルタグと実際の応答で確認してください。
- **プロバイダーページは編集できません**：モデル選択には CherryAI が表示され、モデルプロバイダー設定には表示されないのが想定された動作です。
- **トライアルモデルは変更される場合があります**：アシスタントに保存したモデルが提供終了になった場合は、モデル選択を開き直して別のモデルに変更してください。

## 自分のモデルと併用する

まず CherryAI で初回体験を済ませ、その後に自分のプロバイダーを設定できます。設定後は次の操作を行います。

1. モデルプロバイダーページで、対象のプロバイダーとモデルを有効にします。
2. モデル選択に戻り、新しいモデルを選びます。
3. 必要に応じて、[デフォルトモデル設定](../../../cherrystudio/preview/settings/default-models.md)でデフォルト、クイック、翻訳、トピック名生成用のモデルを指定します。

これにより、トライアル利用枠が一時的に使えない場合でも、自分のモデルへ直接切り替えられます。

CherryAI がモデル選択に表示されない場合や、すべてのトライアルモデルでリクエストに失敗する場合は、まずネットワーク接続を確認してアプリを再起動してください。それでも利用できない場合は、Cherry Studio のバージョン、OS、機密情報を除いたエラー内容を添えて報告してください。フィードバック先は[フィードバックとご提案](../../../question-contact/suggestions.md)を参照してください。
