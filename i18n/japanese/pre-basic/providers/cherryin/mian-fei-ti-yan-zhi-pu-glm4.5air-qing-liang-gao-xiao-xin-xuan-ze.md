# ZhiPu GLM-4.5-Air

Cherry Studio は、複数のプロバイダーが提供する GLM-4.5-Air と一般的な派生モデルを識別できます。標準モデルはテキスト推論とツール呼び出しに対応するモデルとして識別されます。これらの機能が実際に提供されるかは、プロバイダーの API と実際のテスト結果を確認してください。

{% hint style="warning" %}
このページでは、GLM-4.5-Air が CherryAI または CherryIN の無料トライアルモデルとして常に提供されることを保証しません。モデルが無料か、現在も利用できるかは、モデル選択、プロバイダーのコンソール、実際のリクエスト結果を確認してください。
{% endhint %}

## すでに利用できるか確認する

1. チャット画面でモデル選択を開きます。
2. `GLM-4.5-Air` を検索します。
3. モデルの提供元と機能タグを確認します。
4. モデルを選択して、簡単なテストメッセージを送信します。

同名の項目が複数ある場合は、プロバイダー名と完全なモデル ID で区別してください。

## プロバイダー経由で接続する

モデル選択に GLM-4.5-Air がない場合は、次の手順を行います。

1. `設定 → モデルプロバイダー` を開きます。
2. ZhiPu、またはアカウントでこのモデルを提供している集約プロバイダーを選択します。
3. API Key を入力し、Base URL を確認します。
4. **追加**をクリックして、モデルの変更を適用します。
5. GLM-4.5-Air を検索して有効にします。
6. 接続チェックまたはモデルのヘルスチェックを実行します。

Cherry Studio のモデルレジストリには、複数のプロバイダーで使われている GLM-4.5-Air の識別情報が含まれます。これらのマッピングはモデルを識別するためのもので、アカウントに利用権限や無料利用枠があることを示すものではありません。

## 適切な派生モデルを選ぶ

プロバイダーは、標準版、AirX、FP8、または `free` 接尾辞を持つ項目を提供する場合があります。

- 標準版、AirX、FP8 は、それぞれ異なるモデルまたはデプロイです。
- `free` は、そのプロバイダーがモデル ID に無料の印を付けていることだけを示し、永久無料という意味ではありません。
- 同名モデルでも、コンテキスト、速度、ツール呼び出し、推論制御はエンドポイントによって異なる場合があります。
- あるプロバイダーのモデル ID を別のプロバイダーへそのままコピーしないでください。

{% hint style="danger" %}
現在のプロバイダーのコンソールまたは API ドキュメントからモデル ID をコピーしてください。似ていても実際には対応していない ID を手動で入力すると、404 または「モデルが存在しません」と返されます。
{% endhint %}

## 推論とツール呼び出し

モデル選択に推論機能が表示される場合は、チャットで Cherry Studio の思考設定を使用できます。プロバイダーによって、パラメーター、モデルの派生版、プロンプトなど、推論の制御方法が異なる場合があります。Cherry Studio はプロバイダーの設定に応じて適切な方法を選択します。

MCP などのツールを使用する場合は、次の手順を行います。

1. モデルにツール呼び出し機能のタグが付いていることを確認します。
2. 簡単で結果を検証できるツールを 1 つ有効にします。
3. 明確な指示を送信し、モデルが実際に呼び出しを開始するか確認します。
4. 呼び出し計画だけを出力して実行しない場合は、プロバイダーのエンドポイントとモデル機能を確認します。

## よくある質問

### 思考スイッチが見つからない

現在のプロバイダーまたはモデルの派生版が、制御可能な推論に対応していない可能性があります。モデルを再同期して機能タグを確認してください。モデル名だけで判断しないでください。

### ツール呼び出しの形式が正しくない

プロバイダーのエンドポイントまたはモデルの派生版を変更して、再試行してください。集約ゲートウェイによって、ツール呼び出しパラメーターへの対応状況が異なる場合があります。

### 401、403、または残高不足が返される

API Key、モデルの権限、アカウント残高、地域制限を確認してください。トライアル利用枠を使い切った場合は、自分の認証情報を設定するか、別のモデルへ切り替えてください。

### モデル ID が存在しない

手動で追加した誤った項目を削除し、リストを再同期するか、プロバイダーのドキュメントに記載された完全なモデル ID を使用してください。

無料トライアルの一般的なルールは [CherryAI（無料トライアル）](README.md)、プロバイダーの設定手順は[モデルプロバイダー](../README.md)を参照してください。
