# モデルプロバイダー

モデルプロバイダーを設定すると、Cherry Studio をクラウドモデルプラットフォーム、ローカル推論サービス、またはセルフホスト型ゲートウェイに接続できます。設定後、アシスタント、翻訳、ナレッジベースなどの機能でモデルを選択できるようにするには、プロバイダーのモデルリストで使用するモデルを有効にする必要があります。

{% hint style="info" %}
利用するプロバイダーが決まっている場合は、該当する[プロバイダー設定ガイド](#プロバイダー設定ガイド)に進んでください。対応状況をすぐに比較するだけなら、[全 Provider クイックリファレンス](quick-reference.md)を参照してください。
{% endhint %}

## 始める前の準備

プロバイダーの種類に応じて、次の情報を準備してください。

- **クラウドモデルプラットフォームまたは集約ゲートウェイ**：API Key、およびアカウントで利用可能になっているモデル
- **セルフホスト型ゲートウェイ**：API Key、Base URL、およびゲートウェイが対応する API プロトコル
- **ローカル推論サービス**：起動済みのサービスアドレス、およびダウンロード済みまたは読み込み済みのモデル
- **クラウドプラットフォーム専用接続**：リージョン、プロジェクト、デプロイ名、クラウドアカウントの認証情報などが必要になる場合があります

認証方式とアドレス構成はプロバイダーごとに異なります。まず Cherry Studio に組み込まれているプロバイダーテンプレートを使用してください。目的のプロバイダーが一覧にない場合や、セルフホストした互換 API に接続する場合にのみ、カスタムプロバイダーを作成します。

## プロバイダーを設定する

### 1. プロバイダーを探す、または追加する

`設定 → モデルプロバイダー` を開きます。

左側のリストには、初期状態では有効なプロバイダーが表示されます。ここでは次の操作ができます。

- プロバイダー名またはモデル名を検索する
- **有効**、**無効**、**すべてのプロバイダー**、または Agent API に対応するプロバイダーで絞り込む
- プロバイダーをドラッグして並べ替える
- 検索ボックス右側の `+` をクリックしてカスタムプロバイダーを作成する
- プロバイダーの右クリックメニューから、管理可能な項目を編集、複製、または削除する

{% hint style="warning" %}
「Agent」フィルターは、そのプロバイダーに現在の Agent 機能が必要とする互換エンドポイントがあることだけを示します。プロバイダー内のすべてのモデルがツール呼び出しに対応するわけではありません。実際の機能は、選択したモデルとプロバイダーによって異なります。
{% endhint %}

### 2. 認証情報と API アドレスを入力する

プロバイダーを選択し、右側で認証を設定します。

1. API Key を入力するか、画面の案内に従って OAuth、AWS、Azure、Google Cloud などの専用認証を完了します。
2. Base URL を確認します。組み込みテンプレートを使用する場合、通常は既定のアドレスを変更する必要はありません。
3. プロバイダーが複数のプロトコルを提供している場合は、API 設定で OpenAI Chat Completions、Anthropic Messages、Google Generate Content、または OpenAI Responses の各エンドポイントを個別に設定できます。
4. 画面上部にあるプロバイダーのスイッチをオンにします。

カスタムプロバイダーでは、初期状態で **OpenAI Chat Completions** が主要 API として使用されます。「その他のエンドポイント」を展開して、別の互換 API を追加することもできます。詳しいルールは[カスタムプロバイダー](zi-ding-yi-fu-wu-shang.md)を参照してください。

{% hint style="danger" %}
API Key は機密性の高い認証情報です。実際の Key をドキュメント、チャット、または問題報告用のスクリーンショットに含めないでください。問題を調査するときは、前後の数文字だけを残して、ほかの部分を隠してください。
{% endhint %}

### 3. モデルを同期して有効にする

**モデルリスト**では、次の操作を行います。

1. **追加**をクリックして、プロバイダーから現在利用できるモデルを同期します。
2. 同期プレビューで追加、更新、削除される項目を確認し、変更を適用します。
3. API がモデルリストの取得に対応していない場合は、**カスタム**をクリックしてモデル ID を手動で入力します。
4. 使用するモデルのスイッチをオンにします。

モデルリストでは名前による検索のほか、ビジョン、推論、ツール呼び出しなどの機能による絞り込みもできます。機能タグは主にプロバイダーの情報と Cherry Studio のモデルルールに基づいています。自動判定が正確でない場合は、モデルを編集して手動で調整できます。

### 4. 接続を確認する

設定後は、次の 2 種類の確認を行うことをおすすめします。

- 認証エリアで接続チェックを開始し、設定済みのモデルと API Key を選択してリクエストを検証する
- モデルリストでヘルスチェックを実行し、有効にしたモデルへアクセスできるかまとめて確認する

チェックに成功したら、アシスタントを新規作成するか既存のアシスタントを開き、モデル選択で有効にしたモデルを選んでテストメッセージを送信します。

## 接続方法の選び方

| 利用シーン | 推奨する方法 | 説明 |
|---|---|---|
| OpenAI、Anthropic、DeepSeek などの公式 API を使用する | 対応する組み込みテンプレートを選択する | 既定のアドレスと API タイプが設定済みです |
| 1 つの Key で複数のモデルプロバイダーを使用する | 集約プロバイダーまたはゲートウェイのテンプレートを選択する | モデル、料金、利用可能な地域は、そのプラットフォームによって決まります |
| NewAPI、OneAPI などのセルフホスト型ゲートウェイに接続する | 対応するテンプレートを優先して使用する | デプロイ先のパスが異なる場合は Base URL を変更します |
| Ollama、LM Studio などのローカルサービスを使用する | ローカルサービスのテンプレートを選択する | 先にローカルサービスが起動し、ポートにアクセスできることを確認します |
| 一覧にない互換 API に接続する | カスタムプロバイダーを作成する | プロトコル、Base URL、モデル ID の確認が必要です |

{% hint style="info" %}
1 つのプロバイダーに複数の API Key を設定でき、リクエスト先やパラメーターも細かく調整できます。[モデルプロバイダー設定](../../cherrystudio/preview/settings/providers.md)を参照してください。
{% endhint %}

## よくある質問

### モデルを同期できない

まず、API Key、Base URL、API プロトコルが一致していることを確認してください。一部のプロバイダーはモデルリスト API を提供していません。その場合は、プロバイダーのコンソールに表示されるモデル ID を手動で追加します。

### モデル選択にモデルが表示されない

画面上部のプロバイダースイッチと、対象モデルのスイッチがどちらもオンになっていることを確認してください。モデルを同期済みでも無効になっている場合は、選択できるモデルとして表示されません。

### 401 または 403 が返される

通常は、API Key が無効である、権限が不足している、アカウントで対象モデルが有効になっていない、またはプロバイダーが接続元を制限していることを示します。プロバイダーのコンソールで、認証情報の状態とモデルの権限を確認してください。

### 404 またはプロトコルエラーが返される

Base URL のパスが重複または欠落していないか、プロバイダーが実際に対応する API プロトコルを選択しているかを重点的に確認してください。ゲートウェイを使用している場合は、選択したモデルのエンドポイントにゲートウェイが対応していることも確認します。

### ローカルモデルへの接続がタイムアウトする

ローカル推論サービスが実行中で、リッスンアドレスとポートが Cherry Studio の設定と一致していることを確認してください。サービスがコンテナ、仮想マシン、または別のデバイスで動作している場合は、ネットワークとファイアウォールからアクセスが許可されていることも確認します。
