# プロンプトとクイック挿入

プロンプトには、文章作成の条件、分析の手順、回答形式など、繰り返し入力する内容を保存できます。保存したプロンプトは会話入力欄からすぐに検索して挿入できるため、毎回入力し直す必要がありません。

Cherry Studio V2 では、このような内容を旧バージョンの「クイックフレーズ」に代わり、「プロンプト」として一元管理します。

## プロンプトを新規作成する

### リソースライブラリから作成する

1. [リソースライブラリ](../../cherrystudio/preview/library.md)を開きます。
2. 左側で **プロンプト** を選択します。
3. 新規作成ボタンをクリックし、名前と内容を入力します。
4. 保存ボタンをクリックします。

名前は検索や識別に使用され、内容は会話入力欄に挿入される実際のテキストです。保存したプロンプトは、リソースライブラリと会話入力欄のプロンプト一覧に表示されます。

### 入力欄から作成する

1. 会話入力欄の下にある稲妻アイコンをクリックして、プロンプト一覧を開きます。
2. 一覧の下部にある「プロンプトを追加…」を選択します。
3. 名前と内容を入力して保存します。

既存のプロンプトを編集または削除する場合は、リソースライブラリを使用してください。

## 入力欄にプロンプトを挿入する

次のいずれかの方法でプロンプト一覧を開けます。

* 会話入力欄の下にある稲妻アイコンをクリックする。
* 入力欄に `/` と入力してクイックメニューを開き、「プロンプト管理」を選択する。

一覧からプロンプトを検索して選択すると、Cherry Studio がプロンプトの本文を現在のカーソル位置に挿入します。テキストを選択した状態で稲妻アイコンから挿入すると、選択部分が置き換わります。`/` からクイックメニューを開いた場合は、メニューの起動と検索に入力した文字列が置き換わります。

挿入後も内容を編集してからモデルに送信できます。

## 変数について

プロンプトエディターでは、プレースホルダーとして `${variable}` を挿入できます。現在のバージョンでは、この文字列をそのまま保存して入力欄に挿入し、値を自動入力することはありません。

入力欄で Tab キーを押すと、次の `${...}` プレースホルダーが選択されます。最後のプレースホルダーの後は最初に戻ります。選択されたプレースホルダーは、必要な内容に手動で置き換えてください。

{% hint style="warning" %}
メッセージを送信する前に、`${variable}` を実際の内容に手動で置き換えてください。パスワード、API キー、その他の機密情報をプロンプトに保存しないでください。
{% endhint %}

## 使い方のヒント

* 「製品ドキュメントを確認する」「会議の要約を作成する」など、タスクが分かる名前を付けます。
* 毎回共通する条件をプロンプトに保存し、その都度変わる情報は挿入後に追加します。
* 使用しなくなったプロンプトや内容が重複するプロンプトを定期的に整理し、検索結果を分かりやすく保ちます。
