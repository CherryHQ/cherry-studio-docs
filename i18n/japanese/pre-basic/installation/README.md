# インストールガイド

このページでは、Cherry Studio の一般的なインストール手順を説明し、お使いの OS に対応する詳しいガイドを紹介します。まだインストールパッケージを入手していない場合は、先に[クライアントのダウンロード](../../cherrystudio/download.md)を開いてください。

## インストール前の準備

1. インストールパッケージが Cherry Studio 公式サイト、または公式の `CherryHQ/cherry-studio` GitHub Releases から取得したものであることを確認します。
2. OS と CPU アーキテクチャを確認し、x64、ARM64、amd64、aarch64 のパッケージを取り違えないようにします。
3. 実行中の Cherry Studio を終了します。
4. アップグレード、ダウングレード、プレビュー版のテストを行う場合は、先に **設定 → データ設定**でバックアップを作成します。

{% hint style="warning" %}
バックアップを作成せずに、新しいバージョンから古いバージョンへダウングレードしないでください。新しいバージョンによってローカルデータベースや設定が移行されている場合、古いバージョンでは移行後のデータを読み取れない可能性があります。
{% endhint %}

## Windows

Windows では、インストール版とポータブル版が提供されています。

* **Setup インストール版**：ウィザードに従ってインストール先を選び、インストールを完了します。大半のユーザーに適しています。
* **Portable ポータブル版**：実行ファイルを直接起動します。一時的な使用や、インストール処理を行いたくない場合に適しています。

Cherry Studio は Windows 7 に対応していません。初回起動時にシステム保護の警告が表示された場合は、インストールパッケージの提供元とファイルダイジェストを確認してから、[Windows インストールガイド](windows.md)に従ってください。

## macOS

1. お使いのチップに合う `.dmg` をダウンロードします。Apple チップでは `arm64`、Intel チップでは `x64` を選択します。
2. DMG を開き、Cherry Studio を「アプリケーション」へドラッグします。
3. 「アプリケーション」から起動します。

macOS では、初回起動時に開発元の検証やセキュリティに関する警告が表示される場合があります。対処方法は、[macOS インストールガイド](macos.md)を参照してください。

## Linux

Linux の Release では通常、AppImage、deb、rpm の 3 形式が提供されます。いずれか 1 つを選択し、複数の形式を重複してインストールしないでください。

### AppImage

```bash
chmod +x ./Cherry-Studio-*.AppImage
./Cherry-Studio-*.AppImage
```

AppImage はシステムへのインストールを必要としません。起動できない場合は、まずファイルのアーキテクチャが正しいか確認してください。一部のディストリビューションでは、AppImage に必要な FUSE 互換コンポーネントのインストールも必要です。

### Debian / Ubuntu

```bash
sudo apt install ./Cherry-Studio-*-amd64.deb
```

ARM64 デバイスでは、ファイル名に `arm64` を含む deb パッケージを使用してください。

### Fedora / RHEL / Rocky Linux

```bash
sudo dnf install ./Cherry-Studio-*.rpm
```

お使いのデバイスに応じて、`x86_64` または `aarch64` のパッケージを選択します。

## アップグレード

同じ OS とアーキテクチャで新しい安定版をインストールする場合、通常はローカルデータが保持されます。リスクを抑えるため、次の手順を行ってください。

1. 先にローカルまたはリモートのバックアップを作成します。
2. Cherry Studio を完全に終了します。
3. 現在の OS とアーキテクチャに合う新しいインストールパッケージでアップグレードします。
4. 起動後、モデルサービス、会話、ナレッジベース、エージェントが正常に動作することを確認します。

プレリリース版やデイリープレビュー版には、まだ安定していないデータ移行が含まれる場合があります。重要なデータの唯一のコピーをプレビュー版の環境だけに保存しないでください。

## インストール後

初回起動後は、次の順序で設定することをおすすめします。

1. **設定 → モデルサービス**でプロバイダーとモデルを追加します。
2. 会話ページへ戻り、テストメッセージを送信します。
3. データの保存場所とバックアップ先を確認します。
4. 必要に応じて、ナレッジベース、エージェント、MCP、その他の高度な機能を有効にします。
