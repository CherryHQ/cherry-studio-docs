# macOS

このページでは、Intel または Apple チップを搭載した Mac に適したインストールパッケージの選び方、インストール手順、初回起動時の macOS セキュリティ警告への対処方法を説明します。まだインストールパッケージを入手していない場合は、先に[クライアントのダウンロード](../../cherrystudio/download.md)を開いてください。

## チップの種類を確認する

1. 画面左上の Apple メニュー  をクリックします。
2. **この Mac について**を選択します。
3. 「チップ」または「プロセッサ」を確認します。

| Mac に表示される内容 | ダウンロードするアーキテクチャ |
| --- | --- |
| Apple M シリーズチップ | `arm64` |
| Intel プロセッサ | `x64` |

Apple チップを搭載した Mac では、arm64 ネイティブパッケージを優先してください。誤って x64 パッケージをダウンロードすると、Rosetta のインストールを求められる場合があります。通常は arm64 パッケージをダウンロードし直すほうが適切です。

## DMG と ZIP の選び方

macOS の Release では通常、`.dmg` と `.zip` の両方が提供されます。

| 形式 | 使用方法 | 推奨 |
| --- | --- | --- |
| DMG | ディスクイメージを開き、アプリを「アプリケーション」へドラッグする | 大半のユーザーに適している |
| ZIP | 解凍後、アプリを「アプリケーション」へ移動する | DMG をマウントできない場合や、手動で配布する場合に使用する |

2 つの形式に含まれるアプリは同じであり、両方をインストールする必要はありません。

## ダウンロードしたファイルを検証する

公式の GitHub Release では、インストールパッケージの SHA256 が提供されます。「ターミナル」を開き、次のコマンドを実行してください。

```bash
shasum -a 256 ~/Downloads/Cherry-Studio-*.dmg
```

ZIP を使用する場合は、拡張子を `*.zip` に変更します。出力値は、Release ページに記載された SHA256 と完全に一致する必要があります。

ブラウザーまたは macOS から提供元が不明という警告が表示された場合は、まずダウンロード元のドメイン、ファイル名、SHA256 を確認してください。提供元を確認できない場合は、開かないでください。

## DMG でインストールする

1. ダウンロードした `.dmg` ファイルをダブルクリックします。
2. 開いたウインドウで、Cherry Studio を「アプリケーション」フォルダへドラッグします。
3. コピーが完了するまで待ちます。
4. Finder のサイドバーで Cherry Studio のディスクイメージを取り出します。
5. **Finder → アプリケーション → Cherry Studio**を開きます。

DMG のウインドウからアプリを直接、継続的に実行しないでください。「アプリケーション」へコピーしてから起動すると、その後の更新や権限管理が安定します。

## ZIP でインストールする

1. `.zip` ファイルをダブルクリックして解凍します。
2. 解凍された Cherry Studio を「アプリケーション」フォルダへ移動します。
3. 「アプリケーション」から起動します。

「アプリケーション」に古いバージョンがある場合は、更新前に Cherry Studio を完全に終了し、**設定 → データ設定**でバックアップを作成してください。

## 初回起動時のセキュリティ警告に対処する

インターネットからダウンロードしたアプリを初めて開くとき、macOS は Gatekeeper による確認を行います。

開いてもよいかを確認するメッセージだけが表示された場合は、アプリ名とダウンロード元を確認してから「開く」を選択します。開発元を検証できない、または悪意のあるソフトウェアを確認できないというメッセージが表示された場合：

1. ファイルが Cherry Studio 公式サイトまたは公式の GitHub Releases から取得したものであることを確認します。
2. SHA256 を確認します。
3. macOS にブロックを記録させるため、アプリを一度開いてみます。
4. **システム設定 → プライバシーとセキュリティ**を開きます。
5. 「セキュリティ」セクションで該当するメッセージを探し、**このまま開く**を選択します。
6. システムの指示に従って認証し、もう一度開くことを確認します。

{% hint style="warning" %}
Gatekeeper を無効にしないでください。また、提供元が不明なファイルや SHA256 が一致しないファイルでは「このまま開く」を使用しないでください。アプリがコンピュータを破損する、またはマルウェアが含まれていると明示された場合は、ファイルを削除し、公式チャネルからダウンロードし直してください。
{% endhint %}

Apple の最新手順については、[Mac でアプリを安全に開く](https://support.apple.com/102445)を参照してください。

## システム権限を付与する

Cherry Studio は、関連機能で必要になった場合にだけ権限を要求します。例：

* 音声またはオーディオ機能を使用するときのマイク権限。
* カメラ関連機能を使用するときのカメラ権限。
* ファイルの読み取りや保存を行うときの「書類」または「ダウンロード」フォルダへのアクセス権。

使用中の機能に必要な権限だけを付与してください。変更する場合は、**システム設定 → プライバシーとセキュリティ**を開き、対応する権限カテゴリで Cherry Studio の設定を調整します。

## Cherry Studio を更新する

更新前に、次の操作を行います。

1. **設定 → データ設定**でバックアップを作成します。
2. Cherry Studio を完全に終了します。
3. Mac のチップに合う新しいバージョンをダウンロードします。

新しい DMG を開くか ZIP を解凍し、新しい Cherry Studio を「アプリケーション」へ移動して、システムから確認されたら古いバージョンを置き換えます。新しいバージョンを初めて起動した後は、モデルサービス、会話、ナレッジベース、エージェントが正常に動作することを確認してください。

新しいバージョンから古いバージョンへダウングレードすると、データベースや設定の互換性に関する問題が発生する場合があります。バックアップがあり、影響を明確に理解している場合を除き、ダウングレードはおすすめしません。

## よくある問題

### アプリを開けない

次の順に確認してください。

1. インストールパッケージのアーキテクチャが Mac のチップと一致しているか。
2. ファイルが完全で、SHA256 が一致しているか。
3. アプリを「アプリケーション」へ移動済みか。
4. **システム設定 → プライバシーとセキュリティ**に該当するブロックのメッセージがあるか。
5. Cherry Studio のプロセスがすでに実行されていないか。

### アプリが破損していると表示される

現在のファイルを削除し、公式チャネルからダウンロードし直して SHA256 を確認してください。セキュリティ属性を削除するために、インターネット上のコマンドをそのままコピーして実行しないでください。ファイルが実際に破損または改ざんされている場合、システムの保護を回避することになります。

### アプリが起動直後に終了する

macOS のバージョン、チップの種類、Cherry Studio のバージョン、エラーメッセージ全文を記録し、[フィードバックと提案](../../question-contact/suggestions.md)から送信してください。プレリリース版を使用している場合は、ビルド日またはダウンロード元も記載してください。
