# Windows

このページでは、Windows 用インストールパッケージの選び方、インストール手順、初回起動時によくあるセキュリティ警告やランタイムの問題への対処方法を説明します。まだインストールパッケージを入手していない場合は、先に[クライアントのダウンロード](../../cherrystudio/download.md)を開いてください。

{% hint style="warning" %}
Cherry Studio は Windows 7 に対応していません。インストールパッケージは、Cherry Studio 公式サイトまたは公式の `CherryHQ/cherry-studio` GitHub Releases からのみダウンロードしてください。
{% endhint %}

## インストールパッケージを選ぶ

Windows の Release では、x64 と ARM64 の 2 つのアーキテクチャ、および Setup と Portable の 2 つのパッケージ形式が提供されます。

| インストールパッケージ | 適した用途 |
| --- | --- |
| `x64-setup.exe` | Intel または AMD プロセッサを搭載した一般的な Windows PC。大半のユーザーに適している |
| `arm64-setup.exe` | ARM プロセッサを搭載した Windows PC。一部の Snapdragon デバイスなど |
| `x64-portable.exe` | x64 PC。インストールせず、プログラムとデータを指定したディレクトリに置きたい場合 |
| `arm64-portable.exe` | ARM64 PC。インストールせず、プログラムとデータを指定したディレクトリに置きたい場合 |

アーキテクチャがわからない場合は、**設定 → システム → バージョン情報**を開き、「システムの種類」を確認します。

* 「x64 ベース プロセッサ」と表示される場合は x64 を選択します。
* 「ARM ベース プロセッサ」と表示される場合は ARM64 を選択します。

Setup インストール版は日常利用に適しています。Portable ポータブル版は、一時的なテスト、USB メモリでの持ち運び、独立したデータディレクトリが必要な場合に適しています。

## ダウンロードしたファイルを検証する

公式の GitHub Release では、インストールパッケージの SHA256 が提供されます。ダウンロード後、PowerShell で次のコマンドを実行できます。

```powershell
Get-FileHash ".\Cherry-Studio-*-setup.exe" -Algorithm SHA256
```

ポータブル版を使用する場合は、ファイル名を対応する `*-portable.exe` に変更してください。出力値は、Release ページに記載された SHA256 と完全に一致する必要があります。

ブラウザーまたは Windows からファイルの提供元が不明という警告が表示された場合は、まずダウンロード元のドメイン、ファイル名、SHA256 を確認してください。提供元を確認できない場合は、実行しないでください。

## Setup 版をインストールする

1. 実行中の Cherry Studio を完全に終了します。
2. `*-setup.exe` をダブルクリックします。
3. インストールウィザードに従ってインストール先を選択します。
4. 設定内容を確認し、インストールを完了します。
5. デスクトップのショートカットまたはスタートメニューから Cherry Studio を起動します。

既存のインストールを更新する場合は、同じシステムアーキテクチャ向けの新しい Setup インストールパッケージを実行します。更新前に、**設定 → データ設定**でバックアップを作成することをおすすめします。

## Portable 版を使用する

1. `D:\Apps\CherryStudio` など、書き込み可能なディレクトリを新しく作成します。
2. `*-portable.exe` をそのディレクトリに置きます。
3. 実行ファイルをダブルクリックして起動します。
4. プログラムの実行中は、実行ファイルやデータディレクトリを移動しないでください。

データの保存場所を別途設定していない場合、ポータブル版は実行ファイルと同じ場所の `data` ディレクトリにアプリデータを保存します。ポータブル版をバックアップまたは移行するときは、実行ファイルとこのディレクトリの両方を保持してください。

{% hint style="info" %}
ポータブル版は、書き込みに管理者権限が必要なディレクトリに置かないでください。長期的に使用し、ショートカットの自動作成やインストールウィザードによる更新を利用する場合は、Setup インストール版をおすすめします。
{% endhint %}

## 初回起動

初めて起動した後は、次の項目を確認することをおすすめします。

1. **設定 → モデルサービス**を開き、プロバイダーを追加して、少なくとも 1 つのモデルを有効にします。
2. 会話ページに戻り、テストメッセージを送信します。
3. **設定 → データ設定**を開き、バックアップ方法とデータの保存場所を確認します。

Windows Defender SmartScreen に保護に関する警告が表示された場合は、ファイルが公式チャネルから取得され、SHA256 の検証に合格していることを確認してから、システムの案内に従って詳細を表示してください。提供元が不明なインストールパッケージのために、システムのセキュリティ機能を無効にしないでください。

## Visual C++ ランタイム

Cherry Studio の一部のネイティブコンポーネントは、Microsoft Visual C++ Redistributable に依存しています。インストール時または起動時にランタイムが不足していると表示された場合：

1. まず、Cherry Studio のインストーラーによる依存関係のインストールを許可します。
2. 自動インストールに失敗した場合は、[Microsoft Visual C++ Redistributable 公式ページ](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)を開きます。
3. システムアーキテクチャに合う x64 または ARM64 版をダウンロードし、インストール後に Cherry Studio を再起動します。

サードパーティのソフトウェアダウンロードサイトからランタイムを入手しないでください。

## 更新とバージョンの切り替え

更新前に、次の操作を行います。

1. **設定 → データ設定**でバックアップを作成します。
2. Cherry Studio を完全に終了します。
3. 現在の PC のアーキテクチャに合う新しいインストールパッケージをダウンロードします。

Setup を使用している場合は、新しいバージョンのインストールパッケージをそのまま実行できます。Portable を使用している場合は、既存の `data` ディレクトリを保持し、新しいバージョンの実行ファイルで古いファイルを置き換えます。

新しいバージョンから古いバージョンへダウングレードすると、データベースや設定の互換性に関する問題が発生する場合があります。バックアップがあり、影響を明確に理解している場合を除き、ダウングレードはおすすめしません。プレリリース版やデイリープレビュー版も、重要なデータを扱う唯一の実行環境として使用しないでください。

## よくある問題

### ダブルクリックしても起動しない

次の順に確認してください。

1. インストールパッケージのアーキテクチャがシステムと一致しているか。
2. ファイルが完全で、SHA256 が一致しているか。
3. Visual C++ Redistributable が正しくインストールされているか。
4. セキュリティソフトによってプログラムファイルが隔離されていないか。
5. Cherry Studio のプロセスがすでに実行されていないか。

それでも起動できない場合は、Windows のバージョン、システムアーキテクチャ、Cherry Studio のバージョン、エラーメッセージを記録し、[フィードバックと提案](../../question-contact/suggestions.md)から送信してください。

### Portable 版を起動すると新規インストールのように見える

実行ファイルの横にある `data` ディレクトリが残っているか、現在のディレクトリに書き込みできるか、実行ファイルを移動していないかを確認します。復元する前に現在のディレクトリをコピーし、まだ利用可能なデータを上書きしないようにしてください。
