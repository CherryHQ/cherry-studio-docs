# 翻译

翻译页面使用你已配置的语言模型完成文本翻译。它支持自动识别语言、流式显示结果、导入文本或文档、图片 OCR、翻译历史以及自定义语言，适合处理短文、邮件、代码片段和从文件中提取出的文字。

## 开始前的准备

翻译至少需要一个已启用的文本模型：

1. 打开 `设置` → `模型服务`，完成服务商与模型配置。
2. 在翻译页面右上角选择用于翻译的模型。
3. 如果使用 LLM 自动识别语言，还要在 `设置` → `默认模型` 中配置**快速助手模型**。

嵌入、重排序和图片生成模型不会出现在翻译模型列表中。如果还没有可用模型，请先阅读[配置模型服务](../../pre-basic/providers/README.md)。

## 打开翻译

点击顶部标签栏右侧的 `+`，打开**启动台**，然后选择**翻译**。

页面由以下部分组成：

| 区域 | 用途 |
| --- | --- |
| 顶部语言栏 | 选择源语言和目标语言、交换翻译方向、开始或停止翻译 |
| 左侧输入区 | 输入、粘贴或导入待翻译内容 |
| 右侧结果区 | 流式显示结果，并复制译文 |
| 右上角工具 | 选择模型、打开翻译历史和翻译设置 |

在较窄的窗口中，输入区和结果区会改为上下排列。

## 完成一次翻译

1. 选择源语言。无法确定时保留**自动检测**。
2. 选择目标语言。
3. 在左侧输入或粘贴内容。
4. 点击**翻译**，或按 `Ctrl + Enter`（Windows / Linux）或 `Command + Enter`（macOS）。
5. 在右侧查看流式结果，完成后点击复制按钮。

翻译进行中，可以点击**停止**中断本次请求。清空左侧输入时，右侧结果也会一并清空。

{% hint style="info" %}
翻译结果由当前选择的模型生成。专业术语、合同、医疗或其他高风险内容仍应由具备相关能力的人复核。
{% endhint %}

## 选择源语言和目标语言

### 自动检测

源语言选择**自动检测**后，Cherry Studio 会先判断输入语言，再开始翻译。成功识别后，源语言位置会显示识别结果。

设置中有三种检测方式：

| 方式 | 行为 |
| --- | --- |
| 自动 | 根据内容长度优先选择 LLM 或本地算法；本地算法无法识别时会回退到 LLM |
| 本地算法 | 在本机快速检测，不调用模型，但支持的语言范围较有限 |
| LLM | 使用快速助手模型识别，通常更适合较短或不易判断的文本，但会产生一次额外模型调用 |

如果 LLM 检测失败，请检查快速助手模型是否已配置且可用。

### 交换翻译方向

源语言不是**自动检测**时，可以点击中间的交换按钮。Cherry Studio 会同时交换源语言、目标语言、原文和现有译文。

### 双向翻译

在设置中开启**双向翻译**并指定一对语言后，Cherry Studio 会根据检测到的输入语言自动选择这对语言中的另一种作为目标语言。它适合在两种固定语言之间反复沟通。

输入语言不属于设定的语言对时，应用会提示无法确定方向。

## 导入文件或图片

输入为空时，左侧会显示文件导入区域。点击该区域选择一个文件，也可以将文件拖入页面；剪贴板中的图片还可以直接粘贴。

| 内容类型 | 处理方式 |
| --- | --- |
| 图片 | 先通过当前 OCR 配置识别文字，再追加到输入区 |
| 纯文本、Markdown、代码等文本文件 | 直接读取文字并追加到输入区 |
| PDF、Word、PowerPoint、Excel 和 ODF 文档 | 提取可读取的文本并追加到输入区 |

每次只能导入一个文件。文本文件上限为 5 MB，文档上限为 20 MB；实际可读取内容仍取决于文件格式、文档结构和本机文件处理能力。

{% hint style="warning" %}
文件导入的作用是提取文字，并不会生成一份保留原排版的翻译文档。需要逐段控制格式时，建议先提取内容，再分段翻译和整理。
{% endhint %}

图片没有识别出文字时，请检查 `设置` → `文档处理` 中的 OCR 配置，并确认图片清晰、方向正确。

## 选择翻译模型

点击右上角的模型图标，可以从已启用的文本模型中选择翻译模型。选择时可参考：

- 日常短文本优先考虑响应快、成本可控的模型；
- 长文本要关注模型的上下文长度和输出限制；
- 专业内容可比较不同模型对术语和语气的处理；
- 专用翻译模型可能按自身协议工作，不一定使用自定义翻译提示词。

如果翻译按钮始终不可用，请确认已经输入内容并选中了有效模型。

## 翻译设置

点击右上角的设置按钮打开侧边面板。

### 结果与操作

| 设置 | 作用 |
| --- | --- |
| Markdown 预览 | 将译文按 Markdown 渲染；关闭时显示纯文本 |
| 自动复制 | 翻译完成后自动将结果写入剪贴板 |
| 滚动同步 | 长文本滚动时，让左右两栏按相对位置联动 |

### 翻译提示词

翻译提示词控制普通对话模型如何处理原文。默认模板中包含：

- `{{target_language}}`：当前目标语言；
- `{{text}}`：待翻译文本。

修改模板时应保留这两个占位符，否则模型可能无法收到目标语言或原文。需要恢复时点击**重置**。

### 自定义语言

内置语言以外，还可以添加自定义语言。添加时填写显示名称、语言代码并选择图标；创建后可以编辑名称和图标，或删除该语言。

语言代码必须唯一，不能与内置语言重复。是否能得到可靠译文，仍取决于所选模型是否理解该语言名称和内容。

## 使用翻译历史

每次成功翻译后，原文、译文、语言方向和时间会写入翻译历史。打开右上角的历史面板后，可以：

- 查看并重新载入一条翻译；
- 复制历史中的原文或译文；
- 收藏常用记录，并只查看收藏项；
- 删除单条记录；
- 确认后清空全部历史。

重新载入记录会同时恢复当时的原文、译文和语言方向。

## 常见问题

### 翻译按钮不可用

确认输入区不是空白、已经选择翻译模型，并等待文件读取、语言检测或上一项翻译结束。

### 自动检测报错

如果设置为 LLM 检测，或自动方式回退到 LLM，请检查快速助手模型。也可以改为明确选择源语言，或尝试本地算法。

### 结果为空或中途失败

检查模型服务的密钥、网络、余额、调用频率限制和模型可用状态。长文本还可能超过模型的上下文或输出限制，可拆分为较短段落后重试。

### 源语言和目标语言无法交换

源语言为**自动检测**、正在翻译、正在检测语言或正在处理文件时，交换按钮会暂时不可用。先明确选择源语言并等待当前操作结束。

### 文件导入失败

确认每次只选择一个受支持文件，且没有超过大小限制。扫描版文档、复杂表格、受密码保护或损坏的文件，可能无法完整提取文本。

## 隐私与费用

普通翻译内容会发送给当前所选模型的服务商；LLM 自动检测还会调用快速助手模型。图片在翻译前会交给当前 OCR 组件处理。请根据数据敏感度选择合适的服务和部署方式，并查看相应服务商的隐私政策与计费规则。
