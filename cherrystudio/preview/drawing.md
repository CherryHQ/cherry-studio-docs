# 绘画

绘画是 Cherry Studio 的独立图片生成工作区。它会读取你已经配置好的服务商和模型，让你在同一页面中选择图像模型、输入提示词、调整该模型支持的参数，并管理本次生成的图片。

{% hint style="info" %}
绘画页面只显示具备图片生成能力的可用模型。可选项取决于当前版本、已启用的服务商及模型配置，因此应用内列表才是实际依据。
{% endhint %}

## 开始前的准备

使用绘画前，至少需要一个可用的图片生成模型：

1. 打开 `设置` → `模型服务`。
2. 启用服务商并完成必要的 API 密钥或连接配置。
3. 确认服务商中已添加支持图片生成的模型。

如果还没有配置服务商，请先阅读[配置模型服务](../../pre-basic/providers/README.md)。

## 打开绘画

点击顶部标签栏右侧的 `+`，打开**启动台**，然后选择**绘画**。

页面主要分为三个区域：

| 区域 | 用途 |
| --- | --- |
| 左侧设置区 | 选择服务商和模型，调整当前模型支持的生成参数 |
| 中央画布 | 查看生成状态与结果；一次返回多张图片时可逐张切换 |
| 右侧历史区 | 新建绘画、切换历史记录或删除不再需要的记录 |

底部是提示词输入区。选择模型并写好描述后，即可开始生成。

## 文生图

文生图只需要描述你想得到的画面：

1. 在左侧选择服务商和图片生成模型。
2. 在底部输入提示词。
3. 按需调整尺寸、宽高比、分辨率或其他参数。
4. 点击发送按钮开始生成。
5. 等待中央画布显示结果。

例如：

```text
一只戴圆眼镜的橘猫坐在书堆上，复古油画风格，温暖的黄昏光线，中景构图
```

生成过程中，画布会显示进度；需要终止时可以取消当前任务。模型一次返回多张图片时，使用画布上的上一张、下一张按钮切换。

## 使用参考图或编辑图片

部分模型除了文生图，还支持图片编辑、混合或其他图像模式。选择这类模型后，提示词输入区会出现添加图片的入口。

你可以：

- 从本地选择图片；
- 将图片拖入输入区；
- 从剪贴板粘贴图片；
- 在模型支持时添加多张参考图。

添加图片后，描述需要保留和修改的内容，再开始生成。例如：

```text
保留主体和构图，把背景改成雨后的东京街道，增加霓虹灯倒影
```

{% hint style="warning" %}
如果输入区没有添加图片的入口，表示当前所选模型没有提供图片编辑能力。请改用支持相关模式的模型。
{% endhint %}

## 调整生成参数

参数面板会根据所选模型动态变化，只显示该模型声明支持的选项。常见参数包括：

| 参数 | 作用 |
| --- | --- |
| 尺寸或宽高比 | 控制图片的画布形状和输出尺寸 |
| 分辨率 | 在模型支持时选择输出清晰度 |
| 图片数量 | 控制一次生成返回的结果数量 |
| 质量、风格、背景 | 调整模型提供的画面选项 |
| Seed、Guidance、Steps | 控制随机性或生成过程，仅部分模型提供 |

不同模型的参数名称、取值和计费方式可能不同。不确定时，建议先使用默认值完成一次生成，再逐项调整；模型没有显示的参数不需要手动补充。

## 管理绘画记录

右侧历史区用于管理不同的绘画任务：

- 点击顶部的 `+` 新建一条空白绘画；
- 点击缩略图回到已有记录；
- 记录较多时向下滚动加载更多；
- 删除不再需要的记录前，应用会再次确认。

生成结果会显示在中央画布。点击图片可打开大图预览，再使用预览界面提供的操作查看或保存结果。

## 写出更有效的提示词

提示词不需要固定格式，但建议至少包含以下信息：

- **主体**：人物、物品或场景；
- **环境**：地点、时间、天气和背景；
- **视觉风格**：摄影、插画、油画、3D 等；
- **构图**：近景、全身、俯拍、对称构图等；
- **光线与色彩**：柔光、逆光、冷色、低饱和等；
- **约束**：希望保留或避免的元素。

不同模型对语言和提示词结构的理解不同。如果结果偏离预期，可先减少互相冲突的要求，再逐步增加细节。

## 常见问题

### 看不到可选的服务商或模型

绘画页面只列出当前已启用且具备图片生成能力的模型。请检查服务商是否启用、密钥是否有效、模型是否已添加，以及模型能力或端点类型是否配置正确。

### 添加图片按钮没有显示

当前模型只支持文生图，或没有向 Cherry Studio 声明图片编辑能力。切换到支持图片编辑的模型后再试。

### 生成一直失败

依次检查：

1. 服务商连接和 API 密钥；
2. 模型是否仍然可用；
3. 账户余额、额度或调用频率限制；
4. 提示词和参考图是否触发服务商内容政策；
5. 当前参数组合是否受模型支持；
6. 网络或代理能否访问服务商及其图片地址。

服务商返回的详细错误通常会帮助判断是鉴权、额度、参数还是内容限制问题。

### 同一提示词的结果为什么不同

图片生成通常包含随机过程。若模型提供 `Seed`，可以固定种子并保持其他参数不变，以提高结果的可复现性；没有该参数时，重复生成出现差异属于正常情况。

## 隐私与费用

提示词、参考图和生成参数会发送给所选服务商处理。请不要上传无权处理的敏感图片，并在使用前确认服务商的隐私政策、内容政策和计费规则。提高分辨率、增加图片数量或使用编辑模式，可能带来更高费用。
