# 对话界面

对话是 Cherry Studio 最常用的工作区。你可以为不同用途创建助手，在每个助手下管理多个独立话题，并按需要加入文件、知识库、网络搜索、MCP 工具或多个模型。

{% hint style="info" %}
第一次使用前，请先在[模型服务](../../pre-basic/providers/)中添加服务商、启用模型并通过连接检查。
{% endhint %}

## 先理解助手和话题

对话页采用“助手 → 话题”两层结构：

* **助手**：保存角色提示词、当前模型、模型参数、知识库、MCP 和联网搜索等配置。
* **话题**：保存一段独立的对话历史。

一个助手可以有多个话题。它们共用助手配置，但消息历史互不混合。例如，可以在同一个“代码审查助手”下分别创建“项目 A”和“项目 B”两个话题。

需要自主访问工作区、读写文件或执行命令时，应使用[智能体](../../advanced-basic/agent.md)，不要把对话助手和智能体混为一类。更多概念见[概念入门](../../advanced-basic/concepts-101.md)。

## 页面组成

对话页主要由四部分组成：

1. **助手与话题列表**：切换助手、创建话题、搜索或管理历史。
2. **顶部栏**：显示当前助手和模型，并提供对话设置、搜索和侧栏开关。
3. **消息区**：显示用户消息、模型回复、思考过程、工具调用和引用。
4. **输入区**：输入消息并使用附件、联网搜索、知识库、MCP、多模型等工具。

话题列表可以按显示设置放在左侧或右侧；侧栏也可以收起。界面位置不同不会改变助手和话题的层级关系。

## 开始第一次对话

1. 打开侧栏中的 **对话**。
2. 选择一个助手，或从[助手库](assistants.md)添加助手。
3. 点击 **新话题**。
4. 在顶部选择要使用的模型。
5. 在输入框中写下问题，按当前设置的发送快捷键发送。

如果模型没有回复，先检查模型服务是否启用、API Key 和地址是否正确，以及当前模型是否可用。

## 选择模型

### 当前助手模型

顶部的模型选择器决定当前助手使用的基础模型。切换后，后续消息将使用新模型；助手的默认模型和新话题是否重置模型可在助手设置中调整。

只选择可用于对话的模型。嵌入模型和重排序模型用于知识库处理，不会出现在普通对话模型列表中。

### 使用多个模型并行回复

在输入区点击模型提及按钮，或输入 `@`，可以选择一个或多个模型。选中的模型会显示在输入框上方：

* 只选一个模型时，该模型代替助手基础模型回复。
* 选择多个模型时，Cherry Studio 会并行生成多份回复，便于比较结果。
* 删除输入框上方的模型标签后，恢复使用助手基础模型。

上传图片时，所有被提及的模型都应支持视觉输入；否则可能无法选择或发送。

## 输入工具

输入区工具可以拖动排序，也可以通过右键菜单显示或隐藏。窗口较窄或工具较多时，部分按钮会收起。

| 工具 | 作用 | 说明 |
| --- | --- | --- |
| 新话题 | 在当前助手下创建独立话题 | 不会删除原话题 |
| 附件 | 添加图片、文档或文本 | 可选类型取决于模型能力 |
| 联网搜索 | 把搜索结果加入回答依据 | 需要模型原生搜索或已配置搜索服务 |
| 知识库 | 为助手选择一个或多个知识库 | 选择会保留在助手配置中，直到移除 |
| MCP | 查看或调用已分配给助手的 MCP 工具 | 需要先配置 MCP 服务器 |
| 提及模型 | 为输入选择一个或多个回复模型 | 也可输入 `@` 打开 |
| 快捷短语 | 插入常用提示词模板 | 在设置中统一管理 |
| 思考 | 调整支持推理模型的思考模式或强度 | 仅在模型支持时显示 |
| 网页上下文 | 允许支持的模型读取 URL | 只在兼容模型和服务商组合下显示 |
| 生成图片 | 让支持图像生成的模型返回图片 | 专门创作图片也可使用[绘画](drawing.md) |
| 清空消息 | 删除当前话题中的消息 | 删除后不可恢复 |
| 新上下文 | 保留屏幕上的历史，但从此处截断发送给模型的上下文 | 适合话题未结束但模型不应继续参考旧内容 |
| 展开输入框 | 扩大或恢复输入区 | 适合长提示词 |

工具是否出现由当前页面、模型能力、助手配置和你的工具栏设置共同决定。看不到某个按钮时，先右键输入区工具栏检查它是否被隐藏，再检查模型或助手是否满足条件。

### `@` 和 `/` 快速面板

启用输入快速面板后：

* 输入 `@` 可以打开模型选择面板。
* 输入 `/` 可以打开可用操作和资源的快速面板。

快速面板中显示什么取决于当前对话环境和已启用工具。可以在输入设置中关闭字符触发，但仍通过工具按钮使用相关功能。

## 使用附件

1. 点击 **附件**，或把文件拖入输入区。
2. 确认文件预览出现在输入框上方。
3. 在问题中明确说明希望模型如何处理文件。
4. 发送消息。

可选文件类型会根据模型能力变化：

* 图片需要视觉模型或支持图片生成/编辑的模型。
* 文档和文本会先作为附件处理，再随消息进入上下文。
* 提及多个模型时，附件必须与所选模型的共同能力匹配。

长文本也可以按输入设置自动转成文件，避免占满输入框。涉及隐私或机密信息时，发送前确认当前模型服务商和数据策略。

## 使用知识库

1. 先在[知识库](knowledge-base.md)中创建知识库并完成资料处理。
2. 返回对话页，点击 **知识库**。
3. 选择一个或多个知识库。
4. 提问时写明希望检索的主题、范围或时间条件。

知识库标签会显示在输入框上方。当前版本中，附件和知识库选择在部分组合下可能互斥；如果按钮不可用，先移除当前附件再选择知识库。

知识库检索结果是模型回答的参考内容，不保证回答一定正确。重要结论仍应检查引用和原始资料。

## 使用联网搜索和 MCP

### 联网搜索

联网搜索有两类来源：

* 模型服务商提供的原生搜索能力。
* 在 Cherry Studio 中配置的外部搜索服务。

具体配置见[联网模式](../../pre-basic/websearch/)。启用后，仍应检查引用链接是否真正支持模型结论。

### MCP 工具

MCP 让对话助手调用外部工具或数据。使用前需要：

1. 在 MCP 设置中安装并启用服务器。
2. 把需要的 MCP 服务器分配给当前助手。
3. 选择支持工具调用的模型。
4. 在发送前检查启用的工具和权限。

完整说明见[MCP](../../advanced-basic/mcp/)。

## 操作消息

把鼠标移到消息附近可以看到操作栏。实际按钮会根据消息角色和设置变化。

| 操作 | 用途 |
| --- | --- |
| 复制 | 复制消息正文 |
| 编辑并重发 | 修改用户消息并从该位置重新生成 |
| 重新生成 | 让模型再次回答 |
| 用其他模型回答 | 从当前位置选择模型生成另一份回复 |
| 翻译 | 把模型回复翻译成所选语言 |
| 保存到笔记 | 将回复保存到 Cherry Studio 笔记 |
| 删除 | 删除单条消息 |
| 新建分支 | 从当前消息创建新的对话分支 |
| 多选 | 批量选择消息进行后续操作 |
| 保存或导出 | 保存为文件、加入知识库或导出内容 |

在重新生成、编辑历史消息或删除前，注意这些操作可能改变后续对话链。需要保留原结果时，先新建分支。

## 管理长对话

| 操作 | 消息是否保留 | 后续是否继续携带旧上下文 | 适合场景 |
| --- | --- | --- | --- |
| 新话题 | 保留在原话题 | 否 | 开始新的任务或项目 |
| 新上下文 | 保留在当前话题 | 从标记处重新开始 | 同一任务换阶段，或上下文已经混乱 |
| 清空消息 | 删除 | 否 | 确定不再需要当前话题内容 |
| 新建分支 | 原对话保留 | 从选定消息继续 | 比较不同提示或模型路线 |

{% hint style="warning" %}
“清空消息”会删除当前话题内容；“新上下文”只截断发送给模型的历史。两者不是同一个操作。
{% endhint %}

输入区显示的 Token 数是估算值，用于判断上下文是否接近模型上限。不同模型的分词方式和服务商计费规则不同，最终用量以服务商为准。

## 助手设置与全局设置

### 助手设置

助手设置会影响该助手下的所有话题，主要包括：

* 名称、头像和系统提示词。
* 默认模型和模型参数。
* 知识库、联网搜索和 MCP。
* 上下文数量、最大输出长度、流式输出和服务商专用参数。

并非所有模型都支持相同参数。没有明确需求时，优先使用默认值；自定义参数可能覆盖内置设置。

### 对话与输入设置

对话设置还包含全局显示和输入偏好，例如：

* 消息样式、字体、代码块、数学公式和思考内容显示。
* Token 估算、长文本粘贴、输入翻译和发送方式。
* 助手列表、话题位置和工具栏显示。

相关页面：

* [显示设置](../../pre-basic/settings/display.md)
* [快捷键](../../pre-basic/settings/key-shortcut.md)

## 常见问题

### 发送按钮不可用

检查输入是否为空、是否仍在生成、附件类型是否被当前模型支持，以及模型服务是否已经启用。

### 找不到知识库或 MCP

确认对应功能已经创建或启用，并检查当前助手是否支持工具调用。知识库按钮不可用时，先移除输入区附件。

### 多模型回复没有出现

确认输入框上方仍显示已提及模型，并检查这些模型是否都可用。被禁用、余额不足或接口不兼容的模型可能单独失败。

### 对话越来越慢或回答偏离主题

先检查 Token 估算和上下文数量。可以使用 **新上下文** 在当前话题中重新开始，或创建新话题分离任务。

仍无法解决时，通过[反馈与建议](../../question-contact/suggestions.md)提交 Cherry Studio 版本、模型名称、服务商、复现步骤和错误信息。
