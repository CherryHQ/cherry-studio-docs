# 启动台

启动台是 Cherry Studio 的首页，用于集中打开常用功能和小程序。你可以从这里进入知识库、绘画、助手库、翻译、文件、代码工具、OpenClaw、笔记和资源库等工作区。

## 打开启动台

启动 Cherry Studio 后，应用会默认进入启动台。使用过程中还可以通过以下方式返回或新建启动台：

* 点击窗口顶部标签栏左侧的首页按钮，返回已有的启动台标签页。
* 点击标签栏中的 `+`，新建一个标签页。新标签页会从启动台开始。

从启动台点击应用后，当前标签页会进入相应工作区。需要同时处理多项工作时，可以使用 `+` 新建多个标签页。

## 应用入口

启动台的“应用”区域提供以下入口：

| 应用 | 用途 |
| :--- | :--- |
| 小程序 | 打开和管理网页小程序 |
| 知识库 | 管理知识库、数据源和检索设置 |
| 绘画 | 使用图像模型生成和管理图片 |
| 助手库 | 浏览和导入社区助手 |
| 翻译 | 翻译文本并对照原文与译文 |
| 文件 | 查看 Cherry Studio 中使用过的文件 |
| Code | 管理和运行支持的 AI 编程工具 |
| OpenClaw | 安装、配置和打开 OpenClaw |
| 笔记 | 创建和整理 Markdown 笔记 |
| 资源库 | 管理助手、智能体、技能和提示词 |

“助手库”和“资源库”是两个不同的入口：助手库用于浏览可导入的助手，资源库用于管理自己的助手、智能体、技能和提示词。

## 小程序区域

固定到启动台的小程序会显示在“应用”区域下方。保持打开状态的小程序也可能出现在这里，方便快速返回。

如需添加或移除入口，请在“小程序”页面打开对应小程序的操作菜单，然后选择“添加到启动台”或“从启动台移除”。

{% hint style="info" %}
从启动台移除小程序只会取消快捷入口，不会删除小程序本身。
{% endhint %}

## 使用建议

* 从启动台开始一项新工作；需要继续已有对话或任务时，使用左侧边栏或相应页面的历史列表。
* 使用多个标签页并行打开不同功能，避免频繁退出当前工作区。
* 将常用网页小程序添加到启动台，减少重复查找。
