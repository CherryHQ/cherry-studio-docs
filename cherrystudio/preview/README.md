# 功能介绍

Cherry Studio 的主要功能通过**顶部应用栏、启动台和设置页**进入。下面按客户端中实际看到的顺序排列，便于在软件和文档之间对应查找。

第一次使用时，请先完成[快速开始](../../getting-started/quick-start.md)。下面是功能索引，不需要在开始对话前逐项配置。

<figure><img src="../../.gitbook/assets/cherry-launchpad.png" alt="Cherry Studio 顶部应用栏"><figcaption><p>常用应用固定到顶部应用栏后，可在不同功能间快速切换。</p></figcaption></figure>

| 功能 | 简述 | 软件入口 |
|---|---|---|
| [启动台](launchpad.md) | 查找并打开应用，把常用应用固定到顶部 | 顶部 `+` |
| [对话](chat.md) | 与模型对话，管理助手、助手库、话题和工具 | 顶部 `对话` |
| [工作](../../advanced-basic/agent.md) | 让 Agent 读写工作区、调用工具并执行多步任务 | 顶部 `工作` |
| [绘画](drawing.md) | 通过已配置的图像模型生成或编辑图片 | 顶部 `绘画` 或启动台 |
| [翻译](translation.md) | 文本、图片和文档的双栏翻译 | 顶部 `翻译` 或启动台 |
| [小程序](app.md) | 在客户端中打开常用 AI 网页应用 | 启动台 → `小程序` |
| [知识库](knowledge-base.md) | 对文件、目录、网页和笔记建立检索索引 | 顶部 `知识库` 或启动台 |
| [文件](files.md) | 上传并集中管理应用内文件 | 启动台 → `文件` |
| [Code Switch](../../advanced-basic/code-tools.md) | 管理和调用外部编码工具 | 启动台 → `Code Switch` |
| [笔记](notes.md) | 内置 Markdown 编辑器 | 启动台 → `笔记` |
| [快捷助手](quick-assistant.md) | 用全局快捷键唤起迷你提问窗口 | `设置 → 快捷助手` |
| [划词助手](selection-assistant.md) | 对其他应用中选中的文字执行翻译、解释等操作 | `设置 → 划词助手` |

{% hint style="info" %}
顶部应用栏可同时保留多个标签。启动台中的应用被打开后会出现在顶部；不需要时可关闭标签，不会删除该功能或数据。
{% endhint %}

需要自动执行任务时，从[工作（Agent）](../../advanced-basic/agent.md)开始；各项能力的定位和组合方式见[核心概念](../../advanced-basic/concepts-101.md)。
