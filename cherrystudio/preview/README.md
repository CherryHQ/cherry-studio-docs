# 功能一览

Cherry Studio V2 把多模型对话、智能体、内容创作、知识管理和自动化工具放在同一个桌面工作空间中。本页帮助你快速判断应该进入哪个模块；具体操作请继续阅读各功能的独立教程。

## 如何找到功能

Cherry Studio 有三种常用入口：

* **启动台**：集中打开应用模块和已经固定的小程序。
* **左侧栏**：放置你经常使用的模块。可以在设置中调整显示哪些图标。
* **顶部标签栏**：每次打开功能或内容时创建标签页，适合在多个任务之间切换。

不了解界面时，先阅读[启动台](launchpad.md)。

## 对话助手和智能体有什么区别

这两个模块都可以使用模型，但侧重点不同：

| | 对话助手 | 智能体 |
| --- | --- | --- |
| 适合 | 问答、写作、分析和固定角色对话 | 需要读写文件、调用工具或连续执行的任务 |
| 核心配置 | 提示词、模型、知识库、MCP | 工作区、权限、技能、工具、最大轮数 |
| 执行方式 | 以消息往返为主 | 围绕目标自主规划并执行多步操作 |
| 风险控制 | 主要控制发送给模型的内容 | 还需要控制文件和命令权限 |

只需要讨论和生成内容时，先用对话助手。任务需要访问本地工作区或执行操作时，再使用智能体。

## 常见工作流

### 第一次使用

1. 在[模型服务](../../pre-basic/providers/)中添加服务商和模型。
2. 打开[对话](chat.md)，发送一条测试消息。
3. 从[助手库](assistants.md)添加常用助手。
4. 在[数据设置](../../pre-basic/data-settings/)中配置备份。

### 基于资料问答

1. 在[知识库](knowledge-base.md)中新建知识库。
2. 导入文件、网址或其他支持的数据源。
3. 等待资料处理完成。
4. 在对话中选择知识库后提问。

### 执行项目任务

1. 在[资源库](library.md)中创建智能体。
2. 选择模型、权限模式、技能和工具。
3. 打开智能体并确认工作区。
4. 用清晰目标开始任务，执行过程中检查权限请求和文件改动。

### 随时调用 AI

* 使用[快捷助手](quick-assistant.md)在不切换当前应用的情况下提问。
* 使用[划词助手](selection-assistant.md)翻译、总结或改写已经选中的文字。

## 自动化与外部接入

当基础功能无法覆盖工作流时，可以继续使用：

* [MCP](../../advanced-basic/mcp/)：为对话助手连接外部工具和数据。
* [API 服务器](../../advanced-basic/api-server.md)：通过兼容接口调用本地 Cherry Studio 能力，也是 V2 智能体运行链路的一部分。
* [频道](../../advanced-basic/agent-channels.md)：把智能体接入支持的消息渠道。
* [定时任务](../../advanced-basic/scheduled-tasks.md)：按时间触发智能体会话。

{% hint style="info" %}
先完成模型服务和数据备份，再逐步启用智能体、MCP、频道或定时任务。涉及文件写入、命令执行和外部发送时，应使用满足任务所需的最小权限。
{% endhint %}
