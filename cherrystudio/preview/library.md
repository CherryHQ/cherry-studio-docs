# 资源管理入口

Cherry Studio V2 不再提供独立的“资源库”页面。助手、智能体、技能和提示词仍然可以管理，但入口已经移动到各自的使用场景中。

{% hint style="warning" %}
旧版 `/app/library` 路由已停止提供，启动台也没有“资源库”图标。升级后，旧的资源库固定标签会被自动移除；不要继续按照旧截图寻找该页面。
{% endhint %}

## 当前入口

| 资源 | 在哪里管理 | 主要操作 |
| :--- | :--- | :--- |
| 助手 | 打开**对话**，在左侧资源菜单进入助手管理 | 新建、导入、编辑、复制、导出、分组和删除助手 |
| 智能体 | 打开**工作**，在左侧资源菜单进入智能体管理 | 新建、编辑、配置工作目录与工具、删除智能体 |
| 技能 | 打开**设置 → 技能** | 搜索、安装、查看和卸载全局技能 |
| 提示词 | 在对话输入框打开**快捷短语**，选择**管理**或**添加** | 新建、编辑、搜索、插入和删除可复用提示词 |

这些入口会直接显示在当前工作上下文中。例如，在助手管理中完成编辑后，可以返回对话继续使用，不需要先离开到一个独立资源页面。

## 助手库与资源管理

[助手库](assistants.md)仍用于浏览和导入社区助手。导入后的助手会进入你的助手列表，并在**对话**页面的助手管理入口中维护。

助手库不是旧“资源库”页面的替代路由：

- 助手库提供社区内容；
- 助手管理维护你已经拥有的助手；
- 智能体、技能和提示词使用上表中的独立入口。

## 旧链接无法打开

如果书签、历史记录或旧教程包含 `/app/library`：

1. 不要重复刷新该地址。
2. 根据资源类型打开上表中的新入口。
3. 旧固定标签在应用恢复时会被清理，不会删除实际的助手、智能体、技能或提示词数据。

全局搜索也会过滤旧资源库路由记录，避免再次打开已经移除的页面。
