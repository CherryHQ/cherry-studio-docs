# 知识库

知识库可以把文档、网页等资料整理成可检索的参考库。聊天时，Cherry Studio 会先从知识库召回相关片段，再把片段交给模型生成回答。

知识库不会训练或修改模型。它更适合需要反复查询、跨对话复用，或者资料总量较大的场景。

{% hint style="info" %}
这是知识库的快速上手页。需要了解每一项参数时，请查看[完整知识库教程](../../knowledge-base/knowledge-base.md)。
{% endhint %}

## 使用前准备

创建知识库前，至少需要启用一个支持**嵌入（Embedding）**能力的模型。嵌入模型会把资料和问题转换为可检索的数据。

建议提前确认：

* 模型服务已配置完成，嵌入模型可以正常调用
* 扫描版 PDF 或复杂文档已配置合适的文档处理方式
* 需要进一步优化排序时，再准备重排序（Rerank）模型

可参考：

* [嵌入模型参考](../../knowledge-base/emb-models-info.md)
* [文档预处理](../../knowledge-base/document-preprocessing.md)

## 创建知识库

1. 在启动台打开 **知识库**。
2. 点击左侧的添加按钮，选择创建知识库。
3. 输入知识库名称。
4. 如有需要，将知识库放入已有分组。
5. 选择一个已启用的嵌入模型，然后完成创建。

{% hint style="warning" %}
嵌入模型和向量维度决定了知识库的索引格式。后续更换模型或维度时，需要重建知识库；因此建议在批量导入资料前先确定配置。
{% endhint %}

## 添加资料

进入知识库后，点击添加资料，并选择来源。

| 来源 | 适合内容 | 当前说明 |
| --- | --- | --- |
| 文件 | 单个或多个本地文件 | 支持 PDF、DOCX、MD、XLSX、TXT、CSV、EPUB |
| 文件夹 | 一组本地资料 | 选择文件夹后批量导入其中的文件 |
| 网址 | 单个网页 | 输入网页地址并提取页面内容 |
| Sitemap | 网站中的多篇页面 | 输入 Sitemap 地址后批量发现网页 |
| 笔记 | 手动输入内容 | 当前版本的添加界面尚未开放提交 |

添加任务提交后，可以关闭对话框继续使用应用。资料读取、分块和嵌入会在后台继续进行。

## 等待索引完成

资料会依次经历准备、读取、处理和嵌入等阶段。不同来源显示的中间状态可能不同，最终以状态为**已完成**为准。

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 准备中 / 读取中 / 处理中 / 嵌入中 | 正在建立索引 | 保持应用运行并等待 |
| 已完成 | 可以被检索和用于聊天 | 先做一次召回测试 |
| 失败 | 当前资料未完成索引 | 修复模型、网络或文件问题后重新索引 |
| 删除中 | 正在清理资料及索引 | 等待清理完成 |

只有完成索引的内容才能稳定参与检索。正在处理的资料不能强制重新索引；需要等待它完成或失败后再操作。

## 检查和管理资料

知识库的数据源页面提供以下操作：

* 按文件、文件夹、网址或 Sitemap 筛选
* 搜索资料名称并查看已就绪数量
* 预览提取后的内容
* 查看资料被切分后的片段
* 删除单个片段
* 对已完成或失败的资料重新索引
* 多选资料后批量重新索引或删除

如果原文件已经更新，重新索引可以用新内容替换旧索引。删除资料时，对应的检索数据也会异步清理。

## 先做召回测试

在知识库顶部打开**召回测试**，输入一个用户实际可能提出的问题。

测试结果会显示匹配片段、得分、排序和耗时。重点检查：

* 正确资料是否出现在前几条结果中
* 召回片段是否包含回答问题所需的信息
* 片段是否过长、过短或被错误切断
* 无关结果是否过多

如果召回结果本身不准确，聊天模型通常也无法给出可靠答案。应先调整资料或检索配置，再测试聊天效果。

## 在聊天中使用

### 临时选择知识库

1. 打开**对话**并进入一个聊天。
2. 在输入框的工具区域打开知识库选择器。
3. 选择一个或多个知识库。
4. 提出与资料相关的问题。

该入口只会在当前助手和工具模式支持知识库时可用。当输入框已经附加文件时，知识库选择会被禁用；先移除附件再选择知识库。

### 固定到助手

如果某个助手需要长期使用同一组资料，可以打开**资源库 → 助手**，编辑助手并关联知识库。以后使用该助手时，不必每次重新选择。

更多助手设置请查看[助手](assistants.md)。

{% hint style="warning" %}
知识库负责提供相关片段，最终回答仍由聊天模型生成。重要结论应结合引用片段和原始资料复核。
{% endhint %}

## 调整 RAG 设置

点击知识库顶部的 RAG 设置按钮，可以调整检索流程。

| 设置 | 作用 | 调整提示 |
| --- | --- | --- |
| 文件处理器 | 把文档转换为可分块文本 | 扫描件、图片或复杂版式优先检查此项 |
| 分块大小和重叠 | 决定每个检索片段的范围 | 改动后，已有资料需要重新索引 |
| 嵌入模型和维度 | 生成并存储向量索引 | 改动会触发重建或恢复流程 |
| 搜索模式 | 在向量、关键词或混合检索之间选择 | 一般先使用默认的混合检索 |
| 结果数量 | 控制返回给模型的片段数量 | 过少可能漏信息，过多可能引入噪声 |
| 相似度阈值 | 过滤相关性不足的结果 | 仅在相应检索模式下生效 |
| 混合权重 | 平衡语义匹配和关键词匹配 | 专有名词较多时可结合召回测试调整 |
| 重排序模型 | 对初次召回结果再次排序 | 会增加一次模型调用和等待时间 |

建议一次只改一类参数，并用同一组问题重复召回测试，便于判断哪项调整真正有效。

## 常见问题

### 创建时没有可选的嵌入模型

检查模型服务是否已启用、模型是否带有嵌入能力标记，以及 API 配置是否可用。普通聊天模型不会出现在嵌入模型列表中。

### 资料一直处理中或显示失败

先等待当前任务结束，再检查网络、模型服务、文件格式和文档处理器。修复后，对已失败的资料执行重新索引。

### 扫描版 PDF 没有有效文字

扫描版 PDF 通常只有图片，需要使用支持 OCR 或图片解析的文档处理方式。请参考[文档预处理](../../knowledge-base/document-preprocessing.md)。

### 召回不到正确内容

先确认资料已经完成索引，再用召回测试定位问题。可以依次检查原文质量、分块大小、搜索模式、结果数量、阈值和重排序配置。

### 聊天没有使用知识库

确认当前聊天已经选中知识库、目标资料状态为已完成，并且助手与工具模式支持知识库。若输入框附加了文件，请先移除附件。

## 数据、隐私和费用

知识库元数据和向量索引由 Cherry Studio 管理。根据所选的文档处理、嵌入、重排序和聊天服务，原文或提取后的内容可能会发送给相应服务商处理；回答时，召回片段也会发送给当前聊天模型。

导入敏感资料前，请确认服务商的数据政策和部署方式。建立索引、重新索引、重排序和聊天回答也可能产生模型调用费用。

知识库相关文件和清理方式请查看[知识库数据](../../knowledge-base/data.md)。
