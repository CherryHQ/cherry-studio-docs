# 助手与助手库

{% hint style="warning" %}
V2 已移除独立的「助手库」启动台/侧边栏页面。助手预设没有消失，而是改为直接在**助手对话页**中浏览和管理。
{% endhint %}

**命名说明**：Cherry Studio 中有两个相关但不同的概念，请注意区分：

* **助手 / 助手库**：用于普通对话的「角色 + 提示词 + 参数」预设。助手库是对话页内的预设目录，添加后会出现在助手列表中。
* **Agent**：能够自主调用工具、访问文件并执行多步任务。入口：顶部导航的 **工作**。如需让其他应用调用 Cherry Studio 中的模型，可另行配置[本地 API 网关](../../advanced-basic/api-server.md)，但它不是运行 Agent 的前置条件。详见 [Agent](../../advanced-basic/agent.md)。

两者是不同模块：助手侧重日常对话，Agent 侧重工具调用与任务执行。

### 使用前需要什么？

创建助手前，需要先在 `设置 → 模型服务` 中启用至少一个对话模型。还没有可用模型时，请先完成[快速开始](../../getting-started/quick-start.md)。

### 进入资源库

进入顶部 **对话**，点击助手列表右上角的 **展示方式 → 管理助手**。资源库用于搜索、创建、导入、编辑和分组管理自己的助手。

<figure><img src="../../.gitbook/assets/cherry-resource-library-v2.png" alt="Cherry Studio V2 浅色模式的助手资源库，右上角提供新建助手、助手库和导入助手入口"><figcaption><p>V2 助手资源库</p></figcaption></figure>

### 在助手库中查找助手

点击资源库右上角的 **助手库**，可浏览 Cherry Studio 提供的助手预设；顶部搜索框用于按名称或描述查找资源。

### 添加到我的助手

1. 点击右上角 **助手库**；
2. 选择需要的助手预设并添加；
3. 返回资源库或对话页助手列表确认结果。

添加后的助手可以继续编辑、分组或导出。

### 创建自己的助手

1. 在资源库右上角点击 **新建助手**
2. 按向导完成三个步骤：
   * **基础信息**：设置头像、名称、模型和描述；名称与模型为必填项，向导会优先带入可用的默认模型
   * **角色设定**：填写系统提示词，决定助手的角色与行为
   * **知识库**：按需关联已有知识库，让助手在对话时检索相关资料
3. 检查信息后点击 **创建**

**成功标志**：新助手出现在助手列表中；打开一个新话题并发送消息后，可以收到符合角色设定的回答。

{% hint style="info" %}
创建时必须选择一个模型。创建完成后，仍可在对话页顶部切换当前话题使用的模型，或在助手设置中更改默认模型。
{% endhint %}

{% hint style="info" %}
**提示词改写**：提示词输入框右上角的闪电按钮即「AI 优化提示词」，点击后会用全局默认助手模型把当前内容改写得更结构化。
{% endhint %}

### 分组管理

V2 使用**分组**组织助手：

* 一个助手只能属于一个分组，也可以保持未分组
* 可在助手列表中切换 **按分组显示**
* V1 的助手标签会在升级时自动迁移为分组，原有顺序会保留
* 分组不再使用标签颜色

### 导入 / 管理

资源库内可完成以下操作：

* **搜索**：按关键词查找助手
* **从外部导入**：支持从 JSON 文件、剪贴板内容或 URL 导入他人分享的助手
* **管理助手**：编辑、复制、删除、导出或调整分组
* **创建助手**：新建自己的助手

点击右上角 **导入助手**，打开“从外部导入”对话框：

* **文件**：选择本地 JSON 文件
* **剪贴板**：粘贴或读取已复制的助手 JSON
* **URL**：填写可直接访问的助手 JSON 地址

选择来源并确认解析结果后点击 **导入**。V2 当前提供一次性导入，不包含持续同步的助手订阅流程。

<figure><img src="../../.gitbook/assets/cherry-assistant-import-v2.png" alt="Cherry Studio V2 从外部导入助手对话框，支持文件上传、剪贴板和 URL 导入"><figcaption><p>V2 助手导入对话框</p></figcaption></figure>

### 何时使用助手库，何时使用 Agent？

| 场景 | 推荐 |
|---|---|
| 个性化"角色"快速对话（写作、翻译、技术问答等） | **助手库** |
| 让 AI 自主调用工具、读写文件、跨步骤完成任务 | **[Agent](../../advanced-basic/agent.md)** |
| 定时执行、跨平台消息推送 | **Agent + [定时任务](../../advanced-basic/scheduled-tasks.md) + [频道](../../advanced-basic/agent-channels.md)** |

### 下一步

* 想让助手根据自己的资料回答：创建[知识库](../../knowledge-base/knowledge-base.md)并关联到助手；

* 想调整模型、温度和工具栏：继续阅读[对话界面](chat.md)。
