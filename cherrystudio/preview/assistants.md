# 助手库

助手库是 Cherry Studio 的对话助手预设市场。预设主要保存名称、图标、提示词和部分默认配置；把预设添加到对话后，它会成为一个可独立编辑的助手。

{% hint style="warning" %}
助手库中的“助手”用于角色对话，不等同于 [Cherry Agent 智能体](../../advanced-basic/agent.md)。需要访问工作区、读写文件、执行命令或连续调用工具时，请使用智能体。
{% endhint %}

## 助手库、对话助手和资源库

| 名称 | 用途 |
| --- | --- |
| 助手库 | 浏览内置预设、维护自己的预设、导入或订阅预设源 |
| 对话助手 | 已经添加到[对话页](chat.md)的可用助手；拥有自己的话题和设置 |
| [资源库](library.md) | 集中创建和编辑模型、助手、智能体等资源；适合完整配置 |

从助手库添加预设时，Cherry Studio 会复制一份新的对话助手。之后修改或删除原预设，不会自动改动已经创建的助手。

## 打开助手库

可以通过以下入口打开：

* **启动台 → 助手库**。
* 对话页助手列表中的添加按钮。

如果只是想快速增加一个助手，从对话页添加入口搜索预设更快；需要浏览分类、导入、订阅或批量管理时，进入完整助手库。

## 浏览和搜索预设

助手库左侧按“我的”和用途分类组织预设，主区域显示当前分类中的卡片。

* **分类**：查看当前内置或订阅源提供的分类。
* **搜索**：按名称和描述跨分类查找。
* **卡片预览**：查看名称、说明和提示词摘要。
* **我的**：查看自己创建或导入的预设。

分类和数量会随应用版本、当前语言或订阅源变化，文档不列出固定清单。

## 从预设创建对话助手

1. 找到需要的预设。
2. 点击卡片，查看提示词和说明。
3. 选择 **添加到助手**。
4. 返回[对话页](chat.md)。
5. 在助手列表中选择刚添加的助手，并在顶部选择模型。

添加后，助手会拥有独立 ID 和默认话题。可以继续修改提示词、模型、知识库、MCP 和模型参数，而不影响助手库中的原预设。

## 创建自己的助手

有两种方式，适合不同需求。

### 在助手库创建轻量预设

点击 **创建助手**，填写：

* **名称**：用于搜索和识别。
* **Emoji**：助手图标；未选择时会尝试从名称中提取。
* **提示词**：定义角色、目标、边界和输出方式。
* **知识库**：可选；关联已经创建的知识库。

名称和提示词不能为空。提示词编辑区可以调用默认助手模型进行优化，也可以撤销本次 AI 改写。

保存后，预设会出现在“我的”中。要在对话中使用它，还需要点击该预设并选择 **添加到助手**。

### 在资源库创建完整助手

需要一次性设置模型、标签和高级参数时，建议进入[资源库](library.md)创建助手。完整编辑器包含：

* 名称、Emoji、描述、标签和模型。
* 系统提示词。
* Temperature、Top P、最大输出、上下文数量和流式输出。
* 工具调用模式、最大工具调用次数和自定义参数。
* 知识库。
* MCP 模式和服务器。

完整编辑器仍要求名称和提示词。没有明确需求时，模型参数保持默认值即可。

## 模型如何确定

通过助手库创建或导入轻量预设时，Cherry Studio 会使用当前[默认助手模型](../../pre-basic/settings/default-models.md)作为预设默认模型。添加到对话后，可以在对话顶部切换模型。

通过资源库创建完整助手时，可以在保存前直接选择模型。

模型设置不应写进系统提示词。需要换模型时使用模型选择器，便于检查服务商和实际模型 ID。

## 导入助手预设

点击 **导入**，选择以下方式之一：

### 从 URL 导入

1. 选择 **URL**。
2. 粘贴可以直接返回 JSON 的地址。
3. 点击导入。

### 从文件导入

1. 选择 **文件**。
2. 选择 `.json` 文件。
3. 点击导入。

导入内容可以是一个对象或对象数组。每个预设至少需要 `name` 和 `prompt`：

```json
[
  {
    "name": "文档审阅助手",
    "emoji": "📝",
    "description": "检查结构、术语和可执行性",
    "prompt": "你负责审阅产品文档，并给出具体修改建议。"
  }
]
```

导入时会为每个预设生成新的本地 ID，并使用当前默认助手模型。来源文件中的旧话题和消息不会作为对话历史导入。

{% hint style="warning" %}
只导入可信来源。预设提示词可能包含隐藏目标、外部链接或不适合你的行为要求；添加到对话前应先检查提示词。
{% endhint %}

## 订阅助手源

订阅适合由团队或社区维护一组远程预设：

1. 点击 **导入**。
2. 在订阅区域填写可以直接返回 JSON 数组的 HTTP(S) 地址。
3. 点击 **订阅**。
4. Cherry Studio 重新加载后，从该地址读取系统预设。

订阅源可用时，它会作为系统预设来源。远程读取失败时，Cherry Studio 会回退到应用内置预设。取消订阅后恢复使用内置预设。

订阅与一次性导入的区别：

| | 一次性导入 | 订阅 |
| --- | --- | --- |
| 数据位置 | 导入为本地“我的”预设 | 启动或重新加载时从远程源读取 |
| 后续更新 | 不自动变化 | 远程源更新后可随重新加载更新 |
| 是否适合本地修改 | 适合 | 建议由订阅源统一维护 |

详细格式和维护方式见[助手订阅](../../pre-basic/data-settings/assistants-subscribe.md)。

## 管理“我的”预设

在“我的”分类中，可以通过卡片菜单或 **管理助手** 完成：

* 编辑预设。
* 添加为对话助手。
* 导出单个预设为 JSON。
* 删除预设。
* 拖动调整顺序。
* 批量选择、导出或删除。

批量导出的 JSON 可以在其他设备再次导入。删除预设前，确认它是否仍需要用于创建新助手；已经添加到对话的助手不会随预设一起删除。

## 修改已经添加的助手

预设添加到对话后，请在对话助手设置或资源库中修改。常见配置包括：

* 系统提示词。
* 当前和默认模型。
* 知识库与联网搜索。
* MCP 工具。
* 上下文和输出参数。

完整对话操作见[对话界面](chat.md)。

## 助手还是智能体

| 需求 | 推荐 |
| --- | --- |
| 固定角色的问答、写作、翻译或分析 | 对话助手 |
| 复用和分享提示词模板 | 助手库预设 |
| 集中编辑模型、参数、知识库和 MCP | 资源库中的助手编辑器 |
| 访问工作区、读写文件、执行命令 | [智能体](../../advanced-basic/agent.md) |
| 定时执行并向外部渠道发送结果 | 智能体 + [定时任务](../../advanced-basic/scheduled-tasks.md) + [频道](../../advanced-basic/agent-channels.md) |

遇到导入失败、订阅源无法读取或预设异常时，请通过[反馈与建议](../../question-contact/suggestions.md)提供 JSON 示例、地址返回状态和错误信息；提交前删除隐私数据或密钥。
