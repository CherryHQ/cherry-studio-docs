# 文件

文件页面用于查看和清理 Cherry Studio 文件索引中的内容，例如对话附件、粘贴的图片，以及部分由应用生成或保存的文件。

它不是电脑中的通用文件管理器，也不会自动展示磁盘上的所有文件。

{% hint style="info" %}
知识库的数据源由知识库页面单独管理，不一定会出现在这里。需要更新、重新索引或删除知识库资料时，请前往[知识库](knowledge-base.md)。
{% endhint %}

## 打开文件页面

1. 点击窗口顶部标签栏右侧的 **+**，打开新的启动台标签页。
2. 在启动台点击**文件**。

页面左侧是类型筛选，右侧是当前分类中的文件。

## 查看和筛选文件

左侧提供四个分类：

| 分类 | 显示内容 |
| --- | --- |
| 文档 | 被识别为文档的文件 |
| 图片 | 图片文件 |
| 文本 | 纯文本或文本类文件 |
| 所有文件 | 文件索引中的全部内容 |

页面默认打开**文档**分类。切换分类时，当前的多选状态会被清除。

### 排序

可以按以下字段排序：

* 创建时间
* 大小
* 文件名

第一次点击某个字段会按降序排列；再次点击同一字段会切换为升序。

### 文件信息

文档、文本和“所有文件”使用列表显示。每一项包含文件名、扩展名、创建时间、计数和文件大小。

图片分类使用缩略图网格，便于快速浏览。

## 打开或预览

### 文档和文本

点击列表中的文件名，Cherry Studio 会调用系统为该格式设置的默认应用打开文件。

如果文件已被移走、磁盘权限不足，或系统没有可用的默认应用，打开操作可能失败。

### 图片

点击图片缩略图会打开图片查看器。可以在查看器中切换当前分类里的其他图片。

## 重命名文件

在文档、文本或“所有文件”列表中：

1. 找到目标文件。
2. 点击该行右侧的编辑按钮。
3. 输入新名称并确认。

如果新名称没有包含原扩展名，Cherry Studio 会自动保留原扩展名。

{% hint style="warning" %}
重命名只改变 Cherry Studio 显示和管理的文件名，不会修改文件内容。
{% endhint %}

## 删除单个文件

### 文档和文本

点击文件行右侧的删除按钮，然后在确认框中确认。

### 图片

将鼠标移到图片缩略图上，点击右上角的删除按钮，然后确认。

删除会同时清理文件及其在消息中的附件引用。此操作无法在 Cherry Studio 中撤销。

如果图片仍被绘画记录使用，Cherry Studio 会阻止删除并显示提示。需要先在绘画中处理相关记录。

## 批量删除

批量操作适用于文档、文本和“所有文件”分类，图片分类不提供批量选择。

1. 勾选需要删除的文件，或点击右上角的**全选**。
2. 打开批量操作菜单。
3. 选择**批量删除**并确认。

{% hint style="warning" %}
批量删除同样会移除这些文件在消息中的附件引用。执行前请确认重要文件已有独立备份。
{% endhint %}

## 哪些文件会出现在这里

通常会看到：

* 在对话中上传或粘贴并保存到应用文件目录的内容
* 聊天过程中生成并写入文件索引的图片或其他结果
* 被 Cherry Studio 旧版文件流程登记的本地文件

以下内容不一定显示：

* 电脑磁盘中从未添加到 Cherry Studio 的文件
* 仅保存在外部服务商服务器上的文件
* 由新版知识库数据源单独管理的原始资料
* 已从文件索引中删除的内容

要在聊天中添加新附件，请前往[对话](chat.md)，使用输入框中的附件按钮或直接拖入文件。

## 存储位置

文件内容保存在 Cherry Studio 的应用数据目录中。建议通过**设置 → 数据设置 → 数据目录**查看或迁移，不要在应用运行时手动移动、重命名或删除目录中的内部文件。

具体位置和迁移方法请查看[修改存储位置](../../pre-basic/personalization-settings/storage.md)。

## 常见问题

### 删除文件后，旧消息里的附件不见了

这是当前删除行为的一部分：文件被删除时，对应的消息附件引用也会被移除。需要保留历史附件时，请不要从文件页面删除原文件。

### 找不到知识库里导入的资料

知识库使用自己的数据源和索引管理流程。请在知识库详情页查看、重新索引或删除资料。

### 点击文件名没有反应

确认文件仍存在，并检查系统是否为该扩展名配置了默认应用。如果应用数据目录被手动移动，也可能导致原路径失效。

### 无法删除某张图片

该图片可能仍被绘画记录使用。先打开绘画页面处理相关记录，再返回文件页面删除。
